# 上下文退化模式：技术参考

## 注意力分布分析

**U 形曲线测量。** 对上下文中每个位置测量模型的注意力权重；把前 10% 与后 10% 归为「注意力偏好区」，其余归为「注意力退化区」。

**中间迷失检测。** 给定关键信息所在位置列表，检查它们落在哪个区。任何关键位置落在退化区即「有风险」，对应建议：把关键信息移到偏好区；用显式标记突出关键信息；考虑拆分上下文以缩短中段。

## 上下文投毒检测

**幻觉追踪。** 从每轮文本抽取主张，记录「已验证 / 未验证 / 验证为假」。投毒风险指标：存在验证为假的主张，或未验证主张超过总数的 30%。

**错误传播分析。** 对每个已知错误点，找出其后所有引用它的内容，构建影响图；被三处以上下游引用的错误点视为高影响区，需要干预。

## 干扰度量

**相关性评分。** 把任务描述与每个上下文元素做嵌入相似度；按得分排序；低于阈值（自适应计算或固定值）的标为潜在干扰项，建议移除。

## 退化监控

**上下文健康评分。** 综合指标：token 数、占用率（token / 窗口上限）、注意力分布、相关性得分、最近 token 占比。综合分 = 1 − 占用惩罚（占用率 × 0.5，上限 0.3）− 注意力惩罚 − 相关性惩罚。解释：> 0.8 健康；> 0.6 警告；> 0.4 退化；否则危急。

**告警阈值参考：**

| 指标 | 阈值 |
|---|---|
| 占用率警告 | 70% |
| 占用率危急 | 90% |
| 中段注意力退化占比 | 30% |
| 相关性下限 | 0.3 |
| 连续警告触发告警 | 3 次 |

## 恢复流程

**恢复截断策略。** 上下文退化到无法挽回时按优先级截断：
1. 始终保留系统提示词与工具定义
2. 保留最近的对话轮次（如最近 10 轮）
3. 保留关键的检索文档
4. 仍超目标时，先摘要最旧的文档类内容
5. 还超，就截掉最旧的轮次（至少保留最近 5 轮）
