## 已核验

- 13 项自动测试全过，无跳过。覆盖本机 HTTP 请求、独立运行、自有输入、错误退出码、拒绝覆盖空或非空输出目录、原件保护和确定性构建。
- 打包器仅收录 Git 跟踪的技能文件，并将实际字节与 HEAD blob 对照。临时私有仓库回归确认 ignored/untracked 本地配置不会入包，隐藏的源文件修改也不会误标为提交快照；独立审查七项聚焦检查通过。
- 另一维护者 AI 只取得 ZIP 和说明，在含空格的新目录完成三个正式候选演示。清单覆盖的 45 个文件与 3 份清单自身均无运行修改；接口保留原脚本 1/0，报价缺项保持未知、补齐差额 1500，PPT 两处小字号修复后仍保留一处未知。
- 正式发布后，不带账号或 Cookie 从公开地址各取回一次三个 ZIP 和两份校验文件，全部 HTTP 200，与正式候选逐字一致；GitHub 服务端摘要与大小也匹配。
- 三个原技能共 22 份文件及原有未跟踪文件保持不变。新包代码使用 MIT，技能说明及合成内容使用 CC BY 4.0，保留来源和作者。

验证环境是 macOS / Python 3.12.12。未声明其他系统执行验证；PPT 的逐页视觉验收仍需演示软件。API 样例需要系统允许本机回环端口；报价与 PPT 不发网络请求。
