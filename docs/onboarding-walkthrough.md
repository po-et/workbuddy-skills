## 步骤

**1. 登录**
- 浏览器面板已停在 https://open.workbuddy.cn 的登录页
- 主入口「微信登录」；底部备选「手机号 / 邮箱 / SSO」。建议微信，与你客户端账号体系一致
- 登录前需勾选并同意三份协议：《WorkBuddy 开放平台开发者服务协议》《隐私保护指引》《数据处理协议》。**勾选是你的动作**，建议扫一眼服务协议里的"知识产权"与"分成"条款，有异议告诉我

**2. 选择认证类型 → 个人认证**
- 每账号最多创建一个个人主体
- 「一个账号，可以同时做个人认证和企业认证」——以后要做 Buddy 应用再补企业认证，不冲突

**3. 填写个人认证信息**（官方必填项）
- 开发者真实姓名
- 身份证号码
- 已完成实名登记的本人手机号（会收验证码）
- 可以正常接收验证码的邮箱
- 人脸识别（手机完成）

**4. 填写开发者资料**（认证通过后或同步填写，之后可在「设置—开发者信息」修改）

| 字段 | 规则 | 填这个 |
|---|---|---|
| 开发者头像 | 512×512，≤5000KB，JPG/PNG，必填 | `dist/avatar-captain-512.png` 或自备 |
| 开发者昵称 | 2—20 字符，必填；不能纯数字/空格/emoji，不能含「官方、平台、客服、管理员、admin」 | `Captain` |
| 开发者简介 | 20—120 字符，必填；「说明专业方向与主要资产」 | 见下方，二选一 |
| 联系方式 | 至少 1 项，最多 5 项：官网 / 联系邮箱 / 公众号 / 自定义 | 官网填仓库地址；邮箱填个人邮箱 |

资料是**公开主页**：头像、昵称、认证标识、简介、联系方式、已发布资产都对外展示。

**5. 等审核**
- 官方指南未写个人认证时长；第三方入驻文称「官方说 7 个工作日左右」。**待确认**，通过后记一下实际用时
