# 报价显微镜

一个无需登录的中文静态网页：粘贴两份购车报价，核对 3 项条件与 7 项费用，保留原文证据，确认后比较录入范围并下载报告。

公开体验：<https://po-et.github.io/workbuddy-skills/quote-lens/>

## 使用

将本目录完整放到支持静态文件的 HTTPS 站点，打开 `index.html`。不需要构建、运行时 CDN、API 密钥或服务端。使用标准 ES modules，直接双击 `file://` 打开可能被浏览器的模块策略阻止。

1. 选择公开合成案例，或点击“粘贴自己的报价”。每项费用单独一行，注明元或万元更易核对。点击“体验已核对案例”会重新载入公开样例，并明确预设有唯一原文候选项的确认状态，真正缺项仍未知；这不是独立真人核对。正常载入、自有输入与修改后均需逐项确认。
2. 点“提取并核对”，再点击金额回到原文；逐项确认两侧费用与车型/配置、付款方式、费用范围。
3. 原文没有的金额保持未知；明确的 0 元可以确认。手工修改会撤回原文证据，必须填写补充来源再确认；可用单项“恢复原文”重新获得待确认候选。改动一侧原文后，仅重新提取该侧，另一侧的确认与补充保留。
4. 费用齐全、逐项已确认且条件一致时，才显示完整差额。未齐时只显示已知小计。
5. 下载 Markdown 或 JSON 报告。默认省略原文、摘录与自由文本条件，仍保留金额、来源类别与核对状态；主动勾选后才包含这些文本。省略原文不代表适合公开分享，请自己检查内容。

三个样例与补充回复均为原创合成数字，不是真实行情或税费政策。工具不推算税费，不推荐车型、商家或融资方案。

## 数据与草稿

报价在浏览器本机处理，不发起报价上传或远程计算请求。只有点击“保存到本机”才保存草稿，草稿包含两份原文与人工补充，即使某侧原文待重新提取，补充草稿也会保留；恢复后所有确认失效，必须重新核对。切换案例或恢复内容不同的草稿前会提示覆盖风险，取消会保留当前内容。清空当前输入不会删除本机草稿。“清除本机草稿”不会清空当前输入。

导出与剪贴板均由明确点击触发。浏览器拒绝剪贴板时会显示可手工复制的文本；拒绝本机存储时给出失败反馈。

## 文件与实现来源

- `engine.js`：WorkBuddy 客户端创建的纯逻辑初版；维护者随后修复边界与报告输出，真实来源记录以项目外的开发证据为准。
- `samples.js`：WorkBuddy 客户端创建的三组合成案例。
- `index.html`、`styles.css`、`app.js`、`icon.svg`：Codex 辅助实现静态前端；随后在 WorkBuddy 中由 GLM-5.3 修复状态管理、Step-5-Preview 补齐覆盖守卫，维护者独立复核。不是全部由 WorkBuddy 原生生成。

前端不依赖框架。用户文本通过 `textContent` 与 DOM API 呈现，不拼入 HTML。七项费用的金额以分为单位交给纯逻辑引擎。

## 验证与限制

2026-10-23，当前逻辑引擎的 18 项 Node 行为检查通过；维护者已在匿名公开页面核验独立合成原文输入、20 项确认、126.60 元差额、条件不同阻断、零元删除撤回、人工补充来源、原文定位和两种报告格式的原文开关。这些是维护者合成算例检查，不代表独立真人采用。状态保护修订另做受影响路径的浏览器复核，版本以 `provenance.json` 文件哈希为准。

关键词提取只生成候选，不保证理解所有商家的自由文本。图片、PDF 不提供识别，歧义内容应手工补充来源；条件比较采用文本核对，不折算全款与分期的成本。同条件及 7 项齐全也只代表录入范围可比较，不代表已经收集全部交易条件。
