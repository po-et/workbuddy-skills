# 报价显微镜：报价证据核对

用于用户已经取得两份购车报价、希望核对费用的任务。仅比较录入范围，不推荐车型、商家或融资方案，不推算税费政策或实时价格。此为独立作品，非官方 Skill；本文件自包含，不需要安装依赖、联网或下载其他文件。

## 核对步骤

1. 收集报价 A、B 的原文，分别编号行或段。缺少一份时先说明还不能比较，不编造报价。图片无法可靠辨认时请用户补充可读文本，辨认不清的数字保持未知。
2. 分别列出 3 项条件：车型/配置、付款方式、费用范围。保留原文及对应位置；没有写明、不明确或存在矛盾时标为待核对。请用户确认，不能默认两份一致，也不能自行折算全款与分期差异。
3. 分别抽取 7 项费用：裸车价、报价税费、保险、上牌、服务费、强制附加项、其他费用。每项记录金额、单位、来源位置及确认状态。原文未报不等于 0；只有明确的零元且用户确认后才能按零计入。某行多个金额、同项冲突或范围不明时保留全部候选，不能随意取第一个。
4. 让用户逐项核对候选。手工修改或补充必须单独注明补充内容及来源，不把旧原文当作新金额证据；修改后撤回该项旧确认。原文变化后，重新提取该份报价并重新确认，不复用失效证据。
5. 使用十进制精确金额或整数分计算，先统一单位再求和；不得用二进制浮点结果直接作为金额结论。元的小数最多 2 位，万元同样检查格式并换算为分。拒绝负数、NaN、Infinity、非法千位分隔、超出安全范围或无法确定单位的值，保留原文等待核实。存在工具时用本机确定性计算工具复核；工具不可用时明确尚缺独立计算复核。
6. 将已知小计与完整合计分开。已知小计只累加当前有效金额，并标明包含多少项、哪些尚未确认；不得暗补未知值。仅当 7 项全部有明确金额且确认后提供完整录入合计。原文另有合计时单独交叉核对，差额不能反推为某缺项的金额。
7. 只有两份 7 项费用全部确认、3 项条件全部确认且一致，才能输出差额。按“B 减 A”逐项计算并检查分项差额之和等于合计差额；其他情况输出阻断原因和具体追问，不判断谁更便宜。

## 结果格式

先给出结论：**待补齐 / 待确认 / 条件不同 / 录入范围可比较**。多种问题并存时全部列出；“可比较”仅描述已录入范围。

随后输出：

- 条件表：项目、A、B、来源位置、确认状态、是否一致。
- 费用表：7 项费用的 A/B 金额、来源位置、确认状态；未知写“未报价/待核实”，不写 0。
- A/B 已知小计、有效项数；符合条件时另列完整合计。
- 符合比较条件时列 B 减 A 的分项与合计差额；否则列出阻断项。
- 编号追问清单，逐条指明哪份报价、哪项费用或条件需要补充。例如：“请明确报价 B 服务费的金额；若为 0 元，请书面明示。”

在当前任务中按需呈现原文证据。默认供用户带走的报告省略原文、摘录及自由文本条件，仅保留金额、状态与来源位置；包含这些文本前先取得用户选择。省略原文不等于已彻底去除个人信息，分享前仍需用户检查。不得自动联系销售、上传报价或对外发送报告。
