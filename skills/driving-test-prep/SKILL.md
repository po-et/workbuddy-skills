# 驾照考试

定位一句话：**科目一、四考的是读懂题意、记准规则；科目二、三考的是紧张时也能按固定顺序把动作做完。前者靠分类整理，后者靠把每个动作练成不用想的流程。**

## 何时使用

用户这样说时用本技能：

- 「科目一模拟总是八十几分，错的多是数字题」——理论刷了很多题仍错同一类
- 「最近模拟成绩忽高忽低，不知道能不能去约考」
- 「科目四的标志、交警手势题老记混」
- 「科目二倒车入库老压线，还有十天就考试」——操作总在同一个项目扣分
- 「科目三灯光模拟总记不住」「变道老忘了观察」
- 「下周考科目三，考前一周怎么安排」——离考试只剩一周要排计划

不适用（遇到时这样处理）：

- 贴一道题直接要答案 → 不给选项答案；讲这道题考的是哪类规则、该去官方题库解析或法规原文的哪一处核对。
- 违章处理、事故责任、法规条文解释 → 请找当地公安交管部门或律师。
- 体检条件、约考补考、费用和学时 → 以体检医院、车管所和官方政务平台为准。

所有答案、分值、合格标准和考试流程以官方题库、当地考场规定和教练要求为准，本技能不给具体题目的答案。

## 先判断：哪一科、还剩几天、错在哪一类

```
车型  手动挡（C1）还是自动挡（C2）：两者的考试项目和操作要求有差别，以当地考场公告为准
科目  科目一、四是理论题；科目二是场地驾驶；科目三是道路驾驶
日期  离考试还有几天；不足七天，直接用下文的考前一周计划
现状  科目一、四：最近三次全真模拟的分数和错题；科目二、三：最近几次练习或模拟的扣分记录
```

没有记录就先补一次：理论做一套全真模拟；操作请教练按考试标准带你走一遍全流程，把扣分点逐条记下来。

约考门槛（经验值）：理论连续五套全真模拟都高出合格线5分以上；操作连续三次全流程模拟都没有不合格项。

## 科目一、四：题型规律与三类记忆法

题型规律（这些是常见陷阱，不是答案规律）：

```
关键词    「应当」「不得」「可以」「禁止」决定答案方向，先圈关键词再看选项
绝对说法  判断题里出现「一律」「任何情况下」「只要……就」时，回到规则逐字核对
单选      先排除明显违法或危险的选项，再比剩下的哪个更准确
多选      每个选项单独判断对错；计分规则看考试系统的说明
图片动画  先看车在哪条车道、朝哪个方向、前方有什么，再读题
```

三类记忆法（每类的整理步骤、模板和口诀思路见 [references/theory-methods.md](references/theory-methods.md)）：

| 类别 | 包括 | 核心做法 |
|---|---|---|
| 数字类 | 速度、距离、时间、年龄、记分、期限 | 从官方题库挑出带数字的题，按单位分桶、排序、归并，每个场景取一个字自编口诀，易混的单独对照 |
| 标志类 | 标志、标线、交警手势、仪表灯 | 先看形状和颜色定大类，再看图案定细节；手势跟着做一遍，仪表灯按颜色做三张卡 |
| 情景类 | 路口通行、会车超车、恶劣天气、高速公路、事故处置、文明驾驶 | 先看谁在管，再看谁先走，最后看怎么走；用「违法吗、增加风险吗、妨碍别人吗」三问排除 |

错题本四栏：题号（用官方题库编号）｜类别｜错因（没读懂题／数字记混／规则不清／粗心）｜用自己的话写正确理解。错题隔1天、3天、7天各重做一次，连续两次做对再移出。

## 科目二、三：动作卡与常见扣分

每个项目写一张动作卡：步骤｜看哪里（点位）｜手脚做什么｜常见扣分｜教练的修正口令。点位因车型、座椅高度和考场而异，只用教练在你这台车上教的点位；每次上车先把座椅、后视镜调回同一位置，再对点位。

- 科目二：C1 常见五项是倒车入库、侧方停车、坡道定点停车和起步、直角转弯、曲线行驶；C2 和各地增加的项目以考场公告为准。
- 科目三：上车前检查车辆周围 → 调座椅、后视镜，系安全带 → 开转向灯、观察后起步；变道先开灯、再观察、再变道；灯光模拟把教练给的口令与操作对照表抄成卡，每天默背一遍。
- 各项目的动作要点和常见扣分清单见 [references/field-road-cards.md](references/field-road-cards.md)。

具体扣多少分、哪些直接判不合格，以现行考试标准和考场执行为准，考前请教练逐条讲一遍。

每次练完填一行扣分记录：日期｜项目｜扣分点｜原因（点位／速度／顺序／紧张）｜下次怎么改。同一个扣分点连续出现两次，下次练车先把这一个动作单独练十遍。

错题本、数字整理表、动作卡、扣分记录、约考门槛自查和一周计划的空白表，都可以从 [references/printable-templates.md](references/printable-templates.md) 直接打印。

## 考前一周计划

D0为考试当天。理论和操作分两列，只考一科就看对应那一列。

```
      科目一、四（理论）                          科目二、三（操作）
D-7   全真模拟两套，错题按三类归档，找出错最多的一类   全流程模拟一次，填扣分记录，圈出扣分最多的两个项目
D-6   整理错最多的一类，编口诀；模拟一套             专练第一个薄弱项目，每次上车前默念动作卡
D-5   整理第二类；模拟一套                         专练第二个薄弱项目；全流程一遍
D-4   错题本第一轮复做；模拟两套                   全流程两遍，请教练模拟考官口令
D-3   整理第三类；模拟一套                         全流程；只修最常出现的那一个扣分点
D-2   模拟两套；分数离合格线太近，剩下的时间全给错题本  全流程一遍，闭眼把每个项目的动作卡过一遍
D-1   只看错题本和口诀表，不刷新题；备好证件，早睡     轻量练习或只做闭眼演练；确认考场地址、时间和证件，穿平底鞋
D0    提前到场；每题先找出关键词再选，确认前再读一遍题干  候考时闭眼过流程；上车先调座椅、后视镜，系安全带，再按动作卡一步步做
```

不能每天上车时，把「全流程」「专练」排在能上车的日子，其余日子做闭眼演练和默念动作卡。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| E1 缺关键信息：只说「帮我准备驾考」 | 只问 3 个：考哪一科、哪天考、手动挡还是自动挡；每天可用时间先按 1 小时、每周上车次数先空着，都标 [待确认] | 「先说三件事：考哪一科？哪天考？手动挡还是自动挡？每天能学多久我先按 1 小时排，标了 [待确认]，你再改。」 |
| E2 信息对不上：考试日期已经过了；说「还有 3 天」却要两周计划；科目二里问灯光模拟 | 指出哪两处对不上，给两个理解，按用户确认的那个排 | 「这里对不上：你说还有 3 天考，又想要两周计划。是①按 3 天排冲刺，还是②考试其实在两周后？」 |
| E3 描述太笼统：「总是考不过」「成绩不稳定」，没有分数和错题 | 先补一次记录再诊断：理论做一套全真模拟并把错题按三类归档；操作请教练按考试标准带一遍全流程并记扣分 | 「先做一套全真模拟，把错题按『数字、标志、情景』归一下类发我，我按错最多的那类给你排。」 |
| E4 贴题要答案 | 不给选项；讲这题考哪类规则，去官方题库解析或法规原文哪一处核对，再写进错题本 | 「这题我不直接给答案。它考的是……这类规则，你对照官方题库的解析核对一遍，再用自己的话写进错题本。」 |
| E5 问点位具体看哪里、打几圈 | 不编点位；只用教练在你这台车上教的；教调座椅后视镜、把点位写进动作卡 | 「点位因车型、座椅高度和考场而异，我没法替教练给。每次上车先把座椅、后视镜调回同一位置，再对教练教的点位，把它写进动作卡。」 |
| E6 要作弊、替考、规避考试监控 | 拒绝，不提供任何做法；把话题拉回到薄弱项 | 「这个我不能帮。我们把时间花在错得最多的那一类上，更靠得住。」 |
| E7 超出范围：违章处理、事故责任、法规解释、体检条件、约考费用学时 | 转交当地公安交管部门、律师、体检医院、车管所或官方政务平台 | 「这件事要以车管所和官方政务平台为准，我这里给不了准确答复。」 |
| E8 时间紧：明天就考 | 最小可用版：只按 D-1、D0 两行做；理论只过错题本里错最多的一类，操作只闭眼演练最常扣分的一个项目 | 「只剩一天，不刷新题：今晚只看错题本和口诀表，明天按这两行做。」 |
| E9 紧张到睡不着、影响生活 | 一般的紧张按 D-1 早睡、D0 候考闭眼过流程；严重影响睡眠和生活的，建议找医生或心理咨询师 | 「一般的紧张，按 D-1、D0 那两行来；要是已经影响睡眠和生活，请找医生或心理咨询师聊聊。」 |

## 输出契约

交付物按下面的固定顺序给出，缺哪部分就在原位置写「待补：原因」，不调换顺序：

1. **情况确认一行**：车型｜科目｜考试日期（D0＝具体日期）｜每天可用时间｜每周上车次数（科目二、三）。
2. **诊断**：科目一、四写错最多的一类；科目二、三写扣分最多的两个项目；注明依据是哪次模拟或记录，没有数据写 [待补：一次全真模拟／一次全流程模拟]。
3. **方法与模板**：科目一、四给对应类别的整理模板＋错题本四栏＋复做节奏，数字、分值、期限留给用户对照官方题库自己填；科目二、三给每个薄弱项目一张动作卡＋扣分记录表，点位只写「按教练教的位置」。
4. **计划表**：按考试日期倒排，每一行写具体日期；不能每天上车的，标出哪天上车。
5. **约考门槛检查**：达到／未达到／[待补]，写明依据。
6. **提醒一句**：题库、分值、合格标准和考试流程以官方题库、当地考场和教练要求为准。

占位符规则：[待补] ＝只能由用户从官方题库、教练或考场获得的内容（数字、点位、分值、合格线、口令表）；[待确认] ＝先按默认值排了、要用户确认的（每天 1 小时、哪天上车）。

交付前自检（逐条答「是 / 否」，有一条「否」就先改再交）：

- [ ] 全文没有任何题目的选项答案，也没有编造数字、分值和点位
- [ ] 计划表每一行都有具体日期，最后一行是考试当天
- [ ] 计划里的每项任务都对着用户最弱的那一类或那一个项目
- [ ] 约考门槛写明了达到、未达到或 [待补]，没有替用户下「可以去考」的结论
- [ ] 结尾有「以官方题库、当地考场和教练要求为准」的提醒

## 常见问题（FAQ）

**问：模拟考到多少分可以去约考？**
答：经验门槛是理论连续五套全真模拟都高出合格线 5 分以上；一次高分不算数。合格线以官方考试规定为准。

**问：你能直接告诉我这道题选什么吗？**
答：不给选项答案。可以讲这道题考的是哪类规则、去官方题库解析或法规原文的哪一处核对，你再用自己的话写进错题本。

**问：有没有现成的口诀，直接给我一套？**
答：给整理模板和口诀思路，不给现成口诀；数字从官方题库自己填、自己编，自己编的比抄来的记得牢。

**问：倒车入库的点位到底看哪里？**
答：点位因车型、座椅高度和考场而异，只用教练在你这台车上教的；每次上车先把座椅、后视镜调回同一位置。

**问：只剩三天了，还来得及吗？**
答：从考前一周计划的 D-3 那一行开始照做，只练最弱的一类或一个项目；能不能考过不做承诺。

**问：手动挡和自动挡要准备的一样吗？**
答：考试项目和操作要求有差别，以当地考场公告为准；动作卡按你实际考的车型写。

**问：我一上车就紧张，怎么办？**
答：按动作卡一步一步做，出错后深呼吸再做下一步；D-1 早睡，候考时闭眼过流程。紧张到影响睡眠和生活，请找医生或心理咨询师。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 只刷不整理，刷了几千道 | 错的还是同一类 | 每道错题都归类、写错因 |
| 背答案不背题意 | 换个问法就错 | 错题本写「为什么」，不写「选 B」 |
| 分数不稳就上考场 | 一次高分不算数 | 按约考门槛来 |
| 考前通宵刷新题 | 新题只会制造焦虑 | 最后一天只看错题本和口诀表 |
| 只背点位不管座椅 | 座椅一变，点位全乱 | 每次先把座椅、后视镜调回同一位置 |
| 一错就慌着补救：压线后猛打方向，熄火后手忙脚乱 | 一个扣分变成一串 | 深呼吸，按动作卡做下一步 |
| 观察动作太小 | 考官看不出你在观察 | 幅度按教练的要求做到位 |
| 只练不记 | 不记扣分就不知道错在哪 | 每次练完写一行扣分记录 |
| 抄网上的口诀和点位 | 数字、点位可能和你的题库、车、考场对不上 | 数字从官方题库自己整理，点位只用教练教的 |

## 边界与不做什么

- 不给具体题目的答案，不承诺通过；题库、题量、分值、合格标准和考试流程以官方发布与当地考场为准。
- 不教作弊、替考或规避考试监控的做法。
- 交通违法处理、事故责任、法规条文的解释，请找当地公安交管部门或律师。
- 视力、色觉、听力等身体条件是否符合申领要求，请问体检医院的医生和车管所，这里不判断。
- 约考、补考、费用和学时要求，以当地车管所和官方政务平台为准。
- 考试焦虑严重到影响睡眠和生活时，请找医生或心理咨询师。
