# 驾照考试

定位一句话：**科目一、四考的是读懂题意、记准规则；科目二、三考的是紧张时也能按固定顺序把动作做完。前者靠分类整理，后者靠把每个动作练成不用想的流程。**
何时用：科目一、四刷了很多题仍错同一类；科目二、三总在同一个项目扣分；离考试只剩一周要排计划时。所有答案、分值、合格标准和考试流程以官方题库、当地考场规定和教练要求为准，本技能不给具体题目的答案。

## 先判断：哪一科、还剩几天、错在哪一类

```
车型  手动挡（C1）还是自动挡（C2）：两者的考试项目和操作要求有差别，以当地考场公告为准
科目  科目一、四是理论题；科目二是场地驾驶；科目三是道路驾驶
日期  离考试还有几天；不足七天，直接用下文的考前一周计划
现状  科目一、四：最近三次全真模拟的分数和错题；科目二、三：最近几次练习或模拟的扣分记录
```

没有记录就先补一次：理论做一套全真模拟；操作请教练按考试标准带你走一遍全流程，把扣分点逐条记下来。

约考门槛（经验值）：理论连续五套全真模拟都高出合格线5分以上；操作连续三次全流程模拟都没有不合格项。

## 科目一、四：题型规律与三类记忆法

题型规律（这些是常见陷阱，不是答案规律）：

```
关键词    「应当」「不得」「可以」「禁止」决定答案方向，先圈关键词再看选项
绝对说法  判断题里出现「一律」「任何情况下」「只要……就」时，回到规则逐字核对
单选      先排除明显违法或危险的选项，再比剩下的哪个更准确
多选      每个选项单独判断对错；计分规则看考试系统的说明
图片动画  先看车在哪条车道、朝哪个方向、前方有什么，再读题
```

**数字类**（速度、距离、时间、年龄、记分、期限）：别一道道死背，按单位整理成表。

```
1 分桶    从官方题库挑出所有带数字的题，按单位分：米、公里/小时、日、年、分、周岁
2 排序    每个桶内按数字从小到大排成三栏：数字｜场景｜题号
3 归并    同一个数字对应的多个场景合成一行
4 编口诀  每个场景取一个字，按数字顺序串成一句顺口的话；自己编的比抄来的记得牢
5 对照    数字相近、场景也相近的，单独做一行对比
模板      【米】＿米：场景＿＿、＿＿ → 口诀「＿＿＿＿」
          易混：场景甲＿米 vs 场景乙＿米，区别在＿＿
```

**标志类**（标志、标线、交警手势、仪表灯）：先分大类，再记细节。

```
标志    先看形状和颜色定大类，再看图案：警告标志多为黄底黑边三角形，禁令标志多为白底红圈，
        指示标志多为蓝底白图案（以现行国家标准图示和官方题库为准）
标线    颜色看方向：白线多分隔同向车道，黄线多分隔对向车流；线型看能否越线：实线不越，虚线在安全时可越
手势    把题目图片转成交警的朝向，自己面朝同一方向跟着做一遍，左右就不会反
仪表灯  按颜色做三张卡：红色多为必须马上处理的警示，黄色多为故障或提醒，绿色、蓝色多表示某项功能已开启
口诀思路 「形状颜色定大类，图案定细节」；同一图案不同颜色时，先认颜色
```

**情景类**（路口通行、会车超车、恶劣天气、高速公路、事故处置、文明驾驶）：

```
谁在管    交警指挥→信号灯→标志标线→无信号路口的让行规则（以《道路交通安全法》及其实施条例原文为准）
排除三问  这样做违法吗？增加风险吗？妨碍别人吗？三问都答「否」的选项才留下
画简图    复杂的题先画出路口、车辆和行驶方向再选
口诀思路  「先看谁在管，再看谁先走，最后看怎么走」
提醒      排除法只是思路；和直觉相反的官方答案，单独记进错题本
```

错题本四栏：题号（用官方题库编号）｜类别｜错因（没读懂题／数字记混／规则不清／粗心）｜用自己的话写正确理解。错题隔1天、3天、7天各重做一次，连续两次做对再移出。

## 科目二、三：动作卡与常见扣分

每个项目写一张动作卡：步骤｜看哪里（点位）｜手脚做什么｜常见扣分｜教练的修正口令。点位因车型、座椅高度和考场而异，只用教练在你这台车上教的点位；每次上车先把座椅、后视镜调回同一位置，再对点位。

```
科目二    C1常见五项：倒车入库、侧方停车、坡道定点停车和起步、直角转弯、曲线行驶；C2和各地增加的项目以考场公告为准
  通用    全程低速匀速，速度靠离合或刹车控制；眼睛按动作卡的顺序看点位，不盯方向盘
  倒车入库 看后视镜找点位→打方向→车身正了及时回正→看停车点位
  侧方停车 到点位向右打满→车身斜到位回正→再到点位向左打满→车身摆正后停车；出库按要求开转向灯
  坡道    停车对准停车线和右侧边线的点位；起步时手刹、离合、油门配合，不后溜
  直角转弯 靠外侧行驶，到点位打满方向，车身摆正后回正
  曲线行驶 用车头上的点位沿边线走，小幅修正，不猛打方向
科目三    上车前按要求检查车辆周围→调座椅、后视镜，系安全带→开转向灯、观察后起步；
          变道先开灯、再观察、再变道；路口、人行横道、学校和公交站前减速观察
  灯光模拟 把教练给的口令与操作对照表抄成一张卡，每天默背一遍，再上车空练一遍
常见扣分  压线或车身出线；中途停车；超时；坡道后溜或停车位置偏差；熄火；未系安全带；
          转向灯没开或开得太晚；起步、变道不观察；路口不减速；遇行人不让行；
          档位与车速不匹配（手动挡）；靠边停车距离超出要求；没听清指令就操作
```

具体扣多少分、哪些直接判不合格，以现行考试标准和考场执行为准，考前请教练逐条讲一遍。

每次练完填一行扣分记录：日期｜项目｜扣分点｜原因（点位／速度／顺序／紧张）｜下次怎么改。同一个扣分点连续出现两次，下次练车先把这一个动作单独练十遍。

## 考前一周计划

D0为考试当天。理论和操作分两列，只考一科就看对应那一列。

```
      科目一、四（理论）                          科目二、三（操作）
D-7   全真模拟两套，错题按三类归档，找出错最多的一类   全流程模拟一次，填扣分记录，圈出扣分最多的两个项目
D-6   整理错最多的一类，编口诀；模拟一套             专练第一个薄弱项目，每次上车前默念动作卡
D-5   整理第二类；模拟一套                         专练第二个薄弱项目；全流程一遍
D-4   错题本第一轮复做；模拟两套                   全流程两遍，请教练模拟考官口令
D-3   整理第三类；模拟一套                         全流程；只修最常出现的那一个扣分点
D-2   模拟两套；分数离合格线太近，剩下的时间全给错题本  全流程一遍，闭眼把每个项目的动作卡过一遍
D-1   只看错题本和口诀表，不刷新题；备好证件，早睡     轻量练习或只做闭眼演练；确认考场地址、时间和证件，穿平底鞋
D0    提前到场；每题先找出关键词再选，确认前再读一遍题干  候考时闭眼过流程；上车先调座椅、后视镜，系安全带，再按动作卡一步步做
```

## 最常见的错误

```
只刷不整理       刷了几千道，错的还是同一类；每道错题都归类、写错因
背答案不背题意    换个问法就错；错题本写「为什么」，不写「选B」
分数不稳就上考场  一次高分不算数，按上面的约考门槛来
考前通宵刷新题    新题只会制造焦虑；最后一天只看错题本
只背点位不管座椅  座椅一变，点位全乱；每次先调回同一位置
一错就慌着补救    压线后猛打方向、熄火后手忙脚乱；深呼吸，按动作卡做下一步
观察动作太小      考官看不出你在观察；幅度按教练的要求做到位
只练不记         不记扣分就不知道错在哪；每次练完写一行
```

## 输出契约

1. 先确认车型、科目、考试日期、每天可用时间；科目二、三还要问每周能上车几次。
2. 科目一、四：交付错题本格式、三类口诀的整理模板和复做节奏；只教方法，数字、分值、期限请用户对照官方题库自己填。
3. 科目二、三：交付每个项目的动作卡模板和扣分记录表；点位只写「按教练教的位置」，不编造点位。
4. 考前一周计划按用户的考试日期排出具体日子。
5. 用户贴题要答案时，不给选项答案，只讲这道题考的是哪类规则、该去题库解析或法规原文的哪一处核对。

## 边界与不做什么

- 不给具体题目的答案，不承诺通过；题库、题量、分值、合格标准和考试流程以官方发布与当地考场为准。
- 不教作弊、替考或规避考试监控的做法。
- 交通违法处理、事故责任、法规条文的解释，请找当地公安交管部门或律师。
- 视力、色觉、听力等身体条件是否符合申领要求，请问体检医院的医生和车管所，这里不判断。
- 约考、补考、费用和学时要求，以当地车管所和官方政务平台为准。
- 考试焦虑严重到影响睡眠和生活时，请找医生或心理咨询师。
