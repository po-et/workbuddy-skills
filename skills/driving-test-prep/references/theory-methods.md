# 科目一、四：三类记忆法详解

所有数字、分值、期限和答案以官方题库为准。这里只给整理方法，表格里的数字请用户从官方题库自己填，不要抄网上的「答案口诀」。

## 数字类（速度、距离、时间、年龄、记分、期限）

别一道道死背，按单位整理成表。

```
1 分桶    从官方题库挑出所有带数字的题，按单位分：米、公里/小时、日、年、分、周岁
2 排序    每个桶内按数字从小到大排成三栏：数字｜场景｜题号
3 归并    同一个数字对应的多个场景合成一行
4 编口诀  每个场景取一个字，按数字顺序串成一句顺口的话；自己编的比抄来的记得牢
5 对照    数字相近、场景也相近的，单独做一行对比
模板      【米】＿米：场景＿＿、＿＿ → 口诀「＿＿＿＿」
          易混：场景甲＿米 vs 场景乙＿米，区别在＿＿
```

## 标志类（标志、标线、交警手势、仪表灯）

先分大类，再记细节。

```
标志    先看形状和颜色定大类，再看图案：警告标志多为黄底黑边三角形，禁令标志多为白底红圈，
        指示标志多为蓝底白图案（以现行国家标准图示和官方题库为准）
标线    颜色看方向：白线多分隔同向车道，黄线多分隔对向车流；线型看能否越线：实线不越，虚线在安全时可越
手势    把题目图片转成交警的朝向，自己面朝同一方向跟着做一遍，左右就不会反
仪表灯  按颜色做三张卡：红色多为必须马上处理的警示，黄色多为故障或提醒，绿色、蓝色多表示某项功能已开启
口诀思路 「形状颜色定大类，图案定细节」；同一图案不同颜色时，先认颜色
```

## 情景类（路口通行、会车超车、恶劣天气、高速公路、事故处置、文明驾驶）

```
谁在管    交警指挥→信号灯→标志标线→无信号路口的让行规则（以《道路交通安全法》及其实施条例原文为准）
排除三问  这样做违法吗？增加风险吗？妨碍别人吗？三问都答「否」的选项才留下
画简图    复杂的题先画出路口、车辆和行驶方向再选
口诀思路  「先看谁在管，再看谁先走，最后看怎么走」
提醒      排除法只是思路；和直觉相反的官方答案，单独记进错题本
```

## 错题本与复做节奏

错题本四栏：题号（用官方题库编号）｜类别｜错因（没读懂题／数字记混／规则不清／粗心）｜用自己的话写正确理解。

- 错题隔 1 天、3 天、7 天各重做一次，连续两次做对再移出。
- 错因一栏只写四种之一，统计哪种最多：「没读懂题」多就回到题型规律圈关键词；「数字记混」多就补数字类整理表；「规则不清」多就按情景类的「谁在管」重排；「粗心」多就练「确认前再读一遍题干」。
- 可打印的空白表见 [printable-templates.md](printable-templates.md)。
