# 提交格式：标题、署名、排版、命名、字数口径

原则：**通知怎么要求就怎么做；通知没写的，才用下面的默认值，并在交付物里标 [待确认]。** 下面的默认值是常见做法，不是任何单位的规定。

## 1. 先从通知里找这七项

| 项目 | 常见写法 | 没写时怎么办 |
|---|---|---|
| 字数 | 「不少于 1500 字」「800 字左右」 | 默认 1500 字档，标 [待确认] |
| 格式 | 字体字号、行距、页边距 | 用下面第 4 节的默认值 |
| 截止时间 | 日期加时刻 | 问清楚，写进待补清单 |
| 提交方式 | 纸质、邮件、办公系统、网盘 | 问清楚 |
| 文件命名 | 「姓名+部门」 | 用第 5 节的默认命名 |
| 是否手写 | 「手写稿」「打印稿」 | 默认电子版 |
| 是否签名 | 「本人签字」 | 打印稿留签名处 |

## 2. 标题的三种写法

- **直陈式**：《[活动名称]学习心得》《参加[培训名称]的心得体会》。稳妥，适合统一收集。
- **主副式**：主标题一句话点出你的触动点，副标题写「——[活动名称]心得体会」。例：《从「没有记录」开始——时间管理讲座学习心得》。最能体现「从一个触动点写起」。
- **「关于」式**：《关于[活动名称]的心得体会》。偏正式，单位常见。

主标题只写你正文里真有的内容，不写「收获满满」这类空话。

## 3. 署名与日期

- 标题下一行：「[部门或班级]　[姓名]」，居中；学校要求学号的加学号。
- 文末右下：日期。单位要求只署一处的，按要求。
- 代表小组或集体写的，署「[小组名称]」并在待确认清单里注明执笔人。

## 4. 排版默认值（通知没写时）

- 标题：居中，加粗，比正文大两号左右。
- 正文：宋体或仿宋，小四或四号；1.5 倍行距；首行缩进 2 字符。
- 小标题（1500 字及以上）：加粗，单独成行，用「一、二、三」编号。
- 页码：两页以上加页码。

单位或学校发了模板，就用模板，不用这里的默认值。

## 5. 文件命名与提交附言

- 文件名：「姓名-部门或班级-活动名称心得.docx」，例：「[姓名]-[部门]-消防安全培训心得.docx」。
- 要不要转 PDF：通知说了按通知；没说时交 .docx 方便汇总人修改格式。
- 邮件或消息附言：

```
[称呼]您好：附件是我的[活动名称]心得体会，请查收。
[部门或班级]　[姓名]　[日期]
```

## 6. 手写稿

- 先在电脑上定稿，再誊写；誊写时不再改内容。
- 稿纸有格子的，格数就是字数的参照；标题居中占一行，每段首行空两格。
- 涂改尽量少；写错一个字用一道横线划掉，不用涂改液大片覆盖（以老师要求为准）。

## 7. 字数口径

- 不同软件对「字数」的算法略有不同（是否计标点、英文按词还是按字母），以收稿方的口径为准。
- 「不少于 N 字」：多写 5%–10% 留余量。
- 「N 字左右」：控制在 ±10% 以内。
- 「不超过 N 字」：按收稿方口径算，宁少勿多。

## 8. 集体学习类心得的特别注意

- 单位发了学习材料的，先读材料再动笔；心得里的观点要能在材料里找到出处。
- 引用文件、讲话原文：照原文抄录并注明出处，由你提供原文；不凭记忆写原文，也不改动原文的表述。
- 「联系实际」落到你本人的岗位和一件具体的事上；「查找差距」写真实、具体的差距，并在行动段写对应的改进。
