# 加薪申请

定位一句话：**加薪谈的不是「我需要」，而是「我已经交付了什么、接下来还能交付什么」——证据摆清楚，时机选对，再给对方一个能点头的方案。**
何时用：准备向直属上级提加薪、要交书面调薪申请，或刚被拒、要想好下一步时。调薪窗口、审批链、薪酬保密要求以本公司制度为准；本技能不提供任何薪资数据，也不保证结果。

## 先判断：现在提不提、凭什么提

```
依据强弱  职责扩大（实际在做超出岗位的事）＞ 成果可量化 ＞ 市场偏离且有公开来源 ＞ 生活需要（只能当背景，不当理由）
公司节奏  有年度调薪或晋升评审的，赶在窗口前提；窗口外提要单独报批，先弄清上级有没有调整权限
你要什么  加薪、晋级、一次性奖金、职责确认——排出先后，想好能接受的最低结果
先缓一缓  团队在降本、你刚出过重大失误、上级刚接手团队——改谈职责和下个周期的条件
```

开口前先自测三问：为什么是现在？为什么是这个数？这次调不了你打算怎么办？哪一问答不上，哪里就还要准备。如果你实际承担的已经是上一级的职责，谈职级往往比单谈薪资顺——职级定了，薪资跟着走，上级也好报批；具体怎么挂钩以本公司制度为准。一条强依据都没有时先别提，用一两个季度把证据做出来，比硬谈更划算。

## 准备：证据、参照、口径、时机

按下面的步骤准备，每一步都留书面记录。

1. **证据清单**：列出过去一个考核周期的事，每条写成「做了什么—结果—来源—谁能佐证」。结果写能核对的数，附时间窗和口径，出处可以是周报、报表、客户邮件；没有数就写可观察的事实，比如「独立负责原来两个人分担的对账」。不写「大幅提升」「效果显著」。最后挑最硬的三条，按对团队的影响排序。
   - 弱：「今年很努力，负责了很多项目，大家都认可。」
   - 强（示例）：「一至九月独立负责对账流程改造，月结从五个工作日缩到两个，见财务月报；此前由两人分担。」
2. **市场参照**（可选，找不到可靠来源就不用）：只用可追溯的公开信息——同城、同岗位、同年限的公开招聘薪资区间，至少收集五条，每条记下岗位名称、城市、年限要求、区间、来源和日期，职责和你差得远的剔除；行业机构公开发布的薪酬报告，注明发布方、年份和样本口径。猎头或朋友的口头说法只供自己参考，谈话里不引用。结论只说「我查到的公开区间和来源」，不说「市场价就是多少」。
3. **期望口径**：说清是月薪还是年度总包、税前还是税后、含不含奖金。涨幅自己先算清：涨幅 =（期望 − 现在）÷ 现在；年度差额 = 月差 × 实际发薪月数。
4. **时机**：好时机是年度调薪或考核定档之前、重要项目交付并有可见成果之后、职责刚扩大的时候；坏时机是上级刚挨批、会议间隙、群聊里、饭局上。提前约三十分钟单独谈，事先说明主题：「想约您半小时，聊聊我这一年的工作和下一步，也想谈谈薪酬，您看哪天方便？」不搞突袭。
5. **预演**：前一晚把三条成果、期望的数、备选清单写在一张纸上，把下一节「对方常见回应」逐条说出声练一遍。

## 谈话结构：贡献→期望→备选

```
开场  感谢您抽时间。想聊聊我这一年的工作、下阶段的打算，也包括薪酬。
贡献  三条成果，每条一句「做了什么—结果是多少—对团队意味着什么」；
      再说职责变化：「入职时我负责[ ]，现在实际还承担[ ]。」
期望  给一个具体数或窄区间，带上依据：「结合职责变化和我查到的公开区间，希望调整到[ ]。」
      说完停下来听，不自己往下砍。
备选  对方说没额度时：「如果这次调不了，能不能明确要达到什么、什么时候重新评估？」
      可谈的替代：生效时间后延、书面的晋升或调薪条件、一次性奖金、职级确认、关键项目或培训资源。
收尾  复述结论和下一步，当天发邮件确认。
```

检查点：走出会议室前要拿到三样——对方认可的贡献是哪几条、明确的答复时间、这次不成时的条件。三样缺一样，就在收尾时补问。

对方常见回应怎么接：

```
「今年没预算」          理解。那能不能先确认我的职责和评估时间？预算下来时我再来找您。
「表现不错，但还不够」  具体差在哪？能不能给我两三条能衡量的标准？
「大家都没涨」          明白。我想谈的是我的职责变化，看能不能在岗位或职级上体现。
「你从哪儿听的行情」    我没有比较同事，只看了公开招聘信息，来源和日期都在这里。
「是不是有别的机会」    如实说，不夸大也不拿来施压；更想留下就直说：我更想在这儿做下去，所以先跟您谈。
「先把手上的事做好」    好的，那我们约个日子回顾，我带着结果来。
```

谈完当天，把结论整理成书面申请：

```
主题：关于薪酬调整的申请——[姓名]
[上级称呼]：
感谢您[日期]与我沟通。按谈话内容，申请整理如下：
一、主要贡献（[时间窗]）：1.[事项]：[做了什么]，[结果与口径]，[来源]；2.……
二、职责变化：入职时岗位职责为[ ]，目前实际承担[ ]。
三、申请事项：希望薪酬调整至[ ]，自[ ]起生效，依据为上述贡献及[公开参照的来源与日期]。
四、如本期无法调整，希望明确：[条件]、[重新评估的时间]。
接下来我会继续推进[下一阶段目标]。
[姓名]  [日期]
```

用「希望」不用「要求」；不附、不提同事的薪资。公司有固定调薪申请表的就用表，理由栏照上面的一、二、三条填。

## 被拒后的三种走法

当场先稳住：「谢谢您直说。我想了解一下，要达到什么才能调整？」不争辩、不甩脸色。当天发一封确认邮件，把原因和条件落在纸面上：

```
[上级称呼]：感谢今天的沟通。确认一下共识：本次暂不调整，原因是[ ]；
如我在[日期]前达成[条件一]、[条件二]，您会帮我重新评估。如有理解偏差，请您指正。
```

然后三选一：

1. **拿条件再战**：把条件写成可验收的目标和评估时间，每月对照进度；到点主动约，带着达成的证据重谈。没有新证据，不要一两个月内就再提。
2. **换一种回报**：现金调不了，就争取职级确认、关键项目、培训或认证资源、弹性安排，同样落在书面上。
3. **看外部机会**：连续两个周期达成条件仍不调，或对方拒绝给任何条件时，开始看外面；拿到书面录用前不在内部表态，更不拿并不存在的录用施压。

## 最常见的错误

- 拿「房贷压力大」「别人都涨了」当理由：公司为贡献付钱，不为需要付钱。
- 数字含糊或编造：一句追问就垮，信任也跟着垮。
- 打听、比较同事薪资：很多公司有保密要求，以本公司制度为准。
- 先发邮件、后当面：上级被突袭，只能先说不；越过直属上级找上一级，更是把他推到对面。
- 拿离职要挟却没准备走：答应了伤信任，不答应下不来台。
- 只说「涨一点」：没有数，上级没法往上报。
- 谈一次就不跟进：条件没落在书面上，等于没谈。

## 输出契约

1. 先问：岗位与年限、公司调薪窗口、上次调薪时间、手上的成果与来源、期望与底线。
2. 交付：证据清单（每条带来源，缺的标「待补」）、十分钟谈话提纲、书面申请草稿、被拒后的确认邮件与应对话术。
3. 用户需要时扮演上级陪练，按「对方常见回应」逐条出题，每轮点评一处可改的说法。
4. 不编数字：成果数字只用用户给的；市场参照只给查找方法、整理用户找到的来源，不提供任何薪资区间或「合理涨幅」。
5. 不预测成败：只说怎样更有说服力，不说「这样一定能涨」。

## 边界与不做什么

- 不提供薪资数据、行情判断或「该涨多少」的建议；数字由用户自己查、自己定。
- 不承诺结果，决定权在公司。
- 不做劳动法定性：降薪、欠薪、调岗降薪、加班费等争议，找人力资源部门、当地劳动保障部门或律师。
- 不帮伪造录用通知、业绩数据或他人评价。
- 不代发邮件，不替用户与上级沟通。
