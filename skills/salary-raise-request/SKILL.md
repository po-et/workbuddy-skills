# 加薪申请

定位一句话：**加薪谈的不是「我需要」，而是「我已经交付了什么、接下来还能交付什么」——证据摆清楚，时机选对，再给对方一个能点头的方案。**

## 何时使用

用户这样说时启用（前四条是主要场景，后两条是辅助场景）：

- 「入职两年没调过薪，想提加薪怎么开口才不尴尬」
- 「年底考核前想交一份加薪申请，帮我把今年的成果理一理」
- 「加薪申请邮件怎么写」
- 「领导说今年没名额，加薪被拒了怎么办」
- 「你扮演我的领导，陪我把谈话练一遍」
- 「职责多了一大块，是该谈加薪还是谈晋升」

调用方式：在对话里说岗位与年限、上次调薪时间、手上的成果和来源、期望与底线；要陪练就说「扮演我的上级」。调薪窗口、审批链、薪酬保密要求以本公司制度为准；本技能不提供任何薪资数据，也不保证结果。

不适用（遇到时这样处理）：

- 降薪、欠薪、调岗降薪、加班费等争议 → 找人力资源部门、当地劳动保障部门或律师。
- 准备跳槽、比较 offer、和新公司谈薪 → 转「求职」类技能（如 resume-job-expert）。
- 已经决定离职，想知道怎么提 → 转「离职谈话」类技能（如 resignation-conversation）。

## 先判断：现在提不提、凭什么提

```
依据强弱  职责扩大（实际在做超出岗位的事）＞ 成果可量化 ＞ 市场偏离且有公开来源 ＞ 生活需要（只能当背景，不当理由）
公司节奏  有年度调薪或晋升评审的，赶在窗口前提；窗口外提要单独报批，先弄清上级有没有调整权限
你要什么  加薪、晋级、一次性奖金、职责确认——排出先后，想好能接受的最低结果
先缓一缓  团队在降本、你刚出过重大失误、上级刚接手团队——改谈职责和下个周期的条件
```

开口前先自测三问：为什么是现在？为什么是这个数？这次调不了你打算怎么办？哪一问答不上，哪里就还要准备。如果你实际承担的已经是上一级的职责，谈职级往往比单谈薪资顺——职级定了，薪资跟着走，上级也好报批；具体怎么挂钩以本公司制度为准。一条强依据都没有时先别提，用一两个季度把证据做出来，比硬谈更划算。

## 准备：证据、参照、口径、时机

按下面的步骤准备，每一步都留书面记录。

1. **证据清单**：列出过去一个考核周期的事，每条写成「做了什么—结果—来源—谁能佐证」。结果写能核对的数，附时间窗和口径，出处可以是周报、报表、客户邮件；没有数就写可观察的事实，比如「独立负责原来两个人分担的对账」。不写「大幅提升」「效果显著」。最后挑最硬的三条，按对团队的影响排序。
   - 弱：「今年很努力，负责了很多项目，大家都认可。」
   - 强（示例）：「一至九月独立负责对账流程改造，月结从五个工作日缩到两个，见财务月报；此前由两人分担。」
2. **市场参照**（可选，找不到可靠来源就不用）：只用可追溯的公开信息——同城、同岗位、同年限的公开招聘薪资区间，至少收集五条，每条记下岗位名称、城市、年限要求、区间、来源和日期，职责和你差得远的剔除；行业机构公开发布的薪酬报告，注明发布方、年份和样本口径。猎头或朋友的口头说法只供自己参考，谈话里不引用。结论只说「我查到的公开区间和来源」，不说「市场价就是多少」。
3. **期望口径**：说清是月薪还是年度总包、税前还是税后、含不含奖金。涨幅自己先算清：涨幅 =（期望 − 现在）÷ 现在；年度差额 = 月差 × 实际发薪月数。
4. **时机**：好时机是年度调薪或考核定档之前、重要项目交付并有可见成果之后、职责刚扩大的时候；坏时机是上级刚挨批、会议间隙、群聊里、饭局上。提前约三十分钟单独谈，事先说明主题：「想约您半小时，聊聊我这一年的工作和下一步，也想谈谈薪酬，您看哪天方便？」不搞突袭。
5. **预演**：前一晚把三条成果、期望的数、备选清单写在一张纸上，把下一节「对方常见回应」逐条说出声练一遍。

## 谈话结构：贡献→期望→备选

```
开场  感谢您抽时间。想聊聊我这一年的工作、下阶段的打算，也包括薪酬。
贡献  三条成果，每条一句「做了什么—结果是多少—对团队意味着什么」；
      再说职责变化：「入职时我负责[ ]，现在实际还承担[ ]。」
期望  给一个具体数或窄区间，带上依据：「结合职责变化和我查到的公开区间，希望调整到[ ]。」
      说完停下来听，不自己往下砍。
备选  对方说没额度时：「如果这次调不了，能不能明确要达到什么、什么时候重新评估？」
      可谈的替代：生效时间后延、书面的晋升或调薪条件、一次性奖金、职级确认、关键项目或培训资源。
收尾  复述结论和下一步，当天发邮件确认。
```

检查点：走出会议室前要拿到三样——对方认可的贡献是哪几条、明确的答复时间、这次不成时的条件。三样缺一样，就在收尾时补问。

对方常见回应怎么接：

```
「今年没预算」          理解。那能不能先确认我的职责和评估时间？预算下来时我再来找您。
「表现不错，但还不够」  具体差在哪？能不能给我两三条能衡量的标准？
「大家都没涨」          明白。我想谈的是我的职责变化，看能不能在岗位或职级上体现。
「你从哪儿听的行情」    我没有比较同事，只看了公开招聘信息，来源和日期都在这里。
「是不是有别的机会」    如实说，不夸大也不拿来施压；更想留下就直说：我更想在这儿做下去，所以先跟您谈。
「先把手上的事做好」    好的，那我们约个日子回顾，我带着结果来。
```

谈完当天，把结论整理成书面申请：

```
主题：关于薪酬调整的申请——[姓名]
[上级称呼]：
感谢您[日期]与我沟通。按谈话内容，申请整理如下：
一、主要贡献（[时间窗]）：1.[事项]：[做了什么]，[结果与口径]，[来源]；2.……
二、职责变化：入职时岗位职责为[ ]，目前实际承担[ ]。
三、申请事项：希望薪酬调整至[ ]，自[ ]起生效，依据为上述贡献及[公开参照的来源与日期]。
四、如本期无法调整，希望明确：[条件]、[重新评估的时间]。
接下来我会继续推进[下一阶段目标]。
[姓名]  [日期]
```

用「希望」不用「要求」；不附、不提同事的薪资。公司有固定调薪申请表的就用表，理由栏照上面的一、二、三条填。

## 被拒后的三种走法

当场先稳住：「谢谢您直说。我想了解一下，要达到什么才能调整？」不争辩、不甩脸色。当天发一封确认邮件，把原因和条件落在纸面上：

```
[上级称呼]：感谢今天的沟通。确认一下共识：本次暂不调整，原因是[ ]；
如我在[日期]前达成[条件一]、[条件二]，您会帮我重新评估。如有理解偏差，请您指正。
```

然后三选一：

1. **拿条件再战**：把条件写成可验收的目标和评估时间，每月对照进度；到点主动约，带着达成的证据重谈。没有新证据，不要一两个月内就再提。
2. **换一种回报**：现金调不了，就争取职级确认、关键项目、培训或认证资源、弹性安排，同样落在书面上。
3. **看外部机会**：连续两个周期达成条件仍不调，或对方拒绝给任何条件时，开始看外面；拿到书面录用前不在内部表态，更不拿并不存在的录用施压。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息：只说「想涨薪」 | 只问 3 个：岗位与年限；上次调薪时间和公司调薪窗口；最硬的一两条成果及来源。期望与底线没说的，交付物里标 [待补] | 「先问三件事：你的岗位和年限？上次调薪是什么时候，公司一般几月调？今年最拿得出手的一两件事是什么，有没有报表或邮件能佐证？」 |
| 数字含糊或口径打架：「效率提升很多」；说月薪却按年包算涨幅 | 指出含糊或矛盾处，要来源和口径；两种口径各算一遍给他看 | 「『提升很多』要落到能核对的数：从多少到多少、哪个时间段、出处在哪？你说的是月薪还是年度总包？两种口径算出的涨幅不一样。」 |
| 理由站不住：房贷、「别人都涨了」、同事比我拿得多 | 说明为什么不当理由，引导回到职责变化和成果 | 「房贷可以当背景，但不当理由，公司为贡献付钱；我们把理由换成你职责的变化和那条对账成果。」 |
| 超出范围：问「市场价多少」「该涨多少」；降薪、欠薪等劳动争议 | 不给数据、不建议涨幅，只给查公开来源的方法；劳动争议转 HR、劳动保障部门或律师 | 「我不提供薪资数据，也不判断该涨多少；可以教你找可追溯的公开招聘区间，整理成来源清单。」 |
| 时间紧，明天就要谈 | 最小版 = 三条成果（每条一句「做了什么—结果—来源」）+ 一个期望数和依据 + 一句备选请求 + 开场白 | 「来不及准备全套，先备四样：三条成果、一个数和依据、一句『这次调不了的话，能不能明确条件和时间』，再加开场白。」 |
| 坚持越界：要编业绩数字、伪造录用通知、拿假 offer 施压、让我替他发邮件 | 守住：不编不造，不代发 | 「数字只用你拿得出来源的；没有录用就不要说有，一句追问就会失去信任。邮件我帮你写好，由你自己发。」 |
| 用户其实已决定要走 | 不劝留也不劝走；仍想先谈加薪的照常准备，决定离职的转离职谈话类技能 | 「如果已经决定走，这次谈话就不必拿加薪做筹码；怎么提离职可以转『离职谈话』。」 |

## 输出契约

交付物按以下顺序，缺哪块写明原因：

1. **信息确认**：岗位与年限、公司调薪窗口、上次调薪时间、手上的成果与来源、期望与底线；没给的标 [待补]。
2. **证据清单**：每条「做了什么—结果—来源—谁能佐证」，按对团队的影响排序，标出最硬的三条；缺来源的标 [待补：来源]。
3. **市场参照**（可选）：只整理用户找到的公开来源（岗位、城市、年限、区间、来源、日期），不提供任何区间或「合理涨幅」。
4. **十分钟谈话提纲**：开场—贡献—期望—备选—收尾，附对方常见回应的接法。
5. **书面申请草稿**：谈完当天用。
6. **被拒后的确认邮件与三种走法**。
7. **待补清单**：所有 [待补]、[待确认] 汇总在最后。

陪练模式：用户需要时扮演上级，按「对方常见回应」逐条出题，每轮点评一处可改的说法。不编数字：成果数字只用用户给的；市场参照只给查找方法、整理用户找到的来源。不预测成败：只说怎样更有说服力，不说「这样一定能涨」。占位符：用户必须提供的（成果数字、来源、期望数）写 [待补]；从上下文推断的（如调薪窗口在年初）写 [待确认]。

交付前自检（逐条答是/否）：

- [ ] 每条成果都有来源或可观察的事实，没有「大幅提升」「效果显著」？
- [ ] 所有数字都来自用户，涨幅和年度差额按公式算对了？
- [ ] 没有给出任何薪资区间或「合理涨幅」？
- [ ] 没有提及、比较同事的薪资？
- [ ] 书面材料用「希望」不用「要求」，没有「一定能涨」之类的预测？
- [ ] 邮件草稿交给用户自己发，没有代发、没有替用户联系上级？

## 示例

以下为示例，人物和成果为虚构（成果沿用上文「强」的写法）。

**用户**：入职两年没调过薪，想提加薪怎么开口才不尴尬？

**助手先问**：① 你的岗位？公司一般几月调薪？② 这一年最拿得出手的一两件事是什么，有没有报表或邮件能佐证？③ 期望的数定了吗，是月薪还是年包？

**用户**：财务专员，公司每年一月调薪。今年一到九月我独立负责对账流程改造，月结从五个工作日缩到两个，财务月报里有；以前这事是两个人分担。期望的数我还没想好。

**助手交付**（节选；完整版见下方链接）：

```text
一、信息确认：财务专员，入职两年未调薪；调薪窗口一月 → 赶在窗口前约谈 [待确认：公司实际报批时间]；期望的数 [待补]
二、证据清单（最硬的一条）
  做了什么：一至九月独立负责对账流程改造
  结果：月结从五个工作日缩到两个（时间窗：一至九月）
  出处：财务月报   谁能佐证：[待补：比如财务经理]
  职责变化：此前由两人分担，现由我独立负责
三、约谈的话：「想约您半小时，聊聊我这一年的工作和下一步，也想谈谈薪酬，您看哪天方便？」
四、开场：「感谢您抽时间。想聊聊我这一年的工作、下阶段的打算，也包括薪酬。」
五、期望：[待补：先定口径（月薪/年包、税前/税后），再定一个具体数，用「涨幅 =（期望 − 现在）÷ 现在」算清]
六、备选：「如果这次调不了，能不能明确要达到什么、什么时候重新评估？」
七、待补清单：期望的数与口径；另外两条成果；能佐证的人
```

## 常见问题（FAQ）

**Q：什么时候提最好？**
A：年度调薪或考核定档之前、重要项目交付并有可见成果之后、职责刚扩大的时候；避开上级刚挨批、会议间隙、群聊和饭局。

**Q：先发邮件还是先当面？**
A：先约当面谈，谈完当天再发邮件确认。先发邮件等于突袭，上级只能先说不。

**Q：该要多少？你帮我定个数吧。**
A：不替你定，也不提供行情数据。可以教你找可追溯的公开招聘区间，并按「涨幅 =（期望 − 现在）÷ 现在」把你自己的数算清楚。

**Q：能不能说我有别的 offer？**
A：有就如实说，不夸大也不拿来施压；没有就别说，一句追问就会失去信任。

**Q：领导说「今年没预算」怎么接？**
A：「理解。那能不能先确认我的职责和评估时间？预算下来时我再来找您。」谈完当天发邮件把共识落在纸面上。

**Q：被拒之后多久能再提？**
A：没有新证据，不要一两个月内就再提。把对方给的条件写成可验收的目标，到约定的评估时间带着证据重谈。

**Q：能直接帮我把邮件发给领导吗？**
A：不能。邮件我帮你写好，由你自己发；本技能不替你和上级沟通。

**Q：加薪和晋升先谈哪个？**
A：如果你实际承担的已经是上一级的职责，谈职级往往比单谈薪资顺——职级定了，薪资跟着走；具体怎么挂钩以本公司制度为准。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 拿「房贷压力大」「别人都涨了」当理由 | 公司为贡献付钱，不为需要付钱 | 讲职责变化和可核对的成果；生活需要只当背景 |
| 数字含糊或编造 | 一句追问就垮，信任也跟着垮 | 用能核对的数，附时间窗、口径和来源 |
| 打听、比较同事薪资 | 很多公司有保密要求（以本公司制度为准），还会把上级推到对立面 | 只用公开招聘信息，注明来源和日期 |
| 先发邮件、后当面；越过直属上级找上一级 | 上级被突袭，只能先说不；越级更是把他推到对面 | 先约直属上级当面谈，谈完当天邮件确认 |
| 拿离职要挟却没准备走 | 答应了伤信任，不答应下不来台 | 有外部机会如实说、不施压；没有就不提 |
| 只说「涨一点」 | 没有数，上级没法往上报 | 给一个具体数或窄区间，带上依据 |
| 谈一次就不跟进 | 条件没落在书面上，等于没谈 | 当天发确认邮件，每月对照条件进度，到点主动约 |

## 边界与不做什么

- 不提供薪资数据、行情判断或「该涨多少」的建议；数字由用户自己查、自己定。
- 不承诺结果，决定权在公司。
- 不做劳动法定性：降薪、欠薪、调岗降薪、加班费等争议，找人力资源部门、当地劳动保障部门或律师。
- 不帮伪造录用通知、业绩数据或他人评价。
- 不代发邮件，不替用户与上级沟通。
