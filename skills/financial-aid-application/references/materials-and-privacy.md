# 材料清单、隐私保护、被退回的常见原因

## 一、材料清单常见项

**以下是常见项，不是标准清单。要交什么、交原件还是复印件、交纸质还是在系统里上传，一律以学校资助中心（或学院）当年通知为准。**

| 材料 | 说明 |
|---|---|
| 家庭经济困难认定申请表 | 通常用学校或本省统一的格式；助学金一般在认定之后申请，以通知为准 |
| 助学金申请表 | 有的学校和认定表合在一起，有的单独交 |
| 申请书或个人陈述 | 部分学校要求单独交，部分只在申请表里写申请理由 |
| 特殊情况佐证材料 | 如低保、特困供养、残疾、重大疾病、受灾等相关证件或证明，按通知要求提供 |
| 身份证、学生证复印件 | 部分学校要求 |
| 发放资助用的银行卡信息 | 只填在学校指定的表格或系统里，不发到任何群里 |

交之前对照通知逐条打勾；通知里有、清单里没有的，以通知为准。

## 二、隐私保护：写、交、传、公示四个环节

| 环节 | 做法 |
|---|---|
| 写 | 正文只写评定需要的信息；病名、病历、证件号、银行卡号、门牌住址、他人姓名电话不写进正文 |
| 交 | 按学校指定渠道提交（纸质交辅导员，或在学校系统里上传）；不通过私人聊天发给不相关的人 |
| 传 | 不发班级群、朋友圈、贴吧、网盘公开链接；请人帮看先生成脱敏版（`scripts/privacy_scan.py --out`） |
| 公示 | 公示内容和范围按学校规定；发现不该公开的信息被公开了，私下找辅导员或资助中心反映 |

电子文件的小习惯：
- 文件名不要带身份证号、手机号，用「姓名-助学金申请书.docx」这样的名字就够。
- 在公共电脑上打印完，删掉下载目录里的文件，退出登录的账号。

## 三、被退回的常见原因（经验归纳，不是官方统计）

| 原因 | 怎么避免 |
|---|---|
| 没用学校规定的表格或格式 | 先下载通知里的附件，照格式填 |
| 申请书和认定表的数字对不上（人口、收入、变故时间） | 用一致性核对表逐项对照，以认定表为准 |
| 只有形容词，没有事实 | 每句话回答：谁、什么时候、多少钱、对收支的影响 |
| 缺签名、日期或承诺 | 交之前看一遍表格的签字栏和日期栏 |
| 材料缺项或不清楚（复印件看不清） | 对照通知逐条打勾，复印件检查清晰度 |
| 超过或远低于字数要求 | 按通知控制篇幅 |
| 手写潦草、涂改多 | 需要手写的，先打草稿再誊写 |
| 写了不该写的隐私（他人证件号、详细住址） | 交之前跑一遍 `scripts/privacy_scan.py` |
| 和别人雷同（套用同一份网上模板） | 从自己的事实写起 |
| 过了截止时间或交错了渠道 | 记下截止时间，按指定渠道交 |

被退回后：先问清具体原因，再对照上表逐条改；改完重新做一次一致性核对和隐私扫描。
