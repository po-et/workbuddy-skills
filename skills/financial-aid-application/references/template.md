# 助学金申请书模板与「感恩、规划」写法

学校给了固定表格或格式的，以学校的为准；本模板只作内容参考。

## 一、申请书模板

```
[国家助学金／其他资助项目名称]申请书

尊敬的[学院资助工作小组老师／辅导员老师]：

我是[学院][专业][年级]学生[姓名]，[已通过本学年家庭经济困难学生认定／正在参加认定，按实际写]。现申请[资助项目名称]，将家庭和个人情况说明如下。

一、家庭经济情况
我家[几]口人：[成员]。[谁]＋[做什么工作／能否工作]。[主要收入来源]，家庭年收入约[与认定表一致的数字]。[刚性支出：医疗、上学、赡养、债务，写金额]。[变故：什么时间、发生了什么、对收支的影响]。

二、本人情况
上学年[成绩、排名、有无不及格]。[勤工助学或兼职：岗位、每周几小时、做了多久]。

三、感谢与打算
[一件真实受过的帮助：谁、什么时候、帮了什么，一两句。]
如果获得资助，这笔钱我会主要用于[具体用途]。下学年，我计划[一到两个可检验的目标]，[一件你能做的回馈]。

以上情况属实，如有不实，愿意承担相应责任。恳请老师审核。

申请人：[姓名]
[年月日]
```

使用说明：
- 方括号全部换成真实内容；没有的整句删掉，不要留空。
- 承诺句按学校要求写；很多学校的表格里已经印好承诺，照表签字即可。
- 手写还是打印、要不要签名，以学校通知为准。

## 二、申请理由短版（申请表里的小格子）

顺序固定：**家庭情况（两三句事实）→ 本人情况（一句）→ 用途与规划（一句）→「以上情况属实」**。约 150–200 字足够；格子更小就先砍规划，再砍本人情况，家庭事实保留。

## 三、感恩写法：一件真事，一两句

| 空的写法 | 具体的写法（虚构示例） |
|---|---|
| 感谢国家、感谢学校、感谢老师的关心与培养 | 大一冬天，辅导员知道我没带厚衣服，帮我申请了临时困难补助 |
| 党和国家的资助政策让我深受感动 | 入学时我走了绿色通道，先报到后缴费，第一周就安心上课了 |
| 我会永远铭记这份恩情 | （删掉，把篇幅留给规划） |

没有具体受助经历的，感谢一句就够，不要硬编一件事。

## 四、规划写法：用途＋可检验的目标＋一件回馈

| 空的写法 | 具体的写法（虚构示例） |
|---|---|
| 好好学习，报效祖国 | 下学年把平均分提高到 85 分以上，通过英语四级 |
| 合理使用资助金 | 这笔钱主要用于生活费和专业课教材，尽量不再向家里要钱 |
| 将来回报社会 | 报名了学院的学业帮扶志愿活动，给大一新生讲选课注意事项 |
