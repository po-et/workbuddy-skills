# 写事实，不渲染苦情：追问话术、改写对照、一致性核对

配合 SKILL.md「第 2 步：如实陈述家庭经济情况」使用。

## 一、四类事实怎么问（用户不想说的可以跳过）

| 类别 | 先问 | 再追问（拿到能核对的细节） |
|---|---|---|
| 家庭成员与劳动力 | 家里几口人？谁在工作？ | 各自做什么工作？有没有人因为年龄、疾病、残疾不能工作，或者需要人照顾？ |
| 收入 | 家庭年收入大概多少？认定表上填的是多少？ | 主要来自哪里（务工、务农、个体、退休金、补助）？稳定吗？ |
| 刚性支出 | 有没有大的固定开销？ | 医疗（每月或每年约多少）、几个孩子在上学、赡养老人、欠款（约多少、还了多少） |
| 变故 | 最近几年家里有没有大的变化？ | 什么时候、发生了什么、对收入或支出的影响有多大？ |

问到这里就够了。和经济状况无关的家事（家庭矛盾、亲戚纠纷），不需要问，也不写。

## 二、改写对照：形容词 → 事实＋影响

以下示例均为虚构。

| 渲染式写法 | 事实＋影响 |
|---|---|
| 家里穷得揭不开锅 | 家庭年收入约 3.1 万元，主要来自父亲打零工和母亲种地 |
| 父亲积劳成疾，家庭雪上加霜 | 父亲 2024 年腰部受伤后不能再干重活，现在打零工，收入不固定 |
| 奶奶常年卧病在床，全家苦不堪言 | 奶奶需要长期服药，每月药费约 400 元，平时由母亲照顾 |
| 为了供我上学，父母操碎了心 | 学费通过生源地信用助学贷款缴纳，生活费主要靠家里和我勤工助学 |
| 我从小就吃尽了苦 | （删掉。写你现在做的事：每周勤工助学 6 小时） |
| 求求老师帮帮我 | 恳请老师审核 |
| 天灾人祸接连不断 | 2025 年夏天家里的玉米地受灾，当年收入减少约一半（有村里的说明） |
| 母亲身患重病 | 母亲 2025 年做了手术，医疗费四万余元，部分向亲戚借款，尚未还清 |

规律：
- 删掉只表达情绪的词：雪上加霜、揭不开锅、绝境、苦不堪言、操碎了心、吃尽了苦。
- 每句话都要能回答：谁？什么时候？多少钱？对收支有什么影响？
- 病情写到评定需要的程度（手术、长期服药、费用），病名和病历交给材料，不写进正文。

## 三、一致性核对表（交付物第 3 部分）

| 正文内容 | 对应的认定表栏目或证明材料 | 是否一致 |
|---|---|---|
| 家庭人口数 | 认定表「家庭成员」 | 是／否 |
| 家庭年收入 | 认定表「家庭年收入」 | 是／否 |
| 医疗支出 | 病历、票据（按学校要求） | 是／否 |
| 变故时间与影响 | 相关证明（按学校要求） | 是／否 |
| 勤工助学时长 | 勤工助学记录 | 是／否 |

有「否」就先统一，再交。认定表是已经交上去的材料，申请书要以它为准；认定表本身填错了，去找辅导员更正，不要在申请书里写一个新数字。

## 四、本人情况怎么写

一段即可，全部是能核对的事实：
- 学习：平均分或绩点、排名、有无不及格、比上学期进步多少。
- 努力：勤工助学（岗位、每周几小时、做了多久）、假期打工（做什么、挣的钱用在哪）、节省开支的具体做法。
- 不写「我一直很努力」「我从不乱花钱」这种没法核对的话。
