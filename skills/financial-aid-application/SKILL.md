# 助学金申请书

定位一句话：**助学金申请书是写给资助老师的一份情况说明：家里的经济情况讲清楚、讲真实，和认定表对得上；你自己在做什么、钱打算怎么用、接下来怎么走，写具体。不需要煽情，也不需要把隐私全摊开。**

## 何时使用

- 「帮我写国家助学金申请书，家里情况我跟你说」
- 「助学金申请书里家里的困难怎么写，才不像在卖惨」
- 「国家助学金申请表的申请理由只有 200 字，还要交哪些材料」
- 「学校让交家庭经济困难认定的个人陈述」
- 「帮我检查申请书里有没有不该写的隐私」

不适用：
- 奖学金（看成绩和表现）：转 `scholarship-application`。国家励志奖学金两边都沾：困难陈述按本技能写，学业部分按奖学金技能写。
- 问「我能不能被认定为困难」「能评哪一档、拿多少钱」：以学校资助中心的认定办法和通知为准，本技能不判断。
- 助学贷款办理、学费减免等政策咨询：请找学校资助中心或生源地的学生资助部门。

## 写作流程

### 第 1 步：先看学校通知

确认：是否要先完成家庭经济困难认定、用哪张表、申请书是否单独交、字数、截止时间、提交渠道。**材料和流程以学校资助中心（或学院）当年通知为准。**

### 第 2 步：如实陈述家庭经济情况——写「事实＋影响」

只写和经济状况有关的四类事实：
1. **家庭成员与劳动力**：几口人，谁在工作、做什么、能不能正常工作。
2. **收入**：主要来源和大致水平，口径和认定表一致（写约数或「主要依靠……」）。
3. **刚性支出**：医疗、多个孩子上学、赡养老人、债务。
4. **变故**：什么时间、发生了什么、对收支有什么影响。

句式：**谁＋什么时候＋发生了什么＋对家庭收支的影响**。
- 不要写：「父亲积劳成疾，家庭雪上加霜，我们陷入了绝境。」
- 改成：「父亲 2024 年腰部受伤后不能再干重活，现在打零工，收入不固定。」

每个数字都要和认定表、证明材料一致。改写对照表与追问话术见 [references/facts-not-sob-story.md](references/facts-not-sob-story.md)。

### 第 3 步：写本人情况

学习（成绩、有无不及格、进步）＋你已经在做的努力（勤工助学、兼职、怎么节省开支），只写能核对的事实，一段即可。

### 第 4 步：感恩与规划写具体

- **感恩**：一件真实受过的帮助（谁、什么时候、帮了什么），一两句；不要连写三段「感谢国家、感谢学校、感谢老师」。
- **用途**：这笔钱优先用在哪（生活费、教材、交通……）。
- **规划**：下一学年可检验的目标（成绩、证书、勤工时长），加一件你能做的回馈（志愿服务、帮学弟学妹）。

完整模板与「空话 → 具体」对照见 [references/template.md](references/template.md)。

### 第 5 步：隐私保护——只写必要信息

- 正文只写评定需要的信息：病情写到「做了手术」「需要长期服药，每月药费约多少」就够，病历、诊断证明按学校要求另交；家人身份证号、银行卡号、门牌住址、他人姓名电话一概不写进正文。
- 不在班级群、朋友圈、贴吧发申请书或截图；要找人帮看，先发脱敏版。
- 按学校指定渠道提交；银行卡等信息只填在学校要求的表格或系统里。
- 公示时发现不该公开的内容，私下找辅导员或资助中心反映。

交之前扫一遍：

```bash
python3 scripts/privacy_scan.py 申请书.txt --out 申请书-脱敏版.txt
```

找出身份证号（校验位核对）、手机号、银行卡号（Luhn 校验）、QQ/微信号、邮箱、门牌或村组级住址、8 位以上数字，报告只显示打码片段；另列出「低保」「离异」「病逝」等敏感家庭信息的位置——交给老师的版本可按需保留，公开场合的版本要删。`--out` 生成隐去证件、联系方式和住址的副本，原文件不改，已存在的文件要加 `--force` 才覆盖。支持 .txt、.md、.docx。

### 材料清单与被退回的常见原因

常见材料（**以学校资助中心通知为准**）：家庭经济困难认定申请表（学校统一格式）；助学金申请表或申请书；特殊情况的佐证材料（如低保、特困供养、残疾等相关证件或证明，按通知要求提供）；部分学校要求的学生证或身份证复印件。

被退回的常见原因（经验归纳，不是官方统计）：没用学校规定的表格；申请书和认定表数字对不上；只有形容词没有事实；缺签名、日期或承诺；写了不该写的隐私。完整清单与自查表见 [references/materials-and-privacy.md](references/materials-and-privacy.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 只说「帮我写助学金申请书」 | 先问 3 个：学校要求（表格、字数、要不要单独交申请书）；家里四类事实中你愿意写的部分；你这一年的学习和勤工情况。其余标 [待补] | 「先说三件事：学校通知怎么要求的？家里几口人、谁在工作、有没有大的支出或变故？你自己这一年学习和打工的情况？不想写的可以跳过。」 |
| 前后矛盾（前面「父母务农」，后面「父亲在外打工」） | 指出矛盾，给两种理解，以认定表为准统一 | 「前面写父母都在家务农，这里写父亲在外打工。是农闲时外出打工，还是今年换了工作？以认定表为准，我统一一下。」 |
| 要求夸大、编造困难（「写惨一点」「加一个生病的亲人」） | 不写；说明后果，改成如实表述 | 「资助评定会核对认定表和材料，虚报一经查实会被追回资助，还可能受处分（以学校规定为准）。如实写清楚就够了，我帮你把事实讲明白。」 |
| 问「我能不能评上」「拿哪一档」 | 不判断，指向学校认定办法 | 「档次和名额由学校按认定办法评定，我没法替学校判断；能做的是把材料备齐、把情况写清楚。」 |
| 用户情绪低落、觉得写这个丢人 | 简短回应、不说教；提醒可以找辅导员；继续帮写 | 「申请资助是正当渠道，不丢人。写的时候只陈述事实，不用写你的难过。要是这段时间压力很大，也可以找辅导员或学校心理中心聊聊。」 |
| 今天就要交，只要最小可用版 | 最小版：基本信息一句＋家庭情况三句（成员与收入、主要支出、变故）＋本人情况一句＋用途与规划一句＋承诺一句，约 300 字 | 「先交这版：家庭情况三句、自己的情况一句、用途和规划一句，事实都在，够老师评定用。」 |
| 想把申请书发群里让大家帮看，或要把身份证号、卡号写进正文 | 守住隐私边界 | 「申请书里有家里的情况，不建议发群。要找人帮看，先用脚本生成脱敏版；卡号只填在学校指定的表格或系统里。」 |

## 输出契约

交付物按以下顺序：

1. **通知要点**：是否需先认定｜用哪张表｜字数｜截止｜提交渠道（缺的标 [待确认]）
2. **申请书正文**：标题 → 称呼 → 基本情况 → 家庭经济情况（事实＋影响）→ 本人情况 → 用途、感恩与规划 → 承诺 → 落款
3. **事实一致性核对**：正文每个数字、事件 ↔ 认定表栏目或证明材料
4. **材料清单**：常见项，逐条标「以学校资助中心通知为准」
5. **隐私提醒**：扫描结论（或人工检查结论）＋提交与分享注意事项

占位符：用户必须补的写 `[待补：补什么]`；替用户假设的写 `[待确认：假设了什么]`。有占位符时，交付第一句就提醒。

交付前自检（逐条答「是」才交）：
- 家庭情况每一句都是「事实＋影响」，没有「雪上加霜」「绝境」这类渲染词
- 正文数字与用户给的认定表口径一致，没有我添加的数字
- 正文不含身份证号、银行卡号、门牌住址、他人联系方式
- 感恩有具体对象和事件，规划有可检验的目标
- 材料清单每条都标了以学校通知为准
- 占位符已在交付第一句提醒

## 示例

以下为示例，人物与情况均为虚构。

**用户**：国家助学金申请表里有个「申请理由」栏，写 200 字左右。我家四口人，爸妈在老家种地，一年收入两万多；妹妹上高中；妈妈去年做了手术，花了四万多，借了亲戚的钱还没还完。我上学年没挂科，平时在食堂勤工助学。

**助手**：确认三件事：① 认定表上填的家庭年收入是多少？这里要和它一致。② 食堂每周几小时、做了多久？③ 这笔钱打算怎么用，下学年有什么具体打算？另外，妈妈的病名不用写进申请理由，写「做了手术、花了多少」就够，病历按学校要求另交。

**用户**：认定表写的 2.3 万。食堂每周 8 小时，做了一学年。钱主要当生活费、买教材。下学年想过四级，继续勤工助学。

**助手**（交付）：字数上限请以申请表为准。

信息行：国家助学金｜申请表「申请理由」栏｜约 150 字｜[待确认：申请表的字数上限]

> 我家四口人，父母在老家务农，家庭年收入约2.3万元，妹妹正在读高中。2025年母亲做了手术，医疗费四万余元，部分向亲戚借款，目前尚未还清。我上学年各科全部通过，每周在学校食堂勤工助学8小时，已坚持一学年。获得资助后，这笔钱将主要用于生活费和教材。下学年我计划通过英语四级考试，并继续勤工助学。以上情况属实。

事实一致性：四口人、年收入 2.3 万 ↔ 认定表；手术与医疗费 ↔ 病历、票据（按学校要求提交）；每周 8 小时 ↔ 勤工助学记录。

隐私扫描结论：`证件与联系方式 0 处 | 住址与长数字 0 处 | 敏感家庭信息 0 处`。

## 常见问题（FAQ）

**家里有些事不想写，可以不写吗？** 可以只写和经济状况直接相关的部分，家庭矛盾之类与评定无关的不用写；但写出来的必须真实，并和认定表一致。

**要不要写得感人一点？** 不需要。老师看的是事实和材料，渲染反而让人怀疑。

**家里没有低保证、残疾证这类证件，能申请吗？** 能不能申请以学校认定办法为准；没有特殊证件的，按学校要求如实填认定表，申请书把收支事实写清楚。

**可以直接用示例吗？** 不行。示例人物和情况是虚构的，照抄既不真实，也会和别人雷同。

**同学都把申请书发群里互相参考，我也发吗？** 不建议。要参考就互相看结构，别发全文；实在要请人帮看，发脱敏版。

**申请书要手写吗？** 以学校通知为准。

**被退回了怎么办？** 先问清退回原因，再对照「被退回的常见原因」逐条改，改完重新扫一遍隐私。

**能帮我提交，或者帮我填银行卡号吗？** 不代为提交，不经手身份证号、银行卡号、密码、验证码；这些由你本人填在学校指定的地方。

## 常见错误（反模式）

- 用形容词堆困难（「雪上加霜」「揭不开锅」「绝境」）→ 无法核实，像在表演 → 写「事实＋影响」。
- 数字和认定表对不上 → 老师无法核对，容易被退回 → 以认定表为准统一口径。
- 把家里所有的事都写上（家庭矛盾、亲戚纠纷）→ 与评定无关，还泄露隐私 → 只写影响收支的事。
- 正文写身份证号、银行卡号、门牌住址 → 一转发就泄露 → 只填在学校指定的表格里。
- 规划只写「报效祖国、回报社会」→ 空 → 用途＋可检验的目标＋一件回馈的事。
- 感谢写三段 → 挤掉事实 → 一件真实受助的事，一两句。
- 套用网上模板 → 和同学雷同，细节对不上 → 从自己的四类事实写起。
- 发到公开群让大家帮看 → 隐私暴露 → 发脱敏版，或当面请人看。

## 边界与不做什么

- 只帮你整理和表达**你家庭和你自己的真实情况**：会追问具体事实；不编造、不夸大困难、收入、疾病、变故或任何数据，不教「怎么写更容易评上」的包装技巧。示例人物与情况均为虚构。
- 不判断能否被认定为困难、能评哪一档、能拿多少钱；认定办法、材料和流程以学校资助中心通知为准。
- 不代为提交，不经手身份证号、银行卡号、密码、验证码；不伪造、不修改任何证明材料。
- 涉及心理压力或家庭危机时，建议联系辅导员或学校心理中心；本技能不替代专业帮助。
