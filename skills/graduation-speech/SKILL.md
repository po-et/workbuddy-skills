# 毕业致辞

定位一句话：**台下几百人记不住排比句，只记得住画面。一篇毕业致辞只要三样：一个只有你讲得出的具体故事、一个全场都经历过的共同记忆、一个说得出口也做得到的期许。**

## 何时使用

用户这样说时用本技能：

- 「我被选为毕业典礼学生代表，要讲 5 分钟，从哪下笔」
- 「我是班主任，要写毕业致辞，不想讲成一串套话」
- 「家长代表毕业致辞 3 分钟，稿子写多少字，念的时候在哪停顿」
- 「这篇致辞帮我改得不空一点」——把现成的稿子改具体
- 「典礼时间压缩了，5 分钟的稿子要删到 3 分钟」
- 「致辞要用英文讲 / 中英双语，时长怎么算」

适用范围：小学、初中、高中、大学的毕业典礼，以学生代表、教师（班主任、任课老师）或家长代表的身份致辞，从零写稿或改稿。

不适用（遇到时这样处理）：

- 校长、领导、嘉宾的讲话 → 代表学校表态，不在本技能范围；请用学校提供的材料，由学校把关。
- 开学典礼、升学宴、谢师宴上的发言 → 不在本技能范围，只简答一句「同样从一件具体的事讲起」；典礼主持串词可转「主持词」（event-host-script）。
- 要求编一段感人的经历、编学校荣誉和数据 → 不编；用「信息不全或出错时」里的三个问题帮用户从自己的经历里找。

## 先判断：你是谁，就站在谁的位置讲

| 身份 | 站的位置 | 故事从哪来 | 最容易写砸 |
|---|---|---|---|
| 学生代表 | 同学中的一个 | 自己或同学的一件小事（先问过本人） | 替全体同学表决心；只感谢不讲事 |
| 教师 | 陪他们走过这几年的人 | 某个学生、某堂课、某次谈话（匿名或经本人同意） | 讲成最后一堂说教课；翻旧账 |
| 家长代表 | 台下所有家长中的一个 | 自家孩子的一个片段，接送路上的一个观察 | 只讲自家孩子多优秀；替别的家长把话说满 |

动笔前问清：规定时长；前后是谁发言（别和校长讲话撞内容）；要不要提前交稿审核；有没有提词器，还是只能手拿稿。

不同学段，结构不变，换的是用词和选材：

| 学段 | 台下主要是谁 | 语言 | 故事与共同记忆怎么选 |
|---|---|---|---|
| 小学 | 孩子，家长在场 | 短句、孩子听得懂的词，少用成语和抽象词 | 孩子认得出的小事：一节课、一次值日、一次运动会 |
| 初中 | 同学、老师、家长 | 句子短，可以带一点幽默 | 三年里全年级都经历过的事 |
| 高中 | 同学、老师、家长 | 可以讲一次选择或坚持 | 高三的具体场景；不讲分数和排名 |
| 大学 | 同学、老师、部分家长 | 可以更个人化；引用要说得出出处 | 宿舍、课堂、实验室、社团里的具体一天 |

## 三块结构：故事 → 共同记忆 → 期许（分五步写，附填空模板）

```
第 1 步 开场（两三句）：称呼＋你是谁＋一句直接进入画面的话，不从「时光飞逝」讲起。
第 2 步 具体故事：一个时间、一个地点、一个人、一个动作或一句原话。
        检查点：换一所学校、换一个人来讲，这段就不成立——才算具体。
第 3 步 共同记忆：全场都经历过的事——军训时的一场雨、停电的那次晚自习、食堂的某道菜、运动会的接力。
        检查点：念到这里，台下多数人会点头或笑出声；只有你们班知道的事不算。
第 4 步 期许：只说一个，从故事里长出来——「愿你们以后遇到[类似处境]，还能像那天的[某人]一样[动作]。」
        检查点：期许里有一个动作，而不是一串形容词。
第 5 步 感谢与收尾：感谢落到具体的人和事（「谢谢[李老师]那年冬天每天七点就来开教室门」），最后一句回到开头的画面。
```

```
【3 分钟填空模板，约 530 字；三种身份只换方括号里的视角】
称呼：按学校惯例排，如「尊敬的各位老师、各位家长，亲爱的同学们」
开场（约 50 字）
  学生代表：我是[班级]的[名字]。[一句画面，如：三年前的今天，我在校门口找错了教学楼。]
  教师：我是[学科]老师[名字]。这是我送走的第[N]届学生，[一句画面]。
  家长：我是[班级][孩子名字]的[妈妈/爸爸]。[一句画面，如：今天早上出门前，孩子……]
故事（约 200 字）：[时间]，[地点]，[人物][做了什么/说了什么]。当时我[反应]。后来我才明白[这件事背后的东西]。
共同记忆（约 120 字）：我想大家都还记得[全场经历过的那件事]。[一个大家都知道的细节]。
期许（约 80 字）：[学生：我希望我们……/教师：最后我只嘱咐一件事……/家长：我们只盼着……]，就像[故事里的人]那天[那个动作]。
感谢与收尾（约 80 字）：谢谢[具体的人][具体的事]。[回到开头的画面，一句]。谢谢大家。
```

## 3、5、8 分钟三档：字数与配比

请致辞人按上台的速度念一分钟，数出字数；测不了先按每分钟约 200 字估（致辞要停顿、等掌声，比平时说话慢，以实测为准）。字数 = 分钟 × 语速 × 0.9。

| 时长 | 总字数（按 200 字/分钟） | 开场 | 故事 | 共同记忆 | 期许 | 感谢与收尾 |
|---|---|---|---|---|---|---|
| 3 分钟 | 500–550 | 50 | 200 | 120 | 80 | 80 |
| 5 分钟 | 850–900 | 60 | 300 | 200 | 150 | 150 |
| 8 分钟 | 1400–1450 | 80 | 两个故事共 550 | 300 | 250 | 250 |

表里的字数是动笔时的目标；标注的停顿和等掌声的地方越多，同样时长能放的字越少，定稿以下文脚本的估算和实测计时为准。

时间临时被压缩时的删法：先删第二个故事，再删感谢里的名单；故事和期许最后动。

## 套话清单：删掉，或换成一件具体的事

| 套话 | 为什么不行 | 换成 |
|---|---|---|
| 时光飞逝，岁月如梭；转眼间 | 人人这么开头，台下一听就走神 | 一个画面：「三年前的九月，我在校门口找错了教学楼。」 |
| 感谢老师的辛勤培育 | 没有人，也没有事 | 「谢谢[李老师]把我的作文本改到第三遍。」 |
| 今天我们以母校为荣，明天母校以我们为荣 | 用的人太多，听不出是谁在说 | 一件你真打算去做的事 |
| 愿你出走半生，归来仍是少年 | 网络流行句，全场都听过 | 用故事里的那个动作写期许 |
| 我们哭过、笑过、奋斗过 | 排比三连，一样都没讲 | 挑其中一次哭或笑，讲具体 |
| 不忘初心、青春无悔、前程似锦 | 抽象词堆在一起 | 每个词后面补得出「比如……」，补不出就删 |

## 朗读标注：断句、停顿、重音

打印稿每行一句，字号放大（建议三号以上），段与段之间空一行，然后标四种记号：

```
/      短停，约半秒：意群之间换气
//     长停，一到两秒：段落转换，或故事最关键的一句之后
▲      停下等反应：预计有笑声、掌声的地方，等声音落下再开口
**词**  重音：每句最多一个，落在最想让人记住的词上（打印时改成加粗或下划线）
示例：
那年冬天 / 李老师每天早上七点 / 就来把教室的门打开。//
她从来没说过为什么。//
今天我想告诉她：/ **我们都知道。** ▲
```

断句规则：按意群断，不在「的」「了」「和」前后硬断；称呼之后停一下；故事讲完的最后一句后长停，让画面落地。上台前按标注完整念三遍并计时，超时先删形容词，再按上面的删法删段落。

标注好的稿子存成 UTF-8 的 speech.txt，用脚本估算含停顿的时长（短停按 0.5 秒、长停 1.5 秒、▲ 3 秒计）：

```bash
python3 {baseDir}/scripts/speech_timer.py speech.txt 200              # 200 换成实测语速（字/分钟）
python3 {baseDir}/scripts/speech_timer.py speech.txt 185 --target 3   # 和规定时长比，超时退出码为 3
python3 {baseDir}/scripts/speech_timer.py speech.txt --wpm 110        # 稿子里有英文，按实测每分钟词数计入
```

脚本只读不改文件，只用 Python 标准库；语速、时长写错会直接提示，退出码见下一节。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| E1 缺关键信息：没说身份、学段或时长 | 只问 3 个：以什么身份讲、什么学段；规定几分钟；有没有一件具体的小事。语速先按 200 字/分钟、称呼按学校惯例写，标 [待确认] | 「先告诉我三件事：你以什么身份讲、什么学段？规定几分钟？有没有一件只有你讲得出的小事？其余我先按常见做法写，标了 [待确认] 的你再改。」 |
| E2 时长没法用：写成 0、负数、「半小时」或没写单位 | 指出这个时长排不了字数；请用户对照学校规定，给出 3、5、8 分钟三档或实际分钟数；脚本遇到非正数直接报错 | 「规定时长写的是……，这个没法排字数。学校规定的是 3、5、8 分钟里的哪一档，还是别的时长？」 |
| E3 信息自相矛盾：3 分钟要讲三个故事再感谢二十位老师；学生代表却要「代表全体同学表决心」 | 指出矛盾，给两个选项让用户选 | 「3 分钟放不下三个故事和二十个名字。你想①只讲一个故事、感谢里点一两位老师，还是②和学校确认能不能讲 5 分钟？」 |
| E4 素材不足，想不出故事 | 不编；用三个问题帮用户从自己的经历里挖：哪一天印象最深，当时在哪、谁在场、说了什么；故事位置先写 [待补：故事]，其余先写 | 「故事我不能替你编。回想一下：这几年哪一天你印象最深？当时在哪、谁在场、说了什么？先说个大概，我帮你理成一段。」 |
| E5 超出范围：校长、领导、嘉宾讲话；开学典礼、升学宴、谢师宴发言 | 说明不在本技能范围；只简答一句通用建议；主持串词转主持词技能 | 「校长和嘉宾的讲话代表学校表态，不在我这里写。要是你是典礼主持人，可以用主持词技能写串词。」 |
| E6 要求编造经历、荣誉、数据，或写未经同意的真人真事与隐私 | 不编、不写；真人真事先征得本人同意；成绩排名、家庭状况、健康状况不进稿子 | 「这段写到同学的真名和家里的事，得先问过他本人；成绩排名和家庭情况不进稿子，我换一个写法。」 |
| E7 要提到离世的师生或重大变故 | 先和学校商量怎么讲、讲多少，必要时请心理老师把关；这一段先标 [待确认：学校意见] | 「这一段先别定稿，请先和学校商量怎么讲、讲多少。我先写一个克制的版本，标了 [待确认]。」 |
| E8 时间紧，只要一版能先交的 | 最小可用版：用 3 分钟填空模板，拿用户的一句话故事和一件共同记忆直接出稿，附一行时长估算；朗读标注随后补 | 「给我一句话的故事和一件全场都记得的事，我先按 3 分钟模板出一版能交的稿子。」 |

脚本 `speech_timer.py` 的退出码与报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 估算完成；给了 `--target` 时未超时 | 仍要上台前实测念三遍 |
| 3 | 给了 `--target`，估算时长超过规定 | 先删形容词，再先删第二个故事、再删感谢名单 |
| 1「语速必须是正数」「规定时长必须是正数」「内容为空」 | 参数写错，或稿子里没有文字 | 语速填实测的每分钟字数，如 200；时长填分钟数，如 3 |
| 2「找不到文件」「像是 Word 或 PDF」「不是 UTF-8 文本」 | 路径错误；稿子还在 Word 里或是 GBK 编码 | 把稿子复制进 UTF-8 的 speech.txt 再估算 |
| 130 | 按了 Ctrl+C | 重新运行即可 |

## 输出契约

交付物按下面的固定顺序给出，缺哪部分就在原位置写「待补：原因」，不调换顺序：

1. **信息确认一行**：身份｜学段｜规定时长｜学校要求（是否审稿、有无统一格式）｜语速（实测，或按 200 字/分钟估并标 [待确认]）｜目标字数（分钟 × 语速 × 0.9）。
2. **带朗读标注的正文**：每行一句，用 / // ▲ **词** 四种记号。
3. **时长估算一行**：脚本输出或手算，写明是否超时。
4. **结构对照**：开场、故事、共同记忆、期许、感谢与收尾各在第几行。
5. **套话处理记录**：删掉或替换了哪些套话（改稿时逐句列）。
6. **压缩方案**：规定时长临时缩短时先删哪段，删完怎么接上。
7. **待补 / 待确认清单**：要本人同意的真人真事、要学校确认的内容、需要用户补的细节。

占位符规则：[待补] ＝只有用户知道的故事、人名和细节，不替用户编；[待确认] ＝按默认值写的内容（语速、称呼），以及写进稿子前要征得同意的真人真事。

交付前自检（逐条答「是 / 否」，有一条「否」就先改再交）：

- [ ] 开头不是「时光飞逝」一类套话，第一段就有画面
- [ ] 故事有时间、地点、人物、一个动作或一句原话，而且全部来自用户提供的素材
- [ ] 共同记忆是全场都经历过的事，不是只有你们班知道的
- [ ] 期许只有一个，里面有一个动作
- [ ] 估算时长不超过规定时长（脚本退出码 0，或手算不超）
- [ ] 真人真事都标明了是否已征得同意，稿子里没有成绩排名、家庭状况等隐私

## 示例

以下为示例，人物与事件均为虚构，全部来自示例中「用户」提供的素材。

**用户：** 家长代表毕业致辞 3 分钟，稿子写多少字，念的时候在哪停顿？

**助手（先问 3 件事）：** ① 什么学段，孩子在哪个班，学校要不要提前交稿？② 有没有一个只有你讲得出的片段：时间、地点、孩子说了什么？③ 全年级都经历过的一件事是什么？想具体感谢谁、为了什么？

**用户：** 高中，高三（2）班，孩子叫小林，学校要提前一周交稿。高三冬天我每天早上六点半送她到校门口，天还黑着，她在车上背单词；有一次她发烧还坚持去，在车上睡着了，我让她多睡了十分钟，她醒来第一句是「妈，你回去再睡会儿」。全年级都记得百日誓师那天雨突然下大，没有一个人跑，大家在雨里把口号喊完，喊完全场都在笑。想谢谢班主任王老师，每天晚自习陪到十点，走前把教室每扇窗户关好。

**助手（交付）：**

① 信息确认：家长代表｜高中｜规定 3 分钟｜学校要求：提前一周交稿｜语速按 200 字/分钟估 [待确认：请实测]｜按公式目标约 540 字

② 带朗读标注的正文：

```
尊敬的各位老师、各位家长，/ 亲爱的同学们：//
我是高三（2）班小林的妈妈。//
高三那年冬天，/ 我每天早上六点半送她到校门口。/
天还黑着，/ 她就在车上背单词。/
有一次她感冒发烧，/ 还是坚持去上课，/ 在车上睡着了。/
到了校门口，/ 我没叫醒她，/ 让她多睡了十分钟。//
她醒过来，/ 第一句话是：/「妈，/ 你回去再睡会儿。」//
```

## 常见问题（FAQ）

**问：3 分钟到底写多少字？**
答：先按上台的速度念一分钟数出语速；测不了按 200 字/分钟估，字数 = 分钟 × 语速 × 0.9，3 分钟约 500–550 字。停顿标得多，字数要再少一些，以脚本估算和实测为准。

**问：能帮我编一个感人的故事吗？**
答：不编。故事只能来自你自己的经历；回答三个问题——哪一天印象最深、当时在哪、谁说了什么——我帮你理成一段。

**问：能写英文或中英双语的致辞吗？**
答：可以，结构和配比不变。英文部分按实测每分钟词数估时长（脚本加 `--wpm`）；双语稿要把两种语言实际念的时间加在一起算。

**问：小学和大学的致辞写法一样吗？**
答：结构一样，用词和选材不同：小学用短句和孩子听得懂的词，大学可以更个人化。详见「先判断」里的学段表。

**问：上台忘词了怎么办？**
答：打印稿每行一句、字号放大，就是为了随时找回位置；忘了就低头找到下一行，停一下再接，不要临场编新句子。

**问：话筒突然没声音了怎么办？**
答：停下来，等工作人员处理好，再从当前这一段的第一句重新开始。

**问：典礼上临时说时间不够了，现场怎么删？**
答：先删第二个故事，再删感谢里的名单；故事和期许最后动。稿子里提前标好「可删段」，现场就不慌。

**问：稿子要不要背下来？**
答：不必逐字背。按标注完整念三遍并计时，熟到看一眼每行开头就能接上即可。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 从「时光飞逝，岁月如梭」开头 | 人人这么开头，台下一听就走神 | 第一句就进画面 |
| 学生代表替全体同学表决心 | 你是同学中的一个，不是全体 | 讲你自己或同学的一件小事（先问过本人） |
| 只感谢，不讲事 | 没有画面，台下记不住 | 感谢落到具体的人和事 |
| 教师讲成最后一堂说教课，或翻旧账 | 典礼不是训话 | 从某个学生、某堂课、某次谈话讲起（匿名或经本人同意） |
| 家长只讲自家孩子多优秀，替别的家长把话说满 | 台下其他家长和孩子会不舒服 | 你是台下家长中的一个，讲一个片段 |
| 共同记忆只有你们班知道 | 其他人接不上 | 挑全场都经历过的事 |
| 期许是一串形容词：不忘初心、前程似锦 | 抽象词堆在一起，没人记得住 | 只说一个，带一个动作，从故事里长出来 |
| 排比三连：「哭过、笑过、奋斗过」 | 一样都没讲 | 挑其中一次讲具体 |
| 未经同意写真人真事，公开成绩排名、家庭状况 | 侵犯隐私，也可能伤人 | 先征得本人同意；隐私不进稿子 |
| 超时就临场加快语速 | 听不清，停顿全没了 | 先删形容词，再按删法删段落 |

## 边界与不做什么

- 写进稿子的真人真事先征得本人同意；不公开成绩排名、家庭状况、健康状况等隐私，不拿任何学生当反面例子。
- 不编造学校的历史、荣誉和数据；要引用的以学校提供的材料为准，审稿、定稿按学校流程走。
- 不代表学校表态，不拿别的学校、别的孩子、别的家长做比较。
- 典礼上要提到离世的师生或重大变故时，先和学校商量怎么讲、讲多少，必要时请心理老师一起把关。
- 校长、领导、嘉宾的讲话，以及开学典礼、升学宴上的发言，不在本技能范围。
