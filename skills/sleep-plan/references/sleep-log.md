# 睡眠日志：字段、记法与复盘

每天起床后两分钟内填完，填估计值即可，不必精确。用电子表格记，另存为 `sleep_log.csv`（UTF-8）。

```
date,bed,latency,waso,wake,up,nap,caffeine_last,screen_off,energy
09-01,23:10,40,20,06:50,07:05,0,15:30,22:40,3
```

| 字段 | 含义 | 写法 |
|---|---|---|
| date | 日期 | 09-01 这样即可 |
| bed | 上床时间 | 24 小时制 HH:MM |
| latency | 大约多久睡着 | 分钟数，凭感觉估，不看表 |
| waso | 夜里醒着共多久 | 分钟数，没醒就写 0 |
| wake | 最终醒来 | HH:MM |
| up | 下床 | HH:MM，不能早于 wake |
| nap | 午睡 | 分钟数，没睡写 0 |
| caffeine_last | 最后一次咖啡因 | HH:MM；咖啡、浓茶、奶茶、能量饮料、可乐都算 |
| screen_off | 放下手机 | HH:MM |
| energy | 白天精神 | 1–5 分 |

前 6 列必填，后 4 列建议填：复盘时要靠它们找「破例」。

## 算四个数

```bash
python3 scripts/sleep_log_stats.py sleep_log.csv
```

输出平均卧床、平均睡着、睡眠效率（睡着时间 ÷ 卧床时间）、起床时间最早与最晚之差，逐条对照第 14 天复盘规则，并列出睡得最差的三晚。某一行时间写错（如 `23.10`）、入睡加夜醒比卧床还长、下床早于醒来，这一行会被跳过并说明原因，其余照算。

## 复盘时再对照一遍

挑出睡得最差的三晚（脚本已列出），看当天的午睡、最后一次咖啡因、放下手机时间有没有破例，找出最常见的那个原因，下两周先改它。

脚本只算数、对规则，不从日志推断任何疾病；消费级设备估算的睡眠分期有误差，只看趋势，结论交给医生。
