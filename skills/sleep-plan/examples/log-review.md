# 完整示例：记满 14 天日志后的第 14 天复盘

## 4. 交付物

**① 四个数与规则对照**

```bash
python3 scripts/sleep_log_stats.py sleep_log.csv
```

```
有效记录 14 天
平均卧床 7.7 小时，平均睡着 6.7 小时
睡眠效率 87%，起床时间最早与最晚相差 30 分钟
白天精神平均 3.1 分（1–5）

对照第 14 天复盘规则（睡眠效率 = 睡着时间 ÷ 卧床时间；85% 是常用参考线，不是诊断标准）
  · 第 2 条：效率 ≥ 85%，白天精神 ≥ 3 分 → 保持；想多睡就把上床提前 15 分钟，观察一周再动

睡得最差的 3 晚（按当晚效率），看当天有没有破例：
  日期      效率  入睡  午睡  最后咖啡因  放下手机
  10-12      80%    50     0  15:30       22:40
  10-14      80%    60     0  16:40       23:00
  10-16      83%    35    20  14:40       22:15

只算数、对规则，不判断是不是失眠症或别的疾病；持续失眠、打鼾憋气、白天控制不住地睡着，请就医。
```

**② 解读**

- 起床时间最早与最晚只差 30 分钟，没触发第 1 条：起床已经钉住了。
- 效率 87%、白天精神平均 3.1 分，对上第 2 条：保持现在的作息。
- 入睡用时从第一周的 30–60 分钟降到第二周的 15–30 分钟，趋势是好的。
- 最差的三晚里，10-12 和 10-14 的最后一次咖啡因在 15:30、16:40，晚于计划的 15:00 截止；10-16 午睡了 20 分钟。最常见的破例是咖啡因晚了，下两周先改这一条。

**③ 下两周的调整**（依据：复盘规则第 2 条）

- 起床仍是每天 07:00，周末最多晚 30 分钟。
- 想多睡的话，第 15–21 天把计划上床从 23:15 提前到 23:00，观察一周再动；不想加就保持 23:15。
- 咖啡因严格在 15:00 前结束，下午想喝就换成不含咖啡因的饮品。
- 睡前 60 分钟流程和「困了再上床」照常执行，日志继续记。
