# 问卷设计

定位一句话：**每道题都要能指回一条假设；指不回去的题，收得再多也是噪音。**
适用：员工或用户满意度调查、毕业论文问卷、活动反馈、需求摸底；手里有一份问卷想挑毛病；不知道该发多少份。

## 先判断：这件事该不该用问卷

- 适合：要知道「有多少人、占多大比例、哪一组更高」，也就是量的问题。
- 不适合：要知道「为什么、怎么想的、卡在哪一步」——先做几场访谈把选项找全，再出问卷（见 访谈提纲 interview-outline）。
- 动笔前写下三句话，写不出就先别出题：① 这份问卷服务哪个决策（例：食堂晚餐要不要从 19:00 延到 20:30）；② 谁来答、一共多少人、怎么触达他们；③ 结果是 A 你做什么、是 B 你做什么——两种结果做的事一样，这份问卷就不必发。

## 流程：目标 → 假设 → 题目 → 题型 → 题序

```
第 1 步 写假设：把决策拆成 2–4 条能被数据推翻的判断
  H1 晚餐需求主要来自每周加班两天以上的人
  H2 不来食堂吃晚饭的主因是关门早，不是口味或价格
  H3 延长后每天来吃的人够覆盖成本（盈亏线由行政自己算）
第 2 步 先画空表：为每条假设画出结论要用的表，如「加班天数 × 预计就餐次数」交叉表；
  表里每个行列变量对应一道题，没进任何表的题删掉
第 3 步 选题型
  单选：选项互斥且穷尽，末尾给「其他（请注明）」或「不适用」
  多选：限定「最多选 2 项」，否则人人全选，没有区分度
  量表：五级或七级，每个刻度都写文字，全卷方向一致，另设「不了解，不评价」
  频率：必须带时间窗，问「过去 4 周几次」，不问「经常／偶尔」
  排序：不超过 5 项，再多就改问「最重要的一项」
  开放：全卷 1–2 道、放最后、选填；要统计的内容别用开放题收
  敏感：收入、健康这类给区间不问精确数，加「不便回答」，放到最后
第 4 步 排题序：筛选题 → 好答的行为题 → 评价题 → 意向题 → 背景信息 → 开放题；
  先问总体再问细项；部门、原因这类选项可随机排序，「其他」固定在最后，量表选项不随机
第 5 步 设跳转：画跳转图，每条路径从头走到尾，不该答的人看不到，该答的人不会被跳过
第 6 步 写开头：三句话说清谁在做、结果用来做什么、大约几分钟；匿名与否照实写，承诺的时长要守住
```

## 预测试与样本量粗算

预测试：找 5–10 位目标人群（经验值），不找参与出题的人；请对方边读边说「这题在问什么、选哪个、为什么犹豫」。记下用时、卡住的题、理解与原意不同的词、几乎人人选同一项的题；改完再测 2–3 人。正式发放后先看前 20 份：成片空白的题、「其他」里反复出现的同一答案（说明漏了选项）。以手机作答为主时，题干不超过两行、矩阵题不超过五行（经验值），否则中途放弃的人会明显变多。

样本量：比例类结论，95% 置信、按最保守的 p=0.5 算，误差 ±10% 约 97 份，±5% 约 385 份，±3% 约 1068 份。总体只有几百人要做有限总体修正；发放量 = 需要份数 ÷ 预计回收率。

```bash
# z 置信系数，p 预估比例，e 允许误差，N 总体人数，r 预计回收率
python3 -c "import math;z,p,e,N,r=1.96,0.5,0.05,500,0.3;n0=z*z*p*(1-p)/e/e;n=n0/(1+(n0-1)/N);print(math.ceil(n0),math.ceil(n),math.ceil(n/r))"
# 输出 385 218 725：总体很大要 385 份；500 人的总体要 218 份；回收率 30% 就得发 725 份
```

分组比较：每个要单独下结论的组各按公式算；两组各 100 份时，相差不到约 14 个百分点就可能只是抽样误差。公式只对随机或接近随机的样本成立；朋友圈转发、自愿填写的方便样本，份数再多也修不了偏差，报告里只能写「本次填答者中」，不能写「全体员工中」。回收后先剔除用时明显过短、整页都选同一项的问卷，剔除规则发放前写好，别看了结果再定。

## 示例：12 题问卷与自查清单

```
Q1 【筛选】你目前每周至少 3 天在本园区办公吗？ ○是 ○否（结束）
Q2 【H1】过去 4 周（约 20 个工作日），你 19:00 以后仍在公司的天数？
   ○0 天（跳至 Q10） ○1–4 天 ○5–8 天 ○9–12 天 ○13 天及以上
Q3 【H3】这些天你通常几点离开？ ○19:00–19:59 ○20:00–20:59 ○21:00–21:59 ○22:00 及以后
Q4 【基线】过去 4 周你在食堂吃晚饭几次？ ○0 次 ○1–4 次 ○5–8 次 ○9 次及以上（非 0 次跳至 Q6）
Q5 【H2】没在食堂吃晚饭的主要原因？（最多选 2 项）
   □到饭点已关门 □口味不合适 □价格偏高 □品种太少 □更习惯外卖或回家吃 □其他____
Q6 【H2】加班日的晚饭你最常怎么解决？ ○食堂 ○外卖 ○附近餐馆 ○回家再吃 ○不吃 ○其他____
Q7 【H2】你对食堂晚餐以下各项的满意程度？（每行单选）
   口味／价格／品种／供应时间 × 非常不满意／不太满意／一般／比较满意／非常满意／没吃过，不评价
Q8 【H2】以下改进哪一项对你最重要？ ○延长供应时间 ○增加品种 ○降低价格 ○提供打包 ○都不需要
Q9 【H3，只作上限】若供应到 20:30，按过去 4 周的节奏，你预计每周来吃几次？ ○0 ○1 ○2–3 ○4 次及以上
Q10【分组】你所在的部门类型？ ○研发 ○销售 ○职能 ○生产 ○其他
Q11【分组】单程通勤时间？ ○不到 30 分钟 ○30–59 分钟 ○60–89 分钟 ○90 分钟及以上
Q12【开放，选填】关于晚餐，还有什么想告诉行政部的？____
```

读法：H1 看 Q2 × Q9 交叉表，加班天数越多的组，预计每周来吃两次以上的比例是否明显更高；H2 看 Q5 的原因分布与 Q7 中「供应时间」一行是否明显低于口味和价格。Q3 若多数人 21:00 以后才走，延到 20:30 也接不住，结论该是「延到几点」而不是「延不延」；Q9 是意向题，意向普遍高估实际行为，决策以 Q2、Q4 的行为数据为主。

```
□ 每题都标得出服务哪条假设或哪个分组变量
□ 一题只问一件事：题干里有「和」「及」「或」的逐个复查
□ 题干没有褒贬词，没有「大家都说」「你是否同意……很重要」
□ 选项互斥且穷尽，数字区间不重叠（1–4／5–8，不是 1–5／5–10）
□ 频率和数量题都带时间窗；量表每个刻度都有文字、全卷方向一致
□ 敏感题和背景题放最后，没有收集用不上的个人信息
□ 每条跳转路径都实际走过一遍，预测试用时不超过开头承诺的时长
```

## 最常见的错误

```
诱导：「新食堂品种这么丰富，你满意吗？」→「你对食堂晚餐品种的满意程度？」配平衡量表
双重提问：「你对价格和口味满意吗？」→ 拆成两行；一个满意一个不满意的人没法答原题
预设前提：没筛选就问「你每周在食堂吃几次晚饭」→ 先问吃没吃过，或给「0 次」
模糊频率：「你经常加班吗？」→「过去 4 周，19:00 以后还在公司的天数？」
否定句：「你是否不同意取消晚餐？」→ 改成正向陈述，双重否定一律删
选项重叠：年龄「18–25／25–30」→「18–24／25–29」
意向当事实：「推出后你会来吗」的「会」被当成来客数——意向只当上限，结论靠行为题
题目太多：每题都「顺便问问」→ 回到第 2 步的空表，没进表的删掉
开放题太多：五道开放题收回来没人读得完 → 能列出选项的都改成选择题
```

## 输出契约

1. 先交「决策—假设—空表」三件套，用户确认后再出题。
2. 每题标注服务的假设或分组变量、题型与跳转规则，附问卷开头的说明文字。
3. 附预测试计划与样本量算式，数字写出算法与前提，用户能自己重算。
4. 改别人的问卷时逐题给「原题 → 问题所在 → 改法」，不整卷重写。
5. 附分析计划：每条假设看哪张表、什么结果算支持、什么结果算推翻，发放前就写好。

## 边界与不做什么

- 不做统计检验与建模，不替你下「显著」的结论；论文里的分析方法请与导师确认。
- 面向学生、患者、未成年人或涉及健康、收入等敏感信息的调查，要不要伦理审批与知情同意，以学校或单位规定为准，问导师或伦理委员会。
- 不自编测评心理状况或用于诊断的量表；需要标准化量表时用已发表并验证过的版本，并遵守其使用许可。
- 不代发、不代填、不刷份数；不收集身份证号、手机号这类用不上的个人信息，抽奖要留联系方式的，单独收集、与答卷分开存放。
