# 生日策划

定位一句话：**生日办得好不好，不看花了多少钱，看寿星那天有没有被照顾到——在意的人在场，在意的细节被记住，流程没让他尴尬或操心。**
何时用：给孩子办生日会，给伴侣或父母过生日，给同事准备办公室惊喜，或者想给自己好好过一次生日，需要一份从准备到当天的完整方案时。

## 先定六件事：对象、预算、人数、场地、时间、惊喜与否

| 对象 | 重点 | 建议时长 | 最容易踩的坑 |
|---|---|---|---|
| 小孩 | 孩子玩得尽兴，家长放心 | 1.5–2.5 小时 | 环节太长、没问过敏、没安排大人看护 |
| 伴侣 | 专属感：只有你知道的细节 | 半天到一天 | 照搬网上模板；当众惊喜让不爱被关注的人下不来台 |
| 父母 | 团圆、省心，不让他们张罗 | 一顿饭加一小时 | 子女办得热闹，老人跟着忙前忙后 |
| 同事 | 轻松不尴尬，不耽误工作 | 15–30 分钟 | 公开年龄、搞恶作剧、强行 AA |
| 自己 | 按自己舒服的方式来 | 随意 | 等别人来安排，最后没人安排 |

- 预算：总额还是人均，谁出钱（自己、AA、公费）。人均 = 总预算 ÷ 确定人数；人均连一份餐都不够，先减人数或换场地。
- 人数：分「确定来」和「可能来」，吃的按确定人数多备一成。
- 场地：家里、户外、餐厅包间、租用场地或办公室；户外必须同时定好室内备选。
- 时间：先确认寿星当天有没有别的安排；小孩避开午睡，老人别安排太晚，同事选下午茶时段。
- 惊喜与否：先问一个知情人「他喜欢被关注吗」；怕尴尬的人不做当众惊喜。
- 小孩生日会请几个小朋友：学龄前常见的经验是「年龄 + 1」个，先照这个起步。
- 父母整寿：按虚岁还是周岁、要不要「做九不做十」，各地习俗不同，先问家里长辈。

```
预算起步分配（按实际调整）
餐饮与蛋糕   45%   对人数最敏感，先算它
场地         15%   在家办就是 0，挪给餐饮或活动
布置         10%   气球、横幅、桌布、照片墙
活动与道具   10%   游戏奖品、手工材料、音乐
礼物与回礼   10%   回礼按到场人数多备 2 份
备用金       10%   临时加人、补买东西都从这里出，不要省
```

## 时间线：前 2 周、前 3 天、当天

```
前 2 周
[ ] 定日期、时段、人数上限、总预算、主题（一句话说得清，如「恐龙探险」「老照片回顾」）
[ ] 定场地：包间问清容纳人数、最低消费、能否自带蛋糕饮品、取消规则；在家办先估客厅站得下几人
[ ] 发邀请：写明时间、地点、要不要带东西，顺带问忌口与过敏；小朋友的邀请发给家长
[ ] 订蛋糕：尺寸、口味、字样、取货时间；造型蛋糕要提前几天，问店家
[ ] 分工：采购、布置、拍照、控场、带寿星（惊喜时）各落到一个人
前 3 天
[ ] 二次确认人数，按最终人数改餐饮和回礼数量
[ ] 买齐不怕放的东西：布置、餐具、道具、蜡烛、电池
[ ] 看天气预报，户外活动定好下雨去哪
[ ] 把当天环节表发给帮忙的人，约好到场时间
[ ] 惊喜：和带寿星来的人对好借口与到达时间
当天
[ ] 开场前 1 小时布置完，留出补救时间；试一遍音箱、投影和灯
[ ] 取蛋糕、买生鲜；蛋糕冷藏，蜡烛和打火机交给切蛋糕的人
[ ] 控场的人按环节表盯时间
[ ] 散场后收垃圾、归还场地，当晚发合影和感谢
```

采购清单按类别勾，数量写在后面：

```
布置  气球、打气筒、横幅或字母气球、桌布、胶带、照片墙夹子
蛋糕  蜡烛（数字或普通）、打火机、蛋糕刀、纸盘、叉子
餐饮  主食、水果、饮料、冰块、杯子、纸巾、湿巾
活动  游戏奖品、手工材料、音箱或手机外放、充电宝
回礼  回礼袋（到场人数 + 2）、感谢卡
应急  垃圾袋、创可贴、剪刀、备用电池、一套备用餐具
```

蛋糕尺寸常见参考：6 寸约 2–4 人，8 寸约 4–8 人，10 寸约 8–12 人，以店家说明为准。

邀请文案（前 2 周发；小朋友的发给家长）：

```
[小宇]的 5 岁生日会，想请[孩子名]来一起玩！
时间：10 月 17 日（周六）15:00–17:00
地点：[地址]，到了打这个电话：[ ]
主题：恐龙探险，穿绿色衣服更应景，没有也没关系
礼物：[人来就好 / 其他说明]
孩子有过敏或忌口，请提前告诉我；10 月 10 日前回复能不能来，方便准备吃的和回礼
```

## 当天环节怎么排

```
时间      环节          负责人   要点
T-15 分   迎客          ___     先到的人有事做：小朋友发贴纸或涂色卡，大人有饮料
T+0       开场          ___     一句欢迎加今天怎么玩，不超过 2 分钟
T+10      主活动        ___     小朋友每个游戏 10 分钟左右，大人可以长一些
T+40      吃东西        ___     玩过一轮就开饭，饿着的孩子容易闹
T+70      蛋糕          ___     关灯、点蜡烛、唱歌、许愿、吹蜡烛、切蛋糕；拍照的人提前站好位
T+85      祝福与礼物    ___     小朋友的礼物可以回家再拆，免得互相比较
T+100     合影、送客    ___     回礼在门口发
```

- 蛋糕环节是唯一需要所有人都在场的节点；时间紧就删别的环节，别删它。
- 蜡烛远离气球和纸质装饰；气球破了，碎片马上捡走，别让小孩含着玩。
- 学龄前孩子多的场合，每 4–5 个孩子至少安排一个大人专门看着；整颗葡萄要切小，坚果、硬糖、小杯果冻不给小小孩。

## 三份可直接套用的方案

```
【A 家庭小型】给父母或小孩 · 6–10 人 · 在家 · 约 2 小时（不含布置）
流程  17:00 布置 → 18:00 开饭 → 19:00 照片回顾或亲友视频祝福 → 19:20 蛋糕 → 19:40 合影
分工  一人做饭或订餐，一人布置兼拍照，一人陪寿星（惊喜时负责拖到 17:50 再回家）
亮点  提前一周请亲友各录 20 秒祝福，剪成 3 分钟连着放；给老人的蛋糕选小尺寸，或换成长寿面
备用  寿星提前到家 → 改成一起布置；视频放不了 → 手机轮流递着看

【B 朋友聚会】给伴侣、朋友或自己 · 8–15 人 · 包间或租用场地 · 约 3 小时
流程  19:00 入场拍照 → 19:30 吃饭 → 20:30 小游戏两轮，每轮 15 分钟 → 21:00 蛋糕、每人一句祝福 → 22:00 散场
分工  一人对接场地，一人控场，一人负责把寿星带到
亮点  主题取寿星的一个梗或爱好，来的人照着穿一件单品；提前收集每人一句话，做成一叠卡片
备用  寿星迟到 → 先开饭，蛋糕等人到齐；场地临时出问题 → 启用前 3 天问好的第二选择

【C 办公室惊喜】给同事 · 10–20 人 · 会议室 · 20–30 分钟
前一天  和他的直属上级打招呼，确认次日下午没有要紧的会；谁出钱说清楚，AA 自愿、金额公开
15:00   蛋糕藏进会议室，蜡烛插一个问号，不公开年龄；贺卡传一圈签名
15:20   一人以「对一下方案」为由把寿星带进会议室；关灯、蛋糕进场、唱歌、许愿
15:30   送贺卡和礼物，一起吃蛋糕
15:45   收拾干净，各回工位
雷区    不抹奶油、不整蛊、不喝酒；有人不吃甜食或有忌口，另备水果
备用    寿星请假或临时被叫走 → 蛋糕冷藏，改到第二天上午
```

只有两个人（给伴侣）或一个人（给自己）过：把方案 B 改成半天到一天的路线，四站就够——一个有共同回忆的地方、一件对方（或你自己）念叨过想做的事、一顿饭、一个收尾的小仪式（一封信、一本照片书）；每站写好时间、预算和下雨时的替代。

## 最常见的错误

- 没确认寿星当天在不在，惊喜办了个空场。
- 邀请发得太晚：周末的局至少提前一周发，还要顺带问忌口和过敏。
- 环节塞太满，每个人都在等下一项；小朋友一个游戏一般撑不过十来分钟。
- 预算只算大头：蜡烛、餐具、垃圾袋、打车钱都是钱，又没留备用金。
- 当天才去采购；当天只该买生鲜、取蛋糕。
- 把自己想要的当成寿星想要的：内向的人被全场围着唱歌，可能是折磨。
- 办给朋友圈看：拍照比陪寿星还忙。指定一个人拍，其他人专心陪。
- 给父母过生日，最后还是父母下厨、收拾。

## 输出契约

1. 先问六件事：对象（年龄或关系）、总预算、人数、日期与时段、场地条件、是否惊喜；缺哪项问哪项，一次不超过三个问题，其余先给默认值并标出来。
2. 交付一份完整方案，依次包括：基本信息表；预算拆分表（金额、谁付）；前 2 周、前 3 天、当天的勾选清单；采购清单（物品、数量、预估价、谁买）；当天环节表（时间、环节、负责人、道具）；至少三条「如果……就……」的备用方案；一段邀请文案。
3. 金额只按用户给的预算拆；单价留空或给区间，由用户按当地实际填写。
4. 格式用 Markdown 表格和勾选框，可以直接复制进备忘录或群公告。

## 边界与不做什么

- 不推荐具体商家、品牌、平台或门店，只给挑选标准：容纳人数、最低消费、能否自带、取消规则、卫生状况。
- 不代为预订、付款、发邀请或在群里通知；文案交给你，发不发、怎么发你决定。
- 过敏与忌口以本人或家长确认为准；现场有人过敏或身体不适，立即联系医护或拨打急救电话，不在这里判断病情。
- 人多、在公共场所、要放烟花或用明火表演的活动，先问场地方和当地规定，必要时请专业活动公司。
- 有未成年人的场合不提供酒精；办公室里不喝酒，遵守公司规定。
- 用公费给同事过生日，报销标准与流程按本单位制度，不在这里判断能不能报。
- 惊喜不以恶作剧、吓人、公开隐私（年龄、感情状况）为代价。
