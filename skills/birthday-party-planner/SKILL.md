# 生日策划

定位一句话：**生日办得好不好，不看花了多少钱，看寿星那天有没有被照顾到——在意的人在场，在意的细节被记住，流程没让他尴尬或操心。**

## 何时使用

给孩子办生日会，给伴侣或父母过生日，给同事准备办公室惊喜，或者想给自己好好过一次生日，需要一份从准备到当天的完整方案时。识别信号：提到「生日」，并且要「策划、办、过、准备惊喜、派对」。用户通常这样说：

- 「女儿下个月满 5 岁，想在家请几个小朋友办生日会，预算一千」
- 「男朋友生日不想只吃顿饭，预算两千，帮我出个方案」
- 「部门同事周五生日，想在办公室给他一个 20 分钟的惊喜」
- 「爸爸六十岁生日，全家怎么安排才不让他操心」
- 「今年想给自己好好过个生日，一个人也行」

不适用（遇到时直接简答或转交）：

- **只要一句生日祝福、贺卡或朋友圈文案**：直接给两三条，不走完整方案。
- **只挑礼物**：交给礼物清单类技能；本技能只在方案里留「礼物与回礼」预算。
- **婚礼、满月酒、几十桌的寿宴，或要放烟花、明火表演**：本技能只给流程框架，场地与执行建议找专业活动公司，并先问场地方和当地规定。

## 先定六件事：对象、预算、人数、场地、时间、惊喜与否

| 对象 | 重点 | 建议时长 | 最容易踩的坑 |
|---|---|---|---|
| 小孩 | 孩子玩得尽兴，家长放心 | 1.5–2.5 小时 | 环节太长、没问过敏、没安排大人看护 |
| 伴侣 | 专属感：只有你知道的细节 | 半天到一天 | 照搬网上模板；当众惊喜让不爱被关注的人下不来台 |
| 父母 | 团圆、省心，不让他们张罗 | 一顿饭加一小时 | 子女办得热闹，老人跟着忙前忙后 |
| 同事 | 轻松不尴尬，不耽误工作 | 15–30 分钟 | 公开年龄、搞恶作剧、强行 AA |
| 自己 | 按自己舒服的方式来 | 随意 | 等别人来安排，最后没人安排 |

- 预算：总额还是人均，谁出钱（自己、AA、公费）。人均 = 总预算 ÷ 确定人数；人均连一份餐都不够，先减人数或换场地。
- 人数：分「确定来」和「可能来」，吃的按确定人数多备一成。
- 场地：家里、户外、餐厅包间、租用场地或办公室；户外必须同时定好室内备选。
- 时间：先确认寿星当天有没有别的安排；小孩避开午睡，老人别安排太晚，同事选下午茶时段。
- 惊喜与否：先问一个知情人「他喜欢被关注吗」；怕尴尬的人不做当众惊喜。
- 小孩生日会请几个小朋友：学龄前常见的经验是「年龄 + 1」个，先照这个起步。
- 父母整寿：按虚岁还是周岁、要不要「做九不做十」，各地习俗不同，先问家里长辈。

```
预算起步分配（按实际调整）
餐饮与蛋糕   45%   对人数最敏感，先算它
场地         15%   在家办就是 0，挪给餐饮或活动
布置         10%   气球、横幅、桌布、照片墙
活动与道具   10%   游戏奖品、手工材料、音乐
礼物与回礼   10%   回礼按到场人数多备 2 份
备用金       10%   临时加人、补买东西都从这里出，不要省
```

日期、星期和预算金额用脚本算，不心算（只用 Python 标准库，不联网）：

```bash
python3 {baseDir}/scripts/party_plan.py --date 2026-10-17 --people 11 --kids 6 --budget 1000 --who 小孩 --venue 家里 --age 5
```

脚本先校验输入（日期要写成 YYYY-MM-DD 且不能已过，人数、预算要大于 0），再输出：距生日还有几天和该走哪种节奏（充裕 / 赶工 / 最小版）、前 2 周与前 3 天与回复截止的具体日期和星期、按比例拆好且合计等于总预算的金额、人均、吃的备几份、蛋糕尺寸参考、回礼份数与看护人数。给了 `--meal-price`（你估的每人餐费）还会提醒预算够几个人吃。

## 时间线：前 2 周、前 3 天、当天

```
前 2 周
[ ] 定日期、时段、人数上限、总预算、主题（一句话说得清，如「恐龙探险」「老照片回顾」）
[ ] 定场地：包间问清容纳人数、最低消费、能否自带蛋糕饮品、取消规则；在家办先估客厅站得下几人
[ ] 发邀请：写明时间、地点、要不要带东西，顺带问忌口与过敏；小朋友的邀请发给家长
[ ] 订蛋糕：尺寸、口味、字样、取货时间；造型蛋糕要提前几天，问店家
[ ] 分工：采购、布置、拍照、控场、带寿星（惊喜时）各落到一个人
前 3 天
[ ] 二次确认人数，按最终人数改餐饮和回礼数量
[ ] 买齐不怕放的东西：布置、餐具、道具、蜡烛、电池
[ ] 看天气预报，户外活动定好下雨去哪
[ ] 把当天环节表发给帮忙的人，约好到场时间
[ ] 惊喜：和带寿星来的人对好借口与到达时间
当天
[ ] 开场前 1 小时布置完，留出补救时间；试一遍音箱、投影和灯
[ ] 取蛋糕、买生鲜；蛋糕冷藏，蜡烛和打火机交给切蛋糕的人
[ ] 控场的人按环节表盯时间
[ ] 散场后收垃圾、归还场地，当晚发合影和感谢
```

采购清单按布置、蛋糕、餐饮、活动、回礼、应急六类勾；蛋糕尺寸常见参考是 6 寸约 2–4 人、8 寸约 4–8 人、10 寸约 8–12 人，以店家说明为准；邀请文案前 2 周发，小朋友的发给家长。完整采购清单、邀请文案模板见 [references/checklists.md](references/checklists.md)。

## 当天环节怎么排

```
时间      环节          负责人   要点
T-15 分   迎客          ___     先到的人有事做：小朋友发贴纸或涂色卡，大人有饮料
T+0       开场          ___     一句欢迎加今天怎么玩，不超过 2 分钟
T+10      主活动        ___     小朋友每个游戏 10 分钟左右，大人可以长一些
T+40      吃东西        ___     玩过一轮就开饭，饿着的孩子容易闹
T+70      蛋糕          ___     关灯、点蜡烛、唱歌、许愿、吹蜡烛、切蛋糕；拍照的人提前站好位
T+85      祝福与礼物    ___     小朋友的礼物可以回家再拆，免得互相比较
T+100     合影、送客    ___     回礼在门口发
```

- 蛋糕环节是唯一需要所有人都在场的节点；时间紧就删别的环节，别删它。
- 蜡烛远离气球和纸质装饰；气球破了，碎片马上捡走，别让小孩含着玩。
- 学龄前孩子多的场合，每 4–5 个孩子至少安排一个大人专门看着；整颗葡萄要切小，坚果、硬糖、小杯果冻不给小小孩。

## 三份可直接套用的方案（摘要）

- **A 家庭小型**：给父母或小孩，6–10 人，在家，约 2 小时；亮点是亲友各录 20 秒祝福连着放，给老人的蛋糕选小尺寸或换长寿面。
- **B 朋友聚会**：给伴侣、朋友或自己，8–15 人，包间或租用场地，约 3 小时；主题取寿星的一个梗，提前收集每人一句话做成卡片。
- **C 办公室惊喜**：给同事，10–20 人，会议室，20–30 分钟；前一天和直属上级打招呼，不公开年龄、不整蛊、不喝酒。
- **两个人或一个人过**：把 B 改成半天到一天的四站路线——共同回忆的地方、念叨过想做的事、一顿饭、一个收尾小仪式。

每份方案的流程、分工、亮点与备用见 [references/plan-templates.md](references/plan-templates.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| E1 缺关键信息：对象、预算、人数、日期、场地、是否惊喜没说全 | 一次最多问三个，按「日期 → 人数 → 预算」的顺序问（决定时间线和规模的先问）；其余给默认值：场地在家、不做惊喜、时段按对象定（小孩下午避开午睡、父母晚饭、同事下午茶），默认值标 [待确认] | 「先确认三件事：哪天办（带年份）、大概几个人、总预算多少？场地我先按在家、不做惊喜来排，标了 [待确认]。」 |
| E2 输入格式不对或自相矛盾：日期写成「10.17」「下下周六」、日期已经过了、预算为 0 或负数、人均连一份餐都不够、说要惊喜却让寿星一起筹备 | 日期换成「YYYY-MM-DD（周几）」复述确认；已过的日期问是不是补过；预算、人数不合理请重给；人均过低给两个选项；矛盾处指出来让用户选 | 「10.17 是 2026 年 10 月 17 日（周六）吗？另外 8 个人 300 元，人均不到 40 元：减到 5 个人，还是把正餐改成下午茶？」 |
| E3 超出范围：推荐具体餐厅、蛋糕店、平台；代订、代付、代发邀请；几十桌的宴席、烟花明火；公费能不能报 | 说明不做，给挑选标准和要问商家的问题；大型活动建议找专业活动公司；公费按单位制度 | 「具体哪家店我不推荐，给你四条挑选标准：容纳人数、最低消费、能否自带蛋糕、取消规则。」 |
| E4 时间紧（离生日不到 3 天）或只要最小可用版 | 出最小版：当天环节表、只含蛋糕和吃的的采购单、一条备用方案、一条邀请短信；预算只分「蛋糕与吃的 / 其他 / 备用金」三项；标题行写「状态：最小版」 | 「只剩两天，给你最小版：一张当天流程、一张采购单、一条备用方案，今晚就能开始准备。」 |
| E5 用户坚持越界：惊喜要整蛊、抹奶油、公开年龄；有未成年人的局要上酒；办公室强制 AA | 守住：不写恶作剧和公开隐私；有未成年人不提供酒；AA 自愿、金额公开；给一个同样有记忆点的替代 | 「整蛊我不写进方案——寿星当众下不来台，惊喜就变味了；换成每人一句话的卡片，一样让他记得住。」 |
| 过敏、忌口或现场有人不适 | 过敏与忌口以本人或家长确认为准；现场有人过敏或身体不适，立即联系医护或拨打急救电话，不在这里判断病情 | 「有没有过敏，请家长确认后告诉我，我按确认的结果改吃的。」 |

脚本出错时：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 正常输出日期与预算核算 | 把结果填进方案的时间线和预算表 |
| 1「参数错误」 | 日期不是 YYYY-MM-DD 或不存在（如 2 月 30 日）、人数小于 1、预算不大于 0、对象或场地不在可选范围 | 按提示改：日期带年份写全；没定预算就不写 `--budget` |
| 2「写不了输出文件」 | `--out` 指向的目录不存在或没权限 | 换一个可写目录，或去掉 `--out` 直接看屏幕输出 |
| 3「日期已经过去了」 | 生日日期早于今天 | 补过生日就给新的日期再算 |
| 130「已中断」 | 按了 Ctrl+C | 直接重跑，不会留下半截文件 |

## 输出契约

交付一份完整方案，按固定顺序输出 Markdown 表格和勾选框（能直接复制进备忘录或群公告），某部分没有内容写「无」：

```
0 标题行：[寿星]的生日方案｜日期（周几）｜状态：完整版 / 最小版｜[待确认] N 项
1 基本信息表：对象、日期时段、场地、确定与可能人数、主题、是否惊喜、谁出钱
2 预算拆分表：类别、比例、金额、谁付；合计等于总预算
3 时间线勾选清单：前 2 周 / 前 3 天 / 当天，每段写上具体日期
4 采购清单：类别、物品、数量、预估价、谁买
5 当天环节表：时间、环节、负责人、道具与要点
6 备用方案：至少三条「如果……就……」
7 邀请文案
```

- 先问六件事：对象（年龄或关系）、总预算、人数、日期与时段、场地条件、是否惊喜；缺哪项问哪项，一次不超过三个问题，其余先给默认值并标出来。
- 金额只按用户给的预算拆；单价留空或给区间，由用户按当地实际填写。

占位符：[待补]——价格、地址、电话、负责人等由用户填的空；[待确认]——没问到、先按默认值写的项，数量写进标题行。

交付前自检（每条答「是」才交）：

- [ ] 日期写成「YYYY-MM-DD（周几）」，并和用户确认过？
- [ ] 预算拆分的合计等于总预算，人均够一份餐或已提醒？
- [ ] 邀请里问了过敏与忌口，小朋友的发给家长？
- [ ] 蛋糕环节在环节表里，且负责人、道具都有着落？
- [ ] 至少三条「如果……就……」的备用方案？
- [ ] 方案里没有任何商家、平台名；有未成年人的场合没有酒？

## 示例

> 示例：人物与场景为虚构，只演示格式。

用户：「部门同事 11 月 13 号周五生日，想在办公室给他一个 20 分钟的惊喜。」

助手先问：「按 2026 年 11 月 13 日（周五）排，对吗？大概几个人参加、预算多少、谁出钱？他喜欢被关注吗，有没有忌口？」用户答：「对。12 个人左右，每人自愿 25 元。他挺开朗的，不爱吃太甜的。」

交付：

```
[同事名]生日办公室惊喜｜2026-11-13（周五）15:00–15:45 [待确认]｜状态：完整版｜[待确认] 2 项
1 基本信息：会议室 [待补]｜约 12 人｜当众惊喜（性格开朗）｜每人自愿 25 元，共约 300 元，金额公开
2 预算（300 元）：蛋糕与水果 180（不爱太甜，一半换水果）｜布置与贺卡 30｜活动 30｜礼物 30｜备用金 30
3 时间线
  [ ] 11-10（周二，前 3 天）：确认人数；订 8–10 寸蛋糕，口味偏淡 [待确认]；买问号蜡烛、贺卡
  [ ] 11-12（周四，前一天）：和他的直属上级打招呼，确认周五下午没有要紧的会；订会议室
  [ ] 11-13（周五）当天：按下面的环节走
4 采购：蛋糕 1 个、问号蜡烛、打火机、纸盘叉子、水果、贺卡 1 张、礼物 1 份｜预估价 [待补]｜谁买 [待补]
5 环节（负责人 [待补]：藏蛋糕的人、带寿星的人、拍照的人）
  15:00 蛋糕藏进会议室，蜡烛插问号，不公开年龄；贺卡传一圈签名
  15:20 一人以「对一下方案」为由把寿星带进会议室；关灯、蛋糕进场、唱歌、许愿
  15:30 送贺卡和礼物，一起吃蛋糕和水果
  15:45 收拾干净，各回工位
6 备用
  如果他当天请假或被临时叫走，就把蛋糕冷藏，改到下周一上午
  如果会议室被占，就改在茶水间，时间缩到 15 分钟
  如果有人不吃甜食，就吃水果（已含在预算里）
7 通知（只发参与的同事，不发寿星）
  「周五 15:15 前到[会议室]，给[同事名]过生日；每人自愿 25 元，金额公开；有忌口或过敏请私信我。别在群里说漏嘴。」
```

「[待确认] 2 项」是：时段 15:00–15:45（按同事下午茶时段的默认值）、蛋糕口味。

## 常见问题（FAQ）

**问：预算不够怎么办？**
答：先减人数或换场地（在家办场地费为 0，挪给餐饮），再压布置；蛋糕和备用金别砍。人均连一份餐都不够时，把正餐改成下午茶。

**问：寿星当天有别的安排，时间冲突怎么协调？**
答：先向知情人确认寿星当天的安排，冲突就挪到最近的周末或提前一天；惊喜要有一个知情人帮忙拖住或带人，方案里写好「寿星迟到或请假」的备用。

**问：能帮我订餐厅、订蛋糕、在群里发邀请吗？**
答：不代订、不代付、不代发。我给挑选标准、要问商家的问题和写好的邀请文案，发不发、怎么发你决定。

**问：不想太隆重，只想两个人过呢？**
答：用四站路线：共同回忆的地方、对方念叨过想做的事、一顿饭、一个收尾小仪式；每站写好时间、预算和下雨时的替代。

**问：小朋友的生日会请多少人合适？**
答：学龄前常见经验是「年龄 + 1」个；每 4–5 个孩子至少一个大人专门看着。

**问：给父母过整寿要注意什么？**
答：按虚岁还是周岁、要不要「做九不做十」先问长辈；别让父母下厨和收拾，蛋糕可以换成长寿面。

**问：户外办赶上下雨怎么办？**
答：户外必须同时定好室内备选；前 3 天看天气预报，当天按备选地点通知大家。

## 常见错误（反模式）

最佳实践先记三条：先确认寿星当天在不在、喜不喜欢被关注；蛋糕环节必须保住；留一成备用金。

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 没确认寿星当天在不在 | 惊喜办了个空场 | 先问知情人，把寿星的时间锁住 |
| 邀请发得太晚 | 周末大家早有安排，人凑不齐 | 周末的局至少提前一周发，顺带问忌口和过敏 |
| 环节塞太满 | 每个人都在等下一项，小朋友一个游戏撑不过十来分钟 | 少排几项，每项留余量，时间紧就删别的、保蛋糕 |
| 预算只算大头 | 蜡烛、餐具、垃圾袋、打车钱都是钱，最后超支 | 按六类拆，留一成备用金 |
| 当天才去采购 | 缺货、赶不及，布置完不了 | 前 3 天买齐不怕放的，当天只买生鲜、取蛋糕 |
| 把自己想要的当成寿星想要的 | 内向的人被全场围着唱歌，可能是折磨 | 先问知情人「他喜欢被关注吗」 |
| 办给朋友圈看 | 拍照比陪寿星还忙 | 指定一个人拍，其他人专心陪 |
| 给父母过生日，最后还是父母下厨、收拾 | 违背了「让他们省心」的初衷 | 订餐或子女分工做，收拾也由子女包 |
| 惊喜靠整蛊、抹奶油、公开年龄 | 寿星当众难堪，关系受伤 | 用贺卡、视频祝福这类不伤人的记忆点 |

## 边界与不做什么

- 不推荐具体商家、品牌、平台或门店，只给挑选标准：容纳人数、最低消费、能否自带、取消规则、卫生状况。
- 不代为预订、付款、发邀请或在群里通知；文案交给你，发不发、怎么发你决定。
- 过敏与忌口以本人或家长确认为准；现场有人过敏或身体不适，立即联系医护或拨打急救电话，不在这里判断病情。
- 人多、在公共场所、要放烟花或用明火表演的活动，先问场地方和当地规定，必要时请专业活动公司。
- 有未成年人的场合不提供酒精；办公室里不喝酒，遵守公司规定。
- 用公费给同事过生日，报销标准与流程按本单位制度，不在这里判断能不能报。
- 惊喜不以恶作剧、吓人、公开隐私（年龄、感情状况）为代价。
