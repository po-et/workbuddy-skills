# 三份可直接套用的方案

按寿星和规模挑一份，改日期、人数、分工即可。时间、人数都是起步值，按实际调整。

```
【A 家庭小型】给父母或小孩 · 6–10 人 · 在家 · 约 2 小时（不含布置）
流程  17:00 布置 → 18:00 开饭 → 19:00 照片回顾或亲友视频祝福 → 19:20 蛋糕 → 19:40 合影
分工  一人做饭或订餐，一人布置兼拍照，一人陪寿星（惊喜时负责拖到 17:50 再回家）
亮点  提前一周请亲友各录 20 秒祝福，剪成 3 分钟连着放；给老人的蛋糕选小尺寸，或换成长寿面
备用  寿星提前到家 → 改成一起布置；视频放不了 → 手机轮流递着看

【B 朋友聚会】给伴侣、朋友或自己 · 8–15 人 · 包间或租用场地 · 约 3 小时
流程  19:00 入场拍照 → 19:30 吃饭 → 20:30 小游戏两轮，每轮 15 分钟 → 21:00 蛋糕、每人一句祝福 → 22:00 散场
分工  一人对接场地，一人控场，一人负责把寿星带到
亮点  主题取寿星的一个梗或爱好，来的人照着穿一件单品；提前收集每人一句话，做成一叠卡片
备用  寿星迟到 → 先开饭，蛋糕等人到齐；场地临时出问题 → 启用前 3 天问好的第二选择

【C 办公室惊喜】给同事 · 10–20 人 · 会议室 · 20–30 分钟
前一天  和他的直属上级打招呼，确认次日下午没有要紧的会；谁出钱说清楚，AA 自愿、金额公开
15:00   蛋糕藏进会议室，蜡烛插一个问号，不公开年龄；贺卡传一圈签名
15:20   一人以「对一下方案」为由把寿星带进会议室；关灯、蛋糕进场、唱歌、许愿
15:30   送贺卡和礼物，一起吃蛋糕
15:45   收拾干净，各回工位
雷区    不抹奶油、不整蛊、不喝酒；有人不吃甜食或有忌口，另备水果
备用    寿星请假或临时被叫走 → 蛋糕冷藏，改到第二天上午
```

## 只有两个人或一个人过

只有两个人（给伴侣）或一个人（给自己）过：把方案 B 改成半天到一天的路线，四站就够——一个有共同回忆的地方、一件对方（或你自己）念叨过想做的事、一顿饭、一个收尾的小仪式（一封信、一本照片书）；每站写好时间、预算和下雨时的替代。
