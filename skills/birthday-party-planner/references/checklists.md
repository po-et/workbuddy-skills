# 采购清单、蛋糕尺寸与邀请文案

## 采购清单

按类别勾，数量写在后面；交付时每项再补「预估价 [待补]」和「谁买」两栏。

```
布置  气球、打气筒、横幅或字母气球、桌布、胶带、照片墙夹子
蛋糕  蜡烛（数字或普通）、打火机、蛋糕刀、纸盘、叉子
餐饮  主食、水果、饮料、冰块、杯子、纸巾、湿巾
活动  游戏奖品、手工材料、音箱或手机外放、充电宝
回礼  回礼袋（到场人数 + 2）、感谢卡
应急  垃圾袋、创可贴、剪刀、备用电池、一套备用餐具
```

交付用的表头：

```
类别 ｜ 物品 ｜ 数量 ｜ 预估价 ｜ 谁买 ｜ 已买
```

## 蛋糕尺寸常见参考

6 寸约 2–4 人，8 寸约 4–8 人，10 寸约 8–12 人，以店家说明为准。造型蛋糕要提前几天订，具体问店家。

## 邀请文案（前 2 周发；小朋友的发给家长）

```
[小宇]的 5 岁生日会，想请[孩子名]来一起玩！
时间：10 月 17 日（周六）15:00–17:00
地点：[地址]，到了打这个电话：[ ]
主题：恐龙探险，穿绿色衣服更应景，没有也没关系
礼物：[人来就好 / 其他说明]
孩子有过敏或忌口，请提前告诉我；10 月 10 日前回复能不能来，方便准备吃的和回礼
```

给大人的邀请把「孩子有过敏或忌口」改成「有忌口或过敏请提前说」，其余照用。回复截止日一般定在生日前一周，用 `scripts/party_plan.py` 可以直接算出具体日期和星期。
