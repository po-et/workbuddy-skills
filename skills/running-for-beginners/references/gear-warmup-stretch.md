# 装备、热身、拉伸与力量

SKILL.md 里只留了一句话摘要，完整做法在这里。都是入门够用的最低要求，不推荐具体品牌和产品。

## 装备

```
必须：一双合脚的跑鞋——下午试穿、穿跑步袜，脚趾前留约一指宽，脚跟不滑不磨；
      以自己穿着舒服为准，不必追高价或某种功能
必须：透气速干的衣裤；女性穿有支撑的运动内衣；30 分钟以内一般不用随身带水
冬天：分层穿，起跑时略觉得冷正合适，跑热了再脱
夜跑：反光或亮色衣物、头灯或臂灯；带手机或写有紧急联系人的卡片
不急：心率带、压缩装备、能量胶——建立稳定习惯后再考虑
```

新鞋先穿着走路、短跑几次，再正式用来跑整堂课。

## 热身、放松与力量

```
热身（跑前 8–10 分钟）
  快走 5 分钟 → 原地高抬腿 20 次 → 后踢腿 20 次 → 弓步走 10 步 → 侧向滑步左右各 10 步 → 踝关节绕环各 10 圈
  以动态动作为主，由慢到快；跑前不做长时间的静态拉伸
放松（跑后）
  慢走 5 分钟到呼吸平稳；静态拉伸每个动作 20–30 秒，不弹震，有牵拉感即止：
  小腿（扶墙弓步、后腿伸直）、大腿前侧（单腿站、手拉脚背）、大腿后侧（直腿前屈、背不弓）、
  臀部（仰卧「4」字）、髋前侧（跪姿弓步向前推髋）
力量（身体已恢复、动作无疼痛时才考虑；非跑步日的自拟示例）
  深蹲 2×10、臀桥 2×12、提踵 2×15、平板支撑 2×20 秒
```

肌肉酸胀与局部膝/关节痛不能混为一谈；本技能不判断原因，也不保证“活动开”就能继续。拉伸或力量动作出现疼痛时停止动作，不直接用快走或骑车替代；局部疼痛反复或持续时寻求专业评估，按 SKILL.md 的停跑规则处理。
