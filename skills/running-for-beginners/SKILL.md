# 跑步入门

定位一句话：**先建立可持续的走跑习惯，再按恢复情况调整；阶段可以重复或延长，疼痛时先暂停，不能用低分或固定日期保证继续跑。**

**文件导航**：本页是主流程。按日期排好的 8 阶段演示交付见 [examples/8-week-plan-dated.md](examples/8-week-plan-dated.md)；装备、热身、拉伸与力量的完整做法见 [references/gear-warmup-stretch.md](references/gear-warmup-stretch.md)；每周复盘脚本是 `scripts/run_review.py`。

## 何时使用

从没系统跑过，或停跑很久想重新开始时，用下面的自拟阶段表讨论安排；连续慢跑 30 分钟只是示例目标，不能保证在 8 周内完成，不设配速、距离和减重目标。用户常这样说：

- 「零基础想跑步，现在跑两分钟就喘，从哪开始」
- 「跑完膝盖疼要不要停，还是歇两天接着练」
- 「心率一跑就到 170，是不是跑太快了」
- 「停了一个月没跑，该从第几周接着来」
- 「这是我这周的跑步记录，下周该怎么练」

不适用：

- 疼痛是什么伤、怎么康复、要不要吃药戴护具：不做医疗判断，有疼痛先停跑；红灯信号及时处理，由医生判断。
- 提速、备赛 10 公里或马拉松：找有资质的教练；儿童青少年的训练量听体育老师或教练的。
- 减重和饮食方案：不在本技能范围；只问「跑步能不能减肥」这类小问题，直接简答并说明本计划不设减重目标。

## 先判断什么：能不能开始、从哪周开始

```
先问身体（任一项「是」→ 先咨询医生，按医生给的限制再开始）
  □ 有心脏病、高血压、糖尿病、哮喘等慢性病，或正在长期服药
  □ 活动时出现过胸闷胸痛、心慌、头晕、晕倒
  □ 医生说过要限制运动；孕期或产后恢复期
  □ 当前关节、腰背有疼痛，或旧伤、术后仍未恢复
  □ 多年不运动且体重明显超重，或年纪较大又很久没运动
再问起点
  能连续快走 30 分钟不费力 → 从第 1 阶段开始
  快走 20 分钟就累 → 从能舒适完成的较短步行开始，按恢复延长，不硬凑 30 分钟或固定两周
  已有慢跑基础 → 先核对近期训练与恢复，再讨论适合的阶段，不只凭 10 分钟自动跳级
再定三件事
  时间  每周 3 次、隔天跑（如周一三六），两次跑之间至少隔一天，休息日可以散步
  地点  平整路面、操场、公园步道；夜跑选有照明、人多的路线
  目标  按恢复逐步建立习惯；示例末阶段的 30 分钟不是固定期限或达标承诺
```

用户的回答逐项核对，不合常理的不硬排：

| 要问的 | 有效的回答 | 回答不清或不合常理时 |
|---|---|---|
| 年龄 | 具体年龄或年龄段 | 未成年：训练量听体育老师或教练的，本计划只作一般参考；年纪较大又多年没运动，按身体清单第 5 项先咨询医生 |
| 身体清单五项 | 每项「是 / 否」 | 答「有一点」「控制得还行」「不确定」都按「是」处理：先咨询医生，再按医生定的强度用本计划 |
| 现在能快走或慢跑多久 | 分钟数 | 只说「不太行」：请他先快走一次并计时；拿不到数就从「先快走两周」开始 |
| 每周哪三天 | 三天，互不相邻 | 给了相邻的日子（如一二三）：改成隔天（如一三五）并说明原因；只有两天：阶段安排按可用时间延长，不能用固定 12 周承诺完成；想每天跑：只排 3 天，其余散步或做力量 |
| 在哪跑、白天还是晚上 | 地点与时段 | 夜跑：加上照明、反光衣物、紧急联系人的提醒 |
| 目标 | 阶段可重复或延长，无固定完成周数 | 要配速、距离、减重或备赛：说明本技能不设这些目标，备赛找有资质的教练 |

## 8 阶段自拟示例：可重复或延长

这是作者自拟的 8 个阶段示例，每个阶段可以重复或延长，阶段号不等于日历周数，不保证末阶段或固定日期达到 30 分钟；不将此表称为 NHS 官方方案。NHS [Couch to 5K](https://www.nhs.uk/better-health/get-active/get-running-with-couch-to-5k/) 的官方项目为 9 周或更长，每周 3 次、期间安排休息。本页只借鉴渐进与休息原则，下面具体进度未由 NHS 验证。疼痛处理参考 [NHS 跑步伤痛](https://www.nhs.uk/live-well/exercise/knee-pain-and-other-running-injuries/)：有膝痛不继续跑。本技能不提供伤后康复方案。

每次都是三步：热身 8–10 分钟 → 主体 → 慢走 5 分钟加拉伸。下表只写主体，「跑」一律指能说整句话的慢跑。走跑结合让你在心肺还跟不上时也能攒下跑步时间，走的那两分钟是计划的一部分，不是偷懒。

```
阶段  主体示例（单位：分钟，每周最多 3 次、两次之间休息）
1   跑 1 + 走 2，重复 8 组
2   跑 2 + 走 2，重复 6 组
3   跑 3 + 走 2，重复 5 组
4   跑 5 + 走 2，重复 4 组
5   跑 8 + 走 2，重复 3 组
6   跑 12 + 走 2 + 跑 12
7   前两次：跑 15 + 走 2 + 跑 10；第三次：连续跑 20
8   第一次：连续跑 25；第二次：跑 15 + 走 1 + 跑 15；第三次：连续跑 30
进退规则
  无疼痛、已恢复日常活动、说话测试可通过 → 才讨论是否进入下一阶段；仍可重复或延长
  很吃力但无疼痛 → 重复当前阶段或减少训练；有疼痛 → 暂停，不自动进阶
  中断后先确认恢复；有疼痛或伤后不按停跑天数自动恢复，需按专业人员意见安排
```

跑两分钟就喘怎么办：喘多半是因为太快，不是体能太差。把速度降到能说整句话，步子迈小、步频稍快，用鼻子和嘴一起呼吸，不必刻意数步子配呼吸；仍然喘，就把第 1 阶段换成「跑 30 秒 + 走 2 分钟」，做满一周再回到表上。姿势不必刻意改：身体微微前倾、脚落在身体下方附近、手臂自然前后摆；与其纠结前掌还是脚跟着地，不如先把速度放慢。饭后 1–2 小时再跑，空腹晨跑容易头晕的先吃点东西，跑完喝水补回来。

怎么坚持下来：把三次跑步写进日历当成约会；约一个同伴一起跑；天气不好就改快走或在家做力量，不让计划断掉；每跑完一周在日志里打个勾，看得见的进度最能留住人。
完成示例阶段不等于必须达到 30 分钟。能否继续、重复或减少训练要看恢复，不按第几周自动加量；记录反复疼痛或持续不适时先寻求评估。

每次跑完记一行，存成 `run_log.csv`：

```
date,week,session,run_min,talk,effort,pain,next_morning,note
09-02,1,1,8,整句,4,0,0,无
```

字段依次为：日期、周次、本周第几次、实际跑步分钟、说话测试（整句/几个词）、吃力程度 0–10、跑中疼痛 0–10、次日早上疼痛 0–10、备注（疼在哪、睡得怎样、天气）。每周日复盘一次：

```bash
python3 scripts/run_review.py run_log.csv
```

它检查日志完整性与恢复信号，给每周一个结论（讨论下一阶段 / 重复本周 / 先记录完整 / 暂停核实恢复 / 按红灯处理）并写明依据；填错的行会指出第几行、错在哪、怎么改，其余行照常复盘；无停跑信号时才提示中断安排；有疼痛记录则不按中断天数自动继续。脚本只看数字和部分备注关键词，不能保证识别所有疼痛描述；有不适时不依赖脚本作为继续许可。胸闷、头晕这类红灯症状不等复盘，当场按下面的红绿灯处理。

## 配速、心率与装备：够用的常识

```
配速  说话测试：边跑边能说完整的句子、但唱不了歌，就是对的速度
      只能蹦几个词 → 太快，放慢到接近快走也没关系；新手慢跑和快走差不多快很正常
      吃力程度按 0–10 分自评，慢跑保持在 4–5 分：有点累，但能一直坚持
心率  最大心率常用「220 − 年龄」粗估，个体差异很大，只能作参考
      手腕光电心率在起跑头几分钟、天冷、表带松时常常不准，看趋势别看单个读数
      服用影响心率药物的人，心率数字不适用，强度听医生的
装备  必须：合脚的跑鞋、透气速干的衣裤（女性加有支撑的运动内衣）；夜跑加反光衣物和照明
      不急：心率带、压缩装备、能量胶——建立稳定习惯后再考虑
```

跑鞋怎么试、冬天怎么穿、热身和跑后拉伸的具体动作、恢复充分且动作无疼痛时才考虑的力量示例，见 [references/gear-warmup-stretch.md](references/gear-warmup-stretch.md)。

心率一跑就很高怎么判断：新手刚开始跑，同样的速度心率偏高很常见，坚持几周后同样速度下的心率通常会降下来。先做说话测试——能说整句话、身体没有不适，就按说话测试来，不必盯着数字硬压；说不出整句就放慢或改走；伴随胸闷、头晕、心慌，按红灯立即停下。

## 疼痛红绿灯

一般肌肉酸胀与局部膝/关节痛不能混为一谈；本技能不判断原因。疼痛分数只用于记录，不是继续跑步的许可，也不把“活动开后减轻”当作无伤证明：

```
绿灯 讨论下一阶段  当前无疼痛、日常活动已恢复、说话测试通过；仍可重复或延长，不是医学许可
黄灯 核实恢复      肌肉酸胀、疲劳等原因不明，先休息并确认恢复；不自动认定正常或直接进阶
疼痛 停跑          跑中疼痛、局部膝/关节痛，即使很轻也先停止；分数 1–3 不能作继续许可
                   疼痛反复或持续应寻求医生或物理治疗师评估；膝痛休息一周仍不消失时就诊
红灯 及时处理      胸闷胸痛、心慌、异常气喘、头晕眼黑、冷汗 → 立即停下，严重时拨打 120
                   严重疼痛、明显肿胀、不能正常承重等及时就医；伤后恢复时机听专业人员意见
天热       高温高湿改到早晚或室内并缩短时间；头晕、恶心 → 停下到阴凉处补水，不缓解就就医；
           意识发懵、说话含糊 → 立即拨打 120
```

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 身体清单没答，或只说「身体还行」 | 身体清单必须逐项答完才排计划；这是唯一不给默认值的地方 | 「排计划前先过一下这五项，任何一项是『是』都要先问医生——这一步不能跳。」 |
| 起点、时间、地点没说 | 起点按「从第 1 阶段开始」、三天按周一三六、地点按平整步道先排，标 [待确认] | 「我先按从第 1 阶段开始、每周一三六排了，标了 [待确认]；你告诉我现在能快走多久、哪三天有空，我再调。」 |
| 回答自相矛盾（如说零基础，又说能连续跑 20 分钟；给的三天是连着的） | 指出矛盾，给两种理解让用户选 | 「你说零基础，又说能连续跑 20 分钟——如果能连续跑 20 分钟，再核对恢复讨论起点；如果是走跑加起来 20 分钟，从更容易的阶段讨论。是哪种？」 |
| 日志填错（数字写成汉字、说话测试写「还行」、缺列） | 指出第几行哪一列、正确写法；全部修正前不生成继续跑步或进阶建议；空/重复表头或坏行也先纠正 | 「第 8 行的疼痛写成了『七』，改成 7；说话测试只写『整句』或『几个词』。先修正全部问题，再跑一次复盘。」 |
| 超出范围（诊断伤痛、康复方案、减重饮食、备赛提速） | 不诊断或给康复动作；有疼痛先暂停，复发或持续找医生或物理治疗师 | 「疼痛原因我判断不了；先暂停跑步，不用低分当继续许可。局部膝/关节痛不继续跑，反复或持续时寻求专业评估。」 |
| 时间紧，只想马上开始 | 最小版：今天就能做的第 1 阶段第 1 次（热身 10 分钟＋较短的舒适走跑示例；分流未通过或有疼痛时不安排跑步）、说话测试一句话、红灯症状三条 | 「先别看全表：先完成分流并确认当前无疼痛，再讨论较短的起步安排，速度以能说整句话为准；胸闷、头晕、剧痛就停。恢复无疼痛后再讨论后续阶段。」 |
| 用户坚持加量（想跳周、一周跑 5 次、带着疼跑、吃止痛药跑） | 守住规则：阶段可重复、隔天训练；带疼痛先暂停，不自动改安排快走或力量 | 「先核对恢复；有疼痛先停止，不自动补跑、快走或力量。无疼痛时也可以重复或延长当前阶段。」 |
| 回复太长被截断或中途断了 | 按输出契约的顺序分段交付；用户说「继续」就从下一段接着写 | 「上一条排到第 4 阶段。回复『继续』，我从第 5 阶段接着排。」 |

| 130 | 按了 Ctrl+C | 重新运行即可，脚本不改任何文件 |

## 输出契约

1. **先分流**：问年龄段、身体清单、当前疼痛、起点、时间和地点；有健康顾虑或尚未恢复的伤痛时先咨询医生，不直接交付跑步负荷。
2. **交付 8 阶段演示表**：按用户的三天排出具体日期，列为日期、第几周第几次、热身、主体、放松、备注（如「恢复待核，本次不安排跑步」），主体精确到分钟和组数。
3. **每周复盘**：先检查疼痛与完整性，输出实际日志结论和依据；停跑时不直接安排下一次训练，无停跑信号时也只讨论下一阶段、重复或延长，不保证日期和达标。
4. **只用时间和说话测试描述强度**，不给配速、距离和减重目标。

计划类回复按固定顺序：分流结论 → 8 阶段演示表（日期可顺延）→ 进退规则 → 每周复盘方法 → 疼痛红绿灯 → 自检。复盘类回复按固定顺序：每周结论 → 依据哪一条 → 需要核实的恢复情况或可讨论的安排；停跑时不交付跑步负荷。

占位符：`[待确认]` 是按默认值排的内容（起始阶段、三天、地点）；`[待补]` 是只有用户才有的信息（身体清单的回答、日志里缺的数）。身体清单不用默认值，没答完不排计划。

交付前自检（逐条判断是/否，有一条「否」就改完再交）：

1. 身体清单五项都问过；有「是」的，已写「请先咨询医生」并放在计划前面？
2. 起始阶段与用户现在的能力对得上（快走 30 分钟不费力才从第 1 阶段开始）？
3. 每次跑步之间至少隔一天，每周不超过 3 次？
4. 强度只用时间和说话测试描述，没有配速、距离、减重目标？
5. 附了进退规则和疼痛红绿灯，红灯写明「立即停下，严重时拨打 120」？
6. 复盘结论写明了依据哪一条规则？

## 常见问题（FAQ）

**Q：跑不动、跑两分钟就喘怎么办？**
A：多半是太快。降到能说整句话的速度，步子迈小；仍然喘，就把第 1 阶段换成「跑 30 秒 + 走 2 分钟」，做满一周再回到表上。

**Q：天太热还能跑吗？**
A：高温高湿改到早晚或室内并缩短时间；头晕、恶心就停下到阴凉处补水，不缓解就就医；意识发懵、说话含糊立即拨打 120。

**Q：中断了一段时间，怎么接？**
A：先问是否有疼痛、伤后是否已恢复；有伤痛不按停跑天数自动恢复。无疼痛时也可以重复或延长当前阶段，不在一天里补两次课。

**Q：跑完膝盖疼，要不要停？**
A：先停止跑步，不因只有 1–3 分就继续；膝痛原因本技能无法判断。严重疼痛或肿胀及时就医；停止后膝痛一周仍不消失，或反复出现，咨询医生或物理治疗师。恢复时机按评估意见决定，不自动安排“歇两天再跑”。

**Q：心率一跑就到 170，是不是太快了？**
A：先做说话测试：能说整句话、没有不适，就按说话测试来；说不出整句就放慢。「220 − 年龄」只是粗估，手腕心率起跑头几分钟常常不准。

**Q：感觉很轻松，能不能跳周？**
A：不建议。心肺跟上了不代表腿跟上了，按表走；有余力就在非跑步日加 15 分钟力量。

**Q：需要买专业跑鞋、运动手表吗？**
A：只需要一双合脚的跑鞋和透气的衣服，以自己穿着舒服为准；心率带、手表这些 建立稳定习惯后再考虑。本技能不推荐具体品牌。

**Q：跑步能减肥吗？**
A：本技能不设减重目标，也不做饮食方案；阶段表帮助讨论习惯与恢复，没有固定 8 周达标保证。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 跑得太快 | 喘不上气、跑不久，还容易伤 | 说话测试不过就是太快；慢到像快走也没关系 |
| 连着几天都跑 | 肌腱、关节来不及恢复 | 阶段表均安排两次跑步之间休息，必要时延长阶段 |
| 漏课后硬补 | 一天两次负荷翻倍 | 漏一次顺延到下一个隔天，不在一天里补两次 |
| 感觉轻松就跳周 | 心肺跟上了不代表腿跟上了 | 按表走，按进退规则进周 |
| 带着疼跑、吃止痛药跑 | 止痛药会盖住信号 | 有疼痛先暂停，不以低分或止痛后感觉作为继续许可 |
| 新鞋直接跑长时间 | 容易磨脚、不适应 | 先穿着走路、短跑几次再正式用 |
| 只跑不练力量 | 下肢和核心跟不上跑量 | 恢复充分且动作无疼痛时，才讨论非跑步日力量练习 |
| 和别人比配速 | 为了追速度跑太快 | 只和上周的自己比 |
| 盯着手表心率硬压速度 | 读数常不准，反而焦虑 | 以说话测试为准，看心率趋势不看单个读数 |
| 断了几周直接从断点接着跑 | 身体已经退回去了，容易受伤 | 先核对恢复与疼痛，必要时重复阶段；伤后听专业评估意见 |

## 边界与不做什么

- 不做医疗判断：不判断疼痛是什么伤、不给康复方案、不推荐药物和护具；有疼痛先停跑；红灯信号及时处理，由医生判断；伤后什么时候、从哪一周恢复跑步，也听医生或康复治疗师的。
- 有慢性病、孕产期、术后、正在服药，或年纪较大且久不运动的人：先咨询医生，按医生定的强度执行，本计划只作时间安排参考。
- 儿童青少年的训练量听体育老师或教练的；想提速、备赛 10 公里或马拉松，找有资质的教练，不在本技能范围。
- 不做减重和饮食方案，不推荐具体品牌和产品。
- 雾霾、雷雨、冰雪、极端高温天气：改室内或休息，不硬跑。
