# 跑步入门

定位一句话：**新手最常见的失败不是跑不动，而是加得太快——心肺几周就能跟上，肌腱、关节和骨头适应得慢，所以计划宁可慢一点，也要保证每周都能接着跑。**
何时用：从没系统跑过，或停跑很久想重新开始，目标是 8 周后能连续慢跑 30 分钟；不设配速、距离和减重目标。

## 先判断什么：能不能开始、从哪周开始

```
先问身体（任一项「是」→ 先咨询医生，按医生给的限制再开始）
  □ 有心脏病、高血压、糖尿病、哮喘等慢性病，或正在长期服药
  □ 活动时出现过胸闷胸痛、心慌、头晕、晕倒
  □ 医生说过要限制运动；孕期或产后恢复期
  □ 关节、腰背有旧伤仍在疼，或手术后没完全恢复
  □ 多年不运动且体重明显超重，或年纪较大又很久没运动
再问起点
  能连续快走 30 分钟不费力 → 从第 1 周开始
  快走 20 分钟就累 → 先快走两周（每周 3–4 次，每次 30 分钟），再进第 1 周
  已能连续慢跑 10 分钟以上 → 可从第 4 周开始，照样遵守疼痛规则
再定三件事
  时间  每周 3 次、隔天跑（如周一三六），两次跑之间至少隔一天，休息日可以散步
  地点  平整路面、操场、公园步道；夜跑选有照明、人多的路线
  目标  第 8 周连续跑 30 分钟，只和自己比
```

## 8 周计划：步骤与进退规则

每次都是三步：热身 8–10 分钟 → 主体 → 慢走 5 分钟加拉伸。下表只写主体，「跑」一律指能说整句话的慢跑。走跑结合让你在心肺还跟不上时也能攒下跑步时间，走的那两分钟是计划的一部分，不是偷懒。

```
周  主体（单位：分钟，每周 3 次）
1   跑 1 + 走 2，重复 8 组
2   跑 2 + 走 2，重复 6 组
3   跑 3 + 走 2，重复 5 组
4   跑 5 + 走 2，重复 4 组
5   跑 8 + 走 2，重复 3 组
6   跑 12 + 走 2 + 跑 12
7   前两次：跑 15 + 走 2 + 跑 10；第三次：连续跑 20
8   第一次：连续跑 25；第二次：跑 15 + 走 1 + 跑 15；第三次：连续跑 30
进退规则
  本周最后一次能说整句话、第二天没有明显疼痛 → 进入下一周
  本周最后一次很吃力，或疼痛到了黄灯 → 重复这一周；重复不是失败
  中断不到一周，从断点接着跑；中断一到两周，退回一周；两周以上，退回两周
```

跑两分钟就喘怎么办：喘多半是因为太快，不是体能太差。把速度降到能说整句话，步子迈小、步频稍快，用鼻子和嘴一起呼吸，不必刻意数步子配呼吸；仍然喘，就把第 1 周换成「跑 30 秒 + 走 2 分钟」，做满一周再回到表上。姿势不必刻意改：身体微微前倾、脚落在身体下方附近、手臂自然前后摆；与其纠结前掌还是脚跟着地，不如先把速度放慢。饭后 1–2 小时再跑，空腹晨跑容易头晕的先吃点东西，跑完喝水补回来。

怎么坚持下来：把三次跑步写进日历当成约会；约一个同伴一起跑；天气不好就改快走或在家做力量，不让计划断掉；每跑完一周在日志里打个勾，看得见的进度最能留住人。
第 8 周之后：保持每周 3 次、每次连续慢跑 30 分钟，至少稳定一个月再考虑加量；加量一次只动一样（次数、时长或速度），每次都加得少一点。

每次跑完记一行，存成 `run_log.csv`：

```
date,week,session,run_min,talk,effort,pain,next_morning,note
09-02,1,1,8,整句,4,0,0,无
```

字段依次为：日期、周次、本周第几次、实际跑步分钟、说话测试（整句/几个词）、吃力程度 0–10、跑中疼痛 0–10、次日早上疼痛 0–10、备注（疼在哪、睡得怎样、天气）。每周日复盘一次：

```bash
python3 - <<'EOF'
import csv, collections
wk = collections.defaultdict(list)
for r in csv.DictReader(open('run_log.csv', encoding='utf-8')):
    wk[int(r['week'])].append(r)
for w, rs in sorted(wk.items()):
    pain = max(max(int(r['pain']), int(r['next_morning'])) for r in rs)
    hard = rs[-1]['talk'] != '整句' or int(rs[-1]['effort']) >= 7
    act = '停跑，按红灯处理' if pain >= 6 else '重复本周' if pain >= 4 or hard else '进入下一周'
    print('第%d周 %d次 共跑%d分钟 最高疼痛%d → %s' % (w, len(rs), sum(int(r['run_min']) for r in rs), pain, act))
EOF
```

脚本只看数字；胸闷、头晕这类红灯症状不等复盘，当场按下面的红绿灯处理。

## 配速、心率与装备：够用的常识

```
配速  说话测试：边跑边能说完整的句子、但唱不了歌，就是对的速度
      只能蹦几个词 → 太快，放慢到接近快走也没关系；新手慢跑和快走差不多快很正常
      吃力程度按 0–10 分自评，慢跑保持在 4–5 分：有点累，但能一直坚持
心率  最大心率常用「220 − 年龄」粗估，个体差异很大，只能作参考
      手腕光电心率在起跑头几分钟、天冷、表带松时常常不准，看趋势别看单个读数
      服用影响心率药物的人，心率数字不适用，强度听医生的
装备  必须：一双合脚的跑鞋——下午试穿、穿跑步袜，脚趾前留约一指宽，脚跟不滑不磨；
            以自己穿着舒服为准，不必追高价或某种功能
      必须：透气速干的衣裤；女性穿有支撑的运动内衣；30 分钟以内一般不用随身带水
      冬天：分层穿，起跑时略觉得冷正合适，跑热了再脱
      夜跑：反光或亮色衣物、头灯或臂灯；带手机或写有紧急联系人的卡片
      不急：心率带、压缩装备、能量胶——8 周后还在跑再考虑
```

心率一跑就很高怎么判断：新手刚开始跑，同样的速度心率偏高很常见，坚持几周后同样速度下的心率通常会降下来。先做说话测试——能说整句话、身体没有不适，就按说话测试来，不必盯着数字硬压；说不出整句就放慢或改走；伴随胸闷、头晕、心慌，按红灯立即停下。

## 热身、拉伸与疼痛红绿灯

```
热身（跑前 8–10 分钟）
  快走 5 分钟 → 原地高抬腿 20 次 → 后踢腿 20 次 → 弓步走 10 步 → 侧向滑步左右各 10 步 → 踝关节绕环各 10 圈
  以动态动作为主，由慢到快；跑前不做长时间的静态拉伸
放松（跑后）
  慢走 5 分钟到呼吸平稳；静态拉伸每个动作 20–30 秒，不弹震，有牵拉感即止：
  小腿（扶墙弓步、后腿伸直）、大腿前侧（单腿站、手拉脚背）、大腿后侧（直腿前屈、背不弓）、
  臀部（仰卧「4」字）、髋前侧（跪姿弓步向前推髋）
力量（第 3 周起，非跑步日 15 分钟，推荐）
  深蹲 2×10、臀桥 2×12、提踵 2×15、平板支撑 2×20 秒
```

跑后一两天腿酸是正常反应：多走动、睡够，第二天快走或骑车活动开，通常比完全不动舒服。疼痛按 0–10 分自评，下面是训练调整规则，不是诊断：

```
绿灯 继续  跑后 1–2 天大腿小腿肌肉酸胀、活动开后减轻；跑中不适 ≤ 3 分，第二天早上不加重
黄灯 降量  不适 4–5 分；第二天早上比前一天更疼；同一个位置每次跑都疼（膝前、跟腱、脚底、小腿内侧）
           → 下次改快走或退回上一周；连续两次黄灯就暂停跑步，去医院看
红灯 停跑  胸闷胸痛、心慌、与强度不相称的气喘、头晕眼黑、冷汗 → 立即停下，严重时拨打 120
           疼痛 6 分以上；骨头上某一点疼、按压明显疼，或休息和夜里也疼
           关节肿胀、卡住、打软腿，或疼得改变了走路和跑步姿势
           受伤当下有明显响声、之后不能正常承重；任何疼痛超过一周不减轻 → 都停跑就医
天热       高温高湿改到早晚或室内并缩短时间；头晕、恶心 → 停下到阴凉处补水，不缓解就就医；
           意识发懵、说话含糊 → 立即拨打 120
```

## 最常见的错误

- 跑得太快 → 说话测试不过就是太快；慢到像快走也没关系。
- 连着几天都跑 → 前 8 周隔天跑，休息日的恢复本身就是训练。
- 漏课后硬补 → 漏一次顺延到下一个隔天，不在一天里补两次。
- 感觉轻松就跳周 → 心肺跟上了不代表腿跟上了，按表走。
- 带着疼跑、吃止痛药跑 → 止痛药会盖住信号，疼痛按红绿灯处理。
- 新鞋直接跑长时间 → 先穿着走路、短跑几次再正式用。
- 只跑不练力量 → 非跑步日加 15 分钟下肢和核心力量。
- 和别人比配速 → 只和上周的自己比。

## 输出契约

1. **先分流**：问年龄段、有没有身体清单里的情况、现在能快走或慢跑多久、每周哪三天有空、在哪跑；有「是」先写「请先咨询医生」，再给计划。
2. **交付 8 周表**：按用户的三天排出具体日期，列为日期、第几周第几次、热身、主体、放松、备注（如「上次黄灯，本次改快走」），主体精确到分钟和组数。
3. **每周复盘**：用户贴日志，按进退规则和红绿灯给出「进入下一周 / 重复本周 / 退回一周 / 停跑就医」之一，并写明依据哪一条。
4. **只用时间和说话测试描述强度**，不给配速、距离和减重目标。

## 边界与不做什么

- 不做医疗判断：不判断疼痛是什么伤、不给康复方案、不推荐药物和护具；出现红灯信号就停跑，由医生判断；伤后什么时候、从哪一周恢复跑步，也听医生或康复治疗师的。
- 有慢性病、孕产期、术后、正在服药，或年纪较大且久不运动的人：先咨询医生，按医生定的强度执行，本计划只作时间安排参考。
- 儿童青少年的训练量听体育老师或教练的；想提速、备赛 10 公里或马拉松，找有资质的教练，不在本技能范围。
- 不做减重和饮食方案，不推荐具体品牌和产品。
- 雾霾、雷雨、冰雪、极端高温天气：改室内或休息，不硬跑。
