# 三份模板与活动通知

用法：先按 SKILL.md「先判断」定一个主目的，再从下面挑时长对应的模板；主活动按目的从 SKILL.md 第 3 步的清单里选。负责人没定的写 [待补]，时间、地点没定的写 [待确认]。流程最终要排到每十五分钟，每个环节写上负责人。

## 半天（约三个半小时）

```
14:00  暖场：分组起组名，每组五到八人                   负责人[ ]
14:20  主活动：按目的选——协作任务／共创／成果回顾         负责人[ ]
15:50  茶歇
16:10  第二环节：分享、复盘或致谢                        负责人[ ]
17:10  收尾：每人一句话收获，合照
17:30  解散；聚餐自愿参加
```

## 一天

```
09:30  集合出发，点名；迟到的人直接到场地会合
10:30  主活动一：户外协作、参观或手作，强度分两档可选
12:00  午餐与午休
13:30  主活动二：共创、复盘或跨组任务
15:00  休息
15:20  成果展示、致谢、颁奖
16:30  收尾反馈；17:00 前解散返程
```

## 线上（九十分钟）

```
00–10  开场破冰：用一张照片介绍你窗外的景色，摄像头自愿
10–40  分组讨论室，每组四到六人，完成一个小任务，比如合写一页新人指南
40–70  回主会场，每组三分钟展示
70–85  点名致谢：每人感谢一位同事做过的一件具体的事
85–90  一题投票收反馈
```

## 活动通知（可以直接套）

```
[活动名称]通知
时间：[日期、时段]（工作时间内）  集合：[时间、地点]
内容：[一句话目的]，流程见附件；请穿舒适的衣服和鞋，需自带[ ]
有饮食禁忌、身体不便或无法参加的，请在[日期]前私信[负责人]，不必说明原因。
聚餐自愿参加，全程不劝酒。
```

## 匿名问卷（四题就够）

```
1 方便的时段（多选）：工作日上午 / 工作日下午 / 其他：____
2 不能参加的活动类型（多选）：体力类 / 饮酒 / 夜间 / 其他：____
3 饮食禁忌：____
4 最想从这次活动得到什么：____
```
