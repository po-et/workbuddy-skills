# 示例：项目上线庆功（不喝酒、不占周末）

**示例**（项目组情况为虚构；预算用 SKILL.md 里的 budget.py 算过）

## 对话

用户：「项目刚上线想搞个庆功团建，不想喝酒也不想占周末。」

助手：「好，目的就定庆功。再问三件事：项目组多少人，预算人均多少、含不含餐？想放在哪天、多长时间？这次最想点名感谢的人和事，你心里有名单吗？」

用户：「18 个人，人均 150，含一顿下午茶。下周四下午，半天。最想谢的是熬夜修线上问题的两位同事，还有一直顶着客户压力的产品经理。」

## 交付

**目的与成功标准**：庆功——结束时，每位功臣都被点名感谢过一件具体的事；每个人都在里程碑墙上写下一句话。

**基本信息**：18 人；下周四 14:00–17:30，工作时间内；场地类型：单位会议室或附近能包场的茶歇空间 [待确认]；预算人均 150 元，含下午茶。

**流程表**：

| 时间 | 环节 | 内容 | 负责人 |
|---|---|---|---|
| 14:00 | 暖场 | 分三组，每组 6 人，打散岗位；每组用一句话说出「上线那天我在干什么」 | 主持 [待补] |
| 14:20 | 成果时间线 | 墙上贴出项目里程碑，每人在上面写一句当时最难忘的事 | 主持 |
| 15:00 | 回看 | 主持沿时间线走一遍，每个里程碑请当事人说一分钟 | 主持 |
| 15:40 | 下午茶 | 无酒精饮品，自由交流 | 物料 [待补] |
| 16:10 | 致谢卡 | 每人给两位同事各写一张，写清对方哪件事帮了自己 | 主持 |
| 16:40 | 点名致谢 | 负责人逐一点名三位功臣，各说一件具体的事；其他人把致谢卡当面交给对方 | 总负责 [待补] |
| 17:10 | 收尾 | 每人一句话收获，合照 | 记录 [待补] |
| 17:30 | 解散 | 不另设聚餐 | |

**分工**：

| 角色 | 人数 | 职责 | 姓名 |
|---|---|---|---|
| 总负责 | 1 | 定稿、预算、点名致谢 | [待补] |
| 场地与物料 | 1–2 | 场地、里程碑墙、便签和卡片、下午茶 | [待补] |
| 主持计时 | 1 | 串场、控时间 | [待补] |
| 安全后勤 | 1 | 饮食禁忌、有特殊需要的同事 | [待补] |
| 记录 | 1 | 拍照、收反馈 | [待补] |

三位功臣不排进场地、物料这类张罗的活。

**预算表**：

| 项目 | 计算 | 金额 |
|---|---|---|
| 基础 | 18 人 × 150 元（`python3 budget.py 18 150 0.1`） | 2700 |
| 备用金 | 一成 | 270 |
| 合计 | | 2970 |

下午茶、卡片与便签、场地（如需付费）的单价按实际填 [待补]，合计不超过 2700；人均 150 如果是上限，备用金从里面预留 [待确认]。

**备选方案**：

- 天气：全程室内，不受影响。
- 人数：少三成以上就合并成两组，物料多备一成。
- 场地：临时不能用，就在三十分钟车程内换一个替代点，或改成线上九十分钟版（点名致谢环节保留）。
- 有人不适：每个环节都允许旁观，不扣分、不点名。

**避雷确认**：

- [x] 全程无酒精，不设劝酒环节
- [x] 工作日下午，不占周末
- [x] 没有身体对抗和竞技项目
- [x] 不让功臣张罗、搬东西
- [x] 不强制表演、不公开排名

**活动通知**：

```
项目上线庆功会通知
时间：下周四 14:00–17:30（工作时间内）  集合：14:00，[地点待补]
内容：一起回看项目里程碑，感谢为上线出力的每一位，流程见附件；请穿舒适的衣服和鞋，无需自带物品
有饮食禁忌、身体不便或无法参加的，请在[日期]前私信[负责人]，不必说明原因。
全程无酒精，不劝酒。
```

**结束后一周内**：发三个问题——最有收获的环节、最想删掉的环节、下次想试什么。
