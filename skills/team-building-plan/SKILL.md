# 团建方案

定位一句话：**团建先定目的再选形式——同样是半天，破冰要让人开口，庆功要让人被看见，复盘要让人说真话。**
何时用：要给部门、项目组或跨部门小组策划团建；手上有预算、人数、时长，要出一页方案；上次团建效果差，想换个做法。费用标准、报销、能否占用工作时间以本单位制度为准；本技能不推荐具体商家、场地或品牌。

## 先判断：目的、约束、人

```
目的    要的结果            适合的形式                                  不适合
破冰    互相认识、敢开口    混编小组协作任务、自我介绍接力、合作完成一件作品    高强度竞技、酒局
庆功    被看见、被感谢      成果回顾＋点名致谢＋轻松活动或聚餐                让功臣去张罗、搬东西
复盘    说真话、定改进项    引导式复盘会＋轻松收尾                          把复盘搬上饭桌
跨部门  了解对方的活和难处  混编分组、互讲「我们的一天」、共创一个小方案        按部门分队对抗
```

一场只定一个主目的。再问清五件事：预算（人均还是总额，含不含交通和餐费）；人数（十人以内可以全体一起，几十人就要分组、要主持）；时长（两小时、半天、一天、线上）；时间（默认工作日，周末必须先征求意见）；人（孕期、行动不便、饮食禁忌、宗教习惯、要接孩子的同事——用匿名问卷提前收集）。

## 方法：五步出方案

1. **写一句话成功标准**：比如「结束时每人至少认识三个别组的人」「每位功臣都被点名感谢过一件具体的事」。
2. **收约束**：预算、人数、日期、场地条件（室内、户外、线上）。匿名问卷四题就够：方便的时段（多选）；不能参加的活动类型（体力、饮酒、夜间等）；饮食禁忌；最想从这次活动得到什么。
3. **选形式**：一个暖场＋一个主活动＋一个收尾；人多就分组，每组五到八人，打散部门和资历。预算紧时，钱只花在吃饭和交通上，场地用单位会议室或能免费使用的公共场地，主活动从下面挑不花钱的：

```
破冰    两真一假：每人说三件关于自己的事，两真一假，组员来猜
        共同点接力：小组十分钟内找出全组都有的五个共同点，越冷门越好
庆功    成果时间线：墙上贴出项目里程碑，每人在上面写一句当时最难忘的事
        致谢卡：每人给两位同事各写一张，写清对方哪件事帮了自己
复盘    帆船图：风（推动我们的）、锚（拖住我们的）、礁石（前面的风险）、岛（目标），先贴便签再归类
        开始／停止／继续：每人各写一条，投票选出三条改进项，当场定负责人
跨部门  我们的一天：每个部门五分钟，讲清一天在忙什么、最怕对方怎么做、最希望对方怎么做
        混编共创：混编小组用四十五分钟解决一个真实的跨部门小问题，最后各组展示
```

4. **排流程与分工**：流程排到每十五分钟，每个环节写上负责人。分工：总负责一人（定稿、预算、对接领导）；场地与物料一到两人（含天气备选）；主持计时一到两人；安全后勤一人（交通、药箱、有特殊需要的同事，外出保险按单位要求）；记录一人（照片、反馈）。预算按「人数 × 人均 ＋ 备用金」算，备用金留一成左右：

```bash
python3 -c "import sys;n,p,r=int(sys.argv[1]),float(sys.argv[2]),float(sys.argv[3]);b=n*p;print('基础',round(b),'备用金',round(b*r),'合计',round(b*(1+r)))" 25 150 0.1
```

三个参数依次是人数、人均、备用金比例，示例数字换成你们自己的；交通、物料、场地如果单独计价，分别加上。

5. **定备选、收反馈**：备选见下文；结束后一周内发三个问题——最有收获的环节、最想删掉的环节、下次想试什么。

## 三份模板：半天、一天、线上

```
半天（约三个半小时）
14:00  暖场：分组起组名，每组五到八人                   负责人[ ]
14:20  主活动：按目的选——协作任务／共创／成果回顾         负责人[ ]
15:50  茶歇
16:10  第二环节：分享、复盘或致谢                        负责人[ ]
17:10  收尾：每人一句话收获，合照
17:30  解散；聚餐自愿参加
```

```
一天
09:30  集合出发，点名；迟到的人直接到场地会合
10:30  主活动一：户外协作、参观或手作，强度分两档可选
12:00  午餐与午休
13:30  主活动二：共创、复盘或跨组任务
15:00  休息
15:20  成果展示、致谢、颁奖
16:30  收尾反馈；17:00 前解散返程
```

```
线上（九十分钟）
00–10  开场破冰：用一张照片介绍你窗外的景色，摄像头自愿
10–40  分组讨论室，每组四到六人，完成一个小任务，比如合写一页新人指南
40–70  回主会场，每组三分钟展示
70–85  点名致谢：每人感谢一位同事做过的一件具体的事
85–90  一题投票收反馈
```

活动通知可以直接套：

```
[活动名称]通知
时间：[日期、时段]（工作时间内）  集合：[时间、地点]
内容：[一句话目的]，流程见附件；请穿舒适的衣服和鞋，需自带[ ]
有饮食禁忌、身体不便或无法参加的，请在[日期]前私信[负责人]，不必说明原因。
聚餐自愿参加，全程不劝酒。
```

## 避雷与备选方案

避雷：

- **强制饮酒**：不设劝酒环节，默认无酒精饮品，领导带头不劝。
- **占用周末**：默认工作时间；确需周末或下班后，提前征求意见，写明是否自愿、有没有调休（按制度）。
- **竞技伤人**：不排身体对抗和高冲撞项目（拔河、背人跑、叠人一类）；户外设两档强度；不想参加的人安排计分、裁判、摄影等不尴尬的角色。
- 其他：强制表演节目、当众揭短、打探隐私的问答、只让新人或女同事做服务性工作、公开排名。

备选：

- **天气**：户外必须备好室内方案，提前两天定。
- **人数**：比预期少三成以上就合并小组；物料多备一成。
- **场地或交通出问题**：在三十分钟车程内备一个替代点，或者改线上。
- **有人不适**：每个环节都允许旁观，不扣分、不点名。

## 最常见的错误

- 一场想同时破冰、庆功、复盘，结果哪样都没做好。
- 领导讲话占掉一半时间。
- 流程排满没有休息，下午全员疲惫。
- 预算只算人均，漏了交通、物料和备用金。
- 活动后不收反馈，下次踩同一个坑。

## 输出契约

1. 先问：目的、人数、预算、时长与日期、场地条件、特殊需要。
2. 交付一页方案：目的与成功标准、流程表、分工表、预算表、备选方案、避雷确认；需要时附活动通知文案。
3. 预算只按用户给的数算，价格不猜；场地与商家只写类型，不写名字。
4. 聚餐、饮酒、周末环节一律标「自愿」。

## 边界与不做什么

- 不推荐具体商家、场地、品牌，不比价。
- 涉水、攀爬、露营等高风险项目，只提示须找有资质的机构并做安全评估，不给操作方案。
- 费用报销、加班调休、保险责任以单位制度为准，有争议找人事或行政。
- 活动中有人受伤或突发不适：先拨打急救电话、就近就医，后续交给单位和专业人士处理。
