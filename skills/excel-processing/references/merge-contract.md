# 严格按表头合并的输入与输出规则

脚本：`scripts/merge_xlsx.py`。只使用标准库和已有 openpyxl，本次用 Python 3.12、openpyxl 3.1.5 实测；本脚本不安装依赖、不登录、不上传、不发送材料。

```bash
python3 scripts/merge_xlsx.py east.xlsx west.xlsx \
  --sheet 明细 --header-row 1 --out combined.xlsx
```

输入文件按命令给定顺序读取；每个文件必须有完全匹配的 `--sheet` 名称。不会选择活动工作表或遍历全部工作表。只支持正常 `.xlsx`，不接受 `~$` 锁文件、旧 `.xls`、宏 `.xlsm`、加密文件。宏与复杂工作簿仍按 SKILL.md 配方及边界另行处理。

## 表头与行

- 默认第 1 行为表头，`--header-row` 可指定其他行，所有输入使用同一行号。
- 表头必须是非空文本，去首尾空格后不能重复。列顺序可以变化；字段名称集合必须与第一个输入一致。`金额` 与 `金额(元)` 不自动认作同一个字段。
- 尾部纯空表头格忽略；如果数据行在这些无表头列有内容，则报错，避免丢数据。中间的空表头格直接报错。
- 全空数据行跳过，部分空格保留；数据行数不包含表头及其上方说明行。
- 输入先整理成一行一条记录的平面表。合并单元格先按配方⑥拆开填满，夹小计或标题的行先清理；脚本不推断业务含义，也不自动去重。
- 不能使用保留名称 `来源文件`、`来源工作表`、`来源行` 作为输入表头。结果会追加这三列，原行号用于逐格复核。文件路径保存为解析后的绝对路径，真实输出不要直接当公开样例传播。

## 公式必须明确

默认 `--formulas reject`：所选数据区出现公式即报错，给出文件、工作表、单元格坐标。原因是重排列和追加行以后，原引用可能算错。

明确指定 `--formulas cached`：并行读取公式标识与 `data_only=True` 的缓存，只复制已有非空且不是 Excel 错误值的缓存。缺缓存或错误缓存报错，输出文件不生成。公式返回空白且没有可识别缓存时也会报错，由用户在原软件中确认。

openpyxl 不计算公式；读取缓存不能证明缓存是最新或正确的。真实材料先在 Excel/WPS 中计算并保存，再核对三个样本行，之后才选 cached。脚本不移动公式文本、不重算、不宣称已验证财务结论。

原本是文本的 `=说明` 会保持为文本，避免合并时意外变成新公式。正常值保留 Python 类型和 number_format，其他样式、合并区、图形、宏等工作簿结构不复制。

## 输出保护与验收

只生成一个新的 `.xlsx`，工作表名 `合并明细`，第一行是表头，冻结 `A2` 并添加筛选。输出路径不能等于任一输入；同名输出已存在则报错，不提供覆盖选项。成功前先保存临时文件，使用原子且不覆盖的文件创建方式写到目标名；运行失败时不交付部分结果。

JSON 汇总包含输出路径、表头、公式模式、数据行读入/写出/空行数量、公式缓存格数量，以及每个来源文件的行数。所有输入只读加载，用完显式 close；合成示例用执行前后 SHA256 一致核对原件不变。

| 退出码 | 意义 | 下一步 |
|---|---|---|
| 0 | 成功 | 打开新结果，按来源列抽查至少 3 行 |
| 1 | 参数、表头、公式、文件内容不满足规则 | 按报错坐标修正输入或选择；不强行合并 |
| 2 | 输入缺失、输出已存在或无法写入 | 检查路径或换新输出名 |
| 3 | 当前 Python 没有 openpyxl | 使用已有该库的环境，或由用户管理依赖 |
| 130 | 用户中断 | 检查是否已有结果，换新路径重跑 |

Excel 单表上限包含表头为 1,048,576 行、16,384 列。达到上限会报错；大量数据建议按用途改用 CSV/数据库。

## 已核对的官方依据

2026-10-09 查阅 openpyxl 官方文档；文档 stable 页面标注 3.1.3，本机实际库为 3.1.5。

- [Tutorial：保存与读取](https://openpyxl.readthedocs.io/en/stable/tutorial.html)：`save` 会无提示覆盖；`data_only` 取上次保存的缓存；复杂形状可能在重存时丢失。
- [Simple Formulae](https://openpyxl.readthedocs.io/en/stable/simple_formulae.html)：库不求值公式。
- [Optimised Modes](https://openpyxl.readthedocs.io/en/stable/optimized.html)：只读工作簿需显式 close；部分生成器记录的范围不正确时可 reset_dimensions。

脚本与测试为本仓库新增实现；以上是 API 行为依据，不是复制他人技能。
