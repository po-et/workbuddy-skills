# 答辩常见问题与鉴定表写法

## 一、答辩常见问题与回答思路

| 问题 | 回答思路 |
|---|---|
| 1. 用两分钟介绍你的实习 | 单位与岗位一句 → 做了哪三件事 → 最大的收获一句；掐表练到两分钟内 |
| 2. 你做的最有价值的一件事是什么？ | 一个 STAR 故事，结果要有数字或可验证的产出 |
| 3. 报告里的这个数字是怎么来的？ | 说清口径和来源（自己统计、自己导出、经指导人同意引用）；记不清就说"约"，讲清估算方法 |
| 4. 专业知识在实习中用上了哪些？ | 一门课 + 一个知识点 + 一个具体场景 |
| 5. 遇到的最大困难是什么？怎么解决的？ | 困难要具体，重点讲自己的行动和结果 |
| 6. 你觉得自己哪里做得不好？ | 一个真实的不足 + 已经在做的改进 |
| 7. 实际工作和课堂所学有什么不同？ | 举一个例子，讲差别在哪，不评价好坏 |
| 8. 如果再实习一次，你会怎么做？ | 两点具体调整 |
| 9. 这段实习对你的职业方向有什么影响？ | 真实想法：确认了什么、排除了什么 |
| 10. 你对课程或实习安排有什么建议？ | 建设性、具体、可执行 |
| 11. 单位是做什么的？你的部门处在什么位置？ | 公开信息 + 部门职能，不讲内部细节 |
| 12. 你的报告和周记有一处对不上，怎么回事？ | 如实说明；提交前自己先对照一遍，避免被问到 |

## 二、答辩准备卡（一页，带进答辩现场）

```
两分钟介绍提纲：[单位与岗位] / [三件事] / [一个收获]
STAR 故事一（1 分钟）：[ ]
STAR 故事二（1 分钟）：[ ]
STAR 故事三（1 分钟）：[ ]
报告里每个数字的来源：[数字 → 来源]
最可能被追问的三点：[ ]
一条对课程的建议：[ ]
```

## 三、鉴定表"自我鉴定"

篇幅按表格留白，一般一段。结构：实习概况一句 → 主要工作与成果 2–3 句 → 收获与不足 1–2 句 → 今后打算一句。用事实代替"表现优秀""认真负责"这类形容词。

模板：

```
本人于[起止时间]在[单位]（按学校要求写全称或简称）[部门]担任[岗位]实习生，主要负责[工作 1]、[工作 2]。实习期间，我[代表性成果，带事实]，并[第二项成果]。通过实习，我[能力上的具体变化]，也认识到自己在[不足]方面还需加强。今后我将[具体打算]。
```

示例（虚构）：

> 本人于 2026 年 7 月 6 日至 8 月 28 日在某连锁茶饮品牌华东区域运营中心用户运营组担任用户运营实习生，主要负责用户反馈整理和会员社群运营。实习期间，我完成了 600 多条用户反馈的分类与汇总，建立的分类表被组内沿用到每周的反馈整理；参与会员日活动筹备，编写的常见问题答复在活动当天用于统一回复。通过实习，我学会了先定口径再做统计，文案修改次数明显减少；也认识到自己在数据工具和会议表达上还需加强。今后我将系统学习数据透视表和 SQL 基础，并在课堂讨论中多主动发言。

## 四、单位意见栏

由单位填写并盖章。指导人让你起草时：
- 只列可核实的事实：实习起止、岗位、出勤（以单位记录为准）、完成的主要工作、可验证的成果。
- 评价用语（优秀、良好等）留给指导人决定，不替对方写好评。
- 盖章按单位流程办理（人事或部门负责人），提前约时间；不自己代盖、代签。

## 五、鉴定表常见问题

- 手写还是打印？以学校要求为准。
- 写错了能不能涂改？很多表格要求不涂改，先在草稿上写好再誊抄；以学校要求为准。
- 单位盖章来不及？提前一到两周联系指导人；按学校规定办理延期，不要代盖。
