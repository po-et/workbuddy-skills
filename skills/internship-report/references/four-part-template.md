# 实习报告模板（四段式）

用法：学校或学院下发了模板，一律以模板为准；本模板用于没有模板时起草，或拿来对照有没有漏项。`[ ]` 里是要替换的内容，没有的信息先写 [待补：…]。

## 封面信息（按学校要求取舍）

```
实习报告
学院：[ ]            专业班级：[ ]
姓名：[ ]            学号：[ ]
实习单位：[按学校要求写全称或简称；写全称前先问单位能否写]
部门与岗位：[ ]
实习时间：[年月日] 至 [年月日]（共 [N] 周）
校内指导教师：[ ]    单位指导人：[ ]
```

## 一、实习单位与岗位（约占 10–15%）

要写的：
- 单位概况 3–5 句：行业、主营业务，只用公开信息。
- 所在部门的职能 1–2 句。
- 岗位与职责 2–4 条。
- 实习安排：起止、每周几天、谁指导、怎么指导。

句式：
- 「[单位]是一家[行业]的[企业/机构]，主要从事[业务]。我所在的[部门]负责[职能]。」
- 「我的岗位是[岗位]，主要职责包括：[职责 1]；[职责 2]；[职责 3]。」

## 二、实习内容（约占 40–50%）

按任务模块组织，每个模块一个小标题：

```
（一）[核心任务一：用 STAR 展开]
（二）[核心任务二：用 STAR 展开]
（三）日常工作：[一两句带过]
```

STAR 段落骨架：

```
[时间或阶段]，[情境：当时的问题或需要]（S）。我负责[任务]（T）。
我[具体做法 1]，[具体做法 2]；遇到[困难]时，我[怎么解决]（A）。
最后[结果：数字或可验证的产出]，[后续影响]（R）。
这件事让我[连回专业的一句]。
```

写正式稿时去掉（S）（T）（A）（R）标记。结果写不出数字时，写可验证的产出：交付了什么、被谁采用、后来是否沿用。

## 三、收获与反思（约占 20–25%）

- 专业知识的应用：[一门课] 的 [一个知识点] 在 [一个场景] 里怎么用上的。
- 能力的变化：[能力]——以前 [怎样]，现在 [怎样]，例子是 [哪件事]。
- 不足：[一条真实的不足] + [已经在做的改进]。

避免只列"提高了沟通能力、团队协作能力"而没有例子。

## 四、问题与建议（约占 10–15%）

- 对自己：[下一步要补的知识或技能，具体到课程或工具]。
- 对学校课程：[哪门课可以加什么练习，为什么]。
- 对实习安排：[建设性建议，对事不对人]。

## 结语（2–3 句）

「[时长]的实习让我[最重要的一点收获]。感谢[单位指导人]和[校内指导教师]的指导。今后我将[具体打算]。」

## 字数分配参考（建议值，学校有要求按学校）

| 总字数 | 单位与岗位 | 实习内容 | 收获与反思 | 问题与建议 | 结语 |
|---|---|---|---|---|---|
| 3000 | 350–450 | 1200–1500 | 600–750 | 300–450 | 约 100 |
| 5000 | 500–750 | 2000–2500 | 1000–1250 | 500–750 | 约 150 |

## 扩写清单（字数不够时按顺序用，不注水）

1. 把"日常工作"里最有变化的一件升级成第三个 STAR 段。
2. 给每条收获配一个具体例子。
3. 在"问题与建议"里写一条对课程的具体建议，说明理由。
4. 在实习内容里补上"遇到的困难与解决"的细节。
