# 周记与日志模板

周记是报告的素材库：每周写实写细，最后写报告只需要挑选和改写。周记同样适用保密红线：不写客户信息和单位内部数据。

## 周记模板（每周一篇）

```
第 [N] 周（[起止日期]）
一、本周做了什么（3–5 条，动词开头，写清交付物）
1. [完成/整理/撰写/参与] [什么]，[交付物或结果]
2.
3.
二、遇到的问题与解决
[问题] → [我怎么做的] → [结果]
三、学到的 / 想到的
[一个具体的点，最好连到一门课]
四、下周计划
[1–3 条]
```

## 日志模板（每天一行）

| 日期 | 做了什么 | 产出 | 用时 | 备注（遇到的问题、谁指导） |
|---|---|---|---|---|
| [ ] | [ ] | [ ] | [ ] | [ ] |

## 补写周记：回忆清单（只依据真实痕迹）

按周回答：
- 这周开了哪些会？我在会上做了什么（记录、汇报、提问）？
- 这周交出去了什么（文件、表格、文案、代码、报告）？交给了谁？
- 用了什么工具（只写通用名称，不写单位内部系统名）？
- 被表扬或被指出了什么问题？
- 翻自己的聊天记录、邮件、日历和文件修改时间，核对日期。

回忆不起来的那一周，写这周的常规工作，不虚构具体事件；时间线要和实习起止一致。

## 填好的周记示例（虚构）

```
第 3 周（7 月 20 日—7 月 24 日）
一、本周做了什么
1. 完成 600 多条用户反馈的分类，做成汇总表，周四交给组长
2. 协助准备会员日活动的常见问题初稿，列出 20 个问题
3. 每天维护 2 个会员群的日常消息
二、遇到的问题与解决
反馈类别边界模糊，一条反馈可能同时属于"口味"和"出品速度"。我先抽 50 条试分，和组长对齐出 8 个类别和"只归主要问题"的规则，再批量处理。
三、学到的 / 想到的
市场调研课讲的"先定口径再统计"，在实际工作里最费时间也最关键；口径不统一，后面的统计都白做。
四、下周计划
1. 把分类表做成每周可复用的模板
2. 完成活动常见问题的定稿
```

## 常见问题

- 篇数和实习周数对不上：以学校要求为准，先问清是按周交还是按天交。
- 周记和报告要一致：报告里写到的事，周记里应当有对应记录；答辩时老师可能对照着问。
- 一周什么都没做成：写清做了哪些尝试、卡在哪里、下周怎么推进，这同样是真实记录。
