# 两版模板（方括号处替换）

SKILL.md 里只放了结构和检查点，可直接填空的两版模板在这里。方括号里的内容必须来自写作者本人：看到的细节、当时的反应、自己的经历；作品信息拿不准的标「[待核]」。

## 中小学生版（600 字左右）

```
【中小学生版，600 字左右】
题目：《[作品名]》观后感（也可以用细节做题目：[细节]——《[作品名]》观后感）
第一段 细节：[谁在什么时候做了什么/说了什么]。那一刻，我[当时的反应：一个动作或表情]。
第二段 感受：我[情绪]，因为[这个细节和前后哪里不一样/它让我看懂了人物什么]。
第三段 联系自身：这让我想起[时间]，[我/身边的谁]在[地点][做了什么]。当时我[想法]，现在我才明白[……]。
第四段 观点与结尾：[一句话观点]。以后[一个具体的小行动，如：每次……时，我会先……]。[一句话再写开头的细节]。
```

600 字的大致分配：细节约 90 字、感受约 150 字、联系自身约 210 字、观点与结尾约 150 字。

## 成人版（1000 字左右，单位组织观影、参观后提交，或自己记录）

```
【成人版，1000 字左右（单位组织观影、参观后提交，或自己记录）】
标题：[从细节提炼的一句话]——观看《[作品名]》（参观[展览名]）有感
一、细节（约 150 字）：[细节]＋[一句背景：作品讲什么/展览在哪里、什么主题]
二、感受与原因（约 250 字）：[情绪]＋[原因]；可对照作品里另一处细节，说明这一处为什么格外打动你
三、联系工作或生活（约 350 字）：[本职工作里的一件具体的事/一次真实的判断]，写清当时怎么做、现在会怎么做
四、观点与行动（约 250 字）：[一个观点]＋[一两件做得到的事，写明从什么时候开始]＋[回扣开头的细节]
```

单位心得里涉及表态和评价的句子，给两三个分量不同的写法，由写的人自己选；合不合要求，以组织方的意见为准。

## 小学低年级（一段话）

小学低年级可以缩成一段话：我看了《[作品名]》。我最记得[细节]。我想[感受]，因为[原因]。以后我要[一件小事]。

## 开头细节段的三种写法

同一个细节，可以这样起笔（每种都只写看到、听到的，不写「感人」「震撼」）：

```
直接写画面  [人物][在什么时候][做了什么]。[一个让你停住的具体之处]。
先写声音    [一句台词或一个声音]。说这句话的是[谁]，那时他正[在做什么]。
写自己的反应 看到[细节]时，我[一个动作：按了暂停／停在展柜前／忘了鼓掌]。
```

写好后用脚本看每段占比和字数：`python3 scripts/essay_check.py draft.txt --target 600`。
