# 完整示例：单位组织参观展览后的 1000 字心得（成人版全文）

> 示例。展览、门牌、说明牌文字、工作经历都是虚构的，由示例中的「用户」提供；正文按用户给的细节和经历写成，没有另外添加事实。检查结果是 `scripts/essay_check.py` 的实际输出。

## 1. 用户原话

> 单位组织参观展览，要写一篇观后感，怎么写才不空

## 2. 助手先问（一次问完）

1. 交给谁、多少字、有没有指定主题？
2. 展览叫什么、讲什么？你记住的一个细节是什么——一件展品、说明牌上的一句话都行？当时你有什么反应？
3. 你的工作里，有没有一件事和这个细节能对上？当时怎么做的？

## 3. 用户补充

> 交给单位办公室，1000 字左右，没指定主题。展览叫「老城区变迁档案展」，讲老城区几十年的改造。我记得最里面展柜里有块搪瓷门牌「胜利街17号」，边上锈了，钉孔里还卡着半截钉子，说明牌大概写的是「住户搬离前自己摘下，托人送来」，原话记不太清。我在那儿站了很久。我在街道做社区工作，去年协调老旧小区加装电梯，三单元一楼一位老住户一直不同意，说住了三十年不想折腾，我上门三次都在讲政策，后来他不开门了，这一户一直没签字，方案拖了两个多月。第三次上门时他指着楼道墙上铅笔画的身高刻度说是他儿子小时候量的，我没接话。

## 4. 交付物

**① 开头细节段的另外两种写法**（正文用的是「直接写画面」）

```
先写声音    「住户搬离前自己摘下，托人送来。」说明牌上只有这一行字，旁边的展柜里是一块锈了边的搪瓷门牌。
写自己的反应 在「胜利街17号」那块门牌前，我站了很久，[待补：当时的一个动作，比如有没有凑近看、拍没拍照]。
```

**② 正文**（标题：一块摘下来的门牌——参观「老城区变迁档案展」有感）

一、展厅最里面的展柜里，放着一块蓝底白字的搪瓷门牌，写着「胜利街17号」。门牌四个角的漆掉了，边上锈了一圈，钉孔里还卡着半截铁钉。说明牌上只有一行字：住户搬离前自己摘下，托人送来[待核：说明牌原话]。这次展览讲的是老城区几十年来的改造，照片和图纸占了大半个展厅，我却在这块门牌前站得最久。

二、我先是愣了一下，心里有点发紧，因为整个展厅里，大多数展品是档案馆收来的规划图、批文和施工照片，记的是一片街区怎么被改变；只有这块门牌是住户自己送来的。他摘下它的时候，房子还在，家已经要搬走了。钉子没拔干净，说明摘得并不从容，也许是临走前一晚，也许是搬家车已经在楼下等着。一块门牌本来只标一个地址，可对住在那里的人来说，它是每天回家时抬头看见的那一眼。他没有把它扔掉，而是送到一个能被人看见的地方。这让我第一次觉得，改造的记录里少写了一样东西：住在那里的人舍不得什么。

三、我在街道做社区工作，去年负责一个老旧小区加装电梯的入户协调。三单元一楼的一位老住户坚决不同意，理由翻来覆去就是一句「我住了三十年，不想折腾」。我带着方案和补偿办法上门三次，每次都在讲政策、算账，讲到最后他干脆不开门。这一户一直没签字，整个单元的方案拖了两个多月。我在工作记录里写的是「沟通困难，建议由单元长再做工作」，心里其实觉得他不讲道理：电梯装好了，楼上的邻居方便，他家也不吃亏。站在那块门牌前，我想起第三次上门时，他指着楼道墙上一排铅笔画的身高刻度说，那是他儿子小时候量的。当时我只当是闲聊，接着讲我的方案。现在回头看，他在意的也许不是施工的麻烦，而是楼道一改、墙一刷，那排刻度就没了。我从头到尾没问过他一句：这栋楼里，有什么是您舍不得的。

四、这次参观让我明白，做改造的人看的是图纸，住在里面的人看的是日子；协调工作不能只把政策讲清楚，还得先把人家舍不得的东西听清楚。从下个月的入户开始，我给自己定两件事：第一次上门不带方案，先请住户讲讲这栋楼、这间屋里的事，记在本子上；方案里能保留的，比如楼道里的刻度、门口的老信箱，先想办法保留或者拍照存档，再去谈施工。这两件事不增加多少工作量，只是把顺序换一下：先听，再谈。那块门牌被摘下来的时候，钉子还卡在孔里。我希望下一次，住户不必在搬走前的晚上，一个人把舍不得的东西匆匆摘下来。

**③ 表态句的三种分量**（第四部分第一句，按单位要求自己选；合不合要求以组织方意见为准）

```
轻  这次参观提醒我，协调工作除了讲清政策，也要听清住户舍不得什么。
中  这次参观让我明白，做改造的人看的是图纸，住在里面的人看的是日子；协调工作不能只把政策讲清楚，还得先把人家舍不得的东西听清楚。（正文用的这一句）
重  这次参观让我认识到，老旧小区改造做得好不好，不只看工程进度，也要看住户的感情有没有被尊重；我会把「先倾听」作为入户协调的第一步。
```

**④ 自查**（正文一段一行存成 draft.txt 后运行）

```bash
python3 scripts/essay_check.py draft.txt --target 1000
```

```
  第1段 细节 15%（参考 15%）
  第2段 感受 24%（参考 25%）
  第3段 联系自身 34%（参考 35%）
  第4段 观点与结尾 25%（参考 25%）

提示（按字面规则找的线索，只作参考，不是评分）
  · 第1段像在复述情节（讲的是）：剧情介绍全篇不超过五分之一
  · 首尾共有的词：住户、图纸、块门、孔里、摘下、改造（结尾有没有回到开头的那个细节，自己再读一遍确认）
```

脚本的两条提示这样处理：第 1 段的「讲的是」是一句必要背景，只有一句，保留；首尾共有「摘下」「块门」「孔里」，说明结尾回到了开头的门牌和钉子，回扣成立。

**⑤ 待核与待确认**：说明牌原话用户记不清，正文里标了 [待核：说明牌原话]，提交前请对照照片或展览资料核实，核实不了就改成「说明牌上写着，这块门牌是住户搬离前自己摘下送来的」这类转述。第四部分的两件事（第一次上门不带方案、能保留的先保留或拍照）是按你的经历提的建议 [待确认]，改成你真打算做的事再交。
