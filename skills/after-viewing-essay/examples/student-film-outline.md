# 完整示例：学生 600 字电影观后感（给提纲和一段示范，由学生自己写完）

> 示例。片名用占位符，人物和情节细节都是虚构的，由示例中的学生提供。按本技能边界，中小学生的日常作业只给提问、提纲、一段示范和修改意见，感受和经历由学生本人写。

## 1. 用户原话

> 学校组织看了一部电影，老师要交 600 字观后感，我只会复述剧情

## 2. 助手先问（一次问完）

1. 片名是什么？老师有没有指定主题？
2. 看的时候，哪一个画面、哪一句台词让你愣了一下或鼻子一酸？当时你做了什么？
3. 这个画面让你想起了自己身边的哪个人、哪件事？

## 3. 学生补充

> 片名《[片名]》，没指定主题。男孩小亮冬天每天早上去送报纸，他爸爸话很少，还老凶他。有一个镜头，天没亮，爸爸把自行车推出来，先用袖子把车座上的霜擦干，才把车交给小亮。我当时鼻子一酸，没敢让同桌看见。这让我想起我妈，她每天早上把我的校服放在暖气片上烘着，我以前还嫌她起太早把我吵醒。

## 4. 交付物

**① 开头细节段的三种写法**（选一种，用你自己的话改）

```
直接写画面   天还没亮，爸爸把自行车推出来，先用袖子把车座上的霜擦干，才把车交给小亮。
先写声音     [待补：爸爸递车时如果说了话，写那句原话；没说话就写「爸爸一句话也没说」]
写自己的反应 看到爸爸用袖子擦车座的那一下，我鼻子一酸，赶紧低下头，怕同桌看见。
```

**② 提纲**（600 字，一段一行，括号里是大致字数）

```
第一段 细节（约 90 字）：天没亮，爸爸用袖子擦干车座上的霜，再把车交给小亮；那一刻我鼻子一酸。
第二段 感受（约 150 字）：我为什么鼻子酸——爸爸平时话少、老凶他，这个动作和前面哪里不一样？它让你看懂了爸爸什么？（这段必须你自己写，每个感受后面跟一个「因为」）
第三段 联系自身（约 210 字）：妈妈每天早上把我的校服放在暖气片上烘着；我以前嫌她起得早把我吵醒；写清是哪个季节、几点、我当时说过或想过什么。
第四段 观点与结尾（约 150 字）：一句话写你明白了什么（不写「我们要学习……」）；一件你真的会做的小事，写清从哪天开始 [待补：你打算做什么]；最后一句回到那个车座。
```

**③ 一段示范**（只示范第一段，其余三段按提纲自己写）

```
天还没亮，爸爸把自行车推出来，先用袖子把车座上的霜擦干，才把车交给小亮。他一句话也没说，转身就回屋了。看到这里，我鼻子一酸，赶紧低下头，怕同桌看见。
```

（「一句话也没说、转身回屋」是按你说的「爸爸话很少」推的，「低下头」是按你说的「没敢让同桌看见」写的；如果电影里、你当时不是这样，改成你看到的、你做的。）

**④ 写完后自查**

把四段各写成一行，存成 `我的观后感.txt`，运行：

```bash
python3 scripts/essay_check.py 我的观后感.txt --target 600
```

再对照这张表：

| 检查项 | 怎么看 |
|---|---|
| 复述占比 | 介绍剧情的句子加起来不超过全文五分之一（约 120 字） |
| 情绪词有没有原因 | 每个「感动」「难过」后面都跟得出「因为」；跟不出就换成一个动作 |
| 联系自身够不够具体 | 时间、地点、人物至少写出两样 |
| 结尾有没有回扣 | 最后一句回到车座，或回到妈妈烘校服的暖气片 |
| 字数 | 540–660 字之间；不够就补第三段的细节，不加口号 |

## 5. 交付前自检

| 检查项 | 结果 |
|---|---|
| 没有替学生写完整篇，只给了提纲和第一段示范 | 是 |
| 细节和经历都来自学生本人的描述 | 是 |
| 没有编造电影情节；示范段里推测的部分已标出请学生核对 | 是 |
| 给了字数分配和自查方法 | 是 |
