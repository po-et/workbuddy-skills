# 观后感

定位一句话：**观后感不是内容简介，而是「我看到了什么 → 它为什么打动我 → 我因此想明白了什么」。用一个细节开头，胜过一整段剧情梗概。**
何时用：看完电影、纪录片、展览，或话剧、音乐会、舞蹈等演出，要交一篇观后感（学校作业、单位组织观影或参观后的心得），或自己想写下来时。

## 先判断：四件事问清再动笔

| 先问 | 为什么 |
|---|---|
| 交给谁、要多少字 | 以对方要求为准；没给字数时，学生作业按 600 字、成人心得按 1000 字左右起步 |
| 有没有指定主题 | 有主题，观点段就要回应它，但要从你自己的细节走过去，不照抄主题口号 |
| 看的是哪类作品 | 电影、纪录片、展览、演出能用的细节不一样，见第 1 步 |
| 你记住了什么 | 一个画面、一句台词、一件展品都行；一个都说不出，先回看片段、翻展览图录再写 |

## 第 1 步 找细节：先别急着写「感动」

看的时候或刚看完，记下三个「停顿点」——你愣了一下、鼻子一酸、笑出声、想拍下来的时刻。

```
电影    一个镜头、一句台词、一个反复出现的道具（例：主人公每次出门前都把门口的鞋摆正）
纪录片  一个数字、一位受访者的一句原话、一段没有解说的空镜头
展览    展品上的一道磨损、说明牌上的一句话、展柜里一件东西旁边的空位
演出    一个动作、音乐突然停下的一拍、谢幕时演员的一个表情
挑选    三个里留下你最能回答「为什么是它」的那个；答不上来就换一个
写下    用 50–100 字原样描述看到了什么、听到了什么；这一步不写「感人」「震撼」
```

## 第 2–5 步 三段结构：感受 → 联系自身 → 观点

```
第 2 步 开头细节（约占全文 15%）：直接写那个细节，加一句必要背景（作品名、人物、处境）。
        检查点：第一句里有画面或声音，而不是「今天我观看了一部感人的影片」。
第 3 步 感受（约 25%）：这个细节让我[什么情绪]，因为[它和前后哪里不一样/它让我看懂了什么]。
        检查点：每个情绪词后面都跟得出「因为」。
第 4 步 联系自身（约 35%）：我经历过的一件事、身边的一个人，或我原来的一个看法。
        检查点：时间、地点、人物至少写出两样；「我们都应该……」不算联系自身。
第 5 步 观点与结尾（约 25%）：一句话说清我明白或改变了什么，落到一个小行动，最后回到开头的细节。
        检查点：观点的高度不超过前文写到的内容；首尾是同一个画面。
        有指定主题时，观点句用自己的话回应主题词。例如主题是「坚持」：「我以前以为坚持是……，看完才觉得是……」。
```

剧情或展览内容的介绍，全篇不超过五分之一。学校常教的「引、议、联、结」也适用，这里只是把「引」压缩成一个细节。草稿存成 draft.txt，一段一行，看每段占比和总字数：

```bash
python3 -c "import sys;ps=[p.strip() for p in open(sys.argv[1],encoding='utf-8') if p.strip()];n=sum(map(len,ps));[print(i+1,len(p),'%d%%'%(100*len(p)//n),p[:10]) for i,p in enumerate(ps)];print('合计',n)" draft.txt
```

## 两版模板（方括号处替换）

```
【中小学生版，600 字左右】
题目：《[作品名]》观后感（也可以用细节做题目：[细节]——《[作品名]》观后感）
第一段 细节：[谁在什么时候做了什么/说了什么]。那一刻，我[当时的反应：一个动作或表情]。
第二段 感受：我[情绪]，因为[这个细节和前后哪里不一样/它让我看懂了人物什么]。
第三段 联系自身：这让我想起[时间]，[我/身边的谁]在[地点][做了什么]。当时我[想法]，现在我才明白[……]。
第四段 观点与结尾：[一句话观点]。以后[一个具体的小行动，如：每次……时，我会先……]。[一句话再写开头的细节]。

【成人版，1000 字左右（单位组织观影、参观后提交，或自己记录）】
标题：[从细节提炼的一句话]——观看《[作品名]》（参观[展览名]）有感
一、细节（约 150 字）：[细节]＋[一句背景：作品讲什么/展览在哪里、什么主题]
二、感受与原因（约 250 字）：[情绪]＋[原因]；可对照作品里另一处细节，说明这一处为什么格外打动你
三、联系工作或生活（约 350 字）：[本职工作里的一件具体的事/一次真实的判断]，写清当时怎么做、现在会怎么做
四、观点与行动（约 250 字）：[一个观点]＋[一两件做得到的事，写明从什么时候开始]＋[回扣开头的细节]
```

小学低年级可以缩成一段话：我看了《[作品名]》。我最记得[细节]。我想[感受]，因为[原因]。以后我要[一件小事]。

## 最常见的问题

| 问题 | 典型句子 | 改法 |
|---|---|---|
| 全篇复述 | 「影片讲述了……后来……最后……」占了大半篇 | 背景只留理解细节必需的一两句；把复述段整段删掉，文章还立得住才算对 |
| 空喊口号 | 「我们要珍惜今天的幸福生活」 | 口号句后面必须接得上「比如我……」；接不上就删，或换成一件具体的事 |
| 结尾硬升华 | 看的是讲导盲犬的电影，结尾却写「长大要为社会做贡献」 | 观点只往外推一层：从细节到自己，最多到身边的人 |
| 感受空泛 | 「非常感动」「深受震撼」反复出现 | 每个情绪词配一个原因，或换成动作：「我把暂停键按住了很久」 |
| 套用范文 | 网上搜来的开头和结尾 | 老师和同事多半看过同一部作品，细节对不上一眼就露馅；换成你自己记住的那个细节 |

```
改前：今天我观看了电影《[作品名]》，影片讲述了……（复述 300 字）。看完我非常感动，我们要学习主人公的精神，长大为社会做贡献。
改后：主人公每次出门前，都会把门口那双旧鞋摆正。影片快结束时，鞋还摆在那里，人却没有回来。（细节）
      那一刻我按了暂停，鼻子发酸：这个最不起眼的动作，原来一直在说他想回家。（感受）
      我想起外婆总把我的书包挂在同一个钩子上，我以前嫌她啰嗦。（联系自身）
      现在我明白，那是她等我回家的方式。这周回家，我要先把书包挂回那个钩子，就像他摆正那双鞋。（观点与行动，回扣细节）
```

## 输出契约

1. 先问后写：作品名和类型、交给谁、字数和主题要求；再问用户记住的一个细节和当时的反应——感受必须是用户自己的。
2. 交付：开头细节段的两三种写法；按三段结构写成的正文，学生日常作业则给提纲加一段示范，由学生自己写完；一张自查表（复述占比、情绪词有没有原因、结尾有没有回扣细节）。
3. 字数贴着要求，默认不超出一成；不够就补联系自身的细节，不加口号。
4. 作品信息以用户提供的为准：片名、人物、台词、展品说明拿不准的标「[待核]」，不凭印象编情节。

## 边界与不做什么

- 不代写考场作文和作文比赛稿；中小学生的日常作业以提问、提纲和修改意见为主，感受和经历必须来自学生本人。
- 不编造作品内容：没看过、记不清的情节不写；台词、歌词只引一两句短句并注明出处，不大段照抄。
- 单位要求的心得里涉及表态和评价的句子，给两三个分量不同的写法由用户自己选；合不合要求，以老师或组织方的意见为准。
- 看完战争、灾难、疾病、离别题材后情绪久久缓不过来，先和家人、老师或朋友聊一聊，需要时寻求专业心理帮助。
- 影评、书评、读后感和学术性的作品分析不在本技能范围。
