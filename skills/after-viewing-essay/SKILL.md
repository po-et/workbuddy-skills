# 观后感

定位一句话：**观后感不是内容简介，而是「我看到了什么 → 它为什么打动我 → 我因此想明白了什么」。用一个细节开头，胜过一整段剧情梗概。**

## 何时使用

用户这样说时用本技能：

- 「学校组织看了一部电影，要交 600 字观后感，我只会复述剧情」
- 「单位组织参观展览，要写观后感，怎么写才不空」
- 「看完一场话剧想写观后感，结尾总忍不住硬升华」
- 「纪录片观后感开头怎么写」
- 「帮我看看这篇观后感哪里空」

适用场景：看完电影、纪录片、展览，或话剧、音乐会、舞蹈等演出，要交一篇观后感（学校作业、单位组织观影或参观后的心得），或自己想写下来时。

不适用（遇到时这样处理）：

- 考场作文、作文比赛稿要整篇代写：不接，可以讲写法、看提纲、改一两句示范。
- 读后感、影评、书评、学术性的作品分析：一句话说明不在本技能范围，读后感可按同样的「细节 → 感受 → 联系自身 → 观点」思路，由写的人自己套用。
- 看完战争、灾难、疾病、离别题材后情绪久久缓不过来：先建议和家人、老师或朋友聊一聊，需要时寻求专业心理帮助，写作放在后面。

## 先判断：四件事问清再动笔

| 先问 | 为什么 |
|---|---|
| 交给谁、要多少字 | 以对方要求为准；没给字数时，学生作业按 600 字、成人心得按 1000 字左右起步 |
| 有没有指定主题 | 有主题，观点段就要回应它，但要从你自己的细节走过去，不照抄主题口号 |
| 看的是哪类作品 | 电影、纪录片、展览、演出能用的细节不一样，见第 1 步 |
| 你记住了什么 | 一个画面、一句台词、一件展品都行；一个都说不出，先回看片段、翻展览图录再写 |

## 第 1 步 找细节：先别急着写「感动」

看的时候或刚看完，记下三个「停顿点」——你愣了一下、鼻子一酸、笑出声、想拍下来的时刻。

```
电影    一个镜头、一句台词、一个反复出现的道具（例：主人公每次出门前都把门口的鞋摆正）
纪录片  一个数字、一位受访者的一句原话、一段没有解说的空镜头
展览    展品上的一道磨损、说明牌上的一句话、展柜里一件东西旁边的空位
演出    一个动作、音乐突然停下的一拍、谢幕时演员的一个表情
挑选    三个里留下你最能回答「为什么是它」的那个；答不上来就换一个
写下    用 50–100 字原样描述看到了什么、听到了什么；这一步不写「感人」「震撼」
```

## 第 2–5 步 三段结构：感受 → 联系自身 → 观点

```
第 2 步 开头细节（约占全文 15%）：直接写那个细节，加一句必要背景（作品名、人物、处境）。
        检查点：第一句里有画面或声音，而不是「今天我观看了一部感人的影片」。
第 3 步 感受（约 25%）：这个细节让我[什么情绪]，因为[它和前后哪里不一样/它让我看懂了什么]。
        检查点：每个情绪词后面都跟得出「因为」。
第 4 步 联系自身（约 35%）：我经历过的一件事、身边的一个人，或我原来的一个看法。
        检查点：时间、地点、人物至少写出两样；「我们都应该……」不算联系自身。
第 5 步 观点与结尾（约 25%）：一句话说清我明白或改变了什么，落到一个小行动，最后回到开头的细节。
        检查点：观点的高度不超过前文写到的内容；首尾是同一个画面。
        有指定主题时，观点句用自己的话回应主题词。例如主题是「坚持」：「我以前以为坚持是……，看完才觉得是……」。
```

剧情或展览内容的介绍，全篇不超过五分之一。学校常教的「引、议、联、结」也适用，这里只是把「引」压缩成一个细节。草稿存成 draft.txt，一段一行，用脚本看每段占比和总字数，并找出复述、口号、没有原因的情绪词、首尾没回扣这几类线索：

```bash
python3 scripts/essay_check.py draft.txt --target 600
```

## 两版模板

- **中小学生版（600 字左右）**：四段——细节（谁在什么时候做了什么，我当时的反应）→ 感受（情绪＋因为）→ 联系自身（时间、人物、地点、当时的想法、现在明白了什么）→ 观点与结尾（一句观点＋一个具体小行动＋回扣细节）。
- **成人版（1000 字左右）**：细节约 150 字 → 感受与原因约 250 字 → 联系工作或生活约 350 字（写清当时怎么做、现在会怎么做）→ 观点与行动约 250 字（写明从什么时候开始，回扣开头）。
- **小学低年级**：缩成一段话——我看了什么，我最记得什么，我想到什么、因为什么，以后我要做一件什么小事。

可直接填空的完整模板和「开头细节段的三种写法」见 [references/templates.md](references/templates.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（作品名、字数要求、记住的细节） | 先问 1–3 项：交给谁要多少字、看的是什么、记住的一个细节和当时的反应；字数没给按默认（学生 600、成人 1000）并标 [待确认] | 「先告诉我三件事：交给谁、要多少字，看的是什么，你记住的一个画面或一句话。」 |
| 什么细节都没记住 | 降级：先回看预告片或片段、翻展览图录和自己拍的照片，从里面挑一个；实在没有，就写「我最记得的一种感觉」，再追问是哪一刻出现的 | 「先别急着写，去看两分钟预告或翻翻照片，挑一个让你停住的画面，告诉我它是什么样的。」 |
| 输入自相矛盾（小学生要 3000 字；说是纪录片，描述的却是剧情片的情节） | 指出哪里对不上，给两种理解让用户选 | 「小学作业 3000 字不太常见：是 300 字，还是整个活动的总结要 3000 字？」 |
| 作品信息拿不准（片名、人物、台词、展品说明记不清） | 不凭印象编；正文里标 [待核]，请用户对照资料核实 | 「这句台词我标了待核，你对一下原片或字幕，确认了再交。」 |
| 超出本技能范围（考场作文、影评、学术分析） | 说明边界，转成能做的：讲方法、看提纲、改一两句 | 「考场作文我不代写；可以一起把提纲理顺，你来写。」 |
| 时间紧，只要最小可用版 | 学生：开头细节段的写法＋四段提纲（每段一句）＋字数分配；成人：细节段＋四段提纲＋结尾一句回扣。其余由用户补写 | 「先给你最小版：开头一段加四句提纲，照着写半小时就能成稿。」 |
| 用户坚持越界（学生要整篇代写；要编一段没发生过的经历） | 守住边界：学生作业给提纲和一段示范；经历只能用本人的，没有就换一个真实的小事 | 「整篇我不能替你写，感受得是你自己的；我把提纲和第一段示范写好，剩下三段你来写，写完我帮你改。」 |
| 输出中断或只写了一半 | 按输出契约的编号从断开的那一部分续写，不重写已给出的部分 | 「刚才停在第 ③ 部分，我从这里接着写。」 |

脚本 `scripts/essay_check.py` 的退出码与报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 检查完成；「提示」只是线索，不影响退出码 | 逐条读提示，自己判断改不改 |
| 1「没有正文」 | 文件是空的，或全是空行 | 草稿一段一行存进文件 |
| 1「没有输入」 | 没给文件路径，也没有用管道传入 | `python3 scripts/essay_check.py draft.txt` |
| 1「参数错误」「--target 要大于 0」 | 目标字数写成了非数字或 0 | `--target 600` |
| 2「找不到文件」「不是 UTF-8 文本」 | 路径不对，或文件是其他编码 | 检查路径；用编辑器另存为 UTF-8 |
| 130 | 按了 Ctrl+C | 重新运行即可 |

## 输出契约

先问后写：作品名和类型、交给谁、字数和主题要求；再问用户记住的一个细节和当时的反应——感受必须是用户自己的。

交付物按这个顺序编号给出，不增不减：

1. **开头细节段的两三种写法**（直接写画面、先写声音、写自己的反应）。
2. **正文或提纲**：成人按三段结构写成正文；学生日常作业给四段提纲加一段示范，由学生自己写完。
3. **字数说明**：贴着要求，默认不超出一成；不够就补联系自身的细节，不加口号。
4. **自查表**：复述占比、情绪词有没有原因、联系自身是否具体、结尾有没有回扣细节（能跑脚本就附脚本输出）。
5. **待核 / 待补清单**：作品信息拿不准的、需要用户补的经历，逐条列出。

占位符规则：作品信息以用户提供的为准，片名、人物、台词、展品说明拿不准的标 `[待核]`；需要用户本人补的感受、经历、行动写 `[待补：……]`；按默认值处理的（如字数）写 `[待确认：……]`；不凭印象编情节。

断点续写：交付物按上面的编号输出；如果输出中断，用户说「继续」时从断开的那一部分重新开始，不重写已给出的部分，也不改动用户已确认的内容。

交付前自检（逐条答「是」才交）：

- [ ] 第一句有画面或声音，不是「今天我观看了……」？
- [ ] 剧情或展览介绍不超过全文五分之一？
- [ ] 每个情绪词后面都跟得出「因为」？
- [ ] 联系自身写出了时间、地点、人物中的至少两样，而且来自用户本人？
- [ ] 结尾回到了开头的细节，观点没有超出前文写到的高度？
- [ ] 拿不准的作品信息都标了 [待核]，学生作业没有整篇代写？

## 示例

示例（话剧和经历均为虚构，由示例中的用户提供）：

**用户**：看完一场话剧想写观后感，结尾总忍不住硬升华。我现在的结尾是：「这部话剧让我明白了，我们每个人都应该珍惜身边的人，为建设美好社会贡献自己的力量。」

**助手**（先问）：两个问题：你开头写的是哪个细节？这个细节让你想到了自己的哪件事？

**用户**：开头写的是老人把一封没寄出的信夹回书里。我想到我给我爸写过一段很长的微信，一直在草稿箱里没发。

**助手**（交付）：

问题在两处：「我们每个人都应该」是口号，接不上「比如我……」；「为建设美好社会」比前文高出了好几层，也没有回到那封信。观点只往外推一层——从那封信到你的草稿箱就够了。两个改法：

```
改法一（短）：那封信最后还是夹回了书里。我的那段话，也还在草稿箱里。[待确认：换成你真打算做的事，比如「今晚我想先把第一句发出去」]
改法二（稍长）：散场的路上，我一直想着那封没寄出的信。有些话放久了，就越来越找不到说出口的时候。我的那段微信在草稿箱里存了[待补：多久]，[待确认：你打算什么时候、怎么说给他听]；我不想让它也夹回哪本书里。
```

自查：首尾都是那封信（回扣成立）；没有「我们都应该」；行动那一句要换成你自己真的会做的事。

## 常见问题（FAQ）

**Q：看完什么细节都没记住怎么办？**
A：先回看预告片或片段，翻展览图录、自己拍的照片，挑一个让你停住的画面；一个都挑不出，就从「我最记得的一种感觉」倒推是哪一刻出现的。

**Q：能不能直接帮我写完整篇？**
A：成人的心得可以按你给的细节和经历写成正文；中小学生的作业只给提纲、一段示范和修改意见，考场作文和比赛稿不代写。

**Q：字数不够怎么凑？**
A：补「联系自身」那段的细节：时间、地点、当时说的话；不要加口号，也不要多复述剧情。

**Q：老师指定了主题怎么办？**
A：观点段用自己的话回应主题词，但要从你自己的细节走过去，比如「我以前以为坚持是……，看完才觉得是……」。

**Q：观后感和读后感、影评有什么区别？**
A：观后感写「我看到的一个细节和我的变化」；影评要评价作品的好坏和手法，不在本技能范围。读后感可以用同样的思路自己套。

**Q：单位要求写表态，怎么写不假？**
A：表态句给两三个分量不同的写法，你自己选；每一种都落到一件做得到、写明从什么时候开始的事。

**Q：台词记不清，能凭印象写吗？**
A：不凭印象编；写你记得的大意并标 [待核]，交之前对照原片或字幕核实。

## 常见错误（反模式）

| 错误做法（典型句子） | 为什么错 | 正确做法 |
|---|---|---|
| 全篇复述：「影片讲述了……后来……最后……」占了大半篇 | 读的人看过作品，想看的是你看到了什么 | 背景只留理解细节必需的一两句；把复述段整段删掉，文章还立得住才算对 |
| 空喊口号：「我们要珍惜今天的幸福生活」 | 放进任何一篇都成立，等于没说 | 口号句后面必须接得上「比如我……」；接不上就删，或换成一件具体的事 |
| 结尾硬升华：看的是讲导盲犬的电影，结尾却写「长大要为社会做贡献」 | 观点高出前文好几层，读起来像贴上去的 | 观点只往外推一层：从细节到自己，最多到身边的人 |
| 感受空泛：「非常感动」「深受震撼」反复出现 | 没有原因的情绪词，读者感受不到 | 每个情绪词配一个原因，或换成动作：「我把暂停键按住了很久」 |
| 套用范文：网上搜来的开头和结尾 | 老师和同事多半看过同一部作品，细节对不上一眼就露馅 | 换成你自己记住的那个细节 |

同一段话的改前与改后：

```
改前：今天我观看了电影《[作品名]》，影片讲述了……（复述 300 字）。看完我非常感动，我们要学习主人公的精神，长大为社会做贡献。
改后：主人公每次出门前，都会把门口那双旧鞋摆正。影片快结束时，鞋还摆在那里，人却没有回来。（细节）
      那一刻我按了暂停，鼻子发酸：这个最不起眼的动作，原来一直在说他想回家。（感受）
      我想起外婆总把我的书包挂在同一个钩子上，我以前嫌她啰嗦。（联系自身）
      现在我明白，那是她等我回家的方式。这周回家，我要先把书包挂回那个钩子，就像他摆正那双鞋。（观点与行动，回扣细节）
```

## 边界与不做什么

- 不代写考场作文和作文比赛稿；中小学生的日常作业以提问、提纲和修改意见为主，感受和经历必须来自学生本人。
- 不编造作品内容：没看过、记不清的情节不写；台词、歌词只引一两句短句并注明出处，不大段照抄。
- 单位要求的心得里涉及表态和评价的句子，给两三个分量不同的写法由用户自己选；合不合要求，以老师或组织方的意见为准。
- 看完战争、灾难、疾病、离别题材后情绪久久缓不过来，先和家人、老师或朋友聊一聊，需要时寻求专业心理帮助。
- 影评、书评、读后感和学术性的作品分析不在本技能范围。
