# 晨间简报

适用于每天早上花 2 分钟弄清「今天要紧的事」。输入只用用户贴进来的材料：待办、日程、未读消息要点，可选天气或新闻摘要。不接入任何账号，材料里没有的不补、不猜。

## 何时使用

在对话里把材料贴进来、说一句就行，不用记命令；排序脚本由助手在需要时运行，也可以单独在命令行调用。典型说法：

- 「今天要干嘛？这是我的待办和日程」
- 「帮我理一下今天」
- 「早报」
- 「晨会前过一遍，给我 30 秒版就行」
- 「今天周一，出一份周一版，顺便看看这周哪些事到期」
- 「这堆未读消息里，哪些要我今天回？」

不适用（遇到时这样处理）：

- 「直接看我的邮箱、日历」→ 不接入任何账号；请把要点粘贴进来。
- 「帮我回复张经理 / 把牙医改到下午」→ 只到提醒和建议：可以拟回复草稿、写改约话术，发不发、改不改由用户决定。
- 消息里有体检异常、合同纠纷、投资提醒 → 不做医疗、法律、理财判断，只列为待办，并建议找医生、律师或持牌顾问。

## 先判断什么

1. **要哪种长度**：默认 2 分钟版；用户说「快速」「一句话」给 30 秒版；周一或提到「这周」给周一版。
2. **今天是哪天**：以用户说的日期为准，脚本用参数指定，避免隔夜或时区错位。
3. **材料够不够**：没有日程就不写时间段；只有一堆消息没有待办，先从消息里拆出待办（动作 + 截止 + 相关人）再排；拿不准的标 [待确认]。

## 优先级判断规则

- **截止时间**：逾期、今天到期的必须完成；影响大且明天到期的，今天不动手就来不及，也算必须。要别人审、签、付款的事，截止往前挪一天。
- **影响面**：问一句「今天不做，明天谁会来找我？」上级、客户、多人协作、钱、对外承诺标 `!`；只影响自己的不标。
- **依赖他人**：别人在等你（`@人名`），先做，做不完也先回个进度；你在等别人（`等:人名`），上午第一件事去催，并想好对方不回时的备选。
- **档内排序**：影响大 > 有人在等 > 截止更早。逾期的小事已经晚了，先保住今天还来得及的大事，再顺手清掉。
- **封顶**：必须完成超过 5 件就是排不下，列出来请用户砍或改期，不全塞进今天；会议之间不足 30 分钟的空档只放回复类小事。

## 流程：三步出简报

第 1 步，把待办整理成一行一件：`截止:9-24`（也认 `2026-09-24`、`9/24`、`9月24日`、`今天`、`明天`、`后天`），`!` 表示影响大，`@人名` 表示这个人在等你，`等:人名` 表示你在等他；全角的 `！`、`：` 也认；以 `10:00` 或 `10:00-11:00` 开头的行算日程。更多写法、怎么把消息拆成待办，见 [references/input-format.md](references/input-format.md)。

第 2 步，跑脚本出骨架。脚本只用 python3 标准库，按上面的规则排序、查时间重叠；第二个参数指定「今天」，加 `--week` 多出周一版要的「本周还要到期」：

```bash
python3 scripts/brief.py todo.txt 2026-09-24             # 2 分钟版骨架
python3 scripts/brief.py todo.txt 2026-09-24 --week      # 周一版：多出「本周还要到期」
python3 scripts/brief.py - 2026-09-24 < todo.txt          # 从标准输入读
python3 scripts/brief.py --demo                           # 用内置样例试跑（就是下面示例的输入）
python3 scripts/brief.py todo.txt 2026-09-24 --out 简报.md
```

第 3 步，把消息要点、天气并进骨架，按要的长度裁剪，再对照输出契约自查。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息（没给日程、没给待办、没说今天几号） | 没日程就不写时间段；只有消息就先拆成待办；日期没说就问一句，同时按本机日期先出一版并标 [待确认] | 「今天按 9 月 24 日周四出的，对吗？你没给日程，时间段一节先写（无）。」 |
| 格式看不懂（「截止:周五」、时间写成 25:00、结束早于开始） | 脚本把看不懂的列进「风险与冲突」并标 [待确认]，退出码 3；给两种理解请用户选 | 「"截止:周五"是这周五（9 月 25 日）还是下周五（10 月 2 日）？」 |
| 自相矛盾（两个会议时间重叠；同一件事两个截止日） | 写进「风险与冲突」，每个冲突给一到两个选项，不替用户决定 | 「10:30 牙医和周会重叠：改约牙医，或者周会只参加前半小时，选哪个？」 |
| 必须完成超过 5 件 | 排不下，列出来请用户砍或改期，不全塞进今天 | 「今天必须完成的有 7 件，排不下。哪两件可以改期？」 |
| 超出本技能范围（接入邮箱日历、代发消息、医疗法律理财判断） | 不接入、不代发；只列为待办，建议找专业人士 | 「我不读邮箱，把要点粘进来就行；需要回复的我先拟草稿，你来发。」 |
| 时间紧，只要最小可用版 | 给 30 秒版：一句话三件事，不超过 80 字 | 「30 秒版：先交预算表；10:30 牙医撞周会，改一个；合同卡在法务，上午催小王。」 |
| 用户坚持越界（「你直接替我回张经理」「帮我把牙医改到下午」） | 守住：不代发、不改日程；给草稿和改约话术 | 「改约要你本人在预约渠道操作；改约的话我先写好：……」 |

**脚本退出码与报错**

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 简报骨架已生成 | 并进消息要点和天气，按长度裁剪 |
| 3 | 有看不懂的日期或时间，已标 [待确认] 列进「风险与冲突」 | 跟用户核对后改写那几行，再跑一次 |
| 1（参数错误 / 待办为空） | 没给待办文件、文件是空的、「今天」的日期写错 | 按用法重跑；试跑用 `--demo` |
| 2（读取失败 / 写文件失败） | 待办文件不存在、没权限、编码认不出，或 --out 写不进去 | 检查路径、另存为 UTF-8；换个输出目录 |
| 130 | 按了 Ctrl+C | 重跑；先写临时文件再替换，不会留下半截文件 |
| python3 用不了 | 本机没有 Python 3 | 按优先级规则手排：先挑逾期和今天到期的，再按影响大 > 有人在等 > 截止早 |

## 输出契约

- 五段固定顺序：今天必须完成、有时间点的安排、需要回复的人、风险与冲突、一句话提醒；某段没内容写「（无）」，不删段。周一版在第 4、5 段之间多一段「本周还要到期」。
- 每条一行，事项在前，截止或相关人在后；每段最多 5 条，多出的写「其余 N 项见原清单」。
- 长度：30 秒版不超过 80 字，2 分钟版不超过 400 字，周一版不超过 700 字。
- 每条都能在用户材料里找到出处；推测的标 [待确认]；天气新闻只转述用户给的摘要，没给就不写。
- 一句话提醒必须是一个具体动作，不写空泛的鼓励。

占位符规则：`[待确认]` 用于推测的内容和看不懂的日期、时间（脚本输出同样用这个标记）；`[待补：会议地点]` 用于简报要用、但材料里没有的信息。

交付前自检（逐条答是/否，有「否」先改再交）：

- [ ] 五段齐全、顺序固定，没内容的写了「（无）」？
- [ ] 每条都能在用户材料里找到出处，推测的标了 [待确认]？
- [ ] 必须完成不超过 5 件，超过的已请用户砍或改期？
- [ ] 每个时间冲突都给了具体的解决选项？
- [ ] 字数没超：30 秒版 ≤80 字、2 分钟版 ≤400 字、周一版 ≤700 字？
- [ ] 一句话提醒是具体动作；没有复述手机号、证件号、账户？

## 示例

**示例（虚构场景）**：用户说「帮我理一下今天，这是我的待办和日程」，贴了下面的待办，另附消息要点与天气——张经理「预算表今天下班前要，附上季度对比」；小王「合同条款还在等法务回复」；物业「明天 9:00-12:00 停水」；天气小雨 18–24℃。

助手只问了一句「今天是 9 月 24 日周四吗？」，用户回「对」。

```text
- 交季度预算表 截止:9-24 ! @张经理
- 报销单补签 截止:9-23
- 课表调整回复 截止:明天 @李老师
- 合同终稿 截止:9-25 ！ 等:小王
- 整理发票 截止:9-30
- 学 Python 第三章
- 10:00-11:00 项目周会
- 10:30-11:00 牙医复诊
- 15:00 客户电话
```

存成 todo.txt，跑 `python3 scripts/brief.py todo.txt 2026-09-24` 出骨架（退出码 0），再并进消息和天气，得到 2 分钟版：

```text
# 晨间简报 2026-09-24 周四
## 今天必须完成
1. [今天][!] 交季度预算表——张经理下班前要，附上季度对比
2. [明天][!] 合同终稿——卡在小王等法务，今天先催
3. [逾期1天] 报销单补签——会议间隙清掉
## 有时间点的安排
- 10:00-11:00 项目周会
- 10:30-11:00 牙医复诊（与周会重叠）
- 15:00 客户电话
## 需要回复的人
- 张经理：预算表，问清「下班前」是几点
- 李老师：课表调整回复（明天截止）
## 风险与冲突
- 10:30 牙医撞上周会：改约牙医，或周会只参加前半小时
- 合同卡在两层依赖（小王、法务）：上午问清法务哪天回复
- 明天上午停水（物业通知）
## 一句话提醒
先交预算表，再催合同；有小雨，出门带伞。
```

30 秒版（同一份材料）：先交预算表（张经理下班前要）；10:30 牙医撞周会，改一个；合同卡在法务，上午催小王。

周一版：2 分钟版加上脚本 `--week` 输出的「本周还要到期」，用户提供了上周遗留和本周关键会议就各列一段。

更多示例：[examples/monday.md](examples/monday.md)（周一版：本周到期、上周遗留、时间冲突）、[examples/messages-only.md](examples/messages-only.md)（只有一堆未读消息、没有待办和日程时，怎么先拆成待办再出简报）。

**从示例提炼的最佳实践**：先确认「今天是哪天」再排；骨架交给脚本，人只做合并和裁剪；冲突一定带解决选项；消息里的原话（「下班前」「附上季度对比」）并进对应条目，不另起一段。

## 常见问题（FAQ）

**Q：能直接读我的邮箱、日历吗？**
A：不接入任何账号。把待办、日程、消息要点粘进来就行，材料里没有的不补、不猜。

**Q：待办很乱，要先整理成固定格式吗？**
A：不用。我先按一行一件拆好（动作 + 截止 + 相关人），拿不准的标 [待确认]；想自己写，格式见 references/input-format.md。

**Q：30 秒版、2 分钟版、周一版有什么区别？**
A：30 秒版一句话三件事（≤80 字）；2 分钟版五段（≤400 字）；周一版再加「本周还要到期」，有上周遗留和本周关键会议就各列一段（≤700 字）。

**Q：为什么逾期的小事排在今天到期的大事后面？**
A：逾期的小事已经晚了，先保住今天还来得及的大事，再顺手清掉。

**Q：必须完成的事太多怎么办？**
A：超过 5 件就是排不下，我会列出来请你砍或改期，不全塞进今天。

**Q：天气和新闻你会自己去查吗？**
A：不联网补。你给了摘要就转述一句，没给就不写。

**Q：能每天早上自动发给我吗？**
A：本技能不做定时推送。每天早上把材料贴进来就行，需要到点提醒的请用自己的日历或待办工具。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 把所有待办都塞进「今天必须完成」 | 排不下，最后哪件都没做完 | 只放逾期、今天到期、影响大且明天到期的；超过 5 件请用户砍 |
| 按材料原来的顺序排 | 重要的事被埋在后面 | 按影响大 > 有人在等 > 截止早排 |
| 只列冲突，不给解法 | 用户还得自己想 | 每个冲突给一到两个选项 |
| 自己补天气、新闻、日程 | 材料里没有的内容可能是错的 | 只转述用户给的，没给就不写 |
| 一句话提醒写成「今天也要加油」 | 没法执行 | 写一个具体动作：先交预算表 |
| 复述手机号、证件号、账户 | 简报会被转发、截图，泄露敏感信息 | 他人信息只留称呼和事由 |
| 心算日期和星期 | 隔夜、跨月、时区容易算错 | 用脚本并指定「今天」 |
| 替用户回复消息、改日程 | 越界，用户可能另有安排 | 拟草稿或改约话术，发不发由用户决定 |

## 边界与不做什么

- 不接入邮箱、日历、聊天账号，只处理贴进来的内容，不联网补天气和新闻。
- 「主动」只到提醒和建议：不代发消息、不改日程、不替用户回复；可以帮拟回复草稿，发不发由用户决定。
- 不做医疗、法律、理财判断：消息里有体检异常、合同纠纷、投资提醒，只列为待办，并建议找医生、律师或持牌顾问。
- 他人信息只留称呼和事由，不复述手机号、证件号、账户等敏感信息。
