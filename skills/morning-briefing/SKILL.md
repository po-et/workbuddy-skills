# 晨间简报

适用于每天早上花 2 分钟弄清「今天要紧的事」。输入只用用户贴进来的材料：待办、日程、未读消息要点，可选天气或新闻摘要。不接入任何账号，材料里没有的不补、不猜。

## 先判断什么

1. **要哪种长度**：默认 2 分钟版；用户说「快速」「一句话」给 30 秒版；周一或提到「这周」给周一版。
2. **今天是哪天**：以用户说的日期为准，脚本用参数指定，避免隔夜或时区错位。
3. **材料够不够**：没有日程就不写时间段；只有一堆消息没有待办，先从消息里拆出待办（动作 + 截止 + 相关人）再排；拿不准的标「待确认」。

## 优先级判断规则

- **截止时间**：逾期、今天到期的必须完成；影响大且明天到期的，今天不动手就来不及，也算必须。要别人审、签、付款的事，截止往前挪一天。
- **影响面**：问一句「今天不做，明天谁会来找我？」上级、客户、多人协作、钱、对外承诺标 `!`；只影响自己的不标。
- **依赖他人**：别人在等你（`@人名`），先做，做不完也先回个进度；你在等别人（`等:人名`），上午第一件事去催，并想好对方不回时的备选。
- **档内排序**：影响大 > 有人在等 > 截止更早。逾期的小事已经晚了，先保住今天还来得及的大事，再顺手清掉。
- **封顶**：必须完成超过 5 件就是排不下，列出来请用户砍或改期，不全塞进今天；会议之间不足 30 分钟的空档只放回复类小事。

## 流程：三步出简报

第 1 步，把待办整理成一行一件：`截止:9-24`（也认 `2026-09-24`、`今天`、`明天`），`!` 表示影响大，`@人名` 表示这个人在等你，`等:人名` 表示你在等他；全角的 `！`、`：` 也认；以 `10:00` 或 `10:00-11:00` 开头的行算日程。

第 2 步，跑脚本出骨架。脚本只用 python3 标准库，按上面的规则排序、查时间重叠；第二个参数指定「今天」，加 `--week` 多出周一版要的「本周还要到期」。

第 3 步，把消息要点、天气并进骨架，按要的长度裁剪，再对照输出契约自查。

```bash
cat > brief.py <<'PY'
import re, sys, datetime as dt
if len(sys.argv) < 2: sys.exit("用法：python3 brief.py todo.txt [2026-09-24] [--week]")
f, *opt = sys.argv[1:]
T = dt.date.fromisoformat(opt[0]) if opt and opt[0][0].isdigit() else dt.date.today()
def days_left(s):  # 距截止几天；没写或看不懂返回 99
    m = re.search(r"截止[:：](\S+)", s)
    if not m: return 99
    if m[1] in ("今天", "明天"): return int(m[1] == "明天")
    try: return (dt.date(*([T.year] + [int(x) for x in re.split("[-/]", m[1])])[-3:]) - T).days
    except (ValueError, TypeError): print("看不懂的日期:", m[1], file=sys.stderr); return 99
todo, cal, rep, risk, conf = [], [], [], [], []
for s in open(f, encoding="utf-8"):
    s = s.strip(" -*\n")
    t = re.match(r"(\d{1,2}:\d\d)(?:-(\d{1,2}:\d\d))?\s*(.*)", s)
    if t: cal.append((t[1].zfill(5), (t[2] or t[1]).zfill(5), t[3])); continue
    if not s: continue
    n, l, imp = re.sub(r"\s*(截止[:：]|等[:：]|@)\S+|\s*[!！]", "", s), days_left(s), bool(re.search("[!！]", s))
    todo.append((not imp, "@" not in s, l, n))  # 排序键：影响大 > 有人在等 > 截止早
    rep += [f"{p}：{n}" for p in re.findall(r"@(\S+)", s)]
    risk += [f"在等{p}：{n}，上午先催" for p in re.findall(r"等[:：](\S+)", s) if l <= 2]
must = sorted(x for x in todo if x[2] <= 0 or (not x[0] and x[2] == 1))
cal.sort(); last = None
for c in cal:
    if last and c[0] < last[1]: conf.append(f"时间冲突：{last[0]} {last[2]} 与 {c[0]} {c[2]}")
    if not last or c[1] > last[1]: last = c
if len(must) > 5: risk.append(f"必须完成 {len(must)} 件，超过 5 件，先砍或改期")
def tag(x):
    l = x[2]; k = f"逾期{-l}天" if l < 0 else ["今天", "明天"][l] if l < 2 else f"{l}天后"
    return f"[{k}]" + "[!]" * (not x[0]) + " " + x[3]
def sec(title, rows): print(f"## {title}\n" + ("\n".join(rows) or "（无）"))
print(f"# 晨间简报 {T} 周{'一二三四五六日'[T.weekday()]}")
sec("今天必须完成", [f"{i}. {tag(x)}" for i, x in enumerate(must, 1)])
sec("有时间点的安排", [f"- {a}{'-' + b if b != a else ''} {n}" for a, b, n in cal])
sec("需要回复的人", ["- " + r for r in rep])
sec("风险与冲突", ["- " + r for r in conf + risk])
if "--week" in opt:
    sec("本周还要到期", ["- " + tag(x) for x in sorted(todo, key=lambda x: x[2]) if x not in must and 0 < x[2] <= 7])
sec("一句话提醒", [f"先做「{must[0][3]}」。" if must else "今天没有硬截止，先做最重要的那件。"])
PY
```

## 完整示例

输入：上面的 todo.txt，加上用户贴的消息要点与天气——
张经理「预算表今天下班前要，附上季度对比」；小王「合同条款还在等法务回复」；物业「明天 9:00-12:00 停水」；天气小雨 18–24℃。

跑完第 3 步，得到 2 分钟版：

```text
# 晨间简报 2026-09-24 周四
## 今天必须完成
1. [今天][!] 交季度预算表——张经理下班前要，附上季度对比
2. [明天][!] 合同终稿——卡在小王等法务，今天先催
3. [逾期1天] 报销单补签——会议间隙清掉
## 有时间点的安排
- 10:00-11:00 项目周会
- 10:30-11:00 牙医复诊（与周会重叠）
- 15:00 客户电话
## 需要回复的人
- 张经理：预算表，问清「下班前」是几点
- 李老师：课表调整回复（明天截止）
## 风险与冲突
- 10:30 牙医撞上周会：改约牙医，或周会只参加前半小时
- 合同卡在两层依赖（小王、法务）：上午问清法务哪天回复
- 明天上午停水（物业通知）
## 一句话提醒
先交预算表，再催合同；有小雨，出门带伞。
```

30 秒版（同一份材料）：先交预算表（张经理下班前要）；10:30 牙医撞周会，改一个；合同卡在法务，上午催小王。

周一版：2 分钟版加上脚本 `--week` 输出的「本周还要到期」，用户提供了上周遗留和本周关键会议就各列一段。

## 输出契约

- 五段固定顺序：今天必须完成、有时间点的安排、需要回复的人、风险与冲突、一句话提醒；某段没内容写「（无）」，不删段。
- 每条一行，事项在前，截止或相关人在后；每段最多 5 条，多出的写「其余 N 项见原清单」。
- 长度：30 秒版不超过 80 字，2 分钟版不超过 400 字，周一版不超过 700 字。
- 每条都能在用户材料里找到出处；推测的标「（推测，待确认）」；天气新闻只转述用户给的摘要，没给就不写。
- 一句话提醒必须是一个具体动作，不写空泛的鼓励。

## 边界与不做什么

- 不接入邮箱、日历、聊天账号，只处理贴进来的内容，不联网补天气和新闻。
- 「主动」只到提醒和建议：不代发消息、不改日程、不替用户回复；可以帮拟回复草稿，发不发由用户决定。
- 不做医疗、法律、理财判断：消息里有体检异常、合同纠纷、投资提醒，只列为待办，并建议找医生、律师或持牌顾问。
- 他人信息只留称呼和事由，不复述手机号、证件号、账户等敏感信息。
