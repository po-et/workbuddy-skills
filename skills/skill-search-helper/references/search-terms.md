# 搜索词改写对照与规则

## 为什么要改写

平台搜索按字面匹配、不分词。实测「写请假条」只返回与请假条无关的补位技能，「请假条」才搜得到真正的请假条技能。所以不能拿用户原话直接搜，要先改写成名词。

## 改写规则

1. 去掉动词和客套：写、做、生成、帮我、好用的、有没有、能不能。
2. 保留对象名词：请假条、会议纪要、Excel、周报。
3. 补一个同义词、一个上位词，凑成 2–4 个词。
4. 用户说的是英文或缩写（PPT、PDF、OCR），原样保留，再补一个中文说法。

## 对照表

```
用户原话                        搜索词
帮我写个请假条                  请假条 / 请假申请 / 请假
把会议录音整理成纪要            会议纪要 / 录音转写 / 纪要
做一份给老板看的周报            周报 / 工作汇报 / 汇报
帮我处理一下这个 Excel 表格      Excel / 表格处理 / 表格
把 PDF 转成 Word                PDF / 文档转换 / PDF 转换
给孩子定个玩手机的规矩          手机管理 / 屏幕时间 / 亲子
剪一段录音                      音频剪辑 / 录音剪辑 / 音频
写一封道歉信                    道歉信 / 致歉 / 书信
```

对照表里的搜索词是改写示范，不代表这些词在平台上一定有结果；结果以当次搜索为准。

## 换词顺序

第一轮全是补位条目时，按这个顺序换词再搜一轮：

1. 同义词（请假条 → 请假申请）
2. 上位词（请假申请 → 请假、办公文书）
3. 相邻任务词（会议纪要 → 录音转写、会议记录）

三轮仍然没有，就如实告诉用户「没找到匹配的技能」，并说明换过哪些词。
