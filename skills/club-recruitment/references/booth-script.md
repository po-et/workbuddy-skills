# 摆摊：动线、排班、话术卡

## 动线示意（顺着人流方向摆）

```
人流方向 →→→→→→→→→→→→→→→→→→→→→→→→→→

   [招呼员]            （站在摊位前一两步，不拦路）

 ┌──────────────┬─────────────┬──────────┐
 │ 吸引区（最前）│ 讲解区       │ 登记区    │
 │ 作品、成品、  │ 1–2 人讲     │ 扫码填表  │
 │ 能上手的体验  │ 30 秒话术    │ 不堵正前方│
 └──────────────┴─────────────┴──────────┘
        [机动 / 拍照]（摊位侧后）
```

- 能上手的体验最吸引人：拍一张、弹一下、答一道题、试一件作品。
- 桌子别横在最前面挡住人，作品朝向人流。
- 登记区放在侧后，扫码的人不挡住后面想看的人。

## 30 秒话术卡

**开场（选一个，问和对方有关的问题）**

- 「同学，你平时[拍照 / 听歌 / 运动]多吗？」
- 「来试一下？[拍一张 / 弹一下 / 答一题]，十秒钟。」
- 「你是哪个学院的？我们社团[学院]的同学挺多的。」（只在属实时说）

**介绍（一句话）**

- 「我们是[社团名]，[一句话定位]。」

**具体活动（一句话，说新人能做的事）**

- 「新人第一个月会[活动一]、[活动二]，还有[活动三]。」

**邀请**

- 「感兴趣的话扫这个码报名，截止到[日期]。」
- 「不急着报的话，[周几]的公开活动欢迎来看看。」

**应答**

| 对方说 | 你答 |
|---|---|
| 「没时间」 | 「每周一次活动，大概[时长]，其余都是自愿参加的。」 |
| 「零基础」 | 「第一个月就是带新手的，[入门课的安排]。」（前提是真的有） |
| 「要交钱吗」 | 「一学期[金额]，用在[用途]。」或「不收费。」 |
| 「我再看看」 | 「好的，这张卡上有公众号，周六的公开活动欢迎来。」（不纠缠） |
| 「你们和 XX 社有什么区别」 | 「我们更偏[你们的特点]。两个都去看看，选适合你的。」（不贬低别人） |
| 「能加分吗」 | 「这个要看学校规定，我们不承诺。我们能给的是[真实收获]。」 |

**结束**

- 「谢谢你停下来看！」

## 注意

- 场地、时间、音响使用以团委或社团管理部门的通知为准。
- 不拉扯、不堵路、不强迫扫码；对方说不用了就停。
- 不在摊位上用纸质表格收集手机号；统一扫码填表，表单开头有隐私告知。
- 不贬低其他社团。
