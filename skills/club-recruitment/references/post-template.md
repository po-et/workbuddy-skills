# 招新推文与海报文字模板

方括号内换成你们的真实信息。照片、成员原话、往届数据必须真实，并征得本人同意。

## 推文七段模板

```
【标题】[用标题公式写 3 个备选，选一个]

【一句话我们是谁】
我们是[社团名]，一个[一句话定位，不超过 20 字]的社团。

【你能在这里做什么】
1. [具体活动一：时间频率 + 做什么 + 新人能得到什么]
2. [具体活动二]
3. [具体活动三]
（配 3 张真实活动照片，图注写清是哪次活动）

【我们想找什么样的你】
- [必要条件，例如：每周能参加一次活动]
- [欢迎的特质，例如：零基础也欢迎，只要愿意动手]
- [加分项，例如：会剪视频的同学可以直接加入后期组]

【时间投入与费用】
- 时间：[每周几次、每次多久；哪些是自愿参加的]
- 费用：[会费金额和用途；没有就写「无」]

【怎么报名】
扫描下方二维码填写报名表，截止时间：[日期 时间]。
[面试或试活动的时间安排]

【招新日程与联系方式】
- 摆摊：[日期、时间、地点]
- 公开活动：[日期、时间、地点，欢迎来看]
- 有问题：[社团公共邮箱或公众号留言]（不放个人手机号）
```

## 标题公式与更多示例（虚构）

| 公式 | 示例 |
|---|---|
| 身份召唤 + 具体收获 | 「理科生也能写诗：文学社第一课，写出你的第一首」 |
| 数字 + 场景 | 「每周两次夜跑，一学期一起跑完一个半马距离」 |
| 问题 + 反差 | 「不会下棋，也能进棋社吗？」 |
| 时间地点 + 行动 | 「周日下午，图书馆门口，来下你的第一盘围棋」 |
| 成员原话 | 「"我在这里第一次站上舞台"——话剧社新人手记」（本人同意后使用） |

写标题的规矩：不用「最」「第一」「100%」；不承诺加分、奖学金、保研；不贬低其他社团。

## 海报文字模板

```
[社团名]（大字）
[一句卖点，不超过 15 字]
[时间] · [地点]
[报名表或公众号二维码]
[一行小字：零基础欢迎 / 费用说明]
```

检查：站在 3 米外看，只看得清这四样东西就对了；二维码扫一次试试能不能打开；不要印会过期的群二维码。

## 发布前检查

- [ ] 标题没有绝对化用语和做不到的承诺
- [ ] 时间、地点、截止日期都写了，且和海报一致
- [ ] 费用写清楚了（没有就写「无」）
- [ ] 照片和成员原话都征得了本人同意
- [ ] 二维码能打开，报名表开头有隐私告知
- [ ] 至少一位没参与写作的成员通读过一遍，找错别字
- [ ] 平台的发布规则、功能以其官方文档为准（例如微信公众平台的运营规范）
