# 报名表、面试打分表与通知模板

## 报名表模板（最少必要信息）

表单开头放隐私告知：

```
你填写的信息只用于[社团名]本次招新的联系和面试安排，由[招新负责人职务]保管，不会提供给其他个人或组织。招新结束后[N]周内删除未录取同学的信息。有疑问请联系[社团公共邮箱或公众号]。提交即表示你同意以上用途。
```

| 序号 | 题目 | 题型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | 姓名 | 填空 | 是 | |
| 2 | 年级 | 单选：大一 / 大二 / 大三 / 大四 / 研究生 | 是 | 做成单选，统计才不乱 |
| 3 | 学院或专业 | 单选或填空 | 是 | 学院少的话做成单选 |
| 4 | 联系方式（手机号或微信号，填一个即可） | 填空 | 是 | 只留一个就够联系 |
| 5 | 意向部门 | 多选，最多 2 个 | 是 | 想区分先后，就拆成「第一志愿」「第二志愿」两道单选 |
| 6 | 学号 | 填空 | 按需 | 只有学校社团系统或第二课堂登记要求时才加，并写明用途 |
| 7 | 每周大概能投入多少时间 | 单选 | 选填 | |
| 8 | 相关经历或作品链接 | 填空 | 选填 | 零基础的可以不填 |
| 9 | 可以参加面试或试活动的时段 | 多选 | 选填 | |

不收：身份证号、家庭住址、家庭经济情况、照片、生日、宿舍号。

导出和保管：

- 导出的表格只在招新负责人之间传递，不发大群。
- 共享的在线表格只给负责人权限（设置方法以所用工具的官方帮助为准）。
- 招新结束后按告知的期限删除未录取同学的信息，并在负责人群里说一声「已删除」。

## 面试打分表

先定标准再面试，每条 1–3 分（1 = 不符合，2 = 基本符合，3 = 很符合）。

| 候选人 | 必要 1：[能保证每周一次活动] | 必要 2：[对社团内容有兴趣] | 必要 3：[愿意和人合作] | 加分 1：[相关基础] | 加分 2：[能贡献的技能] | 合计 | 备注 |
|---|---|---|---|---|---|---|---|
| [ ] | | | | | | | |

规则：必要条件有一条 1 分的，讨论后再定；加分项只用于名额不够时排序；不以外貌、地域、家庭背景打分。

## 面试或试活动通知

```
[姓名]同学你好！感谢报名[社团名]。
请在以下时段中选一个参加[面试 / 试活动]，[时长]左右：
① [日期 时间]  ② [日期 时间]  ③ [日期 时间]
地点：[地点]。请在[日期]前回复你选的时段。
有问题联系[社团公共邮箱或公众号]。
```

## 录取通知

```
[姓名]同学你好！欢迎加入[社团名][部门]！
第一次活动：[日期 时间]，[地点]，[活动内容一句话]。
请在[日期]前回复「确认加入」，我们会邀请你进新成员群。
```

## 未录取通知

```
[姓名]同学你好！感谢你报名[社团名]。这次名额有限，很遗憾没能录取。
我们的公开活动欢迎你来参加：[日期、地点]。下学期招新时也欢迎再来。
```

## 7 天回访（匿名，3 题）

1. 第一次活动，你最喜欢的是哪个环节？
2. 有没有让你觉得不舒服或没跟上的地方？
3. 接下来你最想做什么？
