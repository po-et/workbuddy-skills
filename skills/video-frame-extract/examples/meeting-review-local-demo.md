# 本地会议复盘素材演示（合成测试）

> 本例的输入是 ffmpeg 自带测试图案生成的 8 秒视频；2026-10-09 用技能 0.1.2 和本机已有的 ffmpeg 9.0.2 实跑。它没有真实会议、真实用户或腾讯服务调用。截图能辅助复盘画面，不能替代音频转写或证明会议结论。

## 可以完成的交付

用户已有且有权使用的录屏或腾讯会议本地导出视频，可以先在本机抽出 12 张图片和时间点，再生成一张 4×3 拼图。由用户确认内容与隐私后，将图片作为腾讯文档复盘稿的素材；本技能不登录、不上传、不编辑腾讯文档或腾讯会议。

下面演示的是本地素材准备这一步。真实材料换成自己的本地视频路径即可，命令在技能目录中运行。

## 1. 准备一个明确标注为合成的输入

依赖为已有的 Python 3.8+、ffmpeg、ffprobe。先确认 `ffmpeg -version`、`ffprobe -version` 能运行；本例不自动安装工具。

```bash
case_dir=$(mktemp -d "${TMPDIR:-/tmp}/synthetic-video-review.XXXXXX")
ffmpeg -hide_banner -nostats -n -f lavfi \
  -i "testsrc2=size=320x180:rate=12:duration=8" \
  -c:v libx264 -pix_fmt yuv420p -g 24 "$case_dir/synthetic-demo.mp4"
python3 scripts/frames.py probe "$case_dir/synthetic-demo.mp4"
```

实测参数：8.000 秒、12 帧/秒、320×180、旋转 0、yuv420p、96 帧。测试图案随时间变化，画面里没有会议信息。

## 2. 抽 12 张并生成对照表

```bash
python3 scripts/frames.py interval "$case_dir/synthetic-demo.mp4" \
  --count 12 --out-dir "$case_dir/frames"
```

实测输出：12 张 768×432 JPG 和 `frames/index.csv`。

## 3. 做一张拼图

```bash
python3 scripts/frames.py sheet "$case_dir/synthetic-demo.mp4" \
  --cols 4 --rows 3 --out "$case_dir/sheet.jpg"
```

实测输出：1300×556 JPG，137756 字节。大小取决于内容与工具版本，不能据此承诺真实会议视频的文件大小。

拼图从左到右、从上到下对应上面的 12 个采样时刻。0.1.2 的拼图与均分抽帧都使用 `round=up` 从第 0 秒起采样；图片本身没有时间文字，要将 `index.csv` 一起交付。

## 4. 交给下一步的最小材料

- `sheet.jpg`：快速看全貌。
- `frames/f_*.jpg`：需要看细节时使用。
- `frames/index.csv`：图片文件名与采样时刻。
- 输入说明：本例是合成测试；真实材料要说明视频来源、使用权限、是否有需遮盖的敏感画面。

不要从这份合成视频生成“真实会议纪要”。真实会议需要另有授权的转写文本与人工核对。

## 5. 如何核对成功

本次实跑用 ffprobe 核对了全部 12 张图片尺寸、CSV 的 12 行与文件名对应关系；对输入视频执行前后计算 SHA256，两次一致。场景抽帧默认阈值 0.3 在此连续测试图案上只有第一张，脚本会提示这个限制，所以本例选均分抽帧。

同一输出再次运行会先拒绝覆盖，连已有 `index.csv` 也保护。要保留上次结果就使用新目录；确认覆盖时才加 `--overwrite`。`--every` 预计超过 1000 张、`--rate 0`、`nan/inf`、时间 `1:61` 都会直接报参数错误。

0.1.2 回归检查覆盖正常抽帧、拼图和 GIF 可读取、拼图首格确为第 0 秒、已有输出保护、非法数值、超量抽帧、时间范围、dry-run 不写输出。运行方式（源码仓库根目录）：

