# 长文总结

定位一句话：**总结不是把原文按比例缩短，而是替一个具体的读者决定「哪些可以不读」。读者和用途没定，删什么都是瞎删。**

## 何时使用

用户这样说时用：

- 「帮我总结这篇文章」「这份报告讲了什么」
- 「压成 300 字，里面的数字别丢」
- 「我要跟领导转述，他只给我一分钟」
- 「四十页，明天开会我要表态」
- 「这几份材料说法不一样，帮我对一下」「帮我看看我写的总结有没有歪」

也就是：手上有一篇长文章、几十页的报告、一份会议材料或书里的一章，需要自己吃透、转述给别人，或者拿它来做决定时。原文长到一次读不完，按流程第 2 步先切块、再合并。

调用格式（可选，一次给全就不再追问）：`总结：《材料》；给谁：____；用途：决策 / 学习 / 转述；长度：100 / 300 / 1000 字；范围：全文 / 第__章`。

不适用：

- 合同、判决书、病历与检验报告、财务报表的效力、诊断含义或投资判断：只做结构导读，结论请找律师、医生或持证的专业人士（见文末边界）。
- 课程要求本人完成的读书报告、文献综述：可以帮你读懂原文、检查你写的总结有没有失真，正文由你自己写。
- 翻译全文、改写文风、续写：这些不是总结，直接说明，按用户真正要的另行处理。

## 先判断：谁读，读完要干什么

动笔前只问一个问题：「这份总结给谁看，他看完要做什么？」对方只说「随便总结一下」，就追问一句：「是你自己看、要讲给别人，还是要据此做决定？」仍然没有答案，按「转述」处理，并在摘要第一行写明这个假设。三种用途要的东西完全不同：

```
用途  读者真正要的        必须保留                          可以砍掉                    默认层级
决策  能不能做、代价多大  结论、关键数字、风险、成立的前提  背景铺垫、方法细节、作者感想  300字+未决问题
学习  为什么成立          概念定义、推理链、反例与适用边界  重复举例、客套话、轶事        1000字
转述  一分钟讲得清        一句话结论、最硬的一个数、一个例子  论证过程、次要分支、术语    100字
```

三种用途各多一道工序：决策用途把「成立的前提」逐条列出，请读者判断这些前提在自己的情境里是否成立；学习用途读完用自己的话把推理链复述一遍，复述不下来的地方就是没读懂，回原文重读那一块；转述用途最后出声念一遍，一分钟念不完就继续删。

还要看读者懂不懂行：懂行的读者保留术语、省掉解释；外行读者把术语换成一句白话，第一次出现时在括号里注上原词。

再看原文属于哪一类，它决定「一句话结论」该长什么样：

- 论证型（评论、研究、方案）：作者主张什么，加上最关键的前提。
- 数据型（调研、年报、统计）：最重要的那个数、变化方向、统计口径。
- 叙事型（案例、复盘、人物稿）：发生了什么、转折点在哪、作者从中得出什么判断。
- 说明型（制度、手册、操作指南）：谁在什么条件下要做什么，有哪些例外。
- 记录型（会议纪要、访谈转写）：按「定了什么、谁负责、何时完成、还没定什么」整理，不按发言顺序。

## 流程：六步从原文到三层摘要

```
1 定位  摘要第一行写「给谁：__；用途：决策/学习/转述；覆盖范围：全文/第__章」
2 切块  按原文小标题切；没有小标题就大约每1500字一块，编号P1、P2……（有页码用页码）
        每块写一行「这块在说什么」，此时只摘录，不评价、不合并；编号留着后面对账用
        图表单独成块：写一句「这张图想说明什么」，抄下它支撑结论的那个数
3 抽骨  找中心论点：多在开头、结尾，或「因此」「我们认为」「综上」之后
        列出支撑它的论据，每条标类型：数据、案例、引用、推理
        数据注明是作者自己调查的还是转引的；转引的写上转引自哪里
        单独圈出限定语：「截至」「样本为」「在……前提下」「可能」「初步」「部分」
4 摘数  数字原样照抄，带单位、时间、口径、位置；不自行换算，不改写成「约一半」
        非换算不可时两个都写：「原文37.6%，约四成」
5 分层  先写100字版，再扩到300字，最后到1000字；由短往长写，每一层都自洽
        反过来从长往短删，最容易删掉结论、留下铺垫
6 对账  摘要里每一句都要能指到原文位置；指不到的删掉，或标「（推断）」
        逐条核对限定语有没有带上、数字有没有抄错
```

中心论点拿不准时做个检验：把候选句放到最前面，看其余各块是不是都在支撑它。若有两三块和它无关，要么选错了句子，要么原文本来就有两个论点——那就如实写成两条结论，不要硬捏成一条。

字数用命令数，不靠目测（空白不算，汉字、数字、标点各算一个；上下浮动一成以内算达标）：

```bash
python3 -c "import sys;print(len(''.join(open(sys.argv[1],encoding='utf-8').read().split())))" summary_300.txt
```

超长材料一次读不完：每块先按四段式写一份小摘要，再把小摘要合并成总摘要；合并后回原文抽查三处数字，确认合并时没有走样。

## 模板：四段式，直接套

骨架：抬头两行（给谁、用途、原文；未覆盖）→【一句话结论】（不超过 40 字，主语是作者或报告）→【三条要点】（按读者用途排序，每条标位置）→【论据与数据】→【未决问题】。三层取舍：100 字版 = 一句话结论 + 最硬的一条依据；300 字版再加三条要点和最关键的一个限定条件；1000 字版再展开全部论据与数据、未决问题和原文导读。口头转述用 100 字版，按「结论、数字、例子、希望对方做什么」的顺序说。

填空模板全文、三层取舍表、多份材料对照格式、检查别人总结的批注格式，见 [references/four-part-template.md](references/four-part-template.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话 |
|---|---|---|
| 没说读者和用途 | 只问一句；仍没答案就按「转述」给 100 字版，第一行写明假设并标 [待确认] | 「这份总结给谁看？你自己看、讲给别人，还是要据此做决定？」 |
| 材料没给全或读不全（截断、附件没传、扫描件识别不清、图表读不到） | 如实写进「未覆盖」，列出缺哪几页；问要不要补传，不装作读完 | 「第 20–22 页是扫描图，数字认不清，我先写进『未覆盖』；能补一份清晰版吗？」 |
| 原文自相矛盾（前后数字对不上） | 不替原文选，两处说法并列写进未决问题，各带位置，标 [待确认] | 「原文第 12 页写 44%，第 30 页写 42%，两处我都列出来了，以哪个为准需要你或作者确认。」 |
| 用户的要求互相冲突（100 字，但每个数字都要留） | 指出冲突，给两个方案让用户选 | 「100 字放不下全部数字：①100 字只留最硬的一个数，另附数字表；②放宽到 300 字。选哪个？」 |
| 超出范围（合同效力、诊断含义、投资判断，或要我替作者下结论） | 只做结构导读，标出关键条款或指标在第几页；结论转交专业人士 | 「我可以标出关键条款在第几页，条款效力需要律师判断。」 |
| 时间紧，只要最小可用版 | 最小版 = 第一行（给谁、用途、覆盖范围）+ 一句话结论 + 最硬的一条依据（带数字和位置）+「未覆盖」一行 | 「先给你一句话结论和最关键的数字，完整版随后补。」 |
| 用户坚持越界（删掉作者写的局限、把「报告认为」写成事实、替课程作业写正文） | 守住边界，给能做的替代 | 「可以写得更短更有力，但『报告认为』这个主语不能丢，不然就成了替作者下结论。」 |
| 材料太长，一次读不完 | 按流程第 2 步切块，每块写小摘要再合并，合并后回原文抽查三处数字 | 「材料很长，我分块读：每块先出小摘要，最后合并，并抽查三处数字。」 |

## 输出契约

交付物按这个顺序，缺哪部分也保留标题并写 [待补]：

1. **抬头**：给谁、用途、原文与覆盖范围；下一行「未覆盖」，全部读完写「无」。用途没问到时写「默认按转述处理」并标 [待确认]。
2. **分层正文**：用户指定的层级；没指定按上表的默认层级，标出实数字数。
3. **四段式**：【一句话结论】【三条要点】【论据与数据】【未决问题】。
4. **按需追加**：决策用途列「成立的前提」；多份材料时，每份单独做四段式，最后加「几份材料之间的一致与冲突」，冲突处并列写出各自的说法和位置；需要时加「我的看法」，并注明是我的。
5. **结尾一句**：「需要其他长度可以直接说。」

规则：每个数字都带位置（页码、小节号或「第 N 段」），与原文一字不差；作者观点一律带主语，我的推断标「（推断）」，我的评价单列，不混进三条要点；读不全就明说，原文被截断、图表没读到、扫描件识别不清，都写进「未覆盖」；用户自己写了总结请我检查时，逐句对照原文，按下文九条失真标出问题，只改有问题的句子，并说明改动理由。

占位符：[待补] = 需要用户补的信息（缺的页、没传的附件、希望对方做什么）；[待确认] = 我的默认假设（读者、用途），以及原文里识别不清或前后矛盾的数字。

交付前自检（逐条答是或否）：

- [ ] 第一行写了给谁、用途、覆盖范围？
- [ ] 每个数字与原文一字不差，并带位置？
- [ ] 每个判断句都有主语（作者认为、数据显示、受访者表示）？
- [ ] 原文的限定条件（样本、时间、前提）带上了？
- [ ] 每一句都能指回原文位置，指不到的已删掉或标了「（推断）」？
- [ ] 字数用命令数过，在目标上下一成以内？

## 示例

**示例**（虚构材料）：小王拿到一份四十页的《社区团购用户调研》，要向李老师转述。

用户：「帮我总结这篇文章，我要跟领导转述，他只给我一分钟。」

读者（领导）和用途（转述）都已说清，不再追问，按默认给 100 字版。交付：

```
给谁：李老师（领导）　用途：转述　原文：《社区团购用户调研》，共40页；覆盖范围：全文
未覆盖：无

【100字版】（实数101字）
《社区团购用户调研》基于某市1200份线上问卷（P3）发现，半年内复购率从61%降到44%（P12），受访者最常提到的原因是配送时效（P15）；样本只覆盖一个城市，作者也承认问卷偏向年轻用户（P38）。

【一句话结论】《社区团购用户调研》发现半年内复购率从61%降到44%，样本限于某市线上问卷
【三条要点】
1. 半年内复购率从61%降到44%（P12）
2. 受访者最常提到的原因是配送时效（P15）；报告没有论证这就是复购下降的原因
3. 样本是某市1200份线上问卷，作者承认偏向年轻用户（P3、P38）
【论据与数据】
- 数字：复购率61%→44%（口径：半年内复购；起止月份原文未写 [待确认]；位置P12）
- 数字：问卷1200份（口径：某市线上问卷；位置P3）
【未决问题】
- 配送时效和复购下降之间是不是因果，原文没有论证
- 读者如果要行动，还缺：其他城市的数据

一分钟口头版：结论（复购率半年从61%降到44%）→ 数字出处（1200份问卷）→ 例子（受访者最常提到配送时效）→ 希望李老师做什么 [待补]
需要其他长度可以直接说。
```

同一份材料的失真版是「社区团购的用户正在流失，主要因为配送慢。」忠实版多出来的四样东西——主语、数字、位置、限定——正是总结最常丢的四样；失真版还把「受访者最常提到」偷换成了「主要因为」。

开会表态用的 300 字决策摘要（含「成立的前提」和「我的看法」）见 [examples/decision-brief.md](examples/decision-brief.md)。

## 常见问题（FAQ）

**Q：材料太长，一次读不完怎么办？**
A：按流程第 2 步切块，每块先写小摘要再合并，合并后回原文抽查三处数字；读不到的部分写进「未覆盖」。

**Q：能只给我三个要点吗？**
A：可以，三条要点就是四段式的第二段；但第一行（给谁、用途）和「未覆盖」不省，读者才知道这三条的边界。

**Q：为什么不能把 37.6% 写成「约四成」？**
A：换算会丢精度，有时连方向都会变；非换算不可时两个都写：「原文37.6%，约四成」。

**Q：能加上你自己的看法吗？**
A：可以，单列一栏「我的看法」并注明是我的，不混进三条要点。

**Q：几份材料能一起总结吗？**
A：能。每份单独做四段式，最后加一段「一致与冲突」，冲突处并列写出各自的说法和位置。

**Q：英文材料能总结成中文吗？**
A：能。数字照原文保留，术语第一次出现时在括号里注上原词。

**Q：能帮我写读书报告或文献综述吗？**
A：可以帮你读懂原文、检查你写的总结有没有失真；课程要求本人完成的正文由你自己写。

**Q：只给链接可以吗？**
A：打得开的链接按全文处理；打不开、要登录或要付费的，请把文字贴过来，我不绕过付费墙。

## 常见错误（反模式）

九种最常见的失真，交付前逐条自查：

| 错误做法（例子） | 为什么错 | 正确做法 |
|---|---|---|
| 观点写成事实：「报告认为 X」被写成「X」 | 读者会把作者的判断当成已证实的事实 | 每个判断句都要有主语：作者认为、数据显示、受访者表示 |
| 丢了限定条件：原文「在三家试点门店中，客单价提高12%」，摘要只剩「客单价提高12%」 | 局部结论被放大成整体结论 | 「截至」「样本为」「在……前提下」这类限定语原样带上 |
| 数字变形：百分点写成百分比；「最高」写成「平均」；48%写成「一半以上」 | 意思变了，48% 写成「一半以上」连方向都错了 | 数字原样照抄，带单位、口径和位置 |
| 相关写成因果：「用A的团队效率更高」被写成「A提高了效率」 | 原文没论证因果，摘要就替它下了结论 | 原文怎么说就怎么写，因果要有原文论证才写 |
| 按篇幅分配：原文十页背景、一页结论，摘要照这个比例 | 重要的内容被挤掉 | 按读者用途分配篇幅；一笔带过的风险提示可能要升格 |
| 夹带私货：自己的评价混进要点 | 读者分不清哪句是原文、哪句是你的 | 评价单列一栏「我的看法」，并说明是我的 |
| 删掉局限与反方：作者写的「局限」「不足」一节被当成客套话删掉 | 读者会高估结论的可靠性 | 保留作者写的局限，最关键的一条进 300 字版 |
| 照原文顺序罗列：按章节依次缩写 | 得到的是目录，不是总结 | 要点按读者用途排序，最重要的放第一条 |
| 挑最抓眼的句子：拿原文最吸引人的一句当结论 | 那句不一定是作者真正论证过的 | 用中心论点检验：放到最前面，看其余各块是不是都在支撑它 |

交付前再问自己三句：作者读到这份摘要，会不会说「我不是这个意思」？读者只凭这份摘要去行动，会不会踩到原文提醒过的坑？每个数字能不能在十秒内找到原文位置？

## 边界与不做什么

- 只总结给到的文本，不替作者补结论；原文没下的判断，不写成原文的判断。
- 忠实于原文不等于原文正确：本技能不替原文的事实背书；发现原文前后数字矛盾，写进未决问题。
- 合同、判决书、病历与检验报告、财务报表：可以做结构导读，标出关键条款或指标在第几页；条款效力、诊断含义、投资判断请找律师、医生或持证的专业人士，这里不给法律、诊疗或投资结论。
- 课程要求本人完成的读书报告、文献综述：可以帮你读懂原文、检查你写的总结有没有失真，正文由你自己写。
- 不帮忙绕过付费墙或版权限制获取原文；摘要不大段照搬原文，引用只取关键短句并标位置。
- 材料含个人信息或未公开内容时，先脱敏再处理。
