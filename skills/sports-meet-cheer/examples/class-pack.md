# 示例：广播站收齐一个年级的投稿，出投稿清单

> 示例（虚构）：年级、班级、作者都是编的；下面的脚本输出是用这份虚构稿件文件夹真实运行 `scripts/cheer_list.py` 得到的，未改动。

## 对话

**用户**：我是广播站的，高二年级交来一批运动会加油稿，规定每篇不超过 150 字（含标点）。帮我按项目整理个清单，看看哪些要退改，再估一下全念完要多久。

**助手**（先问）：三件事：稿子是什么格式——能不能每篇存成一个 .txt 放进同一个文件夹？文件开头有没有写「项目：」「班级：」？能不能请播音员先读一篇计个时，这样时长估得准？

**用户**：都在「高二年级投稿」文件夹里，大部分是 .txt，8 班交的是 Word。有的写了项目，有的没写。播音员读《800米-高二2班》用了 26 秒。

**助手**：先用那篇样稿校准语速，再出清单。

```bash
python3 scripts/cheer_list.py --calibrate 高二年级投稿/800米-高二2班.txt 26
python3 scripts/cheer_list.py 高二年级投稿 --cpm 189 --max-chars 150
```

## 助手交付：处理建议

**1. 退改（2 个班）**

| 班级 | 问题 | 建议 |
|---|---|---|
| 高二（3）班 | 超出上限 24 字 | 请该班删改后重交；下面的删改稿供参考，用不用由该班决定 |
| 高二（6）班、高二（7）班 | 两篇内容完全相同，可能抄自同一来源 | 请两个班各自重写，或说明情况；在弄清之前两篇都先不播 |

给高二（3）班的删改参考（实测 149 字，约 39 秒）：

```
四乘一百米，四个人，一根棒。
第一棒，起跑要快，把好势头交出去；中间两棒，每一次伸手，都是毫无保留的托付；最后一棒，接过所有人的期待，冲向终点。
接力比的从来不只是速度，还有默契——是一声「接」之后不回头的信任。
高二（3）班的队员们，棒在手里，队友在前方，全班在看台上。跑出你们的配合，跑出你们的速度！
```

退改通知（可直接发给班级宣传委员）：

```
[班级]宣传委员你好：你们班交的运动会加油稿[问题：超出 150 字上限 24 字 / 与其他班稿件内容相同]，请在[待补：截止时间]前修改后重交，每篇一个 .txt，开头写一行「项目：」。谢谢！——广播站
```

**2. 待确认（2 篇）**

- 《高二4班.txt》没写项目，按正文里的「横杆」推断为跳高，请向该班确认。
- 《高二6班-加油.txt》同样按正文推断为短跑；如退改重交，请让该班在开头补「项目：」。

**3. 未读取（1 篇）**

- 《团体操-高二8班.docx》是 Word 文件：请该班另存为 .txt，或由广播站复制正文存成 .txt 后重跑脚本。

**4. 其余可以直接播的（4 篇）**

短跑-高二1班、800米-高二2班、拔河-高二5班、检录通知。其中拔河稿是 GB18030 编码，脚本已自动读出，内容无误。

**5. 时长**

8 篇合计约 3 分 13 秒（按实测每分钟 189 字）；退改的两篇改完后请重跑一次脚本。播出顺序请按秩序册里各项目的比赛时间排 [待补：秩序册]。
