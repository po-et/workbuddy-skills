# 运动会加油稿

定位一句话：**加油稿是写给耳朵听的——短句、好读、有这个项目的画面；叫真实的名字，说真实的事；不贬低对手，不替人许诺名次。**

## 何时使用

用户这样说时用本技能：

- 「帮我写几篇运动会加油稿，100 字左右」
- 「给 800 米、接力、跳高各写一篇」
- 「我们班[同学]报了 1500 米，想写一篇只属于他的」
- 「广播站要检录通知、成绩播报、颁奖和闭幕的串词」
- 「交给广播站现场念的运动会通讯稿怎么写」（有些学校把这种现场短稿也叫通讯稿）
- 「收了几十篇稿子，想按项目统计字数和朗读时长」

不适用（遇到时这样处理）：

- 赛后发在校园网、公众号上的运动会新闻报道：转「通讯稿」技能。
- 广播站日常栏目稿、节目串词：转「广播稿」技能。
- 开幕式致辞、入场式长篇解说词：结构不同，本技能不给模板；可以借用下面「朗读节奏」的规则自己改。

## 第 1 步：先定三件事

| 要定的事 | 怎么问 | 用户不说时的默认 |
|---|---|---|
| 项目 | 哪些项目、哪个组别 | 用户点名的项目，每项 2 篇 |
| 篇幅 | 50、100 还是 200 字；广播站有没有限字 | 100 字档 |
| 对象 | 泛用稿，还是写给具体班级或同学 | 泛用稿，班级处留 [班级] |

## 三档篇幅：50 / 100 / 200 字

| 档位 | 写作目标字数（含标点） | 约读多久* | 结构 | 适合什么时候念 |
|---|---|---|---|---|
| 50 字 | 40–60 | 10–15 秒 | 一个动作画面 + 一句鼓劲 + 呼名 | 比赛进行中、项目间隙 |
| 100 字 | 85–115 | 20–30 秒 | 点题 + 两三句画面 + 收尾鼓劲 | 检录后、发令前 |
| 200 字 | 170–220 | 45–60 秒 | 场景 + 过程（起步—中段—冲刺）+ 精神 + 呼号 | 广播空档、项目开始前、稿件评比 |

\*按每分钟 200 字估算。这是经验估计值，没有经过测量；播音员语速差别很大，排播音时间前请实测（见下文脚本的 `--calibrate`）。

## 写给耳朵听：朗读节奏

- 句子短：一句 5–15 字，一口气读得完；长句拆成两三句。
- 押韵适度：句尾顺口就押，押不上不硬凑，更不为押韵改事实。
- 画面具体：写这个项目独有的动作（起跑、交接棒、腾空、出手、最后一圈），少用「精彩」「激烈」这类空词。
- 名字响亮：个性化稿里名字出现 2–3 次，开头和结尾各一次；多音字、生僻字在括号里标读音。
- 数字写成读法：「4×100 米」写成「四乘一百米」，免得播音员临场换算。
- 停顿记号：给播音员的版本可用「／」标短停、「／／」标长停，投稿评比版删掉。

## 分项目写作要点

| 项目 | 抓住什么 | 画面词 | 特别注意 |
|---|---|---|---|
| 短跑（100/200/400 米） | 爆发、瞬间 | 起跑线、枪声、冲线 | 比赛很短，50 字档最实用，发令前念完 |
| 中长跑（800 米及以上） | 坚持、节奏、最后一圈 | 呼吸、弯道、铃声 | 鼓励量力而行，可加一句「不舒服及时示意」 |
| 接力 | 默契、交接、托付 | 接力棒、交接区、四个人 | 写团队；不点名谁掉棒、谁慢了 |
| 跳远跳高 | 助跑—起跳—腾空，一次次尝试 | 踏板、沙坑、横杆 | 备一篇「这一跳没过，下一跳再来」 |
| 投掷（铅球、实心球等） | 力量与技术 | 蹬地、转体、出手、弧线 | 「别进投掷区」这类提醒放进串场稿 |
| 拔河 | 齐心、口令、后倾 | 一根绳、脚跟、口令 | 写全队，不写「把对手拽趴下」 |
| 团体操 | 整齐、精神面貌 | 队形、节拍、口令 | 写集体与练习，适合 200 字档 |

每个项目的要点展开和 2 篇示例（共 14 篇原创泛用稿，都标了脚本实测的字数和档位）见 [references/by-event.md](references/by-event.md)。

## 个性化稿：只用真实信息

写给具体同学或班级的稿子最打动人，也最容易写错。动笔前收齐：

1. 姓名与读音（多音字、生僻字标拼音），班级或部门，项目与组别；
2. 一两件真实的小事：训练时的一个习惯、上一届的表现、同学眼里的他——只写本人同意公开的；
3. 同学想对他说的一句话，原话最好。

规则：没给的小事不编，写 [待补：一件真实的小事]，或者改成只含班级、姓名、项目的「半个性化」版；不写伤病、体重、成绩排名、家庭情况等隐私，除非本人同意；不给压力（「全班就等你拿第一」）。

骨架（100 字档）：呼名 → 真实小事一句 → 项目画面两句 → 同学的话 → 呼名收尾。

## 串场短稿：检录、成绩、颁奖、闭幕

- 检录：项目、组别、检录地点、截止时间全部照秩序册或裁判组通知，同一条读两遍。
- 成绩播报与颁奖：只念裁判组确认的成绩单；「破纪录」须经组委会确认后再播。
- 闭幕：感谢裁判、志愿者和运动员，回顾只用真实结果，最后提醒有序离场。
- 安全提醒、赛程调整、失物招领：信息来自组委会；失物只说物品和认领地点，不念证件、手机里的个人信息。

可直接填空的串场模板见 [references/transitions.md](references/transitions.md)。

## 投稿清单脚本

把稿子存成 .txt（一篇一个文件）放进同一个文件夹，运行：

```bash
python3 scripts/cheer_list.py 稿件文件夹                              # 按项目分组，终端表格
python3 scripts/cheer_list.py 稿件文件夹 --max-chars 150 --format md --out 投稿清单.md
python3 scripts/cheer_list.py --calibrate 样稿.txt 26                  # 播音员读样稿用了 26 秒
python3 scripts/cheer_list.py 稿件文件夹 --cpm 185 --format csv --out 投稿清单.csv
```

- 项目怎么认：文件开头写一行「项目：800米」最准（同一段还认「班级：」「作者：」「标题：」「对象：」）；其次看文件名或子文件夹名（如「短跑-高一3班.txt」「接力/03.txt」）；再次按正文关键词推断，清单里标「请核对」；都认不出归「未分组」。
- 统计口径：字数含标点、不含空白；朗读字数只算汉字、数字、字母；预计时长 = 朗读字数 ÷ 每分钟字数 × 60。档位列是粗分：75 字以内算 50 字档，76–150 算 100 字档，151–300 算 200 字档，更长标「长稿」。
- 会标出来的问题：超出上限或不足下限、空文件、内容完全相同（撞稿）、非 UTF-8 编码（能读的自动读出并注明）、读取失败，以及 Word、PDF 文件（请另存为 .txt）。
- 同样的输入得到同样的清单：按文件名自然排序，不写时间戳。只读文件夹里的 .txt，只写 `--out` 指定的文件（先写临时文件再替换），不联网。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（项目、篇幅、对象） | 先问这三项；不答的按默认：点名的项目各 2 篇、100 字档、泛用稿，班级留 [班级] | 「先确认三件事：写哪些项目？每篇 50、100 还是 200 字？泛用稿还是写给具体班级或同学？」 |
| 个性化稿缺真实素材 | 先交半个性化版，小事留 [待补]；追问一两件真事 | 「我先写了不含具体事迹的版本。你告诉我一件他训练时的真事，我换进去。」 |
| 要求自相矛盾（50 字里要写起跑到冲刺全过程，还要点三个名字；标「跳高」内容却是跑步） | 指出矛盾，给两个选项 | 「50 字放不下全过程加三个名字：要么升到 100 字档，要么只写冲刺一个画面加一个名字，你选哪个？」 |
| 超出本技能范围（赛后新闻、栏目稿、致辞） | 转交对应技能 | 「赛后发校园网的报道用『通讯稿』技能更合适。」 |
| 时间紧，只要最小可用版 | 每个点名项目一篇 50 字泛用稿，加一条检录模板；个性化稿和 200 字稿之后补 | 「先给你每个项目一篇 50 字的，马上能交；专属稿等你给我素材再写。」 |
| 坚持越界（嘲讽对手、承诺夺冠、写同学伤病隐私、编成绩或纪录） | 不写；给同样有劲但合规的写法 | 「贬低对手的句子我不写，念出来伤人，也容易被广播站退稿；我把劲儿放在我们自己的冲刺上。」 |
| 名字读音、组别、比赛时间拿不准 | 标 [待确认]，提醒对照报名表或秩序册 | 「名字里这个字有两个读音，我先标了待确认，请问一下本人。」 |

脚本 `scripts/cheer_list.py` 的退出码与报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 统计完成；个别文件读取失败会列在清单末尾 | 按「需要处理」逐条改 |
| 1「参数错误」「需要大于 0 的数字」 | 选项写错；`--cpm` 或秒数不是正数；`--min-chars` 大于 `--max-chars` | 按提示改，或看 `--help` |
| 1「--out 不能是稿件文件夹里的 .txt」 | 输出会覆盖或混进稿件 | 换个位置，或用 .md、.csv |
| 1「样稿里没有可朗读的文字」 | 校准用的样稿是空的 | 换一篇正常的样稿 |
| 2「找不到文件夹」「不是文件夹」「没有 .txt 稿件」「找不到样稿文件」 | 路径不对，或稿子是 Word、PDF | 检查路径；把稿子另存为 .txt |
| 2「写不了输出文件」「输出目录不存在」 | 目录不存在或没有写权限 | 换一个能写的位置 |
| 清单里「读取失败」 | 文件既不是 UTF-8 也不是 GB18030，或已损坏 | 用记事本打开后另存为 UTF-8 |
| 130 | 按了 Ctrl+C | 重新运行；未完成的临时文件已清理 |

## 输出契约

交付物按这个顺序，不增不减：

1. **稿件清单**：项目 | 档位 | 篇数 | 泛用或个性化。
2. **稿件正文**：按项目分组；每篇标「项目／档位／字数（含标点）／约 N 秒」，个性化稿再标「对象：[班级][姓名]（读音）」。
3. **串场短稿**（用户要了才给）：事实全部用 [待补] 占位，注明「以秩序册、裁判组为准」；没要时写「未要求」。
4. **播音提示**：多音字与读音、停顿记号、哪几篇适合发令前念。
5. **待补 / 待确认清单**：真实小事、读音、本人是否同意公开、秩序册信息。
6. **投稿清单**（用了脚本时）：脚本原样输出；没用写「未统计」。

占位符规则：用户没给的事实写 [待补：……]；用了默认值或需要核对的写 [待确认：……]；泛用稿里的班级写 [班级]。字数以脚本或字数统计工具实测为准，不凭感觉估。

交付前自检（逐条答「是」才交）：

- [ ] 每篇字数落在所选档位的写作目标内（50 字档 40–60，100 字档 85–115，200 字档 170–220）？
- [ ] 没有贬低对手、承诺名次、施压、调侃身体或性别的句子？
- [ ] 个性化稿里每个事实都来自用户，并提醒了确认本人同意公开？
- [ ] 检录、成绩、颁奖信息全部是 [待补]，或来自秩序册、裁判组？
- [ ] 人名和多音字标了读音，或标了 [待确认]？
- [ ] 大声读一遍，没有一口气读不完或拗口的句子？

## 示例

示例（虚构：班级、人名、事迹都是编的，只演示写法）

**用户**：我们班小周报了男子 1500 米，想写一篇专属加油稿，100 字左右，再来一篇 50 字的。

**助手**（先问）：三件事：他的全名和班级，名字里有没有多音字？有没有一两件大家都知道的真事，比如训练时的习惯？这些内容他本人同意在广播里念吗？

**用户**：高二（5）班周子乐，「乐」读 lè。他每天早读前绕操场跑三圈，坚持了一个月。本人同意。同学们想对他说「子乐，我们在终点等你」。

**助手**交付：

```
【中长跑／100 字档／104 字／约 27 秒】对象：高二（5）班 周子乐（乐：lè）
高二（5）班的周子乐，一千五百米的赛道上有你！
一个月来，每天早读前，操场上都有你跑三圈的身影。
今天，把那些清晨攒下的力气，一步一步用出来。
最后一圈铃声响起时，别忘了，全班都在喊你的名字。
子乐，我们在终点等你！

【中长跑／50 字档／46 字／约 12 秒】对象：同上
早读前的三圈，你跑了一个月；今天的一千五百米，稳住节奏跑下来。周子乐，加油，我们在终点等你！
```

- 播音提示：「乐」读 lè；第三句前可长停，等运动员入场再念后两句。
- 待确认：比赛时间与组别以秩序册为准 [待补]；本人同意公开已由用户确认。
- 字数与时长：`python3 scripts/cheer_list.py` 实测，时长按默认每分钟 200 字（经验值）。

## 常见问题（FAQ）

**Q：一分钟能念多少字？**
A：默认按 200 字估，这是经验估计值，没有测量过。最准的办法是让你们的播音员读一篇样稿计时，用 `--calibrate 样稿.txt 秒数` 算出来，再用 `--cpm` 统计。

**Q：网上的加油稿能直接用吗？**
A：不建议。各班容易撞稿，评比时也看原创；按本技能的要点写，最好加一句你们班的真事。脚本能查出文件夹里内容完全相同的稿子。

**Q：能提对手班级吗？**
A：可以尊重地提，比如「对手很强，我们更要拼」；不写嘲讽、贬低的话。

**Q：押韵重要吗？**
A：顺口比押韵重要。能押就押，押不上就用短句和重复制造节奏，别为押韵硬凑词。

**Q：没有同学的具体信息，还能写个性化稿吗？**
A：能写半个性化版：班级、姓名、项目加项目画面，真事的位置留 [待补]，拿到素材再换。

**Q：能直接帮我投稿或者念稿吗？**
A：不能，本技能只写稿和统计；投稿、审核、播音由你和广播站完成。

**Q：广播站限每篇 100 字，怎么批量查？**
A：运行 `python3 scripts/cheer_list.py 稿件文件夹 --max-chars 100`，超出的会标「超出上限 N 字」。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 贬低对手（「让他们望尘莫及」「不堪一击」） | 伤人，违背体育精神，常被广播站退稿 | 把劲儿写在自己人的动作和坚持上 |
| 夸张承诺（「冠军非你莫属」「一定破纪录」） | 结果没出来就许诺，没做到反而尴尬 | 写过程和态度：「拼出你的最好成绩」 |
| 施压（「输了别回来」「全班的希望都在你身上」） | 把加油变成负担 | 写陪伴：「我们在终点等你」 |
| 鼓励带伤硬撑（「倒下也要冲过终点」） | 有安全风险 | 加一句「不舒服及时示意」 |
| 调侃身材、性别（「女生也能跑这么快」） | 刻板印象，伤人 | 只写动作、速度和坚持 |
| 编事迹、编成绩 | 当事人和同学都听得出，尴尬且失信 | 只用真事；没有就留 [待补] |
| 长句、生僻字、网络烂梗 | 播音员读不顺，听众听不清 | 短句、常用字，名字标读音 |
| 通篇「加油加油加油」 | 没有画面，听众记不住 | 写一个这个项目独有的动作 |
| 照抄网上现成稿 | 撞稿、评比失分 | 按要点自己写，加本班真实细节 |

## 边界与不做什么

- 不编运动员的成绩、经历、伤病；不写未经本人同意的隐私。
- 不写贬低对手、人身攻击、带歧视的稿；不写承诺名次、施压的稿。
- 成绩、名次、破纪录以裁判组、组委会公布为准；不提前播报未确认的结果。
- 不替用户投稿、审核或播音。
- 赛后新闻报道转「通讯稿」，广播站栏目稿转「广播稿」。
- 脚本只读指定文件夹里的 .txt，只写 `--out` 指定的文件，不联网。
