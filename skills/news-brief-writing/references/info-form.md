# 活动信息收集表

通讯稿写得准不准，取决于活动前后有没有把信息收齐。建议活动前把这张表发给负责拍照、记录的同学，按「活动前、活动中、活动后」三段填。**每一项都写依据**（通知、名单、签到表、录音、组委会公布），没有依据的留空，稿子里对应写 [待补]。

## 一、活动前（从通知、议程、嘉宾名单里抄）

| 项目 | 内容 | 依据 |
|---|---|---|
| 活动全称（含第几届） | | 通知 |
| 主办单位全称 | | 通知 |
| 承办、协办单位全称 | | 通知 |
| 日期、星期、起止时刻 | | 通知、议程 |
| 地点全称 | | 通知 |
| 主要环节（按议程顺序） | | 议程 |
| 出席嘉宾：姓名 + 职务（逐字照名单） | | 嘉宾名单 |
| 主办方说明的活动目的 | | 通知、主持词 |
| 投稿平台、截稿时间、字数要求 | | 编辑、宣传部门 |
| 审核人 | | 宣传部门 |

## 二、活动中（现场记录）

| 项目 | 记录要点 |
|---|---|
| 实际开始、结束时间 | 和议程不一致的，以实际为准 |
| 亮点候选 | 只记亲眼看到的：首次、破纪录、获奖、一个具体的场景 |
| 可用引语 | 原话 + 说话人姓名与职务 + 记录方式（录音／笔记／讲稿）；拿不准的标「大意」 |
| 互动情况 | 提问人数、举手人数等，只记数过的 |
| 照片清单 | 编号、画面内容、拍摄者、画面里有没有未成年人或服务对象、肖像同意状态 |

## 三、活动后（结果与审核）

| 项目 | 依据 |
|---|---|
| 结果：名次、成绩、获奖名单 | 裁判组、组委会公布的结果 |
| 参与人数 | 签到表、报名表；报名数和到场数分开写 |
| 破纪录、特别奖项 | 组委会的正式确认 |
| 会议形成的决定 | 以会议纪要为准 |
| 照片的同意状态复核 | 同意记录表 |
| 审核人意见 | 审核人 |

## 四、分活动类型的补充项

**运动会**：届数；项目数和参赛人数（秩序册）；团体总分名次（组委会公布）；破纪录项目、成绩和原纪录（组委会确认）；精神文明奖等集体奖项；开闭幕式讲话要点（讲话稿）；志愿者和裁判的人数（组委会）。

**讲座**：主讲人姓名、职务、单位（对照海报或邀请函）；讲座题目全称；主要观点，按录音或讲稿整理，分点记；互动问答的问题和回答要点；听众规模（签到表）。

**志愿活动**：服务机构全称，以及机构是否同意报道和拍照；服务对象的类别（写到「老人」「小朋友」即可，不写个人信息）；服务内容和时长（活动记录）；志愿者人数（签到表）；机构负责人或服务对象的反馈（原话，并确认同意引用、是否匿名）。

**比赛**：比赛全称和届数；主办单位；赛制与轮次；对手；比分或成绩；奖项名称（对照获奖名单）；教练或领队的话（录音）。

**会议**：会议名称；主持人；出席人员（按名单顺序）；议程；会议形成的决定和部署（以会议纪要为准，不自己概括拔高）。会议纪要本身是公文，转「公文写作」技能。
