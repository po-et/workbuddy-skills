# 投稿前自查（12 条）

交稿前逐条勾选；有一条答「否」，先改再交。

## 事实

- [ ] 1. 导语里有何时、何地、何人、何事和结果。
- [ ] 2. 活动全称、届数、主办和承办单位全称，与通知一致。
- [ ] 3. 嘉宾姓名和职务逐字对照名单；排序按主办方名单或本单位惯例。
- [ ] 4. 人数、名次、成绩与签到表、组委会公布的一致；报名数和到场数没有混用。
- [ ] 5. 同一个数字在标题、导语、正文里前后一致。

## 引语

- [ ] 6. 每条带引号的话都有出处（录音、笔记、讲稿、本人确认）；只记得大意的用了间接引语。
- [ ] 7. 没有「同学们纷纷表示」「受到广泛好评」这类没有出处的集体表态。

## 图片

- [ ] 8. 每张照片的肖像同意状态都清楚；未成年人和服务对象的照片符合同意范围。
- [ ] 9. 背景里的名单、屏幕、证件、车牌已处理；图片说明与画面对得上，写了摄影者。

## 文字与格式

- [ ] 10. 标题和导语没有套话（「圆满落幕」「金秋十月」「隆重举行」）。
- [ ] 11. 字数符合投稿平台要求；按统一口径数过。
- [ ] 12. 署名齐全：文、图、审核；需要审核的已经审核。
