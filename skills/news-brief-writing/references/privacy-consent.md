# 拍摄与发布前的隐私与肖像同意

原则：**拍之前让人知道，发之前让人同意，拿不准就不发正脸。** 本文是写作上的通行做法，不是法律意见；具体以本单位的宣传审核制度和个人信息保护、未成年人保护方面的法律法规为准，拿不准问宣传部门或法务。

## 1. 拍摄前告知

活动开始时，主持人或摄影同学说一句：

```
各位好，今天的活动会拍照，照片会用在[校园网／公众号／院报]的活动报道里。不希望出现在照片里的，请跟[摄影同学或工作人员]说一声，拍的时候我们会避开。
```

需要避开的人多时，可以约定一个简单标识（比如一张贴纸），拍摄时留意。

## 2. 未成年人

- **监护人同意**：按学校规定办；学校在学期初统一收过肖像使用同意书的，以学校记录为准，并留意同意的用途范围。
- **点名与照片**：不需要点名的，不写全名；需要点名表彰的（获奖、破纪录），在同意范围内写姓名和班级，配中远景的动作照，不配正脸特写。全名、班级和正脸特写三样不同时放出。
- **不发的信息**：学号、住址、联系方式、家庭情况、成绩排名。
- **不拍、不发的场景**：哭泣、受伤、摔倒、被批评、更衣，以及孩子明显不愿被拍的时刻。
- **学生摄影、学生记者**：同样遵守以上规则；稿件和照片由指导老师审核。

## 3. 服务对象（老人、病人、儿童、困难群众）

- **先机构，后本人**：先征得服务机构同意，再征得本人同意；本人无法表达意愿的，按机构的规定处理，不擅自拍摄发布。
- **匿名**：写到「一位老人」「一位小朋友」即可；本人同意引用原话时，也可以只写称谓不写姓名。
- **不发的画面**：能认出身份的正脸、门牌、床头卡、病历、药盒和药单、账本和证件。
- **构图**：拍志愿者和服务对象一起做事、平视交谈的场景；不拍居高临下的「施舍」式摆拍，不拍对方的窘态。

## 4. 同意记录表

| 照片编号 | 画面里的人 | 是否有未成年人 | 同意方式（书面／口头／学校统一） | 同意人 | 同意的用途 | 处理（原图／打码／换图） |
|---|---|---|---|---|---|---|
| 01 | | | | | | |
| 02 | | | | | | |

口头同意的，记下时间和同意人；用途超出当初说明的（比如从校园网改投到外部媒体），要重新征得同意。

## 5. 发布前检查

1. 每张照片的同意状态都能在记录表里查到。
2. 背景里的名单、电脑和手机屏幕、证件、车牌、门牌，已打码或换图。
3. 图片说明里的姓名、职务和画面对得上，合影按「前排左起」逐一核对。
4. 涉及未成年人和服务对象的照片，符合上面第 2、3 节。
5. 审核人看过稿子和照片。

## 6. 撤图与更正

- 有人提出撤图或更正：先回应、再核实、尽快联系编辑处理，不争辩。
- 事实写错了：按平台的规则更正，并在内部记录原因，下次核对时注意。
