# 通讯稿

定位一句话：**通讯稿要让没到场的人读完第一段就知道：谁、什么时候、在哪儿、做了什么、结果怎样——而且每个名字、数字和引语都经得起当事人核对。**

本技能的「通讯稿」指活动结束后发在校园网、公众号、院报、单位内网上的活动报道，以新闻消息的写法为主。运动会期间交给广播站现场念的短稿，有些学校也叫「通讯稿」，那其实是加油稿，转「运动会加油稿」技能。

## 何时使用

用户这样说时用本技能：

- 「学院办了一场讲座，帮我写篇通讯稿」
- 「校运会结束了，要写一篇报道投校园网」
- 「志愿活动的新闻稿怎么写？照片能不能发？」
- 「辩论赛拿了冠军，写一篇赛事报道」
- 「部门开了个会，要发一条会议新闻」
- 「帮我看看这篇通讯稿有什么问题」

不适用（遇到时这样处理）：

- 运动会现场广播念的加油稿、检录和颁奖串词：转「运动会加油稿」技能。
- 广播站栏目稿、节目串词：转「广播稿」技能。
- 会议纪要、通知、请示、报告等公文：转「公文写作」技能。
- 个人参加活动后的感想：转「心得体会」技能。
- 涉及事故、伤亡、纠纷、舆情的报道和回应：由单位宣传部门统一处理，本技能不写。

## 第 1 步：动笔前收齐 5W1H

| 要素 | 要问清什么 | 可靠的依据 |
|---|---|---|
| 何时 | 日期、星期、起止时刻 | 活动通知、议程 |
| 何地 | 场地全称 | 活动通知 |
| 何人 | 主办、承办单位全称；嘉宾姓名和职务（逐字核对）；参与规模 | 通知、嘉宾名单、签到表 |
| 何事 | 活动全称（第几届）、主要环节 | 通知、秩序册、议程 |
| 为何 | 主办方说明的活动目的 | 通知、主持词、讲话稿；不自己拔高 |
| 如何 | 流程、形式、亮点 | 现场记录、照片 |
| 结果 | 名次、成绩、成果 | 裁判组、组委会公布的结果 |

何时、何地、何人、何事和结果缺一项就不能发，先标 [待补] 再追问；为何、如何可以写得简略。活动前、中、后分别要记什么，以及运动会、讲座、志愿活动、比赛、会议各自的补充项，见 [references/info-form.md](references/info-form.md)。

## 第 2 步：用倒金字塔搭结构

标题 → 导语（最重要的事实：5W 加结果，一段 60–120 字）→ 正文（按重要性递减）→ 结尾（可省：后续安排或背景）→ 图片说明 → 署名（文、图、审核）。

篇幅：简讯 150–300 字，常规 500–800 字，重大活动 1000–1500 字；以投稿平台或编辑的要求为准。字数每次用同一个口径数（不含空白的字符，含标点），把正文存成文本后运行：

```bash
python3 -c "import sys; t=open(sys.argv[1], encoding='utf-8').read(); print(sum(1 for c in t if not c.isspace()))" 正文.txt
```

**标题公式**

- 单行实题：主体 + 动作 + 活动（+ 结果或亮点）。如「[学院]举办第[N]届[活动名称]」「[队伍]获[比赛全称][奖项]」「[单位]志愿者走进[社区]开展[服务内容]」。
- 主副标题：主题写活动中真实出现的亮点，副题写实题。如主题「[一句概括亮点的话]」，副题「——[主办方]举办[活动名称]」。
- 不要：只有「圆满落幕」「成功举办」；「史上最」「震撼」；标题里的数字和正文对不上。

**导语公式**

- 叙述式（最常用）：「[日期]，[主办单位]在[地点]举办[活动全称]。[参与者与规模]参加。[一句话结果或亮点]。」
- 亮点式：先写最有新闻价值的事实（首次、破纪录、获奖），再补时间、地点。
- 不要：以天气、季节开头（「金秋十月，丹桂飘香」）；以「为了进一步……」的长句开头；导语里没有结果。

更多标题、导语、结尾写法和套话替换表见 [references/headline-lead.md](references/headline-lead.md)。

## 第 3 步：正文按时间还是按亮点

| 活动类型 | 组织方式 | 理由 |
|---|---|---|
| 讲座、培训、会议 | 按时间：开场—主讲内容—互动—总结 | 读者想知道讲了什么，顺序就是内容的逻辑 |
| 运动会、比赛 | 按亮点：总成绩—精彩瞬间—其他项目 | 读者先关心结果 |
| 志愿活动 | 按服务内容：服务了谁—做了什么—效果 | 写清服务对象和实际效果，不夸大 |

每段只讲一件事，段首一句概括，段落之间按重要性往下排。

## 引语：只用真实说过的话

- 出处只能是：录音、现场笔记、讲话稿，或会后本人当面、书面确认。
- 写法：「……」+ 说话人姓名与职务 + 说／表示。记得意思、不是原话的，用间接引语，不加引号；条件允许时请本人过目。
- 不写：没有记录的「同学们纷纷表示收获很大」；替嘉宾补的总结语；把主持词当成嘉宾的原话。
- 没有真实引语就不写引语，通讯稿没有引语也成立。

## 图片说明

- 公式：谁 + 在做什么 +（何时何地，和导语重复的可省）+（摄影：[姓名]）。
- 合影写「前排左起：……」，名单逐一核对。
- 一句话，只写看得见的事实，不写「场面热烈」这类评价。
- 例：「[学院]院长[姓名]（左二）为获奖同学颁发证书。（摄影：[姓名]）」

## 拍摄与发布前：隐私与肖像

- **拍摄前告知**：活动开始时说明会拍照、用在哪里；不愿出镜的可以示意，拍摄时避开。
- **未成年人**：按学校规定取得监护人同意（学校统一收集过的，以学校记录为准）。不需要点名的不写全名；需要点名表彰的（获奖、破纪录），在同意范围内写姓名和班级，配中远景的动作照，不配正脸特写；不发学号、住址、联系方式；不拍、不发哭泣、受伤、被批评等场景。
- **服务对象**（老人、病人、儿童、困难群众）：先征得机构和本人同意；不发能认出身份的正脸、门牌、病历、药品；不拍居高临下的「施舍」式摆拍。
- **发布前再看一遍**：背景里的名单、屏幕、证件、车牌，打码或换图。
- **有人要求撤图**：尽快联系编辑处理。
- 以本单位的宣传审核制度和个人信息保护、未成年人保护方面的法律法规为准，拿不准问宣传部门。

告知话术、同意记录表、发布前检查细则见 [references/privacy-consent.md](references/privacy-consent.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（活动全称、时间地点、结果） | 先问三问：活动全称和主办单位？时间地点？结果或最重要的一个亮点？其余标 [待补] | 「先确认三件事：活动全称和主办单位是什么？哪天在哪儿办的？结果或最值得写的一件事是什么？」 |
| 嘉宾姓名、职务，单位全称拿不准 | 标 [待确认：请对照通知或嘉宾名单]，不猜职务 | 「嘉宾的职务我先标了待确认，请对照海报或嘉宾名单核一下，职务写错是通讯稿最常见的硬伤。」 |
| 信息互相矛盾（人数前后不一、名次和成绩对不上） | 指出矛盾，给两种理解，请用户按依据选 | 「你前面说 200 人参加，后面说签到 180 人——是报名 200、到场 180，还是其中一个数记错了？」 |
| 要写「领导高度评价」「同学们纷纷表示」，但没有原话 | 不写引语；改成事实陈述，或改成间接引语并标 [待确认：请本人过目] | 「没有记录的话我不写成引语。可以写他讲了哪几方面，或者你找到录音后再加。」 |
| 超出本技能范围（加油稿、栏目稿、会议纪要、事故通报） | 转交对应技能或宣传部门 | 「现场广播念的稿子用『运动会加油稿』技能更合适。」 |
| 时间紧，只要最小可用版 | 交 150–200 字简讯：标题 + 导语（5W + 结果）+ 一段亮点 + 署名，图片说明一条；[待补] 清单附后 | 「先给你一条 200 字的简讯，能马上投；嘉宾职务等标了待补，核对后再发。」 |
| 照片的肖像同意状态不清楚 | 先按「不发正脸」处理：换背影、远景或打码，标 [待确认：肖像同意] | 「这张有同学正脸，同意情况不清楚，我先建议换成背影照，确认后再说。」 |
| 坚持越界（发未取得同意的未成年人照片、夸大人数和效果、编引语） | 不做；给合规做法 | 「没取得同意的正脸照我不建议发，也不编引语。换一张背影照，稿子一样成立。」 |

## 输出契约

动笔前确认：活动全称与主办、时间地点、结果、嘉宾名单、可用引语及其出处、照片及同意状态、投稿平台与字数。缺哪项问哪项，一次不超过三个问题。

交付物按这个顺序，不增不减：

1. **标题**：主推一个，备选一个；主副标题写全。
2. **导语**。
3. **正文**。
4. **结尾**：没有就写「无」。
5. **图片说明**：每张一条，编号和照片对应。
6. **署名行**：文、图、审核，不知道的写 [待补]。
7. **核对清单**：人名与职务、单位全称、数字、引语出处、照片同意状态，每项写依据或 [待确认]。
8. **待补 / 待确认清单**。

占位符规则：用户没给的事实写 [待补：……]；需要对照通知、名单或本人确认的写 [待确认：……]；不猜职务，不编数字和引语。

交付前自检（逐条答「是」才交）：

- [ ] 导语里有何时、何地、何人、何事和结果？
- [ ] 人名、职务、单位全称都有依据，或标了 [待确认]？
- [ ] 每条引语都有出处（录音、笔记、讲稿、本人确认），没有出处的已删除或改为间接引语？
- [ ] 人数、名次、成绩和通知、签到表、组委会公布的一致，或标了依据？
- [ ] 每张照片都知道肖像同意状态，涉及未成年人和服务对象的符合规定？
- [ ] 标题和导语里没有「圆满落幕」「金秋十月」这类套话？

投稿前完整自查（12 条）见 [references/checklist.md](references/checklist.md)。

## 示例

示例（虚构：学院、人物、比赛都是编的，只演示写法）

**用户**：我们学院辩论队昨天拿了校园辩论赛冠军，帮我写条简讯发学院公众号，200 字左右。决赛在图书馆报告厅，对手是外国语学院，我们是正方，四辩拿了最佳辩手。

**助手**（先问）：三个问题：比赛全称、届数和主办单位是什么？最佳辩手的全名是什么，本人同意公开吗，有没有照片？有没有想引用的话——录音或笔记里的原话？

**用户**：第十二届校园辩论赛，校团委主办。四辩叫王一鸣，本人同意。照片是现场拍的颁奖照，队员都同意发。领队李老师赛后说「这个冠军是一场一场练出来的」，我手机录了。

**助手**交付：

```
标题：我院辩论队获第十二届校园辩论赛冠军
备选：一场一场练出来的冠军——我院辩论队获校园辩论赛冠军

[待补：日期]下午，由校团委主办的第十二届校园辩论赛决赛在图书馆报告厅举行。我院辩论队作为正方，战胜外国语学院代表队，获得冠军；我院队员王一鸣获评决赛最佳辩手。

本场决赛的辩题为「[待补：辩题全文]」。[待补：比赛过程中最值得写的一个细节，没有可删]

赛后，辩论队领队李[待补：老师全名]说：「这个冠军是一场一场练出来的。」

图片说明：[待补：颁奖嘉宾姓名、职务]为我院辩论队颁奖。（摄影：[待补]）

文／[待补]　图／[待补]　审核／[待补]
```

- 核对清单：比赛全称、届数、主办单位、地点、对手、正方、冠军、最佳辩手（用户提供；王一鸣本人同意公开）；引语出自用户手机录音；颁奖照队员均同意发布。
- 待补：日期、辩题全文、领队全名（职务如需写，请对照学院名单）、颁奖嘉宾、摄影、署名。结尾：无。
- 字数：去掉标题、署名和图片说明，正文约 160 字（含占位符）；补上辩题和比赛细节后约 200 字。

## 常见问题（FAQ）

**Q：通讯稿、新闻稿、消息有什么区别？**
A：校园和单位里常混着叫。本技能写的是以事实为主的活动报道，即消息的写法；需要人物通讯、长篇特写时，结构从倒金字塔改成故事线，但事实和引语的规矩不变。

**Q：没人给我原话，能不能写一句「嘉宾表示……」？**
A：不能编。可以写嘉宾讲了哪几方面（有笔记或讲稿为依据），或者找到录音后再加引语。

**Q：写多长合适？**
A：简讯 150–300 字，常规 500–800 字，重大活动 1000–1500 字；以投稿平台或编辑的要求为准。

**Q：照片里有学生正脸，能发吗？**
A：看是否取得同意和本校规定。拿不准时用背影、远景、动作照，或者打码、换图。

**Q：领导和嘉宾的名字怎么排？**
A：按主办方的嘉宾名单顺序或本单位惯例；不确定就问主办方或宣传部门，不自己排。

**Q：活动中有人受伤、出了意外，要不要写？**
A：不写进活动报道；涉及事故的信息由单位统一发布。

**Q：能直接帮我发到公众号吗？**
A：不能。本技能只写稿和自查，发布走你们单位的审核流程。

**Q：运动会期间交广播站的「通讯稿」怎么写？**
A：那是现场播报的加油稿，用「运动会加油稿」技能。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 以天气、季节或活动意义开头 | 读者读到第三句还不知道发生了什么 | 导语先给何时、何地、何人、何事和结果 |
| 标题只写「圆满落幕」「成功举办」 | 没有信息，也看不出是什么活动 | 标题写主体、活动和结果 |
| 编引语，或写「同学们纷纷表示」 | 当事人一看就知道没说过，失信 | 只用有出处的原话；没有就不写 |
| 嘉宾职务写错、排序凭感觉 | 最容易被追责的硬伤 | 对照通知或嘉宾名单，拿不准标待确认 |
| 所有环节平均用力，写成流水账 | 重点被淹没 | 讲座按时间、比赛按亮点，重要的放前面 |
| 堆形容词（热烈、精彩、圆满、隆重） | 空，读者不信 | 写一个看得见的事实 |
| 数字前后不一致 | 读者会怀疑整篇的真实性 | 数字统一到一个依据，发稿前再核一遍 |
| 不管肖像同意就发正脸照 | 侵犯隐私，未成年人尤其敏感 | 先确认同意，不清楚就换图 |
| 通讯稿里大段写个人感受 | 那是心得，不是新闻 | 感受放进心得体会，通讯稿只写事实 |

## 边界与不做什么

- 不编造引语、人数、成绩、评价和效果。
- 不写事故、伤亡、纠纷、舆情类的报道和回应，交宣传部门处理。
- 不替用户发布；发布前走本单位的审核流程。
- 不提供法律意见；肖像与个人信息问题按本单位规定和相关法律法规处理，拿不准问宣传或法务部门。
- 加油稿、广播栏目稿、公文、个人心得，分别转「运动会加油稿」「广播稿」「公文写作」「心得体会」。
