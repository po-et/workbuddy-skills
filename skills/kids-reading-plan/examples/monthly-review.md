# 示例：用阅读记录表做月度复盘

> 以下为示例。孩子情况、书名（《书名A》…《书名E》）为虚构；脚本输出是对这份示例记录表实际运行 `scripts/review.py` 的结果。

## 1. 用户提问

> 孩子 7 岁，八月每天睡前读，记录表在这里，帮我复盘一下，九月要不要调整？计划是每天 20 分钟。

记录表 `八月阅读记录.csv` 节选（共读、自主各记一行；共 44 行）：

```text
日期,书名,方式,分钟,读到哪,孩子说的一句话
2026-08-01,《书名A》,共读,10,第2章,
2026-08-01,《书名A》,自主,8,第2章,
2026-08-02,《书名A》,共读,10,第3章,
……
2026-08-29,《书名E》,共读,10,读完,
2026-08-29,《书名E》,自主,10,读完,还想看
```

## 2. 算四个数

运行：

```bash
python3 scripts/review.py 八月阅读记录.csv --plan-minutes 20
```

输出：

```text
复盘范围：2026-08（共 31 天）
1 读书天数 22 天（占 71%）
2 读书日平均 19 分钟
3 共读:自主 = 220 : 196（分钟）
4 读完 4 本，放弃 1 本（记录里出现过 5 个书名）

复盘提示（下个月最多改一处，由家长结合孩子的反应决定）：
- 数字上没有触发调整规则；再看三个问题和孩子的状态，决定是否保持不变
- 另外两条要靠观察：书名八成以上是同一类 → 加一本「同题材换体裁」；孩子开始抗拒 → 退回上个月的量
```

## 3. 助手追问三个问题

1. 这个月他最喜欢哪本？
2. 最不想再读哪本，为什么？
3. 九月他想读什么题材？另外，这五本书大多是同一类吗？

用户回答：最喜欢《书名B》；最不想读《书名C》，他说「太长了」，读到一半放弃了；九月想看讲火山的；五本里有四本是动物故事。

## 4. 助手交付：八月复盘单

```text
一、四个数（脚本算出）
  读书天数 22/31 天；读书日平均 19 分钟（计划 20）；共读:自主 = 220:196；读完 4 本、放弃 1 本
二、三个问题
  最喜欢：《书名B》   最不想读：《书名C》，「太长了」   九月想读：火山
三、九月只改一处：加一本讲火山的知识书，作为「同题材换体裁」
  理由：五本里四本是动物故事，已到「八成以上同一类」；天数和分钟都接近计划，其他不动
  选书：先借后买；这本书让他自己读一段，用五指法：2–3 根手指放进自主读，4–5 根放进共读
四、给孩子听的一句话
  「这个月你读了 22 天，最喜欢《书名B》，九月我们去找讲火山的书。」
五、保持不变：锚点睡前、每天 20 分钟、共读和自主各半（过渡期参考比例 6:4 → 4:6，参考区间）
六、待确认：火山书的具体书名 [待补：借到后发我按六条标准判断]
```

## 5. 这个示例说明了什么

- 四个数交给脚本算，结果可复查；同一本书共读、自主各记一行时，读完只算一次。
- 数字没有触发规则时，不为改而改；这次的调整来自家长的观察（八成同一类），而且只改一处。
- 放弃《书名C》不算失败：一个月只放弃一本，没有触发「放弃多」的提示，只需在选书时留意篇幅。
