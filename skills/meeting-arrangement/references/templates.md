# 会议模板：30／60 分钟议程、邀请文案、纪要、主持人话术

SKILL.md 里只放了规则和会议卡，可直接复制的整套模板在这里。方括号处替换；人名、会议室、链接都是占位符，用户没给的保留方括号，不替他编。

议程排时间用脚本，免得手算出错：把每项写成「议题|类型|负责人|分钟|产出」一行，存成 `agenda.txt`，再运行

```bash
python3 scripts/agenda_slots.py --length 30 --start 14:00 --file agenda.txt --title 决策会
```

## 1. 30 分钟 · 决策会

```
【30 分钟 · 决策会】目标：散会时确定上线日期
00–03  开场：目标和今天要做的决定               主持人   —
03–08  现状与选项（材料已读，只补充变化）        [小王]   确认 A、B 两个选项
08–23  讨论与决策                               决策人   选定方案及前提条件
23–27  风险与依赖                               [李老师] 风险清单与各自负责人
27–30  复述决定与待办                           记录人   待办表
```

对应的 `agenda.txt`（第一行 # 开头是注释）：

```
# 议题|类型|负责人|分钟|产出
开场：目标和今天要做的决定|开场|主持人|3|—
现状与选项（材料已读，只补充变化）|知会|[小王]|5|确认 A、B 两个选项
讨论与决策|决策|决策人|15|选定方案及前提条件
风险与依赖|讨论|[李老师]|4|风险清单与各自负责人
复述决定与待办|收尾|记录人|3|待办表
```

## 2. 60 分钟 · 多议题会

```
【60 分钟 · 多议题会】目标：散会时得到选定的方案和下季度排期
00–05  开场：目标、议程、规则（离题的先放进「待议区」）  主持人
05–15  议题一 知会：进展与数据，只讲变化和异常          [小王]    数据口径确认
15–35  议题二 讨论：方案取舍                            [李老师]  选定方案或待补信息清单
35–50  议题三 决策：排期与人手                          决策人    排期表
50–55  待议区：逐条定下是否另约、谁负责                  主持人    另约清单
55–60  复述决定与待办，约定纪要发出时间                  记录人    待办表
```

## 3. 邀请文案

```
【邀请文案】
标题：[决策] [项目名] 上线时间对齐｜30 分钟
时间：10 月 13 日（周二）14:00–14:30
地点：[会议室] ／ 线上：https://example.com/meeting/0000
目标：散会时确定上线日期和回滚预案负责人
议程：1 现状与选项  2 讨论与决策  3 风险与依赖  4 待办确认
会前请：读完附件《上线方案对比》（约 5 分钟）；[小王] 带上压测结果
决策人：[张经理]  记录人：[小李]
不能参加的，请回复并指定一位能代你表态的同事
```

跨时区的会，在「时间」一行写清各地时间；脚本加 `--date 2026-10-13 --also-tz Europe/Berlin` 可以换算，并提示落在对方 07:00 前或 21:00 后的时段。

## 4. 会议纪要

```
【会议纪要】[会议名] · [日期]
参会：    缺席：    记录：
决定
  D1 ……（前提 / 适用范围）
待办
  事项 | 负责人 | 截止 | 完成标准
待议
  Q1 ……  负责人 [ ]，[日期]前给结论或另约
跟进：[日期]在[周会]上过一遍待办状态
```

纪要在会后 24 小时内发出，发出前请决策人确认「决定」一栏的措辞，免得会后各自理解不同；每条待办在截止前一天提醒负责人，逾期的放在下次例会第一项过。

## 5. 主持人常用的几句话

```
跑题了      「这点值得谈，先放进待议区，会后由[小王]跟进」
一人说太久  「先停一下，听听还没发言的[李老师]怎么看」
卡住不动    「还剩 5 分钟，先按方案 A 定；谁有否决意见，现在说」
没人表态    「我们逐个过一遍：同意、反对还是需要更多信息」
线上会      提前 5 分钟开好会议室、试好共享屏幕；每个议题结束前，点名问一句还没开口的关键人
```

## 6. 不开会时的替代消息

```
主题：[事项]，请在[周三 18:00]前回复
背景：[两三句话说清现状]
需要你做的：[同意 / 提意见 / 补数据]，直接回复即可
默认处理：截止前没有异议，就按[方案 A]执行
```
