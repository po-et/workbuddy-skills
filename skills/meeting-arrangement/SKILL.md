# 会议安排

定位一句话：**一场会值不值得开，看散会时有没有多出一个决定，或者一张「谁在什么时候做完什么」的清单；两样都没有，这场会就不该开。**
何时用：要组织跨人或跨部门的讨论、评审、复盘、启动会，需要写议程、会前材料和邀请，或者拿不准一件事该开会还是发邮件时。本技能只产出文本，发邀请、订会议室、进日历由你自己操作。

## 第一步：先判断要不要开

```
逐题回答，任何一题答「是」就先别开，改用右边的办法
只是单向通知，不需要大家当场回应？          是 → 邮件或文档，附「有疑问请回复」
一个人就能拍板，只是想让大家知道？          是 → 决策人直接定，结果书面通知
意见可以各自写，不需要来回讨论？            是 → 在文档里评论收集意见
只和一两个人有关？                          是 → 直接找当事人聊
材料还没准备好，开了也只是「先碰一下」？    是 → 备齐材料再约
五题都是「否」，而且散会时能拿到一个决定、一份清单或一版方案，才开
```

不开会时，用这段消息代替：

```
主题：[事项]，请在[周三 18:00]前回复
背景：[两三句话说清现状]
需要你做的：[同意 / 提意见 / 补数据]，直接回复即可
默认处理：截止前没有异议，就按[方案 A]执行
```

## 第二步：目标、参会人、时长、议程、会前材料

目标只写一句：「散会时我们要得到____」。空里填的必须是一样东西——一个决定、一份排期、一张风险清单、一版方案。填不出来，回到第一步。

```
参会人按角色排，每个名字都要说得出为什么在场
决策人  有权拍板的那一个人；他来不了就改期，不要「先讨论着」
必需者  提供关键信息或负责执行的人
主持人  控时间、收口；尽量不兼记录
记录人  只记决定、待办和待议问题
知会者  不进会，会后收纪要
规模    经验上，要做决定的会尽量不超过 8 人；人更多就先小范围定，再大范围同步
```

```
时长
一个决定或一个问题   25–30 分钟
两三个议题           50–60 分钟
超过 90 分钟         拆成两场，或先用文档把「知会」部分消化掉
想给大家留出赶下一场的时间，可以设成 25、50 分钟，从知会项里压出这 5 分钟；跨时区的写清各地时间
```

议程每一项写五样：议题、类型（知会／讨论／决策）、负责人、时长、产出。决策项尽量放前面，趁大家注意力还在；前后有依赖的（先定方案才能排期）按依赖排；能写进材料的知会项不在会上念；最后 5 分钟固定留给复述决定与待办。

会前材料提前一个工作日发，最前面放一页摘要：背景、可选方案、推荐方案及理由、需要大家决定什么；标明「请会前读完」，会上不逐页讲；需要谁带着答案来的问题，点名写清。

不同类型的会，目标和议程骨架不一样，套下面的模板时把议题换成对应骨架：

```
类型        散会时得到                       时长       议程骨架
决策会      一个决定及其前提条件             30 分钟    选项 → 讨论 → 拍板 → 待办
头脑风暴    一张候选清单和筛选办法           45–60 分钟 讲规则 → 各自先写 → 轮流讲 → 归类 → 投票
项目复盘    三条能落地的改进及负责人         60 分钟    回顾目标 → 对比结果 → 分析原因 → 保持与改进 → 待办
启动会      分工、里程碑和沟通机制           60 分钟    背景目标 → 范围 → 分工 → 里程碑 → 风险 → 待办
站会        阻塞项清单                       15 分钟    每人说昨天、今天、卡在哪；细节会后单独约
```

复盘会先让每人独立写下看法再讨论，免得第一个发言的人定了调；只谈事和流程，不追究个人。

以上定下来的，写成一张会议卡，发邀请前先请决策人过目：

```
【会议卡】
会议：[项目名] 上线时间对齐        类型：决策会    时长：30 分钟    形式：线下加线上
目标：散会时确定上线日期与回滚预案负责人
决策人：[张经理]    主持：[小赵]    记录：[小李]
必需者：[小王]（压测数据）、[李老师]（风险与依赖）
知会者：[市场部]，会后收纪要
会前材料：《上线方案对比》，开会前一个工作日发出
```

## 模板：30／60 分钟议程与邀请文案

```
【30 分钟 · 决策会】目标：散会时确定上线日期
00–03  开场：目标和今天要做的决定               主持人   —
03–08  现状与选项（材料已读，只补充变化）        [小王]   确认 A、B 两个选项
08–23  讨论与决策                               决策人   选定方案及前提条件
23–27  风险与依赖                               [李老师] 风险清单与各自负责人
27–30  复述决定与待办                           记录人   待办表
```

```
【60 分钟 · 多议题会】目标：散会时得到选定的方案和下季度排期
00–05  开场：目标、议程、规则（离题的先放进「待议区」）  主持人
05–15  议题一 知会：进展与数据，只讲变化和异常          [小王]    数据口径确认
15–35  议题二 讨论：方案取舍                            [李老师]  选定方案或待补信息清单
35–50  议题三 决策：排期与人手                          决策人    排期表
50–55  待议区：逐条定下是否另约、谁负责                  主持人    另约清单
55–60  复述决定与待办，约定纪要发出时间                  记录人    待办表
```

```
【邀请文案】
标题：[决策] [项目名] 上线时间对齐｜30 分钟
时间：10 月 13 日（周二）14:00–14:30
地点：[会议室] ／ 线上：https://example.com/meeting/0000
目标：散会时确定上线日期和回滚预案负责人
议程：1 现状与选项  2 讨论与决策  3 风险与依赖  4 待办确认
会前请：读完附件《上线方案对比》（约 5 分钟）；[小王] 带上压测结果
决策人：[张经理]  记录人：[小李]
不能参加的，请回复并指定一位能代你表态的同事
```

## 第三步：会中记录、会后纪要与待办

```
会中只记三类
D 决定  「上线日期定为 10 月 20 日，前提是压测通过」
A 待办  事项 + 负责人 + 截止时间 + 怎样算完成
Q 待议  没谈完或离题的，写下谁负责、何时再议
主持人每到一个议题的时间就收口：「这项先定成 X，还有异议的会后找我」；拿不到决定的，写进 Q
```

```
主持人常用的几句话
跑题了      「这点值得谈，先放进待议区，会后由[小王]跟进」
一人说太久  「先停一下，听听还没发言的[李老师]怎么看」
卡住不动    「还剩 5 分钟，先按方案 A 定；谁有否决意见，现在说」
没人表态    「我们逐个过一遍：同意、反对还是需要更多信息」
线上会      提前 5 分钟开好会议室、试好共享屏幕；每个议题结束前，点名问一句还没开口的关键人
```

```
【会议纪要】[会议名] · [日期]
参会：    缺席：    记录：
决定
  D1 ……（前提 / 适用范围）
待办
  事项 | 负责人 | 截止 | 完成标准
待议
  Q1 ……  负责人 [ ]，[日期]前给结论或另约
跟进：[日期]在[周会]上过一遍待办状态
```

纪要在会后 24 小时内发出，发出前请决策人确认「决定」一栏的措辞，免得会后各自理解不同；每条待办在截止前一天提醒负责人，逾期的放在下次例会第一项过。

## 最常见的错误

- 议程只有标题（「讨论上线」），没写产出，开完不知道结论是什么。
- 决策人不在场，讨论一小时，结论是「再请示」。
- 材料会上才发，会上现念。
- 邀请只写「讨论一下」：别人不知道要准备什么，也判断不了自己该不该来。
- 人越拉越多，一半人只是旁听。
- 主持人兼记录人，两样都没做好。
- 只记讨论过程，不记决定。
- 待办写「大家跟进」——没有具体负责人，就是没人负责。
- 说好 30 分钟开了 50 分钟，后面的人全被拖住。
- 会后不发纪要，一周后每个人记得的版本都不一样。
- 例会从不回头审：每季度问一次，这个例会还要不要开、能不能缩短。

## 输出契约

1. 先问：要解决什么事、谁有权拍板、涉及哪些人、希望哪天前有结果、线上还是线下；缺哪项问哪项，一次不超过三个问题。
2. 先给判断：开还是不开，附一句理由；不开就直接给替代消息。
3. 要开就依次交付：会议卡（目标、决策人、参会人及角色、时长、形式）；议程表（时间、议题、类型、负责人、产出）；会前材料清单；邀请文案；会中记录模板；纪要模板。
4. 全部是可复制的纯文本或 Markdown；时间写到分钟，跨时区注明时区；链接和会议室只用占位符；用户没给的人名、日期、数据留成方括号，不替他编。

## 边界与不做什么

- 只产出文本：不发邀请、不订会议室，不接入、不读写任何日历、邮箱或会议系统，发送和预订由你自己操作。
- 不替你做业务决定；议程里的「推荐方案」由你或负责人填写，本技能只帮你把选项和取舍理清楚。
- 涉及绩效、辞退、劳动纠纷、投诉调查的谈话，先找 HR，按本单位制度准备；合同谈判、法律争议相关的会，请法务或律师参与。
- 股东会、董事会、业主大会这类有法定程序（通知期限、表决规则）的会，程序以章程和相关规定为准，找专业人士把关。
- 要录音录像的，提前告知参会人并遵守本单位规定；保密内容不写进邀请正文。
- 示例中的人名、会议室和链接都是虚构占位符。
