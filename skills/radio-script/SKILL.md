# 广播稿

定位一句话：**广播稿是写给耳朵的：听众不能回看，也不能放慢，一句没听清就过去了。所以句子要短，关键信息要说两遍，数字要写成念出来的样子。**
何时用：学校广播站的午间或课间广播、小区和社区的广播通知、企业早会或车间广播，要从零写稿，或把一份书面通知改成能直接念的稿子时。

## 先判断：谁在听、在哪听、播多久

| 场景 | 听众状态 | 写法重点 |
|---|---|---|
| 校园午间广播 | 边吃饭边听，教室里有杂音 | 每个栏目一到三分钟，有串词，多讲同学身边的事 |
| 社区通知 | 在家或在路上，多半只听一遍 | 什么事、什么时间、什么地点、要做什么放最前，结尾完整重复一遍 |
| 企业早会 | 站着听，赶着开工 | 三分钟以内，安全提示和当天重点放最前，表扬点到具体的人和事 |

动笔前问清：播出总时长；有没有片头片尾音乐和栏目间的垫乐；谁来念；现场念还是录好循环播放——循环播放的不写「今天」「明天」，写具体日期和星期几。

## 时长换算：三个步骤

```
第 1 步 测语速：请念稿人按播音时的速度念一分钟，数出字数。测不了就先按每分钟 200–240 字估（经验值，以实测校正）。
第 2 步 扣音乐：可用时长 = 总时长 − 片头片尾 − 栏目间垫乐 − 要整首播放的歌曲或录音。
第 3 步 算字数：正文字数 = 可用分钟数 × 语速 × 0.9（留一成给停顿和换气）。
例：10 分钟午间广播，片头片尾各 30 秒、垫乐两次各 20 秒，可用 8 分 20 秒；语速每分钟 220 字，正文约 1650 字。
```

写完核一次：音乐和动作提示单独一行、以全角括号「（」开头，不计入字数；参数依次是语速、音乐总秒数。


## 口语化改写：八条规则

```
1 短句：一句一口气念完，十五到二十字，一句只说一件事。
  改前：请全体参加下周三下午在操场举行的运动会开幕式的同学提前到场。
  改后：下周三下午，运动会开幕式在操场举行。参加开幕式的同学，请提前十分钟到场。
2 避开同音歧义：听起来一样、意思不同的词，换一种说法。
  期中/期终 → 期中/期末；全部及格/全不及格 → 都及格了/都没及格；
  终止/中止 → 彻底停止/暂时停下；致癌/治癌 → 会引起癌症/能治疗癌症。
3 数字读法：稿子里直接写成要念的样子。
  年份逐位念：二〇二六年；电话、房号、车次逐位念，「1」念「幺」，免得和「7」听混；
  大数写中文：一万两千五百人；百分之三点五；时间写「下午三点半」，不写 15:30；
  「两」和「二」：两个班、两点钟，但二年级、第二名。
4 单位和符号：km 写「公里」，℃ 写「摄氏度」，「10～15」写「十到十五」；/、%、& 都换成字。
5 书面词换口语：于→在，及→和，该→这个，拟→打算，须→需要，逾→超过，如下→下面几件事。
6 括号和简称：括号里的话要么念出来，要么删；听众不熟的简称，第一次出现说全称。
7 关键信息说两遍：时间、地点、要带的东西、联系电话，正文说一遍，结尾原样再说一遍；电话三四位一组，放慢念。
8 念前标注：多音字（重、长、行、还）和生僻的人名、地名在稿上注拼音；写完大声念一遍，卡壳的地方就是句子太长或词太拗口，拆短或换词。
```

## 开场、栏目串联、结束语

```
开场三句：问候（早上好/中午好）＋台名和日期（「这里是[台名]，今天是[月日，星期几]」）＋播音员和本期栏目（不超过三个）。
串联：一句收、一句开——「听完了[上一栏目的一个关键词]，我们来到[下一栏目]，[一句引子]」，三十字以内，不复述上一栏。
      例：「听完了操场上的好消息，我们回到教室。今天的班级故事，主角是一块黑板擦。」
结束语三件事：重复本期最重要的一条信息；预告下次播出时间；道别（「感谢收听，我们[时间]再见」）。
```

## 三类模板（方括号处替换）

```
【校园午间广播，10 分钟，双人】
（片头音乐 30 秒）
甲：老师们、同学们，中午好！这里是[校名][台名]，今天是[月日，星期几]。
乙：我是[班级][名字]。本期三个栏目：[校园新闻]、[班级故事]、[好书推荐]。
甲：先听校园新闻。[三到五条，每条三句以内：谁、什么时候、做了什么]
（垫乐 20 秒）
乙：听完了[关键词]，接下来是[班级故事]。[一位同学或老师的一件小事，约 600 字]
（垫乐 20 秒）
甲：最后是好书推荐。[班级][同学]推荐[书名]：[书里打动他的一个细节]，[推荐给谁、为什么]，约 300 字。
乙：再提醒一次：[本周最重要的通知，时间、地点重说一遍]。
甲乙：今天的广播就到这里，感谢收听，我们[下次播出时间]再见！
（片尾音乐 30 秒）

【社区通知，1 分钟以内，可循环播放】
各位居民，[小区名]物业通知：
[月日，星期几][上午几点]到[下午几点]，[几号楼到几号楼][停水]，原因是[更换水管]。请大家提前储水。
有急事请打物业电话：[三四位一组，逐位写出]。
再说一遍：[月日，星期几][上午几点]到[下午几点]，[几号楼到几号楼][停水]。谢谢大家配合。

【企业早会广播，3 分钟以内】
各位同事早上好，今天是[月日，星期几]，下面是今天的早会广播。
第一，安全提示：[哪个区域、什么风险、怎么做]。
第二，昨天的情况：[一到两个关键数字，写成念的样子]，比目标[多/少]了[多少]。
第三，今天的重点：[一件事＋负责人＋完成时间]。
第四，表扬：[班组或名字]，[做了什么具体的事]，[带来什么结果]。
最后再提醒一次：[重复安全提示]。早会广播到此结束，祝大家工作顺利、平安下班。
```

## 输出契约

1. 先问清：场景、播出总时长、音乐安排、念稿人、现场念还是循环播放；缺的事实写「[待补]」，不编时间、地点、电话和数字。
2. 交付：能直接念的稿子（数字、单位、符号都已改成读法）；一行时长估算；改用户现成的稿子时，附一张「原句 → 改后 → 理由」对照表。
3. 双人对播标好甲、乙和音乐位置；要重复的关键信息在稿子里原样写两遍，不写「同上」。

## 边界与不做什么

- 通知的事实（停水时间、检查安排、收费标准）以发布单位的正式通知为准：广播稿只改说法，不改事实，播出前由负责人核对。
- 不写虚假信息、未经核实的传言和商业推销；火灾、燃气泄漏、极端天气等紧急广播，按单位应急预案和有关部门发布的内容原样播报，不自行增减。
- 念学生或员工的名字前确认本人同意；表扬可以点名，批评不在广播里点名。
- 片头、垫乐和要播放的歌曲，用学校或单位已获授权的曲库。
- 电台、电视台的正式节目稿和商业广告词不在本技能范围。
