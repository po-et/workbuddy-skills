# 广播稿

定位一句话：**广播稿是写给耳朵的：听众不能回看，也不能放慢，一句没听清就过去了。所以句子要短，关键信息要说两遍，数字要写成念出来的样子。**

## 何时使用

学校广播站的午间或课间广播、小区和社区的广播通知、企业早会或车间广播，要从零写稿，或把一份书面通知改成能直接念的稿子时。用户这样说时用本技能：

- 「学校广播站让我写一期午间广播稿，10 分钟要写多少字」→ 先算字数，再按校园模板写
- 「小区要停水，物业让我写一条社区广播通知，怎么说大家才听得清」→ 社区通知模板，关键信息说两遍
- 「公司早会要播一段安全广播稿，帮我把书面通知改成口语」→ 按八条规则改写，附对照表
- 「帮我写个开场白 / 栏目串词 / 结束语」→ 只写这一段
- 「这篇稿子念出来太长，压到 3 分钟」→ 跑时长脚本，算出要删多少字

不适用：

- 电台、电视台的正式节目稿和商业广告词：不在本技能范围，说明后不接。
- 演讲稿、主持词、晚会串词：转演讲稿、主持稿类技能。
- 火灾、燃气泄漏、极端天气等紧急广播：按单位应急预案和有关部门发布的内容原样播报，不改写、不增减。

## 先判断：谁在听、在哪听、播多久

| 场景 | 听众状态 | 写法重点 |
|---|---|---|
| 校园午间广播 | 边吃饭边听，教室里有杂音 | 每个栏目一到三分钟，有串词，多讲同学身边的事 |
| 社区通知 | 在家或在路上，多半只听一遍 | 什么事、什么时间、什么地点、要做什么放最前，结尾完整重复一遍 |
| 企业早会 | 站着听，赶着开工 | 三分钟以内，安全提示和当天重点放最前，表扬点到具体的人和事 |

动笔前问清：播出总时长；有没有片头片尾音乐和栏目间的垫乐；谁来念；现场念还是录好循环播放——循环播放的不写「今天」「明天」，写具体日期和星期几。

## 时长换算：三个步骤

```
第 1 步 测语速：请念稿人按播音时的速度念一分钟，数出字数。测不了就先按每分钟 200–240 字估（经验值，以实测校正）。
第 2 步 扣音乐：可用时长 = 总时长 − 片头片尾 − 栏目间垫乐 − 要整首播放的歌曲或录音。
第 3 步 算字数：正文字数 = 可用分钟数 × 语速 × 0.9（留一成给停顿和换气）。
例：10 分钟午间广播，片头片尾各 30 秒、垫乐两次各 20 秒，可用 8 分 20 秒；语速每分钟 220 字，正文约 1650 字。
```

写之前用 plan 算字数，写完用 check 核一次。音乐和动作提示单独一行、以全角括号「（」开头，不计入字数；行首的「甲：」「乙：」和 [待补] 占位也不计入，占位会单独列出。check 还会指出还没改成念法的数字、符号和超过二十字的长句：

```bash
python3 scripts/broadcast_time.py plan --total 10m --intro-outro 60 --pads 40 --rate 220
python3 scripts/broadcast_time.py check script.txt --rate 220 --music 100 --target 10m
```

plan 的输出（本机实测）：

```
总时长 10 分 0 秒 − 片头片尾 1 分 0 秒 − 垫乐 40 秒 − 整首播放 0 秒 = 可用 8 分 20 秒
语速每分钟 220 字，留一成给停顿和换气
正文约 1650 字
```

## 口语化改写：八条规则

```
1 短句：一句一口气念完，十五到二十字，一句只说一件事。
  改前：请全体参加下周三下午在操场举行的运动会开幕式的同学提前到场。
  改后：下周三下午，运动会开幕式在操场举行。参加开幕式的同学，请提前十分钟到场。
2 避开同音歧义：听起来一样、意思不同的词，换一种说法。
  期中/期终 → 期中/期末；全部及格/全不及格 → 都及格了/都没及格；
  终止/中止 → 彻底停止/暂时停下；致癌/治癌 → 会引起癌症/能治疗癌症。
3 数字读法：稿子里直接写成要念的样子。
  年份逐位念：二〇二六年；电话、房号、车次逐位念，「1」念「幺」，免得和「7」听混；
  大数写中文：一万两千五百人；百分之三点五；时间写「下午三点半」，不写 15:30；
  「两」和「二」：两个班、两点钟，但二年级、第二名。
4 单位和符号：km 写「公里」，℃ 写「摄氏度」，「10～15」写「十到十五」；/、%、& 都换成字。
5 书面词换口语：于→在，及→和，该→这个，拟→打算，须→需要，逾→超过，如下→下面几件事。
6 括号和简称：括号里的话要么念出来，要么删；听众不熟的简称，第一次出现说全称。
7 关键信息说两遍：时间、地点、要带的东西、联系电话，正文说一遍，结尾原样再说一遍；电话三四位一组，放慢念。
8 念前标注：多音字（重、长、行、还）和生僻的人名、地名在稿上注拼音；写完大声念一遍，卡壳的地方就是句子太长或词太拗口，拆短或换词。
```

## 开场、栏目串联、结束语

```
开场三句：问候（早上好/中午好）＋台名和日期（「这里是[台名]，今天是[月日，星期几]」）＋播音员和本期栏目（不超过三个）。
串联：一句收、一句开——「听完了[上一栏目的一个关键词]，我们来到[下一栏目]，[一句引子]」，三十字以内，不复述上一栏。
      例：「听完了操场上的好消息，我们回到教室。今天的班级故事，主角是一块黑板擦。」
结束语三件事：重复本期最重要的一条信息；预告下次播出时间；道别（「感谢收听，我们[时间]再见」）。
```

## 三类模板（方括号处替换）

- **校园午间广播，10 分钟，双人**：片头 → 开场与栏目预告 → 校园新闻（三到五条）→ 垫乐 → 班级故事（约 600 字）→ 垫乐 → 好书推荐（约 300 字）→ 重复本周最重要的通知 → 道别 → 片尾。
- **社区通知，1 分钟以内，可循环播放**：谁通知 → 日期星期、起止时间、范围、事项、原因 → 要大家做什么 → 联系电话 → 原样再说一遍关键信息。
- **企业早会广播，3 分钟以内**：安全提示 → 昨天的情况（一到两个数字）→ 今天的重点（事＋负责人＋完成时间）→ 表扬 → 再提醒一次安全。

三类模板的逐句填空版见 [references/templates.md](references/templates.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键事实（日期、起止时间、地点、电话） | 只问最关键的三项：播出总时长、现场念还是循环播放、通知的时间地点；其余按模板默认（双人、片头片尾各 30 秒）写，标 [待确认]；事实缺的写 [待补]，不编 | 「先确认三件事：播多久？现场念还是录好循环播？停水的日期、时间和楼号是什么？其余我按常见安排先写，标了 [待确认]。」 |
| 用户坚持不给某个事实（「电话你随便写一个」） | 稿子照交，那处保留 [待补]，附一条「播出前必须补齐」的核对清单；说明带 [待补] 的稿子不能直接播 | 「电话我不能编，念错一个数字大家就打不通。稿子里先留 [待补]，播出前由物业负责人补上并核对。」 |
| 场景不在三类里，或没说场景 | 请用户在校园、社区、企业里选最接近的一类；没选就按最接近的写，标 [待确认] | 「这是医院候诊区的广播？我按『社区通知』的写法来：关键信息放最前、结尾重复一遍。要是更像早会，告诉我再调。」 |
| 时长或语速不合理（负数、0、音乐比总时长还长、3 分钟要写 3000 字） | 脚本会拦下并说明；指出矛盾，给两种理解 | 「总时长 3 分钟、音乐 200 秒，没有留给念稿的时间。是音乐只有 20 秒，还是总时长其实是 5 分钟？」 |
| 输入自相矛盾（循环播放却写「今天」「明天」；双人对播却只有一个念稿人） | 指出矛盾，给两种改法 | 「这条要循环播两天，『明天』到了第二天就错了。两种改法：写成『十月十五日，星期四』；或者只在当天播。」 |
| 超出范围（电台正式节目、商业广告、演讲稿） | 说明不做，转相应技能 | 「商业广告词不在我这里写；学校和社区的广播稿、通知稿我可以写。」 |
| 时间紧，只要最小可用版 | 最小版：开场一句 + 核心信息一段（什么事、什么时间、什么地点、要做什么）+ 关键信息原样再说一遍 + 结束一句，一分钟以内 | 「先给最小可用版：四句话，一分钟以内，关键信息说两遍；需要栏目和串词再加。」 |
| 用户坚持越界（点名批评、播未经核实的传言、加商业推销、紧急广播要「自己发挥」） | 守住边界，给替代 | 「批评不在广播里点名，我改成不点名的提醒；紧急广播请按应急预案原文播，我只帮你把数字写成念法。」 |

脚本报错对照（`python3 scripts/broadcast_time.py plan|check …`）：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 正常 | plan 的字数、check 的时长写进交付物 |
| 1，「参数不合理：总时长不能为负数」「语速必须大于 0」 | 时长、语速写成负数或 0 | 改成正数 |
| 1，「音乐加起来…不少于总时长」 | 音乐比总时长还长，常见于把分钟写成了秒 | 不带单位时：--total、--target 按分钟，音乐类参数按秒；或写 10m、30s |
| 1，「看不懂」「缺少必填参数」「请指定子命令」 | 时长写法不认识，或漏了 plan/check、--total | 写成 10m、8分20秒、500s、1:30 |
| 2，「找不到稿子」「只读纯文本」「无法识别编码」 | 路径不对，或给的是 .docx、PDF | 另存为 UTF-8 的 .txt 再试 |
| 3，「比目标…多…约需删 N 字」 | check 给了 --target，念稿超时 | 按提示删字，或删一个栏目 |
| 130，「已中断」 | 手动按了 Ctrl+C | 重新运行 |
| 提示「语速…不太常见」 | 语速不在每分钟 100–400 字之间 | 确认是「每分钟」而不是「每秒」 |
| 环境里跑不了脚本 | 只有对话、没有终端 | 手算：念稿秒数 = 汉字数 ÷ 语速 × 60，再加音乐秒数 |

## 输出契约

交付物按下面的顺序，每次都一样：

1. **能直接念的稿子**：数字、单位、符号都已改成读法；双人对播标好甲、乙和音乐位置；要重复的关键信息原样写两遍，不写「同上」。
2. **一行时长估算**：汉字数、念稿秒数、连音乐总秒数（语速注明是实测还是按经验值估）。
3. **[待补] 清单与播出前核对项**：缺的事实逐条列出，写明由谁补；事实以发布单位的正式通知为准。
4. **对照表**（改用户现成的稿子时）：「原句 → 改后 → 理由」。

占位符规则：[待补] = 只有用户或发布单位能提供的事实（时间、地点、电话、数字、人名），一律不编；[待确认] = 我按模板先定的安排（单人还是双人、音乐时长、栏目顺序）。带 [待补] 的稿子不能直接播。

交付前自检（每条都答「是」才交）：

- [ ] 没有一个数字、单位、符号还是书面写法（跑 check 没有「还没改成念法」）？
- [ ] 每句一口气念得完，没有超过二十字的长句（或已标出请念稿人试读）？
- [ ] 关键信息（时间、地点、要做什么、电话）在稿子里原样出现了两遍？
- [ ] 循环播放的稿子没有「今天」「明天」，写的是具体日期和星期几？
- [ ] 时长估算和总时长对得上？
- [ ] 所有 [待补] 都列进了核对清单，没有编任何事实？

## 示例

（示例，场景和事实都是虚构的；脚本输出为本机实测）

> 用户：小区要停水，物业让我写一条社区广播通知，怎么说大家才听得清？物业给的原文是：「接供水公司通知，定于10月15日9:00-15:00对3#~5#楼进行管网改造，届时将暂停供水，请各位业主提前做好储水准备，由此带来的不便敬请谅解。」

助手：先问两件事——现场念还是循环播放？物业电话是多少？

> 用户：录好在小区里循环播。电话我还没要到。

助手交付：

```
各位居民，幸福里小区物业通知：
供水公司要改造供水管道。十月十五日，星期四，上午九点到下午三点。三号楼到五号楼停水。请大家提前储水。
有急事请打物业电话：[待补]。
再说一遍。十月十五日，星期四，上午九点到下午三点。三号楼到五号楼停水。物业电话：[待补]。谢谢大家配合。
```

时长核对（本机实测）：

```
$ python3 scripts/broadcast_time.py check notice.txt --rate 220 --target 1m
汉字 106 | 念稿约 29 秒 | 连音乐约 29 秒
还有 2 处方括号占位（[待补] 等，不计入字数），播出前必须补齐：第 3 行、第 4 行
比目标 1 分 0 秒 少 31 秒，还可加约 102 字
```

| 原句 | 改后 | 理由 |
|---|---|---|
| 接供水公司通知……进行管网改造 | 供水公司要改造供水管道。 | 事实不变，书面词换口语，先说原因 |
| 定于10月15日9:00-15:00 | 十月十五日，星期四，上午九点到下午三点。 | 数字写成念法；循环播放要写星期几 |
| 对3#~5#楼……届时将暂停供水 | 三号楼到五号楼停水。 | 符号换成字；一句只说一件事 |
| 请各位业主提前做好储水准备 | 请大家提前储水 | 短句 |
| （无） | 再说一遍……物业电话：[待补]。 | 只听一遍的人要靠结尾重复，时间、楼号、电话都原样再说 |

原文跑 check 的结果：「还没改成念法的写法 8 处」「超过 20 字的句子 1 句（50 字）」，改后两项都清零。

播出前核对：物业电话 [待补]，按三四位一组写好，放慢念；停水时间和楼号以供水公司的正式通知为准，由物业负责人核对后再录；「星期四」是按今年日历推算的，录之前再对一次日历 [待确认]。

## 常见问题（FAQ）

**10 分钟要写多少字？** 先测念稿人语速，再扣掉片头片尾和垫乐：片头片尾各 30 秒、垫乐两次各 20 秒、语速每分钟 220 字时，正文约 1650 字。

**不知道念稿人的语速怎么办？** 请他按播音速度念一分钟数字数；测不了先按每分钟 200–240 字估，写完念一遍再校正。

**电话号码怎么写？** 逐位写成要念的样子，三四位一组，「1」念「幺」；结尾原样再说一遍。

**录好循环播放的通知要注意什么？** 不写「今天」「明天」，写具体日期和星期几；关键信息结尾原样重复。

**能在广播里批评某个班或某个人吗？** 表扬可以点名，批评不点名；念学生或员工的名字前先确认本人同意。

**垫乐可以用流行歌吗？** 用学校或单位已获授权的曲库。

**能帮我直接录音或配音吗？** 不能，交付的是能直接念的文字稿和时长估算。

**紧急通知（燃气泄漏、极端天气）怎么写？** 按单位应急预案和有关部门发布的内容原样播报，不自行增减；我只帮你把数字写成念法。

## 常见错误（反模式）

每条：错误做法 → 为什么错 → 正确做法。

1. **照搬书面长句** → 听众一口气记不住，后半句就漏了 → 一句十五到二十字，一句只说一件事。
2. **数字照书面写（15:30、10～15、3# 楼）** → 念稿人临场换算容易念错 → 写成「下午三点半」「十到十五」「三号楼」。
3. **符号和单位不改（km、℃、%、/）** → 念的人得停下来想 → 换成「公里」「摄氏度」「百分之」。
4. **关键信息只说一遍，或写「同上」** → 只听一遍的人没抓住就错过了 → 时间、地点、电话在结尾原样再说一遍。
5. **循环播放的稿子写「今天」「明天」** → 第二天播就错了 → 写具体日期和星期几。
6. **同音词不换（期中/期终、全部及格/全不及格）** → 听起来一样，意思相反 → 换成期中/期末、都及格了/都没及格。
7. **括号里的话和生僻简称照写** → 念出来别扭，听众听不懂 → 括号要么念出来要么删；简称第一次说全称。
8. **不念一遍就交稿** → 卡壳的长句和拗口词发现不了 → 大声念一遍，卡壳处拆短或换词；多音字注拼音。
9. **书面词不换（于、及、拟、须、逾）** → 听起来像公文，不像说话 → 在、和、打算、需要、超过。
10. **批评点名、念名字不打招呼** → 伤人，也可能引出纠纷 → 表扬可以点名，批评不点名；念名字前确认本人同意。

## 边界与不做什么

- 通知的事实（停水时间、检查安排、收费标准）以发布单位的正式通知为准：广播稿只改说法，不改事实，播出前由负责人核对。
- 不写虚假信息、未经核实的传言和商业推销；火灾、燃气泄漏、极端天气等紧急广播，按单位应急预案和有关部门发布的内容原样播报，不自行增减。
- 念学生或员工的名字前确认本人同意；表扬可以点名，批评不在广播里点名。
- 片头、垫乐和要播放的歌曲，用学校或单位已获授权的曲库。
- 电台、电视台的正式节目稿和商业广告词不在本技能范围。
