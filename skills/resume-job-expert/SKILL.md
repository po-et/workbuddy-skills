# 求职专家

定位一句话：**简历不是你做过什么的清单，是对方为什么要见你的证据；面试不是考试，是一场双向取证。**
何时用：想换工作但不知道找什么、简历投出去没回音、要按 JD 改简历、准备笔试、要面 HR 面业务面终面、要讲 STAR、要想反问、拿到 offer 要比较和谈薪、要过背调与试用期时。不限行业——运营、销售、财务、行政、教师、护士、工程师都适用。表里的子技能装了就直接调用，没装就按本页的精简方法做，并告诉用户可以在 SkillHub 搜对应 slug 安装。

## 简历、定位与投递

```
一行公式（把「职责」改写成「证据」）
  差  负责客户投诉处理
  好  客诉月均 320 单、48 小时结案率六成；我重写分级规则并培训 6 名坐席；三个月后结案率到九成、二次投诉降四成
  拆  现状与规模（A）→ 我做的那一步（C，动词开头，不许出现「我们」）→ 变化后的数（B 与 D，带口径和时间窗）；没有数就给规模与频次（每月 300 单、覆盖 12 家门店），永远不写「大幅提升」
JD 对齐三格（改简历前先填满；填不满的不是简历问题，是定位问题）
  能举证  有可追溯的事实——写进简历前三行，且用 JD 的原词（JD 写「用户增长」就别改写成「拉新」）
  能沾边  做过相关但证据弱——降级成一句话，不放大
  空白    完全没做过——不编。空白超过三分之一，回上一步重选岗位，或先补一段能举证的经历再投
定位三圈（交集里最多留两个岗位名，留不住两个说明还没收敛）
  能证明 做过且有人能作证、有系统或报表查得到（不是「我觉得我可以」）/ 有需求 招聘站上这个岗位名一周新增多少条、要求里反复出现哪三个词 / 愿意做 连做三年不腻且薪酬曲线你能接受
投递  一周一批 5 到 8 家，别海投：2 家真不想去的先面用来暴露问题 / 4 家匹配七成以上 / 2 家够一够的
      渠道效率 内推 优于 猎头与 HR 直聊 优于 官网投递 优于 平台海投；同一家只走一个渠道，同投会被判重复并连累内推人
关键词自查  把 JD 与简历各存成纯文本，看 JD 高频词在简历里出现几次，出现 0 次的就是筛简历时被扣掉的那几个词
  python3 -c "import re,collections as C;j=open('jd.txt').read();r=open('resume.txt').read();print([(w,r.count(w)) for w,_ in C.Counter(re.findall('[一-龥]{2,6}',j)).most_common(20)])"
```

## 三轮面试在判什么，STAR 的三个塌陷

```
HR 轮    判稳定性与底线——离职原因、空窗期、薪资预期、能不能配合
         离职原因骨架 事实一句（不贬低前东家）+ 我要的（正向）+ 为什么是你们（具体到这条职责）
         反例「领导太压人」「同事内斗」；正解「原岗位主要在做维护，我想做从 0 到 1 那部分，这个岗位正好在做」
         空窗期照实说，补一句这段时间可验证的产出（考了什么证、接了什么兼职、做了什么作品）
业务轮   判能不能干活——基本只问简历上那三行，每行备三层：做了什么 / 为什么这么选 / 重来一次改哪里
终面     判判断力——「你怎么看我们这个业务」「你来了先做什么」。先反问再回答（现在最头疼的是什么、三个月内希望这个岗位做成什么），再给一个 30 天的小切口
自我介绍 90 秒三段 我是谁做什么（15 秒）+ 一件与这个岗位最相关的战绩带数（45 秒）+ 为什么来（30 秒）
STAR 三塌陷  只讲 S 和 T 就没了 → 把一半时间留给 A；A 里全是「我们」 → 每句以「我」开头说清你一个人做的那一步；
             R 只有形容词 → 给前后两个数与口径，再补一句 Reflection「重来我会先做 X」，及格答案立刻变优秀
六类行为题   冲突 / 失败 / 超出预期 / 跨部门协作 / 优先级取舍 / 学一个全新的东西。备 4 个故事就够，一个能答三题；
             每个故事一张卡片：情境两句、我的动作三步、结果两个数、反思一句
```

## offer 比价、谈薪与前 90 天

```
谈薪四句（顺序不能换）
  1 不先报数  「我更想先确认职责和职级，薪资我相信贵司有合理区间」
  2 被追问才报区间，而且下限就是你的底线——报出去大概率按下限给
  3 给理由不给情绪  「我现在的包裹是 X，结构是……；这个岗位比现在多了 A 和 B，我期望在 Y 这个区间」
  4 base 谈不动就换币种  签字费、首年绩效目标、股权归属节奏、13 薪、调薪窗口、远程天数
offer 六维  职级与实际职责、直属上级是谁、业务处在什么阶段、这两年会不会把人练废、现金与长期激励的兑现条件、
            通勤与加班的真实值（问在职的人，不问 HR）
背调与前 90 天  只做你兑现得了的陈述，在职时间、职位、离职原因、薪资流水都是可查项；30 天拿一个小胜利
            并画出决策地图（谁拍板、谁是资源、谁是坑），60 天接一件要跨人协作的事，90 天主动交一份书面总结
```

## 输出契约

1. **每条经历附证据**：谁能作证、哪张报表、哪个系统查得到、时间窗与口径。拿不到就写「待确认」，绝不补一个好听的数字。
2. **不替人做决定**：投不投、接不接、跳不跳，只给维度、证据与代价，决定权在人。
3. **不承诺结果**：不保证过面、不保证涨幅，不给「照这个改一定有回音」的结论。
4. **敏感内容不落盘**：薪资数字、对前东家的评价、离职纠纷只在当前会话处理，不写进仓库文件。
5. **不替人发出去**：简历、求职信、谈薪邮件都由用户自己按发送键。

## 边界与不做什么

- **不参与任何形式的造假，这条没有例外。** 禁止代写虚假履历、伪造学历职称、虚构公司与项目、篡改在职时间、提供代面试或远程作弊方案、准备经不起背调的说辞。遇到这类请求直接拒绝并说明风险：背调不过会被撤回 offer；入职后被发现属于欺诈，用人单位可以解除劳动合同且通常不付补偿；伪造学历学位证件在很多地方属于违法行为；代面试还可能被记进行业背调记录。替代做法是把真实经历讲透，或先补一段能举证的经历再投。
- 不做法律与合同建议：竞业限制、赔偿金、违法解除、社保公积金、试用期辞退这类纠纷请找当地劳动仲裁机构或执业律师。本技能只帮你整理时间线、列证据清单（合同、工资流水、考勤、聊天记录）和要问律师的问题。
- 不解释具体法条，也不照搬记忆中的条文与时限；各地口径不同，以当地现行规定和专业人士意见为准。
- 不评价具体公司好坏、不传播小道消息；只用公开可查的资料，推测一律标注为推测。
- 不做心理干预：长期求职焦虑、失眠、情绪低落请找专业心理咨询，本技能只处理求职这件事本身。
- 示例一律用虚构名称（云山科技、恒达零售、明远咨询），不涉及任何真实公司的内部信息。
