# 新生自我介绍

定位一句话：**新生自我介绍不是展示你多优秀，而是让别人记住你的名字，再留一个能接话的点。** 名字 + 一个真实的记忆点 + 一句邀请，就够了。

## 何时使用

- 「开学班会要自我介绍，帮我写 1 分钟的」
- 「第一次见室友说什么，宿舍群发什么」
- 「社团第一次例会，新人轮流上去讲两句」
- 「研一第一次组会，导师让每人讲 3 分钟」
- 「被拉进新生群，怎么介绍自己」
- 「一上台就紧张忘词怎么办」

不适用（遇到时这样处理）：

- 学生会、社团面试里的自我介绍（要回答「为什么选这个部门」）：转「学生会面试」技能（`student-union-interview`）。
- 求职、考研复试、保研的自我介绍：看点不同，可以简答结构（身份 → 经历 → 动机），建议另找求职或复试类技能。
- 英文课上的自我介绍：可以套用同样的结构，但本技能不做英文润色。

## 第 1 步：认清场合

| 场合 | 听众 | 常见长度 | 重点 | 最容易踩的雷 |
|---|---|---|---|---|
| 班级见面会 | 三四十个同学、辅导员 | 30 秒–1 分钟 | 名字好记 + 一个钩子 | 背简历、报高考分数 |
| 宿舍 | 3–5 个室友 | 不是演讲，是聊天 | 作息、习惯、边界（几点睡、怕不怕吵） | 一见面就交底隐私，或给室友贴标签 |
| 社团 | 新成员、学长学姐 | 30 秒 | 为什么来 + 想学或能贡献什么 | 夸大水平 |
| 导师、实验室 | 导师、师兄师姐 | 1–3 分钟 | 本科背景、会什么、对什么方向感兴趣、能投入多少时间 | 空谈「对科研很感兴趣」 |
| 线上群 | 全班或全年级 | 3–5 行文字 | 姓名、专业、家乡、一个钩子；按群公告改备注 | 发手机号、宿舍号、自拍、生日 |

## 第 2 步：选长度（三档）

按每分钟约 200 字估算，并给停顿和紧张留出余量（经验值，语速因人而异，以你自己掐表为准）。字数口径同下面的命令：只数汉字、英文单词和数字，不数标点。

| 档位 | 字数 | 结构 |
|---|---|---|
| 30 秒 | 约 80–100 字 | 名字 → 一个身份信息 → 一个钩子 → 一句邀请 |
| 1 分钟 | 约 150–200 字 | 30 秒版 + 名字记法 + 把钩子讲成一个小故事 + 对这个集体的期待 |
| 3 分钟 | 约 450–600 字 | 1 分钟版 + 两段真实经历 + 我能帮大家的事 + 想认识什么样的人；分三段，段间停一拍 |

写完测字数和时长：

```bash
python3 -c "import re,sys;t=open(sys.argv[1],encoding='utf-8').read();n=len(re.findall(r'[\u4e00-\u9fff]|[A-Za-z]+|\d+',t));print(n,'字，约',round(n/200*60),'秒')" 自我介绍.txt
```

宿舍和线上群不按秒算：宿舍是「一句开场 + 聊天清单」，线上群是「3 行版 / 5 行版」，见模板。

## 第 3 步：设计一个记忆点

只用一个主记忆点，而且必须是真的。五种做法：

1. 名字记法：拆字、谐音、字的来历——拿自己的名字开玩笑可以，不拿别人开玩笑。
2. 具体爱好 + 细节：不说「喜欢运动」，说「每天晚上九点在东操场跑 5 公里」。
3. 一个 30 字以内的小故事：比如报到那天发生的一件小事。
4. 一样可以分享的东西：会修电脑、会剪视频、带了打气筒，「有需要找我」。
5. 一个邀请：给别人一个来找你说话的理由，比如「缺个夜跑搭子」。

检验：讲完后，别人能不能用一句话复述你？「那个每晚跑步、想找搭子的柳州同学」——能复述，就成功了。

## 第 4 步：套模板

五种场合的完整模板（含三档怎么扩写、压缩）见 [references/templates.md](references/templates.md)。班级见面会 1 分钟版：

```
大家好，我叫[姓名]，[名字记法]。
我来自[家乡]，[家乡的一个特点，一句话]。
平时我喜欢[具体爱好 + 细节]，[一个小故事或近况]。
[如果有：我会……，大家需要可以找我]。
希望这四年能和大家[一个具体的期待]。我是[姓名]，谢谢大家！
```

## 第 5 步：怯场应对

- 准备：只写 4 个关键词（名字、家乡、钩子、邀请），不写逐字稿；用手机录两遍，听一遍。
- 上场前：做几次呼气比吸气长的慢呼吸；手里拿张卡片或一支笔。
- 开口：第一句只说名字，说慢一点；眼睛看后排，或者看一张友善的脸。
- 忘词：直接说「有点紧张，我再说一遍我的名字：……」，然后跳到邀请那句收尾。
- 声音发抖：放慢语速、压低一点音调，比硬撑着快速讲完好。
- 讲完：别反复回想口误，大家通常只记得你的名字和那个钩子。

如果紧张到长期回避社交、影响正常生活，可以预约学校心理中心，这不丢人。

## 第 6 步：三个雷区

| 雷区 | 例子 | 改成 |
|---|---|---|
| 过度自夸 | 「高中拿过十几个奖，数学一直年级第一」 | 挑一件和听众有关的事，用平常语气讲 |
| 背简历 | 「毕业于某某中学，高考多少分，曾任学生会主席……」 | 讲一个具体的爱好或小故事 |
| 隐私过多 | 手机号、住址、家庭情况、健康状况、感情经历 | 只说姓名、专业、家乡、爱好这类可以公开的信息 |

另外避开：地域梗和学校鄙视链、用「我没什么好说的」开头、超时、只报游戏段位没有别的。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息（只说「帮我写个自我介绍」） | 先问 3 个：在哪讲、讲多久、一件你真实常做的事；姓名、家乡等先写 [待补]，场合不明写 [待确认] | 「先告诉我三件事：在哪讲（班级、宿舍、社团、组会还是群里）、要讲多久、你最近真实常做的一件事。名字和家乡我先空着。」 |
| 场合和长度矛盾（群里发要 3 分钟；宿舍要一篇演讲稿） | 指出不匹配，给两种理解 | 「群里一般发 3–5 行字，3 分钟太长——你要的是[群里发的文字版]，还是[当面讲的 3 分钟稿]？」 |
| 说自己「没爱好、很普通」 | 用问题挖：最近一周做得最多的事、周末怎么过、手机里用得最多的功能；从中挑一个真实细节 | 「不用是特长，真实就行。你最近一周做得最多的一件事是什么？」 |
| 要求编造经历、特长或夸大奖项 | 拒绝编造，给真实版本；用户坚持也不改 | 「编的东西别人一接话就露馅，这个我不写。我们用你真有的：……」 |
| 超出范围（面试、复试、求职的自我介绍） | 简答结构，转对应技能 | 「面试的自我介绍要回答『为什么选你』，我先给你结构：……细节建议用面试类技能。」 |
| 时间紧（马上就要上台） | 最小版：名字 + 专业家乡 + 一个钩子 + 一句邀请，外加一句忘词救场 | 「来不及写长的，先记这四句：我叫……；……专业，……人；我平时……；希望和大家……。」 |
| 想在大群发手机号、宿舍号、证件照 | 提醒隐私与诈骗风险，建议只写姓名专业家乡，联系方式私聊再给 | 「大群人多、也可能混进陌生人，手机号和宿舍号建议私聊再给。」 |
| 想让我替室友或同学写，但没有对方的信息 | 只写能由本人提供信息的部分，其余留 [待补] | 「可以给他们各写一份，但要他们自己提供真实信息，我不替别人编。」 |

## 输出契约

交付物按以下固定顺序给出：

1. 场合卡：场合、听众、目标时长；缺的写 [待确认]。
2. 正文：按所选档位写；标注字数和预计时长。
3. 记忆点说明：用了哪个钩子、来自你提供的哪条信息。
4. 关键词卡：4 个词，用于脱稿。
5. 相邻档位（可选）：压缩版或扩展版。
6. 怯场提示：针对你情况的 2 条。

占位规则：姓名、家乡、爱好等用户没给的写 [待补：……]；场合或时长不确定写 [待确认]；不出现用户没提供的经历、奖项、数字。

交付前自检（逐条答是/否）：

- [ ] 名字在开头出现；1 分钟及以上的版本结尾再说一次？
- [ ] 字数落在所选档位范围内（用上面的命令测过）？
- [ ] 只有一个主记忆点，且来自用户提供的真实信息？
- [ ] 没有手机号、住址、证件号、家庭经济、健康、感情等隐私？
- [ ] 没有地域梗、贬低他人或学校的说法？
- [ ] 示例人物标了「示例（虚构）」？

## 示例

示例（虚构）。用户：「明天班级见面会，每人 1 分钟。我叫林小舟，广西柳州人，计算机专业，喜欢夜跑。」

助手问两个问题：「① 夜跑一般几点、在哪、跑多远？② 为什么选计算机，或者最近在做什么和专业有关的事？这两个细节会让大家记住你。」用户：「晚上九点左右，东操场，五公里，想找个搭子。高中自己做过一个背单词的小程序，给同桌用过，想在大学里学得更系统。」

交付：

> **场合卡**：班级见面会｜同学和辅导员｜1 分钟
>
> **正文（约 160 字，约 50 秒）**：大家好，我叫林小舟，双木林，一叶小舟的小舟。我来自广西柳州，对，就是螺蛳粉的那个柳州。我是计算机专业的。高中时我自己做过一个背单词的小程序，还给同桌用过，所以特别想在大学里把编程学得更系统。平时我喜欢夜跑，一般晚上九点左右在东操场，跑五公里，现在还缺一个搭子，有兴趣的同学可以来找我。希望这四年能和大家一起把代码写明白，也把身体练结实。我是林小舟，谢谢大家！
>
> **记忆点**：夜跑找搭子（来自你说的「九点、东操场、五公里、想找搭子」）；名字拆字、「螺蛳粉的柳州」和背单词小程序只作辅助。
>
> **关键词卡**：双木林小舟 → 柳州 → 背单词小程序 → 九点东操场找搭子
>
> **怯场提示**：① 第一句「我叫林小舟」说慢一点；② 忘词就直接跳到「缺个搭子」那句收尾。

宿舍、社团、组会、线上群的完整示例见 [examples/five-scenes.md](examples/five-scenes.md)。

## 常见问题（FAQ）

**Q：名字很普通，或者很难念，怎么办？**
A：普通的就给一个记法（拆字、字的来历）；难念的主动教读音，比如「我姓单，念 shàn，不念 dān」。

**Q：没有什么爱好特长怎么办？**
A：不必是特长，一件真实的小事就行：在学的一道菜、每天必去的食堂窗口、最近在追的一部剧。

**Q：要不要说高考分数、毕业的高中？**
A：不建议报分数，容易被当成比较。想提高中，就讲一件在那里发生的小事。

**Q：要不要讲个笑话？**
A：可以用一句轻松的自嘲，不讲段子；拿不准就不讲，真诚比好笑重要。

**Q：突然被点名、完全没准备怎么办？**
A：用四句救场：名字，专业和家乡，最近在做的一件事，「希望和大家多交流」。

**Q：能不能帮室友也写一份？**
A：可以分别写，但每份都要本人提供真实信息，我不替别人编。

**Q：组会自我介绍和班级的有什么不同？**
A：组会要让导师知道你会什么、对什么方向感兴趣、能投入多少时间；少讲爱好，多讲技能和方向，同样只讲真实的。

**Q：群里发了之后没人回，是不是很尴尬？**
A：很正常，大群消息刷得快。你的目的只是让大家把名字和人对上，之后在宿舍、课堂和活动里慢慢认识。

## 常见错误（反模式）

- 逐字背稿 → 一紧张就断片 → 背 4 个关键词。
- 三个记忆点一起上 → 一个都记不住 → 只留一个主钩子。
- 爱好说「看书、听音乐、运动」→ 太泛，没人能接话 → 加一个具体细节。
- 用「我没什么好说的」开头 → 冷场，也显得不重视 → 直接说名字。
- 报成绩、报获奖 → 容易被当成炫耀，拉开距离 → 讲一件具体的小事。
- 在大群发手机号、宿舍号 → 有隐私和诈骗风险 → 私聊再给。
- 超时 → 挤占后面同学的时间，老师可能会打断 → 按档位字数写，测一遍时长。
- 组会上说「对所有方向都感兴趣」→ 等于没说 → 说一个具体方向和原因。

## 边界与不做什么

- 只写你自己的真实信息：不编造经历、特长、奖项。示例里的人物都是虚构的，不能照抄。
- 隐私默认不写：手机号、住址、证件号、家庭经济、健康、宗教、感情等；你本人决定要说的，我会先提醒风险。
- 不替别人写冒充本人的介绍，不帮你伪装身份。
- 室友矛盾、换宿舍等问题不在本技能范围，找辅导员或宿舍管理老师。
- 社交焦虑严重影响生活时，建议联系学校心理中心；本技能不做心理评估。
- 只起草，不代你在任何群里发送。
