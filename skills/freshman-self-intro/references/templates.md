# 五种场合的模板（含三档）

方括号内换成你的真实信息；不想说的项直接删，不要硬凑。字数按每分钟约 200 字估算并留出停顿余量，只数汉字、英文单词和数字，不数标点（经验值，以你自己掐表为准）。

## 1. 班级见面会

**1 分钟版（约 150–200 字）**

```
大家好，我叫[姓名]，[名字记法]。
我来自[家乡]，[家乡的一个特点，一句话]。
平时我喜欢[具体爱好 + 细节]，[一个小故事或近况]。
[如果有：我会……，大家需要可以找我]。
希望这四年能和大家[一个具体的期待]。我是[姓名]，谢谢大家！
```

- 压成 30 秒（约 80–100 字）：留名字、家乡、爱好细节、最后一句，删小故事和「我会……」。
- 扩成 3 分钟（约 450–600 字）：加两段真实经历（例如高中做过的一件事、暑假学会的一样东西），每段 100–150 字；再加一段「想认识什么样的同学」。段与段之间停一拍。

## 2. 宿舍（聊天，不是演讲）

**开场一句话**

```
嗨，我是[姓名]，[专业]，[家乡]人，叫我[昵称]就行。
```

**第一周内聊开的清单**（比自我介绍本身更重要）

- 作息：一般几点睡、几点起，闹钟会不会响很多遍。
- 声音：打游戏、打电话、看视频戴不戴耳机。
- 灯和空调：几点关灯，空调开多少度。
- 卫生：值日怎么排，垃圾谁倒。
- 访客与物品：能不能带朋友来，东西能不能互相借用。

三档对应：一句话开场 → 三句话（加一个爱好）→ 聊开了（聊上面的清单）。

提醒：习惯说清楚就好，不急着交底家庭情况、感情经历这类隐私；也别在第一天就给室友下判断。

## 3. 社团（新成员见面会）

**30 秒版（约 80–100 字）**

```
大家好，我是[学院][年级]的[姓名]。我加入[社团]是因为[一个具体原因]。
我现在的水平是[如实写：零基础 / 入门 / 能独立……]，这学期想学会[一项具体技能]。
[如果有：我可以帮社团做……]。以后请多指教！
```

- 1 分钟：加一个和社团有关的小故事（第一次接触这件事的经历）。
- 3 分钟（少见，社团要求才用）：再加「我希望和社团一起做成的一件事」。

## 4. 导师、实验室（第一次组会）

**1 分钟版**

```
老师好，师兄师姐好，我是[姓名]，本科[学校][专业]。
本科期间我做过[一个真实的项目、课程设计或毕业设计，一句话说做了什么]。
我会[编程语言、实验技能或软件，如实写水平]，正在补[需要学的东西]。
我对[课题组的某个方向]比较感兴趣，因为[一个具体原因]。
接下来[时间段]，我每周能在实验室[时间安排]。希望尽快跟上大家，谢谢！
```

- 3 分钟：项目部分展开成「做了什么 → 遇到的一个问题 → 怎么解决」；加「我读过组里的哪篇论文、有什么问题想请教」——只在你真的读过时说。
- 30 秒：姓名、本科专业、会什么、感兴趣的方向。
- 书面版（第一次发邮件或消息）三句：我是谁；我做过或读过什么和组里相关的事；希望[面谈 / 旁听组会]，附上[简历]。

提醒：不要说「对所有方向都感兴趣」；没读过的论文不要说读过；水平如实写，「会一点」和「用过」要分清。

## 5. 线上群（班级群、年级群、社团群）

**3 行版**

```
大家好，我是[姓名]，[专业][班级]，来自[家乡]。
[一个钩子：爱好 + 细节，或者一样能分享的东西]。
很高兴认识大家，[一句邀请，比如「有一起夜跑的可以找我」]！
```

**5 行版**：在 3 行版基础上加「最近在做的一件事」和「希望在群里得到或提供什么帮助」。

提醒：

- 按群公告的格式改群备注（常见如「专业-姓名」），群规优先。
- 不在大群发手机号、宿舍号、证件照、生日。
- 群里有人自称老师或辅导员，要求转账、交费、扫码、下载软件，先通过线下或已确认的电话向辅导员核实——这是开学季常见的诈骗手法。
