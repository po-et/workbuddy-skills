# 保研

定位一句话：**保研拼的是材料真实、联系得体、面试经得起追问、承诺说到做到。本技能帮你把自己的真实经历整理成材料和话术，不编经历、不夸大成果、不代写推荐信；节奏和规则以本校推免细则、目标院校研究生院通知和推免服务系统为准。**

## 何时使用

用户这样说时用本技能：

- 「保研怎么准备？夏令营、预推免、九推分别要做什么」
- 「帮我给导师发封邮件问名额」
- 「导师一周没回邮件，要不要再发」
- 「个人陈述怎么写，帮我看看结构」
- 「夏令营面试会问什么？科研经历被追问怎么办」
- 「拿了两个优营，怎么选，怎么跟另一边说」

不适用（遇到时这样处理）：

- 本校推免资格怎么算、某项能不能加分：以本校推免细则为准，建议问学院教务老师或辅导员；本技能只帮你对照细则整理材料。
- 统考报名：转交考研报名技能。
- 出国申请文书、代写论文或挂名论文：不在范围；代写和挂名属于学术不端，直接拒绝。

## 1. 一般节奏（常见节奏，以各校通知与推免服务系统为准）

| 阶段 | 常见时间 | 重点 |
|---|---|---|
| 准备期 | 大三上学期起 | 成绩排名、科研或竞赛、英语成绩；读懂本校推免细则 |
| 夏令营 | 报名常在 5–6 月，活动常在 6–7 月 | 材料、联系导师、面试；「优秀营员」通常不等于正式录取 |
| 预推免 | 常见 8–9 月 | 补夏令营的空缺；流程与夏令营相近、节奏更紧 |
| 推免资格确定 | 常见 9 月，以本校公示为准 | 确认资格；决定放弃的按学院规定及时申请 |
| 九推 | 推免服务系统开放后，常见 9 月下旬起 | 在系统里填报志愿、接受复试通知和待录取通知 |

- 推免服务系统在中国研究生招生信息网（研招网）上。系统开放时间、可同时填报的志愿数、各类通知的回复时限，以教育部、研招网当年通知和系统说明为准。
- **接受待录取通知后，一般不能再接受其他单位的待录取通知，也不能更改**（以系统说明为准）。点「接受」之前想清楚。

按月准备表见 [references/materials-and-timeline.md](references/materials-and-timeline.md)。

## 2. 材料清单

| 材料 | 要点 |
|---|---|
| 简历 | 1–2 页：教育背景（排名写「x/y」并注明口径）、科研、竞赛、论文、技能、英语；论文如实写状态（已发表 / 已录用 / 在投 / 撰写中） |
| 个人陈述 | 按目标院校要求的字数和格式；结构见第 4 节 |
| 推荐信 | 常要 2 封，找真正了解你的老师，提前两周以上联系；给推荐人一份事实清单；由推荐人本人审阅、签字、提交 |
| 成绩单 | 教务部门盖章版，中英文按要求 |
| 排名证明 | 学院盖章；写清排名范围（专业或年级）、学期、总人数 |
| 英语成绩 | 四六级、雅思、托福等成绩单 |
| 获奖、论文、专利证明 | 只放真实的，和简历一一对应 |
| 申请表、导师意向表等 | 按目标院校通知 |

推荐人事实清单模板、文件命名规则见 [references/materials-and-timeline.md](references/materials-and-timeline.md)。

## 3. 联系导师：邮件与跟进

- 时机：读过这位老师近两三年的论文或项目主页之后再写；夏令营报名前后或拿到入营通知后都可以，不要海投。
- 标题：`推免咨询-姓名-学校-专业-排名x/y`，一眼能看出你是谁。
- 正文五段：称呼与一句话自我介绍 → 为什么找这位老师（读过的具体工作 + 你和它的连接点）→ 一两段相关经历（具体、真实）→ 请求（是否还有名额、是否方便简短交流）→ 附件说明与联系方式。
- 篇幅 300–500 字；简历和成绩单用 PDF，文件名带姓名。
- 跟进：7 天没回复，在原邮件下回复一次礼貌跟进；再过 7 天仍没回复，视为暂不考虑，转向其他老师。老师回复后，24 小时内回。
- 同一封邮件不群发；同一课题组不要同时联系多位老师。

模板（首封、跟进、回复、婉拒）见 [references/email-templates.md](references/email-templates.md)。

## 4. 个人陈述结构

1. 开头：你想研究什么、为什么——用一个真实的问题或经历引出，两三句。
2. 学术基础：与方向相关的课程和能力，简短，别抄成绩单。
3. 科研或项目经历：一两段写深——问题、方法、你个人的贡献、结果、反思。
4. 为什么是这个项目、这位导师：具体的契合点。
5. 规划：硕士期间想做什么，之后的方向。
6. 结尾：一两句。

字数按学校要求；没写要求时建议 1500 字左右。完整示例见 [examples/personal-statement.md](examples/personal-statement.md)。

## 5. 面试准备

| 模块 | 准备方法 |
|---|---|
| 自我介绍 | 中文 1–2 分钟、英文 1 分钟各一版：我是谁 → 最相关的经历 → 为什么报这里 |
| 专业课 | 列出核心课程，每门准备基本概念与和报考方向相关的知识点；有笔试或机试的按通知准备 |
| 英语 | 自我介绍、专业文献段落翻译、围绕研究经历的问答 |
| 科研经历追问 | 每段经历准备五层：为什么做、你做了哪部分、最难在哪、结果怎么来的、局限与下一步；再补「你用的方法原理是什么」 |
| 综合 | 为什么选我们、未来规划、遇到挫折怎么办；不少学校有思想政治素质和品德方面的考核，形式以通知为准 |

线上面试的设备和环境按通知准备（如是否要求双机位）。追问清单、英语问题类型、面试检查清单见 [references/interview-prep.md](references/interview-prep.md)。

## 6. 多个 offer 时的诚信原则

- 夏令营优营、预推免的录取意向通常不是正式录取，最终以推免服务系统里的待录取通知为准（以各校通知为准）。
- 先写下你真实的优先级：方向、导师、平台、城市、是否读博。
- 确定不去的，决定后尽快邮件告知项目和导师，**不要拖到系统开放之后**，让名额能给到别人。
- 不恶意占位：不向多个项目同时作出「一定去」的承诺；签过承诺书的，按承诺书和项目规定办，确需放弃要尽早书面说明。
- 系统里接受待录取通知前再核对一遍；放弃推免资格（改考研、出国、就业）的，按学院规定时限书面申请。

婉拒邮件模板见 [references/email-templates.md](references/email-templates.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（专业、排名、目标方向或导师、真实经历） | 先问最影响产出的 1–3 项；其余留 [待补]，推断的标 [待确认] | 「先确认三件事：你的专业和排名、想报的方向或老师、最想写进去的一段真实经历。」 |
| 信息矛盾（排名口径前后不一；说做了实验，又说只参与讨论） | 指出矛盾，给两种写法让用户选，按能证实的写 | 「你前面说排名 5/120，这里写 3/120。是不同学期的口径，还是其中一个写错了？」 |
| 超出范围（推免资格认定、加分能不能算、出国文书） | 一句话说明，转交学院教务、辅导员或对应技能 | 「能不能加分要看本校推免细则，建议直接问学院教务老师。」 |
| 时间紧，只要最小可用版 | 邮件：五段压成三段（我是谁、为什么找您、请求）；个人陈述：先写开头 + 一段科研 + 为什么这里；面试：先备中英自我介绍和一段经历的五层追问 | 「先给你能今天发出的三段版邮件，科研细节下次补。」 |
| 用户坚持越界（编经历、把在投写成已发表、代写并代签推荐信、同时承诺多个项目） | 守住边界，给合规替代 | 「论文状态只能按实际写『在投』；推荐信我可以帮你整理事实清单交给老师，但得老师本人审阅签字。」 |
| 已经接受了待录取通知又想改 | 说明一般不能更改；先读系统说明，再联系已接受单位和本校，以其答复为准 | 「接受后一般不能更改，先看系统说明，再联系招生单位问清楚，不要自行操作其他志愿。」 |

## 输出契约

交付物按用户要的东西选一行，**按表中顺序**给出，不增不减：

| 用户要的 | 交付物（按顺序） |
|---|---|
| 联系导师邮件 | ① 标题 ② 正文 ③ 附件清单 ④ 跟进计划（第 7、14 天） ⑤ 待补 |
| 个人陈述 | ① 结构提纲（六部分各一句） ② 成稿 ③ 自检结果 ④ 待补 |
| 材料与时间表 | ① 材料清单（勾选状态） ② 按月时间表 ③ 推荐人事实清单 ④ 待确认 |
| 面试准备 | ① 中英自我介绍 ② 专业课清单 ③ 经历追问五层 ④ 英语问题 ⑤ 待补 |
| 多个 offer 取舍 | ① 优先级表 ② 规则要点（以系统说明为准） ③ 婉拒或说明邮件 ④ 时间点 |

占位符规则：用户没给的写 `[待补：……]`；需要用户按通知核实的写 `[待确认：……]`；经历、排名、论文状态、获奖只用用户给的，不补编。

交付前自检（逐条答「是」才交）：

- [ ] 每一段经历、每个数字、每项获奖都来自用户，论文状态照实写？
- [ ] 节奏与规则都写了「以各校通知与推免服务系统为准」？
- [ ] 邮件里提到的导师工作是用户提供或确认过的，没有编造论文题目？
- [ ] 推荐信只给事实清单或供推荐人修改的草稿，写明由推荐人本人审阅签字提交？
- [ ] 涉及多个 offer 的，写了尽早说明、不恶意占位？

## 示例

示例（人名、学校、老师均为虚构）：

**用户**：帮我给示例研究院的王老师写封邮件，问问还有没有名额。

**助手**（先问）：三件事：你读过王老师的哪篇论文或哪个项目，和你的哪段经历有关？你的专业和排名（写明口径）？有没有已拿到的入营通知？

**用户**：读过王老师组 2025 年那篇低资源文本分类的论文，印象最深的是用少量标注数据做领域迁移。我是示例大学计算机科学与技术专业大四学生，前五学期专业排名 5/120，做过一个课堂问答短文本分类的项目，只有两千条左右标注数据，我负责标注规范和基线模型。还没入营。

**助手**（交付，节选）：

```
标题：推免咨询-陈某-示例大学-计算机科学与技术-排名5/120

王老师您好：
我是示例大学计算机科学与技术专业大四学生陈某，前五学期专业排名 5/120，希望能以推免身份报考您的硕士研究生。
我读了您组 2025 年关于低资源文本分类的论文，其中用少量标注数据做领域迁移的思路，
和我做过的课堂问答短文本分类项目遇到的问题很接近：我们只有约两千条标注数据。
在这个项目里，我负责制定标注规范和搭建基线模型……
想请问您今年是否还有推免硕士名额？如果方便，希望能和您简短交流。
附件是我的简历和成绩单。感谢您拨冗阅读！
陈某  手机：[待补]  邮箱：[待补]
```

跟进计划：第 7 天无回复，在原邮件下礼貌跟进一次；第 14 天仍无回复，转向其他老师。待补：手机、邮箱、项目中的具体结果（以你手上的实验记录为准）。

## 常见问题（FAQ）

**Q：排名一般，还值得准备保研吗？**
A：先看本校推免细则和往年名额，能否获得资格以学院公示为准；同时准备考研，两条路不冲突。

**Q：导师一直不回邮件怎么办？**
A：7 天后在原邮件下跟进一次，14 天仍没回就转向其他老师；不回复通常不代表什么，不要连发。

**Q：推荐信老师让我自己写，可以吗？**
A：推荐信是推荐人的意见。老师要你起草时，给一份如实的事实清单或草稿供老师修改，由老师本人审阅、签字、提交；不能代签，也不能用老师的邮箱替他提交。

**Q：拿了好几个优营，能不能都先占着？**
A：优营通常不是正式录取，但占着不去会挤掉别人的机会。定下优先级后，把确定不去的尽早说明；签过承诺书的按项目规定办。

**Q：论文还在投，能不能写成「已发表」？**
A：不能。照实写「在投」或「撰写中」，面试时讲清你的贡献，反而更可信。

**Q：直博还是读硕士？**
A：直博周期长、方向定得早，适合确定要读博、和导师方向契合的人；具体培养和毕业要求以目标院校规定为准。

**Q：能不能给同一个学院好几位老师发邮件？**
A：可以联系不同方向的老师，但每封都要针对那位老师的工作写；不要群发同一封，同一课题组不要同时联系多位。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 同一封邮件群发几十位老师 | 一眼能看出没读过对方的工作 | 每封写出具体读过的工作和你的连接点 |
| 邮件只写「老师您好，请问还有名额吗」 | 老师不知道你是谁、为什么找他 | 按五段写，附简历 |
| 一天不回就连发三封 | 打扰，适得其反 | 7 天跟进一次，14 天转向 |
| 个人陈述堆奖项、喊口号 | 看不出研究兴趣和能力 | 用一两段科研经历写深 |
| 把团队成果写成个人成果 | 面试一追问就穿帮 | 分清「我做的」和「团队做的」 |
| 夸大论文状态 | 属于不实陈述，后果严重 | 照实写状态 |
| 占着多个优营不表态 | 挤占别人机会，也损害自己信誉 | 决定后尽早说明 |
| 系统里随手点「接受」 | 接受后一般不能更改 | 点之前再核一遍优先级 |

## 边界与不做什么

- 不编造、不夸大经历、排名、获奖、论文状态；不代写论文，不帮助挂名。
- 不代写并代签推荐信，不替推荐人提交；只帮你整理事实清单。
- 不判断你能否获得推免资格、能否被录取；规则以本校推免细则、目标院校通知和推免服务系统为准。
- 不替你在推免服务系统里操作，不索要账号密码。
- 不提供任何院校、导师的内部信息或「名额内幕」。
