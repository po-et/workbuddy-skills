# 联系导师与说明去向的邮件模板

本文件是 [SKILL.md](../SKILL.md) 第 3、6 节的展开。方括号里的内容都要换成你自己的真实信息；读过的论文、做过的事，写不出具体内容就先别发。

## 1. 首封邮件

```
标题：推免咨询-[姓名]-[学校]-[专业]-排名[x/y]

[X]老师您好：
我是[学校][专业]大四学生[姓名]，[学期口径]专业排名[x/y]，希望以推免身份报考您的[硕士 / 直博]研究生。

我读了您[组 / 团队][年份]关于[主题]的[论文 / 项目]，其中[具体让你有共鸣的做法或问题，一句话]，
和我在[经历名称]中遇到的[具体问题]很接近。

在[经历名称]中，我负责[你个人做的部分]，[结果，只写有记录可查的]。
[如有第二段相关经历，一两句。]

想请问您今年是否还有推免[硕士 / 博士]名额？如果方便，希望能和您简短交流。
附件是我的简历和成绩单[，以及排名证明]。感谢您拨冗阅读！

[姓名]
手机：[号码]  邮箱：[邮箱]
```

## 2. 7 天后的跟进（在原邮件下回复）

```
[X]老师您好：
冒昧再打扰一次。上周我发送了关于推免报考的邮件（附简历与成绩单），不知您是否方便查看。
如果您今年名额已满或方向不太匹配，也烦请告知，我好及时调整。再次感谢！

[姓名]
```

再过 7 天仍无回复：不再追发，转向其他老师。

## 3. 老师回复后

**老师愿意交流**：

```
[X]老师您好：
非常感谢您的回复！[按老师提出的时间或方式回应，如：我[日期]全天都方便，
可以按您的时间安排线上或线下交流。]
交流前我会再读一遍您组[具体工作]，并准备好我的项目介绍。

[姓名]
```

**老师说名额已满**：

```
[X]老师您好：
谢谢您的及时回复，也感谢您的时间。祝您和团队一切顺利！

[姓名]
```

## 4. 确定不去时的说明（优营、预推免意向、口头承诺）

```
标题：[姓名]关于[项目名称]录取意向的说明

[X]老师 / [项目]老师您好：
感谢您和[项目]在[夏令营 / 预推免]中给我的认可。经过慎重考虑，我决定[去向，可只写"选择其他项目"]，
因此不再接受贵项目的录取意向。决定后第一时间告知您，希望名额能尽早安排给其他同学。
给您带来不便，非常抱歉，再次感谢！

[姓名]  [日期]
```

要点：决定了就发，不拖到系统开放之后；签过承诺书的，同时按承诺书和项目规定的方式说明。

## 5. 面试后致谢（可选）

```
[X]老师您好：
感谢您今天抽时间和我交流。您提到的[具体建议或问题]对我很有启发，我会[具体跟进，如：补读相关论文]。
期待有机会在您的指导下学习。

[姓名]
```
