# 保研材料与按月准备表

本文件是 [SKILL.md](../SKILL.md) 第 1、2 节的展开。时间都是**常见节奏**，以本校推免细则、目标院校研究生院通知和推免服务系统为准。

## 1. 按月准备表

| 时间 | 要做的事 | 产出 |
|---|---|---|
| 大三上学期 | 读本校推免细则（排名口径、加分项、时间节点）；稳住成绩；找科研或竞赛机会 | 细则要点笔记 |
| 大三寒假 | 整理科研经历；列出目标院校与方向 | 目标清单（冲刺 / 稳妥 / 保底） |
| 3–4 月 | 简历初稿；联系推荐人；关注目标院校往年夏令营通知发布渠道 | 简历、推荐人名单 |
| 5–6 月 | 夏令营报名；按需联系导师；准备个人陈述 | 报名材料包 |
| 6–7 月 | 参加夏令营；每场面试后复盘 | 复盘表 |
| 8–9 月 | 预推免；确认本校推免资格；决定放弃的按学院规定申请 | 资格公示截图、决定记录 |
| 推免服务系统开放后 | 填报志愿、按时回复复试通知与待录取通知 | 系统操作记录 |

## 2. 材料包检查表

| 材料 | 状态 | 备注 |
|---|---|---|
| 简历（中文 / 英文） | ☐ | 1–2 页，PDF |
| 个人陈述 | ☐ | 每所学校按要求改写，不要一稿多投不改 |
| 推荐信 × 2 | ☐ | 推荐人本人审阅、签字、提交 |
| 成绩单（盖章） | ☐ | 中英文按要求 |
| 排名证明（盖章） | ☐ | 写清范围、学期、总人数 |
| 英语成绩单 | ☐ | |
| 获奖证书、论文、专利 | ☐ | 与简历一一对应 |
| 身份证、学生证 | ☐ | 按要求扫描 |
| 目标院校申请表、导师意向表等 | ☐ | 按通知 |

文件命名：`姓名-学校-材料名.pdf`，如「陈某-示例大学-排名证明.pdf」。扫描件清晰、方向正确、盖章可见。

## 3. 推荐人事实清单（交给推荐人参考）

推荐信是推荐人自己的意见。你能做的是把**真实、可核对的事实**整理好，方便老师回忆和取舍：

```
推荐人：[老师姓名、职称]
我与老师的关系：[如：老师讲授的某课程，我是学生；我在老师指导下做了某项目]
时间：[起止年月]
我做过的具体事情：
1. [事实，如：负责实验数据清洗与基线模型，最终报告的第 3 章由我完成]
2. [事实]
可以核对的成果：[课程成绩、项目报告、代码仓库、获奖证书]
我申请的方向与学校：[如：示例研究院，自然语言处理方向，硕士]
提交方式与截止：[目标院校要求的提交方式与截止时间，以通知为准]
```

提醒：提前两周以上请老师；截止前三天礼貌确认一次；提交后发邮件致谢。老师要你起草时，只写上面清单里能核对的事实，由老师修改、签字并本人提交。

## 4. 排名证明怎么写清楚

- 排名范围：专业内 / 年级内，写清楚。
- 学期：前五学期 / 前六学期，与本校推免细则的口径一致。
- 总人数：分母要写。
- 口径不一致时（如加权平均分和绩点排名不同），以本校推免细则和学院出具的证明为准，简历里写的和证明保持一致。
