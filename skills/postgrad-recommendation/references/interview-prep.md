# 保研面试准备

本文件是 [SKILL.md](../SKILL.md) 第 5 节的展开。各校面试的形式、时长、是否有笔试或机试，以通知为准。

## 1. 自我介绍

中文 1–2 分钟：

1. 我是谁：学校、专业、排名（口径和简历一致）。
2. 最相关的一两段经历：每段一句「做了什么」+ 一句「结果」。
3. 为什么报这里：一两个具体的契合点。
4. 结尾一句。

英文 1 分钟：同样结构，少一段经历。写好后计时念三遍，不背成朗诵腔。

## 2. 专业课

- 列出与报考方向最相关的 4–6 门核心课。
- 每门准备：核心概念的一句话定义、一个典型例题或应用、和报考方向的联系。
- 有笔试或机试的，按通知给的范围限时练。

## 3. 科研经历追问清单

每段写进简历的经历，按下面逐条准备，答不出的就是要补的：

| 层 | 常见问题 | 准备要点 |
|---|---|---|
| 为什么做 | 这个问题为什么重要？ | 背景一两句 |
| 你做了什么 | 你个人负责哪部分？ | 分清个人与团队 |
| 方法 | 为什么用这个方法？原理是什么？有没有试过别的？ | 能讲清原理和取舍 |
| 难点 | 最难的地方？怎么解决？ | 一个具体难点 |
| 结果 | 指标是什么？和基线比如何？数据从哪来？ | 数字和实验记录对得上 |
| 局限与下一步 | 有什么不足？接下来怎么做？ | 真实反思 |

「不知道」的回答方式：先承认不确定，再说你会怎么查或怎么验证，不要现编。

## 4. 英语面试常见问题类型

- 自我介绍、家乡与学校、兴趣爱好。
- 介绍一个你的项目或一门你喜欢的课。
- 为什么选择这个方向、未来计划。
- 读或翻译一段专业文献。

准备：每类写 3–5 句要点，不背全文；专业词汇整理一页。

## 5. 综合面常见问题

- 为什么选择我们学校、这个方向？
- 如果没有被录取，你怎么打算？
- 遇到过的最大困难？怎么处理的？
- 本科期间最有收获的一件事？

不少学校有思想政治素质和品德方面的考核，形式以通知为准；如实作答即可。

## 6. 线上面试检查清单

- [ ] 按通知安装指定软件、测试设备；是否要求第二机位以通知为准。
- [ ] 网络稳定，准备备用热点；电脑接电源。
- [ ] 安静单人房间，背景整洁，光线在正面。
- [ ] 身份证件、学生证放手边备查。
- [ ] 按通知时间提前进入候场。
