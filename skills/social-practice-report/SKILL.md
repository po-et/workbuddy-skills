# 社会实践报告

定位一句话：**社会实践报告的分量来自「真」——真去了、真问了、真数了。本技能帮你把团队真实收集的材料整理成报告，不编数据、不编访谈、不摆拍、不替你写没经历过的感悟。**

## 何时使用

用户这样说时用本技能：

- 「暑期社会实践报告怎么写？」
- 「我们要去乡村小学调研，选题怎么定、怎么分工」
- 「帮我设计一份问卷／访谈提纲」
- 「问卷收回来了，数据怎么放进报告」
- 「照片能不能放孩子的正脸？」
- 「答辩 PPT 怎么做，评优要交什么」

不适用（遇到时这样处理）：

- 立项申报、经费报销、保险办理的具体规定：以学校团委、学院通知为准，建议直接问指导老师或团委。
- 学术论文投稿、毕业论文：不在范围，建议找论文写作类技能或导师。
- 没有任何实践素材却要整篇代写、要编数据：拒绝编造，先帮你列出还能补收集哪些真实素材。

## 1. 选题与团队分工

- 选题公式：**对象 + 地点 + 一个具体问题**，如「某社区 60 岁以上居民用手机挂号的困难」。题目越小，越能做深。
- 可行性四问：能不能接触到对象（人和单位是否同意）？时间够不够？安全和经费有没有着落？有没有伦理风险（未成年人、弱势群体、敏感话题）？
- 学校或团委发布了选题方向、立项要求的（如暑期「三下乡」等专项活动），以其通知为准。
- 分工：队长兼联络、调研设计、数据整理、记录宣传、后勤与安全、主笔。每人都要下现场，报告分节写、主笔统稿。

分工表和实践日志模板见 [references/templates.md](references/templates.md)。

## 2. 调研方法

| 方法 | 适合回答 | 最少要做到 |
|---|---|---|
| 问卷 | 多少人、多大比例 | 按下面 8 条原则设计，正式发放前找 3–5 人试填 |
| 访谈 | 为什么、怎么想 | 半结构化提纲 5–8 个问题；先征得同意，录音要对方同意 |
| 观察 | 实际怎么做 | 记录表把「看到的事实」和「我的理解」分两栏 |
| 公开资料 | 背景 | 注明出处，数字照抄不改 |

问卷设计最小原则：

1. 先写下想回答的问题，每道题都要对应它，用不上的删掉。
2. 一题只问一件事，不问「价格和质量您满意吗」。
3. 措辞中性，不诱导，不问「您是否也认为很不方便」。
4. 选项互斥且穷尽，留「其他（请注明）」「不清楚」。
5. 先易后难，敏感题放后面；非必要不收集姓名、电话、住址。
6. 开头写清：谁在调查、做什么用、匿名、可随时退出、大约几分钟。
7. 控制在 5–10 分钟答完。
8. 抽样怎么做的就怎么写，如「在社区活动中心门口方便抽样」，不夸大代表性。

问卷骨架、访谈提纲、观察表、知情同意说明模板见 [references/methods-and-consent.md](references/methods-and-consent.md)。

## 3. 报告结构

标题 → 摘要（选写，200–300 字）→ 一、背景与目的 → 二、实践过程（时间、地点、对象、方法、样本、分工）→ 三、调研发现（每条发现一个小标题，配数据或访谈引语）→ 四、问题分析与建议（每条建议对应一条发现，写清对谁、做什么）→ 五、实践感悟（真实、具体）→ 参考资料 → 附录（问卷、访谈提纲、日志、照片说明）。

完整模板见 [references/templates.md](references/templates.md)，完整示例见 [examples/elderly-phone-registration.md](examples/elderly-phone-registration.md)。

## 4. 数据怎么呈现（只用自己真实收集的数据）

- 每张表、每个百分比都写 n 和来源：「数据来源：本队 2026 年 7 月线下问卷，n=86」。
- 分母是**有效回答数**，不是发放数；多选题各项占比相加会超过 100%，要注明。
- 样本少（经验上 n<30）时写人数：「20 人中有 12 人」，不外推到「当地居民普遍……」。
- 图表：比较类别用条形图；组成部分且类别不多才用饼图；量表题按量表顺序排，不按人数排。
- 访谈引语匿名：「受访者 A，70 多岁，退休工人」。
- 没收集到的数据不补、不估、不「合理推算」；引用公开资料注明出处。

问卷统计脚本（只统计文件里真实存在的回答）：

```bash
python3 scripts/survey_tally.py answers.csv --skip "序号,提交时间" --multi "Q3" --sep "┋"
python3 scripts/survey_tally.py answers.csv --order "Q5=很不方便|不太方便|一般|比较方便|很方便" --source "本队 2026 年 7 月线下问卷" --out tables.md
```

输出每题的有效 n、人数、占比（四舍五入到 0.1%）；多选题按「选该项人数 ÷ 回答该题人数」计算并加注；n<30 提示改用人数表述；开放题、编号列和个人信息列自动跳过并列出原因。多选题在导出文件里用什么符号分隔，先打开 CSV 看一眼再填 `--sep`。开放题先人工归类编码，再统计。

## 5. 照片与受访者隐私

- 知情同意：访谈、拍照、录音前说明身份和用途（报告、推文、评优展示）、会不会公开，对方同意再开始；能书面就书面。
- 未成年人：记录和拍摄前取得监护人同意；公开时不露正脸，不写姓名、学校、班级，用背影、局部或打码。《个人信息保护法》规定，处理不满十四周岁未成年人的个人信息，应当取得其父母或者其他监护人的同意。
- 不公开能识别个人的信息：姓名、电话、住址、健康状况、收入等，受访者一律用代号。
- 尊重对方：不摆拍、不刻意渲染困难，对方不愿被拍就不拍；要求删除的照片立即删除。
- 原始问卷、录音、照片存在队内指定位置，按学校要求保存，用完删除不需要的。
- 每张照片配说明：时间、地点、内容、「已获同意」。

## 6. 字数与格式

- 字数、模板、字体字号、提交形式，以学校、学院或团委通知为准。
- 没有要求时的建议（非规定）：个人报告 3000–5000 字；篇幅重点给「发现」和「建议」。
- 通用格式：各级标题编号一致；图表有编号和标题（表题在上、图题在下）；加页码；参考资料常用 GB/T 7714 格式，学校另有要求的从其要求。
- 要查重的，不要搬往届报告和网上范文。

## 7. 答辩与评优材料

- 答辩 PPT 8–12 页：选题与问题 → 方法与样本 → 三条主要发现 → 建议 → 实际成效（只写真实发生的）→ 感悟与不足；时长以通知为准。
- 评优材料包：报告、实践日志、照片集（已获同意）、问卷与原始数据（备查）、接收单位证明（如需要，真实盖章）、媒体报道（真实的才放）。

页面结构、讲稿要点、评委常见追问见 [references/defense-materials.md](references/defense-materials.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（实践主题、时间地点、收集了哪些素材） | 先问这 3 项；其余按模板留 [待补]，推断的标 [待确认] | 「先确认三件事：你们做的主题、时间地点、手上有哪些素材（问卷、访谈记录、照片、日志）？」 |
| 数据自相矛盾（发放 100 份，统计里却有 120 人选了某项） | 指出矛盾，给两种可能（多选题、录入重复）让用户核对原始数据 | 「单选题人数不会超过有效答卷数。这题是多选，还是录入时有重复？请对一下原始问卷。」 |
| 超出范围（立项、报销、保险规定；论文投稿） | 一句话说明，转交团委、指导老师或对应技能 | 「报销规定要看学校团委的通知，建议问指导老师；报告部分我继续帮你写。」 |
| 时间紧，只要最小可用版 | 给五段骨架：背景一段、过程一段、三条发现（各配一个真实数字或引语）、三条对应建议、感悟一段；附录标 [待补] | 「先给你能交的五段版，附录和图表后补。」 |
| 用户坚持越界（编数据、编访谈、补「合理」样本、用没授权的孩子正脸、伪造接收单位证明） | 守住边界，给合规替代 | 「数据和访谈不能编；样本少就如实写 n，并在不足里说明，评委更看重真实。」 |
| 素材太少写不满字数 | 不注水；补真实素材：整理实践日志、回访、补充观察记录；把「不足与改进」写具体 | 「字数不够别注水，把日志和访谈细节整理进去，比套话更有分量。」 |

脚本 `scripts/survey_tally.py` 的退出码与报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 统计成功；「未统计的列」里写了跳过原因 | 核对跳过的列是否符合预期 |
| 1「列不在表头里」 | `--cols`、`--skip`、`--multi` 或 `--order` 写的列名和表头不一致 | 按报错里列出的现有列名复制粘贴 |
| 1「比表头多了 N 列」 | 答案里有英文逗号，导出时没加引号 | 导出选带引号的 CSV，或把逗号换成中文逗号 |
| 1「没有列名」「列名重复」「只有表头」「文件是空的」 | 表头或数据有问题 | 给每题一个唯一列名，确认导出了答卷 |
| 1「没有可统计的列」 | 所有列都被跳过（个人信息、开放题等） | 用 `--cols` 指定要统计的题 |
| 1「--order 格式不对」「参数错误」 | 选项写法不对 | 写成 `列名=选项1\|选项2\|…`，或看 `--help` |
| 2「找不到文件」「写不了文件」「编码」 | 路径、权限或编码 | 检查路径；表格软件另存为「CSV UTF-8」 |
| 130 | 按了 Ctrl+C | 重新运行；中断时不会写出半截文件 |

## 输出契约

按用户要的东西选一行，交付物**按表中顺序**给出，不增不减：

| 用户要的 | 交付物（按顺序） |
|---|---|
| 选题与分工 | ① 选题一句话（对象 + 地点 + 问题）② 可行性四问的回答 ③ 分工表 ④ 日程 ⑤ 待确认 |
| 问卷或访谈提纲 | ① 想回答的问题 ② 问卷或提纲全文 ③ 知情同意说明 ④ 按 8 条原则的自查 ⑤ 待补 |
| 报告 | ① 标题 ② 摘要（如需要）③ 五个正文部分 ④ 参考资料 ⑤ 附录清单 ⑥ 待补 |
| 数据呈现 | ① 脚本命令 ② 统计表（带 n 和来源）③ 正文写法示范 ④ 需核对的问题 |
| 答辩与评优 | ① PPT 页面结构 ② 讲稿要点 ③ 材料清单 ④ 待补 |

占位符规则：用户没给的写 `[待补：……]`；需要用户核对原始材料的写 `[待确认：……]`；数据、引语、照片说明、成效只用用户提供的真实材料。

交付前自检（逐条答「是」才交）：

- [ ] 每个数字都来自用户的真实数据，写了 n 和来源，分母是有效回答数？
- [ ] 访谈引语来自用户的记录，受访者用代号，没有可识别个人的信息？
- [ ] 涉及未成年人的照片和信息，写明了监护人同意与公开时的处理方式？
- [ ] 每条建议都对应一条发现，写清对谁、做什么？
- [ ] 字数和格式标了「以学校通知为准」，没有凭空规定？
- [ ] 待补、待确认逐条列出？

## 示例

示例（团队、地点、数据均为虚构）：

**用户**：我们队今年 7 月在一个社区调研老人用手机挂号的困难，收回 48 份问卷，还访谈了 6 位老人。报告「调研发现」那部分怎么写？

**助手**（先问）：问卷导出成 CSV 了吗？多选题用什么符号分隔？访谈记录有没有整理成文字，受访者同意引用吗？

**用户**：导出了，多选用「┋」隔开。访谈有整理稿，6 位都口头同意匿名引用。其中受访者 B（70 多岁，退休教师）说：「每一步都要重新找按钮，上次学会了，过两周又忘了。」

**助手**（运行 `python3 scripts/survey_tally.py answers.csv --skip "序号,提交时间" --multi "Q3 手机挂号遇到的困难" --sep "┋"`，用统计结果和用户给的引语写出一条发现）：

```
（一）「步骤多」和「字太小」是最常被提到的困难
在回答该题的 38 位受访者中，24 人（63.2%）选择「步骤太多记不住」，21 人（55.3%）选择「字太小看不清」
（多选题，各项占比相加超过 100%）。受访者 B（70 多岁，退休教师）说：「每一步都要重新找按钮，
上次学会了，过两周又忘了。」
数据来源：本队 2026 年 7 月在某社区的线下问卷，n=38。
```

## 常见问题（FAQ）

**Q：问卷只收回 20 多份，能写报告吗？**
A：能。如实写 n，用人数表述，不外推；在「不足」里说明样本少的原因和改进办法。

**Q：能不能帮我把数据「补」得好看一点？**
A：不能。编造或修饰数据一旦被发现，评优资格和个人诚信都会受影响；真实的小样本加上扎实的访谈更有说服力。

**Q：团队报告和个人报告有什么区别？**
A：团队报告写全队的调研与发现；个人报告侧重你负责的部分和你自己的感悟，感悟不要全队共用一段。

**Q：照片里有小朋友，能用吗？**
A：取得监护人同意才能用；公开发布时不露正脸，不写姓名、学校、班级。

**Q：感悟怎么写才不空？**
A：写一个具体场景：当时发生了什么、你原来怎么想、现在怎么想、以后打算怎么做。

**Q：能直接帮我写一整篇吗？**
A：可以帮你搭结构、改写和润色，但数据、访谈、经历必须来自你们的实践；没有的部分我会标成 [待补]。

**Q：参考资料要什么格式？**
A：以学校要求为准；没有要求时常用 GB/T 7714 格式，至少写清作者、题名、来源和时间。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 选题太大，如「乡村振兴研究」 | 几天的实践撑不起，只能空谈 | 对象 + 地点 + 一个具体问题 |
| 百分比不写 n，或用发放数当分母 | 读者无法判断可信度 | 写有效 n 和来源 |
| 把 30 份问卷写成「当地居民普遍认为」 | 外推过度 | 写「本次调查的受访者中」 |
| 多选题占比加起来超过 100% 却不说明 | 看起来像算错了 | 注明是多选题及分母 |
| 引语带真名、照片露孩子正脸 | 侵犯隐私，可能违法 | 代号、打码，取得同意 |
| 摆拍、刻意渲染困难 | 不真实，也伤害受访者尊严 | 记录真实场景 |
| 建议空泛（「政府应加强重视」） | 对谁、做什么都不清楚 | 每条建议对应一条发现，写清对象和做法 |
| 感悟全是口号 | 看不出你经历了什么 | 写一个具体场景和变化 |
| 搬往届报告或网上范文 | 查重和诚信风险 | 用自己的素材写 |

## 边界与不做什么

- 不编造数据、访谈、照片说明和实践成效，不伪造接收单位证明、媒体报道或盖章材料。
- 不代写没有真实素材支撑的报告与感悟；只帮你整理、组织、润色你们的真实材料。
- 不公开或输出受访者的个人信息；涉及未成年人的，先取得监护人同意。
