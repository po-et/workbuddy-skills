# 答辩与评优材料

本文件是 [SKILL.md](../SKILL.md) 第 7 节的展开。答辩时长、页数、评分标准和评优材料清单以学校、学院或团委通知为准。

## 1. 答辩 PPT 页面结构（8–12 页）

| 页 | 内容 | 要点 |
|---|---|---|
| 1 | 标题页 | 题目、队名、指导老师、时间地点 |
| 2 | 我们想回答什么 | 一个现象 + 1–3 个具体问题 |
| 3 | 怎么做的 | 方法、样本（有效 n）、时间、分工 |
| 4–6 | 三条主要发现 | 每页一条：一句结论 + 一张图表（带 n 和来源）+ 一句引语 |
| 7 | 建议 | 每条建议对应一条发现，写清对谁、做什么 |
| 8 | 实际成效 | 只写真实发生的：如教会了多少位老人（有签到记录）、建议被哪个单位采纳（有书面回复） |
| 9 | 不足与改进 | 样本、时间、方法上的局限 |
| 10 | 感悟 | 一两个具体场景 |

页面原则：一页一个观点；图表比文字多；字号在最后一排也能看清；照片只用已获同意的，孩子不露正脸。

## 2. 讲稿要点

- 开头 30 秒讲清：我们看到了什么现象、想回答什么问题。
- 发现部分每条都说「数字 + 分母 + 来源」，如「38 位回答者中有 24 位」。
- 讲不足时具体、诚实，评委通常更看重你知道局限在哪。
- 控制在规定时长内，提前计时演练两遍。

## 3. 评委常见追问与准备

| 追问 | 准备 |
|---|---|
| 样本怎么选的？能代表当地吗？ | 如实说明抽样方式，承认代表性有限 |
| 这个百分比的分母是多少？ | 有效回答数，多选题说明计算方式 |
| 建议可行吗？找相关方聊过吗？ | 说清对象和做法；真聊过才说聊过 |
| 你个人负责了哪部分？ | 对照分工表说具体 |
| 如果再做一次会怎么改？ | 结合「不足」回答 |

## 4. 评优材料包清单

| 材料 | 要求 | 状态 |
|---|---|---|
| 实践报告（终稿） | 按通知的格式和字数 | ☐ |
| 实践日志 | 每天一条，写事实 | ☐ |
| 照片集及说明 | 均已获同意；说明写时间、地点、内容 | ☐ |
| 问卷、访谈提纲与原始数据 | 备查；去掉个人信息 | ☐ |
| 接收单位证明（如需要） | 由接收单位出具并盖章，内容真实 | ☐ |
| 媒体报道、推文链接（如有） | 只放真实发布的 | ☐ |
| 答辩 PPT | 按通知时长准备 | ☐ |
| 经费票据（如需要） | 按学校报销要求 | ☐ |

不伪造、不「借用」任何证明和报道；没有的就不放。
