# 社会实践报告模板、分工表与实践日志

本文件是 [SKILL.md](../SKILL.md) 第 1、3 节的展开。字数、版式、封面等以学校、学院或团委通知为准；下面是没有特别要求时的通用骨架。

## 1. 报告模板

```
[标题：对象 + 地点 + 问题，如「某社区老年居民使用手机挂号的困难与需求调查」]
[副标题（可选）：——示例大学某某实践队暑期社会实践报告]
团队：[队名]  指导老师：[姓名]  时间：[起止日期]  地点：[到区县或社区一级即可]

摘要（选写，200–300 字）
[我们做了什么调查（对象、方法、样本 n）→ 最重要的两三条发现 → 主要建议。]

一、背景与目的
1. 为什么关注这个问题：[你们亲眼看到的现象；引用公开资料要注明出处]
2. 本次实践想回答的问题：[1–3 个具体问题]

二、实践过程
1. 时间与地点：[日期、地点]
2. 对象与样本：[谁；怎么找到的（如在社区活动中心门口方便抽样）；问卷发放 x 份、有效 y 份；访谈 z 人]
3. 方法：[问卷 / 访谈 / 观察 / 公开资料，各做了什么]
4. 分工：[见分工表]
5. 过程中的调整：[如原计划入户，因安全考虑改为在活动中心访谈]

三、调研发现
（一）[发现 1，用一句话作小标题]
[数据：有效 n、人数、占比、来源] [访谈引语：受访者代号 + 年龄段 + 身份]
（二）[发现 2]
（三）[发现 3]

四、问题分析与建议
1. [对应发现 1：原因分析 → 建议（对谁、做什么、怎么做）]
2. [对应发现 2]
3. [对应发现 3]
本次调查的不足：[样本来源、样本量、时间限制等，如实写]

五、实践感悟
[团队版：全队的共同收获；个人版：你自己的一个具体场景 → 原来的想法 → 现在的想法 → 之后打算怎么做]

参考资料
[1] [作者. 题名. 来源, 时间.（格式按学校要求，没有要求常用 GB/T 7714）]

附录
附录一 问卷
附录二 访谈提纲
附录三 实践日志
附录四 照片及说明（均已获得同意）
```
