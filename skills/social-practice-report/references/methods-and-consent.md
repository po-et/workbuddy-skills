# 调研方法与知情同意模板

本文件是 [SKILL.md](../SKILL.md) 第 2、5 节的展开：问卷骨架与自查、访谈提纲、观察记录表、知情同意说明。

## 1. 问卷骨架

```
[问卷标题]

您好！我们是[学校][队名]的学生，正在做关于[主题]的社会实践调查。
问卷匿名填写，结果只用于[实践报告 / 学校评优展示]，不会公开任何个人信息。
您可以跳过不想回答的题，也可以随时停止。大约需要[5–10]分钟。谢谢您！

一、基本情况（只问分析需要的）
1. 您的年龄段：□ 18岁以下 □ 18–39岁 □ 40–59岁 □ 60岁及以上
   （如果调查对象可能包括未成年人，先确认已取得监护人同意）

二、[主题相关的行为]
2. [单选题：一题只问一件事，选项互斥穷尽]
   □ ……  □ ……  □ 其他（请注明）____  □ 不清楚
3. [多选题：注明「可多选」]

三、[态度或评价]
4. [量表题：您觉得……方便吗？]
   □ 很不方便 □ 不太方便 □ 一般 □ 比较方便 □ 很方便

四、开放题（最多 1–2 道）
5. 您对……还有什么建议？____

再次感谢您的参与！
```

## 2. 问卷自查（发放前逐条过）

| 检查项 | 是 / 否 |
|---|---|
| 每道题都对应一个想回答的问题 | |
| 没有一题问两件事 | |
| 没有诱导性措辞 | |
| 选项互斥且穷尽，有「其他」「不清楚」 | |
| 敏感题靠后，没有不必要的个人信息题 | |
| 开头写了身份、用途、匿名、可退出、时长 | |
| 3–5 人试填过，改掉了看不懂的题 | |
| 多选题注明了「可多选」 | |

## 3. 访谈提纲（半结构化）

```
开场：自我介绍 → 说明用途与匿名 → 询问能否记录或录音（同意后再开始）
1. 能说说您平时[相关行为]的情况吗？
2. 最近一次[相关经历]是怎样的？当时发生了什么？
3. 这件事里最让您为难的是什么？
4. 遇到困难时，您一般怎么办？找谁帮忙？
5. 如果可以改变一件事，您最希望改什么？
追问：「能举个例子吗？」「后来呢？」「您为什么这么觉得？」
结束：感谢 → 说明对方可以随时要求删除记录 → 留队伍联系方式（队长的，不留个人私号也可以）
```

访谈记录：时间、地点、受访者代号（如受访者 A）、年龄段、身份（如退休工人），不记姓名和住址；当天整理成文字，引用原话要一字不改。

## 4. 观察记录表

| 时间 | 地点 | 看到的事实（谁、做了什么、几次） | 我的理解（单独写） |
|---|---|---|---|
| [待补] | [待补] | [如：9:00–10:00 挂号窗口前 12 位老人排队，其中 5 位拿着手机询问工作人员] | [如：可能是线上操作遇到困难] |

事实和解释分开写，报告里引用的是事实栏。

## 5. 知情同意说明

**口头版**（访谈、拍照前说）：

「您好，我们是[学校]的学生，在做[主题]的社会实践。想和您聊[10–20]分钟，内容只用于我们的实践报告[和学校评优展示]，报告里不会出现您的名字。我们想[记笔记 / 录音 / 拍一张不露脸的照片]，您看可以吗？您随时可以不答，也可以之后让我们删除。」

**书面版**（能书面就书面）：

```
知情同意书

本人已了解：[学校][队名]正在开展[主题]社会实践调查；访谈 / 拍摄内容将用于[实践报告、学校评优展示、推文]；
报告中不出现本人姓名、住址、电话等信息；本人可以随时拒绝回答或要求删除相关记录。

□ 同意接受访谈  □ 同意记录或录音  □ 同意拍摄（□ 可露脸 □ 不露脸）  □ 同意在推文中使用照片

受访者签字：________   日期：________
调查人签字：________   联系方式（队伍）：________
```

**未成年人**：由监护人签署；公开发布时仍不露正脸，不写姓名、学校、班级。《个人信息保护法》规定，处理不满十四周岁未成年人的个人信息，应当取得其父母或者其他监护人的同意。支教、夏令营等场景，还要遵守接收单位（学校、机构）的管理要求。
