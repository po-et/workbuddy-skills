# 文件处理契约

1. 批次写入前检查所有目标：不得覆盖任何输入（普通路径、真实路径与硬链接），不得把两个输入映射到同一输出，映射报告不能与输入/输出重合。
2. 目录输入保留相对层级；独立文件列表按文件名输出，遇同名冲突要求调整输入目录。重复的相同输入路径去重。输出目录位于输入目录内时不再次收集该输出目录。
3. 输入符号链接拒绝处理；请明确提供普通文件。输入需为 UTF-8 文本，非法编码返回失败而非静默替换字符。
4. 非覆盖输出采用独占提交；已存在输出默认跳过并退出1。`--force`允许替换独立输出，但不授权写输入。已有映射报告同样需要换新路径或`--force`。
5. 先写同目录随机临时文件，再原子提交。每个文件独立处理，并非整个批次事务；某项失败不撤销此前成功副本，报告列成功/跳过/失败。
6. 原地写需`--in-place --yes`。成功后替换原件，失败保留原件。该选择不可自动推断；工具只按调用者提供的开关执行。
7. 命中统计按成功处理文件计算，不把失败文件的部分扫描计入成功。脱敏模式仍是有限的正则识别；原子写与哈希均不能证明输出包含了所有该隐藏的信息。
