# 腾讯位置服务 WebService：本技能用到的部分（通用形态，以官方文档为准）

> 这里只写确定的通用形态。接口的完整参数、返回字段含义、状态码表、配额与计费，一律以腾讯位置服务官方文档和控制台为准。
> 官方文档去哪查：腾讯位置服务官网 → 开发文档 → WebService API，看「地理编码」「逆地址解析」「坐标转换」「签名校验」「状态码」相关章节（章节名以官网目录为准）。

## 1. 两个调用

| 用途 | 请求（GET） | 关键参数 |
|---|---|---|
| 地址 → 坐标（地理编码） | `https://apis.map.qq.com/ws/geocoder/v1/` | `address=地址`、`key=你的key` |
| 坐标 → 地址（逆地址解析） | 同一路径 | `location=纬度,经度`（纬度在前）、`key=你的key` |

脚本的处理约定：
- 返回 JSON 里 `status` 为 0 视为成功，坐标取 `result.location` 的 `lat` / `lng`。
- 行政区划取 `result.address_components`（逆地址解析取 `result.address_component`，两个名字脚本都兼容）；可信度取 `result.reliability`、精度取 `result.level`。**这几个字段的名称与取值含义以官方文档为准**；返回里没有某个字段时，脚本就不据此判断。
- `status` 非 0：原样记录 `status` 和 `message` 到 `geo_note`，不猜测含义。

## 2. key 的管理

- 在腾讯位置服务控制台申请 key 并开启 WebService 能力（入口以控制台为准）。
- **只放环境变量**：`export TENCENT_MAP_KEY=你的key`，脚本用 `--key-env` 指定变量名。不要写进脚本、配置文件模板、前端代码，不要贴进聊天，不要提交进仓库；已经泄露的在控制台作废重建。
- 控制台可能提供调用来源限制（例如 IP 白名单）和签名校验等安全设置，具体选项以控制台为准。如果 key 设置了 IP 白名单，要把运行脚本那台机器的出口 IP 加进去。
- **本脚本没有实现签名校验**。如果你的 key 开了签名校验，请按官方「签名校验」章节在 `Requester.get()` 里补上签名参数，否则会返回鉴权类错误。

## 3. 配额、费用与限频

- 每个 key 的调用量和并发上限、超出后的计费或限制，以控制台和官方说明为准；本技能不写具体数字。
- 脚本的省量设计：默认预演不联网；同一清洗后地址只请求一次；`--cache` 让重跑只补失败的；开头连续 3 次同样的错误就自动停止。
- 限频：用 `--interval` 拉开请求间隔（默认 0.5 秒）。如果官方状态码表里有表示「请求过快」的状态码，把它填进 `--retry-status`，脚本会对它重试（最多 2 次，间隔 1 秒、2 秒）。
- 不要用多个 key 轮换来绕开配额限制。

## 4. 重试与超时（脚本内置）

| 情况 | 行为 |
|---|---|
| 网络错误、超时、HTTP 429 或 5xx | 重试，最多 2 次（`--retries` 可设 0–2），间隔 1 秒、2 秒 |
| `--retry-status` 里列出的 status | 同上 |
| 其他 HTTP 错误（如 4xx） | 不重试，记为失败 |
| 返回不是 JSON | 不重试，提示检查 `--base-url` |
| 开头连续 3 次同样的错误 | 立即停止，未请求的行记为「未处理」，退出码 3 |
| Ctrl-C | 已完成的行照常写出，其余记为「未处理」，缓存照常保存，退出码 130 |

## 5. 坐标系（只讲概念）

- **WGS-84**：GPS 设备和国际通行地图使用的坐标。
- **GCJ-02**：国内地图服务普遍使用的加偏坐标（常称国测局坐标）；腾讯位置服务使用这一套（以官方文档为准），脚本输出的 `geo_coord_sys` 列因此写 GCJ-02。
- **BD-09**：百度地图在 GCJ-02 基础上再加偏的坐标。
- 同一个地点在不同坐标系下数值不同，混用时点位会偏离，在街道级地图上肉眼可见。**算距离、打点之前，所有点必须是同一坐标系。**
- GPS 采集的坐标要先转换再使用；腾讯位置服务提供坐标转换相关接口，参数与支持的转换方向以官方文档为准。本技能不提供自研转换公式。

## 6. 本地演练（不联网）

```bash
python3 scripts/mock_geocoder.py --port 8765          # 另开一个终端运行，Ctrl-C 停止
export TENCENT_MAP_KEY=local-test                      # 假服务不校验 key 内容
python3 scripts/geocode_batch.py geocode orders.csv --column 地址 --out geo.csv \
    --run --base-url http://127.0.0.1:8765 --timeout 1 --retry-status 9001
```

假服务只监听 127.0.0.1，返回的坐标是哈希出来的假数据；9001、9002 等 status 是本地模拟值，不代表真实接口的状态码。它能演练的故障：查无结果、超时、偶发 HTTP 500、请求过快、多个笼统地址落在同一点。
