# 看房检查表（完整版）

看房带齐：充满电的手机（拍照、当手电、测信号）、卷尺（量床和衣柜放不放得下）、充电器（试插座）、纸笔。每个房间边拍视频边说「这是哪里、有什么问题」，问题当场记下，回去对照比较：

```
水    所有龙头放 1 分钟：水压、水色、热水多久出来；马桶冲两次看下水和回水；
      水槽下、马桶根部、天花板和墙角有没有水渍霉斑（常是楼上漏水的痕迹）
电    民用电价还是商业电价、按表计还是按人头分；电表在哪、能不能自己看读数；
      空调、热水器、冰箱、洗衣机逐个开机；插座拿充电器逐个试
燃气  能不能点着；燃气热水器装在浴室里或没有排烟管的，有一氧化碳风险，要求整改，否则别租
网络  宽带通没通、在谁名下、费用谁出；屋里各个角落打个电话试信号
隔音  关上门窗静听 2 分钟：临街、电梯井、楼下商铺、夜市；敲敲隔墙是不是空心板；
      最好晚上 9–10 点再去一次
采光  白天去：主窗朝向、对面楼有多近；拉开窗帘不开灯，能不能看清书上的字
潮湿  衣柜里、床底、墙角闻霉味、找霉点；卫生间有没有窗或排风扇
安全  能否换锁芯；窗户和阳台护栏；楼道有没有堆物堵住消防通道；有没有灭火器、烟感
合租  几个人共用一个卫生间；室友作息、是否吸烟养宠物；公共区域谁打扫；
      水电燃气网按人、按房间还是按表分摊；用板子隔出来的「隔断间」重点看有没有窗和逃生通道
周边  走到最近的地铁或公交站计时；超市、菜场、药店；夜里回家那段路的照明和人流
```

## 怎么用这张表

- 按用户情况删行：整租删掉「合租」一行；只白天有空的，在「隔音」「周边」旁标「待晚上复看」。
- 每套房一张，问题写成「在哪 + 什么问题 + 照片编号」，回去比较时一目了然。
- 燃气那一行是一票否决项：燃气热水器装在浴室里或没有排烟管，对方不整改就别租。
- 几套房的钱和通勤放在一起比，用 `python3 scripts/compare_homes.py`（用法见 SKILL.md）。
