# 租房攻略

定位一句话：**租房的坑很少出在「挑错了房」，多半出在「签之前没核对、入住时没留证据、退租时说不清」——所以每一步都要留下书面记录。**

## 何时使用

第一次在陌生城市租房；约了看房不知道看什么；签合同前想逐条核对；入住交接、退租拿回押金时。无论通过什么渠道找房都适用，本页不推荐具体平台和中介。用户这样说时用本技能，按所处阶段给对应那张清单：

- 「第一次租房，预算 3000，看房要看什么」→ 需求清单 + 看房检查表
- 「这几套房哪个划算」→ 跑比较脚本，把入住先付、每月实付、通勤小时摆出来
- 「明天签合同，签合同前查什么，对方是二房东要注意啥」→ 签约前核对清单，二房东多核两样材料
- 「今天入住，要做什么」→ 交接记录模板 + 入住三件事
- 「下个月退租，房东说要扣清洁费，押金怎么拿回来」→ 退租七步，对照合同与交接记录

第一次租房的按全流程给；说了自己租过房的，只给当前阶段那张清单，不从头讲。

不适用：

- 判断条款是否合法有效、谁违约、押金扣得对不对、能不能索赔：不下结论，转当地调解组织、12345 热线或执业律师；本技能只列要核对什么。
- 推荐具体找房平台、中介、公寓品牌或小区，代谈价、代签、代付：不做。
- 买房、分期或租金贷之类的金融安排：不做金融建议；看不懂先别签，问专业人士。

## 先判断什么：需求清单与预算

```
预算    月租上限：常见经验是不超过到手收入的三分之一，超了就在面积、楼龄或通勤上让步
        入住先付：月租 ×（押金月数 + 首付月数）+ 中介费（如有）+ 搬家与添置
        每月实付：月租 + 水电燃气网 + 物业或服务费 + 通勤费
通勤    定一个单程上限（如 45 分钟），在工作日早高峰实际走一趟
方式    整租：安静自主，贵；合租：便宜，要看室友和分摊规则；机构公寓：手续规范程度差别大，合同更要细看
必须项  写三条非满足不可的（如有窗、独立卫生间、能养猫），其余都算「有更好」
时间    最晚入住日、打算住多久；租期要和工作、学业的变动对得上
```

几套房放在一起比时，把数字填进 CSV（表头：名称,月租,押几,付几,中介费,每月杂费,单程通勤分钟）跑脚本；通勤按每月 22 个工作日算，中介费按一年租期摊。脚本会拦下负数、把金额填进月数这类错，并按预算、收入、通勤上限标出超了的：

```bash
python3 scripts/compare_homes.py homes.csv --budget 3000 --max-commute 45
python3 scripts/compare_homes.py --home "A 地铁口一居,4200,1,3,4200,350,25" --home "B 合租主卧,2600,1,1,0,300,50"
```

第二条的输出（本机实测）：

```
A 地铁口一居：入住先付 21000 元，每月约 4900 元，每月通勤 18 小时
B 合租主卧：入住先付 5200 元，每月约 2900 元，每月通勤 37 小时
与「A 地铁口一居」相比，「B 合租主卧」每月省 2000 元，通勤多 18 小时，相当于每多通勤 1 小时省 109 元
每月省下的房租和多出来的通勤时间怎么换，值不值由你定；这张表只把账摆出来。
```

## 看房检查表

看房带齐：充满电的手机（拍照、当手电、测信号）、卷尺、充电器（试插座）、纸笔；每个房间边拍视频边说「这是哪里、有什么问题」。十类逐项看，每类最要紧的一句：

- **水**：龙头放 1 分钟看水压水色；天花板、墙角有没有水渍霉斑。**电**：民用还是商业电价，电器逐个开机。
- **燃气**：能不能点着。**燃气热水器装在浴室里或没有排烟管的，有一氧化碳风险，要求整改，否则别租。**
- **网络**：宽带在谁名下、谁出钱。**隔音**：关窗静听 2 分钟，最好晚上 9–10 点再去一次。**采光**：白天不开灯能不能看清字。
- **潮湿**：衣柜、床底闻霉味。**安全**：能否换锁芯，消防通道有没有被堵，有没有灭火器、烟感。
- **合租**：几人共用卫生间、室友作息、费用怎么分摊；隔断间看有没有窗和逃生通道。**周边**：走到车站计时，夜里回家那段路。

完整检查表（逐项看法和追问）见 [references/viewing-checklist.md](references/viewing-checklist.md)。

## 签约前核对清单（只列要核对什么）

十一项逐条核对：出租人、房屋、租期、租金、押金、费用、维修、退租、其他、签字、付款。最要紧的是出租人：**身份证件上的姓名 = 合同上的出租人 = 收款账户户名，三处一致**；房主本人看房屋权属证明原件；二房东或机构看原租赁合同和房主同意转租的书面材料，原合同到期日要晚于你的租期。

核对时把每一条标成三种之一：已写明、没写、写得含糊。没写和含糊的，写成问题清单当面问清，答案补进合同或附件，不接受「放心，到时候再说」。

遇到这几种情况先停下，不付任何钱：租金明显低于同地段同户型；对方说人在外地不能带看，只让先转账锁房；证件只给照片不给原件；收款人和出租人不是同一个人；一再催你当天付清。

十一项的完整核对要点和标注示例见 [references/contract-checklist.md](references/contract-checklist.md)。

## 入住交接与退租流程

- **入住当天**：和出租人逐项过一遍，写成交接记录双方签字（电表、水表、燃气表读数，钥匙门卡数量，墙面家具家电的现状，各配照片编号）；顺手换锁芯（征得同意）、试烟感、存好物业维修和燃气抢修电话。住的期间报修用文字留痕。
- **退租七步**：书面通知并约验房 → 自己打扫、修好自己造成的损坏 → 拿交接记录逐项验房 → 抄表结清费用 → 交钥匙拿书面确认 → 押金按合同期限退，要扣钱请对方列出项目、金额和依据 → 谈不拢先协商，再找社区或街道调解、12345 热线或律师。

交接记录模板和七步的完整说明见 [references/move-in-move-out.md](references/move-in-move-out.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息（预算、通勤地点、整租合租） | 只问三项：月租上限、通勤地点和单程上限、整租还是合租；入住日期、必须项先空着标 [待确认]；没说租没租过房的，按第一次租房给全流程 | 「先确认三件事：每月房租最多多少？每天去哪上班或上学，单程最多能接受多久？整租还是合租？其余我先按常见情况排，标了 [待确认]。」 |
| 数字不合理（预算为负或为 0、押金月数填成金额、通勤 0 分钟） | 指出哪个数不对，给两种理解；脚本会拦下并说明 | 「『押几』填的是 3000，这一列是月数。你是想说押一个月（填 1），还是押金 3000 元（押金月数 = 3000 ÷ 月租）？」 |
| 条件自相矛盾（预算 2000，要市中心整租一居、单程 20 分钟内） | 不评价行情，说明几项里要让步一项，给两种取舍 | 「预算、位置、整租这三项现在互相顶着。两种取舍：放宽通勤到 45 分钟找整租；或者留在附近改合租。你更在意哪个？」 |
| 超出范围（条款是否有效、押金扣得对不对、能否索赔、推荐平台中介、分期贷款） | 说明不下结论，转调解组织、12345 或律师；不推荐平台 | 「扣得对不对我不下结论。我帮你列出对方该给的项目、金额和依据，对照合同；谈不拢可以找社区调解或打 12345。」 |
| 时间紧（明天就签、今晚就要定） | 最小可用版：签约前必查五项（出租人三处一致、押金退还条件与期限、提前退租条款、维修责任、付款走留痕方式）+ 五个停下信号；其余标 [待补]，签约后补 | 「时间紧就先查这五项，外加五个『先停下』的信号；其余条款签完再补核。」 |
| 用户坚持越界（「你就说房东违不违法」「帮我判断证件真假」「推荐个靠谱中介」） | 守住边界，给能做的替代 | 「证件真伪我没法核验。能做的是：对照原件、三处姓名一致、房主本人一起去当地不动产登记机构查询，具体办法以当地规定为准。」 |
| 紧急情况（闻到燃气味、电线冒烟） | 先保命，直接给安全步骤，不走清单 | 「先别开关任何电器、别点火，开窗后离开，到室外再打燃气公司抢修电话或 119。」 |
| 贴来的合同条款不全或看不清 | 请贴全文或相关条款原文；按拿到的部分逐条标注，缺的标 [待补] | 「截图里押金那一条被截断了，麻烦贴全；其余我先按三种标注过一遍。」 |

脚本报错对照（`python3 scripts/compare_homes.py`）：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 正常，逐套列出并两两比较 | 把结果整理成比较表 |
| 1，「…是负数」「应是正数」 | 金额、月数、分钟或预算写成了负数 | 去掉负号 |
| 1，「押几…像是把金额填进来了」「付几是 0」 | 押几、付几填的是月数，不是金额；每次至少付一个月 | 押一付三就填 1 和 3 |
| 1，「表头缺少」「应有 7 项」「没有房源」 | CSV 表头不对，或 --home 少写了项 | 复制报错里给的表头；--home 按「名称,月租,押几,付几,中介费,每月杂费,单程通勤分钟」写 |

## 输出契约

交付物按下面的顺序，每次都一样：

1. **情况摘要**：所处阶段（找房、看房、签约、入住、退租）、已知条件、[待确认] 的假设。
2. **本阶段清单**：看房用检查表，签约用核对清单，入住用交接记录模板，退租用七步流程；按用户情况删掉不适用的行。
3. **要问出租人的问题**：没写的、写得含糊的，逐条列出，答案要补进合同或附件。
4. **比较表**（比较多套房时）：用脚本算出入住先付、每月实付和通勤小时。
5. **停下信号与安全提示**：用得上的才写，不堆砌。
6. **下一步与待确认清单**。

用户贴出合同条款时：逐条对照核对清单，标出已写明、没写、写得含糊，列出要问出租人的问题；不评价条款是否合法有效。

占位符规则：[待补] = 只有用户知道的事实（预算、地址、合同原文、读数）；[待确认] = 我按常见情况先定的假设（押付方式、每月通勤天数、摊销月数）。

交付前自检（每条都答「是」才交）：

- [ ] 只列了「要核对什么」，没有判断条款是否合法有效、谁违约？
- [ ] 没有推荐任何具体平台、中介、公寓品牌或小区？
- [ ] 用户贴的合同条款逐条标了「已写明 / 没写 / 写得含糊」？
- [ ] 比较表里的数字都来自用户给的条件或脚本计算，没有编行情？
- [ ] 需要时写了停下信号和燃气、用电安全提示？
- [ ] 所有 [待补]、[待确认] 都进了待确认清单？

## 示例

（示例，场景虚构）

> 用户：明天签合同，签合同前查什么？对方是二房东，要注意啥？

助手：时间紧，不多问，直接给「明天就能用」的版本；缺的信息标出来。

**先核这三样，缺一样就先别付钱**

1. 原租赁合同（房主和二房东签的）：原合同到期日要晚于你的租期 [待补：原合同到期日]。
2. 房主同意转租的书面材料。
3. 三处一致：二房东证件上的姓名 = 你们合同上的出租人 = 收款账户户名。

**合同逐条标「已写明 / 没写 / 写得含糊」**：租期与续租、租金与每期付款日、押金退还条件与期限、各项费用谁付、维修谁负责、提前退租怎么处理、签字（每页签名，手写改动处双方签字）。

**要当面问的问题（答案写进合同或附件）**

- 如果原合同提前结束、房主收回房子，我的押金和已付房租怎么退？
- 押金在什么期限内退？哪些情形可以扣、扣多少？
- 空调、热水器坏了谁修、谁付钱、几天内修好？

**先停下的信号**：证件只给照片不给原件；收款人和出租人不是同一个人；一再催你当天付清；租金明显低于同地段同户型。

**付款**：每一笔走能留痕的方式并备注用途（定金、押金、某月房租），拿到收据；收据写清是「定金」还是「订金」、什么情况下退、怎么退。

**待确认**：原合同到期日与转租同意材料是否齐全（明天当面看原件）。

更多完整示例：第一次租房从需求清单到三套房比较见 [examples/first-time-renter.md](examples/first-time-renter.md)；退租被扣清洁费、怎么拿回押金见 [examples/move-out-deposit.md](examples/move-out-deposit.md)。

## 常见问题（FAQ）

**二房东的房能租吗？** 本技能不判断能不能租，只列要核对的：原租赁合同、房主同意转租的书面材料、原合同到期日晚于你的租期、三处姓名一致。

**定金和订金有什么区别？** 两者后果可能不同，本技能不做法律定性；你要做的是让收据写清是哪一种、什么情况下退、怎么退，拿不准问 12345 或律师。

**房东说要扣清洁费，合理吗？** 不判断合不合理；请对方列出项目、金额和依据，你对照合同里有没有这一项、标准是多少，再拿入住照片协商。

**能推荐个靠谱的平台或中介吗？** 不推荐具体平台、中介或公寓品牌；这些清单无论通过什么渠道找房都适用。

**预算不够怎么取舍？** 在面积、楼龄或通勤上让步；用比较脚本把每月省下的房租和多出来的通勤小时摆出来，值不值由你定。

**只能白天看房怎么办？** 至少挑一个晚上 9–10 点再去一次，听噪音、看夜里回家那段路。

**让我签「租金分期」或贷款，要签吗？** 看懂再决定，看不懂先别签；本技能不做金融建议，先问专业人士。

**闻到燃气味怎么办？** 不开关电器、不点明火，开窗后离开，到室外再打燃气公司抢修电话或 119。

## 常见错误（反模式）

每条：错误做法 → 为什么错 → 正确做法。

1. **没核对出租人就交定金** → 钱付给了没有权利出租的人，事后很难追回 → 先核身份和权属，再付任何钱；定金也要写清退还条件。
2. **「今天不定就没了」当场转账** → 被催促时最容易漏看条款 → 至少回去想一晚；急着逼你转账，本身就是信号。
3. **押金转到个人账户没留凭证** → 退租时说不清交过多少 → 转账备注用途，截图和收据都留着。
4. **只要口头承诺（换床垫、修空调）** → 口头说的事后没法对证 → 写进合同附件，写明完成日期。
5. **入住不拍照不抄表** → 退租时说不清原状，押金容易被扣 → 当天做交接记录，双方签字，照片另存。
6. **只在白天看房** → 噪音、治安、回家的路看不出来 → 晚上再看一次。
7. **合租只看房间不看人** → 作息和费用分摊谈不拢，住进去才发现 → 先见室友，问清作息和费用分摊。
8. **提前退租只打电话** → 通知时间说不清，押金和违约扯皮 → 用短信或聊天这类能留痕的方式通知。

## 边界与不做什么

- 不做法律定性：不判断条款是否有效、谁违约、押金扣得对不对、能不能索赔；有争议或金额较大时，找当地调解组织、12345 热线或执业律师。
- 不核验证件真伪，只提示核对什么；对权属有疑问，可请房主本人一起到当地不动产登记机构查询，具体办法以当地规定为准。
- 不推荐具体找房平台、中介、公寓品牌或小区；不替用户谈价、代签、代付。
- 分期、贷款类付款安排不做金融建议，看不懂就先别签，先问专业人士。
- 紧急情况先保命：闻到燃气味，不开关电器、不点明火，开窗后离开，到室外再打燃气公司抢修电话或 119；电线冒烟起火，能安全断电就断电，不用水浇，离开后打 119。平时的安全隐患由出租人或物业整改。
