# 租房攻略

定位一句话：**租房的坑很少出在「挑错了房」，多半出在「签之前没核对、入住时没留证据、退租时说不清」——所以每一步都要留下书面记录。**
何时用：第一次在陌生城市租房；约了看房不知道看什么；签合同前想逐条核对；入住交接、退租拿回押金时。无论通过什么渠道找房都适用，本页不推荐具体平台和中介。

## 先判断什么：需求清单与预算

```
预算    月租上限：常见经验是不超过到手收入的三分之一，超了就在面积、楼龄或通勤上让步
        入住先付：月租 ×（押金月数 + 首付月数）+ 中介费（如有）+ 搬家与添置
        每月实付：月租 + 水电燃气网 + 物业或服务费 + 通勤费
通勤    定一个单程上限（如 45 分钟），在工作日早高峰实际走一趟
方式    整租：安静自主，贵；合租：便宜，要看室友和分摊规则；机构公寓：手续规范程度差别大，合同更要细看
必须项  写三条非满足不可的（如有窗、独立卫生间、能养猫），其余都算「有更好」
时间    最晚入住日、打算住多久；租期要和工作、学业的变动对得上
```

几套房放在一起比时，把数字填进去跑一下（通勤按每月 22 个工作日算，中介费按一年租期摊）：

```bash
python3 - <<'EOF'
homes = [  # 名称, 月租, 押几, 付几, 中介费, 每月杂费, 单程通勤分钟
    ('A 地铁口一居', 4200, 1, 3, 4200, 350, 25),
    ('B 合租主卧', 2600, 1, 1, 0, 300, 50),
]
for name, rent, ya, fu, agent, misc, commute in homes:
    first = rent * (ya + fu) + agent
    monthly = rent + misc + agent / 12
    hours = commute * 2 * 22 / 60
    print('%s：入住先付 %d 元，每月约 %d 元，每月通勤 %.0f 小时' % (name, first, monthly, hours))
EOF
```

每月省下的房租和多出来的通勤时间怎么换，值不值由你定，但要先把这笔账摆出来。

## 看房检查表

看房带齐：充满电的手机（拍照、当手电、测信号）、卷尺（量床和衣柜放不放得下）、充电器（试插座）、纸笔。每个房间边拍视频边说「这是哪里、有什么问题」，问题当场记下，回去对照比较：

```
水    所有龙头放 1 分钟：水压、水色、热水多久出来；马桶冲两次看下水和回水；
      水槽下、马桶根部、天花板和墙角有没有水渍霉斑（常是楼上漏水的痕迹）
电    民用电价还是商业电价、按表计还是按人头分；电表在哪、能不能自己看读数；
      空调、热水器、冰箱、洗衣机逐个开机；插座拿充电器逐个试
燃气  能不能点着；燃气热水器装在浴室里或没有排烟管的，有一氧化碳风险，要求整改，否则别租
网络  宽带通没通、在谁名下、费用谁出；屋里各个角落打个电话试信号
隔音  关上门窗静听 2 分钟：临街、电梯井、楼下商铺、夜市；敲敲隔墙是不是空心板；
      最好晚上 9–10 点再去一次
采光  白天去：主窗朝向、对面楼有多近；拉开窗帘不开灯，能不能看清书上的字
潮湿  衣柜里、床底、墙角闻霉味、找霉点；卫生间有没有窗或排风扇
安全  能否换锁芯；窗户和阳台护栏；楼道有没有堆物堵住消防通道；有没有灭火器、烟感
合租  几个人共用一个卫生间；室友作息、是否吸烟养宠物；公共区域谁打扫；
      水电燃气网按人、按房间还是按表分摊；用板子隔出来的「隔断间」重点看有没有窗和逃生通道
周边  走到最近的地铁或公交站计时；超市、菜场、药店；夜里回家那段路的照明和人流
```

## 签约前核对清单（只列要核对什么）

```
出租人  身份证件上的姓名 = 合同上的出租人 = 收款账户户名，三处一致
        房主本人：看房屋权属证明原件，与身份证件对得上
        转租方（二房东）或机构：看原租赁合同和房主同意转租的书面材料，原合同到期日要晚于你的租期
房屋    地址门牌与实地一致；附带的家具家电写进附件清单
租期    起止日期；到期续租的条件；租期内能否涨租、怎么涨
租金    金额、月付还是季付、每期付款日、付款方式与收款账户
        如果让你签的是分期或贷款（第三方先替你付房租、你按月还给第三方），看懂再决定，看不懂先别签
押金    金额；退还的条件与期限；可以扣押金的情形逐条写明
费用    水、电、燃气、网、物业、暖气、垃圾费——每一项谁付、按什么价、怎么结算
维修    设施家电坏了谁找人修、谁付钱、多少天内修好；正常损耗和人为损坏怎么区分
退租    任一方提前退租要提前多久通知、要付什么、押金怎么处理；能否找人转租接手
其他    房东进屋是否需要提前通知；能否养宠物、换锁；需要办居住证等手续的，问清出租人是否配合
签字    每页签名或骑缝签；手写改动处双方签字；一式两份各执一份
付款    每一笔都走能留痕的方式并备注用途（定金、押金、某月房租），拿到收据
```

核对时把每一条标成三种之一：已写明、没写、写得含糊。没写和含糊的，写成问题清单当面问清，答案补进合同或附件，不接受「放心，到时候再说」。收据上写的是「定金」还是「订金」、什么情况下退、怎么退，也要写清楚。

遇到这几种情况先停下，不付任何钱：租金明显低于同地段同户型；对方说人在外地不能带看，只让先转账锁房；证件只给照片不给原件；收款人和出租人不是同一个人；一再催你当天付清。

## 入住交接与退租流程

入住当天和出租人一起逐项过一遍，写成清单双方签字，照片视频另存一份：

```
交接记录（示例：租客小王、出租人李老师，201 室）
项目        现状或读数                  照片编号
电表        读数 03512，表号见照片       01
水表        读数 00237                   02
燃气表      读数 00089                   03
钥匙门卡    钥匙 3 把，门卡 1 张          04
客厅墙面    电视墙左下有 10 厘米划痕       05
卧室床垫    右侧有污渍                   06
空调        能制冷，遥控器 1 个           07
签字        小王、李老师，日期
```

入住当天顺手做三件事：征得同意后换锁芯（旧锁芯交还或留存）；按一下烟感试试响不响；把物业、维修、燃气抢修电话存进手机。住的期间报修一律用文字留痕，写清哪里坏了、什么时候发现，附上照片；按合同时间付款，每笔保留凭证。

退租按七步走：

```
1 按合同约定的时间提前通知，用短信或聊天发，留下记录，约好验房日期
2 自己打扫，修好自己造成的损坏，清走个人物品
3 拿入住交接记录逐项对照验房；新发现的问题当场拍照、当场谈
4 抄水电燃气读数，结清费用，保留结算截图
5 交还钥匙门卡，拿到对方的书面确认（收条或聊天记录都行）
6 押金按合同写的期限退还；要扣钱（如清洁费），请对方列出项目、金额和依据，你对照合同里有没有这一项、标准是多少
7 谈不拢：先拿入住照片和合同条款协商；还不行，找房屋所在地的社区或街道调解，拨当地 12345 热线咨询，或咨询律师
```

## 最常见的错误

- 没核对出租人就交定金 → 先核身份和权属，再付任何钱；定金也要写清退还条件。
- 「今天不定就没了」当场转账 → 至少回去想一晚；急着逼你转账，本身就是信号。
- 押金转到个人账户没留凭证 → 转账备注用途，截图和收据都留着。
- 口头承诺（换床垫、修空调）→ 写进合同附件，写明完成日期。
- 入住不拍照不抄表 → 退租时说不清，押金容易被扣。
- 只在白天看房 → 噪音、治安、回家的路都要晚上再看一次。
- 合租只看房间不看人 → 先见室友，问清作息和费用分摊。
- 提前退租只打电话 → 用能留痕的方式通知。

## 输出契约

1. **先问清需求**：城市区域、预算、通勤地点、整租还是合租、入住日期、必须项；缺了先问，不猜。
2. **按阶段交付清单**：看房用检查表，签约用核对清单，入住用交接记录模板，退租用七步流程；按用户情况删掉不适用的行。
3. **用户贴出合同条款时**：逐条对照核对清单，标出已写明、没写、写得含糊，列出要问出租人的问题；不评价条款是否合法有效。
4. **比较多套房时**：用上面的脚本算入住先付、每月实付和通勤小时，列成一张表。

## 边界与不做什么

- 不做法律定性：不判断条款是否有效、谁违约、押金扣得对不对、能不能索赔；有争议或金额较大时，找当地调解组织、12345 热线或执业律师。
- 不核验证件真伪，只提示核对什么；对权属有疑问，可请房主本人一起到当地不动产登记机构查询，具体办法以当地规定为准。
- 不推荐具体找房平台、中介、公寓品牌或小区；不替用户谈价、代签、代付。
- 分期、贷款类付款安排不做金融建议，看不懂就先别签，先问专业人士。
- 紧急情况先保命：闻到燃气味，不开关电器、不点明火，开窗后离开，到室外再打燃气公司抢修电话或 119；电线冒烟起火，能安全断电就断电，不用水浇，离开后打 119。平时的安全隐患由出租人或物业整改。
