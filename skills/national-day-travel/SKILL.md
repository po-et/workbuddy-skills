# 国庆攻略

定位一句话：**黄金周的难点不是"去哪好玩"，而是和大量同时出门的人错开——错开时间、错开地点、给意外留余量，钱花得明白。** 本技能只管黄金周高峰期特有的问题；平日出行的完整行程、签证与出境交给「旅行规划」技能。

## 何时使用

- 「帮我做个国庆攻略，2 号走 5 号回，两个人」
- 「国庆自驾回老家，几点出发不堵？高速免费吗」
- 「国庆去哪人少」「带爸妈出去又怕挤」
- 「国庆的票还没买，现在来得及吗」
- 「国庆出去玩预算怎么算」「人多走散了怎么办」

不适用：
- 平日出行、多城市完整行程、签证与出境 → 转「旅行规划」技能，本技能只补黄金周那一层。
- 「国庆十大必去景点」这类排名 → 不做排名，改用第 3 步帮用户给自己的候选地打分。
- 实时余票、路况、房态、景区实时人数 → 本技能不联网，请用户看 12306、航司、预订平台、地图导航与景区官方渠道。

## 第 1 步：先问三件事

1. 日期：哪天能走、哪天必须回。当年假期起止与调休以国务院办公厅的放假通知为准。
2. 交通：自驾、火车、飞机，还是没定。
3. 人和钱：几个人（有没有老人、小孩）、总预算上限。

目的地没定的先走第 3 步；定了的直接走第 2、4 步。

## 第 2 步：避峰——出发和返程时段

经验规律（据往年公开的出行预测归纳；每年以交通部门和导航软件的节前预测为准）：
- 出程高峰：节前最后一个工作日下午到晚上、假期第 1 天上午。
- 返程高峰：假期最后两天，最后一天下午到晚上最集中。
- 错峰办法：能请假就提前一天走；不能请假就选假期第 1 天清晨或午后，或推到第 2 天；返程提前一天回，或最后一天清早出发。

详细对照表、订票倒计时和官方信息去哪查：[references/peak-and-booking.md](references/peak-and-booking.md)。

## 第 3 步：错峰目的地——只给判断方法，不给排名

把 2–4 个候选地放在一起，用同一套经验信号各打 0–2 分（分越高越挤；只用来比较你自己的候选地），总分最低的就是这次的错峰候选；同分选退改更灵活的：

| 信号 | 怎么查 | 越挤的表现 |
|---|---|---|
| 住宿价格倍数 | 同一家酒店国庆当晚价 ÷ 平时周末价 | 倍数越高，需求越旺 |
| 交通余票 | 目标日期的车次、航班 | 早早售罄、只能候补 |
| 景区预约余量 | 景区官方预约渠道 | 提前多日约满 |
| 离大城市远近 | 地图 | 大城市周边一日往返可达，客源最多 |
| 近期热度 | 社交平台近期讨论量 | 刚被大量传播的"小众地"往往已不小众 |

## 第 4 步：订票订房的通用节奏

以出发日为 T：
- T-30 天以前：定目的地和交通；住宿先订"可免费取消"的占位。
- 火车票开售日（出发日往前数预售期，预售期以 12306 公告为准）：开售前设提醒；没买到就提交候补，同时准备中转或错开一天的方案。
- T-14 起：查景区预约规则（何时放号、是否实名、分几个场次），到点预约；要订位的餐厅一并订。
- T-3：看天气预报和景区公告；把每张票、每间房的退改截止时间写进行程表备注。
- T-1：截图保存全部凭证；自驾的检查车况。

离出发只剩几天：先锁交通（候补、中转、错开一天、改近郊自驾），住宿只订可免费取消的，目的地换成车程 2 小时内的地方。

## 第 5 步：自驾要点

小型客车节假日免费通行，下面每一条都是常见规则，一律以交通运输部当年通知为准：
- 车型：通常是 7 座及以下载客车辆——以交通运输部当年通知为准。
- 时段：通常从假期第一天 0 点到最后一天 24 点——以交通运输部当年通知为准。
- 判定：高速公路通常按驶离出口收费站的时间算——以交通运输部当年通知为准。别为了"赶免费"挤在零点前后上下高速。

出发前查胎压、机油、玻璃水、备胎；新能源车把服务区排队充电算进时间，电量留余量；连续开车别超过 4 小时、每次休息不少于 20 分钟（交通法规对疲劳驾驶有明确要求，以现行法规为准）；堵车不占应急车道。清单与事故处理：[references/driving-and-emergency.md](references/driving-and-emergency.md)。

## 第 6 步：人多时的应急预案

- 走散：出门前约定固定、显眼的集合点；老人小孩身上放写着家人手机号的联系卡，出门拍一张全身照；孩子找不到时立即找景区工作人员广播并报警 110。
- 排队：开园即入，或趁午饭时段进热门点；一人排队、一人买水找厕所；每天备一个室内备选。
- 退改：每张票、每间房记下退改截止时间；天气或景区关闭导致的变更，保存官方公告截图再找平台或商家协商。

应急预案卡模板：[references/driving-and-emergency.md](references/driving-and-emergency.md)。

## 第 7 步：时间线与预算合计（脚本）

行程写成 CSV（表头 `日期,开始,结束,事项,类别,金额,备注`；金额填全队合计，可写 148*2），然后运行：

```bash
python3 scripts/golden_week_plan.py --template > itinerary.csv
python3 scripts/golden_week_plan.py --depart 2026-10-02 --return 2026-10-05 --people 2 \
  --itinerary itinerary.csv --holiday 2026-10-01:2026-10-07 --budget 4000 --out plan.md
```

输出顺序固定：避峰提示（出发、返程是否落在经验高峰日）→ 每日时间线（标出时间交叉重叠、没安排的日子）→ 预算表（分类、占比、10% 应急预备金、人均、与上限对比）→ 提醒。`--holiday` 填当年放假通知里的起止。各类别怎么估、超预算先砍哪项：[references/budget-table.md](references/budget-table.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话 |
|---|---|---|
| 缺日期、交通方式或人数 | 只问这 3 件；预算没给就不做上限对比，交付物里标 [待确认] | 「先告诉我哪天走、哪天回、怎么去、几个人，其余我先按默认排。」 |
| 日期自相矛盾 | 指出矛盾，给两种理解让用户选 | 「返程 10 月 2 日早于出发 10 月 5 日：是写反了，还是 10 月 12 日回？」 |
| 要景点排名、"最值得去" | 不排名，改用第 3 步给候选地打分 | 「我不做排名；把你在犹豫的 2–4 个地方发我，我按人流信号帮你比。」 |
| 要实时余票、路况、房态 | 说明不联网，告诉去哪查 | 「实时余票和路况请看 12306 和导航，查到后发我，我帮你排进行程。」 |
| 时间紧，只要最小可用版 | 给三件套：出发返程时段 + 每天一行的时间线 + 预算合计 | 「先给你出发返程时段、每天一行安排和总预算，应急卡明天再补。」 |
| 要求代下单、抢票、占应急车道或超员 | 守边界，给合规替代 | 「我不能代你下单或抢票；开售时间和候补步骤我列好，你到点自己操作。」 |
| 出行中突发（走散、事故、急病） | 先让用户找现场工作人员、报警 110、急救 120、交通事故 122 | 「先找最近的工作人员并报警，行程稍后再改。」 |

脚本退出码：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 1「日期…看不懂」「返程…早于出发」 | 日期格式错或写反 | 写成 2026-10-02，检查年份月份 |
| 1「表头缺少」「中文逗号」「多出 N 列」 | 表头不对、用「，」分隔、金额带千分位逗号 | 用 `--template` 重新生成；分隔符用英文逗号；金额写 1200 |
| 1「金额…看不懂」「是负数」 | 金额写了文字或负数 | 写数字或 单价*数量；退款写进备注 |
| 2「找不到行程文件」「写不进」 | 路径错、目录不存在或没权限 | 检查路径；`--out` 换到存在的目录 |
| 130 | 手动中断 | 重跑即可，不会留下半截文件 |

## 输出契约

交付物固定按这个顺序：
1. 行程概要：日期、天数、人数、交通方式、预算上限。
2. 避峰判断：出发、返程各建议几点走，哪天是高峰日。
3. 订票订房倒计时：从今天到出发日，每个节点做什么。
4. 每日时间线：脚本输出，或同格式手写。
5. 预算表：分类、小计、应急预备金、总计、人均、与上限对比。
6. 应急预案卡：集合点、联系人、每张票的退改截止时间、每天的室内备选。
7. 待确认清单：全部 [待确认]、[待补] 项。

占位符：用户没给的写 [待补：…]；放假安排、免费通行、预售期、价格等要去官方渠道核实的写 [待确认：…]。

交付前自检（逐条答是/否）：
- [ ] 免费通行写了「以交通运输部当年通知为准」，放假安排、预售期、景区预约也都写了以官方为准？
- [ ] 全文没有景点排名或"必去榜"？
- [ ] 每天都有安排，没有 ⚠ 时间重叠？
- [ ] 总计 = 分项小计 + 预备金，人均算对？
- [ ] 应急预案卡写了集合点和联系人？
- [ ] 每个 [待确认]、[待补] 都进了待确认清单？

2. 避峰：出发日是假期第 2 天，不在经验出程高峰，选早上 7 点前的车次；返程在假期第 5 天，避开最后两天。

6. 应急卡：集合点 = 景区 B 游客中心门口；两人互存对方和民宿电话；民宿免费取消截止 09-30 18:00；第 3 天室内备选是县博物馆。
7. 待确认：[待确认：假期起止以放假通知为准]、[待确认：县博物馆预约放号时间]、[待补：民宿地址电话]。

## 常见问题（FAQ）

- **离国庆只剩几天，还来得及吗？** 来得及做降级版：先锁交通（候补、中转、错开一天或改近郊自驾），住宿只订可免费取消的，目的地换成 2 小时车程内。
- **高速哪天开始免费、按什么时间算？** 常见规则是假期第一天 0 点到最后一天 24 点、高速按驶离出口时间判定——一律以交通运输部当年通知为准。
- **能直接告诉我哪里人少吗？** 不做排名。把候选地发来，我用住宿价格倍数、余票、预约余量这些信号帮你比。
- **能帮我抢票、订酒店吗？** 不能代下单或抢票；我把开售时间、候补步骤、备选车次列成清单，你到点自己操作。
- **带老人小孩怎么调？** 每天核心景点减到 1 个并留午休；集合点和联系卡必备；常用药自带，行程表写上每天最近的医院。
- **预算为什么多留 10%？** 黄金周改签、临时加一晚、打车加价都常见；10% 是默认值，脚本用 `--reserve` 可调。
- **和「旅行规划」技能有什么区别？** 它管完整行程；这里只管黄金周特有的错峰、抢票节奏、人多应急与高峰预算，两者可以一起用。

## 常见错误（反模式）

- 假期第 1 天早上和大家一起出城 → 正撞出程高峰 → 提前一天走或错开时段（第 2 步）。
- 为了免费专门挤零点上下高速 → 收费站排长队又熬夜开车，而且免费时段和判定时点以交通运输部当年通知为准 → 按路况选时段。
- 用平时价估住宿 → 预算严重低估 → 按查到的国庆当晚实价填。
- 每天排 4–5 个热门点 → 排队时间翻倍、全员疲惫 → 每天核心 1–2 个，加 1 个室内备选。
- 订不可退的房和票 → 行程一变全损 → 优先可免费取消，截止时间写进备注。
- 只约定"走散了打电话" → 人多信号差、手机没电 → 固定集合点 + 联系卡。
- 照搬网上"小众景点"清单 → 一传播就不小众 → 用第 3 步的信号实查。

## 边界与不做什么

- 不做景点排名或推荐榜；不代下单、不抢票、不写刷票脚本。
- 不提供实时余票、路况、房态、天气；放假安排以国务院办公厅当年通知为准，小型客车免费通行以交通运输部当年通知为准，预售期与退改以 12306 和各平台规则为准。
- 不给医疗建议；出行中遇到急病、事故、走失，先联系现场工作人员并拨打 110、120 或 122。
- 不指导违规：占用应急车道、超员、疲劳驾驶、逃票、倒卖车票门票。
- 签证、出境和境外行程转「旅行规划」技能。
