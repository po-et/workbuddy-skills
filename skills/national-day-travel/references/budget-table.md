# 黄金周预算表：怎么估、怎么填、超了先砍什么

本文件是 SKILL.md 第 7 步的展开。原则只有一条：**所有金额按你查到的国庆实价填，不用平时价估。**

## 1. 预算表模板

| 类别 | 怎么估 | 金额（元） |
|---|---|---|
| 交通 | 大交通：票价 × 人数 × 往返；自驾：油费或电费 + 免费时段以外的过路费（免费时段以交通运输部当年通知为准）+ 停车费；当地交通：打车、公交、景区接驳 | |
| 住宿 | 国庆当晚实价 × 晚数（同一家店不同日期价格可能不同，逐晚查） | |
| 餐饮 | 人数 × 天数 × 每人每天标准；景区内吃饭通常更贵，按实际菜单估 | |
| 门票 | 门票 + 索道、观光车、预约费等 × 人数 | |
| 购物 | 自己设一个上限 | |
| 其他 | 保险、寄存、雨具、充电宝租借等 | |
| 分项小计 | 以上相加 | |
| 应急预备金 | 小计 × 10%（默认，可调） | |
| 总计 | 小计 + 预备金 | |
| 人均 | 总计 ÷ 人数 | |

为什么要预备金：黄金周改签、临时加一晚、打车加价都常见，10% 是默认值，带老人小孩或行程变数大的可以调到 15%–20%（脚本用 `--reserve` 调）。

## 2. 超预算时先砍什么

按"对体验影响从小到大"的顺序砍：
1. 住宿位置：住远一点、每天通勤进城，常常比换差一档的房更省。
2. 行程天数：少住一晚，影响往往比少去一个景点小。
3. 景点数量：每天只留 1 个核心安排。
4. 购物上限。

不砍的：安全相关的开销（正规交通、带老人小孩时的休息时间）和应急预备金。

## 3. 写成脚本能读的 CSV

表头：`日期,开始,结束,事项,类别,金额,备注`

- 只有「日期」「事项」必填；`#` 开头的行是注释。
- 金额填这一项**全队合计**，可以写 `单价*数量`，例如 `148*2`；不要写千分位逗号。
- 类别写「交通 住宿 餐饮 门票 购物 其他」之一；写「高铁」「酒店」「午饭」也会自动归类。
- 提前付的款（比如出发前一周订的门票）照常写真实日期，脚本会列进"行程日期之外的条目"并计入预算。
- 退改截止时间写进备注，脚本会原样带进时间线。

生成模板：

```bash
python3 scripts/golden_week_plan.py --template > itinerary.csv
```
