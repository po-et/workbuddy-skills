# 避峰时段、错峰目的地打分与订票倒计时

本文件是 SKILL.md 第 2–4 步的展开。所有时段规律都是**经验规律**（据往年公开的出行预测归纳），每年以交通部门和导航软件的节前预测为准。

## 1. 出发与返程时段对照

| 你的情况 | 最好 | 次选 | 尽量别 |
|---|---|---|---|
| 能请假 | 节前一天上午走（避开下班后的出城车流） | 假期第 1 天清晨（天亮前后） | 节前最后一个工作日下班后 |
| 不能请假 | 假期第 1 天清晨，或第 1 天午后 | 假期第 2 天 | 假期第 1 天上午 |
| 返程 | 提前一天回 | 最后一天清早出发 | 最后一天下午到晚上 |
| 车程 2 小时内的周边游 | 早出早归：早上 8 点前出城、下午 3 点前往回走 | 住一晚，第二天错开回城 | 和大家同时段进出城 |

用法：先按上表定"哪一天"，再在出发前一晚和出发前 1 小时各看一次导航的预测，定"几点"。

调休提醒：节前或节后常有调休上班日，请假前先对照当年放假通知，看清哪天要上班、请几天假能拼出更长的连休。

## 2. 错峰目的地打分表（可直接填）

每个信号 0 = 不挤、1 = 一般、2 = 很挤。只和自己的候选地比，不跟网上的榜单比。

| 信号 | 0 分 | 1 分 | 2 分 | 候选 A | 候选 B | 候选 C |
|---|---|---|---|---|---|---|
| 住宿价格倍数（国庆当晚价 ÷ 平时周末价） | 涨得最少的那个 | 居中 | 涨得最多的那个 | | | |
| 交通余票（目标日期） | 余票充足 | 部分车次紧张 | 售罄、只能候补 | | | |
| 景区预约余量 | 随时可约 | 需提前几天 | 提前多日约满或不开放预约 | | | |
| 离大城市远近 | 需要大半天路程 | 半天可达 | 大城市一日往返可达 | | | |
| 近期热度 | 近期没什么讨论 | 有讨论 | 近期被大量传播 | | | |
| **合计** | | | | | | |

判断：
- 合计最低的就是这次的错峰候选；同分选退改更灵活、有室内备选的。
- 住宿价格倍数是最好用的一条：同一家店、同一房型，国庆当晚价除以平时周末价，倍数反映真实需求。
- 某一项拿 2 分不代表不能去，而是要配套错峰：比如景区预约紧张，就约开园第一场。

## 3. 订票订房倒计时（以出发日为 T）

| 时间点 | 做什么 | 以谁为准 |
|---|---|---|
| T-30 天以前 | 定目的地、交通方式；住宿先订可免费取消的占位 | 预订平台的取消规则 |
| 火车票开售日 | 开售日 = 出发日往前数预售期；开售前设提醒；没买到就提交候补，同时查中转和错开一天的车次 | 预售期、候补规则以 12306 公告为准 |
| 机票 | 价格随时间变化，定了日期就可以开始盯；看清退改条件再付款 | 航司和订单的退改规则 |
| T-14 起 | 查景区预约规则（何时放号、是否实名、分几个场次），到点预约；热门餐厅订位 | 景区官方渠道 |
| T-3 | 看天气预报与景区公告；把每张票、每间房的退改截止时间写进行程表备注 | 气象部门、景区公告 |
| T-1 | 截图保存全部凭证；自驾的检查车况，新能源车充满电 | — |
| T 当天 | 出发前 1 小时看导航预测再出门 | 导航实时数据 |

### 只剩几天才开始（降级方案）

1. 先锁交通：候补 + 中转 + 错开一天，三条路同时准备；实在没有就改自驾或近郊。
2. 住宿只订可免费取消的，先占住，边走边换。
3. 目的地收缩到车程 2 小时内，行程改成"住一处、每天往返"。
4. 行程每天只定 1 个核心安排，其余留给现场判断。

## 4. 官方信息去哪查（不给链接，按名称找）

| 要核实的事 | 去哪查 |
|---|---|
| 放假与调休安排 | 国务院办公厅发布的当年部分节假日安排通知 |
| 小型客车免费通行 | 交通运输部发布的当年节假日免费通行相关通知或公告 |
| 火车票预售期、候补、退改 | 12306 网站或 App 的公告与购票须知 |
| 航班与退改 | 航司官网或 App、订单详情里的退改规则 |
| 景区预约、限流、临时闭园 | 景区官网、官方公众号或预约小程序的公告 |
| 路况与出行预测 | 各地交警、高速公路运营方的官方发布，导航软件的预测 |
| 天气 | 气象部门发布的预报 |
