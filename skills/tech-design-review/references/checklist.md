# 五视角评审清单（逐条打钩）

## QA
- [ ] 每个需求点都有可验证的验收标准（输入 → 期望输出）
- [ ] 列出了异常路径：超时、部分失败、重复请求、空数据、极大数据
- [ ] 兼容性：老数据能读吗；老客户端还能用吗；新旧版本并行期怎么处理
- [ ] 测试分层：单元 / 集成 / 端到端各测什么；测试环境与数据从哪来
- [ ] 灰度期间如何验证正确性（对账、抽样、差分）

## SRE
- [ ] 容量：QPS、数据量、增长率的估算依据；压测计划
- [ ] 单点：哪个组件挂了整体不可用；依赖故障（DB、缓存、MQ、第三方）的降级方案
- [ ] 调用链：超时时间、重试次数与退避、幂等键、限流阈值、熔断条件
- [ ] 可观测：核心指标（成功率、延迟、队列积压）、日志字段、trace 传递、告警阈值与值班
- [ ] 上线：分批步骤、每批验证项、回滚触发条件与步骤、数据不可逆点
- [ ] 配置与开关：新功能能否一键关闭；配置变更是否需要重启

## 安全
- [ ] 每个接口的鉴权与授权；越权（横向/纵向）如何防
- [ ] 输入校验；SQL/命令/模板注入；文件上传限制
- [ ] 敏感数据：字段清单、存储加密、日志脱敏、传输加密
- [ ] 密钥：来源、轮换、不落代码与配置文件
- [ ] 审计：谁在什么时候做了什么可追溯

## 数据
- [ ] 一致性：强一致还是最终一致；不一致窗口多长；对账机制
- [ ] 迁移：双写/回填/切读的顺序；每步可回退
- [ ] schema 变更：是否可逆；大表变更的锁与耗时
- [ ] 备份与恢复：RPO/RTO；演练过吗
- [ ] 生命周期：数据保留期、归档、删除

## 成本
- [ ] 资源清单与月账单估算；峰值与常态
- [ ] 运维负担：新增多少需要人盯的东西
- [ ] 锁定：换掉这个第三方/云服务要多久
- [ ] 排期与收益：晚一个月上线损失多少；砍掉哪部分能提前
