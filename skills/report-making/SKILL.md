# 报表制作

定位一句话：**报表不是把数据摆出来，而是让一个具体的人看完能做一个具体的决定；读者和决定没定，一个指标都别加。**
何时用：新做或重做周报、月报、专题数据报表；老板说「看不出重点」；两份报表同一个数对不上；要把 Excel 明细汇总成固定格式。指标本身怎么选、权重怎么分属于 KPI 制定，本技能只管把已定的指标做成报表。

## 先判断：谁看，看完决定什么

动手前填完这三行，填不出来先去问，别急着做表：

```
读者      谁看（职位、人数），在哪看（手机群消息 / 邮件 / 例会投屏），愿意看几分钟
决策问题  看完要决定 ____（例：下周预算要不要往华东倾斜）
必要的数  回答这个问题最少要哪几个数，各跟什么比（上期 / 去年同期 / 目标）
```

读者不同，报表形态完全不同：管理层要一页、结论先行、不超过 5 个指标、每个数都配对比，关心「达没达标、要不要加资源」；业务负责人要能下钻到区域、渠道、产品，关心「哪里掉了、为什么」；一线要看自己的数和待办。同一份数据给三类读者，就做三个版本，不要做一张大表让大家各取所需。自检：拿掉某个指标，决策受不受影响？不受影响的移到附表或删掉。

## 流程：从口径到发布五步

**第 1 步 定口径。** 每个指标写清定义（数什么、不数什么）、来源（哪个表或导出文件的哪个字段）、粒度（按订单、用户还是门店计，汇总到日、周还是月）、更新频率（每天几点出前一天的数、月数据哪天冻结）。时间口径写死：以下单、支付还是完成时间为准；一周从周一还是周日算起。口径写好后请业务负责人书面确认一次，之后的改动都走版本号。
**第 2 步 搭表。** 行放维度（时间、区域、渠道、产品），列放指标和对比。一张表只回答一个问题；维度最多两层；按指标值降序排；单位写进表头，同列小数位一致；合计行加粗。明细存成一行一条记录的长表，展示表由透视表或公式生成，不手敲数字。
**第 3 步 选图。** 先写下这张图回答什么问题，再按下表选：

```
看趋势  折线图，时间放横轴；只有两三期就用柱形图
比大小  横向条形图，按数值排序
看构成  堆积柱形图；饼图只用于不超过 5 块且合计 100% 的情况
看达成  条形图加目标线，或直接用表格列完成率
看分布  直方图、箱线图；看两个指标的关系用散点图
不用    3D 图、双纵轴、纵轴不从 0 开始的柱形图
```

图标题直接写结论，如「华东连续三周下滑，主要掉在线上渠道」，而不是「华东销售额趋势」；要读者注意的那条线用深色，其余用浅灰。

**第 4 步 标异常。** 先定规则再看数据。默认阈值（按业务波动调整）：环比变化超过 ±20% 且绝对量变化够大（小基数的 20% 没意义），或超出近 8 周均值 ±2 倍标准差。表里用 ▲▼ 加颜色，不只靠颜色，黑白打印也要看得出。每个异常写「现象—原因—影响—动作」，原因没确认就写「待查，负责人 ____」。异常值不删不改；确属数据错误的，修正后在数据说明里写明改了什么。口径变更点在趋势图上画竖线标注。
**第 5 步 定节奏。** 例如周报每周一 10:00 发上周（数据截至周日 24:00），月报在次月第 3 个工作日前发。时间、模板固定，口径带版本号；发出后发现错误，发更正说明（错在哪、正确的数、影响哪些结论），不悄悄替换附件。

## Excel 做法：数据透视与基础公式

透视前先把明细整理成一维表：单行表头、一列一个字段、无合并单元格、无空行空列、日期是真日期、数字不是文本（单元格左上角有绿色小三角的，多半是文本数字）。

```
1 选中明细按 Ctrl+T 转成表格，表名改成「明细」，新增行自动纳入
2 插入 → 数据透视表 → 新工作表；行放维度，列放时间，值放指标
3 值默认成了「计数」，说明该列混有文本或空值，回去清洗
4 日期字段右键 → 组合 → 月 / 季度 / 年
5 占比、环比：值字段设置 → 值显示方式 →「总计的百分比」「差异百分比」
6 率类指标用计算字段（分子字段 ÷ 分母字段），它按合计值相除，正合适
7 插入切片器，读者可以自己按区域、渠道筛
8 源数据改动后点 数据 → 全部刷新，透视表不会自己更新
9 核对：透视表总计必须等于明细列求和，不等就查筛选、空白行和文本数字
```

常用公式（B1 填月初日期；日期区间用「≥ 月初且 < 下月初」，带时刻的记录才不会漏掉最后一天）：

```
当月金额  =SUMIFS(明细[金额],明细[区域],$A2,明细[日期],">="&$B$1,明细[日期],"<"&EDATE($B$1,1))
环比      =IFERROR(C2/D2-1,"—")  C 本期、D 上期；上期为 0 或空时显示 —
转化率    =IFERROR(SUMIFS(明细[成交],明细[区域],$A2)/SUMIFS(明细[访客],明细[区域],$A2),"—")
查目标    =XLOOKUP($A2,目标[区域],目标[月目标],"未设目标")  旧版没有 XLOOKUP，改用 INDEX 加 MATCH
周序号    =WEEKNUM(A2,2) 以周一为一周开始；不想让元旦切开一周用 =ISOWEEKNUM(A2)，跨年那几天会归到相邻年份
```

计数就把 SUMIFS 换成 COUNTIFS，去掉求和列即可。

上透视表前，用下面的脚本给导出的明细 CSV 体检，能一眼看出「华东」「华东 」「华东区」这类同物异名、空值和重复行：

```bash
python3 - 明细.csv <<'EOF'
import csv, sys, collections
rows = list(csv.DictReader(open(sys.argv[1], encoding='utf-8-sig')))  # 报 UnicodeDecodeError 就改成 gbk
print('行数', len(rows))
for col in rows[0]:
    vals = [r[col] or '' for r in rows]
    uniq = sorted(set(vals))
    print(col, '空值', sum(not v.strip() for v in vals), '不同值', len(uniq), uniq[:15])
dup = collections.Counter(tuple(map(str, r.values())) for r in rows)
print('重复行', sum(n - 1 for n in dup.values() if n > 1))
EOF
```

## 模板：周报、月报、口径说明

```
××业务周报｜2026 年第 38 周（9 月 14 日至 9 月 20 日）
数据截至 9 月 20 日 24:00｜口径版本 v1.2｜每周一 10:00 发布
一、本周结论（最多 3 条，每条带数字和对比）
1. 销售额 ____ 万元，环比 ____%，完成周目标 ____%
2. 变化最大的是 ____，原因 ____（已确认 / 待查）
3. 需要决定 ____，请 ____ 在 ____ 前回复
二、核心指标  | 指标 | 本周 | 上周 | 环比 | 周目标 | 完成率 | ▲▼ |
三、异常（只列超阈值的）  现象 — 原因 — 影响 — 动作 — 负责人
四、下周动作  事项 — 负责人 — 截止日
五、数据说明  口径变更、已知数据问题、补数计划
```

```
××业务月报｜2026 年 9 月（数据截至 9 月 30 日 24:00，口径版本 v1.2）
一、本月结论（3 条，先结论后数字）
二、目标达成  | 指标 | 本月实际 | 本月目标 | 完成率 | 年累计 | 年目标 | 累计完成率 | 时间进度 |
  时间进度 = 已过天数 ÷ 全年天数；累计完成率低于时间进度的标红
三、趋势  近 13 个月折线，最后一个点可直接和去年同月比
四、结构拆解  按区域、渠道、产品各一张表，按贡献度降序
  贡献度 = 该项增量 ÷ 整体增量（增量 = 本期 − 对比期）
五、异常与专题  每条：现象 — 原因 — 影响 — 动作
六、下月计划与风险  事项 — 负责人 — 截止日
七、附录  口径说明与变更记录
```

```
指标名称  ____（字段名 ____）
定义      一句话：数什么、不数什么
计算公式  分子 ____ ÷ 分母 ____；单位 ____；保留 __ 位小数
数据来源  ____ 表或导出文件的 ____ 字段；取数人 ____
统计粒度  按 订单 / 用户 / 门店 计；汇总到 日 / 周 / 月
时间口径  以 下单 / 支付 / 完成 时间为准；周一至周日为一周
剔除规则  测试单、内部账号、全额退款单 ____
更新频率  每天 __ 点出前一天数据；月数据次月第 __ 个工作日冻结
版本      v__，生效日期 ____；变更记录：日期 — 改了什么 — 影响哪些历史数
```

## 最常见的错误

1. 把各区域转化率求平均当总转化率。率只能用总分子除以总分母，否则小区域会把结果带偏。
2. 口径悄悄变：本周起剔除退款却没写，趋势图凭空出现一个断崖。
3. 只有数没有对比：每个数至少配一个参照——上期、去年同期或目标。
4. 周的定义各用各的，两份周报差出一天的数。
5. 发现异常就删掉，或者只标红不写原因。
6. 不写数据截至时间，读者拿周三的数和周五的数比。
7. 指标越加越多：每加一个，先说清它回答哪个决策问题。

## 输出契约

1. 先交「读者—决策问题—指标清单」请用户确认，再搭表、出模板。
2. 每个指标一张口径卡，字段不留空；取不到的写「待取数」，不编数字、不估算填空。
3. 表结构给表头草图，写清透视表字段怎么摆、每列用什么公式。
4. 每张图写明回答什么问题、为什么选这种图。
5. 写明异常阈值、标注方式、截至时间、发布时间和更正办法。
6. 格式为 Markdown 表格与纯文本模板，可直接粘进 Excel 或文档。

## 边界与不做什么

- 不接任何内部系统、数据库或 BI 平台，不代为取数；数据由用户导出成 Excel 或 CSV 提供。
- 不做资产负债表、利润表、现金流量表等会计报表的编制、审计与税务处理，这些找会计或审计师。
- 不给投资建议，不对经营结果做预测或承诺；报表里的归因是假设，由业务负责人确认。
- 不对具体员工下绩效结论；含姓名、手机号的明细先脱敏再处理。
- 口径跨部门有分歧时，由双方负责人对齐，本技能只负责把分歧摆清楚。
