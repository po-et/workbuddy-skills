# Word 排版

定位一句话：**文档乱，根子在格式直接刷在文字上。先定样式、再放内容，改一处样式全文跟着变，加一章时编号、目录、题注自动跟上。**

## 何时使用

要把一份 Word 文档排成规范的样子（毕业论文、单位公文、简历、报告），或者文档已经乱了：满是手动空格、手打编号、回车撑出来的分页，目录页码对不上，改一个标题要改十处。菜单名按 Microsoft Word 中文版写，快捷键按 Windows 版；Mac 版和 WPS 文字都有同名功能，位置略有不同，按菜单名找。用户这样说时用本技能：

- 「毕业论文格式怎么排，目录和页码总是对不上」→ 先要学校规定，再按八步排，最后更新目录
- 「页码怎么从正文开始，前面摘要目录用罗马数字」→ 只给分节和页码那一步
- 「这份 Word 全是手动空格和手打编号，帮我排成规范的样子」→ 先跑体检脚本，再按问题清单逐项改
- 「图表编号怎么自动，插了一张图后面全乱了」→ 题注和交叉引用
- 「公文格式怎么设」「简历怎么排得整齐」→ 对应的常见规格，以单位或招聘方要求为准

不适用：

- 代写论文、公文、简历的内容：转对应的写作类技能；本技能只管版式。
- PDF 转 Word、扫描件识别、LaTeX 排版、.doc 老格式体检：不做；.doc 先另存为 .docx 再来。
- 查重、学术规范、公文的密级和签发流程：找导师、教务或单位办公室。

## 先判断：按谁的规范、交付什么、乱在哪

1. **按谁的规范。** 学校的论文模板、单位的公文模板、招聘方的简历要求，有就以它为准；本页的三套规格只在手上没有规定时参考。
2. **交付什么。** 打印稿、PDF，还是 Word 原件交给别人接着改？要给别人接着改的，更要全部走样式。
3. **乱在哪。** 打开「显示编辑标记」（开始 → 段落里的 ¶ 按钮，快捷键 Ctrl+Shift+8）：一串「·」是空格，一串「¶」是空段落，「↵」是手动换行符，分页符和分节符也会显示出来。再跑一遍下文的体检脚本，拿到问题清单。

检查点：写下三样东西，依据哪份规范、交付格式、要改的问题清单，再动手。

## 先样式后内容：八步流程

```
1 备份并清直接格式  另存「原名_排版」；Ctrl+A 后 Ctrl+Space 清文字格式、Ctrl+Q 清段落格式（别用「清除所有格式」按钮）
2 查找替换清垃圾    ^l→^p 改真段落；^p^p→^p 删空段落；^m 逐个看手动分页符；通配符 [ ]{2,} 找连续空格
3 定样式            改「正文」「标题 1/2/3」「题注」；首行缩进用 2 字符，标题 1 勾「段前分页」；放图的段落别用固定值行距
4 套样式            标题 Ctrl+Alt+1/2/3，正文 Ctrl+Shift+N；导航窗格里层级完整才算对
5 多级编号绑标题    多级列表 → 定义新的多级列表 → 级别链接到「标题 1/2/3」；二级要显示 1.1 就勾「正规形式编号」
6 题注和交叉引用    引用 → 插入题注（勾「包含章节号」）；正文用 引用 → 交叉引用，不手写「见图 3」
7 分节与页码        封面后、目录后各插「下一页」分节符；点掉「链接到前一节」；罗马数字与「起始页码 1」分节设置
8 目录，最后更新    引用 → 目录 → 自定义目录；改完右键更新整个目录，交付前 Ctrl+A 再按 F9
```

每一步的完整操作、注意事项和菜单路径见 [references/eight-steps.md](references/eight-steps.md)。

## 三套常见规格（以学校、单位、招聘方的规定为准）

毕业论文（正文、各级标题、图表题注、页眉页码、目录与参考文献）、单位公文（版心、行和字、层次序数、页码、成文日期，以 GB/T 9704 原文和本单位办法为准）、简历（篇幅、字号、行距、左右对齐）的常见要求，以及「号」和「磅」的换算表，见 [references/spec-sheets.md](references/spec-sheets.md)。这些是常见要求，不是标准答案；与手上的书面规定冲突时，一律以规定为准。

## 排查清单与体检脚本

| 痕迹 | 怎么认 | 改成 |
|---|---|---|
| 手动空格对齐、缩进 | 显示编辑标记后是一串「·」 | 首行缩进、制表位或表格 |
| 手打编号 | 点一下编号，整列编号不会一起变灰 | 多级列表绑定标题样式，或列表编号 |
| 硬回车分页 | 页尾一串「¶」，前面加一行字后面全乱 | 标题 1 勾「段前分页」，或分页符 Ctrl+Enter、分节符 |
| 空段落撑间距 | 段落之间单独一个「¶」 | 样式里的段前段后间距 |
| 手打目录 | 目录里的点线是打上去的，点了不跳转 | 引用 → 目录 |
| 手打题注和「见图 3」 | 「图1」是普通文字，调了图序编号不变 | 插入题注、交叉引用 |
| 直接格式 | 同级标题大小不一，样式检查器里显示「直接格式」 | 改样式，Ctrl+Space、Ctrl+Q 清掉 |
| 手动换行符 | 行尾是「↵」不是「¶」 | 查找 `^l` 替换为 `^p` |
| 页码不对 | 封面有页码，正文不从 1 起 | 分节，点掉「链接到前一节」，设起始页码 |
| 表格跨页没表头 | 第二页的表格没有标题行 | 表格属性 → 行 →「在各页顶端以标题行形式重复出现」 |
| 图片乱跑 | 图片是「浮于文字上方」 | 改成「嵌入型」，单独一段居中 |

体检脚本只读 .docx、不改文件，只用 python3 标准库（.doc 老格式先另存为 .docx）。它统计样式使用、标题样式、自动目录、题注域、交叉引用、分节和页码，并找出手打编号、手打题注、手打目录行、连续空格、像标题却没用标题样式的段落、连续空段落。表格、文本框和目录条目里的段落不查。它是启发式检查，结果逐条人工确认。

```bash
python3 scripts/docx_check.py 论文.docx
```

在一份故意排乱的测试文档上，本机跑出的结果：

```

[连续空格或行首空格（手动对齐、手动缩进）] 2 处，例：「近年来，这一问题受到关注。这一段用全角空」、「本章用了三种方法。    这里有连续空格」

```

## 输出契约

交付物按下面的顺序，每次都一样：

1. **规格表**：这份文档采用的规格，每一项注明来源（学校或单位的文件，还是本页的常见要求）。
2. **体检结果**：脚本输出加人工看到的问题，按排查清单归类，写明在第几章、哪一段。
3. **操作步骤**：按八步流程写出这份文档要做的具体操作，菜单路径和每一项设的值都写全。
4. **验收清单**：导航窗格层级完整；目录能点击跳转、页码正确；题注和交叉引用已更新；每一节页码正确；导出 PDF 后字体没有被替换。
5. **待确认清单**：规格里标了 [待确认] 的项、需要用户提供的 [待补]（学校规定原文、字体文件等）。

本技能不带写 .docx 的工具，排版操作由用户在 Word 或 WPS 里完成；脚本只读文件做体检。

占位符规则：[待确认] = 没有书面规定、按常见要求先定的数值，或两种理解先选了一种；[待补] = 需要用户提供的（学校规定原文、模板、字体）。

交付前自检（每条都答「是」才交）：

- [ ] 规格表每一项都注明了来源，没有把常见要求说成「学校规定」？
- [ ] 体检结果逐条写了位置（第几章、哪一段），误报已经剔除？
- [ ] 操作步骤里每个菜单路径和数值都写全了，能照着一步步点？
- [ ] 验收清单五项都在，包括导出 PDF 核对字体？
- [ ] 菜单名只用了本页和 references 里出现过的，版本差异已提醒？

## 示例

（示例，场景虚构）

> 用户：页码怎么从正文开始，前面摘要目录用罗马数字？

助手：先确认一句——封面要不要页码？（默认不要，标 [待确认]）然后给这份文档要做的操作：

1. 在封面最后、目录最后各插一个分节符：布局 → 分隔符 →「下一页」。文档分成三节：封面、摘要和目录、正文。
2. 双击正文第一页的页脚进入编辑，点掉「链接到前一节」；摘要和目录那一节的页脚也点掉。页眉要不同的话，页眉也分别点。
3. 摘要和目录那一节：插入 → 页码 →「设置页码格式」，编号格式选罗马数字，「起始页码」从 i 开始。
4. 正文那一节：插入 → 页码 →「设置页码格式」，编号格式选 1, 2, 3，「起始页码」填 1。
5. 封面不要页码 [待确认]：封面已单独成节，删掉这一节页脚里的页码即可；或者在该节勾「首页不同」。
6. 最后右键目录 →「更新域」→「更新整个目录」，让目录里的页码跟着变。

验收：逐节翻一遍，封面无页码、摘要和目录是 i、ii……、正文第一页是 1；目录里每章的页码和实际一致；导出 PDF 再看一遍。
想确认分节和页码设好了，可以跑 `python3 scripts/docx_check.py 论文.docx`，看「分节」「页码重新起算」两项的数目。

完整示例（一份满是手动空格和手打编号的论文：体检 → 规格表 → 逐步操作 → 验收）见 [examples/thesis-cleanup.md](examples/thesis-cleanup.md)。

## 常见问题（FAQ）

**我用 WPS 或 Mac 版，菜单找不到怎么办？** 都有同名功能，位置略有不同，按菜单名找；快捷键本页按 Windows 版写。

**目录里的页码和实际对不上？** 改完内容后右键目录 →「更新域」→「更新整个目录」；交付前 Ctrl+A 再按 F9，把题注和交叉引用一起更新。

**一级标题是「第一章」，二级却显示成「一.1」？** 定义多级列表时在级别 2 勾「正规形式编号」。

**图片只显示一半、被裁掉了？** 段落行距设成了「固定值」；放图片的段落改用单倍行距，图片改成「嵌入型」。

**发给别人打开后字体变了？** 对方电脑没装这个字体就会被替换；交付前导出 PDF 核对一遍。

**能直接帮我把 docx 改好发回来吗？** 本技能不带写 .docx 的工具：给你这份文档的具体操作步骤，脚本只读文件做体检。

**学校要求和你给的规格不一样，听谁的？** 以学校规定为准；本页规格只在手上没有规定时参考。

**.doc 文件能体检吗？** 不能直接体检；在 Word 里另存为 .docx 再跑脚本。

## 常见错误（反模式）

每条：错误做法 → 为什么错 → 正确做法。

1. **用空格对齐、用空格缩进** → 改一个字就全乱，换台电脑也对不齐 → 首行缩进 2 字符、制表位或无框线表格。
2. **手打编号（「第一章」「1.1」打成文字）** → 增删一章，后面的编号全要手改 → 多级列表绑定标题样式。
3. **用回车撑间距、用回车分页** → 前面加一行字，后面全部错位 → 样式里设段前段后；标题 1 勾「段前分页」，或用分页符、分节符。
4. **手打目录、手写「见图 3」** → 点了不跳转，调整后编号和页码不跟着变 → 引用 → 目录；插入题注、交叉引用。
5. **用「清除所有格式」按钮清格式** → 标题也被打回「正文」 → Ctrl+Space 清文字格式、Ctrl+Q 清段落格式，样式保留。
6. **放图片的段落用固定值行距** → 图片和大号公式被裁掉 → 放图的段落改单倍行距。
7. **页码不分节、不点掉「链接到前一节」** → 封面有页码、正文不从 1 起 → 分节后各节分别设页码格式。
8. **改完内容不更新域就交付** → 目录页码、题注编号还是旧的 → 右键更新整个目录，Ctrl+A 再按 F9。
9. **格式直接刷在文字上、不改样式** → 同级标题大小不一，改一处要改十处 → 先改样式，再套到段落上。
10. **交付前不导出 PDF 核对** → 对方没装的字体被替换，版面跟着变 → 导出 PDF 逐页看一遍。

## 边界与不做什么

- 文中的菜单路径与快捷键按常见的 Word 桌面版写，未在每个版本里逐一点验；WPS、Word 网页版或旧版本的名称和位置可能不同，以你所用版本为准。
- 规格数值都是常见要求，以学校、期刊、单位、招聘方最新的书面规定为准，有冲突时以规定为准，拿不准就问导师、教务或单位办公室。
- 只管版式，不代写论文、公文、简历的内容。
- 不处理 .doc 老格式的体检、PDF 转 Word、扫描件识别，也不做 LaTeX 排版。
- 查重、学术规范、公文的密级和签发流程不在本技能范围，找导师、教务或单位办公室。
- 不处理涉密文件；含个人信息的文档只在本机检查，不上传到别处。
