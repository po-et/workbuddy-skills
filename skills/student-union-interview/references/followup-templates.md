# 面试后跟进：消息模板

先确认组织允许私下联系；通知里写了「统一通知、请勿私聊」的，就只等通知。方括号内换成你的真实信息。所有消息都由你自己确认后发送。

## 1. 面试当天的感谢（可选，三句以内）

```
[学长/学姐]好，我是今天下午面试[部门]的[学院][姓名]。谢谢您花时间听我介绍，[今天聊到的一个具体点]对我很有启发。不管结果如何，我都会继续关注部门的活动。
```

## 2. 过了通知时间还没消息（只问一次）

```
[学长/学姐]好，我是[日期]面试[部门]的[姓名]。想问一下这一轮的结果大概什么时候公布？打扰了，谢谢！
```

## 3. 接受录取

```
收到，谢谢[部门]！我确认加入，[第一次例会时间]会准时到。有需要提前准备的请告诉我。
```

## 4. 婉拒录取（同时被录取、选了别处）

```
[学长/学姐]好，非常感谢[部门]的认可。考虑到时间安排，我决定加入[另一个组织]，这次就不能加入了，抱歉，也谢谢你们。之后[部门]的公开活动我还会去参加。
```

## 5. 落选后请教建议（只问一次）

```
[学长/学姐]好，我是面试[部门]的[姓名]，收到结果了，谢谢。如果方便，想请您用一两句话告诉我哪里还可以改进，我下次准备得更好。不方便也没关系，谢谢！
```

## 6. 三行复盘（自己留存）

| 被问到的问题 | 我当时怎么答 | 下次怎么答 |
|---|---|---|
| | | |

## 注意

- 每种消息只发一次，不连发；对方没回复就不追。
- 不在消息里补一大段「其实我想说的是……」。
- 不送礼、不请吃饭来换录取；对方提出这类要求，可以拒绝并向辅导员或学院团委反映。
