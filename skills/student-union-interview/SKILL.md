# 学生会面试

定位一句话：**面试官在 5–10 分钟里只想确认三件事——你为什么来、时间上靠不靠得住、跟这个部门合不合得来。** 每个回答都用你自己做过的一件具体小事来证明，不背空话，更不编经历。

## 何时使用

- 「明天学生会面试，帮我准备自我介绍和可能问的问题」
- 「社团面试一般问什么，怎么答」
- 「二面是无领导小组讨论，我该当什么角色」
- 「竞选班委要上台讲一分钟」
- 「面试完要不要给学长学姐发消息，落选了怎么办」

不适用（遇到时这样处理）：

- 实习、求职、考研复试、保研面试：本技能只覆盖校园组织面试；可以简答通用原则（先说结论再举真实例子），建议另找求职或复试类技能，或去学校就业指导中心。
- 只是在班级、宿舍、群里做新生自我介绍：转「新生自我介绍」技能（`freshman-self-intro`）。
- 你是招新方，要设计面试和筛选：转「社团招新」技能（`club-recruitment`）。

## 第 1 步：面试前摸底

| 要弄清的事 | 去哪查 | 用在哪 |
|---|---|---|
| 部门具体做什么 | 招新推文、部门介绍、往期 3 篇活动推文 | 回答「为什么选这个部门」 |
| 面试形式 | 面试通知：单面、群面、无领导小组讨论、笔试、作品或才艺 | 决定准备重点 |
| 时间投入 | 推文或问学长学姐：例会频率、活动高峰期 | 回答「时间冲突」时不说空话 |
| 你的真实素材 | 翻自己：高中、军训、暑假里做过的相关小事，会的软件或技能 | 所有「做过什么」类问题 |

素材不够时，花 30 分钟做一个「准备行动」：看往期推文写 3 条改进想法、试做一张海报、试写一篇活动通讯稿。这是真实做过的事，面试时可以拿来讲。

## 第 2 步：部门职责速查（通用描述）

各校部门的名称、分工、设置差别很大，**以本校招新推文和章程为准**。下表只帮你把「我想进这个部门」说具体。

| 常见部门（名称因校而异） | 通常做什么 | 面试官想看到 | 可以拿来证明的真实素材 |
|---|---|---|---|
| 办公室、秘书处 | 会议记录、文件与物资管理、部门间协调 | 细心、守时、做事留记录 | 你整理过的表格、做过的记录 |
| 组织部、人力资源 | 成员管理、培训考核、团建 | 愿意和人打交道、做事公平 | 组织过班级或同学的活动 |
| 宣传部、新媒体 | 推文、海报、视频、账号运营 | 审美和按时交付 | 作品截图或链接 |
| 学习部、学术部 | 讲座、竞赛组织、学风活动 | 学习习惯好、执行力 | 你的学习方法、参赛经历 |
| 文艺部 | 晚会、演出、排练组织 | 才艺或后台组织经验 | 演出、主持、舞台经历 |
| 体育部 | 运动会、院系联赛、赛事组织 | 现场组织、安全意识 | 运动经历、做过裁判或后勤 |
| 外联部 | 联系赞助、对接校外单位 | 沟通、被拒后还能继续、守信 | 和陌生人打交道的经历 |
| 权益部、生活部 | 收集同学诉求、对接后勤 | 同理心、会跟进到底 | 帮同学解决过问题的例子 |

## 第 3 步：1 分钟自我介绍（约 150–200 字）

四段：我是谁（10 秒）→ 为什么是这个部门（20 秒）→ 一件能证明的事（20 秒）→ 我能保证什么（10 秒）。

```
[学长学姐们]好，我是[学院][专业]的[姓名]。
我报[部门]，是因为[一个具体原因：看过你们的哪次活动 / 做过类似的事 / 想学会哪项能力]。
[高中/军训/暑假]我[做过的一件相关小事：做了什么 → 结果或学到什么]。
如果能加入，我每周能保证[真实可投入的时间]，也想在这里学会[一项具体能力]。谢谢！
```

写完测一下字数和时长（按每分钟约 200 字估算并留出停顿余量；只数汉字、英文单词和数字，不数标点。这是经验值，以你自己掐表为准）：

```bash
python3 -c "import re,sys;t=open(sys.argv[1],encoding='utf-8').read();n=len(re.findall(r'[\u4e00-\u9fff]|[A-Za-z]+|\d+',t));print(n,'字，约',round(n/200*60),'秒')" 自我介绍.txt
```

超过 220 字就删形容词和第二个例子。背关键词不背全文：写 4 个关键词（学院专业、原因、那件事、保证），上场前看一遍。

## 第 4 步：20 道高频问题

全部 20 道的考察点、回答思路和雷区见 [references/questions.md](references/questions.md)。分五组：

- 动机：为什么加入；为什么选这个部门；对部门了解多少；想在这里得到什么
- 经历：做过什么相关的事；在活动里具体负责什么；有什么技能；最难的一件事
- 时间：学业和部门冲突怎么办；还报了哪些、都录了怎么选；每周能投入多少；考试周有活动怎么办
- 协作：最大的缺点；和同学意见不合；任务不合理怎么办；用三个词形容自己
- 情景：活动前一天物资少一半；推文发出后发现错字；拉赞助被拒三次；你有什么想问我们的

必问四道，先把要点写出来：

| 问题 | 回答骨架 | 雷区 |
|---|---|---|
| 为什么选这个部门 | 部门做过的一件具体事 → 我和它的连接（做过、喜欢、想学）→ 我能贡献的一点 | 「想锻炼自己、结交朋友」这种谁都能说的话 |
| 时间冲突怎么办 | 学业优先但会提前规划 → 具体做法（周计划、提前说、找人交接）→ 一次真实平衡过的例子 | 承诺「随叫随到」；或说「忙就不去了」 |
| 做过什么 | 情境一句 → 你做的 2–3 个动作 → 结果（数字或别人的反馈）→ 学到什么 | 只说「参加过」不说自己干了什么；编 |
| 最大的缺点 | 真实但不致命的缺点 → 一次它造成的小后果 → 正在用的改进办法 | 「太追求完美」；报办公室却说自己很马虎 |

反问准备两个，问具体工作：「新人第一个月一般负责什么」「部门最近在筹备什么活动」。别问「累不累」「能不能加分」。

## 第 5 步：无领导小组讨论

常见流程：读题 → 每人约 1 分钟陈述 → 自由讨论 → 推选一人总结汇报（时长以现场说明为准）。面试官一般看参与、逻辑、合作、能否推动出结论。

| 角色 | 适合谁 | 关键动作 | 风险 |
|---|---|---|---|
| 组织者 | 敢开口、有条理 | 开局提流程和时间分配 | 控场过度、压别人 |
| 计时者 | 慢热、怕抢话 | 在关键时间点提醒，同时说 2–3 个有内容的观点 | 只报时不说内容 |
| 记录者 | 细心 | 记下每人观点，为总结供料 | 埋头记不发言 |
| 总结汇报者 | 表达稳 | 代表全组说结论、理由、分歧的处理 | 把个人观点当全组结论 |
| 贡献者 | 有想法 | 提关键论据、调和分歧 | 只提观点不推进 |

五句备用话：

- 开局：「我先提个流程：前 5 分钟每人说观点，中间 10 分钟排优先级，最后 3 分钟定结论，大家看行吗？」
- 补充：「我同意 A 说的……，再补充一点……」
- 推进：「现在 1、2 两点大家一致，3 还有分歧，建议先……」
- 邀请：「B 同学还没说，你怎么看？」
- 收口：「还剩 3 分钟，我们先把结论定下来。」

排序题、开放题、两难题、资源分配题的拆法和更多句子见 [references/group-discussion.md](references/group-discussion.md)。

## 第 6 步：班委竞选发言（1 分钟）

我是谁 → 竞选哪个职位、为什么 → 上任后做的 2–3 件具体、做得到的事 → 请求支持。只承诺自己能兑现的事，例如「每周五在群里汇总下周各科作业的截止时间」，不说「保证全班都拿奖学金」。辅导员单独面谈的，按第 4 步的「时间冲突」「做过什么」准备。

## 第 7 步：面试后跟进

- 当天写三行复盘：被问了什么、哪题没答好、下次怎么答。
- 有联系方式、组织没说禁止私聊的，可以发一条三句以内的感谢，不追问结果。
- 过了通知里说的出结果时间两三天还没消息，礼貌问一次。
- 同时被多个组织录取：尽快决定，婉拒的一方要礼貌告知，不要一直不回。
- 落选：可以问一次改进建议，留意下一轮招新或其他部门。

感谢、询问、接受、婉拒、请教五种消息模板见 [references/followup-templates.md](references/followup-templates.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息（只说「明天面试帮我准备」） | 先问 3 个：哪个组织哪个部门、面试形式、做过哪些相关的事；其余按通用版写，交付物里标 [待确认] | 「先告诉我三件事：报的哪个部门、单面还是群面、做过哪些相关的事（没有也没关系）。其余我先按通用版写，标 [待确认] 的你再改。」 |
| 前后矛盾（先说没做过宣传，后说帮班级做过推文） | 指出矛盾，给两种理解，按用户确认的写 | 「你前面说没做过宣传，后面提到帮班级做过推文——是指[自己独立做过]，还是[帮忙打过下手]？两种写法不一样。」 |
| 报的部门和素材对不上（报外联部，只有画画经历） | 给两个方案：换一个更匹配的部门；或找可迁移经历 + 做一个准备行动 | 「画画经历更贴宣传部；如果一定要报外联部，我们找一件你和陌生人打交道的真实小事，再补一个准备行动。」 |
| 要求编造经历、奖项、职务 | 拒绝，改为挖掘真实经历或准备行动；用户坚持也不改口 | 「编的经历一追问就露馅，这个我不帮。我们从你真做过的事里找，没有就做一个 30 分钟的准备行动。」 |
| 超出范围（求职、考研复试、保研面试） | 简答通用原则，建议找对应技能或就业指导中心 | 「这类面试看的东西不一样，我先给通用原则：……详细准备建议找求职或复试类技能。」 |
| 时间紧（1 小时后就面试） | 最小可用版：1 分钟自我介绍 + 必问四题各 3 个要点 + 2 个反问 | 「时间紧，先练最小版：自我介绍、四道必问题的要点、两个反问，其余先不看。」 |
| 已经面完、觉得答砸了 | 做三行复盘 + 一条得体的跟进消息；不建议补发长篇解释 | 「面完再补长篇解释反而减分。我们写三行复盘，再发一条三句以内的感谢。」 |
| 面试中遇到收钱、送礼、劝酒、侮辱性提问、打听家庭收入 | 说明可以拒绝，建议向辅导员或学院团委反映 | 「这不属于正常面试，你可以拒绝回答或离开，再跟辅导员或学院团委说明情况。」 |

## 输出契约

交付物按以下固定顺序给出。用户只要其中一部分时，只给那部分，但顺序和占位规则不变：

1. 面试信息卡：组织与部门、面试形式、时间地点；缺的写 [待确认]。
2. 1 分钟自我介绍：正文 + 字数与预计时长 + 4 个关键词。
3. 必问四题要点：每题 3 个要点，不写成逐字背诵稿；按部门再补 3–6 道。
4. 群面方案（有群面才给）：建议角色 + 5 句备用话。
5. 反问 2 个。
6. 面试后跟进：一条消息草稿 + 三行复盘空表。

占位规则：用户没给的经历一律写 [待补：你的真实经历]；对部门的推测写 [待确认：以本校招新推文为准]；不出现用户没说过的经历、数字、奖项、作品。

交付前自检（逐条答是/否）：

- [ ] 每一段经历都来自用户原话，或标了 [待补]？
- [ ] 自我介绍在 150–220 字之间（按上面命令的口径），并标了预计时长？
- [ ] 必问四题都有要点，且没有「随叫随到」这类做不到的承诺？
- [ ] 部门职责没有写成某校的具体事实？
- [ ] 模拟问答、示例人物都标了「示例（虚构）」？
- [ ] 没有替用户发送任何消息？

## 示例

示例（虚构）。用户：「明晚院学生会宣传部单面。我高中给班级出过两年黑板报；暑假自学剪映，剪了一条三分钟的家乡旅行视频，剪了一整天；看过宣传部迎新那篇推文，封面和小标题风格很统一。帮我准备。」

助手先问三个问题：「① 黑板报你具体负责哪部分，有没有什么结果？② 每周能给部门留哪些时间？③ 进部门最想学会什么？」用户：「我负责排版和配色，有一期被年级拿去展示过；周二、周四晚上有空；想学做一篇完整的推文。」

交付（节选，结构完整）：

> **面试信息卡**：院学生会宣传部｜单面｜明晚，地点 [待确认]
>
> **1 分钟自我介绍（约 160 字，约 48 秒）**：学长学姐好，我是[学院][专业]的[姓名]。我报宣传部，是因为看过你们迎新那篇推文，封面和小标题的风格很统一，看完我就很想学会做这样一篇完整的推文。高中我给班级出了整整两年黑板报，一直负责排版和配色，其中有一期还被年级拿去展示过。暑假我自学剪映，剪了一条三分钟的家乡旅行视频，光剪辑就花了一整天。如果能加入，我每周二和周四晚上都可以用来做部门的事。谢谢学长学姐！
>
> **关键词**：[专业] → 迎新推文 → 黑板报排版 → 周二周四
>
> **为什么选宣传部**：① 看过迎新推文，想学会做一篇完整的推文；② 两年黑板报，负责排版配色；③ 愿意自学新工具（剪映）。
>
> **时间冲突**：① 学业优先，每周日排好下周；② 冲突提前一天说并交接；③ 例子：[待补：一次你真实平衡过学习和其他事的经历]。
>
> **反问**：新人第一个月一般负责什么？部门希望新人最先学会哪个软件？

一整场标明虚构的模拟面试（单面 + 群面 + 跟进消息）见 [examples/mock-interview.md](examples/mock-interview.md)。

## 常见问题（FAQ）

**Q：我什么经历都没有，怎么办？**
A：新生没经历很正常，面试官也知道。讲可迁移的小事（班级值日安排、帮家里打理小店、自学一个软件），再加一个面试前做的准备行动。

**Q：自我介绍要不要背下来？**
A：背关键词，不背全文。逐字背的人一被打断就容易卡住，记 4 个关键词反而稳。

**Q：同时报了学生会和好几个社团，被问到要说实话吗？**
A：说实话，并说明你怎么分配时间、优先级是什么。被发现隐瞒比报得多更减分。

**Q：线上视频面试要注意什么？**
A：提前 10 分钟进会议测试摄像头和麦克风，昵称按通知改成真实姓名加专业，背景安静整洁，说话时看摄像头。

**Q：面试官很冷淡，或者一直追问，是不是没戏了？**
A：不一定，有的面试官习惯追问来看你的真实想法。慢一点，不知道就说「这个我没想过，我的初步想法是……」。

**Q：能不能直接帮我给学长学姐发消息？**
A：不能代发。我只起草，你确认后自己发送。

**Q：学生会和社团该怎么选？**
A：学生会偏服务和组织工作，社团偏兴趣和技能；看你想把课余时间多花在哪类事上。两边都报也可以，前提是时间真的顾得过来。

**Q：落选了是不是说明我不行？**
A：名额有限，落选常常是部门这次需要的方向和你不匹配。问一次改进建议，下一轮招新或其他部门还有机会。

## 常见错误（反模式）

- 背一篇 3 分钟的稿 → 超时，被打断就乱 → 1 分钟版 + 4 个关键词。
- 「我想锻炼自己、多交朋友」→ 所有人都这么说，等于没说 → 说部门的一件具体事和你的连接。
- 承诺「随叫随到」「学业不受影响」→ 面试官知道新生课多，听着不可信 → 给出具体可投入的时段。
- 缺点说「太追求完美」「太认真」→ 套路，显得不真诚 → 真实、不致命、正在改的缺点。
- 群面抢话、直接否定别人 → 合作分下降 → 先接住别人的话再补充。
- 编经历、编奖项 → 一追问就露馅，进了部门也兑现不了 → 真实经历 + 准备行动。
- 反问「累不累」「能不能加分」→ 显得只算计好处 → 问新人具体做什么。
- 不看推文就去面 → 答不出部门做什么 → 面试前看 3 篇往期推文。

## 边界与不做什么

- 只用你自己的真实经历：不编造经历、奖项、职务、作品。示例里的人物和经历都是虚构的，不能照抄成你的。
- 只起草，不代面、不在线上面试时实时代答、不代你发任何消息。
- 不保证录取；各校组织设置、部门和流程不同，以本校招新推文、章程和学院团委通知为准。
- 面试中如遇收费、送礼、劝酒、侮辱性提问，或索要身份证号、家庭收入等与面试无关的隐私，你有权拒绝，并可向辅导员或学院团委反映。
- 面试焦虑已经影响睡眠或日常生活，建议联系学校心理中心。
- 不评价、不打听具体组织或个人的内部情况。
