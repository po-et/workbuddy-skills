# 开题报告

定位一句话：**开题报告要让评审相信三件事——这个问题值得做、别人还没做完、你能在规定时间内做完。** 每一节都在为这三件事举证，不是在凑字数。

## 何时使用

写或修改本科、硕士、博士的开题报告，开题答辩前自查。格式、字数、文献数量以学院当年的模板和通知为准。用户这样说时用本技能：

- 「开题报告怎么写，导师只给了一个大方向」→ 先问清五件事，做一句话检验，再按六部分搭框架
- 「导师说我题目太大、综述像流水账，该怎么改」→ 对照八种情况逐条改，保留原句对照
- 「下周开题答辩，帮我把研究内容和技术路线对一遍」→ 路线图每个框标内容编号，逐条对
- 「参考文献格式对不对，正文编号和表对不上」→ 跑引用核对脚本
- 「进度安排怎么排才像样」→ 从学校节点倒排，每段写可交付物

不适用：

- 代写实验结果、编造文献或数据、「帮我凑几篇文献」：不做；给检索词和检索式，建议找图书馆的学科馆员。
- 判断选题能不能过、研究设计是否成立：由导师和学院判断；本技能只帮你把论证写清楚。
- 字体字号、页边距等排版和答辩 PPT：转 Word 排版、PPT 制作类技能，格式以学院模板为准。

## 先判断：动笔前问清五件事

```
层次与模板  本科、硕士还是博士？学院当年的模板、字数、文献数量与外文比例要求是什么？没有模板先去要
选题        导师认可的是哪一版题目？还没定，先做下面的一句话检验，拿着结果去找导师
文献        已经读过并做了笔记的有多少篇？只下载没读的不算
条件        数据、样本、设备、场地拿得到吗？拿不到的不写进研究内容；涉及人的调查按学校要求准备知情同意和伦理审查
节点        开题、中期、预答辩、送审各在哪天？进度安排从这些日子倒排
```

一句话检验：「本研究以＿＿（对象）为对象，针对＿＿（尚未解决的问题），采用＿＿（方法），预期得到＿＿（可检验的产出）。」四个空填不满，说明题目还没想清楚，这时写正文只会越写越散。

## 流程：六步从选题到送审

```
第1步 定题    题目＝对象＋问题＋方法或视角，必要时加范围（地区、时段、样本）；删掉「浅析」「探讨」这类空词
第2步 检索    记下数据库、检索式、时间范围、命中数，方便导师复查，也方便自己补检
第3步 读与记  建文献矩阵：作者年份｜研究问题｜方法｜数据｜结论｜不足｜与本题关系；「不足」一栏填不出，说明还没读透
第4步 先写核心 先写「研究内容与拟解决的问题」，再写方法与路线，最后回头写现状和选题依据——核心定了，其余各节才有东西对齐
第5步 画路线图 每个方框标上对应的研究内容编号；标不上的框，要么删掉，要么补一条研究内容
第6步 自查送审 逐条过下文八种情况，跑一遍引用核对；送审时附上三个自己拿不准的问题，请导师直接判断
```

引用核对（适用于顺序编码制：正文用 [1]、[2-4] 标注，参考文献放在最后、前面单独一行「参考文献」）。直接读 .docx 或纯文本，查「正文引了、表里没有」「表里有、正文没引」、重复编号、缺号、是否按首次引用顺序编号：

```bash
python3 scripts/check_citations.py 开题报告.docx      # 退出码 0 全部对上，3 有不一致，4 没找到参考文献表
```

## 六部分：每部分回答评审的一个问题

| 部分 | 回答评审的问题 | 至少写到 |
|---|---|---|
| 1 选题依据 | 为什么值得做 | 现实问题（附数据与出处）→ 研究缺口 → 研究价值 |
| 2 国内外研究现状 | 别人做到哪一步、还缺什么 | 按主题归类写共识与分歧；最后的述评指向本题 |
| 3 研究内容与拟解决的问题 | 做哪几件事、难在哪 | 一句可判断的研究目标；三到四条动词开头的研究内容；一两个关键问题及对策 |
| 4 研究方法与技术路线 | 用什么办法、按什么顺序做 | 每种方法写清用于哪条内容、数据来源、样本、分析方法；路线图每框标内容编号 |
| 5 进度安排 | 来得及吗 | 起止时间｜任务｜可交付物；从学校节点倒排，数据收集放前半程，留约两成缓冲 |
| 6 参考文献 | 依据可查吗 | 按学院要求著录（常用 GB/T 7714 顺序编码制，以现行版本为准）；只列读过的 |

每部分的可填空模板、一段示例（虚构课题「社区老年人线上挂号的困难与家庭支持」）和常用著录格式，见 [references/six-part-templates.md](references/six-part-templates.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 只有大方向，缺模板和条件 | 只问三个：层次与学院模板要求；导师认可的方向或题目；已读文献和数据条件。节点先按「开题 → 中期 → 预答辩 → 送审」倒排，标 [待确认]；没有模板按本页六部分，注明「以学院模板为准」 | 「先问三件事：本科、硕士还是博士，学院有没有模板和字数、文献要求？导师认可的方向或题目是哪一版？你已经读过哪些文献，数据拿得到吗？其余我先按常见做法排，标了 [待确认]。」 |
| 用户给的文献信息不全或对不上（缺卷期页码、作者年份与题名对不上、只有网页转述） | 标「待核」，请用户给 DOI、链接或原文首页；核实前不写进正文、不进参考文献表；核实不了的删掉 | 「这条文献缺卷期和页码，我没法替你核实，先标『待核』。你手上有原文或 DOI 吗？核实不了就删掉，不能凭印象写进参考文献。」 |

| 输入自相矛盾（研究内容三条、路线图五步对不上；题目写定量、方法全是访谈；数据收集排在最后一个月） | 指出矛盾在哪，给两种改法让用户选 | 「路线图第 4 步『构建评价体系』在研究内容里找不到。两种改法：补一条研究内容；或者删掉这一步。你倾向哪个？」 |
| 超出范围（代写结果、编数据、判断选题能不能过、规避查重或 AI 检测） | 说明不做，转导师、学科馆员 | 「选题能不能过要导师和学院判断；我能做的是把一句话检验和研究内容写清楚，你拿去和导师确认。」 |
| 时间紧，明天就要交 | 最小可用版：一句话检验 + 研究内容三条 + 方法与内容对应表 + 带可交付物的进度表 + 八种情况自查结果 + 三个请导师判断的问题；综述先写「主题—共识—分歧—述评」提纲，缺的标 [待补] | 「先给最小可用版：题目和一句话检验、三条研究内容、方法对应表、进度表和自查结果；综述先交提纲，文献细节标 [待补]。」 |
| 用户坚持越界（「帮我凑 20 篇文献」「编一组预调查数据」） | 守住边界，给能做的替代 | 「编造文献和数据属于学术不端，我不做。我给你检索词和检索式，建议找图书馆学科馆员一起检索；数据部分写成『预期』和『假设』的语气。」 |

## 输出契约

交付物按下面的顺序，每次都一样：

1. **一句话检验与题目**：四个空填好；填不满的空写明要找导师定什么。
2. **六部分（或学院模板的章节）**：每部分先给结合用户题目的填空框架，再给改写建议；修改已有稿子时保留原句对照，只改有问题的句子。
3. **文献**：只用用户提供或能核实的条目；需要补文献时给检索词与检索式，不列具体条目；拿不准的标「待核」。
4. **自查结果**：八种情况逐条写「有没有、在哪、怎么改」，附引用核对结果（或提醒用户跑一遍）。
5. **请导师判断的三个问题**。
6. **待确认清单**：汇总所有 [待补]、[待确认]、「待核」。

占位符规则：[待补] = 只有用户能提供的（数据、样本、学院要求、已读文献）；[待确认] = 我按常见做法先定的（进度节点、方法选择）；「待核」= 拿不准的引用。预期结果写成「预期」「假设」的语气；不编调查数据、预实验结果和实验结论。用户没有模板时按本页六部分给出，并注明「以学院模板为准」。

交付前自检（每条都答「是」才交）：

- [ ] 一句话检验四个空都填上了，或已标出哪个空要找导师定？
- [ ] 每条研究内容在技术路线图里都有对应的框，每个框都标了内容编号？
- [ ] 每种方法都写了用于哪条内容、数据来源、样本和分析方法？
- [ ] 进度表每段都有可交付物，数据收集在前半程？
- [ ] 所有文献都是用户提供或已核实的，没有编任何文献、数据、页码或 DOI？
- [ ] 八种情况逐条过了，引用核对跑过或已提醒？

## 示例

（示例，课题虚构）

> 用户：导师说我的题目「老年人数字鸿沟问题研究」太大，怎么改？

助手：先用一句话检验找出哪几个空填不满，再给两个收窄方向，最后一步交给导师定。

**一句话检验**：本研究以「老年人」为对象（太宽：哪里的、多大年龄？），针对「数字鸿沟」（太宽：哪类使用场景？），采用＿＿（没写方法），预期得到＿＿（没写产出）。四个空只填上了两个，而且都太宽。

| 收窄方向 | 改后题目 | 适合的条件 |
|---|---|---|
| 聚焦一个场景和范围 | 社区老年人线上挂号的困难与家庭支持——以某市两个社区为例 | 能进社区做问卷、访谈和现场操作任务 |
| 聚焦一个问题和方法 | 某市 60 岁以上居民使用线上政务服务的影响因素——基于问卷调查 | 能拿到较大样本的问卷数据 |

- 删掉空词：「问题研究」不说明任何东西，换成「对象 ＋ 问题 ＋ 方法」。
- 选哪个取决于你拿得到哪类数据 [待确认]；拿着两个版本和一句话检验去找导师，请他直接选。
- 请导师判断的问题：两个方向哪个更符合课题组积累？「某市」和样本范围能否写得更具体？是否需要伦理审查？

## 常见问题（FAQ）

**题目太大怎么缩？** 加对象、范围、方法三个限定，删「浅析」「探讨」这类空词；用一句话检验，四个空都能填具体了就差不多。

**综述要引多少篇文献？** 以学院模板和通知为准，不同层次要求不同；只列读过并做了笔记的，只下载没读的不算。

**国内、国外研究现状必须分开写吗？** 学院要求分开的，在每个主题下分开写；没要求的，按主题归类比按国别排队更清楚。

**能帮我找几篇参考文献吗？** 不列具体条目，因为我没法替你核实；给检索词和检索式，建议找图书馆的学科馆员一起检索。

**研究目标和研究内容有什么区别？** 目标是一句话、事后能判断达没达到；内容是三到四件能交付的事，动词开头。

**开题时还没有数据，预期结果怎么写？** 写成「预期」「假设」的语气，说明打算怎么检验，不编数据和结论。

**可以用 AI 帮我写开题报告吗？** 按学校规定使用并声明；本技能帮你把论证写清，不帮助规避查重或 AI 生成内容检测。

**格式（字体字号、页边距、封面）怎么弄？** 以学院模板为准；具体排版操作可用 Word 排版类技能。

## 常见错误（反模式）

每条：错误做法 → 为什么错 → 正确做法。前 8 条是导师最常打回的情况（经验归纳，不同学科侧重不同），交付前逐条自查。

1. **题目太大**：看不出对象和边界 → 评审没法判断你能不能做完 → 加对象、范围、方法三个限定，删空词。
2. **依据只讲意义**：通篇「具有重要的理论和现实意义」→ 没有证据，说服不了评审 → 改成「现实问题—已有研究—缺口—本研究补哪块」，每句有出处或数据。
3. **综述是流水账**：「甲研究了……乙研究了……」→ 看不出共识、分歧和缺口 → 按主题归类，写共识与分歧，最后的述评必须指向你的题目。
4. **内容像目录**：研究内容写成章节标题 → 看不出要交付什么 → 改成三到四件能交付的事；关键问题写难点和对策，不重复研究内容。
5. **方法只列名称**：「采用文献法、问卷法、访谈法」→ 看不出怎么做、做不做得成 → 每种方法写清用于哪条内容、数据从哪来、样本多大、怎么分析。
6. **路线图对不上**：图里的步骤在研究内容里找不到 → 内容和方法脱节 → 每个框标内容编号，标不上的删掉或补内容。
7. **进度不可行**：数据收集排在最后一个月、没有缓冲 → 一拖就来不及 → 按学校节点倒排，数据收集放前半程，每段写可交付物。
8. **文献不规范**：格式混用、正文没引、只有旧文献、查不到出处 → 依据不可查 → 统一格式，跑引用核对，补近年文献，查不到出处的删掉。
9. **写「国内首次」「填补空白」却没有检索记录** → 经不起追问 → 有检索记录支撑，否则改成「在所检索的范围内较少见到……」。
10. **按模板顺序从第一节写起** → 核心没定，其余各节没东西对齐，越写越散 → 先写研究内容与拟解决的问题，再写方法与路线，最后回头写现状和依据。

## 边界与不做什么

- 不代写实验结果，不编造数据、文献、页码或DOI；用户要「凑几篇文献」时只给检索策略，建议找图书馆的学科馆员帮忙检索。
- 选题能不能做、研究设计是否成立、是否符合学术规范，由导师和学院判断；本技能只帮你把论证写清楚。
- 学校对AI辅助写作有规定的，按规定使用并声明；不帮助规避查重或AI生成内容检测。
- 字体字号、页边距、封面等格式以学院模板为准；开题流程与时间以研究生院或教务处的通知为准。
- 涉及人或动物的研究，伦理审查与知情同意按学校规定办理，这里不判断是否需要。
