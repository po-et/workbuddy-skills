# 开题报告

定位一句话：**开题报告要让评审相信三件事——这个问题值得做、别人还没做完、你能在规定时间内做完。** 每一节都在为这三件事举证，不是在凑字数。
何时用：写或修改本科、硕士、博士的开题报告；导师说「题目太大」「综述像流水账」「内容和方法对不上」要返工；开题答辩前自查。格式、字数、文献数量以学院当年的模板和通知为准。

## 先判断：动笔前问清五件事

```
层次与模板  本科、硕士还是博士？学院当年的模板、字数、文献数量与外文比例要求是什么？没有模板先去要
选题        导师认可的是哪一版题目？还没定，先做下面的一句话检验，拿着结果去找导师
文献        已经读过并做了笔记的有多少篇？只下载没读的不算
条件        数据、样本、设备、场地拿得到吗？拿不到的不写进研究内容；涉及人的调查按学校要求准备知情同意和伦理审查
节点        开题、中期、预答辩、送审各在哪天？进度安排从这些日子倒排
```

一句话检验：「本研究以＿＿（对象）为对象，针对＿＿（尚未解决的问题），采用＿＿（方法），预期得到＿＿（可检验的产出）。」四个空填不满，说明题目还没想清楚，这时写正文只会越写越散。

## 流程：六步从选题到送审

```
第1步 定题    题目＝对象＋问题＋方法或视角，必要时加范围（地区、时段、样本）；删掉「浅析」「探讨」这类空词
第2步 检索    记下数据库、检索式、时间范围、命中数，方便导师复查，也方便自己补检
第3步 读与记  建文献矩阵：作者年份｜研究问题｜方法｜数据｜结论｜不足｜与本题关系；「不足」一栏填不出，说明还没读透
第4步 先写核心 先写「研究内容与拟解决的问题」，再写方法与路线，最后回头写现状和选题依据——核心定了，其余各节才有东西对齐
第5步 画路线图 每个方框标上对应的研究内容编号；标不上的框，要么删掉，要么补一条研究内容
第6步 自查送审 逐条过下文八种情况，跑一遍引用核对；送审时附上三个自己拿不准的问题，请导师直接判断
```

引用核对（适用于顺序编码制：正文用[1]、[2-4]标注，稿子另存为纯文本，参考文献放在最后）：

```bash
python3 - 开题报告.txt <<'EOF'
import re, sys
body, _, refs = open(sys.argv[1], encoding='utf-8').read().rpartition('参考文献')
cited = set()
for g in re.findall(r'[\[［]([\d,，\-–]+)[\]］]', body):
    for p in re.split('[,，]', g):
        a, _, b = p.replace('–', '-').partition('-')
        if a: cited.update(range(int(a), int(b or a) + 1))
listed = {int(n) for n in re.findall(r'^\s*[\[［](\d+)[\]］]', refs, re.M)}
print('正文汉字数:', len(re.findall('[一-龥]', body)))
print('正文引了、表里没有:', sorted(cited - listed))
print('表里有、正文没引:', sorted(listed - cited))
EOF
```

## 六部分：可填空模板与示例

示例都用同一个虚构课题「社区老年人线上挂号的困难与家庭支持——以某市两个社区为例」，只演示写法；文献编号是占位符，内容不代表真实研究结论，不能照抄进你的报告。

**1 选题依据**——为什么值得做

```
模板  现实问题：近年来＿＿（现象，附数据与出处），导致＿＿（后果）。
      研究缺口：已有研究主要从＿＿角度讨论了＿＿[文献]，对＿＿（对象、情境或机制）关注不足。
      研究价值：理论上补充＿＿；实践上可为＿＿（谁）做＿＿（什么决定）提供依据。
示例  不少医院把线上预约作为主要挂号方式，部分老年人因不会操作而挂不上号（此处引用官方统计并写明年份）。
      已有研究多讨论老年人上网的总体状况[1-3]，较少聚焦就医挂号这一高频场景，也较少考察子女等家庭成员的作用。
      本研究可为社区设计助老培训提供依据。
```

**2 国内外研究现状**——别人做到哪一步、还缺什么

```
模板  主题一＿＿：共识是＿＿[文献]；分歧在于＿＿，有的认为＿＿[文献]，有的认为＿＿[文献]。
      主题二＿＿：……（按主题归类，不按作者排队；学院要求分国内、国外的，在每个主题下分开写）
      述评：现有研究在＿＿上已较充分，但在＿＿（对象、方法或情境）上仍有不足，本研究从＿＿切入。
示例  关于老年人用手机的障碍，多数研究认为操作复杂和视力下降是主因[4-6]；对心理因素则有分歧，
      有研究认为怕出错是关键[7]，也有研究发现控制受教育程度后这一影响不再显著[8]。
      述评：现有研究多为总体调查，缺少对挂号这类具体任务的实际操作考察。
```

**3 研究内容与拟解决的问题**——做哪几件事、难在哪

```
模板  研究目标：＿＿（一句话，事后能判断达没达到）
      研究内容：（1）＿＿（2）＿＿（3）＿＿，三到四条，动词开头（描述、检验、构建、评估），每条对应一个可交付的结果
      拟解决的关键问题：＿＿（最难的一两处：为什么难、准备怎么解决）
示例  研究内容：（1）描述两个社区老年人线上挂号的使用情况与主要困难；（2）检验年龄、受教育程度、
      子女支持与挂号成功的关系；（3）归纳家庭支持的主要方式。
      关键问题：自报「会用」与实际能力可能不一致，拟加入现场操作任务，核对自报结果。
```

**4 研究方法与技术路线**——用什么办法、按什么顺序做

```
模板  方法＿＿：用于研究内容（＿），数据来自＿＿，样本＿＿，分析用＿＿，结果回答＿＿。
      技术路线：[输入]→[步骤，对应内容1]→[步骤，对应内容2]→[输出]
示例  问卷调查法，用于内容（1）（2）：在两个社区按年龄分层抽取约300名60岁以上居民，先做30人预调查修订问卷，
      再用描述统计和逻辑回归分析。半结构访谈法，用于内容（3）：选约20户家庭，转录后编码归纳。
      路线：文献梳理→问卷与提纲设计→预调查修订→正式调查与访谈→统计与编码→结论与建议。
```

**5 进度安排**——来得及吗

```
模板  起止时间｜任务｜可交付物（每一段都要有能拿给导师看的东西）
示例  第1–2月｜补充文献，设计问卷并预调查｜问卷定稿
      第3–4月｜正式调查与访谈｜数据表、访谈转录稿
      第5–6月｜分析与撰写｜论文初稿（中期检查前完成数据收集）
      第7月｜修改定稿｜送审稿
规则  从学校节点倒排；数据收集放在前半程；总时长里留出约两成缓冲
```

**6 参考文献**——依据可查吗（以学院要求为准；常用国家标准GB/T 7714的顺序编码制，以现行版本为准）

```
期刊      [序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
专著      [序号] 作者. 书名[M]. 出版地: 出版者, 出版年: 页码.
学位论文  [序号] 作者. 题名[D]. 保存地: 保存单位, 年份.
网络资源  [序号] 作者. 题名[EB/OL]. (发布或更新日期)[引用日期]. 网址.
示例（格式演示，非真实文献）
  改前    作者甲，老年人线上就医研究，某某学报2021
  改后    [3] 作者甲. 老年人线上就医研究[J]. 某某学报, 2021, 37(4): 21-29.
规则      按正文首次引用的顺序编号；作者三人以内全列，超过三人列前三人加「等」；只列自己读过的，转引要注明
```

## 最常被导师打回的8种情况

经验归纳，不同学科侧重不同：

```
1 题目太大     看不出对象和边界              → 加对象、范围、方法三个限定，删空词
2 依据只讲意义 通篇「具有重要的理论和现实意义」 → 改成「现实问题—已有研究—缺口—本研究补哪块」，每句有出处或数据
3 综述是流水账 「甲研究了……乙研究了……」       → 按主题归类，写共识与分歧，最后的述评必须指向你的题目
4 内容像目录   研究内容写成章节标题            → 改成三到四件能交付的事；关键问题写难点和对策，不重复研究内容
5 方法只列名称 「采用文献法、问卷法、访谈法」   → 每种方法写清用于哪条内容、数据从哪来、样本多大、怎么分析
6 路线图对不上 图里的步骤在研究内容里找不到    → 每个框标内容编号，标不上的删掉或补内容
7 进度不可行   数据收集排在最后一个月、没有缓冲 → 按学校节点倒排，数据收集放前半程，每段写可交付物
8 文献不规范   格式混用、正文没引、只有旧文献、查不到出处 → 统一格式，跑引用核对，补近年文献，查不到出处的删掉
```

另外，「国内首次」「填补空白」必须有检索记录支撑，否则改成「在所检索的范围内较少见到……」。

## 输出契约

1. 先问清层次、学院模板与要求、一句话检验的四个空、已读文献清单；用户没有模板时按本页六部分给出，并注明「以学院模板为准」。
2. 交付按六部分组织：每部分先给结合用户题目的填空框架，再给改写建议；修改已有稿子时保留原句对照，只改有问题的句子。
3. 文献只用用户提供或能核实的条目；需要补文献时给检索词与检索式，不列具体条目；拿不准的引用标「待核」。
4. 预期结果写成「预期」「假设」的语气；不编调查数据、预实验结果和实验结论。
5. 交付前按八种情况逐条自查，并提醒用户跑一遍引用核对。

## 边界与不做什么

- 不代写实验结果，不编造数据、文献、页码或DOI；用户要「凑几篇文献」时只给检索策略，建议找图书馆的学科馆员帮忙检索。
- 选题能不能做、研究设计是否成立、是否符合学术规范，由导师和学院判断；本技能只帮你把论证写清楚。
- 学校对AI辅助写作有规定的，按规定使用并声明；不帮助规避查重或AI生成内容检测。
- 字体字号、页边距、封面等格式以学院模板为准；开题流程与时间以研究生院或教务处的通知为准。
- 涉及人或动物的研究，伦理审查与知情同意按学校规定办理，这里不判断是否需要。
