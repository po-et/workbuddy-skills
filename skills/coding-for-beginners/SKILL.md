# 编程入门

定位一句话：**入门阶段要练会的不是某门语言的语法，而是「写一点、运行、看结果、再改」这个循环，以及卡住时自己把问题缩小的本事。**
何时用：完全没写过代码、想自学编程；或者看了很多教程还是写不出东西、一报错就卡住、学了两周想放弃时。

## 先判断：学来做什么，每天有多少时间

先问三件事：学来做什么、每天能投入多少分钟、用什么电脑系统。选语言只看一条：**目标明确，就学那个方向最常用的语言；没想好，就学Python。**

```
目标                        先学                   理由
没想好、先体验、办公自动化  Python                 语法接近日常英语，装好就能跑，报错信息好读
整理表格、分析数据          Python                 处理表格和文本的现成工具多
做网页                      HTML/CSS + JavaScript  浏览器就能运行，改完立刻看到效果
学校课程或考试              课程指定的语言         C、Java 都行，先跟上课
```

时间：每天固定三十分钟到一小时，比周末一次突击五小时更容易坚持，也忘得少。每天不足三十分钟，就把下面的30天计划拉长到60天，顺序不变。

第一天就要跑通环境：从Python官网下载安装包，不用来路不明的网盘安装包；装完在终端输入 `python3 --version`（Windows 输入 `py --version`），看到版本号就算成功。编辑器先用安装包自带的IDLE，不要在挑编辑器上花一整天。这份计划要用到终端和文件，需要一台能装软件的电脑；只有手机或平板的话，先解决设备。

## 前30天：每天一件事，每周一个小项目

每天的节奏：先不看教程，把昨天的程序重写一遍（十分钟）；再学今天的新内容；最后改一改今天的例子，故意弄坏它，再修好。学每个知识点都做三件事：照着敲一遍（不复制粘贴）；改一个地方，看结果怎么变；合上教程，自己写一个类似的。每天收工时，今天的程序必须能跑；跑不起来，就把卡住的地方写下来，明天第一件事解决它。

```
第1周  跑起来
 1  安装，写 hello.py 打印一句话，用 python3 hello.py 运行（Windows 用 py hello.py）
 2  变量、输入输出：输入名字，程序回一句问候
 3  运算与类型转换：输入单价和数量，算出总价
 4  条件判断：输入分数，输出优秀、良好、及格或不及格
 5  故意犯错：删一个引号、拼错变量名、打乱缩进，读懂三种报错并记下名字
 6  不看教程，把第2到4天的程序重写一遍
 7  项目①计算器：输入两个数和运算符，除数为0时给出提示
第2周  重复与集合
 8  for 循环：打印九九乘法表
 9  while 循环：一直接收输入，输入 q 才退出
10  列表：录入一组成绩，求最高、最低、平均
11  字典：统计一句英文里每个单词出现的次数
12  字符串：split、strip、lower、replace 各写一个例子
13  给前面每个程序加一个新功能
14  项目②猜数字：随机生成1到100，提示大了还是小了，统计猜了几次
第3周  把代码组织起来
15  函数：把计算器拆成加减乘除四个函数
16  参数与返回值：写三个小函数，每个用两组输入测试
17  文件：读一个文本文件，统计行数和字数
18  异常处理：输入不是数字时提示重输，而不是崩溃
19  标准库：用 random 和 datetime 各做一个小功能
20  读别人的代码：找一段三十行左右的示例，逐行写注释
21  项目③待办清单：能增、删、查看，关掉程序再打开还在（存进文件）
第4周  项目④：做一个完整的小东西
22  选题并写需求：输入是什么、输出是什么、做到哪一步算完成
23  把项目拆成五到八个、每个不超过三十分钟的小步骤
24–26  逐步实现，每完成一步就运行一次
27  调试日：专门修bug，练习下一节的最小复现
28  整理：变量改成看得懂的名字，写一份「怎么运行」的说明
29  请朋友照说明运行，记下他卡住的地方并修改
30  复盘：写出学会的十个概念，每个配一行例子；定下个月的方向
```

项目④从这里挑一个，或者解决你手头一件重复的小事：单词小测验、批量给文件改名、文本统计工具。每个小项目的完成标准：能运行；别人照说明能用起来；至少处理一种错误输入。

30天之后按方向选第二个月：数据处理（读写表格、做统计、画图）、网页（HTML、CSS、JavaScript基础）、自动化（批量处理文件、定时跑脚本）。节奏不变，仍是每天一件事、每周一个小项目。

## 卡住时的求助流程：读报错、缩小问题、再开口

先自己查二十分钟；超过二十分钟没进展，按下面三步走，别硬扛一下午。

**第一步，读报错。** 从最后一行往上读。例如这段代码：

```python
prices = [12, 8, 15]
total = 0
for p in prices:
    total = totle + p
print(total)
```

运行后得到（Python 3.12；路径因电脑而异，其他版本的提示略有不同）：

```
Traceback (most recent call last):
  File ".../shop.py", line 4, in <module>
    total = totle + p
            ^^^^^
NameError: name 'totle' is not defined. Did you mean: 'total'?
```

最后一行是错误类型和说明：用了一个没定义的名字 totle，Python 还猜你想写 total；往上看位置：第4行。SyntaxError 要连上一行一起看，常常是上一行少了括号或引号。实在看不懂，就把最后一行复制去搜，先删掉你自己的路径和变量名。

```
SyntaxError       语法不完整：少了冒号、括号或引号
IndentationError  缩进不一致：统一用4个空格
NameError         名字没定义：拼错了，或者还没赋值就用了
TypeError         类型不匹配：比如字符串加数字，用 int() 或 str() 转换
ValueError        值不合法：比如 int("abc")
IndexError        下标越界：列表只有3个元素，却取第4个
KeyError          字典里没有这个键：先用 in 判断，或者用 get()
```

给自己建一个报错本：每遇到一种新报错，记一行「报错名、原因、怎么改的」，一个月下来就是你自己的排错手册。

**第二步，做最小复现。** 另存一份代码，删掉看起来无关的部分，每删一段运行一次，错误还在就继续删；把读文件、等输入换成直接写在代码里的数据；删到二十行以内、别人复制就能运行、还能出同一个错为止。很多问题删到一半，自己就看出来了。

**第三步，再求助。** 按这个模板发问，发之前删掉代码里的密码、密钥和个人信息：

```
我想做：一句话目标
环境：操作系统；python3 --version 的输出
最小复现代码：二十行以内，能直接运行
完整报错：原样粘贴文字，不截图、不删减
期望结果与实际结果：各一句
我已经试过：至少两条
```

问AI助手也按这个模板。让它解释报错和概念，而不是替你写整段代码；它给的代码，你要能逐行说出每一行在做什么，说不出的那一行，就是还没学会的地方。

## 常见放弃点与对策

```
时间     放弃信号                        对策
第1–3天  环境装不上，命令行看不懂        只装官方Python和自带的IDLE，先跑通hello；装不上就把报错原文拿去问
第2周    教程看得懂，自己写不出          看完一节立刻关掉教程重写；看懂不算，默写出来并跑通才算
第3周    函数、文件变抽象，报错越来越多  每个新概念只做一个十行以内的小例子；报错是日常，不是天赋问题
第4周    项目越做越大，做不完            砍到一个周末能做完的最小版本，先能用，再加功能
随时     断了三天，不好意思接着学        不补进度，从今天的任务继续；最低标准降到每天十五分钟、写五行
随时     收藏几十个教程，反复换语言换课  锁定一个教程学完第一个月；换课往往是在逃避写代码
随时     和别人比，觉得自己不是这块料    只和上周的自己比：这周比上周多会写哪一个程序
随时     英语不好，怕看不懂报错          报错里反复出现的词就那几十个，查一次记进报错本，两周就眼熟
```

## 输出契约

1. 先问清三件事：学来做什么、每天能投入多少分钟、用什么电脑系统；没回答就按「Python、每天一小时、Windows或macOS」默认，并写明。
2. 交付：语言选择加一句理由；按用户时间伸缩后的30天计划；每周项目及完成标准；求助模板。
3. 代码示例都能直接运行，写明假设的Python版本（3.10及以上）和运行命令。
4. 帮看报错时，先指出哪一行、什么错误类型、最可能的原因，再给改法；只改出错的地方，不整份重写。
5. 用户贴来一大段不是自己写的代码时，先讲清每一块在做什么，再讲怎么改。
6. 不承诺「学完就能找到工作」，不给任何收入数字。

## 边界与不做什么

- 不卖课，不推荐也不评价具体的付费课程、培训机构或训练营；学习资料只指向官方文档（Python官方教程有简体中文版）和免费公开资源。
- 不代写课程作业、考试、编程比赛或笔试面试题；可以讲概念，帮你看你自己写的代码为什么报错。
- 不写恶意程序，不写未经授权抓取网站数据或绕过登录验证的代码。
- 要不要辞职转行、要不要报班，牵涉个人财务与职业风险，这里只帮你列出要考虑的问题；具体决定结合自身情况，必要时咨询职业规划师或HR。
- 学校课程的语言、环境与作业规范，以任课老师的要求为准。
- 工作中的代码问题，先确认单位的安全规定，不要把内部代码和数据贴到公开网站或外部工具里。
