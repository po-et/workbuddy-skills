# 示例：月度整理——过期、重复、格式三步走

> 以下为示例。记录目录是一份 6 条的示例目录，脚本输出是实际运行 `scripts/lessons_search.py` 的结果；「今天」按 2026-09-26 算。

## 1. 用户提问

> 踩坑记录攒了几十条，帮我合并重复的、清理过时的。

助手只确认一件事：记录目录在哪（用户答：`~/lessons`）。合并和改状态会改文件，先出方案，用户同意后再改。

## 2. 第一步：列出 90 天没复核的

```bash
python3 scripts/lessons_search.py ~/lessons --stale 90
```

```text
[0] 文件与路径.md | 导出的 CSV 用 Excel 打开中文乱码 | 有效 2026-05-10
    正确做法：写 CSV 时用 utf-8-sig 编码（带 BOM）
    验证方式：生成后双击用 Excel 打开，看第一行中文是否正常
[0] 文件与路径.md | 网页结果的链接写成了相对地址 | 有效 2026-06-01
    正确做法：链接写完整路径，交付前自己点一遍
    验证方式：在另一个目录的终端里打开链接，能直接打开
[0] 日程与时间.md | 约跨城会议没换算时区 | 有效 2026-04-15
    正确做法：跨时区的时间写成「北京时间 15:00（UTC+8）」，并附对方当地时间
    验证方式：发出前用世界时钟核对一遍对方当地时间
共 3 条
```

## 3. 第二步：找疑似重复

```bash
python3 scripts/lessons_search.py ~/lessons --dupes
```

```text
[60%] 文件与路径.md | 交付文件只写了相对路径，用户找不到  <->  文件与路径.md | 网页结果的链接写成了相对地址  （共同关键词：交付、路径、链接）
疑似重复 1 对；同根因的才合并，只是话题相近的保留两条。
```

两条的根因都是「默认用户和我在同一个目录」，属于同根因，可以合并。

## 4. 助手交付：处理方案（用户同意后执行）

```text
复核清单（今天 2026-09-26）
  条目                                   处理           理由
  导出的 CSV 用 Excel 打开中文乱码        续期           做法仍然成立，最后验证改为 2026-09-26
  约跨城会议没换算时区                    续期           做法仍然成立，最后验证改为 2026-09-26
  网页结果的链接写成了相对地址            合并           与「交付文件只写了相对路径」同根因
  周报按旧模板写                          保持已过时     状态已是「已过时：周报改由系统自动生成」，不删除
合并方式：现象合并列出；验证方式补上「链接在另一个目录里点开也能打开」；次数相加 2 + 1 = 第 3 次
升级建议：合并后这个坑累计 3 次，建议写进常驻指令「交付物一律写完整路径」
```

## 5. 执行后核对

```bash
python3 scripts/lessons_search.py ~/lessons --stale 90
python3 scripts/lessons_search.py ~/lessons --dupes
python3 scripts/lessons_search.py ~/lessons --lint
```

```text
没有超过 90 天未复核的条目
没有疑似重复的条目
检查了 5 条，格式都合格
```

合并后的条目：

```markdown
### 交付文件只写了相对路径，用户找不到
- 关键词：路径, 文件位置, 交付, 链接
- 触发场景：把报告、表格、网页结果交给用户时
- 现象：用户回复「report.html 在哪？打不开」；网页结果的链接只写了 report.html，用户点开提示找不到文件
- 根因：默认用户和我在同一个目录，实际不在
- 正确做法：交付物一律写完整路径，如 /Users/xiaowang/周报/report.html
- 验证方式：交付前把路径粘到文件管理器地址栏，能直接打开；链接在另一个目录里点开也能打开
- 类别：被用户纠正（第 3 次，已合并「网页结果的链接写成了相对地址」）
- 最后验证：2026-09-26
- 状态：有效
```

## 6. 这个示例说明了什么

- 三个命令各管一件事：`--stale` 找该复核的，`--dupes` 找该合并的，`--lint` 最后兜底检查格式。
- 脚本只给候选，是否同根因、是否过时由人判断；已过时的条目改状态、不删除。
- 改文件前先出方案；执行后再跑一遍三个命令，用输出证明整理完成。
