# 手机管理

定位一句话：**管屏幕靠的不是没收，是一份孩子参与写、全家都遵守、提前写好例外的约定。**

## 何时使用

孩子（0–17 岁）玩手机、平板或游戏停不下来；每天给多久拿不准；一收设备就哭闹；在犹豫要不要给孩子买自己的手机；家长自己也想少刷一点时。本页的时长数字都是公开的常见建议，不是诊断标准。用户通常这样说：

- 「孩子 8 岁，放学就抱着平板，想定个规矩」
- 「平板每天给多久合适」
- 「一收手机就哭闹摔东西，我该怎么说」
- 「五年级想要自己的手机，给还是不给」
- 「爷爷奶奶带的时候随便玩，规矩执行不下去」
- 「我自己也刷手机停不下来，怎么给孩子做榜样」

不适用（遇到时直接说明并转交）：

- **已经出现严重迹象**：连续几周因为屏幕影响睡眠、上学或吃饭，为了用手机撒谎、偷拿钱、逃学，或说出做出伤害自己的事——先不定规则，按「边界与不做什么」里的办法求助专业人士，紧急时拨打急救电话。
- **要推荐管控软件、设备品牌，教破解或秘密监控**：不做；系统自带的限额和停用时段可以用，开启前告诉孩子。
- **成年子女（18 岁以上）**：本页的年龄建议不适用，改成家庭成员之间的沟通建议，直接简答。

## 先判断：现在怎么用、先解决哪一件事

第 1 步，先记 7 天，不改任何规矩，只记下面这几列：

```
日期,设备,时段,做什么(学习/创作/联系/消遣),分钟,在哪,怎么结束(自己停/提醒后停/哭闹)
```

第 2 步，分清用途。屏幕时间不是一种东西：学习、创作（编程、画画、剪视频）、联系（和亲人视频）可以宽一些，消遣（短视频、游戏）是主要要管的部分。

第 3 步，从七天记录里只挑一到两个问题先解决，按记录对号入座：「怎么结束」一栏里哭闹超过一半，先练结束方式，不急着砍时长；睡前还在用，先管睡前；消遣占了八成以上，先安排替代活动；内容不合适，先管内容；挤掉了作业或户外，先定时段。一次改太多，一样也改不成。

记录存成 CSV 后可以用脚本汇总，按上面第 3 步的顺序直接指出先解决哪一两件事（只用 Python 标准库，不联网，不做诊断）：

```bash
python3 {baseDir}/scripts/screen_log.py log.csv --age 8 --bedtime 21:00
```

脚本输出各用途的分钟与占比、哭闹结束的比例、每天最晚用到几点、卧室里用了几段，并对照该年龄的常见建议；记录不满 7 天、没给入睡时间、「做什么」填错时会提示或报错指出行号。内容合不合适、有没有挤掉作业和户外，记录表看不出来，由家长判断。

要不要给孩子自己的手机，先问五个问题：

- 有真实需要吗（独自上下学、联系家人），而不只是「同学都有」？
- 现有的平板约定，能稳定遵守一个月吗？
- 孩子说得出遇到陌生人私信、看到让人不舒服的内容时怎么做吗？
- 只能通话和定位的设备，确实不够用吗？
- 孩子接受先用「借用制」吗：手机归家长，按约定借用？

三个以上答「否」，先不给，或者先给功能简单的设备。

## 时长参考：常见建议，不是硬标准

```
年龄        常见建议                                          家里怎么落地
0–2 岁      尽量不看屏幕，和亲人视频通话除外                     动画片不当安抚工具
2–5 岁      每天不超过 1 小时，越少越好，大人陪着看               固定时段看一集，看完聊两句
6–12 岁     非学习用途单次不超过 15 分钟，每天累计不超过 1 小时     用定时器；学习用屏 30–40 分钟后远眺 10 分钟
13 岁以上   没有统一数字，看睡眠、运动、功课和面对面交往是否被挤掉   上限由孩子提，家长只看是否兑现
所有年龄    睡前 1 小时不用屏幕，设备不进卧室过夜
```

口径说明：上表数字是按公开渠道常见的家长建议整理的（世界卫生组织、儿科学会类机构和国内近视防控相关文件都发布过按年龄的时长建议），本技能未逐条核对原文，具体数字以各机构最新发布为准。这些数字是上限参考，不是必须用满的额度。

## 五步定约定，用时段、场景、例外落地

五步开一次家庭会议，30 分钟以内：

1. 选平静的时候，不在冲突当下，周末上午最好。
2. 先让孩子说：用手机做什么、最在乎什么（和同学联机、等某个节目更新）。家长复述一遍：「你是说……，对吗？」
3. 家长说底线，最多三条，不谈判：比如睡前 1 小时不用、吃饭不用、不加陌生人。其余都能谈。
4. 一起写约定：时段、场景、例外、怎么结束、做不到怎么办。后果提前约好，只和违约本身有关，只管当天或第二天。
5. 全家签字，试行两周，到期复盘；每次复盘最多改一条。

约定靠三件工具落地：**时段**管什么时候能用，**场景**管在哪、做什么时不用，**例外**把加时和减时提前写好，免得每次临场讨价还价。约定模板有七栏——时段、场景、例外、结束、违约、家长、签名；按 6–12 岁常见建议填好的完整模板、7 天记录表和两周复盘单见 [references/agreement-template.md](references/agreement-template.md)。

执行时有三个帮手：

- **系统设置**：设备自带的屏幕使用时间、应用限额、停用时段、内容分级，用来提醒和上锁，不用来秘密监控；开启前告诉孩子开了什么、为什么。入口以设备说明为准。
- **看得见的时间**：厨房定时器或沙漏，比「再玩一会儿」清楚。
- **接一件具体的事**：关屏幕之后是下楼骑车、洗澡、拼图，而不是笼统的「去学习」。

再按年龄补几条细则：

- **3–6 岁**：约定「看一集」，不说「看 20 分钟」，并关掉自动连播，让终点清清楚楚。
- **6–12 岁**：游戏按「局」约定，比按分钟少吵；新 App、新游戏先一起看年龄分级和评论区，第一次玩时家长在旁边。
- **13 岁以上**：内容以讨论为主，不偷看聊天；夜间设备放客厅、不加陌生人这两条照旧。
- **所有年龄**：关闭免密支付，应用内购买必须家长确认。

两周复盘，10 分钟：先说做到了哪几条；再问孩子哪条最难、难在哪；孩子和家长各提一条想改的；最后只改一条，写进约定，重新签字。

## 冲突时怎么说，家长怎么做

先接情绪，再讲约定；句子要短；当场不翻旧账、不加罚。

```
到点前    「还有 5 分钟。到时候你自己关，还是我来提醒你？」
抗议      「我知道这一局正到关键处，停下来很不爽。时间到了，按约定这局打完，最多 10 分钟。」
哭闹      先保证安全，少说话：「你现在很生气，我在这儿陪你。平板先放这里，平静了我们再说。」
讨价还价  「今天不改约定。你觉得哪条不合理，周日家庭会议上提，我们认真讨论。」
别人都有  「你担心在同学里落单，这个我懂。我们看看具体哪件事需要手机，一起想办法。」
家长违约  「你说得对，我刚才吃饭时看手机了，今晚我的手机也放客厅。」
```

别说：「你就是手机成瘾」（贴标签）、「再玩我就摔了它」（做不到的威胁）、「你看看别人家孩子」（比较）。

冲突平息后，当天或第二天用三句话收尾：刚才发生了什么；下次到点我们怎么做；哪条约定你觉得要改，周日提出来。

家长示范清单：

- 饭桌、睡前、陪玩时间，家长也不用手机；手机不上饭桌、不放床头。
- 必须回工作消息时说出来：「我回一条工作消息，两分钟。」
- 每周看一次自己的屏幕使用时间，在家庭会议上和孩子一起公开。
- 不把屏幕当作默认的安抚、奖励或惩罚。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| E1 缺关键信息：没说年龄，只说「孩子天天玩手机」 | 先问三个：孩子几岁；主要用什么设备、做什么；最头疼的一个场景。其余先用默认：不改规矩、先记 7 天，并把记录表发给家长 | 「孩子几岁？平时主要拿来做什么？最头疼的是停不下来、收的时候闹，还是睡前还在玩？这周先别改规矩，按这张表记 7 天。」 |
| E2 输入超范围或自相矛盾：年龄不在 0–17 岁；「每天玩十个小时」又说「只有周末玩」；描述太笼统定位不了问题 | 年龄超范围就说明本页建议只适用于未成年人；矛盾处指出来，问以哪个为准；笼统的先记 7 天，记录说话 | 「你说每天玩十个小时，又说只有周末玩：是周末两天各玩十个小时，还是平时每天也玩、周末更多？先按这张表记一周，数字准了才好定规矩。」 |
| E3 超出范围：要判断是否成瘾、多动；推荐管控软件或品牌；教破解、秘密监控；视力问题 | 不诊断，转儿童保健科、儿童精神心理门诊或学校心理老师；视力找眼科；不推荐品牌、不教监控，可以用设备自带设置并告诉孩子 | 「是不是成瘾我不能判断；你说的这几条如果持续几周，建议带孩子去儿童保健科或心理门诊看看。」 |
| E4 时间紧：今晚就要一个能用的规矩 | 出最小版：一条底线（睡前 1 小时设备放客厅，家长同样）、一个结束方式（提前 5 分钟提醒加定时器）、一句冲突时的话；两周后再开家庭会议写完整约定；标题写「状态：最小版」 | 「今晚先定一条：九点设备全放客厅，大人也一样；到点前 5 分钟提醒，定时器响了就放下。完整约定周末一起写。」 |
| E5 用户坚持越界：想偷装监控、想当场砸手机、想用屏幕时间做奖惩、要我说孩子「就是成瘾」 | 守住：不教秘密监控，不贴标签；说清代价，给一个能做到的替代 | 「偷看一旦被发现，信任比屏幕问题更难修；担心安全就直接谈，或者开设备自带的限额并告诉孩子。」 |
| 紧急情况：孩子说出或做出伤害自己的事；网络欺凌、陌生人索要照片、诱导转账 | 立刻行动，不谈规则：陪在身边，拨打急救电话（120）或当地心理援助热线；欺凌和诈骗保留证据、告诉学校，必要时报警 | 「这件事先不谈屏幕规则：请现在陪着孩子，马上拨打 120 或当地心理援助热线。」 |

## 输出契约

交付物按固定顺序输出，某部分没有内容写「无」：

```
0 标题行：手机管理方案｜孩子年龄｜状态：完整版 / 最小版｜[待确认] N 项
1 现状定位：根据 7 天记录或用户描述，指出先解决的一到两个问题（没有记录的，先交记录表）
2 约定草稿：按模板六栏（时段、场景、例外、结束、违约、家长）填好；这次不定的栏标 [待补]，写明由谁、什么时候定
3 三到五句原话：针对这个家庭最常见的冲突场景
4 两周复盘单：哪条做到了、哪条最难、下次改哪一条
```

- 时长数字标「常见建议」并写明口径，不写成硬标准。
- 不下判断：不说孩子「成瘾」「多动」，不给任何诊断性结论。

占位符：[待补]——复盘日期、签名等由家庭填的空；[待确认]——没问到、先按默认写的项，或记录里看不出来、要家长判断的项（如内容是否合适），数量写进标题行。

交付前自检（每条答「是」才交）：

- [ ] 先解决的问题不超过两个，而且能在记录或描述里找到依据？
- [ ] 约定里时段、场景、例外、结束、违约、家长六栏都在，没定的标了 [待补]？
- [ ] 时长数字都标了「常见建议」，没有写成诊断标准？
- [ ] 原话没有贴标签、没有做不到的威胁、没有和别人家比较？
- [ ] 家长那一栏有家长自己要做到的事？
- [ ] 出现严重迹象或紧急情况时，已经给了求助途径而不是继续定规则？

## 示例

> 示例：家庭情况为虚构，只演示格式。

用户：「一收手机就哭闹摔东西，我该怎么说？」

助手先问：「孩子几岁？一般什么时候收、收之前有没有说好玩多久？」用户答：「7 岁，晚饭后玩，没说好多久，我觉得差不多了就直接收。」

交付：

```
手机管理方案｜孩子 7 岁｜状态：完整版｜[待确认] 1 项
1 现状定位：先解决结束方式——没有事先约好的终点，收的时机由大人临时决定，孩子没法预期；
  先不砍时长，先让「到点结束」可预期。有没有其他问题 [待确认]：建议这周按记录表记 7 天。
2 约定草稿（这次先改「结束」「违约」「家长」三栏；其余三栏周末家庭会议和孩子一起定）
  时段  晚饭后一段，玩到几点 [待补]（家庭会议定）
  场景  [待补]（家庭会议定；常见底线是吃饭不用、卧室不用）
  例外  [待补]（家庭会议定）
  结束  晚饭后玩之前先说好：玩到几点，定时器摆在看得见的地方；到点前 5 分钟提醒一次
        游戏可以打完当前这一局，最长 10 分钟；放下后接一件具体的事（洗澡或拼图）
  违约  哭闹不加罚，当天不再补玩；连续 3 次，周末开家庭会议重谈
  家长  到点收孩子的手机时，大人的手机也放下
3 这几句话直接用
  开始前  「今天玩到 7 点半，定时器在这儿。到点前 5 分钟我提醒你。」
  到点前  「还有 5 分钟。到时候你自己关，还是我来提醒你？」
  哭闹    先把人和东西隔开，保证安全，少说话：「你现在很生气，我在这儿陪你。手机先放这里，平静了我们再说。」
  收尾    第二天：「昨天到点的时候发生了什么？下次到点我们怎么做？」
4 两周复盘单：哭闹结束的次数（第一周 / 第二周）__ / __；哪条最难；这次只改一条
```

「[待确认] 1 项」是：除了结束方式，还有没有别的问题，要看 7 天记录。[待补] 的三栏由家庭会议填，不算待确认。

完整长示例（8 岁孩子：7 天记录 → 脚本小结 → 约定草稿 → 原话 → 复盘单）见 [examples/8yo-tablet.md](examples/8yo-tablet.md)。

## 常见问题（FAQ）

**问：孩子偷偷玩（半夜拿手机、借同学的）怎么办？**
答：先别加罚，把「夜间设备放客厅充电」这条对全家执行，家长同样；然后找平静的时候问孩子最想玩的是什么，把合理的部分写进约定的时段里。一刀切没收，最容易把孩子逼去偷偷用。

**问：爷爷奶奶带的时候随便给玩，约定执行不下去怎么办？**
答：请老人一起参加家庭会议，约定写成一张纸贴出来，老人只需要执行「到点提醒、定时器响了放下」这一条；不在孩子面前争谁对谁错。

**问：按你给的话说了，孩子还是哭闹、不交设备怎么办？**
答：先保证安全，少说话，不抢夺；等平静下来再用三句话收尾。当场不加罚，按约定的违约办法处理；连续 3 次就重开家庭会议。

**问：学校要求用平板写作业，算不算屏幕时间？**
答：学校布置的线上作业写进约定的「可以，不算娱乐时间」；但学习用屏 30–40 分钟后远眺 10 分钟，查完资料即关。

**问：能用手机自带的限额、停用时段吗？**
答：能，用来提醒和上锁；开启前告诉孩子开了什么、为什么，不用来秘密监控。

**问：孩子说「同学都有手机」怎么办？**
答：先接住担心：「你担心在同学里落单，这个我懂。」再用上面的五个问题一起判断是不是真需要；三个以上答「否」就先不给，或给功能简单的设备。

**问：周末、假期能放宽吗？**
答：能，但要提前写进「例外」：比如周末电影夜一次，生日、假期、生病在家最多加 30 分钟；临时放宽，下次就得临时收紧。

**问：我自己也刷手机停不下来，怎么办？**
答：家长那一栏和孩子同样执行：吃饭、睡前、陪玩时不用手机；每周看一次自己的屏幕使用时间，在家庭会议上公开。

## 常见错误（反模式）

最佳实践先记三条：先记 7 天再定规矩；约定由孩子参与写、家长同样遵守；例外提前写好，冲突当下不改规矩。

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 一刀切没收 | 孩子转去偷偷用、借同学的，冲突反而升级 | 一起写约定，先管一两件事 |
| 只管时长，不管内容和场景 | 一小时刷短视频和一小时做动画不是一回事 | 分清学习、创作、联系、消遣，主要管消遣 |
| 家长单方面宣布、自己不遵守 | 孩子学到的是「规则只管小孩」 | 家长那一栏写进约定，家长同样执行 |
| 把屏幕时间当奖惩货币 | 越奖越值钱，孩子越惦记 | 屏幕时间按约定走，不和成绩、家务挂钩 |
| 气头上临时加罚 | 约定失去信用，下一次更难执行 | 按事先约好的违约办法，当天或第二天处理 |
| 秘密查看聊天、偷装监控 | 一旦被发现，信任比屏幕问题更难修复 | 担心安全就直接谈，或者求助学校和专业人士 |
| 设备放卧室过夜 | 最先被挤掉的是睡眠 | 睡前 1 小时全家设备放客厅充电 |
| 只拿走，不给替代 | 孩子只会一直盯着被拿走的东西 | 关屏幕后接一件具体的事 |
| 一次改好几条规矩 | 一样也改不成 | 每次只改一到两条，两周复盘再改一条 |
| 看到时长超了就说孩子「成瘾」 | 贴标签不是诊断，还会激化冲突 | 只描述行为；有严重迹象就求助专业人士 |

## 边界与不做什么

- 不做诊断：不判断孩子是否成瘾，是否有注意力、情绪或其他心理问题。
- 出现以下迹象，一律建议尽快求助专业人士（儿童保健科、儿童精神心理门诊、学校心理老师）：连续几周因为屏幕严重影响睡眠、上学或吃饭；为了用手机撒谎、偷拿钱、逃学；拿走设备后长时间强烈的情绪或攻击行为；对以前喜欢的事和朋友都没了兴趣；家长已经无法和孩子正常沟通。
- 孩子说出或做出伤害自己的事：立刻陪在身边，拨打急救电话（120）或当地心理援助热线，尽快就医。
- 遇到网络欺凌、陌生人索要照片、诱导转账：保留证据，告诉学校，必要时报警。
- 学校对手机进校园的规定，以学校通知为准；未成年人玩网络游戏的时段限制，以国家现行规定和平台公告为准。
- 不推荐具体的管控软件或设备品牌；不教破解密码、绕过设置，也不教秘密监控。
- 视力下降、眼睛不适，找眼科医生。
