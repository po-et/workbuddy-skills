# 示例：竞选班长（2 分钟）

> 以下为示例：人物李想及其全部经历均为虚构，只演示结构与写法，不能当作任何人的经历使用。

## 对话

**用户**：周五班会竞选班长，每人限时两分钟。我们是大一新生，军训刚结束。

**助手**：写之前问三件事：
1. 军训或高中时，你做过哪些和「组织、协调」有关的事？说具体一点：做了什么、做了多久、结果怎样。
2. 开学这段时间，你觉得班里最不顺的一件事是什么？
3. 竞选是在教室里讲，还是全院一起？台下大概多少人？

**用户**：
1. 军训时我是二排排头，每天早上报人数、统计请假，晚上把名单交给连长，十四天一次都没报错。高三元旦晚会我是总负责，一共十二个节目，从报名到彩排都是我在协调。
2. 辅导员的通知经常在几个群里转，上周体检通知就有三个同学没收到，差点错过。还有，开学两周了，很多人还叫不出彼此的名字。
3. 就在教室，四十个人左右。

## 交付

信息行：班长｜班级内竞选，约 40 人｜2 分钟｜可念 416 字，估 1 分 44 秒 - 2 分 5 秒（经验值）

```
【开场】
各位同学好，我是李想，木子李，想法的想。【停顿】开学两周了，我想先请大家做一件事：能叫出全班一半以上同学名字的，请举一下手。【停顿】谢谢。
【为什么是我】
军训的时候，我是二排的排头，每天早上报人数、统计请假，晚上把名单交给连长，十四天没有报错过一次。高三那年，我是班里元旦晚会的总负责，十二个节目，从报名到彩排都是我在协调。这两件事让我知道，组织工作最怕的不是事情多，而是信息漏掉。所以我想竞选班长，先把咱们班的信息理顺。
【三件事】
上周的体检通知，在几个群里转来转去，还是有三位同学没收到，差点错过。所以如果我当选班长，第一件事：班级正式通知只在一个群里发，重要通知用接龙确认，第二天还没接龙的，我一个一个私信提醒。
第二件事：每个月开一次班会，前十五分钟留给大家提意见，第一次就放在当选后的第二周。提出来的问题，下次班会前我给答复，能办的去办，办不了的说清原因。
第三件事：这个月内组织一次全班见面会，每人一分钟自我介绍，再按宿舍打乱分组做一次小游戏，争取一个月后，大家都能叫出彼此的名字。
【结尾】
如果刚才举手的人不多，我希望下个月再问这个问题的时候，所有人都能举手。请大家投我一票，谢谢！
```

事实出处：

| 稿中内容 | 用户原话 |
|---|---|
| 二排排头，报人数、统计请假、交名单，十四天没报错 | 「军训时我是二排排头……十四天一次都没报错」 |
| 元旦晚会总负责，十二个节目，从报名到彩排协调 | 「高三元旦晚会我是总负责，一共十二个节目，从报名到彩排都是我在协调」 |
| 体检通知三人没收到 | 「上周体检通知就有三个同学没收到，差点错过」 |
| 开场举手提问 | 「开学两周了，很多人还叫不出彼此的名字」 |

说明：结尾写成「如果刚才举手的人不多」，因为现场有多少人举手事先不知道，不能替台下下结论。

台上问答（要点）：
- 「通知让大家接龙，会不会太麻烦？」→ 只有需要本人确认的重要通知才接龙，一般通知不用；接龙比事后一个个问省事。
- 「班会提的意见办不了怎么办？」→ 说清原因，比不回应强；需要辅导员拍板的，我带着整理好的意见去问。
- 「你和别的候选人比优势在哪？」→ 不评价别人；我能保证的是军训十四天报数没出错，和刚才说的第一件事。

练习提醒：两处【停顿】各停两秒，真的看台下；问完「请举一下手」要等大家举完再往下讲。
