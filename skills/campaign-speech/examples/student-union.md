# 示例：竞选学生会宣传部干事（3 分钟）

> 以下为示例：人物陈思远及其全部经历均为虚构，只演示结构与写法，不能当作任何人的经历使用。

## 对话

**用户**：院学生会宣传部招干事，要上台讲三分钟，讲完部长会提问。我大一。

**助手**：问三件事：
1. 你做过哪些和宣传相关的事？写稿、拍照、剪视频、排版、画海报都算。有没有能拿出来的作品？
2. 你看过学院的公众号吗？说一个你觉得可以做得更好的具体地方。
3. 每周大概能拿出多少时间？哪几个时段比较固定？

**用户**：
1. 高中两年是校刊学生编辑，编了六期，每期二十来页，我负责其中两个栏目，约稿、改稿、排版都做过。会用剪映，军训汇演给我们连剪了一个三分钟的回顾视频，素材是全连同学手机里的照片和视频，收了三百多条，花三个晚上剪完，在年级群里被转了很多次。视频和校刊电子版都在手机里。
2. 我翻了学院公众号最近的活动推送，很多是活动结束好几天才发，发出来大家的兴奋劲都过去了。
3. 每周能拿出六到八小时，周三下午没课。

## 交付

信息行：学生会宣传部干事｜院学生会纳新，部长在场｜3 分钟｜可念 653 字，估 2 分 43 秒 - 3 分 16 秒（经验值）

```
【开场】
各位学长学姐好，我是大一新生陈思远，想竞选宣传部干事。我翻了学院公众号最近的活动推送，发现一个小问题：很多推送是在活动结束好几天以后才发出来的。等推送出来，大家的兴奋劲已经过去了。
【为什么是我】
高中两年，我是校刊的学生编辑，一共编了六期。每期二十来页，我负责其中两个栏目，约稿、改稿、排版都做过。这次军训汇演，我用剪映给我们连剪了一个三分钟的回顾视频：素材是全连同学手机里的照片和视频，我收了三百多条，用三个晚上剪完，后来在年级群里被转了很多次。视频和校刊的电子版都在我手机里，等一下可以给各位学长学姐看。这两件事让我知道，宣传最花时间的不是剪辑和排版，而是把素材收齐、按时交出去。
【三件事】
如果我能加入宣传部，我想先做好三件事。
第一，活动结束后二十四小时内交出推送初稿，文字和配图一起交，部长审稿的时候不用再等素材。我会带着手机到现场，边拍边记下关键数字和发言，活动一结束就开始写。我想帮部门把推送从“好几天后”提前到“第二天”。
第二，建一个学院活动照片库，按日期和活动名称整理，每次活动的原图都放进去，每个文件夹写清拍摄人，用的时候方便署名。年底要做回顾视频的时候，不用再到处找照片。
第三，每个月学一个新技能，比如排版规范、短视频字幕，学会了就在部门例会上花十分钟分享给大家。第一个月我想先学公众号的排版规范，因为这是部门每周都要用的。
这三件事都不需要额外经费，也不用改变部门现在的分工，我进来第一周就能开始做。时间上，我每周能拿出六到八个小时，周三下午没课，可以固定用来做部门的事；活动集中的那几周，我会提前把作业安排好。
【结尾】
我想让同学们在活动结束的第二天，就能在公众号上看到自己的照片。如果我能加入宣传部，这件事我从第一场活动就开始做。请给我一个机会，谢谢各位学长学姐！
```

事实出处：

| 稿中内容 | 用户原话 |
|---|---|
| 推送常在活动结束好几天后才发 | 「很多是活动结束好几天才发，发出来大家的兴奋劲都过去了」 |
| 校刊编辑两年、六期、每期二十来页、负责两个栏目 | 「高中两年是校刊学生编辑，编了六期，每期二十来页，我负责其中两个栏目」 |
| 回顾视频三分钟、三百多条素材、三个晚上、被转很多次 | 「剪了一个三分钟的回顾视频……收了三百多条，花三个晚上剪完，在年级群里被转了很多次」 |
| 作品在手机里 | 「视频和校刊电子版都在手机里」 |
| 每周六到八小时、周三下午没课 | 「每周能拿出六到八小时，周三下午没课」 |

说明：开场指出推送偏慢，用的是「发现一个小问题」「我想帮部门」的说法——台下坐的正是做推送的人，只说事实和你能补上的部分，不评价别人做得好不好。「被转了很多次」保持用户原话，没有替他编转发数。

台上问答（要点）：
- 「如果部门活动和你的考试撞了怎么办？」→ 考试周前一周我会先把能提前做的素材整理交掉，并提前跟部长说清哪几天不在。
- 「你的推送初稿被部长大改，你怎么想？」→ 改得越多我学得越快；我会把改动前后对照存下来，下次少犯同样的错。
- 「你觉得推送最重要的是什么？」→ 准确和及时。名字、时间、数字不能错，其次是快。

练习提醒：估算最长 3 分 16 秒，超过 3 分钟。如果现场严格掐 3 分钟，删掉「这三件事都不需要额外经费……就能开始做」一句（35 字）和「每个文件夹写清拍摄人，用的时候方便署名」（18 字），可念字数降到 600，估 2 分 30 秒 - 3 分钟。
