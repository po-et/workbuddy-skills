# 竞选稿

定位一句话：**竞选稿要让台下在一两分钟里记住三件事：你是谁、凭什么信你、你上任第一个月会做什么。** 事实只用你自己的；本技能负责把它们排好、说顺、卡准时间。

## 何时使用

- 「明天班会竞选班长，限时两分钟，帮我写个竞选稿」
- 「想竞选学习委员，但我没当过班干部，写什么」
- 「学生会宣传部竞选要上台讲三分钟，还可能被提问」
- 「社团换届竞选副社长，要一段发言」
- 「稿子写好了，念出来大概多长？会不会超时？」

不适用：
- 只要一段自我介绍（开学破冰、社团面试开场）：不需要「三件事」，直接简答——名字＋一个具体特点＋一件想和大家一起做的事，三句话。
- 奖学金答辩、评优陈述：转 `scholarship-application`（奖学金申请）。
- 公司岗位竞聘、社会选举：不在范围，说明后不代写。

## 写作流程

### 第 1 步：先拿到五样材料

| 要问的 | 为什么要 |
|---|---|
| 职位与场合 | 班长和文体委员要讲的事完全不同；班会、全院大会、面试式竞选的语气也不同 |
| 限时 | 决定字数档位（第 3 步） |
| 台下是谁 | 新生互不认识 → 先让人记住你；老同学 → 少介绍、多讲计划 |
| 2–3 件真实经历 | 「为什么是我」只能用这些；没有就找可迁移的小事，不编 |
| 一个你观察到的真问题 | 「三件事」从这里长出来，比口号有说服力 |

### 第 2 步：四段结构

1. **开场钩子**：称呼一句带过，第二句就进钩子——一个你亲眼见到的场景、一个你自己数过的数字、一个台下都关心的问题，或一个让人记住名字的小细节。选一种，不超过两句。
2. **为什么是我（只讲事实）**：每件事＝做过什么＋做了多久或多少＋结果＋和这个职位的关系。没当过干部就用可迁移的真事（军训报数、宿舍排值日、课代表、社团分工），或者坦白：「我没当过，但……」。
3. **我要做的 3 件具体的事**：每件＝动作＋时间或频率＋同学能感到的变化，并过三关：在职位权限内、一个月后能检验、靠你自己推得动。
4. **结尾**：回扣开场＋一句请求＋谢谢。不喊「给我一个机会，还你一个奇迹」这类口号。

钩子写法、各职位「三件事」点子库、口语化改写对照见 [references/hooks-and-plans.md](references/hooks-and-plans.md)。

### 第 3 步：按限时定字数（经验值）

按每分钟约 200–240 字换算。这是普通语速的经验值，不是标准；紧张时会变快或卡壳。

| 限时 | 总字数 | 开场 | 为什么是我 | 三件事 | 结尾 |
|---|---|---|---|---|---|
| 1 分钟 | 200–240 | 35–40 | 55–60 | 90–110 | 20–30 |
| 2 分钟 | 400–480 | 50–70 | 110–130 | 200–230 | 40–50 |
| 3 分钟 | 600–720 | 70–90 | 170–200 | 300–350 | 60–80 |

限时严格的按下限写，出声计时练两遍。念稿计时（【】里的提示不计字，段落以【开场】【为什么是我】【三件事】【结尾】开头即可分段对照）：

```bash
python3 scripts/campaign_timer.py 竞选稿.txt --minutes 2
```

输出可念字数、估算时长区间、与目标档位差多少字、每段字数与建议值。其他限时（如 90 秒）用 `--minutes 1.5`；支持 .txt、.md、.docx。

### 第 4 步：改成说得出口的稿

- 一句不超过 25 字，念着绊嘴就拆开；
- 「本人」改「我」，「致力于」改「会」，「综上所述」删掉；
- 时间说死：「每周日晚上九点」，不说「定期」；
- 要停顿、要看台下的地方标【停顿】。

### 按职位调整侧重

| 职位 | 台下最关心 | 「三件事」从哪里想 |
|---|---|---|
| 班长 | 能不能协调、公不公平 | 通知怎么传、班会怎么开、班费和评优怎么公开 |
| 学习委员 | 作业、资料、考试信息 | 作业汇总、资料共享、考前答疑 |
| 生活、文体、宣传委员 | 日常省不省心、活动好不好玩 | 报销流程、活动日历与分工、班级相册 |
| 学生会部门 | 你能干什么活、有多少时间 | 你的具体技能＋部门的日常工作 |
| 社团干部 | 活动质量与成员留存 | 例会节奏、新人带教、活动分工与复盘 |

### 台上问答准备

最常被问：为什么想做这个职位；学习和工作冲突怎么办；同学不配合怎么办；没选上怎么办；你说的第一件事第一步做什么。答题公式：**结论一句 → 一个具体做法或经历 → 回到你能为大家做什么**，每题 30 秒内（约 100–120 字，经验值）。完整题库与答题骨架见 [references/stage-qa.md](references/stage-qa.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 只给了职位，缺限时和经历 | 先问 3 个：限时多久、做过哪 2–3 件相关的事、班里最该改进的一件事；场合和台下按「新生班会」默认，交付物里标 [待确认] | 「回答我三个问题就能写：限时多久？你做过哪两三件相关的事？你觉得班里现在最该改进什么？」 |
| 要求编经历、编获奖（「随便编几个」） | 不编；改用可迁移的真实小事，或坦白式写法 | 「编的经历一被追问就穿帮。我们找你真做过的小事——军训、宿舍、高中课代表，哪件和这个职位沾边？」 |
| 限时与字数矛盾（如「1 分钟，写 800 字」） | 指出矛盾，给两种理解让用户选 | 「1 分钟大约念 200–240 字（经验值），800 字要 3 分半左右。你要的是 1 分钟稿，还是限时其实是 3–4 分钟？」 |
| 竞选公司岗位、社会选举 | 超出范围，说明后不代写 | 「这个技能只写学生干部竞选。岗位竞聘要讲业绩和岗位规划，结构不一样。」 |
| 马上上台，只要最小可用版 | 给 1 分钟版：钩子一句＋一件事实＋一件最具体的承诺＋结尾一句，约 200 字；问答只备「为什么选你」 | 「来不及就先用这版 200 字的，1 分钟内讲完；问答先准备『为什么选你』一题。」 |
| 坚持承诺职权外的事或贬低对手（「当选就取消晚自习」） | 守住边界，换成推得动的事 | 「做不到的承诺，当选后会被追着问。换成你推得动的：比如每周把作业要求汇总成一条。」 |

脚本报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 1「参数或输入有误：……--minutes……」 | `--minutes` 不在 0–30 之间，或不是数字 | 例：`--minutes 2`、`--minutes 1.5` |
| 1「参数或输入有误：……--rate……」 | `--rate` 不是「200-240」这种写法，或下限大于上限 | 例：`--rate 180-220` |
| 1「没有可计数的文字」 | 空文件，或只有【】提示和 # 标题 | 确认文件里有正文 |
| 2「文件问题：……」 | 路径不对、没权限、是文件夹、PDF 或旧版 .doc、编码无法识别 | 检查路径；另存为 .txt（UTF-8）或 .docx |
| 130 | 按了 Ctrl+C | 重新运行即可 |

## 输出契约

交付物按以下顺序，每次都一样：

1. **信息行**：职位｜场合｜目标时长｜可念字数与估算时长（经验值）
2. **竞选稿正文**：各段以【开场】【为什么是我】【三件事】【结尾】开头（练习用，上台版可删）
3. **事实出处**：稿中每条经历、数字 → 对应的用户原话
4. **台上问答**：3 道最可能的题＋回答要点（每题 ≤120 字）
5. **练习提醒**：一句话（计时、停顿、眼神）

占位符：用户没给、必须由用户补的写 `[待补：补什么]`；替用户假设的默认值写 `[待确认：假设了什么]`。有占位符时，交付第一句就提醒。

交付前自检（逐条答「是」才交）：
- 稿中每条经历、数字，都能在「事实出处」里找到用户原话
- 三件事都有动作＋时间或频率＋可检验的变化
- 可念字数落在所选档位区间（脚本或手数）
- 没有职权外的承诺，没有点名或暗讽其他候选人
- 没有把示例里的虚构人物、经历写进用户的稿子
- 残留的占位符已在开头提醒

## 示例

以下为示例，人物张一鸣及其经历均为虚构。

**用户**：下周班会竞选学习委员，限时一分钟，我是大一新生。

**助手**：先问两件事：① 高中或军训时，你做过哪件跟「帮大家学习」有关的事？② 你觉得咱们班现在学习上最不方便的是什么？

**用户**：高中当了两年数学课代表，每天收发四十多本作业，没丢过一本，放学前把没交的名单报给老师。现在各科作业要求散在五个群里，上周高数作业有六个人漏交。

**助手**（交付）：

信息行：学习委员｜新生班会｜1 分钟｜可念 220 字，估 55 秒 - 1 分 6 秒（经验值）

> 【开场】各位同学好，我是张一鸣。我们班的作业要求散在五个群里，上周高数作业就有六个人漏交。
> 【为什么是我】高中我当了两年数学课代表，每天收发四十多本作业，没丢过一本，每天放学前把没交的名单报给老师。我知道，作业最怕的不是多，是信息没传到。
> 【三件事】如果我当选，会做三件事：第一，每周日晚上九点，在班群发一条本周各科作业汇总，写清截止时间；第二，建一个共享文件夹，按科目放课件和复习资料；第三，期中考试前两周，每周组织一次答疑，我先讲数学，也欢迎各科学得好的同学来讲。
> 【结尾】一个月后，如果还有人因为没看到通知而漏交作业，请来找我。谢谢大家！

事实出处：五个群、六人漏交 ←「作业要求散在五个群里，上周高数作业有六个人漏交」；两年课代表、四十多本、没丢过、报名单 ←「当了两年数学课代表……放学前把没交的名单报给老师」。

台上问答（要点）：
- 「学习委员很花时间，你自己的成绩怎么办？」→ 汇总固定在周日晚上半小时做完；答疑本身也是我复习数学的时间。
- 「有人还是不看汇总怎么办？」→ 截止前一天在群里再提醒一次，还没交的单独私信。
- 「没选上呢？」→ 作业汇总我照样整理，交给新当选的学习委员。

练习提醒：估算最长 1 分 6 秒；限时卡得严，就删掉「也欢迎各科学得好的同学来讲」这 13 字。念到「六个人漏交」停一秒，看台下。

## 常见问题（FAQ）

**没当过班干部，「为什么是我」写什么？** 写可迁移的真事：军训报数、宿舍排值日、课代表、社团里负责过的一件事。实在没有，就坦白「没当过」，把篇幅留给三件事——具体的计划比空头资历更有说服力。

**要不要脱稿？** 能脱稿最好；做不到就看提纲讲，至少开场和结尾背熟，这两处要看着台下说。

**可以直接用示例吗？** 不行。示例人物和经历是虚构的，只用来看结构；照搬的话，你答不上追问，同一场也可能有人用了同一篇。

**能加名言或口号吗？** 最多一句，而且后面要接你自己的事。整篇靠口号，台下记不住你是谁。

**同时竞选两个职位怎么写？** 主讲第一志愿，结尾加一句「如果没选上班长，我也愿意做生活委员，因为……」，理由也要是事实。

**讲到一半时间到了怎么办？** 直接跳到结尾那句请求。所以写稿时就把最重要的那件事放在三件事的第一位。

**能帮我在群里拉票吗？** 不代发消息，也不做刷票。可以帮你写一段群里的自我介绍，发不发由你决定。

## 常见错误（反模式）

- 开场三句全是称呼和客套 → 前十秒最值钱，被浪费了 → 称呼一句带过，第二句进钩子。
- 「我性格开朗、认真负责、乐于助人」 → 形容词没人信 → 换成一件你做过的事。
- 「我会全心全意为大家服务」 → 无法检验，谁都能说 → 动作＋时间＋变化。
- 承诺职权外的事（取消晚自习、减少作业） → 当选后兑现不了，还显得不懂规则 → 只承诺你推得动的。
- 编经历、编获奖 → 台上一追问就穿帮，同学会记很久 → 用真实小事或坦白式写法。
- 按「写」的标准而不是「念」的标准写 → 长句念不顺，超时被打断 → 短句，出声计时。
- 照搬网上范文 → 同一篇可能在同一场出现两次 → 从你们班的具体问题写起。

## 边界与不做什么

- 只帮你整理和表达**你自己的真实经历**：会追问具体细节；不编造经历、职务、获奖、成绩或数据。示例中的人物与内容均为虚构，不能当作你的经历使用。
- 不写贬低、影射其他候选人的内容；不出请客、送礼换票、刷票这类主意。
- 不代你在班级群、投票系统里发消息或投票。
- 报名条件、投票方式、任期等竞选规则，以学校、学院或社团的通知为准。
