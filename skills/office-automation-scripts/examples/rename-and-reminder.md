# 示例：活动照片改名 + 到期日变日历提醒

> 以下为示例。文件名、事项、日期为虚构；脚本输出是在测试文件夹里实际运行的结果，只把绝对路径截短成 `…/`。

## 场景一：活动照片批量改名

**用户**：秋季市集拍了几百张照片，都叫 DSC_0009 这种，想改成「日期-活动名-序号」。

**助手先问**：① 照片都在同一个文件夹吗？② 按文件名顺序编号就行，还是要按修改时间？③ 序号几位？超过 999 张要用 4 位。

**用户**：都在「活动照片」文件夹；按文件名就行；不到 1000 张。

**助手交付**：

```text
算账：一年只做几次，但一次几百张、手工改容易漏改错改 → 属于「易错、错了麻烦」，值得用脚本
选层：第 3 层（上百个文件、要对照表留底）
预览：python3 scripts/batch_rename.py 活动照片 --prefix 2026-09-20-秋季市集
执行：python3 scripts/batch_rename.py 活动照片 --prefix 2026-09-20-秋季市集 --apply
核对：用表格软件打开「活动照片/改名对照表.csv」，看首尾几行和张数
撤回：原件不动，改好名的是副本，放在「活动照片/已改名」；不满意删掉这个文件夹即可
```

预览输出（这里用 4 张演示）：

```text
DSC_0009.JPG  ->  2026-09-20-秋季市集-001.JPG
DSC_0010.JPG  ->  2026-09-20-秋季市集-002.JPG
DSC_0011.JPG  ->  2026-09-20-秋季市集-003.JPG
DSC_0012.JPG  ->  2026-09-20-秋季市集-004.JPG

对照表：…/活动照片/改名对照表.csv
预览：4 个文件。用表格软件打开对照表核对，确认后加 --apply 生成副本。
```

加 `--apply` 后：

```text
已生成 4 个副本，跳过 0 个，失败 0 个。副本在：…/活动照片/已改名
原件未改动；要撤回，删掉这个文件夹即可。
```

## 场景二：到期清单变成日历提醒

**用户**：店里几个证照和合同的到期日老是忘，能不能到期前几天提醒我？

**助手**：把事项和到期日整理成两列的 CSV（第一行写「事项,到期日」），日期写 2026-10-20 或 2026/10/20 都行。事项里有英文逗号时，这一格加英文双引号。

用户的 `到期清单.csv`：

```text
事项,到期日
门店营业执照年报,2026/12/31
二店租赁合同续签,2026年11月5日
"消防设施年检, 一店",2026-10-20
```

运行 `python3 scripts/ics_reminder.py 到期清单.csv` 的输出：

```text
已写入 3 条提醒，跳过 0 行：…/到期提醒.ics
提醒时间：到期前 3 天 09:00（TRIGGER:-P2DT15H）。导入后抽一条核对，例如「消防设施年检, 一店」应在 2026-10-17 09:00 弹出。
```

生成的 `到期提醒.ics` 开头（每行以 CRLF 结尾，事项里的逗号已按日历格式转义）：

```text
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//example.com//reminder//CN
CALSCALE:GREGORIAN
BEGIN:VEVENT
UID:926cad61248c8409@example.com
DTSTAMP:20260926T144421Z
DTSTART;VALUE=DATE:20261020
DTEND;VALUE=DATE:20261021
SUMMARY:消防设施年检\, 一店到期
BEGIN:VALARM
ACTION:DISPLAY
DESCRIPTION:消防设施年检\, 一店
TRIGGER:-P2DT15H
END:VALARM
END:VEVENT
```

助手的收尾提醒：

> 把 .ics 导入你常用的日历后，按输出里给的例子核对一条：「消防设施年检, 一店」应在 2026-10-17 09:00 弹出。个别日历应用会忽略导入的提醒，没弹就在该应用里手动给这几条加提醒。每年固定的事项（如年报）直接建「每年重复」的日历事件更省事。
