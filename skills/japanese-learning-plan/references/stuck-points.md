# 卡点对策详表：动词变形、敬语与其他高频卡点

> 本页是 SKILL.md「常见卡点与对策」的完整版。用户卡在某一点时，先让他做一次小测（如 20 个动词变形），按错误类型挑下面对应的练法，不推倒整个计划。

## 动词变形

```
先分类  三类：只有する、来る两个
        二类：词尾是る，且る前是い段或え段（食べる、見る、起きる）；
              帰る、入る、走る、知る、切る等长得像二类，其实是一类，单独背
        一类：其余都是（書く、飲む、話す、分かる）
て形    う・つ・る→って｜む・ぶ・ぬ→んで｜く→いて｜ぐ→いで｜す→して｜行く→行って（例外）
        二类去る加て；する→して，来る→来て；た形规则相同，て换成た、で换成だ
ない形  一类把词尾换成あ段加ない，う要变わ（買う→買わない）；二类去る加ない；する→しない，来る→来ない
练法    一张卡一个动词，正面辞书形，背面ます、て、ない、た四种形；每天抽20张计时，
        错了标「分类错」还是「规则错」，分类错就回头背例外表
```

小测怎么判：随机 20 个动词，变て形、ない形、た形，计时。正确率低于 90% 或平均每个超过 2 秒，就按四周复盘的规则每天从新课里挪 5 分钟练变形卡；错题里「分类错」多的先背例外表，「规则错」多的按上表逐条过。

## 敬语

```
先看主语  对方（上级、客户）的动作→尊敬语；自己或己方的动作→谦让语；只求说得礼貌→です/ます
公式      尊敬：お＋ます形去掉ます＋になる（お待ちになる）
          谦让：お＋ます形去掉ます＋する（お持ちします）；汉语词多用ご（ご説明します）
特殊动词  尊敬／谦让：いる→いらっしゃる／おる；行く・来る→いらっしゃる／参る；言う→おっしゃる／申す；
          食べる・飲む→召し上がる／いただく；見る→ご覧になる／拝見する；する→なさる／いたす；
          知っている→ご存じだ／存じている；会う→お会いになる／お目にかかる
内外之别  对外人提到自己公司的上司，用谦让语，名字后不加さん——初学者很容易在这里出错
练法      把一段普通体对话改写成对客户说的版本，再对照教材答案；每周两段
```

## 其他高频卡点

各记一条规则加三个自己造的例句：

- **は和が**：疑问词作主语时用が（誰が来ましたか），回答也用が。
- **に和で**：存在的地点用に，动作发生的地点用で（公園にいます／公園で遊びます）。
- **自动词和他动词**：成对背（開く／開ける、閉まる／閉める、始まる／始める）。
- **汉字**：同形异义词单独建一页（手紙＝信、勉強＝学习、大丈夫＝没关系、娘＝女儿），读音按整词记，不按中文读音去猜。
