# 日语学习

定位一句话：**零基础到N4/N3，拼的不是教材选得多好，而是三件事：第一周把五十音过关；之后每天在固定时段按「复习→新课→单词→听力」走；每四周用实测数据调一次计划。**

## 何时使用

主要场景（从零排一份计划）：

- 「零基础怎么学日语？每天只有 30 分钟，想明年考 N4」
- 「想一年内考 N3，帮我排个计划」「不考试，只想看懂动画，怎么学」

辅助场景（已经在学，卡住或要调整）：

- 「五十音背了一周，还是分不清ぬ和め」
- 「动词变形总记混，敬语也看不懂怎么办」
- 「学了一个月，帮我按四周复盘调一下计划」

调用方式：在对话里说目标、每天可用时间和现在的水平；有教材的给出总课数（看目录）。排进度和复盘调整可以在本机运行 `python3 scripts/plan_calc.py`，结果与下文的手算规则一致。JLPT 的考试日期和报名方式以官方公告为准。

不适用（遇到时这样处理）：

- 要推荐具体付费课程、培训机构或 App → 不点名，只说教材类型（配音频的零基础教材、间隔复习卡片）。
- 留学、签证、求职对日语的要求，正式翻译件，法律或医疗场景的日语文件 → 以学校、使领馆、用人单位的官方说明为准；翻译请找专业译者。
- 只问一个语法点或一个词怎么用 → 直接简答，不必排整份计划。

## 先判断：目标、时间、起点

```
目标  考N4还是N3、哪一次考？不考试的（看动画、旅游、工作），复盘时把「模拟题」换成你的目标材料
时间  每天稳定拿得出30还是60分钟（按最忙的那天算）；时间不固定的，以30分钟版保底，有空的日子只加听力和复习
起点  会五十音的先测：平假名、片假名各随机抽20个，1分钟内各读对18个以上，可跳过第一周
材料  一套配音频的零基础教材，加一种能间隔复习的单词工具（纸卡或任意间隔复习软件）
```

新JLPT官方不公布词汇表和语法表。常见的非官方估计是N4约1500词、300个汉字，N3约3700词、650个汉字，只用来排计划，以教材和官方样题为准。

排进度的算法：可用周数＝离考试的周数－第一周五十音－最后四周总复习；每周课数＝教材总课数÷可用周数。示例：小王每天30分钟，离考试44周，教材共48课（以实际目录为准），可用周数＝44－1－4＝39周，每周约1.2课。第一个四周复盘时，如果实测每周只学得完1课，就要提前决定：每天加到45分钟，还是把最后几课降为只求认得。

同样的算法写成了脚本，顺带列出新课开始、每次四周复盘、总复习开始的日期：

```bash
python3 scripts/plan_calc.py plan --weeks 44 --lessons 48 --minutes 30
```

## 第一周：五十音

```
天  60分钟版｜30分钟版
D1  平假名あ～な行（25个）｜平假名あ～さ行（15个）
D2  平假名は～わ行和ん（21个）｜平假名た～は行（15个）
D3  浊音、半浊音、拗音（きゃ、しゅ等）｜平假名ま～わ行和ん（16个），全表默写一遍
D4  促音っ、长音；平假名全表听写，错的做记号｜浊音、半浊音
D5  片假名ア～ナ行｜拗音、促音、长音
D6  片假名ハ～ン；外来语长音符号「ー」｜平假名全表听写；片假名ア～サ行
D7  平假名、片假名各抽30个，读音加听写｜测平假名；片假名剩下的并入第二周，每天10分钟
```

每行按五个步骤学：看字形→听音跟读三遍→按笔顺写三遍→遮住回想→听写。时间分配：60分钟版前40分钟学新内容，后20分钟复习前一天的并听写；30分钟版前20分钟学新、后10分钟复习听写。过关标准：看到假名1秒内读出，听写正确率90%以上。

- ら行是舌尖轻弹一下，不是英语的r或l；つ、ふ、ん多听原音跟读。
- 长音、促音会改变意思：おばさん（阿姨）和おばあさん（奶奶），きて（来）和きって（邮票）。
- 易混字成对练：ぬ/め、ね/れ/わ、る/ろ、さ/ち、は/ほ；シ/ツ、ソ/ン、ク/ケ/タ、ヌ/ス。
- 片假名在课文里出现得少，最容易忘：第二周起，每课出现的外来语单独抄一遍、读三遍。

## 主线：语法顺序、词汇与听力配比

```
阶段1  名词句：～は～です、ではありません、の、か；こそあど；数字、时间、价格
阶段2  存在句：あります/います；い形容词、な形容词的现在与过去、肯定与否定
阶段3  动词ます形和助词：を、に、で、へ、と、から、まで、が；～たい、～ましょう
阶段4  动词分类与变形：て形（～ている、～てください、～てもいい）、ない形、辞书形、た形——N4的核心关口
阶段5  大致对应N4：可能形、意向形、条件（と/ば/たら/なら）、授受（あげる/くれる/もらう）、被动、使役、简体会话
阶段6  大致对应N3：推测与传闻（ようだ/らしい/そうだ）、ために/ように、使役被动、敬语体系、长句与接续词
```

这条线按常见教材的顺序排，以你手上教材的目录为准；每个阶段学完，用教材的单元测试检查。

```
时间配比  新课与语法｜单词｜听力｜复习与输出
阶段1–3   35%｜25%｜25%｜15%
阶段4–5   30%｜25%｜30%｜15%
阶段6     25%｜25%｜35%｜15%
新词量    30分钟版每天8个，60分钟版每天15个；每个词记读音、汉字、意思和一个例句，学后第1、2、4、7、15天各复习一次
听力四步  不看原文听两遍→看原文听，圈出没听出的词→看原文同步跟读→不看原文慢半拍跟读（影子跟读）
```

听力材料按阶段换：阶段1–3用教材音频；阶段4–5加官方样题的听力；阶段6加面向学习者的简易新闻和带日文字幕的视频。JLPT除了总分，各部分还有最低分要求（以官方公告为准），听力不能留到最后才补。

## 模板：每日日程与四周复盘

```
30分钟版（第二周起）
0–5分   复习：到期单词卡，昨天的课文朗读一遍
5–15分  新课：一个语法点，例句读出声，再仿写一句关于自己的
15–23分 新词：8个
23–30分 听力：本课音频走一遍听力四步
第7天   不学新课：清错卡、变形卡，听写一段

60分钟版（第二周起）
0–10分  复习：到期单词卡，加动词变形卡20张（计时）
10–30分 新课：语法点一到两个，课文读三遍
30–42分 新词：15个
42–57分 听力：本课精听四步，再泛听学过的旧课
57–60分 输出：用今天的语法写三句关于自己的话
第7天   复盘日：小测、整理错题，按复盘规则调整下周
```

上面两版日程按阶段1–3的配比排；进入阶段4以后，按配比表把新课的分钟逐步挪给听力。

四周复盘模板（每四周填一次）：

```
进度  计划＿课，实际＿课，完成率＿%
单词  从已学词中随机抽50个：看日语说中文对＿个，看中文写假名对＿个
变形  随机20个动词，变て形、ない形、た形：正确率＿%，平均每个＿秒
听力  学过的课文音频，不看原文能听懂约＿成；听写30秒，错＿处
输出  不看稿能连续说＿句自我介绍或日常对话
卡点  最卡的三处：＿、＿、＿
调整  下四周：新课＿，新词＿，听力＿分钟
```

调整规则：完成率低于80%，下四周放慢新课，先还复习账；单词抽查对不到七成，新词减三成；变形正确率低于90%或平均每个超过2秒，每天从新课里挪5分钟练变形卡；课文听懂不到五成，从新课里挪10分钟给听力，并全部改成精听。全部达标且有余力，新词加两成。有考试日期的，用「剩余课数÷每周实际课数」算还要几周，来不及就把阶段6的部分内容降为只求认得；考前三个月开始做官方样题和模拟题。

示例：接上面的小王，第一个四周计划5课、实际学完4课（完成率80%），单词抽查50个对32个（64%），变形正确率85%。按规则，新词从8个减到6个，每天从新课里挪5分钟练变形卡；按每周1课重算，48课来不及，他决定每天加到45分钟，四周后再测一次。

填好的复盘数字也可以交给脚本，按同一套规则给出调整：

```bash
python3 scripts/plan_calc.py review --planned 5 --done 4 --words 32/50 --conj-rate 85 --lessons-left 44 --weeks-left 35
```

## 常见卡点与对策

动词变形和敬语是最常卡住的两处。完整规则、特殊动词表和练法见 [卡点对策详表](references/stuck-points.md)，要点如下：

- **动词变形**：先分类再套规则。三类只有する、来る；二类是词尾る且る前为い段或え段，但帰る、入る、走る、知る、切る等长得像二类，其实是一类，单独背；其余是一类。て形口诀：う・つ・る→って｜む・ぶ・ぬ→んで｜く→いて｜ぐ→いで｜す→して｜行く→行って。练法：一张卡一个动词，每天抽 20 张计时，错了标「分类错」还是「规则错」。
- **敬语**：先看主语——对方的动作用尊敬语，自己或己方的动作用谦让语，只求礼貌用です/ます；对外人提到自己公司的上司用谦让语，名字后不加さん。练法：每周把两段普通体对话改写成对客户说的版本。
- **其他高频卡点**：は和が、に和で、自他动词成对背、同形异义汉字单独建页，各记一条规则加三个自己造的例句。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息：只说「想学日语」 | 只问 3 个：目标和哪一次考试；每天稳定能拿出 30 还是 60 分钟；会不会五十音。教材课数没给就写 [待补]；其余按默认（30 分钟版、目标 N4）排，标 [待确认] | 「先问三件事：考 N4、N3 还是不考试，哪一次？每天稳定能拿出 30 还是 60 分钟（按最忙的那天算）？五十音会不会？」 |
| 参数不合理：每天 5 小时、离考试只剩 5 周、每天 10 分钟想一年考 N3 | 指出不合理处，用算法算给他看，给两个可选方案 | 「离考试只剩 5 周，扣掉五十音 1 周和总复习 4 周，新课排不下：要么改考下一次，要么这次只熟悉题型。你选哪个？」 |
| 说法自相矛盾：说零基础又说五十音都会；说考 N3 又说只想看动画 | 指出矛盾，给两种理解，请用户选 | 「你说零基础，又说五十音会了：我先按『会五十音、没学语法』排，第一周改成小测，对吗？」 |
| 超出范围：推荐课程、机构、App；留学签证要求；正式翻译；代写作业、代考 | 说明不做，转官方说明或专业译者；教材只说类型 | 「具体课程和机构我不推荐，选一套配音频的零基础教材就行；留学对日语的要求以学校官方说明为准。」 |
| 时间紧，只要最小可用版 | 最小版 = 按用户时间版本的第一周五十音日程 + 第二周起的每日日程 + 「四周后按复盘模板测一次」 | 「先给最小版：这周的五十音日程和第二周起的每日安排；四周后按复盘表测一次再调。」 |
| 坚持越界：要保证考过、要押题、要代考 | 守住：不承诺通过、不预测考题、不代考 | 「能不能过取决于每天的执行和复盘数据，我不能保证，也不押题；能做的是按实测数据帮你调计划。」 |
| 学到一半卡住（变形、敬语、听不懂） | 不推倒计划：先做小测，按错误类型给练法 | 「先做个小测：随机 20 个动词，变て形、ない形、た形并计时，把错的发我，我按『分类错／规则错』给练法。」 |

`scripts/plan_calc.py` 报错对照：

| 退出码 / 提示 | 原因 | 修正办法 |
|---|---|---|
| 0 | 算完 | 把可用周数、每周课数、关键日期或调整写进交付物 |
| 1「参数错误：…」 | 每天分钟数不在 10–600、周数不在 1–260、单词写成 60/50、考试日期已过、缺 `--weeks` 和 `--exam-date` | 按提示改；不考试的给一个自定的目标周数 |
| 3「排不开」 | 离考试太近，扣掉五十音 1 周和总复习 4 周后没有周数学新课 | 改考下一次，或这次只熟悉题型 |
| 130「已中断」 | 按了 Ctrl+C | 脚本不写文件，直接重跑 |
| 「注意：每天 X 分钟…」 | 时长不是 30 或 60 分钟，按相近的一版排 | 交付物里写明用了哪一版；时间固定的，多出的分钟为赶进度可加给新课，时间不固定的只加听力和复习 |

## 输出契约

交付物按以下顺序：

1. **参数确认**：目标（N4、N3 或不考试）、考试时间、每天 30 还是 60 分钟、五十音掌握情况、教材总课数；缺的逐个问，用户没答的写明用了哪个默认值，标 [待确认]。
2. **进度算式**：可用周数、每周课数和预计学完的日期（有考试日期时）。
3. **第一周五十音日程**：按用户的时间版本；已过关的改成小测。
4. **语法主线**：对照用户教材目录标出阶段 1–6。
5. **每日日程**：30 或 60 分钟版。
6. **四周复盘模板和调整规则**。
7. **卡点对策**（用户提到卡点时）：先让他做一次小测（如 20 个动词变形），按错误类型给练法，不推倒整个计划。
8. **待确认清单**：所有 [待补]、[待确认] 汇总在最后。

教材和工具只说类型（配音频的零基础教材、间隔复习卡片），不点名具体付费课程、App 或机构。词汇量、学习时长这类数字标明是估计，按四周复盘的实测数据修正。占位符：只有用户知道的（教材总课数、考试是哪一次）写 [待补]；按默认值排的写 [待确认：默认值]。

交付前自检（逐条答是/否）：

- [ ] 可用周数、每周课数写出了算式，数字与手算或脚本一致？
- [ ] 第一周日程和用户的时间版本（30/60 分钟）一致？
- [ ] 词汇量、时长等数字标了「估计」？
- [ ] 没有点名具体付费课程、App、机构？
- [ ] 没有承诺通过，没有预测考题，考试安排写了「以官方公告为准」？
- [ ] 默认值都标了 [待确认]，并列进最后的清单？

## 示例

以下为示例，数字取自上文小王的例子。

**用户**：零基础怎么学日语？每天只有 30 分钟，想明年考 N4。

**助手先问**：① 离你要考的那一次大约还有几周？② 用什么教材，目录里一共几课？③ 五十音会不会？

**用户**：大约 44 周；教材 48 课；五十音完全不会。

**助手交付**（节选；完整版见下方链接）：

```text
一、参数确认：目标 N4；离考试约 44 周；每天 30 分钟；五十音不会；教材 48 课
二、进度：可用周数 = 44 − 1（五十音）− 4（总复习）= 39 周；每周课数 = 48 ÷ 39 ≈ 1.2 课
三、第一周五十音（30 分钟版）

四、语法主线：阶段 1–6 [待补：请发教材目录，我把课号对上]
```

## 常见问题（FAQ）

**Q：每天只有 30 分钟，能考过 N4 吗？**
A：不做保证。先按「可用周数、每周课数」算来不来得及，四周复盘用实测数据再调；算不开就改考下一次，或把部分内容降为只求认得。

**Q：五十音要背多久才能往下学？**
A：达到过关标准就往下走：看到假名 1 秒内读出，听写正确率 90% 以上。计划按一周排，别拖一个月。

**Q：要不要报班、买课？推荐哪个？**
A：不推荐具体课程、机构或付费 App；一套配音频的零基础教材，加一种间隔复习的单词工具，就够起步。

**Q：N4、N3 要掌握多少词？**
A：官方不公布词汇表。常见的非官方估计是 N4 约 1500 词、300 个汉字，N3 约 3700 词、650 个汉字，只用来排计划。

**Q：每天的时间不固定怎么办？**
A：以 30 分钟版保底；有空的日子只加听力和复习，不加新课。

**Q：学到一半跟不上进度了？**
A：不推倒重来。按四周复盘的规则调；有考试日期的，用「剩余课数 ÷ 每周实际课数」算还要几周，来不及就把阶段 6 的部分内容降为只求认得。

**Q：不考试，只想看动画或去旅游，也能用吗？**
A：能。复盘时把「模拟题」换成你的目标材料，比如动画片段、旅游会话，其余流程不变。

**Q：考试日期和报名怎么查？**
A：以 JLPT 官方公告为准，本技能不提供具体日期。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 五十音拖一个月，总想「再熟一点」 | 整个计划被拖慢；生字会在课文里反复遇到，本来就会越用越熟 | 达到过关标准就往下走 |
| 只看不听 | 听力要靠每天积累，JLPT 各部分还有最低分要求（以官方公告为准），留到最后补来不及 | 从第二周起每天都有听力 |
| 单词只背释义不带例句 | 会认不会用，也更容易忘 | 每个词记读音、汉字、意思和一个例句 |
| 变形靠考场现推 | 平时没练到 2 秒以内，考场上来不及 | 每天抽 20 张变形卡计时 |
| 频繁换教材 | 每换一次都从第一课重来 | 一套教材跟到底，别的材料只用来补听力和阅读 |
| 卡住就推倒整个计划 | 前面的进度白费，也找不到真正的问题 | 先做小测，按错误类型给练法 |
| 只排计划不复盘 | 进度落后要到考前才发现 | 每四周按模板测一次，用实测数据调 |

## 边界与不做什么

- 不推荐具体付费课程、培训机构或付费App；不代写作业，不代考。
- 不承诺通过JLPT，不预测考题；考试日期、报名、成绩和证书以官方公告为准。
- 留学、签证、求职对日语水平的要求，以学校、使领馆或用人单位的官方说明为准。
- 需要正式翻译件，或法律、医疗场景的日语文件，请找专业译者。
- 长期分不清某些音、口语不敢开口，最好请老师或母语者当面纠正；这里只给练习方法。
