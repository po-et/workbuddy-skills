# 小数显示复跑案例

以下全部为合成数字，仅验证 `car_cost.py` 的金额和公式显示，不代表实际车型、商家、贷款产品或独立用户案例。从本技能目录运行，需要 Python 3，无第三方依赖。

## 一分钱不能显示成零

```bash
python3 scripts/car_cost.py --loan-principal 100000 --loan-total 100000.01 --loan-fees 0
```

应显示总还款额 `100,000.01`、已知还款差额 `0.01`、录入范围费用合计 `0.01`。去掉 `--loan-fees 0` 再运行，应保留 `[待补：另收费用]（已知小计 0.01）`；未知费用不能补成零。

## 报价明细与合计都保留角分

```bash
python3 scripts/car_cost.py --price 150000.49 --tax 1000.49 --insurance 0 --plate 0 --addons 0
```

应显示裸车价 `150,000.49`、购置税 `1,000.49`、落地价合计 `151,000.98`。这组参数明确给出了所有五项，不能把明细取整为 `150,000` 和 `1,000`，再把总额显示成 `151,001`。

## 年度估算与显示公式使用同一占比

```bash
python3 scripts/car_cost.py --km 15000 --consumption 15 --home-price 0.6 --fast-price 1.5 --home-share 80.5%
```

应显示能耗金额 `1,744.875`；公式写家充 `80.5%`、快充 `19.5%`。保险等未提供项仍待补，因此年度总额只是已知金额起算，不能称作完整养车成本。

0.1.3 只移除了显示阶段的整元/整百分比舍入，未改变原有计算流程。整数仍按千位分隔，小数只省略末尾的零。计算沿用 64 位有效数字的 Decimal 上下文，极端大数连乘仍可能在计算阶段舍入；上述显示规则不承诺所有允许输入的连乘结果均无限精确。年度金额始终是按参数估算，未验证真实账单或政策金额。
