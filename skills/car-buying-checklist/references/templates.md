## 需求卡

```
需求卡（[日期]）
城市与牌照：[城市]；限购情况 [待确认：以当地政策为准]
用途排序：1 [通勤，约 N 天/年]  2 [接送孩子]  3 [长途，约 N 次/年]
人数：平时 [N] 人，最多 [N] 人（最多那几次能否租车解决：[能/不能]）
年里程：每天 [N] 公里 × [N] 天 + 长途 [N] 公里 × [N] 次 ≈ [N] 公里
停车与充电：固定车位 [有/无]；能否装充电桩 [物业与电力条件：待确认]；单位充电 [有/无]
驾驶者：[新手/老司机]，[N] 人开
三项硬条件：
  1 [如：后排装得下两个儿童座椅]
  2 [如：后备箱放得下推车]
  3 [如：落地价不超过 N 万]
可放弃：[如：7 座、越野能力、大尺寸屏幕]
```

## 询价话术

询价时先发这段消息给两三家店，拿到书面明细再去谈：

```
您好，我想买[车型、配置、颜色]，[全款／贷款]，[本月内]提车。
请发一份落地价明细：裸车价、购置税、保险（险种和保额）、上牌费用及其他所有费用逐项列出。
另请分别报价：不在店里买保险、不办贷款、不加装时，价格各是多少。
是现车还是要等？车辆出厂日期是哪个月？
```
