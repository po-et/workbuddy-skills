# 买车

定位一句话：**买车最贵的错误不是多花了几千块，而是买了一台不合自己用法的车——先把需求和总账算清楚，再进店。**
按四个步骤走：需求盘点 → 预算拆分 → 判断方向 → 进店核对；前三步在家做完再进店。

## 何时使用

在对话里直接说你的情况就行，不用记命令；算账脚本由助手在需要时运行。典型说法：

- 「第一次买车，预算 15 万左右，该怎么选方向」
- 「买车预算怎么算，落地价要准备多少」
- 「电车还是油车？小区没有固定车位」
- 「下周提车，交车时要检查什么」
- 「销售说今天不定这个价就没了，怎么办」
- 「帮我看看这张报价单有没有坑」

适用：第一次买车不知道从哪下手；在新车、二手车、新能源之间犹豫；要算落地价和每年的养车钱；准备试驾、签合同或提车时。

不适用（遇到时这样处理）：

- 「推荐一款车 / 哪家店便宜」→ 不推荐车型、品牌、经销商和二手车平台；可以按用户的需求卡把他选中的两台车逐项列对比表，由他拍板。
- 「全款还是贷款划算、这车能保值多少」→ 不做投资理财建议；只用脚本把两种方案的总账算清楚。
- 「定金能不能退、合同条款有没有效、能赔多少」→ 不做法律定性；请找律师或当地消费者协会，可以拨打 12315 投诉。

## 第一步：需求盘点（进店之前做完）

```
用途    通勤、接送孩子、跑长途、拉货、自驾游，按一年里各占多少天排序；别为一年一次的场景买单
人数    平时坐几人、一年里最多坐几人；最多的那几次能不能租车或打车解决
里程    单程几公里、堵不堵；每天里程 × 用车天数 ≈ 年里程，后面算油电费要用
停车    有没有固定车位；能不能装充电桩（物业与电力条件先问清）；单位附近停车贵不贵
牌照    所在城市限不限购，能拿到哪种牌照、要等多久，以当地政策为准
驾驶者  新手还是老司机、家里几个人开；新手优先看车身尺寸、视野和倒车辅助
安全    看公开的碰撞测试成绩和主动安全配置，以测试机构公布的报告为准，不以销售口述为准
硬条件  写下必须满足的三项（如后排装得下两个儿童座椅、后备箱放得下推车），其余都算「有更好」
```

需求卡的填写模板见 [references/templates.md](references/templates.md)。

## 第二步：预算拆分——落地价与每年的养车钱

```
落地价 = 裸车价 + 购置税 + 首年保险 + 上牌等费用 + 你主动要的加装
  购置税  燃油车一般为不含增值税车价的 10%，约等于 发票价 ÷ 1.13 × 10%；
          新能源车有减免政策，额度与年份以当年政策为准
  保险    交强险必须买；商业险常见的有车损险、第三者责任险、车上人员责任险，
          保额与附加险按需选；拿两三家报价，比保额和免赔条款，不只比总价
  上牌    自己办还是代办，代办收多少、包含什么，写清楚
每年养车钱 = 保险 + 能耗 + 保养维修 + 停车 + 过路费、年检等杂项
  能耗    年里程 ÷ 100 × 百公里油耗或电耗 × 当地单价；电车按家里慢充、外面快充两种单价分开算
  保养    按保养手册的周期和项目，问清每次大约多少钱
  折旧    不花现金，卖车时才体现；打算几年就换车的人要一起算
```

贷款的话，让销售写出总还款额：总还款额 − 贷款本金 = 这笔贷款的真实成本，手续费、服务费都算进去。全款还是贷款属于你自己的资金安排，这里只负责把两种方案的总账算清楚。

```
算法演示（数字只为演示公式，不代表任何车型、地区的实际价格）
购置税  发票价 150,000 元 → 150,000 ÷ 1.13 × 10% ≈ 13,274 元
油车    年里程 15,000 公里，油耗 7 升／百公里，油价 8 元 → 15,000 ÷ 100 × 7 × 8 = 8,400 元／年
电车    同样里程，电耗 15 度／百公里：家充 0.6 元 → 1,350 元／年；全靠快充 1.5 元 → 3,375 元／年
结论    在这组演示数字里，家充与全靠快充每年差两千多元，这就是下面判断题 Q1 排第一的原因
```

替用户算账时用脚本，别心算。它输出一张带计算式的预算表，没给的项目写 [待补]，政策口径拿不准的写 [待确认]；金额可写 150000、15万、1.5w（python3 标准库，不联网）：

```bash
python3 scripts/car_cost.py 150000 15000 7 8                     # 旧写法：发票价 年里程 百公里油耗 油价
python3 scripts/car_cost.py --price 15万 --insurance 5000 --plate 500 --km 15000 --consumption 7 --unit-price 8 --out 预算表.md
python3 scripts/car_cost.py --price 15万 --ev --km 15000 --consumption 15 --home-price 0.6 --fast-price 1.5 --home-share 80%
python3 scripts/car_cost.py --loan-principal 10万 --loan-total 11.2万 --loan-fees 3000   # 贷款真实成本
```

询价时先把书面明细要到手：发给两三家店的询价话术见 [references/templates.md](references/templates.md)。

## 第三步：新车、二手车、新能源——几道判断题

```
燃油／油电混动，还是新能源（纯电、插混、增程）
Q1 家里或单位能稳定充电吗？    能 → 电车省钱的优势才兑现；不能 → 纯电要慎重
Q2 日常里程与长途频率？        短途为主、长途少 → 纯电合适；常跑长途且沿途充电不便 → 插混、增程或燃油
Q3 冬天冷不冷？                寒冷地区纯电续航会明显缩水，按冬季续航估算够不够用
Q4 当地牌照政策？              限购城市新能源牌照可能更好拿；哪些车能上新能源牌以当地认定为准
Q5 打算开几年？                几年就换的，把折旧算进总账，别只看油电费

新车还是二手车
Q1 预算和想要的配置差多少？    差得多 → 二手值得看；差得少 → 新车省心
Q2 你或身边有人会看车况吗？    不会 → 二手车一定花钱做第三方检测
Q3 打算开很多年？              是 → 新车的质保和确定的车况更值钱
Q4 离不开质保？                选还在原厂质保期内的车，并核实质保能否随车转给你
```

二手车另外必查：维修保养记录、出险记录、过户次数、有没有抵押或查封（到车管所或官方渠道核实），电车要看电池健康报告；把「非事故、非泡水、非火烧、里程未调」写进合同，并写明查出来怎么退赔。

## 第四步：进店核对与防套路

三张核对表的全文见 [references/checklists.md](references/checklists.md)，按用户所处的阶段给对应那张：

- **看车试驾**：同一天、同一路线至少比两台；驾驶姿势、后排真坐人、后备箱放进常带的东西、起步刹车、胎噪风噪、倒车入库；试驾完当场记三句——最喜欢的一点、最不能忍的一点、回家要核实的一点。
- **签合同前**：车型配置写全；价格拆开写；口头承诺写进合同；「定金」还是「订金」逐字写明；交车日期与逾期处理；贷款写明总还款额；删掉不想要的捆绑项。
- **提车当天**：约白天；证件、出厂日期、里程、外观、功能、随车物品逐项看，有问题先拍照写进交车单，处理完再签字。

最常见的销售套路是只报首付和月供、「今天不定这个价就没了」、不在店里买保险或贷款就不给优惠、各种说不清的服务费；十一种套路与应对办法见 [references/sales-tricks.md](references/sales-tricks.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息 | 一次最多问 3 个，先问城市、预算上限、通勤里程与停车充电；人数、车身类型等先按用户说过的推断，标 [待确认] | 「先问三件：在哪个城市？预算上限多少，含不含税费保险？每天通勤多少公里、有没有固定车位能装充电桩？」 |
| 输入格式不对或说得含糊（「十来万」「15 个 w」） | 按常见写法理解并复述；含糊的给两档各算一遍；脚本认 15万、15w、150,000，中文数字要改成阿拉伯数字 | 「"十来万"我先按 10 万和 13 万两档各算一遍，你看哪档更接近。」 |
| 需求自相矛盾（预算 10 万却要 7 座加高配；没车位却要纯电且常跑长途） | 指出哪两条冲突，给两种取舍方案 | 「预算 10 万和"7 座＋高配"很难同时满足：要么保 7 座放宽配置，要么保配置去看二手。你更在意哪个？」 |
| 数值看起来异常（发票价 15 元、油价 800 元） | 脚本退出码 3 并列出「需要先确认」；问清再重算，不擅自改数 | 「发票价只有 15 元，是不是少写了"万"？确认后我重算。」 |
| 超出本技能范围（推荐车型、投资判断、法律定性） | 不推荐、不下结论；列对比表，或建议找律师、消费者协会、12315 | 「具体哪款我不推荐，但可以按你的需求卡把这两台车逐项列对比表，你来拍板。」 |
| 时间紧，只要最小可用版 | 最小版三样：三项硬条件、一条脚本命令算出的落地价估算、当下要用的那一张核对表；其余标 [待补] 回头补 | 「最小版：三项硬条件＋落地价估算＋提车核对表，其余回头补。」 |
| 用户坚持越界（替我砍价、替我签字付款、保证不被坑） | 守住：不代砍价、签字、付款，也不做保证；给话术和核对表 | 「砍价和签字要你本人来。询价话术和签约核对表给你，谈的时候照着逐项问。」 |

|---|---|---|

## 输出契约

先问：所在城市、预算上限、主要用途与人数、每天通勤里程、停车与充电条件、倾向的车身类型（轿车、SUV、MPV）；缺哪项问哪项，一次不超过三个问题。交付物按这个顺序：

1. **需求卡**：三项硬条件与可放弃项。
2. **预算表**：落地价明细和每年养车钱，写出计算式，金额由用户按当地报价填（用脚本生成）。
3. **方向结论**：新车或二手，燃油、混动或纯电，附每道判断题的回答。
4. **进店用的核对表**：按所处阶段给试驾、签约或提车那张，其余给链接。
5. **报价单疑点**：用户给了报价单就逐项列；没有写「无」。
6. **待确认清单**：所有 [待补]、[待确认] 汇总在最后。

所有价格、税费、补贴都以当地实际和现行政策为准。用户拿两台具体的车来问时，只按他的需求卡逐项列对比表，参数以官方配置表为准，不替他拍板。

占位符规则：`[待补：当地保险报价]` 用于只有用户能拿到的数字，不编；`[待确认：新能源减免以当年政策为准]` 用于政策口径或我按默认先填的内容。

交付前自检（逐条答是/否，有「否」先改再交）：

- [ ] 需求卡里有且只有三项硬条件？
- [ ] 预算表每一项都有计算式，或标了 [待补]，没有凭空写的价格？
- [ ] 方向结论逐条对应了判断题的回答？
- [ ] 没有推荐具体车型、品牌、经销商和金融产品？
- [ ] 税费、补贴、牌照都注明以当地现行政策为准？
- [ ] 涉及贷款时算出了总还款额和真实成本，但没替用户决定全款还是贷款？

## 示例

**示例（虚构场景，单价为演示数字）**：用户说「小区没有固定车位，还适合买电车吗」。

助手先问（一次三个）：① 单位或住处附近能不能稳定充电？② 每天开多少公里、多久跑一次长途？③ 在哪个城市，冬天冷不冷？

用户补充：「单位没有充电桩，小区附近有公共快充站；每天通勤往返 30 公里，每月回老家一趟，往返 600 公里；北方，冬天挺冷。」

助手用脚本算两笔能耗账（年里程 30 × 250 天 + 600 × 12 = 14,700 ≈ 15,000 公里）：

```bash
python3 scripts/car_cost.py --km 15000 --consumption 15 --home-price 0.6 --fast-price 1.5 --home-share 0   # 全靠快充
python3 scripts/car_cost.py --km 15000 --consumption 7 --unit-price 8                                     # 同里程的油车
```

最终交付：

```text
方向结论：纯电要慎重。先确认两件事再考虑：① 附近快充站去一趟要多久、平时要不要等位；
② 冬季续航够不够一趟跑完单程 300 公里的回乡路。两件都没把握，就看插混、增程或油电混动。

判断题回答：
Q1 能稳定充电吗？    不能：无固定车位、单位无桩，只能靠公共快充 → 电车省钱的优势打折扣
Q2 日常里程与长途？  短途为主，但每月一次长途 → 长途依赖沿途充电
Q3 冬天冷不冷？      冷 → 纯电冬季续航明显缩水，按冬季续航估算
Q4 当地牌照政策？    [待确认]：限购城市新能源牌照可能更好拿，以当地认定为准
Q5 打算开几年？      [待补]：几年就换的，把折旧算进总账

能耗账（演示单价，按当地实际替换）：
全靠快充：15,000 ÷ 100 × 15 × 1.5 = 3,375 元/年（能家充时约 1,350 元/年）
同里程油车：15,000 ÷ 100 × 7 × 8 = 8,400 元/年
→ 按演示数字，全靠快充仍比油车省；没车位的主要代价是时间、便利和冬季续航，不只是钱。

下一步：去最近的快充站实地看一次（距离、车位、等位情况）；想看插混或增程的，把能耗账按「能充就充」再算一遍。

待确认清单：Q4 牌照政策、Q5 打算开几年、当地实际电价与油价。
```

更多示例：[examples/first-car-15w.md](examples/first-car-15w.md)（第一次买车、预算 15 万：需求卡、预算表、方向结论全套交付）、[examples/delivery-day.md](examples/delivery-day.md)（下周提车：按提车当天的顺序逐项检查，签字前看什么）。

## 常见问题（FAQ）

**Q：落地价到底包括什么？**
A：裸车价 + 购置税 + 首年保险 + 上牌等费用 + 你主动要的加装。让店里逐项列书面明细，再用脚本核一遍。

**Q：全款还是贷款划算？**
A：这是你自己的资金安排，这里不下结论。让销售写出总还款额，用脚本算出真实成本（总还款额 − 本金 + 另收费用），两种方案并排比。

**Q：能直接推荐一款车吗？**
A：不推荐具体车型和品牌。你把选中的两台车发来，我按你的需求卡逐项列对比表，参数以官方配置表为准。

**Q：定金和订金有什么不一样？**
A：两者退还规则不同。合同里逐字写明交的是哪一种、不能按期交车怎么退怎么赔；拿不准就问律师或消费者协会。

**Q：销售说今天不定，这个价就没了？**
A：回家算完账再定，真优惠明天也在；请对方把价格和有效期写进书面报价。

**Q：新能源车的购置税怎么算？**
A：有减免政策，额度与年份以当年政策为准。脚本加 --ev 会把这一项标成 [待确认]，同时给出不减免时的燃油车口径作参考。

**Q：二手车最少要查什么？**
A：维修保养记录、出险记录、过户次数、抵押或查封（到车管所或官方渠道核实），电车看电池健康报告；花钱做第三方检测，把「非事故、非泡水、非火烧、里程未调」写进合同。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 只看首付和月供 | 看不出总共多花多少 | 要落地价明细和总还款额，用脚本算真实成本 |
| 为一年一次的场景买大车 | 其余时间都在为它多付油费，停车也更难 | 按一年里各场景占多少天排序，偶尔的场景租车解决 |
| 没有稳定充电条件就直接定纯电 | 省钱优势打折扣，还要专门跑快充站 | 先答判断题 Q1–Q3 再定方向 |
| 心算税费和油电费 | 容易算错，还会被报价单带偏 | 用脚本算，并写出计算式 |
| 口头承诺不写进合同 | 没写进合同就等于没有 | 赠品、保养、价格保护全部写进合同或附件 |
| 晚上交车、被催着签字 | 光线差看不清漆面，匆忙中漏检 | 约白天，按提车核对表验完再签 |
| 二手车只听「准新车」「一手车主」 | 话术不是证据 | 以检测报告和记录为准 |
| 保险、贷款、加装在店里一次打包决定 | 捆在一起看不出每项的价格 | 逐项单独报价，单独决定要不要 |
| 替用户拍板某款车 | 越界，而且不掌握用户的全部情况 | 只按需求卡列对比表，由用户决定 |

## 边界与不做什么

- 不推荐具体车型、品牌、经销商、二手车平台或金融产品。
- 不做投资理财建议：全款还是贷款、车能保值多少，不下结论，只把各方案的总账算清楚。
- 不做法律定性：合同条款是否有效、定金订金怎么退、能赔多少，找律师或当地消费者协会；可以拨打 12315 投诉。
- 二手车车况以专业检测机构的报告为准；本页的检查只帮你发现疑点，替代不了上举升机的检测。
- 税费、补贴、牌照、保险费率年年会变，以当地现行规定和正式报价为准。
- 不代你砍价、签字或付款。
