# 买车

定位一句话：**买车最贵的错误不是多花了几千块，而是买了一台不合自己用法的车——先把需求和总账算清楚，再进店。**
何时用：第一次买车不知道从哪下手；在新车、二手车、新能源之间犹豫；要算落地价和每年的养车钱；准备试驾、签合同或提车时。
按四个步骤走：需求盘点 → 预算拆分 → 判断方向 → 进店核对；前三步在家做完再进店。

## 第一步：需求盘点（进店之前做完）

```
用途    通勤、接送孩子、跑长途、拉货、自驾游，按一年里各占多少天排序；别为一年一次的场景买单
人数    平时坐几人、一年里最多坐几人；最多的那几次能不能租车或打车解决
里程    单程几公里、堵不堵；每天里程 × 用车天数 ≈ 年里程，后面算油电费要用
停车    有没有固定车位；能不能装充电桩（物业与电力条件先问清）；单位附近停车贵不贵
牌照    所在城市限不限购，能拿到哪种牌照、要等多久，以当地政策为准
驾驶者  新手还是老司机、家里几个人开；新手优先看车身尺寸、视野和倒车辅助
安全    看公开的碰撞测试成绩和主动安全配置，以测试机构公布的报告为准，不以销售口述为准
硬条件  写下必须满足的三项（如后排装得下两个儿童座椅、后备箱放得下推车），其余都算「有更好」
```

## 第二步：预算拆分——落地价与每年的养车钱

```
落地价 = 裸车价 + 购置税 + 首年保险 + 上牌等费用 + 你主动要的加装
  购置税  燃油车一般为不含增值税车价的 10%，约等于 发票价 ÷ 1.13 × 10%；
          新能源车有减免政策，额度与年份以当年政策为准
  保险    交强险必须买；商业险常见的有车损险、第三者责任险、车上人员责任险，
          保额与附加险按需选；拿两三家报价，比保额和免赔条款，不只比总价
  上牌    自己办还是代办，代办收多少、包含什么，写清楚
每年养车钱 = 保险 + 能耗 + 保养维修 + 停车 + 过路费、年检等杂项
  能耗    年里程 ÷ 100 × 百公里油耗或电耗 × 当地单价；电车按家里慢充、外面快充两种单价分开算
  保养    按保养手册的周期和项目，问清每次大约多少钱
  折旧    不花现金，卖车时才体现；打算几年就换车的人要一起算
```

贷款的话，让销售写出总还款额：总还款额 − 贷款本金 = 这笔贷款的真实成本，手续费、服务费都算进去。全款还是贷款属于你自己的资金安排，这里只负责把两种方案的总账算清楚。

```
算法演示（数字只为演示公式，不代表任何车型、地区的实际价格）
购置税  发票价 150,000 元 → 150,000 ÷ 1.13 × 10% ≈ 13,274 元
油车    年里程 15,000 公里，油耗 7 升／百公里，油价 8 元 → 15,000 ÷ 100 × 7 × 8 = 8,400 元／年
电车    同样里程，电耗 15 度／百公里：家充 0.6 元 → 1,350 元／年；全靠快充 1.5 元 → 3,375 元／年
结论    在这组演示数字里，家充与全靠快充每年差两千多元，这就是下面判断题 Q1 排第一的原因
```

替用户算账时用这条命令，别心算；参数依次是发票价、年里程、百公里油耗或电耗、单价：

```bash
python3 -c "import sys;p,km,c,u=map(float,sys.argv[1:]);print('购置税约 %.0f 元（燃油车口径）；年能耗约 %.0f 元' % (p/1.13*0.1, km/100*c*u))" 150000 15000 7 8
```

询价时先发这段消息给两三家店，拿到书面明细再去谈：

```
您好，我想买[车型、配置、颜色]，[全款／贷款]，[本月内]提车。
请发一份落地价明细：裸车价、购置税、保险（险种和保额）、上牌费用及其他所有费用逐项列出。
另请分别报价：不在店里买保险、不办贷款、不加装时，价格各是多少。
是现车还是要等？车辆出厂日期是哪个月？
```

## 第三步：新车、二手车、新能源——几道判断题

```
燃油／油电混动，还是新能源（纯电、插混、增程）
Q1 家里或单位能稳定充电吗？    能 → 电车省钱的优势才兑现；不能 → 纯电要慎重
Q2 日常里程与长途频率？        短途为主、长途少 → 纯电合适；常跑长途且沿途充电不便 → 插混、增程或燃油
Q3 冬天冷不冷？                寒冷地区纯电续航会明显缩水，按冬季续航估算够不够用
Q4 当地牌照政策？              限购城市新能源牌照可能更好拿；哪些车能上新能源牌以当地认定为准
Q5 打算开几年？                几年就换的，把折旧算进总账，别只看油电费

新车还是二手车
Q1 预算和想要的配置差多少？    差得多 → 二手值得看；差得少 → 新车省心
Q2 你或身边有人会看车况吗？    不会 → 二手车一定花钱做第三方检测
Q3 打算开很多年？              是 → 新车的质保和确定的车况更值钱
Q4 离不开质保？                选还在原厂质保期内的车，并核实质保能否随车转给你
```

二手车另外必查：维修保养记录、出险记录、过户次数、有没有抵押或查封（到车管所或官方渠道核实），电车要看电池健康报告；把「非事故、非泡水、非火烧、里程未调」写进合同，并写明查出来怎么退赔。

## 第四步：三张核对表——试驾、签约、提车

```
看车试驾（同一天、同一路线至少比两台）
[ ] 驾驶座调到你的姿势：头顶、膝盖、踏板；前方和两侧盲区大不大
[ ] 后排真坐人：腿部空间、中间座位、上下车；要装儿童座椅的看接口
[ ] 后备箱放进你常带的东西（推车、行李箱），别只看容积数字
[ ] 起步、低速跟车顺不顺，刹车脚感是否线性；过减速带和烂路有没有异响
[ ] 时速 60–100 公里的胎噪风噪：和后排说话要不要提高嗓门
[ ] 倒车入库、窄路掉头，影像雷达好不好用；辅助驾驶只在安全路段按说明体验
[ ] 二手车：约好冷车启动，看仪表故障灯、四条轮胎磨损是否均匀
试驾完当场记三句：最喜欢的一点、最不能忍的一点、回家要核实的一点
```

```
签合同前
[ ] 车型、配置、颜色、内饰写全；已分配车架号的写上
[ ] 价格拆开写：车价、各项费用、优惠形式；口头答应的赠品、保养全部写进合同或附件
[ ] 交的是「定金」还是「订金」、不能按期交车怎么退怎么赔，逐字写明；两者退还规则不同，拿不准问律师或消费者协会
[ ] 交车日期和逾期怎么处理
[ ] 贷款写明总还款额和每项费用名目；手续费、服务费要正规发票
[ ] 不想要的捆绑项（指定保险、精品包、延保）当场删掉
```

```
提车当天（约白天，签字前逐项看）
[ ] 证件：发票、合格证、三包凭证、保修手册、说明书；车架号与车身一致
[ ] 出厂日期：看合格证和车身铭牌，比预期早很多的，问清是不是库存车
[ ] 里程：与「刚运到店」相符，偏多的问原因并写进交车单
[ ] 外观：自然光下绕车看漆面、缝隙、玻璃、轮毂；胎侧四位数字是生产周和年份
[ ] 功能：灯光、雨刷、空调、车窗、座椅、中控、影像雷达逐项开一遍；电车当场试一次充电
[ ] 随车物品：钥匙数量、补胎工具或备胎、随车充电设备
[ ] 有问题先拍照、写进交车单，处理完再签字
```

## 最常见的套路

```
只报首付和月供                     → 要一张落地价和总还款额的明细
「今天不定，这个价就没了」          → 回家算完账再定，真优惠明天也在
不在店里买保险或贷款就不给优惠      → 请对方把优惠写成车价降价
金融服务费、出库费、PDI 费等名目    → 问清是什么服务、开不开发票，说不清的不付
口头送保养、送装潢、价格保护        → 没写进合同就等于没有
库存车、展车、试驾车当新车卖        → 查出厂日期和里程，写进合同
加价提车                           → 加价进不进发票；另收的钱要书面凭证
置换补贴高、旧车估价低              → 旧车单独找两家估价，比「新车优惠 + 旧车价」的总和
延保、贴膜、装潢打包进贷款          → 逐项单独报价，单独决定要不要
晚上交车、催着签字                  → 约白天，验完再签
二手车「准新车」「一手车主」        → 以检测报告和记录为准，不以话术为准
```

## 输出契约

1. 先问：所在城市、预算上限、主要用途与人数、每天通勤里程、停车与充电条件、倾向的车身类型（轿车、SUV、MPV）；缺哪项问哪项，一次不超过三个问题。
2. 交付：需求卡（三项硬条件与可放弃项）；预算表（落地价明细和每年养车钱，写出计算式，金额由用户按当地报价填）；方向结论（新车或二手，燃油、混动或纯电，附每道判断题的回答）；进店用的三张核对表；用户手上报价单的逐项疑点。
3. 所有价格、税费、补贴都以当地实际和现行政策为准。
4. 用户拿两台具体的车来问时，只按他的需求卡逐项列对比表，参数以官方配置表为准，不替他拍板。

## 边界与不做什么

- 不推荐具体车型、品牌、经销商、二手车平台或金融产品。
- 不做投资理财建议：全款还是贷款、车能保值多少，不下结论，只把各方案的总账算清楚。
- 不做法律定性：合同条款是否有效、定金订金怎么退、能赔多少，找律师或当地消费者协会；可以拨打 12315 投诉。
- 二手车车况以专业检测机构的报告为准；本页的检查只帮你发现疑点，替代不了上举升机的检测。
- 税费、补贴、牌照、保险费率年年会变，以当地现行规定和正式报价为准。
- 不代你砍价、签字或付款。
