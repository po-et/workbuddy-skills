# 礼物清单

定位一句话：**好礼物不靠贵，靠让对方觉得「你注意到了我」，而且收下没有负担。**

## 何时使用

在对话里直接说送给谁、什么场合、多少预算就行，不用记命令；多人清单的预算核对脚本由助手在需要时运行，也可以单独在命令行调用。典型说法：

- 「不知道送什么，下周是我妈生日」
- 「春节要给父母、岳父母和两个同事准备礼物，总预算三千」
- 「教师节想给孩子的班主任送点东西，合适吗」
- 「年底给客户寄节礼，公司规定每份不超过 200 元」
- 「同事要离职了，大家凑份子送点什么」
- 「礼物选好了，卡片上写什么」

适用：不知道给父母、伴侣、孩子、同事、老师或客户送什么；一次要给好几个人准备礼物、要控制总预算；拿不准对方能不能收、卡片上写什么时。本页只给判断方法和品类方向，不推荐品牌、店铺或平台。

不适用（遇到时这样处理）：

- 「直接推荐个商品 / 给个购买链接 / 哪家便宜」→ 不推荐品牌、店铺、平台，不比价；给品类方向和挑选标准。
- 「这份礼算不算违规」→ 不判断是否违规违法；以本公司合规部门和对方单位的规定为准，必要时咨询律师。
- 想用礼物修复关系、代替道歉 → 礼物修不好关系，要靠当面沟通；可以帮写一张道歉卡片，需要时找专业的咨询师。

## 先判断四件事

第 1 步，问清四件事，缺哪项问哪项：

```
对象   是谁、多亲近；是不是上下级、老师、客户这类有收礼规定的关系
场合   生日、节日、感谢、道歉、探望、回礼（道歉礼宜轻，感谢礼要具体）
预算   这一份多少钱；多人时的总预算
限制   忌口（清真、素食、过敏、控糖）、信仰、健康状况、住处大小、近期是否搬家或出国
```

第 2 步，先过红灯：对象是老师、客户、公职人员或直属上级，先看下面「避雷」一节，确认能送再往下选。

第 3 步，按预算档位决定钱花在哪。档位按人民币举例，只用来划分思路：

```
≤100 元       买心意：手写卡、亲手做的、对方常用消耗品的「好一点」版本
100–300 元    买升级：把对方天天在用、已经凑合的东西换好一档
300–1000 元   买体验或长期用品：一起去的活动、能用很多年的物件
1000 元以上   只给最亲近的人；先确认对方收得安心，不会有回礼压力
```

对象和档位的常见搭配：

```
父母         100–1000 元：按家里的消费习惯，别让老人「心疼钱」反而不用
伴侣         按你们平时的消费水平，不借钱、不分期去送礼
别人家孩子   300 元以内：不超过对方父母方便回礼的水平
同事         100 元以内：全组统一，可分享
老师         0 元：只送心意，不送有价物品
客户         本公司政策的上限以内，同一批客户统一标准
```

## 判断题：六类对象

每类三四道判断题，按答案走向礼物方向；完整题目见 [references/six-recipients.md](references/six-recipients.md)。每类先问的那一题：

| 对象 | 先问的一题 | 常见方向（只到品类） |
|---|---|---|
| 父母 | 最近抱怨过哪件事不方便吗？ | 解决不便的日用品，当场装好、教会；舍不得用的，送消耗品、服务或一起去的体验 |
| 伴侣 | 最近三个月，TA 说过「想要但舍不得买」的东西吗？ | 就送它；或给你们一起做的事升级装备、安排一次体验 |
| 孩子 | 包装上的适用年龄看过吗？孩子的父母同意吗？ | 顺着兴趣选书、拼搭、画材、户外用品；3 岁以下避开小零件 |
| 同事 | 全组统一，还是个人心意？ | 小额、可分享的：零食、茶、小盆绿植；上下级用集体名义 |
| 老师 | 学校有没有「教师不收礼」的规定？ | 孩子的手写卡片或画，加一封家长写的感谢信 |
| 客户 | 本公司的礼品政策查了吗？对方是公职人员或有采购决定权吗？ | 统一标准的节礼（本地特产或实用品），寄到办公地址、走流程留记录；敏感期暂缓 |

六类答完还是没头绪，按三步找：一翻聊天记录，搜「想要」「坏了」「好想去」这类词；二问对方身边的人，只问「TA 最近在忙什么、缺什么」；三把选择权交出去，亲近的人可以约好一起去挑，别让惊喜变成负担。

送的方式也算礼物的一部分：父母和长辈当面给，顺手装好、教会；同事的放在桌上附一张卡，不在群里晒价格；客户的寄到办公地址，附公司署名的卡片。

## 卡片文案与预算表

卡片公式：**称呼 + 一件具体的事 + 这份礼物和那件事的关系 + 一句祝愿或约定 + 署名**，80 字以内，不提价格。写不出那件具体的事，就问自己三个问题：你们最近一次一起做的事是什么？TA 最近做了什么让你感激？你希望 TA 在什么时候用上这份礼物？父母、伴侣、孩子、同事、老师、客户、道歉七种场景的卡片样例见 [references/card-templates.md](references/card-templates.md)。

多人送礼先列表，再按总预算分配：

```
对象,关系,场合,档位,方向（品类）,限制与备注,预算,状态
妈妈,父母,春节,300–1000,一起出游一天,晕车,800,已订
李老师,老师,教师节,0,手写卡+感谢信,学校规定不收礼,0,已写
小王,同事,生日,≤100,可分享的零食,控糖,60,待买
```

存成 礼物清单.csv 后用脚本核对（python3 标准库，只读不改）。它算合计；超预算时按金额从高到低列出先减哪几项（已下单、已写好的不动）；顺带查出老师档位不是 0、同事超过 100 元、客户没写政策上限、职场送现金等价物、同一群人差距太大这些要改的行：

```bash
python3 scripts/gift_budget.py 礼物清单.csv 3000
python3 scripts/gift_budget.py 礼物清单.csv 3千 --json
```

这张表留着就是送礼记录，明年回礼、避免重复都用得上。

## 避雷：价值观冒犯与职场合规

价值观与冒犯：

| 别送 / 别做 | 为什么 | 换成 |
|---|---|---|
| 没被要求时送减肥产品、抗衰老护肤品、「情商」「口才」类的书 | 暗示对方有缺点 | 顺着对方已有的爱好，或把在用的东西升级 |
| 给清真饮食的人送含猪肉成分的食品，给不喝酒的人送酒，给素食者送肉类礼盒 | 碰到饮食与信仰禁忌 | 送吃的先看配料表；拿不准就送非食品 |
| 钟（送终）、伞（散）、梨（离）；探病送白色的花和菊花 | 中文语境里常见的讲究，各地讲究不同 | 拿不准就避开 |
| 政治、宗教、带性暗示的物品和玩笑礼物 | 职场里容易冒犯人 | 职场一律不送，选中性、实用、可分享的 |
| 给异性同事和客户送贴身衣物、香水 | 太私人，容易引起误会 | 换成可分享的零食、茶、绿植 |
| 活的宠物、大型绿植 | 给对方添长期负担 | 先问再送 |

职场合规：

| 别送 / 别做 | 为什么 | 换成 |
|---|---|---|
| 通不过**公开测试**的礼物：不能当着全组、当着对方领导的面拆开 | 见不得光的礼物本身就是风险 | 换成能公开拆开的 |
| 现金、购物卡、储值卡这类现金等价物 | 职场合规风险最高的一类 | 不送；换成统一标准的实物节礼或书面致谢 |
| 超过本公司和对方单位规定的金额；该审批登记却没走流程 | 违反双方的规定 | 金额以规定为准，先走流程 |
| 单独给直属上级送贵重礼物 | 让上级为难，也容易被误解 | 用集体名义、公开、低价 |
| 商务礼品私下送、不留记录 | 事后说不清 | 公开寄到办公地点，留好记录 |

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息（对象、场合、预算、限制） | 一次最多问 3 个，优先：送给谁、什么关系；预算多少；有没有忌口或要避开的。场合没说就按「日常感谢」处理，标 [待确认] | 「先问三件：送给谁、你们什么关系？每份预算大概多少？对方有没有忌口、信仰或健康上要避开的？」 |
| 用户跳过问题、不愿多说 | 降级：先给三个不容易出错的方向——对方常用消耗品的好一点版本、可分享的食品（先看配料表）、手写卡，都标 [待确认]；说明补哪条信息能更准 | 「先给三个不容易出错的方向，都标了 [待确认]；告诉我对方最近在忙什么，我能收窄到一个。」 |
| 输入自相矛盾（总预算 1000 却要 6 人每人 300；说对方不喝酒又想送酒） | 指出哪里矛盾，给两种方案 | 「6 人 × 300 = 1800，比总预算多 800。二选一：每人降到 160 左右；或者最亲近的 3 人按 300 送，其余人送手写卡。」 |
| 合计超出总预算 | 脚本退出码 3，按金额从高到低列可减项；超预算的清单不交付，先减到预算内 | 「合计超了 N 元。先从还没下单、金额最高的两项减：降一档，或换成体验、手写卡。」 |
| 对象有收礼规定（老师、客户、公职人员、直属上级） | 先给结论：可以送 / 建议不送实物 / 先问规定，再给方向 | 「先说结论：给班主任只送心意，不送有价物品；最稳的是孩子的手写卡加一封家长感谢信。」 |
| 超出本技能范围（推荐品牌链接、判断违规、保健品药品、用礼物修复关系） | 说明不做什么、该找谁，能做的部分照做 | 「算不算违规，以你们公司合规部门和对方单位的规定为准；我能帮你把公开测试和金额上限对一遍。」 |
| 时间紧，只要最小可用版 | 最小版：每人一个方向（品类＋一句理由）＋一句卡片；多人时附合计与是否超预算 | 「最小版：每人一个方向加一句卡片，合计 N 元，没超预算。」 |
| 用户坚持越界（给客户送购物卡、给老师塞红包、要具体商品链接） | 守住边界，给替代 | 「购物卡属于现金等价物，职场不送；可以换成统一标准的本地特产，寄到对方办公地址、走公司流程。」 |

**脚本退出码与报错**

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 合计没超总预算，也没有要改的行 | 可以定稿 |
| 3 | 超预算，或有要改、要确认的行（老师档位不是 0、同事超 100 元、客户没写政策上限、现金等价物、同一群人差距太大、预算不是数字） | 按输出逐条改；超预算先减列出的那几项，改完再跑 |
| 1（参数错误 / 清单有问题） | 总预算看不懂；表头缺「对象」或「预算」列；CSV 引号逗号不配对；没有数据行 | 第一行用标准表头；总预算写 3000、3千 或 0.3万 |
| 2（读取失败） | 文件不存在、没权限、编码认不出 | 检查路径；Excel 里「另存为 CSV UTF-8」 |
| 130 | 按了 Ctrl+C | 重跑；脚本只读，不会改动清单 |
| python3 用不了 | 本机没有 Python 3 | 手工把「预算」列相加，与总预算比；逐行对照避雷表 |

## 输出契约

先问后给：四件事缺哪项问哪项，一次最多问三个问题。交付物按这个顺序：

1. **有收礼规定的对象先给结论**：可以送、建议不送实物，还是先问规定，然后再给方向。
2. **每人两到三个方向**：品类加理由，对应到判断题的答案；不给品牌、店铺、平台和链接。
3. **每份礼物一段卡片草稿**：80 字以内，里面有一件具体的事。
4. **多人给预算表**：合计不超过总预算（跑过脚本），超了指出从哪一项减。
5. **送的方式**一句，加**待确认清单**。

占位符规则：`[待补：对方最近提过想要的东西]` 用于只有用户知道的事实，卡片里缺具体的事也用它，不编；`[待确认：学校是否有不收礼的规定]` 用于需要用户核实的规定或我按默认先给的方向。

交付前自检（逐条答是/否，有「否」先改再交）：

- [ ] 老师、客户、公职人员、直属上级这类对象，先给了能不能送的结论？
- [ ] 每个方向只到品类，没有品牌、店铺、平台和链接？
- [ ] 每张卡片 80 字以内、有一件具体的事、不提价格？
- [ ] 多人清单跑过 gift_budget.py，退出码为 0，或每条提示都处理了？
- [ ] 送吃的提醒了看配料表，避雷表逐条对过？
- [ ] 所有 [待补]、[待确认] 都列进了待确认清单？

## 示例

**示例（虚构场景）**：用户说「教师节想给孩子的班主任送点东西，合适吗」。

助手先问（一次三个）：① 学校或班级发过「不收礼」的通知吗？② 孩子几年级，这学期有没有想感谢老师的具体一件事？③ 以个人名义还是班级名义？

用户补充：「开学时学校发过通知，老师不收礼。孩子三年级，这学期李老师让他当了小组长，他第一次主动整理了书包。个人名义。」

最终交付：

```text
结论：学校已通知不收礼 → 不送有价物品，只送心意。

方向（两个，都不花钱）：
1 孩子的手写卡片或一幅画——老师最在意孩子的变化，孩子亲手做的最合适
2 家长写的感谢信——写清是哪件事，老师能感到自己的用心被看见

卡片草稿（家长的感谢信开头，80 字以内）：
李老师：这学期孩子回家常说您让他当小组长，他第一次主动整理了书包。谢谢您看见了他。——小王家长

送的方式：让孩子当面交给老师，或夹在作业本里；不附任何有价物品。
预算：0 元。
待确认清单：无。
```

## 常见问题（FAQ）

**Q：老师能不能收礼？**
A：很多学校和地区都有「教师不收礼」的规定，先看学校通知；拿不准就不送有价物品，只送孩子的手写卡片或画、家长的感谢信。想集体表示，以班级名义、经学校同意、给班级而不是个人，不凑钱给老师个人。

**Q：给客户送礼要审批吗？**
A：以本公司的礼品政策为准：金额上限、要不要审批登记、能不能报销，先查再送。对方是公职人员、国企员工或手里有采购决定权的，还要先确认对方单位的规定，拿不准就改成书面致谢。

**Q：能直接推荐具体商品或给个链接吗？**
A：不推荐品牌、店铺和平台，也不给链接；给品类方向和挑选标准，你按标准去挑。

**Q：给父母包红包行不行？**
A：家人之间按家里的习惯来；职场、老师、客户这几类关系不送现金和购物卡这类现金等价物。

**Q：预算不够怎么办？**
A：先保住最亲近、最重要的人；其余人降一档，或换成手写卡、一起吃顿饭这类不花大钱的心意。脚本会按金额列出先减哪几项。

**Q：对方说「别送了」怎么办？**
A：长辈说「别送」常常是怕你花钱，送消耗品、服务或陪伴更容易被接受；同事、客户说不要就尊重，改成一张卡或一句当面的感谢。

**Q：同事离职，大家凑钱送什么？**
A：送能带走的小东西，加一张大家签名的卡；金额全组统一，不在群里晒价格。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 按自己的喜好选 | 礼物是给对方用的，不合用就会闲置 | 按判断题，从对方最近的需要出发 |
| 给长辈送要下载 App 才能用的电子产品，却不教会 | 用不上，最后被收起来 | 当场装好、教会，或换成不用 App 的 |
| 最后一天慌忙买 | 选择少、容易踩雷，寄送也可能赶不上 | 提前列清单，用「状态」一列跟进 |
| 同一群人礼物差距太大 | 被比较时有人尴尬 | 同一群人同一档位，脚本会提示差距 |
| 价签没撕 | 让对方掂量价格，添了回礼压力 | 送前撕掉价签 |
| 尺码类不附换货方式 | 不合适就只能闲置 | 附上换货方式 |
| 送完不记录 | 明年重复，回礼也容易失衡 | 预算表留作送礼记录 |
| 没查规定就给老师、客户送有价物品 | 可能违反学校或双方单位的规定，让对方为难 | 先过红灯，给出能不能送的结论再给方向 |
| 替用户挑具体品牌、发购买链接 | 越出本技能边界，也未必适合对方 | 只给品类和挑选标准 |

## 边界与不做什么

- 不推荐具体品牌、店铺或购物平台，不比价，不给购买链接。
- 不判断某份礼物是否违规或违法；以本公司合规部门和对方单位的规定为准，必要时咨询律师。
- 送老师以学校和当地规定为准，拿不准就只送不花钱的心意。
- 保健品、药品、医疗器械不作为礼物方向；有健康需求，先问医生。
- 婴幼儿玩具和食品，以包装上的适用年龄和安全警示为准。
- 礼物修不好关系：道歉和感情问题要靠当面沟通，需要时找专业的咨询师。
