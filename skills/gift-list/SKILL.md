# 礼物清单

定位一句话：**好礼物不靠贵，靠让对方觉得「你注意到了我」，而且收下没有负担。**
何时用：不知道给父母、伴侣、孩子、同事、老师或客户送什么；一次要给好几个人准备礼物、要控制总预算；拿不准对方能不能收、卡片上写什么时。本页只给判断方法和品类方向，不推荐品牌、店铺或平台。

## 先判断四件事

第 1 步，问清四件事，缺哪项问哪项：

```
对象   是谁、多亲近；是不是上下级、老师、客户这类有收礼规定的关系
场合   生日、节日、感谢、道歉、探望、回礼（道歉礼宜轻，感谢礼要具体）
预算   这一份多少钱；多人时的总预算
限制   忌口（清真、素食、过敏、控糖）、信仰、健康状况、住处大小、近期是否搬家或出国
```

第 2 步，先过红灯：对象是老师、客户、公职人员或直属上级，先看下面「避雷」一节，确认能送再往下选。

第 3 步，按预算档位决定钱花在哪。档位按人民币举例，只用来划分思路：

```
≤100 元       买心意：手写卡、亲手做的、对方常用消耗品的「好一点」版本
100–300 元    买升级：把对方天天在用、已经凑合的东西换好一档
300–1000 元   买体验或长期用品：一起去的活动、能用很多年的物件
1000 元以上   只给最亲近的人；先确认对方收得安心，不会有回礼压力
```

对象和档位的常见搭配：

```
父母         100–1000 元：按家里的消费习惯，别让老人「心疼钱」反而不用
伴侣         按你们平时的消费水平，不借钱、不分期去送礼
别人家孩子   300 元以内：不超过对方父母方便回礼的水平
同事         100 元以内：全组统一，可分享
老师         0 元：只送心意，不送有价物品
客户         本公司政策的上限以内，同一批客户统一标准
```

## 判断题：六类对象

每类三四道判断题，按答案走向礼物方向。

**父母**
- 最近抱怨过哪件事不方便吗（看不清、睡不好、手机字太小）？是 → 解决不便的日用品，送的时候当场装好、教会。
- 会舍不得用、把礼物收起来吗？是 → 送消耗品、服务，或一起去的体验。
- 平时见面少吗？是 → 送时间：陪一整天，或一起把老照片整理成相册。
- 是伴侣的父母吗？是 → 先问伴侣，按对方家里的习惯来；同一个节日，两边父母的礼物保持同一档位。

**伴侣**
- 最近三个月，TA 说过「想要但舍不得买」的东西吗？是 → 就送它，最稳。平时就记在备忘录里。
- 你们正在一起做什么（健身、做饭、旅行）？→ 给这件事升级装备，或安排一次体验。
- 是纪念日吗？是 → 纪念意义大于价格，选和共同记忆有关的东西。

**孩子**
- 看过包装上的适用年龄和安全警示吗？3 岁以下避开小零件。
- 孩子的父母同意吗？零食、带屏幕的设备、宠物，先问父母。
- 孩子最近迷什么？→ 顺着兴趣选书、拼搭、画材、户外用品，能一起玩的优先。

**同事**
- 是全组统一，还是个人心意？统一 → 同价同类，不厚此薄彼。
- 对方会觉得必须回礼吗？会 → 小额、可分享的：零食、茶、小盆绿植。
- 是上下级吗？是 → 用集体名义，公开，低价。
- 是离职、升职、住院这类特殊场合吗？离职送能带走的小东西加一张大家签名的卡；升职用集体名义；住院先问家属方不方便探望、需要什么。

**老师**
- 学校有没有「教师不收礼」的规定？很多学校和地区都有，先看通知；拿不准就不送有价物品。
- 最稳的是孩子的手写卡片或画，加一封家长写的感谢信，写清是哪件事。
- 想集体表示：以班级名义、经学校同意、给班级而不是个人；不凑钱给老师个人。

**客户**
- 本公司的礼品政策查了吗？金额上限、要不要审批登记、能不能报销。
- 对方是公职人员、国企员工，或手里有采购决定权吗？是 → 先确认对方单位的规定；拿不准就不送实物，改成书面致谢。
- 正处在招投标、续约、验收这类敏感期吗？是 → 暂缓。
- 能送时：统一标准的节礼，如本地特产或实用品，寄到办公地址，走公司流程、留记录。

六类答完还是没头绪，按三步找：一翻聊天记录，搜「想要」「坏了」「好想去」这类词；二问对方身边的人，只问「TA 最近在忙什么、缺什么」；三把选择权交出去，亲近的人可以约好一起去挑，别让惊喜变成负担。

送的方式也算礼物的一部分：父母和长辈当面给，顺手装好、教会；同事的放在桌上附一张卡，不在群里晒价格；客户的寄到办公地址，附公司署名的卡片。

## 卡片文案与预算表（可直接套用）

卡片公式：**称呼 + 一件具体的事 + 这份礼物和那件事的关系 + 一句祝愿或约定 + 署名**，80 字以内，不提价格。写不出那件具体的事，就问自己三个问题：你们最近一次一起做的事是什么？TA 最近做了什么让你感激？你希望 TA 在什么时候用上这份礼物？

```
父母  爸：上次视频你说晚上看书字太小，这盏台灯亮度能调，我已经帮你调好了。少熬夜，下个月回家陪你钓鱼。——小王
伴侣  三年前的今天，我们在雨里等了四十分钟的车。以后的每一段路，都想和你一起等。生日快乐。
孩子  给 8 岁的你：你说想当宇航员，那就从认识星星开始吧。愿你一直这么好奇。——姑姑
同事  小王：谢谢这半年在项目里帮我兜底，尤其是上线那晚。一点零食，给下午续命。
老师  李老师：这学期孩子回家常说您让他当小组长，他第一次主动整理了书包。谢谢您看见了他。——小王家长
```

## 避雷：价值观冒犯、职场合规与常见错误

价值观与冒犯：
- 暗示对方有缺点的：没被要求时送减肥产品、抗衰老护肤品、「情商」「口才」类的书。
- 碰到饮食与信仰禁忌：给清真饮食的人送含猪肉成分的食品，给不喝酒的人送酒，给素食者送肉类礼盒。送吃的先看配料表。
- 中文语境里常见的讲究：钟（送终）、伞（散）、梨（离）；探病不送白色的花和菊花。各地讲究不同，拿不准就避开。
- 政治、宗教、带性暗示的物品和玩笑礼物，职场里一律不送。
- 贴身衣物、香水，不送异性同事和客户。
- 活的宠物、大型绿植，会给对方添长期负担，先问再送。

职场合规：
- **公开测试**：这份礼物能不能当着全组、当着对方领导的面拆开？不能就换。
- 不送现金、购物卡、储值卡这类现金等价物。
- 金额以本公司和对方单位的规定为准；需要审批登记的，先走流程。
- 不单独给直属上级送贵重礼物。
- 商务礼品公开寄到办公地点，留好记录。

常见错误：按自己的喜好选；给长辈送要下载 App 才能用的电子产品，却不教会；最后一天慌忙买；同一群人礼物差距太大；价签没撕；尺码类不附换货方式；送完不记录，明年重复。

## 输出契约

1. **先问后给**：四件事缺哪项问哪项，一次最多问三个问题。
2. **每人两到三个方向**：品类加理由，对应到判断题的答案；不给品牌、店铺、平台和链接。
3. **每份礼物一段卡片草稿**：80 字以内，里面有一件具体的事。
4. **多人给预算表**：合计不超过总预算，超了指出从哪一项减。
5. **有收礼规定的对象先给结论**：可以送、建议不送实物，还是先问规定，然后再给方向。

## 边界与不做什么

- 不推荐具体品牌、店铺或购物平台，不比价，不给购买链接。
- 不判断某份礼物是否违规或违法；以本公司合规部门和对方单位的规定为准，必要时咨询律师。
- 送老师以学校和当地规定为准，拿不准就只送不花钱的心意。
- 保健品、药品、医疗器械不作为礼物方向；有健康需求，先问医生。
- 婴幼儿玩具和食品，以包装上的适用年龄和安全警示为准。
- 礼物修不好关系：道歉和感情问题要靠当面沟通，需要时找专业的咨询师。
