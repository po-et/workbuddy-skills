# 判断题：六类对象（完整版）

回到 [SKILL.md](../SKILL.md)。每类三四道判断题，按答案走向礼物方向；只给品类，不给品牌、店铺和平台。

## 父母

- 最近抱怨过哪件事不方便吗（看不清、睡不好、手机字太小）？是 → 解决不便的日用品，送的时候当场装好、教会。
- 会舍不得用、把礼物收起来吗？是 → 送消耗品、服务，或一起去的体验。
- 平时见面少吗？是 → 送时间：陪一整天，或一起把老照片整理成相册。
- 是伴侣的父母吗？是 → 先问伴侣，按对方家里的习惯来；同一个节日，两边父母的礼物保持同一档位。

## 伴侣

- 最近三个月，TA 说过「想要但舍不得买」的东西吗？是 → 就送它，最稳。平时就记在备忘录里。
- 你们正在一起做什么（健身、做饭、旅行）？→ 给这件事升级装备，或安排一次体验。
- 是纪念日吗？是 → 纪念意义大于价格，选和共同记忆有关的东西。

## 孩子

- 看过包装上的适用年龄和安全警示吗？3 岁以下避开小零件。
- 孩子的父母同意吗？零食、带屏幕的设备、宠物，先问父母。
- 孩子最近迷什么？→ 顺着兴趣选书、拼搭、画材、户外用品，能一起玩的优先。

## 同事

- 是全组统一，还是个人心意？统一 → 同价同类，不厚此薄彼。
- 对方会觉得必须回礼吗？会 → 小额、可分享的：零食、茶、小盆绿植。
- 是上下级吗？是 → 用集体名义，公开，低价。
- 是离职、升职、住院这类特殊场合吗？离职送能带走的小东西加一张大家签名的卡；升职用集体名义；住院先问家属方不方便探望、需要什么。

## 老师

- 学校有没有「教师不收礼」的规定？很多学校和地区都有，先看通知；拿不准就不送有价物品。
- 最稳的是孩子的手写卡片或画，加一封家长写的感谢信，写清是哪件事。
- 想集体表示：以班级名义、经学校同意、给班级而不是个人；不凑钱给老师个人。

## 客户

- 本公司的礼品政策查了吗？金额上限、要不要审批登记、能不能报销。
- 对方是公职人员、国企员工，或手里有采购决定权吗？是 → 先确认对方单位的规定；拿不准就不送实物，改成书面致谢。
- 正处在招投标、续约、验收这类敏感期吗？是 → 暂缓。
- 能送时：统一标准的节礼，如本地特产或实用品，寄到办公地址，走公司流程、留记录。
