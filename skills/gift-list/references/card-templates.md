# 卡片文案：公式与七种场景样例

回到 [SKILL.md](../SKILL.md)。

公式：**称呼 + 一件具体的事 + 这份礼物和那件事的关系 + 一句祝愿或约定 + 署名**，80 字以内，不提价格。

写不出那件具体的事，就问自己三个问题：你们最近一次一起做的事是什么？TA 最近做了什么让你感激？你希望 TA 在什么时候用上这份礼物？还是想不出来，就在草稿里写 [待补：一件具体的事]，不编。

## 样例（人名为演示，直接替换成你们的事）

```
父母  爸：上次视频你说晚上看书字太小，这盏台灯亮度能调，我已经帮你调好了。少熬夜，下个月回家陪你钓鱼。——小王
伴侣  三年前的今天，我们在雨里等了四十分钟的车。以后的每一段路，都想和你一起等。生日快乐。
孩子  给 8 岁的你：你说想当宇航员，那就从认识星星开始吧。愿你一直这么好奇。——姑姑
同事  小王：谢谢这半年在项目里帮我兜底，尤其是上线那晚。一点零食，给下午续命。
老师  李老师：这学期孩子回家常说您让他当小组长，他第一次主动整理了书包。谢谢您看见了他。——小王家长
客户  张总：感谢一年来对项目的信任与支持。中秋将至，谨以家乡特产一份致意，祝阖家安康。——某某公司 小王
道歉  那天是我说话太急，对不起。这不是赔礼，是想告诉你，我在意。
```

## 自查三问

- 有没有一件只属于你们俩的具体的事？
- 读起来像你平时说话的口气吗？
- 有没有提价格、有没有让对方觉得必须回礼的话？
