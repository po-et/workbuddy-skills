# 示例：春节给父母、岳父母和两位同事，总预算三千

回到 [SKILL.md](../SKILL.md)。以下为虚构场景，人名和金额都是演示；只给品类，不给品牌和链接。

## 用户原话

> 春节要给父母、岳父母和两个同事准备礼物清单，总预算三千

## 助手的澄清问题（一次三个）

1. 四位长辈最近各提过什么不方便、想要的，或者有什么忌口、健康上要避开的？
2. 两位同事：全组统一还是你的个人心意？想感谢他们什么事？
3. 长辈的礼物当面给还是寄？岳父母那边问过伴侣了吗？

用户补充：「我爸上次视频说晚上看书字太小；我妈晕车，平时舍不得花钱，念叨过想去看梅花；岳父不喝酒、爱喝茶，每天下午泡一壶；岳母怕冷，冬天手脚凉。两个同事同组，个人心意：小李上线那晚陪我兜底到半夜，小赵帮我改好了周报模板。长辈都是当面给；岳父母那边还没问伴侣。」

## 最终交付

### 1. 有收礼规定的对象

无（父母、岳父母、同事都不涉及收礼规定）。同事按个人心意、小额、可分享，不在群里晒价格。

### 2. 每人的方向（只到品类）

| 对象 | 方向 | 理由（对应判断题） |
|---|---|---|
| 爸爸 | 亮度可调的阅读台灯 | 最近抱怨过不方便 → 解决不便的日用品，当场装好、调好 |
| 妈妈 | 陪她去近郊看一次梅花（不坐长途车） | 舍不得用 → 送一起去的体验；晕车，路线选短途 |
| 岳父 | 茶叶 | 爱喝茶、不喝酒 → 顺着日常习惯；避开酒 [待确认：先问伴侣] |
| 岳母 | 保暖围巾 | 怕冷 → 天天用得上的保暖用品 [待确认：先问伴侣] |
| 小李 | 可分享的零食 | 同事、个人心意 → 小额、可分享；先看配料表，避开对方忌口 |
| 小赵 | 可分享的茶 | 同上 |

两边父母同一档位（300–1000 元），同事同一档位（≤100 元）。

### 3. 卡片草稿（每张 80 字以内）

```
爸：上次视频你说晚上看书字太小，这盏台灯亮度能调，我已经帮你调好了。少熬夜，春节在家多陪你。——小王
妈：你念叨了好几年想去看梅花，这次不坐长途车，就在近郊走一天，我陪你。新年快乐。——小王
爸：知道您每天下午都要泡一壶茶，这罐茶叶给您的下午添点新味道。新年身体健康。——小王
妈：您说冬天手脚总是凉，这条围巾出门戴上暖和些。新年快乐，常来家里坐。——小王
小李：谢谢这一年帮我兜底，尤其是上线那晚陪我到半夜。一点零食，给下午续命。新年快乐！
小赵：你改好的周报模板我每周都在用，省了不少事。一点茶，谢谢你。新年快乐！
```

### 4. 预算表与脚本核对

```
对象,关系,场合,档位,方向（品类）,限制与备注,预算,状态
爸爸,父母,春节,300–1000,亮度可调的阅读台灯,看书嫌字小；当场调好,400,待买
妈妈,父母,春节,300–1000,近郊一日游（看梅花）,晕车：不坐长途车,800,待订
岳父,父母,春节,300–1000,茶叶,不喝酒；先问伴侣,600,待买
岳母,父母,春节,300–1000,保暖围巾,怕冷；先问伴侣,500,待买
小李,同事,春节,≤100,可分享的零食,,80,待买
小赵,同事,春节,≤100,可分享的茶,,80,待买
```

```text
$ python3 scripts/gift_budget.py 春节礼物.csv 3000
合计 2460 元 / 总预算 3000 元：未超出
  - 爸爸（父母）400 元，待买
  - 妈妈（父母）800 元，待订
  - 岳父（父母）600 元，待买
  - 岳母（父母）500 元，待买
  - 小李（同事）80 元，待买
  - 小赵（同事）80 元，待买
```

退出码 0：没超预算，也没有要改的行。余下 540 元留给包装、路上开销和临时要加的人。

### 5. 送的方式与待确认清单

- 送的方式：长辈当面给，台灯当场装好、调好；同事的放在桌上附卡片。
- 待确认清单：岳父母的礼物先问伴侣，按对方家里的习惯来；梅花的花期和近郊路线以当地实际为准。

## 这个示例对应的自检

有规定的对象先给结论：不适用；只到品类：是；卡片 80 字以内、有具体的事、不提价格：是；脚本退出码 0：是；送吃的看配料表：已在方向表里提醒；待确认已汇总：是。
