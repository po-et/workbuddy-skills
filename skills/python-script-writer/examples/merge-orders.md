# 完整示例：合并 12 个月的订单表，按订单号去重（公司电脑不能装包）

> 示例。文件名、订单号、客户都是虚构的；下面的日志是在 3 个示例文件上实际运行 `scripts/template_merge_csv.py` 的输出（去掉了时间戳）。

## 1. 用户原话

> 帮我合并这些 Excel，按订单号去重，出一张总表

## 2. 助手先问（最多 3 个）

1. 一共几个文件、什么格式（`.xlsx` 还是 `.csv`）？各贴 3 行样例，含表头。
2. 同一个订单号出现在多个文件里、内容还不一样时，以哪份为准？
3. 在 Windows 还是 Mac 上跑？能不能 `pip install` 装包？

## 3. 用户补充

> 12 个月的 xlsx，每月一个，文件名是 2026-01 到 2026-12。表头是「订单号、客户、金额、状态」，有的月份表头前后带空格。后面月份的状态更新，以后面的为准。Windows，公司电脑装不了包。

## 4. 交付物

**① 假设（默认值已标出）**

```
输入  D:\orders 下 12 个 xlsx，先在 Excel 里逐个另存为 CSV UTF-8 格式，放进 D:\orders_csv
输出  D:\orders_out\合并结果.csv（新目录，原文件不动；UTF-8 带 BOM，Excel 直接打开不乱码）
去重  按「订单号」，文件按文件名排序，后面月份覆盖前面月份；内容不同的订单号在日志里逐个列出（前 10 个）
失败  某个文件读不了或没有「订单号」列：跳过并记日志，其余照常合并，最后以退出码 3 提示
环境  Windows、只用 Python 标准库 [待确认：Python 版本 3.8 以上]
```

**② 脚本**：直接用 `scripts/template_merge_csv.py`，不用改代码；表头空格、GBK 编码、订单号前导 0 都已处理。

**③ 两条命令**（Windows 上把 `python3` 换成 `python` 或 `py`）

```
python3 template_merge_csv.py --src D:\orders_csv --dst D:\orders_out --key 订单号 --dry-run
python3 template_merge_csv.py --src D:\orders_csv --dst D:\orders_out --key 订单号
```

**④ 在 3 个示例文件上的实际输出**（1 月 3 行、2 月 2 行、3 月 2 行，其中 00103 的状态 2 月有更新，00104 在 2、3 月重复出现）：

```
INFO 主键 00103 内容不同：保留 2026-02.csv 的版本，覆盖 2026-01.csv 的
INFO 3 个文件 7 行，去重后 5 行（重复 2 行，其中内容不同 1 个主键；主键为空 0 行已原样保留）
INFO 已写出 out/合并结果.csv
```

```
订单号,客户,金额,状态,来源文件
00101,客户A,120,已发货,2026-01.csv
00102,客户B,80,已发货,2026-01.csv
00103,客户C,45,已发货,2026-02.csv
00104,客户D,300,已发货,2026-03.csv
00105,客户E,66,待发货,2026-03.csv
```

**⑤ 核对方法**

- 日志里「去重后 N 行」应等于总表行数；「重复」行数 = 读入行数 − 去重后行数。
- 抽查 3 个「内容不同」的订单号，打开对应两个月的原表，确认保留的是后面月份的版本。
- 订单号列的前导 0 还在（00101 没变成 101）。

**⑥ 回退**：原 xlsx 和另存的 CSV 都没动过，删掉 `D:\orders_out` 就回到原样。

**⑦ 运行说明**：脚本在上面 3 个示例文件上实际跑过；你的 12 个真实文件没有跑过，先 `--dry-run` 看日志里的文件数和行数对不对。
