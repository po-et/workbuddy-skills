# 现场应对与访前准备

提纲写好只是一半；这一页是访谈当天要用的：对方跑题、答得太短、反问你、开始抱怨时怎么接，以及访前一天要过的清单。

## 现场应对

| 现场情况 | 怎么接 |
|---|---|
| 对方跑题 | 「这个我记下了，回到刚才……」 |
| 回答太短，一直「还行」「挺好」 | 换成「带我走一遍那天的经过」；或「能说一次具体的吗？」 |
| 反问你的看法 | 「我更想先听你的，最后再说我的」 |
| 开始抱怨，或要你给办法 | 照录原话，不承诺、不辩解 |
| 对方说完了 | 停三秒再接，常会有补充 |
| 两个人去访 | 一人问一人记；记录的人只在收尾前补问一次 |
| 线上访谈 | 请对方共享屏幕、现场翻出当时的记录，比口述可靠 |
| 线上断线 | 按事先约好的电话继续 |
| 对方情绪明显波动 | 停下来，不追问；必要时建议其联系专业人员（见 SKILL.md「边界与不做什么」） |

## 访前一天过一遍

- [ ] 录音设备电量充足，试录一段能听清
- [ ] 提纲打印出来，或存成离线文件
- [ ] 需要书面同意的，带上同意书
- [ ] 地点或会议链接再发一次给对方
- [ ] 提前五分钟到场或上线

## 专家访谈另做的两件事

1. 先读完他公开写过、讲过的东西，不问网上查得到的事。
2. 邀约时写清三个主题、时长、会不会引用原话、要不要署名；给参与者的报酬或谢礼，金额和发放方式在邀约时就说清。
