# 访谈提纲

定位一句话：**访谈要的是对方做过什么，不是对方觉得什么；主线里的每个问题都应该能用「上一次……」开头。**

## 何时使用

用户这样说时用本技能：

- 「帮我写个访谈提纲，下周要约 6 位独居上班族聊工作日晚饭怎么解决」——做产品或服务前的用户访谈
- 「明天约了一位做了十年的行内前辈，专家访谈要准备什么」——向行内人请教
- 「论文要做半结构化访谈，提纲怎么列」——论文与课题访谈
- 「出问卷前想先聊几个人，把选项摸全」
- 「用户访谈怎么问才不像推销」「帮我看看这份提纲，问题有没有引导性」——改提纲
- 「访完了，这些记录怎么汇总成结论」

不适用（遇到时这样处理）：

- 招聘面试、新闻采访、调查取证、绩效谈话 → 各有规则，不写访谈提纲；分别找 HR、编辑或律师，技术岗面试可转「技术面试」（tech-interview-expert）。
- 要知道「占多少人」「多少人愿意付费」 → 访谈回答不了比例，转「问卷设计」（questionnaire-design）；访谈只负责找原因和选项。
- 以心理创伤、疾病、违法经历或未成年人为主题 → 需要受过训练的研究者主持；只给一般结构，并提示先确认伦理审批与知情同意。

## 先判断：要回答什么、找谁、访几个

```
研究问题  一句话写下「这轮访谈结束后，我要能回答……」，例：独居上班族工作日晚饭为什么多半点外卖
用户访谈  挖他本人的行为与情境：做了什么、用什么、卡在哪、花了多少时间和钱
专家访谈  借他见过的大量案例：常见做法、新手最常错在哪、他怎么判断好坏——问案例，不问预测
找谁      最近三个月真做过这件事的人，不找「理论上会用」的人；熟人越少越好，他们会照顾你的面子
筛选题    招募时先问两三道事实题再约：「过去四周，工作日晚饭点外卖大约几次？」「你现在是一个人住吗？」
          同行、做调研的、只想拿报酬的，一律不约
访几个    同一类人访到第 5–8 位时新信息通常明显变少（经验值），以记录里「新发现」是否还在出现为准
要比例    访谈只负责找原因和选项，「占多少人」交给问卷（见 问卷设计 questionnaire-design）
一对一    一场只访一个人；两三个人一起聊，最后只剩最敢说的那个人的版本
```

专家访谈另做两件事：先读完他公开写过、讲过的东西，不问网上查得到的事；邀约时写清三个主题、时长、会不会引用原话、要不要署名。给参与者的报酬或谢礼，金额和发放方式在邀约时就说清。

## 流程：提纲五段怎么写

```
开场  「我是小王，在研究大家工作日晚饭怎么解决。今天大约 30 分钟，没有对错，想听你真实的做法。
       哪题不想答可以直接跳过。为了不漏记，可以录音吗？录音只用来整理笔记，不外传。」
       征得同意再开录；不说你的假设，不说「我们在做一个产品」
暖场  问好答的事实：「你现在工作大概什么节奏？一般几点下班？」——让对方开口，不在这里深挖
主线  3–5 个主问题，全部问过去的具体经历，每题从一个真实的时间点讲起；每题下预写 2–3 个想挖的点
       （时间、花费、试过的替代办法），对方没主动说到再追问
       「说说昨天的晚饭，从下班那一刻讲起。」
       「方便给我看看当时的订单截图或购物清单吗？」——实物比回忆可靠
       专家版：「你见过做得最好的一次是什么样？最差的呢？」「新手最常在哪一步出错？你怎么一眼看出来？」
追问  要例子「能说一次具体的吗？」         要过程「然后呢？当时你是怎么做的？」
       澄清词「你说的『麻烦』具体指什么？」   问动因「是什么让你那天决定……？」（少连问「为什么」，像审问）
       复述「我听到的是……，对吗？」         沉默：对方说完停三秒再接，常会有补充
收尾  「关于这件事，有什么我该问却没问的？」「还有谁值得我去聊聊？」致谢，说明资料怎么用、会不会回访
```

访谈当天的现场应对（跑题、答得太短、反问你、抱怨、线上断线）和访前一天的检查清单，见 [references/field-tactics.md](references/field-tactics.md)。

## 30 分钟与 60 分钟两版时间分配

```
环节    30 分钟版              60 分钟版
开场    2 分钟                 3 分钟
暖场    3 分钟                 7 分钟
主线    20 分钟，3 个主问题    40 分钟，5 个主问题
收尾    3 分钟                 5 分钟
缓冲    2 分钟                 5 分钟
```

```
主问题清单（30 分钟版只问 P0，60 分钟版全问）
P0  说说昨天的晚饭，从下班那一刻讲起
P0  最近一次点外卖，从打开手机到吃上，中间经过了哪几步
P0  上一次自己做饭是哪天？那天和平时有什么不一样
P1  过去一个月晚饭大概花了多少钱？你是怎么估出来的
P1  试过带饭、食堂或别的办法吗？后来为什么没接着用
```

每个主问题连同追问按 6–8 分钟留；超时先砍 P1，P0 必须问到。60 分钟版多出的暖场时间用来摸背景：一天的时间怎么分配、家里谁管做饭。提纲写满两倍问题的人，主线过半就会超时——宁可少问，把一题问透。

专家版主问题示例（请教李老师）：P0「你见过晚餐时段经营得最好的一家是什么样？最差的呢？」P0「新开的社区食堂最常在哪一步出问题？你是怎么看出来的？」P1「判断一个时段值不值得开，你会先看哪几个数？」

## 记录模板与跨场汇总

```
编号 P03 ｜ 日期 ｜ 时长 ｜ 用户／专家 ｜ 角色与背景（不写姓名、电话）｜ 是否同意录音
主问题        原话（加引号照录）          观察（动作、工具、情绪）      我的解读（标「推测」）
Q1 昨天晚饭   「到家都九点了，懒得做」    说到做饭时下意识看了眼时间    推测：瓶颈是时间，不是厨艺
访后 15 分钟内补完：三个最意外的发现／与假设矛盾的地方／下一场要改或删的问题
```

汇总规则一句话：同一主题在三场以上出现才算一条发现，只出现一次的记为线索。录音转写怎么用、跨场汇总表的格式和「本场发现」一页模板，见 [references/notes-and-synthesis.md](references/notes-and-synthesis.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| E1 缺关键信息：只说「帮我写个访谈提纲」，没说研究什么、访谁 | 只问 3 个：访完要能回答什么、访用户还是专家、每场多长；筛选条件按「最近三个月真做过这件事」、人数按 5–8 位先填，标 [待确认] | 「先告诉我三件事：访完你要能回答什么？访的是用户还是行内专家？每场大约多长？其余我先按常见做法填，标了 [待确认] 的你再改。」 |
| E2 目标和方法对不上：想知道「占多少人」「愿不愿意付费」，却打算只访两三个人 | 指出访谈回答不了比例和意愿，给两个方向让用户选 | 「访谈回答不了『占多少人』。你是想①先弄清原因和选项（用访谈），还是②量化比例（用问卷，可以转问卷设计）？」 |
| E3 时长与问题量矛盾：30 分钟想问 10 个主问题 | 按每题 6–8 分钟折算，保留 3 个 P0，其余标 P1 或留到下一轮 | 「30 分钟最多问透 3 个主问题。我先排 3 个 P0，其余放 P1——或者改成 60 分钟版？」 |
| E4 给来的问题是引导性、问未来假设、问观点或一题两问 | 不照搬；逐题给「原问题 → 问题所在 → 改法」 | 「这几题会让对方顺着你说，比如『你是不是觉得……』。我改成问上一次的具体经历，对照表放在下面。」 |
| E5 超出范围：招聘面试、新闻采访、调查取证、绩效谈话 | 不写提纲，说明各有规则，转 HR、编辑、律师或技术面试技能 | 「这类谈话有自己的规则，访谈提纲帮不上。招聘面试请找 HR，调查取证请找律师。」 |
| E6 敏感主题：心理创伤、疾病、违法经历、未成年人 | 不直接出具体问题；提示需受训研究者主持、先确认伦理审批与书面知情同意；只给一般五段结构 | 「这个主题需要受过训练的研究者主持，论文课题还要先确认伦理审批。我先给一般结构，具体问题请和导师一起定。」 |
| E7 坚持在访谈里介绍产品、问「你会不会买」 | 主线不介绍产品、不问意愿；真要看反应，放到收尾之后单独记录，不和前面的行为证据混在一起 | 「主线里一介绍产品，对方就只剩客气。要看反应的话，放到收尾之后单独做、单独记。」 |
| E8 时间紧，明天就访 | 交最小可用版：研究问题一句＋开场话术＋3 个 P0（各 2 个追问点）＋收尾两问＋记录模板 | 「来不及细磨，先给你一页能照着问的版本：开场、3 个主问题、收尾两句，外加记录表。」 |

## 输出契约

交付分两轮，每轮内部按固定顺序：

1. **第一轮：三行确认**——研究问题｜访谈类型（用户或专家）｜筛选条件（含 2–3 道筛选事实题）。用户确认后再写第二轮。
2. **第二轮：提纲包**
   1. 邀约要点：主题、时长、录音与引用、报酬或谢礼（金额标 [待确认]）
   2. 五段话术：开场、暖场、主线（主问题标 P0／P1，每题 2–3 个追问点）、追问句式、收尾——能照着念
   3. 时间分配表：所选的 30 或 60 分钟版
   4. 记录模板与跨场汇总表：原话与解读分栏，解读一律标「推测」
   5. 待补 / 待确认清单
3. **改别人的提纲时**：第 2 项换成逐题「原问题 → 问题所在 → 改法」对照表，其余不变。
4. **每场结束后**（可选）：一页「本场发现」，三条发现各附原话编号。

占位符规则：[待补] ＝要用户提供、不能替用户编的信息（研究对象的具体情况、专家的公开材料、报酬金额）；[待确认] ＝先按默认写了、要用户确认的（人数 5–8 位、时长 30 分钟、是否录音）。

交付前自检（逐条答「是 / 否」，有一条「否」就先改再交）：

- [ ] 主线每个主问题都能用「上一次……」「最近一次……」或一个具体时间点开头
- [ ] 没有引导性提问、未来假设、问观点、一题两问和「你一般怎么……」
- [ ] 主问题数量与时长匹配：30 分钟版 P0 不超过 3 个，60 分钟版主问题不超过 5 个
- [ ] 开场说清时长、没有对错、可以跳过、录音先征得同意，且没说出你的假设或产品
- [ ] 记录模板只写编号与角色，不写姓名电话；解读栏标「推测」
- [ ] 收尾两问都在：「有什么我该问却没问的」「还有谁值得聊」

以下为示例，人物与场景均为虚构。

**用户：** 帮我写个访谈提纲，下周要约 6 位独居上班族聊工作日晚饭怎么解决。

**助手（第一轮，三行确认）：**

```

访谈类型  用户访谈：挖本人的行为与情境

          同行、做调研的不约；时长 [待确认：30 分钟]
```

**用户：** 对，每场 30 分钟，线上。

**助手（第二轮，提纲包）：**

```

             哪题不想答可以直接跳过。为了不漏记，可以录音吗？录音只用来整理笔记，不外传。」
暖场 3 分钟  「你现在工作大概什么节奏？一般几点下班？」
主线 20 分钟
  P0 说说昨天的晚饭，从下班那一刻讲起
       追问点：几点到家；吃的是什么；花了多少时间和钱
  P0 最近一次点外卖，从打开手机到吃上，中间经过了哪几步
       追问点：「方便共享屏幕，翻一下当时的订单吗？」；哪一步最费劲
  P0 上一次自己做饭是哪天？那天和平时有什么不一样
       追问点：是什么让你那天决定自己做；后来为什么没接着做
收尾 3 分钟  「关于这件事，有什么我该问却没问的？」「还有谁值得我去聊聊？」致谢，说明资料怎么用

```

## 常见问题（FAQ）

**问：到底访几个人才够？**
答：同一类人访到第 5–8 位时，新信息通常明显变少（经验值）；以记录里「新发现」是否还在出现为准，不是凑够数就停。

**问：每场只有 15 分钟，怎么办？**
答：按 30 分钟版的比例砍：开场一两句、暖场一问，主线只问 1–2 个 P0，收尾保留「有什么我该问却没问的」。

**问：能不能约两三个人一起聊，省时间？**
答：本技能按一对一写。两三个人一起聊，最后通常只剩最敢说的那个人的版本。

**问：对方一直说「还行」「挺好的」，问不出东西？**
答：换成讲经过：「带我走一遍那天的经过」「能说一次具体的吗？」；说完停三秒再接，常会有补充。

**问：对方反问我怎么看，或者要我给办法？**
答：说「我更想先听你的，最后再说我的」；抱怨照录原话，不承诺、不辩解。

**问：录音转成文字，能直接拿来下结论吗？**
答：不能。转写只用来核对原话；同一主题在三场以上出现才算一条发现，只出现一次的记为线索，下一轮再验证。

**问：能帮我直接约人、发邀约吗？**
答：不代发。可以写好邀约文字：三个主题、时长、会不会引用原话、要不要署名、报酬怎么给，你自己发出去。

**问：访谈和问卷有什么区别？**
答：访谈找原因和选项，问卷算比例。常见顺序是先访谈把选项摸全，再出问卷。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 引导性提问：「你是不是觉得做饭太麻烦？」 | 答案藏在问题里，对方顺着你说 | 「上一次想做饭最后没做，是怎么回事？」 |
| 问未来假设：「如果有晚饭订阅服务，你会用吗？」 | 对未来的「会」几乎都偏乐观，只有过去的行为算证据 | 「你现在怎么解决？为这件事花过什么钱和时间？」 |
| 问观点：「你觉得外卖健康吗？」 | 观点不等于行为 | 「上周点的几次外卖，分别点了什么？」 |
| 问一般情况：「你一般怎么……」 | 说「一般」时，人会描述理想中的自己 | 「上一次……」 |
| 一题两问：「在哪吃、和谁吃？」 | 对方通常只答后一半 | 拆成两题 |
| 对方说不好用时去解释功能 | 你的任务是记录，不是说服 | 照录原话，不辩解 |
| 对方停顿时抢着补词 | 最后录下的是你自己的话 | 停三秒再接 |
| 满篇「是不是」「有没有」 | 封闭提问只能得到是或否 | 用「怎么」「什么」「哪一次」开头 |
| 你说话超过全场两成（经验值） | 对方就只剩附和 | 少说，多追问 |
| 约熟人、约「理论上会用」的人 | 熟人照顾你的面子；没做过的人只能猜 | 约最近三个月真做过这件事的人，先问筛选题 |
| 专家访谈问网上查得到的事 | 浪费对方时间，也问不出案例 | 先读完他公开写过、讲过的东西 |
| 提纲写满两倍的问题 | 主线过半就超时，每题都问不透 | 宁可少问，超时先砍 P1 |

## 边界与不做什么

- 不用于招聘面试、新闻采访、调查取证或绩效谈话，这些各有规则，分别找 HR、编辑或律师。
- 录音录像必须事先征得同意；论文或课题访谈要不要伦理审批与书面知情同意，以学校规定为准，问导师。
- 涉及心理创伤、疾病、违法经历或未成年人的访谈，需要受过训练的研究者主持；对方情绪明显波动就停下，必要时建议其联系专业人员。
- 专家访谈不打探对方单位的未公开信息，对方说「不方便讲」就换题。
- 记录只写编号与角色，不存姓名电话；原始录音按事先说好的用途与期限处理。
