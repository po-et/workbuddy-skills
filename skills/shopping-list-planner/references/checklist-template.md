# 可勾选模板、常备品主清单与核算脚本的输入格式

## 1 可勾选模板（超市八区）

复制到支持待办勾选的笔记或备忘录里即可点勾；要打印就把「- [ ]」换成「□」。搬家、露营把分区名换成 [scenarios.md](scenarios.md) 里的分组。

```
购物清单｜场景：____｜人数：__｜天数：__｜预算上限：____ 元｜状态：完整版
默认值（没问到、先按这个写的）：____ [待确认]
【1 日用百货】
- [ ] 物品 × 数量｜估价 __｜替代：____
【2 粮油干货调料】
- [ ]
【3 饮料零食】
- [ ]
【4 蔬果】
- [ ]
【5 肉禽水产】
- [ ]
【6 冷藏乳品】
- [ ]
【7 冷冻】
- [ ]
【8 鸡蛋面包等易碎】
- [ ]
合计 __ 元｜上限 __ 元｜机动一成 __ 元｜余量 __ 元

分工（多人采购时）：谁买哪一区｜谁垫付｜怎么结
下次补货（拆开最后一个时写在这里）：____
```

## 2 常备品主清单

把家里常买的二三十样按上面的分区写成一张固定表贴在冰箱上，每周只勾「缺」和「快用完」的，比每次从零想起省事，也最不容易重复买。买完把小票上的实际金额填回清单，下次估价就有数了。

```
常备品主清单（每周勾一次）
分区 ｜ 物品 ｜ 常买量 ｜ 上次实付 ｜ 本周：缺 / 快用完 / 有
```

## 3 核算脚本的输入格式

清单超过十来项、要对照预算时，把清单写成 CSV，交给 `scripts/list_total.py` 排动线、算合计、列可砍的候选：

```
分区,物品,数量,估价,类型,库存,替代
日用百货,垃圾袋,1 卷,12,必需,快用完,
肉禽水产,鲜鱼,1 条,45,必需,缺,冷冻鱼
饮料零食,薯片,2 袋,16,想要,缺,
粮油干货调料,生抽,1 瓶,,必需,有,
```

- 必填列只有「分区」「物品」；估价写这一行的总价，不知道就留空，输出标 [待补]，脚本不替你编价格。
- 「类型」写必需或想要，留空按必需；「库存」写缺、快用完或有，「有」的自动划进「家里已有」。
- 分区写超市八区的名字（也认「调料」「零食」「易碎」这类简称），按动线排序；搬家、露营的自定义分组按首次出现的顺序排在后面。
