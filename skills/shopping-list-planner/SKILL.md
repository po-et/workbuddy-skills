# 购物清单

定位一句话：**好清单不在写得全，在三件事做对：先看家里有什么、按店里怎么走来排、每一项都落在预算里。**
适用：每周买菜补货、搬家前后添置、第一次露营、给宝宝备用品、在家办聚会。

## 先判断：五个问题问清再写

1. 场景与时长：哪一类，管几天。
2. 人数与限制：几个大人几个小孩；忌口、过敏、婴儿月龄——过敏与喂养听医生的，这里只照着列。
3. 预算上限：一个总数，再标出哪几项绝对不能省。
4. 在哪买：大超市、菜市场、便利店还是网上下单，决定动线怎么排；网上下单再问一句送货要多久，生鲜隔天才到就先在附近买两天的量。
5. 能存多少：冰箱多大、有没有冷冻空间，决定一次买几天的量。

缺哪个问哪个；没给预算就只列物品和数量，不替用户编预算，也不编价格。

## 流程：五步出清单

```
第 1 步 套骨架：从下面五个场景里取一套，删掉用不上的，补上家里的特殊需求
第 2 步 盘库存：写之前先看，冰箱冷冻、橱柜调料干货、日用品柜三处各看一眼，
  每项标「缺」「快用完」「有」，「有」的直接划掉；快过期的食材先排进本周菜单
  出门前给冰箱和调料柜各拍一张照片，在店里拿不准「家里有没有」就翻照片
  长期办法：同类东西只放一处；新买的放后面、旧的挪到前面；
  每类日用品只留一个备用，拆开最后一个时当场记进清单
第 3 步 定数量：周采买按菜单倒推，先定五顿晚饭吃什么，再拆成食材和份量；
  聚会按人数，饮品按第一小时每人两杯、之后每小时一杯估（经验值，天热上调），一次性餐具多备两成
  肉类买回来按一顿的量分装冷冻，吃一袋化一袋，量才好估
第 4 步 定预算：每项写估价，不知道就标「待填」，合计和上限比，留一成机动别排满；超了按这个顺序砍：
  先砍「想要」→ 换替代品 → 减数量 → 最后才动「必需」
  单价高的项旁边写一个替代品：当季代反季、大包装代小包装（用得完才算省）、借或租代买、一物多用
  多人分摊的（聚会、露营），清单末尾加一栏：谁买哪一区、谁垫付、怎么结
第 5 步 排动线：按店里的走法分区，不按想到的顺序写
  超市：日用百货 → 粮油干货调料 → 饮料零食 → 蔬果 → 肉禽水产 → 冷藏乳品 → 冷冻 → 鸡蛋面包
  重的先拿垫底，冷的最后拿，易碎的放最上；第一次按常去那家的实际顺序改一遍，以后照用
  菜市场：先绕一圈看新鲜度和价钱，再从干货调料买起，肉和水产最后买
  网上下单也按这几个分区一次下完；为凑满减加的东西，只能从清单里挑
```

## 五个场景的骨架

```
周采买：蔬果／肉蛋奶／主食粮油／调料／早餐／零食饮料／日用清洁（纸、洗洁精、垃圾袋）
  叶菜只买前三四天的量，后几天排根茎类、蛋和冷冻食材；早餐按人头乘天数算
搬家：分三批，别一次买齐
  打包期：纸箱、胶带、记号笔、气泡膜、收纳袋、美工刀
  搬家当天：垃圾袋、抹布、手套、纸巾、饮用水、充电器；证件和合同单独装一个袋随身带
  入住首晚：先保证睡得下、洗得了——床品、毛巾、牙刷、拖鞋、卫生纸；进门先把插座和灯试一遍，坏的记进首周清单
  入住首周：插线板、灯泡、清洁用品、晾衣架、门垫、基础调料与锅具；窗帘、柜子、床垫量好尺寸再买
露营：住（帐篷、防潮垫、睡袋）／吃（炉具与燃料、饮用水、好做的食物、垃圾袋）／
  穿（保暖层、雨具）／照明（头灯、营地灯、备用电池）／安全（急救包、驱蚊、防晒、充电宝）
  睡袋、防潮垫、头灯按人头各一份；水按每人每天 3–4 升估（经验值，含做饭；营地没有饮用水就全部自带）
  第一次露营大件先租或借，去过两三次再决定买；出发前在家把帐篷搭一遍，缺零件还来得及补
  帐篷里不用炉具和炭火，有一氧化碳中毒风险
宝宝用品：喂养／睡眠／洗护／换尿布／衣物／出行
  按月龄分批：出生前只备头一个月要用的，其余满月后看实际需要再买
  小号尿布和新生儿衣服少买，长得快；衣物、绘本、玩具可以用亲友旧物或二手
  安全座椅不买二手，无法确认是否经历过碰撞
  奶粉、辅食、护肤品与药品的选择听儿科医生的，清单只留「数量」和「待医生确认」两栏
聚会：主食与菜／饮品与冰块／一次性餐具与纸巾／垃圾袋／开瓶器与剪刀／装饰与游戏
  家常聚餐菜的道数按人数加一估（经验值）；邀请时顺便问忌口和过敏
  冰块、垃圾袋、开瓶器是最常被忘的三样
```

## 可勾选模板与示例

复制到支持待办勾选的笔记或备忘录里即可点勾；要打印就把「- [ ]」换成「□」。搬家、露营把分区名换成骨架里的分组。

- [ ]

- [ ]

- [ ]

- [ ]

- [ ]
【7 冷冻】
- [ ]

```

常备品主清单：把家里常买的二三十样按上面的分区写成一张固定表贴在冰箱上，每周只勾「缺」和「快用完」的，比每次从零想起省事，也最不容易重复买。买完把小票上的实际金额填回清单，下次估价就有数了。

```

## 最常见的错误

```
不看库存就写：家里还有两瓶酱油又买一瓶——写之前盘一次，出门前再对一次
按想到的顺序写：在店里来回跑还漏买——按动线分区写
只有总预算：超了不知道砍哪个——每项估价，分「必需」和「想要」
为满减凑单：不在清单上的东西，买了不算省钱
促销囤货过量：囤的量超过保质期内用得完的量，等于提前扔钱
大件不量就买：窗帘、柜子、床垫，搬进去量过再买
一次买齐：搬家、露营、宝宝用品都分批，先买第一批，用过再补
临时起意多拿：清单外的东西先放回去，真需要就记进下一张清单
写得太细：精确到牌子和规格，到店缺货就卡住——写品类和用量，现场按替代品换
```

## 输出契约

1. 先问清五个问题；缺预算就只列物品和数量，不编价格。
2. 清单按动线分区，每项带数量，单价高的附一个替代品，末尾给合计与余量。
3. 用可勾选格式输出，并单列「家里已有、已划掉」的项，方便出门前再核一次。
4. 估价只填用户给的数，否则标「待填」，不引用任何店铺或平台的价格。
5. 多人一起采购时按动线分区分工，每人负责一段。

## 边界与不做什么

- 不推荐具体品牌、型号、店铺或购物平台，不比价、不下单、不代付，不索要任何支付信息。
- 食物过敏、婴幼儿喂养、特殊饮食与家庭常备药，按医生或药师的意见办，本技能只把他们的要求照着列进清单。
- 野外露营的路线、天气与安全规定不在这里，以营地和当地管理规定为准；高风险户外活动找有资质的领队。
- 不判断商品真伪与质量，不处理退换货与消费纠纷；遇到纠纷先找商家，再找当地消费者权益保护部门。
