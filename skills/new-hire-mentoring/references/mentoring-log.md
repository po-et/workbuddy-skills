# 带教记录：模板、样例与摘证据

回到 [SKILL.md](../SKILL.md)。记录当场写，一次五分钟。写转正评价时从记录里摘证据，不凭印象。

## 模板

```
带教记录  新人：[小王]  带教人：[ ]  入职日：[ ]  第[ ]周  [日期]
本周完成：[任务]——[结果]——[有无返工，原因]
卡点：[ ]        带教人支持：[示范／资料／引荐了谁]
反馈：认可[行为＋影响]；改进[行为＋影响＋建议]
下周约定：[任务]  [完成标准]  [检查时间]
阶段对照：30/60/90 目标进度[正常／偏慢／超前]，依据：[ ]
```

## 填好的样例（虚构）

```
带教记录  新人：小王  带教人：老张  入职日：2026-10-08  第3周  2026-10-23
本周完成：周报数据整理——按时交付——返工 1 次，原因：复制了上周的数据行
卡点：不知道数据要核对哪几项        带教人支持：给了上周正确的周报作样例、三条自查清单
反馈：认可「评审前把口径说明发给了李经理，会上没有再争论口径」；
      改进「周四的周报把上周数据复制错了行，李经理发现后重做了一遍；下次交之前按自查清单过一遍，先发我复核」
下周约定：周报数据整理  自查清单三项全勾  周四下午我复核
阶段对照：30 天目标进度正常，依据：标准流程已独立跑通一次，练手任务完成 2 个
```

## 按转正标准摘证据

转正标准以本单位书面文件为准。摘证据时每条都要能回到某一周的记录，不写记录里没有的事：

| 转正标准条目（照抄原文） | 证据（记录第几周） | 产出或结果 |
|---|---|---|
| [待补：标准第 1 条原文] | 第 3、5、8 周 | [独立完成的任务与交付物] |
| [待补：标准第 2 条原文] | 第 6 周 | [返工次数的变化，按记录如实写] |
| [待补：标准第 3 条原文] | 第 10–12 周 | [给下一位新人讲清的流程] |

只整理证据，不写「建议转正 / 不予转正」——结论由单位按制度下。

## 没有脚本时的节点日期一行版

第一个日期是入职日，第二个是第一次正式一对一的日期（入职日算第 1 天，每七天一次共十三次）：

```bash
python3 -c "import datetime as d,sys;s,o=(d.date.fromisoformat(x) for x in sys.argv[1:3]);f=lambda x:'%s 周%s'%(x,'一二三四五六日'[x.weekday()]);[print('第%d次一对一'%w,f(o+d.timedelta(weeks=w-1))) for w in range(1,14)];[print('第%d天节点'%n,f(s+d.timedelta(days=n-1))) for n in (30,60,90)]" 2026-10-08 2026-10-09
```
