# 主持词

定位一句话：**主持词不是文章，是念给耳朵听的时间表——每一段都要说清多长、讲完谁上场、出了意外怎么接。**
何时用：年会、婚礼、发布会、班会、颁奖典礼、线上会议要写主持稿或串词，或者要把一张流程单变成能直接念的稿子时。

## 先判断：动笔前要到手的五样东西

| 要什么 | 为什么、要到什么程度 |
|---|---|
| 流程单 | 每个环节谁上、做什么、几分钟、要什么（音乐、PPT、话筒、奖品）；没有就先按活动类型列一张给用户确认 |
| 基调 | 喜庆、温情、庄重、专业、轻松，定一个，全场统一 |
| 人数 | 单主持还是双主持；双主持每句标 A 或 B，轮流说，别一人念一大段 |
| 名单 | 嘉宾姓名、职务、介绍顺序、赞助商全称，以主办方书面确认为准；生僻字标拼音 |
| 时长 | 活动总时长和主持人自己说话的时间分开算，主持词只占其中一小段 |

## 时长换算：每分钟约 220 字

| 段落 | 建议时长 | 字数（按每分钟 220 字） |
|---|---|---|
| 开场白 | 1–2 分钟 | 220–440 字 |
| 每次串场 | 20–40 秒 | 70–150 字 |
| 互动说明 | 30–60 秒 | 110–220 字（互动本身另算） |
| 收尾 | 约 1 分钟 | 约 220 字 |
| 备用段落 | 每段约 30 秒 | 约 110 字，备 2–3 段 |

220 字是正常语速的估算；庄重场合、掌声多的环节会更慢，最后以主持人自己掐表试读一遍为准。稿子存成 script.txt，一行命令算字数和分钟：

```bash
python3 -c "import re,sys;t=open(sys.argv[1],encoding='utf-8').read();n=len(re.findall(r'[\u4e00-\u9fff]',t));print(n,'字，约',round(n/220,1),'分钟')" script.txt
```

## 四段结构与六类活动要点

- **开场白**：问候 → 点题（活动名称与目的）→ 介绍嘉宾（按确认顺序）→ 宣布开始。
- **串场**：承上（对上一环节说一句具体的话）→ 启下（下一环节的看点）→ 请人（身份在前、姓名在后，名字落在句尾，给掌声留出口）。
- **互动**：一句话讲规则 → 主持人先示范 → 说明限时 → 备好没人响应时的台阶。
- **收尾**：一句回顾 → 按名单致谢 → 后续事项（合影、用餐、离场路线、资料领取）→ 宣布结束。

| 类型 | 基调 | 开场要点 | 串场与互动要点 | 收尾要点 |
|---|---|---|---|---|
| 年会 | 热闹、感谢 | 一句回顾全年，感谢全体同事 | 串词点出部门和人名；抽奖规则念两遍 | 祝福，合影或散场指引 |
| 婚礼 | 温情、庄重 | 介绍新人，感谢双方父母与来宾 | 仪式环节放慢；互动不拿新人隐私、酒量开玩笑 | 请新人敬酒，宣布开席 |
| 发布会 | 专业、简洁 | 发布主题、流程与总时长 | 嘉宾按「职务＋姓名」介绍；问答先报单位和姓名，一人一问 | 资料领取与采访安排 |
| 班会 | 亲切、有主题 | 主题由来，今天要解决什么 | 发言按顺序、计时，让每组都有机会 | 总结结论，布置任务 |
| 颁奖 | 庄重、有仪式感 | 奖项设置一句话 | 奖项 → 评选理由 → 停顿 → 获奖者 → 颁奖嘉宾 | 全体合影，感谢评委 |
| 线上会议 | 清晰、节奏快 | 确认声音画面，讲静音规则、提问方式、是否录制 | 点名发言，聊天区收问题；每个议题结束说一句小结 | 行动项与负责人，会后材料去哪看 |

三句示范，照着这个颗粒度写：

```
【年会串场】刚才市场部的合唱把全场都唱热了。下一个节目来自一群平时只和代码打交道的人——有请技术部带来舞蹈[节目名]！
（空串词对照：「感谢精彩表演，下面有请下一个节目。」——没承上、没看点、没人名）
【颁奖宣读】获得[年度新人奖]的是——（停两秒）——[市场部小王]！有请[颁奖嘉宾]上台颁奖。
【线上会议开场】各位好，我是主持人[小王]。先确认两件事：听得到我声音的请在聊天区扣 1；除发言人外请保持静音。本次会议会录制，共[60]分钟，最后[10]分钟集中问答。
```

## 冷场与超时的应对话术

| 情况 | 现场怎么接（方括号处替换） |
|---|---|
| 互动没人响应 | 「看来大家都在等第一位勇士——[事先打过招呼的同事]，就请您先来！」 |
| 设备出故障 | 「技术同事正在调试，趁这一两分钟，我先考大家一个小问题：[备用问答]。」 |
| 嘉宾没到位 | 「[嘉宾]正在赶来，我们先把[下一环节]提前。」再念一段备用段落 |
| 念错名字 | 立即更正一次，不解释、不开玩笑：「更正一下，是[正确姓名]，抱歉。」 |
| 发言人超时 | 事先约好举牌「还剩 2 分钟」「请收尾」；仍不停就接话：「感谢[李总]的精彩分享，时间关系，更多问题我们会后再交流。」 |
| 整体超时 | 先删主持人自己的串词和可选互动，不压缩颁奖、仪式这类核心环节 |
| 时间富余 | 启用备用互动或备用段落，不临场即兴拖长 |

## 可直接填空的模板

```
【开场 · 约 1 分钟 ≈ 220 字】
A：尊敬的[各位领导、来宾]，亲爱的[同事/同学/朋友]们，大家[下午好]！
B：欢迎来到[活动名称]。我是主持人[姓名]。  A：我是主持人[姓名]。
A：[一句点题：今天为什么聚在这里]。
B：出席今天活动的有[职务＋姓名，按确认顺序]，让我们以热烈的掌声表示欢迎！
A：现在我宣布，[活动名称]正式开始！（由领导宣布的，改为「有请[职务＋姓名]宣布开幕」）

【串场 · 每次约 30 秒 ≈ 110 字】
A：刚才[上一环节]让我们[具体亮点]。  B：接下来的[下一环节]，[一句看点]。有请[身份＋姓名]！

【互动 · 说明约 1 分钟】
规则是[一句话]。我先示范一遍：[示范]。限时[N]分钟。（无人响应时请[暖场人]先来）

【收尾 · 约 1 分钟】
A：[一句回顾]。  B：感谢[按名单致谢]。
A：[后续事项：合影、用餐、离场路线]。  B：[活动名称]到此圆满结束，祝大家[祝福语]！

【备用段落 · 每段约 30 秒】
1. [活动或单位的小知识]  2. [现场小问答]  3. [下一环节预告]
```

单主持时去掉 A、B 标记，合并成一人口吻。

## 输出契约

1. 先要流程单和名单；没有流程单就先按活动类型列一张给用户确认，再写词。
2. 交付：按流程顺序的主持词，每段标预计时长与字数；2–3 段备用段落；冷场与超时话术卡，可打印成手卡。
3. 姓名、职务、奖项、赞助商一律用 [ ] 占位或照用户给的原文，不编。
4. 交付前自查五条：一句话能不能一口气念完，超过 20 字就拆；嘉宾姓名职务是否与名单逐字一致；每段是否标了时长；串词有没有只写「下面有请下一个节目」这种空话；玩笑有没有拿人开涮。

## 边界与不做什么

- 不编造嘉宾信息、获奖名单、领导讲话内容和数据。
- 不写低俗段子，不拿隐私、身材、地域、宗教或政治话题开玩笑，也不设计整蛊式互动。
- 发布会里涉及产品参数、价格、功效和合规表述的句子，以主办方法务或公关审定稿为准。
- 大型活动的安全、应急疏散、舞台与音视频技术，不在本技能范围，找活动执行方和场地方。
- 婚礼流程与地方习俗，以双方家庭和婚庆团队的安排为准。
