# 可直接填空的模板（双主持）

整份复制，方括号逐个替换；替换不了的保留方括号，交付前一眼能看出还缺什么。每段标题里的时长会被 `scripts/host_timer.py` 自动拿来对照。

```
【开场 · 约 1 分钟 ≈ 220 字】
A：尊敬的[各位领导、来宾]，亲爱的[同事/同学/朋友]们，大家[下午好]！
B：欢迎来到[活动名称]。我是主持人[姓名]。  A：我是主持人[姓名]。
A：[一句点题：今天为什么聚在这里]。
B：出席今天活动的有[职务＋姓名，按确认顺序]，让我们以热烈的掌声表示欢迎！
A：现在我宣布，[活动名称]正式开始！（由领导宣布的，改为「有请[职务＋姓名]宣布开幕」）

【串场 · 每次约 30 秒 ≈ 110 字】
A：刚才[上一环节]让我们[具体亮点]。  B：接下来的[下一环节]，[一句看点]。有请[身份＋姓名]！

【互动 · 说明约 1 分钟】
规则是[一句话]。我先示范一遍：[示范]。限时[N]分钟。（无人响应时请[暖场人]先来）

【收尾 · 约 1 分钟】
A：[一句回顾]。  B：感谢[按名单致谢]。
A：[后续事项：合影、用餐、离场路线]。  B：[活动名称]到此圆满结束，祝大家[祝福语]！

【备用段落 · 每段约 30 秒】
1. [活动或单位的小知识]  2. [现场小问答]  3. [下一环节预告]
```

单主持时去掉 A、B 标记，合并成一人口吻。

## 按活动类型改哪几句

开场那句点题、串场里必须有的东西、收尾的后续事项，六类活动（年会、婚礼、发布会、班会、颁奖、线上会议）各不相同，按 SKILL.md「四段结构与六类活动要点」那张表改；基调全场统一。

## 写完之后

```bash
python3 scripts/host_timer.py script.txt --total 8:00
```

它会列出每段字数和时长、超出标注的段落、两个停顿之间超过 20 字的长句、「下面有请下一个节目」这类空串词，以及还没替换的方括号占位。
