# 班会策划

定位一句话：**一场好班会 = 一个会后能检验的目标 + 至少一个人人开口或动手的环节 + 一样带得走的产出（公约、清单、计划卡）。** 45 分钟里，讲的时间不超过一半。

## 何时使用

- 「辅导员让我们开一次主题班会，帮我出方案」
- 「开学第一次班会流程怎么排」
- 「防诈骗、安全教育班会怎么开得不无聊」
- 「心理健康班会想做互动，又怕尴尬」
- 「班会主持稿怎么写」
- 「班会开完要交总结和照片」

不适用（遇到时这样处理）：

- 某位同学正处在心理危机（说过想伤害自己、联系不上）：这不是班会能处理的。立即告诉辅导员、联系学校心理中心，紧急情况拨打 120 或 110；本技能只给转介步骤（见「安全与心理类主题的边界」）。
- 迎新晚会、大型文艺演出：涉及节目、舞台、预算，超出本技能；可以借用这里的分工表和倒排时间表。
- 中小学班会课：流程框架可以借用，但选题、时长和安全要求以学校和班主任的安排为准。

## 第 1 步：选题，写一个能检验的目标

目标句式：**会后，每位同学能 [说出 / 写下 / 拿到] [具体的东西]。** 例：「会后每人能说出 3 种常见诈骗话术和对应做法」。

| 选题 | 适合时间 | 目标示例 | 推荐环节 | 注意 |
|---|---|---|---|---|
| 开学 | 开学第 1–3 周 | 每人记住至少 5 个同学的名字；共同定出 5 条班级公约 | 破冰、公约共创 | 别开成班委训话会 |
| 安全 | 开学初、长假前 | 每人能说出 3 种常见诈骗话术和应对 | 案例拆解、情景演练、快问快答 | 不恐吓，不嘲笑受骗的人 |
| 心理健康 | 10 月（10 月 10 日世界精神卫生日前后）、5 月（「5·25」大学生心理健康日前后） | 每人知道学校心理中心在哪、怎么预约；学会 1 个放松方法 | 匿名提问、放松练习、求助渠道介绍 | 不做测评，不要求公开自我暴露 |
| 学风 | 期中、期末前 | 每人写下本学期 1 个学习目标和第一步 | 学长学姐经验分享、学习小组组建 | 不公开成绩排名 |
| 节日 | 中秋、国庆、元旦前 | 全班完成一件共同作品 | 手作、猜灯谜、祝福墙 | 照顾不同民族习俗、宗教信仰和经济条件 |
| 毕业 | 毕业前一学期 | 留一份集体纪念 + 离校事项清单 | 写给未来的信、回顾视频、离校清单 | 不强迫分享去向和收入 |

选题前先问辅导员三件事：学院有没有规定主题、要不要交方案和总结、有没有经费或场地支持（以学院通知为准）。

## 第 2 步：45 分钟标准流程

| 时间 | 环节 | 做什么 | 负责人 |
|---|---|---|---|
| 0–3 分 | 开场 | 问好，说主题、目标和流程 | 主持人 |
| 3–8 分 | 导入 | 一个问题、一段不超过 3 分钟的短视频，或一个现场举手小调查 | 主持人 |
| 8–20 分 | 主体一：输入 | 分享、案例拆解或讲解 | 主讲人 |
| 20–35 分 | 主体二：互动 | 分组讨论、演练或共创 | 各组组长 |
| 35–42 分 | 产出 | 各组汇报，形成公约、清单或计划卡 | 主持人、记录员 |
| 42–45 分 | 收尾 | 回扣目标；辅导员讲话（事先约好时长）；签到合影 | 班长 |

三条规矩：讲的时间不超过一半；每个环节都有负责人；视频和辅导员讲话提前约好时长。

改时长或环节时，输入各环节分钟数，算出每段起止并核对合计：

```bash
python3 -c "import sys;m=[float(x) for x in sys.argv[1:]];s=0
for i,x in enumerate(m,1):print(f'环节{i}：{s:g}–{s+x:g} 分');s+=x
print('合计',f'{s:g}','分钟')" 3 5 12 15 7 3
```

## 第 3 步：主持稿框架

开场白（问候 + 主题 + 目标 + 流程，约 1 分钟）→ 串词（上一环节小结一句 + 下一环节引入一句）→ 互动引导（做什么、多久、产出什么，说清再开始）→ 冷场救场（先给思考时间，再改成组内先说）→ 结束语（回扣目标 + 一个会后行动 + 感谢）。

```
[开场] 大家晚上好，我是今天的主持人[姓名]。今天班会的主题是「[主题]」。开完后，希望每个人都能[目标]。流程是[环节一]、[环节二]、[环节三]，一共 45 分钟，[几点几分]准时结束。
[串词] 刚才我们[上一环节小结]。接下来是[下一环节]，有请[负责人]。
[互动引导] 接下来 [N] 分钟，每组[做什么]，最后每组派一人用 1 分钟说[产出]。计时开始。
[结束] 今天我们[回扣目标]。请大家[一个会后行动]。感谢[负责人们]的准备，散会前请[签到 / 合影]。
```

通用主持稿全文、串词库和冷场救场句见 [references/host-script.md](references/host-script.md)。

## 第 4 步：选 1–2 个互动形式

| 形式 | 适合选题 | 时长 | 要点 |
|---|---|---|---|
| 名字接龙、兴趣连连看 | 开学 | 10–15 分 | 人多就分组做 |
| 便利贴共创（写 → 归类 → 投票） | 开学公约、学风 | 15 分 | 每人至少写一张，可以匿名 |
| 情景演练 | 安全 | 15 分 | 剧本提前写好，「骗子」由班委来演 |
| 快问快答 | 安全、节日 | 10 分 | 题目取自学校或公安机关的宣传材料 |
| 匿名提问 | 心理、学风 | 10 分 | 只收问题和建议，不收个人经历；先由心理委员和辅导员私下过目 |
| 写给未来的信 | 开学、毕业 | 10 分 | 自己保存或由班委封存，不当众朗读 |

每种形式的步骤、物料和翻车预案见 [references/interactions.md](references/interactions.md)。

## 第 5 步：物料与分工

倒排时间：会前 7 天定题定目标并报辅导员 → 会前 5 天借教室（流程以学院规定为准）→ 会前 3 天定稿 PPT 和主持稿 → 会前 1 天彩排、试设备 → 当天提前 20 分钟到场。

| 角色 | 负责 |
|---|---|
| 班长 | 总负责，对接辅导员，控制总时长 |
| 团支书 | 主题把关，会后总结与存档 |
| 主持人 | 主持稿、现场节奏 |
| 宣传委员 | PPT、海报、拍照 |
| 学习委员或心理委员 | 按主题负责内容；心理类必须有心理委员参与 |
| 生活委员 | 场地、物料、班费开支记录 |

物料：教室和投影、转接头、话筒、签到表、便利贴和马克笔、计时器、奖品（用班费的要公开账目）、设备坏了时用的纸质流程单。完整清单与分工表模板见 [references/materials-and-summary.md](references/materials-and-summary.md)。

## 第 6 步：会后总结与存档

48 小时内完成：

- 总结 300–500 字：时间地点、到会人数、目标、流程、效果（用产出物证明）、不足与改进。
- 照片 3–5 张：拍前说一声，不想出镜的同学拍背影或不拍。
- 附件：签到表、产出物（公约、清单）、PPT。
- 存档命名：`YYYYMMDD_主题班会_主题`，放班级共享文件夹；要上传学院系统的，以辅导员通知为准。

总结模板见 [references/materials-and-summary.md](references/materials-and-summary.md)。

## 安全与心理类主题的边界

安全类：

- 案例用真实但隐去个人信息的，请辅导员或学校保卫部门提供；不讲具体的作案手法细节。
- 不嘲笑受骗者；反复强调「被骗了马上报警（110），第一时间告诉辅导员，不丢人」。
- 反诈知识以学校和当地公安机关发布的宣传材料为准。

心理健康类：

- 不做心理测评或筛查，量表只能由学校心理中心的专业人员组织。
- 不要求公开自我暴露（例如「说说你最难过的经历」），每个环节都允许说「我先听」。
- 不做诊断、不贴标签，不拿班里任何一位同学举例。
- 心理委员和辅导员在场；有条件就请心理中心老师来讲 10 分钟。
- 结尾一定给出求助渠道：学校心理中心的位置、电话、预约方式（以本校公布为准）。
- 危机个案：活动中、纸条里或会后发现有人表达伤害自己的想法，或正处在危险中——不在班会上公开讨论；不答应「替你保密」；立即告诉辅导员，由辅导员联系学校心理中心；情况紧急时拨打 120 或 110，并有人陪着当事人，直到专业人员接手。班委不自己做心理咨询。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息（只说「帮我策划个班会」） | 先问 3 个：主题（或辅导员的要求）、人数、时长；其余默认 45 分钟、教室、标准分工，标 [待确认] | 「先告诉我三件事：什么主题、多少人、开多久。其余我先按 45 分钟教室版排，标 [待确认] 的你再改。」 |
| 时长和环节对不上（30 分钟排 4 个互动；时间表合计不等于总时长） | 算出差多少，给两个方案：删环节或延长时间 | 「这几个环节加起来要 60 分钟，比 30 分钟多一倍。两个办法：保留[互动 A]、删掉[B 和 C]；或者申请延长到 60 分钟。」 |
| 主题太大太空（「开一个关于人生的班会」） | 收窄成可检验的目标，给两个方向让用户选 | 「『人生』45 分钟讲不完。可以收窄成[大学四年规划：每人写下第一学期目标]，或[时间管理：每人做一张周计划]，选哪个？」 |
| 要求做心理测评、让同学当众讲伤心事、在班会上讨论某位同学 | 拒绝这部分，给替代方案；坚持也不改 | 「测评和当众讲伤心事容易伤人，班委也没有资格做。换成匿名提问 + 请心理中心老师答疑，更安全也更有用。」 |
| 有同学正处在危机中（说想伤害自己） | 先放下策划，给转介步骤 | 「这件事比班会重要：现在就告诉辅导员、联系学校心理中心；有紧急危险就拨打 120 或 110，并有人陪着他。」 |
| 时间紧（明天就开，今晚要方案） | 最小可用版：一句目标 + 45 分钟时间表 + 开场白和结束语 + 1 个互动 | 「来不及做完整版，先给最小版：目标、时间表、开头结尾两段话、一个互动，其余会后补。」 |
| 要求在总结里编数据（「写全员参与、满意度 98%」） | 不编，只写真实到会人数和产出物 | 「总结里写真实数字更站得住：到会[N]人，产出[公约 5 条]。没做满意度调查就不写满意度。」 |
| 超出范围（晚会、跨班级大型活动） | 借用分工表和倒排时间表，建议另找活动策划类技能 | 「晚会要管节目和舞台，超出班会策划了。分工表和倒排时间表可以直接借用。」 |

## 输出契约

交付物按以下固定顺序给出。用户只要其中一部分时，只给那部分，顺序与占位规则不变：

1. 方案卡：主题、目标（一句能检验的话）、对象与人数、时间地点、时长；缺的写 [待确认]。
2. 流程时间表：各环节起止与负责人；合计等于总时长。
3. 主持稿：开场、串词、互动引导、结束语。
4. 内容与互动规则：主体环节要讲的内容要点；互动做什么、多久、产出什么、需要的物料。
5. 分工与物料：角色表 + 物料清单 + 倒排时间。
6. 风险与预案：设备故障、冷场、超时；安全、心理类必须写求助渠道与危机转介步骤。
7. 会后总结模板：留空待填，不预填数字。

占位规则：用户没给的姓名、时间、地点写 [待补]；需要向辅导员或学校核实的（主题要求、场地流程、心理中心电话）写 [待确认]；不编造案例、人数和效果数据。

交付前自检（逐条答是/否）：

- [ ] 目标能在会后检验（用了「说出 / 写下 / 拿到」）？
- [ ] 时间表合计等于总时长（用上面的命令核对过）？
- [ ] 讲授时间不超过一半，至少有一个人人参与的环节？
- [ ] 每个环节都写了负责人？
- [ ] 安全、心理类方案写了求助渠道和危机转介步骤，且没有测评和当众自我暴露环节？
- [ ] 总结模板没有预填或编造的数字？

## 示例

示例（虚构）。用户：「下周三晚上 7 点开防诈骗班会，我们班 32 人，45 分钟，帮我出方案。」

助手先问一个问题：「辅导员或学校保卫处有没有近期真实的案例（隐去个人信息）？没有的话，我用通用情景，标 [待确认]。」用户：「暂时没有。」

交付（节选，结构完整）：

> **方案卡**：主题「别让第一笔生活费被骗走」｜目标：会后每人能说出 3 种常见诈骗话术和对应做法｜32 人｜下周三 19:00–19:45，[教室待确认]
>
> **时间表**：0–3 开场（主持人）｜3–8 导入：举手调查「开学以来收到过可疑消息的请举手」（主持人）｜8–20 三类话术拆解：冒充老师收费、刷单返利、冒充客服退款（宣传委员）｜20–35 情景演练：4 组各演一个情景，班委扮「骗子」（各组组长）｜35–42 各组说出「识别信号 + 正确做法」，汇总成防骗清单（主持人、记录员）｜42–45 收尾：辅导员讲 2 分钟 + 签到（班长）
>
> **风险与预案**：案例用通用情景，标 [待确认：请辅导员或保卫处提供近期真实案例]；强调「被骗了马上报警（110）、告诉辅导员」；投影用不了时，主持人口述三类话术，情景卡照常进行。
>
> **会后总结**：到会 [ ] 人；产出：防骗清单 [ ] 条；不足与改进：[ ]。

## 常见问题（FAQ）

**Q：大家不想参加、参加了也不说话，怎么办？**
A：主题连上同学眼下关心的事（开学初关心选课、社团、防骗）；让每个人都有事做，分组比全班点名更容易开口；准时开始、准时结束。

**Q：辅导员要讲话，时间怎么排？**
A：提前问好讲多久，一般放在收尾前；主持稿里写好引出语，时间表里给足这几分钟。

**Q：没有经费怎么办？**
A：便利贴、白纸、手机计时器就能开，奖品不是必需品。要花班费的，事先说明、事后公开账目。

**Q：线上班会怎么开？**
A：同样的流程，时长压到 30 分钟左右更好；互动改成在线文档共创或分组讨论。具体功能以所用会议软件的官方帮助为准。

**Q：心理健康班会能不能请同学分享自己抑郁的经历？**
A：不建议在班会上安排个人经历分享，容易给分享者和听的人都带来压力。改请心理中心老师来讲，或用公开的科普材料。

**Q：能不能直接帮我把通知发到班群？**
A：我只起草通知和方案，你确认后自己发。

**Q：班会总结要写多长？**
A：一般 300–500 字够用，以学院要求为准；用产出物说话，比形容词有用。

**Q：主持人紧张怎么办？**
A：主持稿按环节分页打印成大字卡片；串词只背第一句；开场前和主讲人对一遍时间点。

## 常见错误（反模式）

- 目标写「增强安全意识」→ 会后说不出成效 → 写成「会后每人能说出 3 种诈骗话术」。
- 45 分钟全程念 PPT → 没人听 → 讲的时间不超过一半，留一个人人参与的环节。
- 视频放 10 分钟 → 吃掉互动时间 → 剪到 3 分钟以内。
- 心理班会做测评、让人当众讲伤心事 → 可能伤人，班委也没有资格 → 匿名提问 + 专业老师答疑。
- 安全班会用恐吓图片、嘲笑受骗者 → 真被骗的同学更不敢说 → 强调「被骗了马上报警、告诉辅导员」。
- 环节没有负责人 → 现场互相推 → 每个环节写上名字。
- 会后不存档 → 期末评优、写总结时找不到材料 → 48 小时内归档总结、照片、签到表。
- 总结里编数据 → 一核对就穿帮 → 只写真实人数和产出物。

## 边界与不做什么

- 只做策划、起草和整理，不代发通知，不替辅导员审批。
- 不做心理测评、诊断或咨询；危机个案一律转介辅导员和学校心理中心，紧急情况拨打 120 或 110。
- 安全知识以学校保卫部门和当地公安机关发布的材料为准；不传播作案手法细节。
- 示例里的班级、人物都是虚构的；总结只写真实发生的人数和产出。
- 不讨论、不公开任何具体同学的隐私。
- 经费使用、场地借用的规定以学院和学校为准。
