# 主持稿：框架、通用全文、串词与救场

## 框架

1. 开场白（约 1 分钟）：问好 → 主题 → 目标（会后每人能……）→ 流程与结束时间。
2. 串词（每段 15–30 秒）：上一环节小结一句 → 下一环节名称和负责人。
3. 互动引导：做什么 → 多久 → 产出什么 → 计时开始。规则说完问一句「有问题吗」。
4. 冷场救场：先给 30 秒思考时间 → 改成小组内先说 → 主持人或班委先示范一个 → 最后才请人发言（只请愿意的，不点名批评）。
5. 超时处理：提前定好可以砍的环节（通常是第二个分享），不压缩产出环节。
6. 结束语（约 1 分钟）：回扣目标 → 一个会后行动 → 感谢 → 签到或合影。

## 通用主持稿（填空）

```
【开场】
大家晚上好！我是今天的主持人[姓名]。欢迎来到[班级]「[主题]」主题班会。
今天的目标是：[会后每人能……]。
流程分为[环节一]、[环节二]、[环节三]，一共[45]分钟，[几点几分]准时结束。
首先，[导入方式，例如：请开学以来收到过可疑消息的同学举一下手]。

【导入 → 主体一】
刚才[导入的小结，例如：将近一半的同学都举了手]。带着这个问题，我们请[主讲人]来[分享内容]。

【主体一 → 主体二】
谢谢[主讲人]。[一句话提炼刚才的要点]。接下来是互动环节：[规则]。[N]分钟，计时开始。

【主体二 → 产出】
时间到。请各组派一位同学，用 1 分钟说说你们的[产出]。[记录员]会把结论写在[黑板 / 共享文档]上。

【产出 → 收尾】
我们把大家的结论汇总成了[公约 / 清单 / 计划卡]。[如有：下面有请[辅导员]老师为我们讲几句。]

【结束】
今天我们[回扣目标]。请大家[会后行动，例如：今晚把计划卡拍照存进手机相册]。
感谢[负责人们]的准备，也谢谢每一位同学的参与。散会前请[签到 / 合影]。
```

## 串词库

- 「刚才大家说得很热烈，我们把这份热情带到下一个环节。」
- 「这些都是很具体的办法，[记录员]已经记下来了。」
- 「时间有限，还没说完的同学可以写在便利贴上，我们会一起收。」
- 「刚才是『知道』，接下来是『做到』。」

## 冷场救场

- 「大家先想 30 秒，想好的举手。」
- 「那先在组内说说，一会儿每组派一个代表。」
- 「我先抛个砖：……」
- 「没想好的同学也可以说『我同意谁的观点，因为……』。」

## 设备与意外

- 投影坏了：主持人口述流程，按纸质流程单继续；视频改为口述情景。
- 话筒坏了：请大家往前坐，分组环节照常。
- 严重超时：砍第二个分享，保留产出和收尾。

## 心理和安全类主题的额外话术

- 开场说明：「今天所有分享都是自愿的，不想说可以说『我先听』。」
- 结尾一定念出求助渠道：学校心理中心的位置、电话、预约方式（以本校公布为准）；遇到诈骗或危险拨打 110。
