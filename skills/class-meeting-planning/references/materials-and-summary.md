# 物料、分工、倒排时间与总结模板

## 倒排时间表

| 时间 | 事项 | 负责人 | 完成 |
|---|---|---|---|
| 会前 7 天 | 定主题和目标，报辅导员；确认学院有无主题和材料要求 | 班长、团支书 | [ ] |
| 会前 5 天 | 借教室（流程以学院规定为准）；邀请分享人或老师 | 生活委员、班长 | [ ] |
| 会前 3 天 | PPT、主持稿、情景卡或题目定稿 | 宣传委员、主持人 | [ ] |
| 会前 2 天 | 班群发通知（时间、地点、要带什么） | 班长 | [ ] |
| 会前 1 天 | 彩排一遍，试投影和话筒，打印签到表和纸质流程单 | 主持人、宣传委员 | [ ] |
| 当天 | 提前 20 分钟到场布置 | 全体班委 | [ ] |
| 会后 48 小时内 | 总结、照片、签到表、产出物归档 | 团支书 | [ ] |

## 通知模板（班群）

```
【主题班会通知】
主题：[主题]
时间：[日期] [开始]–[结束]（共 [N] 分钟）
地点：[教室]
请带：[手机 / 笔 / 无]
说明：[一句话说明这次班会能带走什么]
有事不能参加请提前向[班长]说明。
```

## 总结模板（300–500 字）

```
[班级]「[主题]」主题班会总结

一、基本情况：[日期] [时间]，[地点]，应到 [ ] 人，实到 [ ] 人。
二、目标：会后每位同学能[……]。
三、流程：[环节一]（[负责人]）→ [环节二] → [环节三]。
四、效果：[用产出物说明，例如：形成班级公约 5 条（见附件）；各组共整理出防骗识别信号 [ ] 条]。
五、不足与改进：[例如：互动环节超时 5 分钟，下次每组发言限时 1 分钟]。
附件：签到表、照片 [ ] 张、[公约 / 清单]、PPT。
```

填写规则：人数、条数只写真实的；没做的调查不写结果；照片只用同意出镜的同学。

## 存档

- 文件夹命名：`YYYYMMDD_主题班会_主题`。
- 放进班级共享文件夹，保留到本学年结束（或按学院要求）。
- 需要上传学院系统的，以辅导员通知为准。
