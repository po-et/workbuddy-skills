# 班级／连队军训总结：模板与写法

写给辅导员或学院看的集体总结，和个人心得是两种文体：用「我们」或「本班」的口吻，讲过程、成绩、不足和下一步，不抒情。篇幅按辅导员或学院的要求；没要求的，把六段写全、每段有数字或具体的人和事即可。

## 六段结构（顺序固定）

```
[学院][年级][班级]／[连队]军训总结

一、基本情况
[人数]名同学编入[连排]，训练从[开始日期]到[会操日期]，共[天数]天。[全程参训人数]；[见习或请假情况，只写人数和原因类别]。训练科目为[科目]。

二、训练过程与成绩
[分阶段写：前几天练什么、中间练什么、最后准备什么；每个阶段一个能说明进步的数字或变化。]
[会操名次、内务评比等结果，只写真实的。]

三、值得表扬的人和事
[2–3 个具体的人或宿舍：做了什么、持续多久。用「王同学」这样的称呼即可。]

四、不足
[1–3 条，具体到现象和次数，不写「个别同学纪律性不强」这种泛泛的话。]

五、感谢
[教官、辅导员、班助、后勤……每人一句，最好带一件具体的事。]

六、下一步
[把军训的作风用到班级建设：2–3 条可执行、可检查的做法；需要全班遵守的，写明怎么征求意见。]
```

## 写之前先收集的材料

| 要什么 | 找谁要 |
|---|---|
| 人数、天数、见习名单 | 班长或辅导员的点名记录 |
| 会操、内务评比结果 | 连队公布的结果 |
| 表扬的人和事 | 排长、宿舍长、同学推荐；写之前问本人愿不愿意被写进去 |
| 不足 | 考勤记录、教官讲评 |

## 注意

- 涉及伤病、见习、请假的同学：只写人数和原因类别（如「因伤病转为见习」），不写病名；点名表扬前先征得本人同意。
- 名次、评比结果照公布的写，不要把「连队第二」写成「全营第二」这类拔高。
- 「下一步」里需要全班遵守的规定（早读时间、内务互查），写成「试行＋征求意见」，不要替全班做决定。
