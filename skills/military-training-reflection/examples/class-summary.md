# 示例：班级军训总结

> 以下为示例：学院、班级、人物、数字与评比结果均为虚构，只演示班级总结的结构与写法，不能照抄。

## 对话

**用户**：我是班长，辅导员让交一份班级军训总结。

**助手**：按六段写，先把材料凑齐：
1. 班里多少人、编在哪个连排、训练起止日期？有没有见习或请假的同学（只要人数和原因类别）？
2. 会操、内务评比的结果（照公布的写）？
3. 想表扬哪两三个人或宿舍，他们做了什么？本人同意被写进去吗？
4. 这次军训暴露了哪些问题（迟到次数、动作问题、身体状况）？
5. 想感谢谁，各有一件什么事？军训之后班里打算怎么做？

**用户**：（逐条回答，内容见下方正文；王同学、赵同学和 312 宿舍都已同意被写进去。）

## 交付

信息行：班级总结｜篇幅 [待确认：辅导员有没有字数要求]｜交给辅导员

```
机电学院2026级3班军训总结

一、基本情况
本班38名同学编入军训三连二排，训练从9月8日开始，到9月21日会操结束，共14天。36人全程参训；2人因伤病持校医院证明转为见习，每天随队参加理论学习和后勤保障。训练科目为队列动作、军体拳和内务整理。

二、训练过程与成绩
前三天练站军姿和停止间转法，第一次站军姿有5人中途报告休息，第三天降到1人；第二周进入齐步、正步和军体拳训练；最后三天集中准备会操。会操中三连获全营第二名。内务评比中，本班6间宿舍有4间被评为“优秀内务宿舍”。

三、值得表扬的人和事
王同学右臂拉伤转为见习后，主动承担全排的打水和物资清点，14天没有断过一次；赵同学担任军体拳领操，每天午休后提前十分钟到操场，带动作不熟的同学复习；312宿舍连续10天内务检查满分，还把叠被子的步骤拍成一分钟的视频发到班级群里。

四、不足
第一周集合迟到共5人次，集中在早操；正步摆臂高度不统一，主要靠教官逐个纠正，同学之间互相提醒得少；训练后有同学没及时补水，出现过1次轻微中暑，经校医处理后当天恢复。

五、感谢
感谢张教官十四天的带训，会操前一晚他陪我们在宿舍楼下多练了半小时；感谢辅导员每天到训练场看望大家；感谢班助学姐帮忙联系校医院、分发防暑药品。

六、下一步
我们想把军训的作风留下来：一是早上7:20前到教室早读，先试行一个月，再由全班投票决定是否继续；二是各宿舍每周互查一次内务；三是班级活动沿用军训时的集合方式，由各宿舍长清点人数。
```

写法说明：
- 见习、中暑只写人数、原因类别和处理结果，不写病名、不点名。
- 「不足」每条都有次数或具体现象，辅导员能据此安排下一步。
- 「下一步」的早读是「试行＋投票」，没有替全班做决定。
