# 军训心得

定位一句话：**军训心得不是写「军训很苦、我很坚强」，而是写一个只有你经历过的瞬间，和它在你身上留下的一个具体变化。** 瞬间要真，变化要小而具体。

## 何时使用

- 「军训刚结束，老师让交一篇 800 字军训心得」
- 「帮我写军训感想，1500 字，不想写成套话」
- 「我是班长，要写一份连队（班级）军训总结」
- 「帮我看看这篇军训心得哪里太空」
- 「高一军训结束了，要交一篇感想」

不适用：
- 闭营式学生代表发言稿：要代表全体、按「念」的节奏写，结构不同。可以用第 1 步帮你挖素材，正文按发言稿写（学生干部竞选类发言转 `campaign-speech`）。
- 军事理论课论文、征文比赛：文体和评分要求不同，本技能不覆盖。
- 免训、请假、身体不适能不能训：以学校规定和校医意见为准，找辅导员。

## 写作流程

### 第 1 步：挖一个具体瞬间

先回答这五个问题，挑一个有「前后变化」的：
1. 哪一刻最想放弃？第几天、什么科目、身体什么感觉？
2. 谁帮过你，或者你帮过谁？说了什么、做了什么？
3. 教官说过的哪一句话你还记得？原话是什么？
4. 哪一刻觉得「值了」？（会操、拉歌、第一次踢齐正步……）
5. 军训前后，你有没有一个小习惯变了？（叠被子、早起、说话方式……）

检验标准：这个瞬间能不能「拍成一张照片」——时间、地点、动作、一个细节（声音、温度、身体的感觉）都有。

### 第 2 步：三段结构——经历 → 变化 → 以后

| 段 | 写什么 | 占比 |
|---|---|---|
| 经历 | 直接从那个瞬间开场，写清发生了什么；军训的天数、科目等基本情况放在后面一句带过 | 约 40% |
| 变化 | 这件事改变了你的什么：一个看法或一个习惯，用「以前我……，现在我……」写出对比 | 约 35% |
| 以后 | 把这个变化用到接下来的学习和生活里：一两件具体的打算，最好已经开始做了 | 约 25% |

### 第 3 步：按字数定篇幅（800 / 1500）

| 档位 | 经历 | 变化 | 以后 | 怎么写 |
|---|---|---|---|---|
| 800 字 | 约 320 | 约 280 | 约 200 | 一个瞬间、一个变化、一两件打算 |
| 1500 字 | 约 600 | 约 520 | 约 380 | 两个瞬间（一苦一暖）、变化写出前后对比、两件打算；可加一小段写教官或战友 |

字数以老师要求为准。「不少于」按不含标点的字数判断、「不超过」按含标点判断，两种口径下都达标最稳。

### 第 4 步：删套话

最常见的：「时光飞逝」「为期十四天的军训」「烈日炎炎」「汗水浸湿了衣衫」「苦并快乐着」「教官严厉而又和蔼」「我学会了坚持」「军训虽然结束了，但……」。这些句子放进谁的文章都成立，等于没写。替换思路只有一条：**换成只有你知道的细节。** 15 类套话与逐条替换思路见 [references/cliches.md](references/cliches.md)。

写完跑一遍自检（字数两种口径、开头是否落进套话、套话命中行号、分段）：

```bash
python3 scripts/cliche_check.py 军训心得.txt --tier 800
```

1500 字档用 `--tier 1500`；老师给了别的字数用 `--min-chars 1000 --max-chars 1200`；`--list` 只打印套话清单。支持 .txt、.md、.docx。

### 班级/连队总结版

集体口吻、写给辅导员或学院看，顺序固定：基本情况 → 训练过程与成绩 → 值得表扬的人和事 → 不足 → 感谢 → 下一步。人数、天数、名次只写真实的；表扬到具体的人，先问本人愿不愿意被写进去（尤其涉及伤病、见习）。模板见 [references/company-version.md](references/company-version.md)，完整示例见 [examples/class-summary.md](examples/class-summary.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 只说「帮我写一篇军训心得」，没给任何经历 | 先问 3 个：老师要求多少字、最记得的一个瞬间、军训后自己哪里变了；其余按「大学新生、800 字」默认并标 [待确认] | 「先回答三个问题：老师要求多少字？军训里你最记得的一个瞬间是什么（哪天、在练什么）？军训之后你自己有什么变化，哪怕很小？」 |
| 要求「随便编一个感人的故事」 | 不编；用追问把真实的瞬间挖出来 | 「编的故事写不出细节，老师一眼能看出来。你说说哪天最累、当时在练什么，我帮你把它写出来。」 |
| 要求自相矛盾（「800 字，写三个故事，每个都详细」） | 指出矛盾，给两种选择 | 「800 字写透一个瞬间刚好，写三个每个只能一两句。你要一个写透，还是改成 1500 字写两个？」 |
| 其实要闭营式发言稿或军事理论课论文 | 超出范围，说明差别 | 「这个技能写个人心得和班级总结。发言稿要代表全体、按念的节奏写，我可以帮你挖素材，正文结构请按发言稿来。」 |
| 马上要交，只要能交的版本 | 只问一个问题：最记得的一个瞬间。按 800 字三段直接写；变化和以后两段里替用户推断的句子，在素材出处表里标 [待确认] | 「来不及就先告诉我一个瞬间，我按 800 字写完；标了 [待确认] 的句子你看一眼，不符合就删。」 |
| 要求照抄示例或网上范文交作业 | 守住边界 | 「示例是虚构的，照交既不是你的经历，也容易和别人撞车。给我一个你的瞬间，很快就能写完。」 |

脚本报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 1「参数 --tier：不在可选范围内」 | `--tier` 只接受 800 或 1500 | 其他字数用 `--min-chars`／`--max-chars` |
| 1「--tier 与 --min-chars/--max-chars 只能二选一」 | 两种方式同时给了 | 保留一种 |
| 1「--min-chars 不能大于 --max-chars」 | 区间写反了 | 调换两个数 |
| 1「没有可检查的文字」 | 空文件，或只有标题 | 确认文件里有正文 |
| 2「文件问题：……」 | 路径不对、没权限、PDF 或旧版 .doc、编码无法识别 | 另存为 .txt（UTF-8）或 .docx |
| 130 | 按了 Ctrl+C | 重新运行即可 |

## 输出契约

交付物按以下顺序：

1. **信息行**：类型（个人心得／班级总结）｜字数档位｜老师的特殊要求（手写、固定标题等，缺的标 [待确认]）
2. **标题**：老师要求用什么标题就用什么；没要求的，用一个具体的短句
3. **正文**：经历 → 变化 → 以后（班级总结版按它的六段）
4. **素材出处**：正文每个细节 → 对应的用户原话；替用户推断的感想标 [待确认]
5. **自检结果**：字数（含／不含标点）、套话命中数、开头是否通过

占位符：用户必须补的写 `[待补：补什么]`；替用户假设或推断的写 `[待确认：……]`。有占位符时，交付第一句就提醒。

交付前自检（逐条答「是」才交）：
- 第一段就进入一个具体瞬间（有时间、动作、细节）
- 每个细节都能在素材出处里找到用户原话，推断的句子已标 [待确认]
- 有一处「以前……，现在……」式的具体变化
- 字数达到档位要求（下限按不含标点计）
- 套话命中为 0，或保留的每一处后面都接了具体细节
- 占位符和 [待确认] 已在交付第一句提醒

## 示例

以下为示例，人物（「我」、小周）与全部经历均为虚构。

**用户**：军训刚结束，辅导员让交一篇军训心得，800 字。我是大一的。

**助手**：先问三个问题：① 军训里你最记得的一个瞬间？哪天、在练什么、身体什么感觉？② 那一刻有没有谁说了什么、做了什么？③ 军训之后，你自己有没有哪里变了，哪怕很小？

**用户**：第五天下午两点半站军姿，教官说站四十分钟。二十多分钟腿开始抖，从小腿抖到膝盖，汗流进眼睛辣得睁不开，也不敢擦，特别想打报告。旁边的室友小周小声说「再撑两分钟」，我就一段一段撑下来了。我以前干什么都三分钟热度，高中买的吉他学了两周手指疼就不练了，总觉得自己坚持不下来，现在觉得撑过最难的那几分钟就行。会操我们连拿了第二名。

**助手**：再补几个细节就够写了：① 那四十分钟你靠什么分散注意力？② 小周平时和你是什么关系，休息时说了什么？③ 会操前后印象最深的画面？④ 军训后给自己定了什么具体的事，做了多久？

**用户**：我在数教官走过去的脚步声，数到几十下就乱了。小周是第一天晚上教我叠被子的，我的被子软塌塌的，他教我先压实、再用手掌压出棱角，第二天内务检查我们宿舍满分。休息时他递给我一瓶水，说他也快撑不住了。高一我还想每天背单词，坚持了五天。现在遇到想放弃的，会先问自己能不能再撑两分钟；最后几天练正步小腿一直疼，也没请假。会操前一晚我们在宿舍楼下多练了半小时正步，会操那天走过主席台，全连脚步声是齐的。现在每天六点半跑两公里，坚持一周了，有两天想赖床，就跟自己说先跑两分钟，跑起来就不想停了。高数每天做五道题，不会的先别翻答案，再想两分钟，第一周作业都是自己做完的。我把「再撑两分钟」写在了高数笔记本第一页。

**助手**（交付）：标了 [待确认] 的三句是我根据你的话推断的感想，不符合就删。

信息行：个人心得｜800 字档｜[待确认：老师有没有指定标题、要不要手写]

> **撑过那两分钟**
>
> 第五天下午两点半，我们开始练站军姿，教官说这一轮站四十分钟。站到二十多分钟，我的腿开始抖，先是小腿，后来连膝盖也跟着晃。汗顺着额头流进眼睛，辣得睁不开，可手贴着裤缝，不敢抬起来擦。为了分散注意力，我开始数教官从队伍前走过的脚步声，数到几十下，数字就乱了。那一刻，我只想举手打报告。
>
> 就在这时，站在我旁边的室友小周用很小的声音说了一句：“再撑两分钟。”小周就是军训第一天晚上教我叠被子的人，那天我的被子怎么叠都是软塌塌的一团，是他教我先把被子压实，再用手掌一点一点压出棱角，第二天内务检查，我们宿舍拿了满分。我不知道两分钟以后会怎样，只是决定先撑这两分钟。两分钟过去了，我又对自己说了一遍“再撑两分钟”。就这样一段一段地撑，直到教官喊“休息”，我才发现自己站完了全程。休息的时候，小周递给我一瓶水，说他其实也快撑不住了。原来那句话，一半是说给我听，一半是说给他自己听的。
>
> 以前的我，做什么都是三分钟热度。高中时我买了一把吉他，学了两个星期，按弦按得手指疼，就把它放进了柜子，再也没拿出来；高一下决心每天背单词，只坚持了五天。我一直觉得自己是个“坚持不下来的人”。那天下午让我换了一个想法：坚持不是一口气撑完四十分钟，而是撑过最难的那两分钟，再撑下一个两分钟。难的从来不是整件事，而是最想放弃的那几分钟。现在遇到想放弃的事，我会先问自己一句：能不能再撑两分钟？军训最后几天练正步，我的小腿一直在疼，也没有请一天假，就是这样一段一段练下来的。
>
> 会操前一天晚上，我们在宿舍楼下又多练了半小时正步。会操那天，我们连正步走过主席台，我听见全连的脚步声落在同一个点上，最后拿了第二名。站在队伍里，我又想起小周那句“再撑两分钟”。原来一个连的整齐，也是这样一段一段练出来的。
>
> 军训结束后，我给自己定了两件事。第一，每天早上六点半跑步两公里，到今天已经坚持了一个星期。有两天特别想赖床，我就对自己说“先跑两分钟”，跑起来也就不想停了。第二，高数每天做五道题，遇到做不出来的题，不急着翻答案，先给自己两分钟再想一遍。开学第一周的高数作业，我都是自己做完的。我把“再撑两分钟”写在了高数笔记本的第一页。大学里一定还会有很多想举手打报告的时刻，到那时，我想对自己说一句：再撑两分钟。

素材出处：全部细节来自用户两轮回答；以下三句为推断，标 [待确认]——「一半是说给我听，一半是说给他自己听的」「站在队伍里，我又想起小周那句」「原来一个连的整齐，也是这样一段一段练出来的」。

自检结果：不含标点 819 字、含标点 925 字，800 字档达标；开头通过；套话 0 处；正文 5 段（经历 2 段、变化 2 段、以后 1 段）。

## 常见问题（FAQ）

**我的军训很平淡，没有感人的事怎么办？** 不需要感人，需要具体。叠不好的被子、磨破的脚后跟、拉歌时嗓子喊哑，都是好瞬间。

**可以写教官吗？** 可以，但写他做过的一件事、说过的一句原话，不要只写「严厉而又和蔼」。

**字数不够怎么补？** 不要堆形容词。补细节（当时在想什么、周围的声音），或把「以后」写得更具体；1500 字档可以加第二个瞬间。

**能引用名言吗？** 全文最多一句，而且后面要接你自己的事。

**老师规定了标题（比如就叫「军训心得」）怎么办？** 按老师的来，可以在正文第一句用你的瞬间抓人。

**班级总结和个人心得能用同一篇吗？** 不能。个人心得写「我」的一个瞬间；班级总结写集体的过程、成绩、不足和下一步，口吻和结构都不同。

**可以直接交示例吗？** 不行。示例是虚构的，老师也可能看到同一篇。

## 常见错误（反模式）

- 开头「时光飞逝，为期十四天的军训结束了」→ 前两行没有任何信息 → 直接从一个瞬间写起。
- 通篇形容天气和汗水（烈日炎炎、汗流浃背）→ 人人都这么写 → 写只有你注意到的细节。
- 感悟直接下结论（学会了坚持、懂得了团结）→ 没有证据 → 写「以前我……，现在我……」的具体变化。
- 名句连用三四句 → 像在凑字数 → 最多一句，接你自己的事。
- 结尾「军训虽然结束了，但它将永远留在我心中」→ 空 → 结尾写一件已经开始做的具体的事。
- 编一个感人故事 → 细节经不起问，也不是你的心得 → 写你真实的小事。
- 把班级总结写成个人抒情 → 辅导员要的是过程、成绩、不足和下一步 → 按总结版六段写。

## 边界与不做什么

- 只帮你整理和表达**你自己的真实经历**：会追问具体细节；不编造经历、感人事件、成绩、名次或任何数据。替你推断的感想一律标 [待确认]。示例中的人物与内容均为虚构，不能当作你的经历使用。
- 不教怎么规避查重，不帮你把别人的文章改写成「自己的」。
- 班级总结里涉及同学的伤病、请假等情况，写之前先征得本人同意，只写必要信息。
- 免训、请假、训练强度与身体状况相关的问题，以学校规定和校医意见为准。
