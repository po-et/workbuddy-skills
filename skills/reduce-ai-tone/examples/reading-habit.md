# 完整示例：公众号初稿「重」档改写（阅读习惯）

> 示例。作者的情况（三个月没读完书、通勤四十分钟、试过飞行模式等）都由示例中的用户提供；前后数字是 `scripts/ai_tone_check.py` 的实际输出。

## 1. 用户原话

> 公众号初稿一堆「值得注意的是」「总而言之」，帮我改自然点

## 2. 助手先问（四件事）

1. 发在哪、写给谁？读完希望读者做什么？
2. 有没有一段你自己以前写的文字，或者平时的聊天记录？我照着你的用词和句子长短改。
3. 这篇想讲的事，你自己有没有经历？最近一次是什么时候、什么情形？能给几个数吗？
4. 改写强度：轻（只删套话）、中（再换细节、调句长）、重（按你的口吻重写，可以调结构）选哪档？

## 3. 用户补充

> 个人公众号，写给跟我一样刷手机停不下来的年轻人，希望他们也试试。旧文风格是短句、第一人称。我自己就是：三个月没读完一本书，每天通勤四十分钟全刷了短视频；上周想重读一本以前很喜欢的小说，翻了二十页就去看手机，前后看了六次。后来上地铁就开飞行模式、只带纸书，第一天读了八页，第四天读了三十多页，这周读完了一本。能坚持多久不知道。选「重」。

原稿（draft.txt）：

```
在当今信息爆炸的时代，阅读习惯正在发生深刻的变化。随着短视频的普及，越来越多的人习惯了碎片化的信息获取方式。值得注意的是，这种变化既带来了机遇，也带来了挑战。

一方面，碎片化阅读让知识获取更加便捷、高效、灵活；另一方面，它也在一定程度上削弱了人们深度思考的能力。研究表明，长期碎片化阅读会导致注意力下降。

**核心观点：** 阅读不是一种消遣，而是一种能力。我们要以更开放的心态、更坚定的信念、更务实的行动，重建深度阅读的习惯。

总而言之，深度阅读至关重要。让我们携手并进，共同开创全民阅读的美好未来！
```

## 4. 交付物

**① 改写强度**：重。按作者口吻重写，结构从「议论文」改成「一件自己的事」；第一人称、短句，全篇口语亲近一档。

**② 改写稿全文**（revised.txt）

```
我已经三个月没读完一本书了。每天通勤有四十分钟，全刷了短视频。

上周想重读一本以前很喜欢的小说，翻了二十页就去看手机，前后看了六次。我开始怀疑自己是不是读不进长东西了。

后来试了个笨办法：上地铁就把手机调成飞行模式，只带纸书。第一天读了八页，第四天读了三十多页。

能坚持多久我不知道。但这周，我读完了一本。
```

**④ 【待补】清单**：没有必补项（细节都来自作者）。可选：读完的那本书的书名，写出来更具体。
