# 秋招

定位一句话：**秋招管好三件事——节奏（什么时候投什么）、证据（每段经历都经得起追问）、决策（offer 按你自己的权重比）。本技能只帮你整理你自己的真实经历和信息，不编经历、奖项和数据。**

## 何时使用

用户这样说时用本技能：

- 「秋招才开始准备，还来得及吗？帮我排个投递计划」
- 「投了三十多家，状态乱了，给我一个记录表」
- 「网申开放题『最有成就感的一件事』怎么写」
- 「下周群面／技术面／HR 面，怎么准备」
- 「手上两个 offer，帮我比一比」
- 「三方签了还能违约吗？有人收费内推靠谱吗？」

不适用（遇到时这样处理）：

- 简历从零写或逐句润色：本技能只给网申用的简历自查要点；整份改写转交简历类技能。
- 考公、选调生、教师招聘、考研：节奏和规则不同，一句话说明「以对应主管部门或学校公告为准」，建议找学校就业指导中心或对应技能。
- 劳动合同、违约金是否有效、欠薪等法律定性：不下结论，转学校就业指导中心、劳动人事争议仲裁委员会或律师。

## 1. 常见节奏（常见节奏，以各公司公告为准）

| 阶段 | 常见时间 | 这时候做什么 |
|---|---|---|
| 提前批 | 暑期前后开启，互联网公司较多 | 投最想去、准备最充分的；先看清结果是否影响正式批 |
| 正式批 | 9–10 月最集中 | 主力投递；网申、测评、笔试、面试并行 |
| 补录 | 11–12 月零星开放，次年春招继续 | 盯公司官网和学校就业信息网，补录不等于降档 |

国企、银行、事业单位的节奏常与互联网公司不同，笔试多为统一时间。每家的开放与截止日期、可投志愿数、提前批结果是否影响正式批，**以该公司当年公告为准**，不要凭往年经验或传言。

## 2. 投递节奏与记录表

- 分三档投：冲刺（很想去、把握小）、主投（匹配度高）、保底（能接受、把握大），比例可先按 2:5:3，再按进展调整。
- 每周固定两个时段集中投递；每天固定一次查看邮箱、短信和官网状态，测评和笔试链接常有时限。
- 记录表最少 8 列：`公司 | 岗位 | 批次 | 渠道 | 投递日期 | 截止/下一步日期 | 状态 | 备注`。状态只用固定词：已投、测评、笔试、一面、二面、HR面、offer、未通过、放弃。

完整表头、状态流转规则和每周复盘模板见 [references/tracker-and-materials.md](references/tracker-and-materials.md)。

## 3. 网申材料

- 简历：一页；每条经历写「做了什么 + 怎么做 + 结果」，数字只写你拿得出证据的。
- 开放题：一题一个真实经历，按「情境—任务—行动—结果—与岗位的关系」写，字数用到上限的八九成。
- 测评：性格测评按真实情况作答、前后一致；行测类要限时练。
- 附件：成绩单、证书、作品集提前扫描，按「姓名-学校-材料名」命名；提交前截图留存。

开放题常见题型写法与简历自查清单见 [references/tracker-and-materials.md](references/tracker-and-materials.md)。

## 4. 笔试与面试

| 环节 | 常见形式 | 怎么准备 |
|---|---|---|
| 笔试 | 行测类、专业题（编程、案例、专业知识）、英语、性格测评 | 按目标岗位找对应题型限时练；在线笔试提前测设备和网络，按考试须知布置环境 |
| 群面 | 读材料 → 个人陈述 → 自由讨论 → 总结汇报 | 先对齐题目要求和时间分配；推动出结论比抢角色重要 |
| 专业面 | 项目深挖、基础知识、现场题 | 每段经历准备「追问五层」：为什么做、你负责哪块、最难在哪、数据怎么来的、重来会怎么做 |
| HR 面 | 动机、稳定性、城市、期望薪资、其他 offer | 期望薪资给有依据的区间；其他 offer 如实说，不编造 |

每场面试当天写复盘：被问了什么、哪里卡住、下次怎么答。群面角色、专业面追问清单、HR 面高频问题、反问清单和复盘表见 [references/tests-and-interviews.md](references/tests-and-interviews.md)。

## 5. offer 比较与决策

先把每个 offer 的**书面**条件填进 CSV（offer 上没写的向 HR 书面确认，别猜），再让脚本按**你给的权重**打分：

```bash
python3 scripts/offer_compare.py --template > offers.csv      # 表头 + 两行以 # 开头的示例（会被跳过）
python3 scripts/offer_compare.py offers.csv --weights "现金=4,公积金=1,通勤=2,成长=3,兴趣=2"
python3 scripts/offer_compare.py offers.csv --weights "现金=3,成长=3,城市=2" --out result.md
```

- 必填列：`公司,城市,税前月薪,月数,公积金比例,单程通勤分钟,成长自评,兴趣自评`；可选列：`公积金基数`（不填按税前月薪算）、`城市自评`（1–5，把生活成本、户口、离家远近折算进去）。
- 口径：年度现金 = 税前月薪 × 月数，**不算个税，只做相对比较**；公积金按单位与个人同比例估算；现金和公积金按「占最高者的比例」打分；通勤按单程 120 分钟记 0 分线性折算；自评 1–5 分折成 0–1。输出排名、各项得分、敏感性检查（每项权重提高或降低一半，第一名变不变）和全部假设。
- 分数只帮你看清取舍。最后问自己三个问题：三年后想成为什么样的人？哪个 offer 的风险你承受不起？如果分数反过来，你会失望吗？

## 6. 三方协议与违约金（通用常识）

- 三方协议通常由毕业生、用人单位、学校三方签署，用于办理就业手续、登记就业信息；它和入职后签的**劳动合同是两份不同的文件**。纸质还是网签、一人几份、怎么解约，**以学校就业指导中心的规定为准**。
- 违约金：数额和条件以协议文本为准；HR 口头说的「不收违约金」「给落户」，写进协议备注栏才算数。
- 签前核对：岗位、工作地点、薪资结构（月薪、月数、试用期薪资）、违约金、户口或编制承诺、报到时间、没拿到毕业证时怎么处理。
- 想违约：先书面联系原单位，按约定处理违约金，拿到解约函或退函（叫法和形式以学校要求为准），再按学校流程办解约；办完再签下一家。
- 纠纷：先找学校就业指导中心协调；入职后的劳动争议可向当地劳动人事争议仲裁委员会申请仲裁；拿不准性质的，咨询律师或当地法律援助机构。本技能不判断条款是否有效。

签约前核对表、解约沟通邮件模板见 [references/tripartite-and-scams.md](references/tripartite-and-scams.md)。

## 7. 求职防骗

看到任何一条先停下核实：

- **收费内推、交钱保 offer**：正规内推由在职员工推荐，不向求职者收费。
- **培训贷**：「先培训后上岗」，让你签分期或贷款付培训费。
- **押金**：以服装费、体检费、保证金、资料费等名义收钱，或扣身份证原件。《劳动合同法》规定，用人单位招用劳动者不得扣押身份证等证件，不得要求劳动者提供担保或者以其他名义收取财物。
- 其他信号：薪资远高于同类岗位却几乎没门槛；只用私人社交账号沟通；面试地点不在公司；索要银行卡密码或验证码；让你刷单、垫付。

核实：到公司官网招聘页、官方公众号或学校就业信息网核对岗位；在国家企业信用信息公示系统查企业主体；看邮件发件域名是不是公司官方域名。已付钱或泄露信息的：保留聊天和转账记录，立即报警（110），同时告诉学校就业指导中心。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（岗位方向、城市、进度） | 先问最影响方案的 1–3 项；其余按常见情况给默认，交付物里标 [待确认] | 「先确认三件事：投什么岗位、想去哪些城市、现在投了几家到哪一步？其余我先按常见节奏排，标了待确认。」 |
| offer 条件缺项（没写公积金比例、月数里含不含绩效说不清） | 能比的先比；缺的项向 HR 书面确认；急着要结果时，缺公积金这类次要项可把该项权重设 0 并注明「未比较」，缺月薪、月数这类核心项就先不出排名 | 「offer 上没写公积金比例，先问 HR；急的话这次公积金权重设 0，结果里我会注明这项没比。」 |
| 说法与数据矛盾（说最看重成长，权重却是现金最高） | 指出矛盾，给两种理解让用户选 | 「你说最看重成长，但权重里现金 4、成长 2。是按你说的把成长调到最高，还是以权重数字为准？」 |
| 超出本技能范围（劳动法定性、考公考编、简历全文改写） | 一句话说明边界，转交学校就业指导中心、仲裁机构、律师或对应技能 | 「违约金是否有效要看协议原文和具体情况，建议先问学校就业指导中心，必要时咨询律师。」 |
| 时间紧，只要最小可用版 | 投递：记录表 8 列 + 本周 3 个动作；面试：自我介绍 + 3 段经历的追问五层；offer：只比现金、成长、通勤三项 | 「先给你最小版：记录表和本周三件事，笔试面试的细节下次补。」 |
| 用户坚持越界（编实习经历、代考笔试、伪造 offer 去压价、付钱买内推） | 守住边界，给合规替代 | 「经历和 offer 我不能编，笔试也不能代考；可以帮你把真实经历写得更有说服力。」 |
| 已经被骗或已违约 | 先止损：保留证据、报警或联系原单位与就业指导中心 | 「先别再转账，保留聊天和转账记录，马上报警，并告诉学校就业指导中心。」 |

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 计算成功（可能附「需要你核对」提示） | 看完提示再用结果 |

## 输出契约

按用户要的东西，交付物各部分**按下表顺序**给出，不增不减：

| 用户要的 | 交付物（按顺序） |
|---|---|
| 投递计划 | ① 现状一句话 ② 到 11 月底的节奏表（标「以各公司公告为准」）③ 记录表表头与已知条目 ④ 本周 3 个动作 ⑤ 待补/待确认 |
| 网申开放题 | ① 题目原文与字数上限 ② 选用的真实经历（用户提供）③ 成稿 ④ 可能被追问的点 ⑤ 待补 |
| 笔试/面试准备 | ① 环节与形式（以通知为准）② 准备清单 ③ 模拟问题与回答要点 ④ 复盘表 ⑤ 待补 |
| offer 比较 | ① offer 信息表（注明书面/口头）② 权重 ③ 脚本输出 ④ 三个问题 ⑤ 签约前核对项 ⑥ 待确认 |
| 三方/防骗 | ① 情况一句话 ② 通用常识要点 ③ 核对或核实步骤 ④ 该找谁 ⑤ 待确认 |

占位符规则：用户没给的写 `[待补：……]`；按常见情况推断、需要用户核对的写 `[待确认：……]`；日期一律写「以各公司公告为准」；经历、数据、offer 条件只用用户给的。

交付前自检（逐条答「是」才交）：

- [ ] 批次和日期都标了「以各公司公告为准」，没有写死某家公司的日期？
- [ ] 经历、数字、奖项、offer 条件全部来自用户，没有补编？
- [ ] offer 比较用的是用户给的权重（或已注明等权默认），输出带着假设和「不算个税」？
- [ ] 涉及违约和劳动纠纷的，只给通用常识，并写明该找就业指导中心、仲裁机构还是律师？
- [ ] 待补/待确认逐条列出？

## 示例

示例（人名、公司均为虚构，对话发生在 9 月底）：

**用户**：手上两个 offer，帮我比一比。A 公司在上海，税前月薪 18000，15 薪，公积金 7%，通勤单程 50 分钟；B 公司在杭州，税前 16000，16 薪，公积金 12%，通勤 20 分钟。我更看重成长。

**助手**（先问）：两件事：成长和兴趣你各给几分（1–5）？现金、公积金、通勤、成长、兴趣五项权重怎么给，比如 3/1/2/4/2？

**用户**：A 成长 4 兴趣 3，B 成长 3 兴趣 4。权重就 3/1/2/4/2。

**助手**（运行 `python3 scripts/offer_compare.py offers.csv --weights "现金=3,公积金=1,通勤=2,成长=4,兴趣=2"`，摘录输出）：

```
| 排名 | 公司 | 城市 | 总分 | 年度现金（税前） | 公积金年额（估） | 单程通勤 | 成长 | 兴趣 |
| 1 | B公司 | 杭州 | 75.1 | 256,000 | 46,080 | 20 分钟 | 3 | 4 |
| 2 | A公司 | 上海 | 73.5 | 270,000 | 30,240 | 50 分钟 | 4 | 3 |
提示：前两名只差 1.6 分（不到 3 分），属于接近——别只看分数，回到三个问题再想一次。
敏感性检查：
- 「通勤」权重降低一半：第一名变成 A公司
- 「成长」权重提高一半：第一名变成 A公司
- 「兴趣」权重降低一半：第一名变成 A公司
```

**助手**（结论）：两个 offer 很接近，B 胜在公积金和通勤，A 胜在成长和年度现金。你说「更看重成长」，而成长权重只要再提高一半，A 就排第一——先确认你说的「更看重」到底有多重。签之前向两家书面确认：公积金基数、试用期薪资、违约金数额。待确认：两家的公积金缴存基数（脚本暂按税前月薪估算）。

## 常见问题（FAQ）

**Q：9 月底才开始，是不是来不及了？**
A：正式批通常还在进行，之后还有补录和春招。先把简历和记录表做好，本周集中投主投档；具体截止以各公司公告为准。

**Q：提前批挂了会影响正式批吗？**
A：各公司规定不同，以该公司招聘页的说明为准；页面没写就问官方招聘渠道。

**Q：能不能直接帮我投递、做测评或者代考笔试？**
A：不能。投递和测评要你本人操作，代考属于作弊；我可以帮你准备材料和练题思路。

**Q：offer 脚本为什么不算到手收入？**
A：个税和社保跟城市政策、个人情况有关，算不准反而误导；只做相对比较更稳。要算到手，请 HR 给出说明或按当地规定自己核算。

**Q：HR 催我三天内签三方怎么办？**
A：可以礼貌说明理由、请求延期，能否延期由公司决定；没看清违约金和书面条件之前不要匆忙签。

**Q：签了三方又拿到更好的 offer？**
A：先读三方里的违约条款，书面联系原单位、按约处理，拿到解约函后按学校流程办理；拿不准就问就业指导中心。

**Q：有人说交几百块「服务费」就能内推，正常吗？**
A：正规内推不向求职者收费，按高风险处理，不要付款。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 只投提前批大厂，不留主投和保底 | 一轮落空就断档 | 冲刺、主投、保底按 2:5:3 起步 |
| 海投不记录 | 错过测评和笔试时限，重复投递 | 8 列记录表，每天固定查一次状态 |
| 简历写「精通」「负责」却讲不出细节 | 专业面一追问就露馅 | 每段经历准备追问五层，只写能讲清楚的 |
| 群面抢 leader、打断别人 | 面试官看的是推动结论和协作 | 先对齐目标和时间，引用他人观点，推动收敛 |
| 期望薪资张口一个数，没有依据 | 报高了出局，报低了吃亏 | 给有依据的区间，说明依据 |
| 把口头承诺当真 | 事后无从对证 | 落户、签字费、违约金写进 offer 或协议备注 |
| offer 只看月薪 | 忽略月数、公积金、通勤和成长 | 用脚本按自己的权重比，再过三个问题 |
| 签了三方不报到、也不办解约 | 影响自己的就业手续，也伤学校与单位的合作 | 书面沟通、按约处理、按学校流程解约 |
| 为了内推交钱 | 高风险骗局 | 走官网和学校渠道，付费即停 |

## 边界与不做什么

- 不编造经历、奖项、数据、offer 条件；不代写代考笔试、不代做测评、不替你投递或签约。
- 不提供任何公司的内部信息，不预测录取结果。
- 不判断三方协议和劳动合同条款是否有效、违约金是否合理，交给学校就业指导中心、劳动人事争议仲裁委员会或律师。
- 不算个税和到手收入，不给投资理财建议。
- 各公司批次和日期以其官方公告为准；本技能写的节奏只是常见情况。
