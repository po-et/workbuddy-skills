# 三方协议、签约核对与求职防骗

本文件是 [SKILL.md](../SKILL.md) 第 6、7 节的展开。这里只写通用常识：协议怎么签、违约怎么办，**以协议文本和学校就业指导中心的规定为准**；条款是否有效、违约金是否合理属于法律问题，找学校就业指导中心、劳动人事争议仲裁委员会或律师。

## 1. 几份文件别混

| 文件 | 通常是什么 | 提醒 |
|---|---|---|
| 口头 offer / 面试通过通知 | 意向，条件未落到纸面 | 要求书面 offer |
| 书面 offer（录用通知） | 写明岗位、薪资、地点等条件 | 看清回复期限和附带条件 |
| 三方协议 | 毕业生、用人单位、学校三方签署，用于就业手续和就业信息登记 | 纸质还是网签、一人几份、怎么解约，以学校规定为准 |
| 劳动合同 | 入职时与单位签订 | 和三方协议是两份不同的文件 |

## 3. 想违约时的步骤

1. 读协议原文：违约金数额、适用条件、解约方式。
2. 书面联系原单位 HR（邮件模板见下），说明情况，询问解约流程和违约金处理方式。
3. 按约定处理违约金（如有），拿到解约函或退函（叫法和形式以学校要求为准）。
4. 到学校就业指导中心办理解约手续，按学校规定领取新的协议。
5. 以上办完，再和新单位签。

## 4. 邮件模板

**解约沟通**（模板，按实际改写）：

```
主题：关于[姓名]三方协议解约事宜的沟通

[HR 称呼]您好：
我是[学校][专业]的[姓名]，已于[日期]与贵公司签订三方协议，岗位为[岗位]。
经过慎重考虑，因[真实原因，一句话]，我希望与贵公司解除三方协议。给您和团队带来不便，非常抱歉。
想请教解约的具体流程，以及违约金的支付方式与解约函的办理方式。我会按协议约定配合办理。
感谢贵公司的认可与这段时间的帮助。

[姓名]  [手机]  [日期]
```

**签约前婉拒 offer**：

```
主题：[姓名]关于[岗位] offer 的回复

[HR 称呼]您好：
感谢贵公司给我[岗位]的 offer，也感谢面试中各位老师的时间。经过慎重考虑，我决定不接受这份 offer。
再次感谢，祝团队一切顺利。

[姓名]  [日期]
```

决定了就尽早回复，不要拖到期限最后一天，更不要不回复。

## 5. 求职防骗核实清单

| 信号 | 为什么可疑 | 怎么核实 / 怎么办 |
|---|---|---|
| 收费内推、交钱保 offer | 正规内推由在职员工推荐，不向求职者收费 | 走官网和学校渠道投递；要钱就停 |
| 先培训后上岗，要签分期或贷款 | 典型培训贷 | 不签任何贷款或分期合同，不提供身份证办贷款 |
| 服装费、体检费、保证金、押金，扣身份证原件 | 《劳动合同法》规定，用人单位招用劳动者不得扣押身份证等证件，不得要求劳动者提供担保或者以其他名义收取财物 | 拒绝付款；留证据 |
| 薪资远高于同类岗位、几乎没有门槛 | 常见诱饵 | 对照公司官网招聘页 |
| 只用私人社交账号联系，面试地点不在公司 | 无法核实身份 | 通过官方电话或官方邮箱反向核实 |
| 要银行卡密码、验证码，让刷单或垫付 | 诈骗 | 立即停止，任何情况下都不提供 |
| 邮件发件域名不是公司官方域名 | 可能冒充 HR | 对照公司官网公布的联系方式 |

核实企业主体：国家企业信用信息公示系统；核实岗位：公司官网招聘页、官方公众号、学校就业信息网。

已经付钱或泄露了信息：

1. 立即停止转账，不再按对方要求操作。
2. 保存聊天记录、转账凭证、对方账号和招聘链接截图。
3. 报警（110），并告诉学校就业指导中心和辅导员。
4. 泄露了银行卡或验证码的，马上联系发卡银行。
