# 笔试与面试准备

本文件是 [SKILL.md](../SKILL.md) 第 4 节的展开。各公司笔试和面试的具体形式、轮次、时长以其通知为准，下面是常见情况。

## 1. 笔试类型与准备

| 类型 | 常见内容 | 准备方法 |
|---|---|---|
| 行测类 | 言语理解、数量关系、判断推理、资料分析等 | 每天一套限时练，错题按题型归类；资料分析先练速算 |
| 技术岗专业题 | 编程题、计算机基础选择题（操作系统、网络、数据库等） | 按题型刷题并限时；「自己处理输入输出」和「只写函数」两种形式都要练 |
| 产品、运营 | 案例分析、数据分析、方案设计 | 练「拆问题 → 给指标 → 提方案 → 说风险」的答题结构 |
| 金融、财会等 | 专业知识 | 按岗位 JD 列知识点，结合专业课复习 |
| 设计类 | 命题设计、作品集 | 作品集按岗位挑 3–5 个最相关的项目，每个写清你的角色 |
| 英语 | 阅读、写作 | 限时做阅读，积累行业相关词汇 |
| 性格/职业测评 | 情境选择、自评量表 | 按真实情况答、前后一致，不要猜「标准答案」 |

在线笔试前一天的环境检查：

- [ ] 电脑电量和充电器；网络稳定，备用热点。
- [ ] 摄像头、麦克风、浏览器按考试须知要求准备好，提前做设备检测（如有）。
- [ ] 关闭消息通知和无关程序；单人安静房间。
- [ ] 身份证件放手边；草稿纸、计算器能不能用，按须知。
- [ ] 按须知要求提前登录。

诚信线：不代考、不找人远程协助、不传题。在线笔试普遍有监考，作弊一旦被认定，后果远比一场考试严重。

## 2. 群面（无领导小组讨论）

常见流程（以现场说明为准）：读材料 → 每人简短陈述观点 → 自由讨论 → 小组总结汇报。

- 角色：组织、计时、记录、总结汇报都能得分，不必抢 leader；没有角色也能靠有质量的发言得分。
- 开局 1 分钟：确认题目要求（要排序、要方案还是要结论）和时间分配。
- 发言句式：「我同意 A 的观点，补充一点……」「我们还剩 10 分钟，建议先把前三项定下来」「刚才有两种意见，差别在……，我们用 X 标准比一下？」
- 禁忌：打断别人、长时间沉默、坚持己见拖住进度、总结时只讲自己的观点。

## 3. 专业面：追问五层

每段写进简历的经历都按下表准备，答不出的那层就是要补的地方：

| 层 | 面试官常问 | 你要准备的 |
|---|---|---|
| 1 为什么 | 为什么做这件事？ | 背景和目标，一两句话 |
| 2 你做了什么 | 你具体负责哪块？ | 分清团队和个人贡献 |
| 3 最难在哪 | 遇到的最大困难？怎么解决的？ | 一个具体难点和解决过程 |
| 4 结果怎么来的 | 数据怎么算的？怎么验证？ | 数字来源和口径 |
| 5 重来会怎样 | 现在看有什么不足？重做怎么改？ | 真实的反思 |

基础知识：把目标岗位 JD 里的关键词逐个列出，每个准备「一句话解释 + 一个你用过的例子」。

## 4. HR 面高频问题

| 问题 | 思路 |
|---|---|
| 为什么选择我们 | 具体业务 + 你的经历 + 你想在这里做成什么 |
| 还投了哪些、手上有没有 offer | 如实说进展，可以不说公司名；不编造 offer 去抬价 |
| 期望薪资 | 给区间并说依据（公开的招聘信息、往届同学的真实情况）；以公司最终书面 offer 为准 |
| 能否接受调剂、外派、加班 | 如实说能接受的范围，别先答应再反悔 |
| 什么时候能到岗或来实习 | 结合毕业安排如实回答 |

反问清单（选 1–2 个）：这个岗位入职后前三个月主要做什么？团队的培养方式？新人怎么考核？后续流程和时间？（能在官网查到的别问。）

线上面试：按通知要求准备会议软件、昵称和环境；提前 10 分钟进入测试设备；背景干净、光线在正面。

## 6. 自我介绍（1 分钟版）

结构：我是谁（学校、专业）→ 与岗位最相关的一两段经历（各一句话 + 一个结果）→ 为什么想做这个岗位 → 结束语。写好后计时念三遍，控制在 60 秒左右；3 分钟版在经历部分展开，不加新话题。
