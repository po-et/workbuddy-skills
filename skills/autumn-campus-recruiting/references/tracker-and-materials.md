# 投递记录表与网申材料

本文件是 [SKILL.md](../SKILL.md) 第 2、3 节的展开：记录表完整版、状态流转、每周复盘，以及开放题写法和简历自查。

## 1. 投递记录表（完整版）

| 列名 | 填法 | 例 |
|---|---|---|
| 编号 | 按投递顺序 | 007 |
| 公司 | 全称，同一公司多岗位分行写 | 甲公司 |
| 岗位 | 照招聘页原文抄 | 用户运营管培生 |
| 档位 | 冲刺 / 主投 / 保底 | 主投 |
| 批次 | 提前批 / 正式批 / 补录 | 正式批 |
| 渠道 | 官网 / 宣讲会 / 内推码 / 学校就业信息网 | 官网 + 内推码 |
| 投递日期 | YYYY-MM-DD | 2026-09-28 |
| 截止日期 | 以该公司公告为准；没写就填「未写」 | 未写 |
| 下一步及日期 | 测评、笔试、面试及时间 | 测评，限 3 天内完成 |
| 状态 | 固定词：已投、测评、笔试、一面、二面、HR面、offer、未通过、放弃 | 测评 |
| 注册账号 | 用的哪个邮箱或手机号（**不要记密码**） | 常用邮箱 |
| 备注 / 复盘 | 被问到的问题、卡在哪、下次怎么改 | 开放题问了职业规划 |

规则：

- 状态只能往前走，或者落到「未通过」「放弃」；落到这两个时，在备注里写止步在哪一环、放弃的原因。
- 同一公司多个岗位，先看招聘页是否写明「只能投 N 个志愿」「投后能否修改」，以公司说明为准。
- 表格每天固定时间更新一次；测评和笔试链接常有时限，看到就排进日程。

看哪一环掉得最多，下周就补哪一环：

- 投了很多、很少进笔试：多半是简历或网申问题，先对照 JD 改简历关键词、重写开放题。
- 笔试多、面试少：笔试准备不够，按岗位题型限时练。
- 面试多、offer 少：看复盘表，找反复卡住的问题；专业面卡追问就补经历细节，HR 面卡动机就补公司研究。

## 3. 网申开放题写法

通用结构：情境（一句话）→ 任务（你要解决什么）→ 行动（你具体做了什么，占一半篇幅）→ 结果（能拿出证据的数字或事实）→ 与岗位的关系（一句话收尾）。

| 题型 | 要点 | 避免 |
|---|---|---|
| 为什么选择我们 / 这个岗位 | 说出你了解到的具体业务或产品，连到你的一段经历，再说你想在这个岗位做成什么 | 空泛夸公司「行业领先」 |
| 最有成就感 / 最大挑战的一件事 | 选和岗位能力相关的真实经历，写清你个人的行动 | 把团队成果写成个人成果 |
| 失败经历 | 真实的失败、你负的那部分责任、改了什么、后来怎么验证改好了 | 假失败（「我太追求完美」） |
| 职业规划 | 1–3 年写具体，和这个岗位的成长路径一致 | 在企业网申里说近期打算读研、考公 |
| 优势与不足 | 优势配证据；不足要真实、不致命，并写正在怎么改 | 把优点包装成缺点 |
| 团队合作 / 冲突 | 具体场景、你怎么沟通、结果如何 | 只说「我善于沟通」 |

字数：用到系统上限的八九成；先在文档里写好再粘贴，避免系统超时丢稿。

## 4. 简历自查清单（网申前逐条过）

- [ ] 一页；PDF；文件名「姓名-学校-岗位-简历.pdf」。
- [ ] 手机号、邮箱正确，邮箱名称正式。
- [ ] 教育背景：学校、专业、起止时间；成绩或排名有优势才写，写就写准确。
- [ ] 经历倒序；每条以动词开头，写「做了什么 + 怎么做 + 结果」。
- [ ] 每个数字都拿得出来源（报表、截图、证书、导师或主管能证实）。
- [ ] 技能写可验证的程度（熟悉、了解）；证书写全称和分数。
- [ ] 和目标岗位 JD 的关键词对得上，但不堆砌、不写做不到的。
- [ ] 通读两遍无错别字；请一位同学按「追问五层」问一遍。
