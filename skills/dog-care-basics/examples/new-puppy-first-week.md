# 示例：接狗前一周的准备

**示例**（情况为虚构；疫苗驱虫的具体时间一律由兽医定）

## 对话

用户：「下周接一只两个月大的柯基回家，现在要准备什么？」

助手：「先问三件事：
1. 住的地方允许养狗吗？家里有没有人过敏或怕狗？
2. 白天有人在家吗？每天大概能抽出多少时间遛、练、陪？
3. 原主人那边有没有疫苗驱虫记录，平时喂什么粮、一天几顿？」

用户：「自己的房子，小区允许。我和老公都不过敏，我在家办公。原主人说打过一针疫苗，记录本会一起给，粮是什么还没问。」

## 交付

**一句话结论**：接狗前四条判断都过了；这一周把东西备齐、把家里查一遍，再跟原主人要齐粮食和记录，接回来就按第一周安排走。

**你的情况**：两个月大，柯基，下周到家；自住，小区允许；在家办公；家人不过敏；已打一针疫苗（以记录本为准）。原来吃的狗粮和喂食量 [待补：问原主人]。

**接狗前清单**（勾选）：

- [ ] 吃：原来吃的那款狗粮 [待补：牌子和喂食量问原主人]、食盆、水盆
- [ ] 住：围栏或航空箱（当窝用）、垫子、尿垫、一件带家里气味的旧衣服
- [ ] 出门：胸背或项圈、牵引绳、写着联系电话的身份牌、拾便袋
- [ ] 训练：小颗粒零食（提前分装）、一个啃咬玩具、一个互动玩具
- [ ] 清洁：酶类除味清洁剂、梳子、指甲剪、毛巾（不用含氨的清洁剂）
- [ ] 资料：疫苗驱虫记录本、原主人的喂食量与作息、附近宠物医院和夜间急诊的地址电话 [待补]

**家居安全检查**：

- [ ] 电线收起或套管，充电器不留在地上
- [ ] 药品、清洁剂、杀虫剂、烟头放进高柜
- [ ] 巧克力、葡萄和葡萄干、洋葱大蒜、含木糖醇的口香糖、酒收好
- [ ] 垃圾桶加盖；阳台、窗户加防护，楼梯口加门栏
- [ ] 袜子、皮筋、玩具零件这类吞得下去的小东西收走

**第一周逐日安排**：

| 天 | 事项 | 备注 |
|---|---|---|
| 第 0 天 | 路上保持安静；到家先带去定点，再在小范围里自己探索 | 家人不围观、不轮流抱 |
| 第 1–2 天 | 按原来的时间喂原来的粮；醒后、饭后、玩后、睡前各带去定点一次 | 换粮至少七天渐进 |
| 第 3 天 | 认名字：一看你就给零食，每轮 5 次，一天几轮 | |
| 第 4 天 | 带上记录本做第一次体检，请兽医定后续疫苗驱虫时间 | 以兽医为准 |
| 第 5 天 | 练独处：你在家时让它在围栏里待几分钟，安静了再放出来 | 逐天加长 |
| 第 6 天 | 练触摸：摸耳朵、爪子、嘴边，每摸一下给一点零食 | 为剪指甲和看病打基础 |
| 第 7 天 | 看记录：哪个时段容易尿错、夜里醒几次 | 下周据此调整 |

夜里把围栏放在床边；半夜哭叫多半是要尿，安静抱去定点，尿完直接回窝。头一周先不洗澡。

**疫苗驱虫记录表**（以兽医为准）：

| 日期 | 项目 | 医院 | 下次时间 | 打完后的反应 |
|---|---|---|---|---|
| [待补：照记录本抄] | 第一针疫苗 | [待补] | 兽医确定 | [待补] |
| 第 4 天体检时 | 后续疫苗与驱虫计划 | [待补] | 兽医确定 | |

疫苗全部打完且兽医确认之前，不去狗多的公园和宠物聚集处。

**就医提醒**（以兽医为准）：呼吸困难、抽搐、误食有毒物或异物、站不起来等，立即去医院或夜间急诊；幼犬不吃不喝、反复呕吐或腹泻，当天联系兽医。去之前准备：症状开始时间、吃过什么、大小便照片、记录本。
