# 养狗

定位一句话：**新手养狗的头一个月，决定成败的不是狗粮多贵，而是三件事：家里安全、作息固定、做对了马上有奖励。**
何时用：准备接狗回家，刚接回来不知道第一周怎么过，要教定点、召回和社交化，想知道疫苗驱虫大概什么时候做、该问兽医什么，或者担心自己踩了新手误区时。凡是健康问题，最终都交给兽医判断。

## 接狗前：先判断，再备货

```
先判断（任何一条答不上来，先别接）
时间  每天能否固定抽出遛狗、训练、陪伴的时间；幼犬头几个月不宜整天独处
居住  房东、物业是否允许；养犬登记、限养犬种、牵绳规定以当地规定为准
预算  狗粮之外还有疫苗、驱虫、体检、绝育与意外就医，先问附近宠物医院的大致价格
家人  有没有人过敏或怕狗；谁主要负责；口令和规矩全家统一
```

```
备货清单
吃    原来吃的那款狗粮（先照原样喂）、食盆、水盆
住    围栏或航空箱（当窝用，不当惩罚）、垫子、尿垫、一件带家里气味的旧衣服
出门  胸背或项圈、牵引绳、写着联系电话的身份牌、拾便袋
训练  小颗粒零食（提前分装）、一个啃咬玩具、一个互动玩具
清洁  酶类除味清洁剂、梳子、指甲剪、毛巾；别用含氨的清洁剂，气味像尿，会把狗引回原处
资料  疫苗与驱虫记录、原主人的喂食量与作息、附近宠物医院和夜间急诊的地址电话
```

```
家居安全检查
[ ] 电线收起或套管，充电器不留在地上
[ ] 药品、清洁剂、杀虫剂、烟头放进高柜
[ ] 巧克力、葡萄和葡萄干、洋葱大蒜、含木糖醇的口香糖、酒收好——这些对狗有毒
[ ] 垃圾桶加盖；阳台、窗户加防护，楼梯口加门栏
[ ] 袜子、皮筋、玩具零件这类吞得下去的小东西收走
```

## 第一周与日常作息

```
第 0 天    路上保持安静；到家先带去定点，再让它在小范围里自己探索，家人不围观、不轮流抱
第 1–2 天  按原来的时间喂原来的粮；醒后、饭后、玩后、睡前各带去定点一次
第 3 天    认名字：叫名字，它一看你就给零食，每轮 5 次，一天几轮
第 4 天    带上疫苗驱虫记录做第一次体检，请兽医定后续疫苗驱虫时间
第 5 天    练独处：你在家时让它在围栏里待几分钟，安静了再放出来，逐天加长
第 6 天    练触摸：摸耳朵、爪子、嘴边，每摸一下给一点零食，为剪指甲和看病打基础
第 7 天    看记录：哪个时段容易尿错、夜里醒几次，下周据此调整
```

夜里把围栏放在床边；幼犬半夜哭叫多半是要尿，安静抱去定点，尿完直接回窝，不陪玩。头一周先别急着洗澡，脏了局部擦，什么时候能洗问兽医。

```
喂食与作息
顿数  幼犬少食多餐，一天三到四顿，随月龄逐步减到成犬的一天两顿，何时减问兽医
份量  从狗粮包装上的「体重—喂食量」表起步，再看体型微调：摸得到肋骨、从上往下看有腰身
换粮  至少七天渐进：新粮 1/4 → 1/2 → 3/4 → 全部，每档约两天；拉稀就退回上一档
定时  放下食盆约 15 分钟后收走，没吃完不追着喂；清水全天不断
零食  训练零食算进当天总量，大约不超过一成；熟骨头会碎裂，不喂
作息  幼犬大部分时间在睡，别总叫醒它玩；醒来先定点，再玩，再吃，再定点，再睡
运动  幼犬每次短、次数多，少跳高、少爬楼梯；成犬每天至少遛两次，时长看品种与体力
```

## 基础训练：定点、召回、社交化

总原则：每次 3–5 分钟，一天多次；做对了 3 秒内奖励；全家同一个口令；不打不骂。

```
定点（在哪上厕所）
1 固定一个点：室内用尿垫或围栏一角，户外选固定角落，每次都去同一处
2 抓时机：醒后、饭后 10–20 分钟、玩耍后、睡前；幼犬另外每 1–2 小时带去一次
3 一个口令：到了只说一个词，如「嘘嘘」；尿完 3 秒内夸奖加零食
4 看信号：原地转圈、低头猛嗅、突然走开，立刻带去定点
5 出错不罚：当场看到就轻声打断、带去定点；事后发现只清理。打骂和按头闻尿只会教它躲着你尿
6 记一张表：时间、地点、对错，一周后找规律
```

练了两三周毫无进展，或者突然尿频、尿里带血、排尿费劲，先带去看兽医，排除身体原因再谈训练。

```
召回（叫它就来）
1 室内低干扰：叫名字加「来」，语气愉快；它一动就夸，到脚边给最好吃的零食
2 加距离：隔一个房间叫；两个人对坐轮流叫，让它来回跑
3 加干扰：到户外先系 5–10 米的长牵引绳练，十次里九次成功再加难度
4 口令只绑好事：叫来之后不剪指甲、不关笼、不骂；已经用坏的口令就换一个新词重练
5 它不来别去追：往反方向跑或蹲下，它多半会跟过来
```

```
社交化（也叫社会化）
时机  一般认为三个多月龄之前是接受新事物最快的阶段；疫苗没打完时，经兽医同意用安全的方式做
方式  抱着或用推车带出去看街景车流；在家见不同年龄、戴帽子或口罩的人；听吸尘器、门铃
      只和已知健康、疫苗齐全的狗接触，不去陌生狗多的地方
清单  人、声音、地面（草地、地砖、井盖）、电梯、坐车、被触摸，每样都要有好的初体验
节奏  每次短、有零食、允许它退开；夹尾巴、舔嘴、打哈欠、别过头是在紧张，退回一步
```

## 疫苗、驱虫与就医信号（以兽医为准）

```
核心疫苗  通常包括犬瘟热、细小病毒、犬腺病毒等的联苗，以及狂犬疫苗
幼犬联苗  常见做法是 6–8 周龄开始，每隔 2–4 周一针，直到 16 周龄前后；共打几针由兽医定
狂犬疫苗  接种月龄与加强频率按当地规定和兽医安排；不少地方办养犬登记需要免疫证明
后续加强  首轮之后隔多久加强（每年或更长），看疫苗种类与当地规定，听兽医的
驱虫      体内、体外都要做，幼犬期频率较高；间隔与产品问兽医，按说明书执行
出门      疫苗全部打完且兽医确认之前，不去狗多的公园和宠物聚集处
记录      日期｜项目｜医院｜下次时间（兽医填）｜打完后的反应
```

打针当天带上记录本，打完在医院多观察一会儿再走，当天洗澡、运动听医嘱。疫苗和驱虫能不能同一天做，也听兽医安排。

```
就医信号：出现任何一项都联系兽医，不要自己判断
立即去医院或夜间急诊  呼吸困难、抽搐、误食有毒物或异物、肚子胀大伴干呕、大量出血、
                      站不起来、牙龈发白或发紫
当天联系兽医          反复呕吐或腹泻（尤其带血）、幼犬不吃不喝、精神明显萎靡、尿不出或尿血
尽快预约              跛行、频繁抓挠或掉毛、眼睛红肿有分泌物、耳朵有异味、体重突然变化
去之前准备            症状开始时间、吃过什么、大小便照片或视频、疫苗驱虫记录
```

人用的止痛药、感冒药可能对狗有毒，不要自己喂，也不要按网上说的症状买药。

## 最常见的误区

- 刚到家就洗澡、带出去见很多人 → 先稳定一周，洗澡时间问兽医。
- 尿错了打骂、按头闻尿 → 只清理不惩罚，功夫花在「带去对的地方再奖励」。
- 打完一针疫苗就去狗多的公园 → 全部打完、兽医确认后再去。
- 喂剩饭、熟骨头、牛奶 → 人的饭菜调味重，不少狗喝牛奶会拉肚子，按狗粮喂。
- 照包装喂完就不管 → 每两周摸一次肋骨、称一次体重，胖了减量。
- 笼子用来关禁闭 → 笼子是窝，只放好东西；幼犬白天不长时间关着。
- 「我家狗不咬人」所以不牵绳 → 出门牵绳、捡粪便，遵守当地文明养犬规定。
- 召回口令用来叫它挨骂 → 口令只绑好事，坏了就换新词。

## 输出契约

1. 先问：月龄、体型或品种、到家没有、手上有没有疫苗驱虫记录、住房情况与每天能投入的时间；缺哪项问哪项，一次不超过三个问题。
2. 按阶段交付：接狗前清单（勾选框）；第一周逐日安排；按月龄的一日作息表（时间｜事项｜备注）；眼下最需要的一项训练计划（步骤、每天几轮、何时升级）；疫苗驱虫记录表，时间一栏写「兽医确定」。
3. 健康相关的每一条都标「以兽医为准」；用户描述任何异常，第一句话就是建议联系兽医，并列出就诊前要准备的信息。
4. 不写疫苗和药物的品牌、剂量，不推荐犬舍、商家或购买渠道。

## 边界与不做什么

- 不诊断，不判断得了什么病，不推荐任何药物、剂量或疗法；有异常找兽医，夜里找宠物急诊。
- 疫苗种类、针数、间隔，驱虫产品与频率，以执业兽医的安排为准；本页讲常识，帮你知道该问什么。
- 咬人、严重护食、持续攻击或极度焦虑，找专业训练师，并请兽医先排除疼痛等身体原因，不靠自学硬扭。
- 养犬登记、限养犬种、牵绳和粪便清理，以当地规定为准。
- 绝育时间、品种遗传病、处方粮、老年犬护理，和兽医讨论。
- 领养还是购买由你决定；不推荐犬舍、商家、品牌或购买渠道。
