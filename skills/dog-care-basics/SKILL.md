# 养狗

定位一句话：**新手养狗的头一个月，决定成败的不是狗粮多贵，而是三件事：家里安全、作息固定、做对了马上有奖励。**

## 何时使用

用户这样说时用：

- 「第一次养狗要准备什么」「下周接一只两个月大的柯基回家」
- 「小狗到家一周了还在客厅乱尿，定点怎么教」
- 「叫它不回来」「怎么让它不怕人、不怕车」
- 「幼犬第二针疫苗什么时候打，打完多久能出门」
- 「刚接回来，晚上一直叫怎么办」

也就是：准备接狗回家，刚接回来不知道第一周怎么过，要教定点、召回和社交化，想知道疫苗驱虫大概什么时候做、该问兽医什么，或者担心自己踩了新手误区时。凡是健康问题，最终都交给兽医判断。

多轮怎么走：第一轮最多问三个问题（月龄与体型、到家没有、眼下最头疼的事），先解决最急的一件；之后请用户按周带着记录回来（定点表、作息、体重），再调整下一步。

不适用：

- 生病或异常（呕吐、腹泻、不吃不喝、误食等）：第一句话就建议联系兽医，按下文「就医信号」分轻重，不做诊断。
- 咬人、严重护食、持续攻击或极度焦虑：找专业训练师，并请兽医先排除疼痛等身体原因。
- 老年犬护理、品种遗传病、绝育时间、处方粮：和兽医讨论，本技能只帮你列出要问的问题；猫和其他宠物也不在本技能范围。

## 接狗前：先判断，再备货

```
先判断（任何一条答不上来，先别接）
时间  每天能否固定抽出遛狗、训练、陪伴的时间；幼犬头几个月不宜整天独处
居住  房东、物业是否允许；养犬登记、限养犬种、牵绳规定以当地规定为准
预算  狗粮之外还有疫苗、驱虫、体检、绝育与意外就医，先问附近宠物医院的大致价格
家人  有没有人过敏或怕狗；谁主要负责；口令和规矩全家统一
```

判断都过了再备货、查家里：备货分吃、住、出门、训练、清洁、资料六类；家居安全查五项——电线、药品和清洁剂、有毒食物（巧克力、葡萄和葡萄干、洋葱大蒜、含木糖醇的口香糖、酒）、垃圾桶与阳台窗户楼梯、吞得下去的小东西。两份勾选清单全文见 [references/prep-checklist.md](references/prep-checklist.md)。

## 第一周与日常作息

```
第 0 天    路上保持安静；到家先带去定点，再让它在小范围里自己探索，家人不围观、不轮流抱
第 1–2 天  按原来的时间喂原来的粮；醒后、饭后、玩后、睡前各带去定点一次
第 3 天    认名字：叫名字，它一看你就给零食，每轮 5 次，一天几轮
第 4 天    带上疫苗驱虫记录做第一次体检，请兽医定后续疫苗驱虫时间
第 5 天    练独处：你在家时让它在围栏里待几分钟，安静了再放出来，逐天加长
第 6 天    练触摸：摸耳朵、爪子、嘴边，每摸一下给一点零食，为剪指甲和看病打基础
第 7 天    看记录：哪个时段容易尿错、夜里醒几次，下周据此调整
```

夜里把围栏放在床边；幼犬半夜哭叫多半是要尿，安静抱去定点，尿完直接回窝，不陪玩。头一周先别急着洗澡，脏了局部擦，什么时候能洗问兽医。

```
喂食与作息
顿数  幼犬少食多餐，一天三到四顿，随月龄逐步减到成犬的一天两顿，何时减问兽医
份量  从狗粮包装上的「体重—喂食量」表起步，再看体型微调：摸得到肋骨、从上往下看有腰身
换粮  至少七天渐进：新粮 1/4 → 1/2 → 3/4 → 全部，每档约两天；拉稀就退回上一档
定时  放下食盆约 15 分钟后收走，没吃完不追着喂；清水全天不断
零食  训练零食算进当天总量，大约不超过一成；熟骨头会碎裂，不喂
作息  幼犬大部分时间在睡，别总叫醒它玩；醒来先定点，再玩，再吃，再定点，再睡
运动  幼犬每次短、次数多，少跳高、少爬楼梯；成犬每天至少遛两次，时长看品种与体力
```

## 基础训练：定点、召回、社交化

总原则：每次 3–5 分钟，一天多次；做对了 3 秒内奖励；全家同一个口令；不打不骂。

```
定点（在哪上厕所）
1 固定一个点：室内用尿垫或围栏一角，户外选固定角落，每次都去同一处
2 抓时机：醒后、饭后 10–20 分钟、玩耍后、睡前；幼犬另外每 1–2 小时带去一次
3 一个口令：到了只说一个词，如「嘘嘘」；尿完 3 秒内夸奖加零食
4 看信号：原地转圈、低头猛嗅、突然走开，立刻带去定点
5 出错不罚：当场看到就轻声打断、带去定点；事后发现只清理。打骂和按头闻尿只会教它躲着你尿
6 记一张表：时间、地点、对错，一周后找规律
```

练了两三周毫无进展，或者突然尿频、尿里带血、排尿费劲，先带去看兽医，排除身体原因再谈训练。

```
召回（叫它就来）
1 室内低干扰：叫名字加「来」，语气愉快；它一动就夸，到脚边给最好吃的零食
2 加距离：隔一个房间叫；两个人对坐轮流叫，让它来回跑
3 加干扰：到户外先系 5–10 米的长牵引绳练，十次里九次成功再加难度
4 口令只绑好事：叫来之后不剪指甲、不关笼、不骂；已经用坏的口令就换一个新词重练
5 它不来别去追：往反方向跑或蹲下，它多半会跟过来
```

```
社交化（也叫社会化）
时机  一般认为三个多月龄之前是接受新事物最快的阶段；疫苗没打完时，经兽医同意用安全的方式做
方式  抱着或用推车带出去看街景车流；在家见不同年龄、戴帽子或口罩的人；听吸尘器、门铃
      只和已知健康、疫苗齐全的狗接触，不去陌生狗多的地方
清单  人、声音、地面（草地、地砖、井盖）、电梯、坐车、被触摸，每样都要有好的初体验
节奏  每次短、有零食、允许它退开；夹尾巴、舔嘴、打哈欠、别过头是在紧张，退回一步
```

## 疫苗、驱虫与就医信号（以兽医为准）

```
核心疫苗  通常包括犬瘟热、细小病毒、犬腺病毒等的联苗，以及狂犬疫苗
幼犬联苗  常见做法是 6–8 周龄开始，每隔 2–4 周一针，直到 16 周龄前后；共打几针由兽医定
狂犬疫苗  接种月龄与加强频率按当地规定和兽医安排；不少地方办养犬登记需要免疫证明
后续加强  首轮之后隔多久加强（每年或更长），看疫苗种类与当地规定，听兽医的
驱虫      体内、体外都要做，幼犬期频率较高；间隔与产品问兽医，按说明书执行
出门      疫苗全部打完且兽医确认之前，不去狗多的公园和宠物聚集处
记录      日期｜项目｜医院｜下次时间（兽医填）｜打完后的反应
```

打针当天带上记录本，打完在医院多观察一会儿再走，当天洗澡、运动听医嘱。疫苗和驱虫能不能同一天做，也听兽医安排。

```
就医信号：出现任何一项都联系兽医，不要自己判断
立即去医院或夜间急诊  呼吸困难、抽搐、误食有毒物或异物、肚子胀大伴干呕、大量出血、
                      站不起来、牙龈发白或发紫
当天联系兽医          反复呕吐或腹泻（尤其带血）、幼犬不吃不喝、精神明显萎靡、尿不出或尿血
尽快预约              跛行、频繁抓挠或掉毛、眼睛红肿有分泌物、耳朵有异味、体重突然变化
去之前准备            症状开始时间、吃过什么、大小便照片或视频、疫苗驱虫记录
```

人用的止痛药、感冒药可能对狗有毒，不要自己喂，也不要按网上说的症状买药。

## 最佳实践：第一个月只盯这五件事

1. **安全先于一切**：有毒食物、药品、电线、小物件收好，接狗前查一遍家。
2. **作息固定**：按「醒 → 定点 → 玩 → 吃 → 定点 → 睡」循环，时间尽量每天一样。
3. **做对了 3 秒内奖励**：每次练 3–5 分钟、一天多次，全家同一个口令，不打不骂。
4. **每天记一张表**：定点对错、吃了多少、体重和异常，一周复盘一次，比凭印象调整准。
5. **健康问题交给兽医**：疫苗驱虫时间由兽医定；出现就医信号，先联系兽医再说别的。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话 |
|---|---|---|
| 缺关键信息 | 一次最多问三个：月龄与体型或品种、到家没有、眼下最头疼的事；其余按「两三个月龄、已到家、住楼房」默认，标 [待确认] | 「先问三件事：它几个月大、什么体型？到家了吗？现在最让你头疼的是哪件事？」 |
| 描述互相矛盾（「两个月大，疫苗已经全部打完」） | 指出和常见接种节奏对不上，给两种理解，请用户拿疫苗本核对，以兽医为准 | 「幼联苗常见做法是打到 16 周龄前后，两个月大一般还没打完。是打完了首针，还是月龄记错了？对一下疫苗本。」 |
| 描述了任何异常或症状 | 第一句话建议联系兽医，按就医信号分轻重，列就诊前要准备的信息，不做诊断 | 「这需要兽医看：反复呕吐请今天就联系兽医。去之前记下开始时间、吃过什么，拍下呕吐物。」 |
| 行为问题严重（咬人、护食、持续攻击、极度焦虑） | 转专业训练师，并请兽医先排除疼痛等身体原因 | 「这种情况先请兽医排除身体原因，再找专业训练师，不建议照着网上硬扭。」 |
| 超出范围（老年犬、品种遗传病、绝育时间、处方粮、猫） | 转兽医；只帮用户列出要问兽医的问题 | 「这要和兽医讨论。我可以帮你列一张问题清单，看病时直接问。」 |
| 时间紧，只要最小可用版 | 最小版 = 家居安全五项 + 一张一日作息表 + 眼下那项训练的前三步；其余下次补 | 「先做这三样：查家里五项安全、按这张作息表过、从定点的前三步练起。」 |
| 用户坚持要药名、剂量、疫苗品牌或诊断 | 守住边界，给能做的替代 | 「药和剂量只能由看过它的兽医定；我帮你整理症状和要问兽医的问题。」 |
| 训练两三周没进展，或突然退步 | 先排除身体原因（找兽医），再对照记录表查时机和奖励是否及时 | 「突然退步先看是不是身体不舒服；没问题的话，把这周的记录表发我，我们找规律。」 |

## 输出契约

交付物按这个顺序，只放和用户问题相关的部分，但顺序不变；缺的信息写 [待补] 或 [待确认]：

1. **一句话结论**：先回答用户最急的问题；涉及健康时，第一句就是「建议联系兽医」。
2. **你的情况**：月龄、体型或品种、到家天数、手上有没有疫苗驱虫记录、住房、每天能投入的时间。
3. **行动清单**，按阶段选：接狗前清单（勾选框）；第一周逐日安排；按月龄的一日作息表（时间｜事项｜备注）；眼下最需要的一项训练计划（步骤、每天几轮、何时升级）。
4. **健康提醒**：疫苗驱虫记录表（下次时间一栏写「兽医确定」）；相关的就医信号；每条标「以兽医为准」。
5. **下一步**：观察什么、记什么，多久后带着记录回来调整。

规则：先问，缺哪项问哪项，一次不超过三个问题；健康相关的每一条都标「以兽医为准」；用户描述任何异常，第一句话就是建议联系兽医，并列出就诊前要准备的信息；不写疫苗和药物的品牌、剂量，不推荐犬舍、商家或购买渠道。

占位符：[待补] = 需要用户去问原主人或查记录的信息（原来的狗粮与喂食量、疫苗驱虫记录）；[待确认] = 我按默认值写的内容（月龄、体型、住房）；「兽医确定」= 疫苗、驱虫、洗澡、减顿的具体时间。

交付前自检（逐条答是或否）：

- [ ] 健康相关的每一条都标了「以兽医为准」？
- [ ] 用户提到异常时，第一句话就是建议联系兽医？
- [ ] 没有药名、剂量、疫苗品牌、犬舍或商家？
- [ ] 训练计划的每一步都写了每天几轮、何时升级？
- [ ] 追问没有超过三个问题，默认值都标了 [待确认]？

## 示例

**示例**（情况为虚构）

用户：「小狗到家一周了还在客厅乱尿，定点怎么教？」

助手：「先问三件事：它几个月大、什么品种？尿错多在什么时候、什么地方？有没有尿得特别频繁、尿里带血或者尿得费劲？」

用户：「三个月的柯基，我在家办公。多半是玩完之后尿在客厅地毯上，一天两三次。没见带血，也不算频繁。」

交付：

> **一句话结论**：问题多半出在「玩完没有马上带去定点」，加上地毯上的气味会把它引回去；先补上这两环，按下面的计划练两三周。
>
> **你的情况**：3 个月，柯基，到家 7 天，在家办公；尿错集中在玩耍后、客厅地毯；暂无尿血或尿频。
>
> **定点训练计划**（每次 3–5 分钟，一天多轮）：
> 1. 固定一个点：客厅离地毯最远的角落放尿垫，位置不换。
> 2. 抓时机：醒后、饭后 10–20 分钟、睡前各一次；**玩完立刻去**；其余时间每 1–2 小时带去一次。
> 3. 一个口令：到了只说「嘘嘘」，尿完 3 秒内夸奖加零食。
> 4. 看信号：原地转圈、低头猛嗅、玩着玩着突然走开，马上抱去定点。
> 5. 出错不罚：当场看到就轻声打断、带去定点；事后发现只清理，用酶类除味清洁剂，不用含氨的；练习期间先把地毯卷起来。
> 6. 记一张表：时间｜地点｜对错。
> 何时升级：连续一周十次里九次尿对，再把「每 1–2 小时带一次」的间隔拉长半小时。
>
> **一日作息**：按「醒来先定点，再玩，再吃，再定点，再睡」循环，玩完多加一次定点；三个月大一般一天三到四顿，何时减顿问兽医。
>
> **健康提醒**（以兽医为准）：练了两三周毫无进展，或突然尿频、尿里带血、排尿费劲，先带去看兽医，排除身体原因。
>
> **下一步**：记满一周后把记录表发我，我们看哪个时段最容易出错，再调时间。

## 常见问题（FAQ）

**Q：幼犬疫苗打到第几针能出门？**
A：疫苗全部打完且兽医确认之后，再去狗多的公园和宠物聚集处。之前经兽医同意，可以抱着或用推车出去做社交化。

**Q：刚接回来，晚上一直叫怎么办？**
A：围栏放在床边；多半是要尿，安静抱去定点，尿完直接回窝，不陪玩。叫得异常或伴有其他不适，联系兽医。

**Q：能推荐狗粮、驱虫药或疫苗牌子吗？**
A：不推荐品牌和剂量。狗粮先照原来的喂；驱虫产品和频率问兽医，按说明书执行。

**Q：多久能洗澡？**
A：头一周先别洗，脏了局部擦；什么时候能洗，打疫苗前后能不能洗，问兽医。

**Q：上班族白天家里没人，能养幼犬吗？**
A：幼犬头几个月不宜整天独处。接狗前「时间」那条判断答不上来，先解决有人照看的问题再接。

**Q：叫它总是不回来怎么办？**
A：口令只绑好事，叫来之后不剪指甲、不关笼、不骂；已经用坏了就换一个新词，从室内低干扰重新练；它不来别去追。

**Q：老年犬或品种遗传病的问题能问吗？**
A：这些要和兽医讨论。我可以帮你把症状和想问的问题列成清单，看病时直接问。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 刚到家就洗澡、带出去见很多人 | 环境全变了，它需要时间稳定下来 | 先稳定一周，洗澡时间问兽医 |
| 尿错了打骂、按头闻尿 | 只会教它躲着你尿 | 只清理不惩罚，功夫花在「带去对的地方再奖励」 |
| 打完一针疫苗就去狗多的公园 | 疫苗还没打完 | 全部打完、兽医确认后再去 |
| 喂剩饭、熟骨头、牛奶 | 人的饭菜调味重，熟骨头会碎裂，不少狗喝牛奶会拉肚子 | 按狗粮喂，零食算进当天总量 |
| 照包装喂完就不管 | 包装上的量只是起点，体型会变 | 每两周摸一次肋骨、称一次体重，胖了减量 |
| 笼子用来关禁闭 | 它会怕进笼子，笼子就当不成窝 | 笼子是窝，只放好东西；幼犬白天不长时间关着 |
| 「我家狗不咬人」所以不牵绳 | 别人不知道，你也无法保证每一次 | 出门牵绳、捡粪便，遵守当地文明养犬规定 |
| 召回口令用来叫它挨骂 | 口令和坏事绑在一起，它就不来了 | 口令只绑好事，坏了就换新词 |

## 边界与不做什么

- 不诊断，不判断得了什么病，不推荐任何药物、剂量或疗法；有异常找兽医，夜里找宠物急诊。
- 疫苗种类、针数、间隔，驱虫产品与频率，以执业兽医的安排为准；本页讲常识，帮你知道该问什么。
- 咬人、严重护食、持续攻击或极度焦虑，找专业训练师，并请兽医先排除疼痛等身体原因，不靠自学硬扭。
- 养犬登记、限养犬种、牵绳和粪便清理，以当地规定为准。
- 绝育时间、品种遗传病、处方粮、老年犬护理，和兽医讨论。
- 领养还是购买由你决定；不推荐犬舍、商家、品牌或购买渠道。
