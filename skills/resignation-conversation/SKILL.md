# 离职谈话

定位一句话：**离职谈话只做两件事：把决定说清楚，把关系和交接留完整——不在这一场里算旧账。**

## 何时使用

员工准备提离职、被挽留、要写辞职信和交接清单时；管理者接到下属提离职、要判断挽留和安排交接时。用户通常这样说：

- 「拿到新工作了，下周想提，怎么跟领导提离职比较体面」
- 「提了离职，领导说给我涨薪让我留下，被挽留了怎么回」
- 「HR 约我做离职面谈，问为什么走，怎么说」
- 「帮我写一封辞职信，再列个交接清单」
- 「团队骨干突然说要走，下属要离职怎么谈，还值不值得留」

通知期、审批和离职手续以劳动合同与公司制度为准；补偿、竞业、违约金等争议一律咨询专业人士。

不适用（遇到时直接说明并转交）：

- **被辞退、协商解除、劳动仲裁**：不在本技能范围；可以帮你把要问的问题整理成清单，交给 HR、当地劳动保障部门或执业律师。
- **只想谈加薪、还没决定走**：别拿离职当筹码，转加薪申请类技能（如 `salary-raise-request`）。
- **长期失眠焦虑、情绪压力很大**：先找信任的人聊，或寻求专业心理咨询。

## 先判断：决定定了没有

员工先过三关：

- 真要走，还是想借此谈条件？想谈条件就直接去谈调薪调岗（可配合加薪申请技能 `salary-raise-request`），别拿离职当筹码——话说出口就收不回。
- 新工作的书面录用到手了吗？口头承诺不算。
- 合同里的通知期、竞业、服务期怎么写的？看原文；看不懂问 HR 或律师，本技能不解读条款。

三关都过了，再备齐四样：手上事项的交接初稿（谈话时能说出计划）；最后工作日的提议和能让步的范围；年假、报销、借用的公司财物等待结清事项，问 HR 怎么办；一句话版的离职原因。

管理者先分辨：对方说「已经接了录用、日期定了」，这是交接窗口；说「最近压力很大，想换个环境」，这是挽留窗口，按下文管理者视角第二步判断。

## 员工视角：时机、开口、原因、挽留、交接

**1 时机与顺序**：先当面或视频告诉直属上级，再交书面，最后才告诉同事。避开项目上线当天和上级情绪低点，尽量选周初，留出当周排交接的时间。提之前把个人文件整理好，公司的资料、代码、客户信息一样都不带走。

**2 开口**：先说决定，再说感谢，不铺垫十分钟。

```
「[领导称呼]，想占用您二十分钟，有件事想当面说。
我决定离职，已经考虑清楚了。这几年在团队收获很多，特别是[一件具体的事]。
我计划最后工作日是[日期]，以公司确认为准；这期间会把[手上的事]交接好，交接清单明天发您。」
```

**3 原因怎么说不伤人**：说「去获得什么」，不说「逃离什么」。

- 可以说：想往[新方向]发展；新机会在[职责、行业或城市]上更贴合我的规划；家里需要我去[城市]。
- 不说：批评上级、同事、公司；比较薪资细节；还没入职的新单位名字。
- 被追问真实原因时，挑一条对事不对人、对后来的人有用的建议：「如果[流程或资源]上能[怎么改]，后面的同事会顺很多。」HR 的离职面谈常问为什么走、对团队有什么建议，也按这个标准答：原因用上面的说法，建议只给一两条对事的，不点具体的人。

**4 被挽留怎么回应**：

- 先谢，再表明决定：「谢谢您的认可，我是认真考虑过才提的，决定不变。」
- 对方开出条件（加薪、调岗）时，先问自己：当初要走的原因，这个条件解决了几条？解决不了的，留下来问题还在；对已经答应的新单位也要守信。
- 需要考虑就给回复时间：「我想一想，[周三]前给您答复。」不拖。
- 反复挽留时重复同一句话，不再补新理由——解释越多，越像在谈价。
- 对方情绪激动、说重话时不接情绪，只回到决定和交接：「我理解这对团队有影响，所以交接计划我已经想好了，您看这样排行不行。」

**5 交接承诺**：只承诺做得到的——一份交接清单、至少一次交接会、接手人试做一轮、离职后一段时间内可以答疑（只答疑，不继续干活）。别说「走之前把所有问题都解决」。上级同意后，再和上级约好对同事怎么说：「我去做[方向]了，后续找[接手人]。」最后一天发一条告别消息，模板见 [references/templates.md](references/templates.md)。

交接倒排表的日期用脚本算，避免把星期和天数算错（只做日期推算，不做法律判断；只用 Python 标准库，不联网）：

```bash
python3 {baseDir}/scripts/handover_dates.py --notice-date 2026-10-12 --last-day 2026-11-11 --notice-days 30
```

脚本先检查日期格式、最后工作日是否早于提出日、是否早于「提出日 + 你填的通知期天数」、是否落在周末，再按工作日把「列清单 / 交接会与试做 / 收尾」三段排出具体日期；不到三周时自动压缩。通知期按自然日还是工作日、从哪天起算，以合同和 HR 答复为准。

## 管理者视角：接到离职的一场谈话

1. **先听不辩**：问「什么时候开始考虑的」「最主要的原因是什么」「如果能改一件事，会是什么」。不说「你这时候走不负责任」。
2. **判断挽留**：原因在你权限内能解决（职责、成长、团队关系、权限内的待遇），且对方是关键人，可以认真挽留一次，只承诺能书面落实的；原因解决不了（家庭、城市、转行、已接受录用），不硬留，转入交接。挽留私下谈，不当着团队。
3. **定交接**：一起确定最后工作日、接手人、清单与节点。从最后工作日往前倒排：最后两三天只做答疑和收尾，再往前一周开交接会、让接手人试做，提出离职后的第一周就把清单列完。约好团队告知的口径和时间——谁先知道、什么时候、怎么说。
4. **体面收尾**：感谢具体贡献；手续交给 HR；不在团队里评价离开的人；日后接到背景调查只讲事实。

表态可以直接用：要挽留时说「谢谢你当面告诉我。我想争取一次，给我一两天，看看能做什么」；不挽留时说「尊重你的决定，我们一起把交接排好」。挽留后对方仍决定走，就说「好，尊重你的选择」，当场转入交接，之后照常同步信息，不冷处理。

每次离职的原因记一笔，每季度翻一次：同一个原因出现第二次，就该当成团队的问题来改。

不要说：「你走了项目怎么办」（施压）、「新单位不一定好」（贬低）、「这样要扣钱、要赔偿」（法律结论交给 HR 和专业人士）。

## 模板：辞职信与交接清单

- **辞职信**：只写决定、最后工作日（「以公司确认为准」）、交接安排和一句具体的感谢，不写原因细节和情绪；按公司规定的方式提交，自己留一份，记下提交日期和方式。
- **交接清单**：每项一行——事项、当前状态、下一步与截止日、接手人、资料位置、对接人；另列进行中的承诺、账号与权限（只列名称，密码不写进清单）、只有你知道的坑。

完整模板（辞职信、交接清单、倒排表、告别消息、管理者表态）见 [references/templates.md](references/templates.md)；补偿、竞业、社保、离职证明等要问 HR 的问题清单见 [references/questions-for-hr.md](references/questions-for-hr.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| E1 缺关键信息：不知道你是哪一方、决定定没定、最后工作日与通知期、在办事项、和上级的关系 | 先问三个：你是提离职还是接离职的一方；决定定了没有（书面录用到手没）；合同写的通知期和想要的最后工作日。其余先用默认：关系「一般」、在办事项与接手人写 [待补]，默认值标 [待确认] | 「先确认三件事：你是提的一方还是接的一方？决定定了吗？合同写的通知期是多少天、想哪天走？其余我先留空标 [待确认]。」 |
| E2 信息自相矛盾：说「已经提了」又问「怎么提」；最后工作日早于提出日，或短于合同通知期；说「决定了」又想先看能不能加薪 | 指出矛盾，给两种理解让用户选；日期对不上的用脚本核对并说出差几天，给「按合同顺延」和「与上级协商提前」两个选项 | 「你说已经提了，是口头说过、还差书面辞职信，还是还没开口、想先练一下？两种我给的东西不一样。」 |
| E3 超出范围：被辞退、协商解除、仲裁；补偿怎么算、竞业是否有效、「走了要赔钱」对不对 | 不做劳动法定性；把要问的问题整理成清单，交给 HR、当地劳动保障部门或执业律师；情绪上的沟通要点可以帮着理 | 「赔不赔、怎么算是法律问题，我不下结论；我把要问的问题列好，你拿去问 HR 或律师。」 |
| E4 时间紧：明早就要谈，只要最小可用版 | 只给四样：三句开口话术、一句挽留回应、一句交接承诺、五行的辞职信；原因说法和交接清单谈完再补；标题行写「状态：最小版」 | 「先给你明早用的最小版：三句开口、一句挽留回应、一句交接承诺，外加一封短辞职信。」 |
| E5 用户坚持越界：辞职信里写上级的问题；想不交接直接走；要我判断「这样走公司告不了我」；要我代发辞职信 | 守住：辞职信只写决定、日期、交接；交接是职业信用，不帮设计「一走了之」；法律后果问专业人士；不代发、不代表用户与公司沟通 | 「辞职信里我不写对上级的评价——白纸黑字会跟着你；想反馈的问题，挑一条对事的在面谈里说。」 |
| 中途改变立场：被挽留后动摇，或反过来决定马上走 | 不替用户决定去留；拿当初的原因清单对照新条件逐条看；按用户的最终选择给对应那一套话术 | 「先把你当初要走的三个原因写出来，对照这次的条件看解决了几条；你定了留还是走，我按你的决定给话术。」 |

## 输出契约

先问：你是提离职的一方还是接离职的一方；决定定了没有；最后工作日与合同写的通知期；在办事项；和上级的关系现状。交付物按身份分两种，各自顺序固定；用户只问其中一件事时，只交对应部分，编号不变，末尾一行写「还可以给：……」。

```
员工版                                  管理者版
0 标题行：身份｜状态｜[待确认] N 项      0 标题行：身份｜状态｜[待确认] N 项
1 情况摘要（决定、日期、在办事项）       1 情况摘要（窗口判断、是否关键人、权限）
2 开口话术                              2 谈话提纲（先听不辩的三个问题）
3 被挽留时的两三种回应（分量不同）       3 挽留判断与两套表态
4 离职原因的说法                         4 交接安排与倒排表
5 辞职信草稿                             5 团队告知口径
6 交接清单与倒排表                       6 体面收尾清单
7 要问 HR 的问题清单                     7 交给 HR 的事
```

- 用户需要时扮演上级或下属陪练挽留那一段，每轮点评一句可改的说法。
- 不替用户决定去留，只帮理清原因和条件。
- 补偿、竞业、违约金、社保、离职证明等问题，只整理成「要问清的问题清单」，交给 HR 或专业人士。

占位符：[待补]——称呼、岗位、具体的事、接手人姓名等由用户填的空，助手不替他编；[待确认]——没问到、先按默认写的项，或要 HR 确认的口径，数量写进标题行。

交付前自检（每条答「是」才交；只交部分内容时，不涉及的项记为「是」）：

- [ ] 身份（员工 / 管理者）和决定状态已确认，用的是对应那一版的顺序？
- [ ] 最后工作日写了「以公司确认为准」，和通知期对不上时已经指出？
- [ ] 话术里没有批评任何人、没有比较薪资、没有新单位名字？
- [ ] 挽留回应至少给了两种分量，且没替用户决定去留？
- [ ] 交接承诺都是做得到的（清单、交接会、试做、限期答疑）？
- [ ] 没有任何劳动法结论；涉及补偿、竞业的都转成了要问的问题？

## 常见问题（FAQ）

**问：新工作的录用还没拿到书面的，能先提吗？**
答：不建议。口头承诺不算，书面录用到手再提；提了之后录用出变故，原岗位不一定能收回。

**问：提了离职之后，新单位的录用被撤回了怎么办？**
答：先别慌，尽快和原上级坦诚说明情况，问能否撤回离职申请——公司不一定同意，以公司答复为准。涉及权益的问题，把经过和书面材料整理好，问 HR 或专业人士。

**问：领导说「现在走要赔钱、要扣工资」，怎么回？**
答：不当场争辩，也不当场答应：「这个我想先弄清楚规定，麻烦把依据的条款发我，我确认后再回复。」赔不赔、扣不扣是法律问题，问 HR、当地劳动保障部门或律师。

**问：领导不批、一直拖着怎么办？**
答：按公司规定的方式提交书面申请，自己留好提交日期和方式的记录；再约一次沟通，把交接计划摆出来谈。流程上的争议交给 HR 或专业人士。

**问：离职面谈要不要说真实原因？**
答：说「去获得什么」，不说「逃离什么」；建议只给一两条对事不对人的，不点具体的人。

**问：可以先跟关系好的同事说吗？**
答：先告诉直属上级，再交书面，最后才告诉同事。上级从别人那里先听说，是最伤关系的一种。

**问：能帮我把辞职信直接发给领导吗？**
答：不代发，也不代表你和公司沟通。我给你能直接用的草稿，按公司规定的方式由你提交。

**问：（管理者）下属一提离职，要不要当场挽留？**
答：先听不辩，问清原因。原因在你权限内能解决、对方又是关键人，才认真挽留一次，而且只承诺能书面落实的。

## 常见错误（反模式）

最佳实践先记三条：先上级后同事；只说「去获得什么」；只承诺做得到的交接。

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 同事和朋友圈先知道，上级最后一个知道 | 上级被动，关系和交接都难谈 | 先当面告诉上级，再交书面，最后告诉同事 |
| 离职面谈一次性吐槽，或在群里发告别长文翻旧账 | 话会传开，背景调查也会问到 | 原因说「去获得什么」，建议只给一两条对事的 |
| 交接只写「资料都在电脑里」 | 没有路径、状态、接手人，等于没交接 | 按清单每项写清状态、下一步、接手人、资料位置 |
| 拿离职换加薪 | 答应了后悔，没答应下不来台 | 想谈条件就直接谈调薪调岗 |
| 最后一个月松懈、突然消失 | 最后的印象最容易被记住 | 按倒排表做到最后一天，发告别消息 |
| 承诺「走之前把所有问题都解决」 | 做不到，最后反而失信 | 只承诺清单、交接会、试做一轮、限期答疑 |
| 被挽留时解释一大堆新理由 | 越解释越像在谈价 | 重复同一句「决定不变」 |
| 管理者当场情绪化、翻旧账，许下兑现不了的挽留条件 | 挽留失败还伤了关系，团队看在眼里 | 先听不辩；只承诺能书面落实的 |
| 管理者迟迟不排交接、想「晾一晾」对方 | 工作断档，团队也会寒心 | 当场转入交接，照常同步信息 |
| 当场给出法律结论（「这样要赔钱」） | 说错了要担责，也激化矛盾 | 法律问题交给 HR 和专业人士 |

## 边界与不做什么

- 不做劳动法定性：能不能走、通知期多长、补偿和违约金怎么算、竞业条款是否有效——咨询人力资源部门、当地劳动保障部门或执业律师。
- 被辞退、协商解除、劳动争议不在本技能范围。
- 不代发辞职信，不代表用户与公司沟通。
- 不替用户决定去留；脚本只做日期推算，不代表对合同的解释。
- 情绪压力大、长期失眠焦虑，找信任的人聊，或寻求专业心理咨询。
