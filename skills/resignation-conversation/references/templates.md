# 模板：辞职信、交接清单、告别消息

## 辞职信

```
辞职信
[领导称呼]：
因个人职业规划调整，我决定辞去[部门][岗位]一职，最后工作日拟定为[日期]，以公司确认为准。
在职期间承蒙您和团队的指导与支持，特别是[一件具体的事]，十分感谢。
离职前我会完成[事项一]、[事项二]的交接，交接清单另附；需要我配合的其他事项请随时告诉我。
祝团队一切顺利。
[姓名]  [日期]
```

辞职信只写决定、日期、交接，不写原因细节和情绪；按公司规定的方式提交，自己留一份，记下提交日期和方式。

## 交接清单

```
交接清单（每项一行）
事项 | 当前状态 | 下一步与截止日 | 接手人 | 资料位置 | 对接人
进行中的承诺 | 答应过谁、什么事、何时给
账号与权限 | 只列名称，按公司流程移交或注销，密码不写进清单
只有你知道的坑 | 例外情况、历史原因、常出错的环节
```

「资料位置」写到能直接打开的路径或文件名，不写「都在电脑里」。

## 交接倒排表

从最后工作日往前倒排：最后两三天只做答疑和收尾，再往前一周开交接会、让接手人试做，提出离职后的第一周就把清单列完。具体日期用脚本算，避免把星期算错：

```bash
python3 scripts/handover_dates.py --notice-date 2026-10-12 --last-day 2026-11-11 --notice-days 30
```

## 最后一天的告别消息

```
各位同事：今天是我在[团队]的最后一天，感谢大家[一件具体的事]。
我手上的[事项]已经交接完毕，后续请直接找[接手人]。祝一切顺利，有缘再会。
```

## 管理者用的两句表态

```
要挽留时：「谢谢你当面告诉我。我想争取一次，给我一两天，看看能做什么。」
不挽留时：「尊重你的决定，我们一起把交接排好。」
挽留后对方仍决定走：「好，尊重你的选择。」——当场转入交接，之后照常同步信息，不冷处理。
```
