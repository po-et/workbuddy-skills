# 完整示例：公司婚假申请（正文＋系统一行版＋附件清单）

> 示例。人名、部门、日期和假期天数都是虚构的，只演示写法；你能休几天、按工作日还是自然日计，以本单位制度为准。

## 1. 用户原话

> 下个月结婚想请婚假，公司的请假申请怎么写、要附什么

## 2. 助手先问（一次问完，不超过 3 个）

1. 你的部门和岗位，申请交给谁？公司有没有办公系统要填「请假理由」？
2. 打算哪天到哪天休？人事有没有说婚假按工作日还是自然日算、一共几天？
3. 哪天登记的？手上在办的事交给谁？

## 3. 用户补充

> 市场部活动策划，交给部门负责人周经理，系统里也要填。12 月 3 日到 12 月 9 日，人事说按工作日算，我能休 5 天。11 月 20 日登记的。手上的年会方案交给同组的小陈。

## 4. 天数核对（脚本实际输出）

```bash
python3 scripts/leave_days.py 2026-12-03 2026-12-09
```

```
请假起止：2026-12-03（周四）上午开始，至 2026-12-09（周三）下午结束
自然日：7 天
其中周一至周五：5 天
未标注节假日与调休：区间内如有法定节假日或调休上班日，用 --off / --work 标注后重算
核对：以上只按你给的日期计算；按工作日还是自然日计、半天怎么算，以本单位考勤口径为准。
```

7 个自然日里有 5 个周一至周五，和「按工作日算 5 天」对得上。区间里若有法定节假日或调休上班日，用 `--off` / `--work` 标出来再算一遍。

## 5. 交付物

【请假申请正文】

```
请假申请
周经理：
本人[待补：姓名]，市场部活动策划，已于2026年11月20日登记结婚，申请婚假5天，自12月3日（星期四）上午至12月9日（星期三）下午，共5个工作日（按公司规定以工作日计），12月10日（星期四）正常到岗。
工作安排：年会方案已交接给小陈，交接清单见附件二；紧急事项可在工作日10:00—11:00通过[待补：手机号]联系我。
附件：一、结婚证复印件；二、工作交接清单
请审批。
申请人：[待补：姓名]    2026年11月25日
```

【系统「请假理由」一行版】

```
婚假：11月20日登记结婚，申请5个工作日（12月3日—12月9日），附结婚证复印件；年会方案已交接小陈。
```

【附件清单】（每条以本单位制度为准）

- 结婚证复印件：婚假常见的附件；交原件核验还是只交复印件，按公司制度。
- 工作交接清单：制度不要求也建议附上，审批人更放心。

【待补 / 待确认】

- [待补]：姓名、手机号。
- [待确认]：婚假天数和计算口径是人事口头说的，提交前在员工手册或系统里再核对一次；公司对婚假有没有「登记后多久内休完」的时限。

## 6. 交付前自检

| 检查项 | 结果 |
|---|---|
| 起止写到日期加上午/下午 | 是 |
| 「共 5 个工作日」与脚本结果一致，并注明口径 | 是 |
| 批假人常问的五件事都有答案（哪天回：12 月 10 日；谁接手：小陈；证明：结婚证复印件；能否联系：工作日 10—11 点；为什么是这几天：刚登记结婚） | 是 |
| 没有编造：天数来自用户转述的人事答复，未替用户判断婚假该有几天 | 是 |
| 附件每条都标了以本单位制度为准 | 是 |
