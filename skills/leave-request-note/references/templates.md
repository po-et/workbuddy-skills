# 请假条模板全集

SKILL.md 只放了每套模板的要素摘要，完整可填空的模板都在这里。方括号 `[ ]` 处替换；用户没给的信息保留成 `[待补：……]`，不要替用户编。

## 1. 学校请假条

```
请假条
[李老师]：
我是[班级]的[小王]，因[事由，一句话写清]，需请假[N]天，自[X月X日]（星期[ ]）[上午/全天]至[X月X日]（星期[ ]）[下午]，共[N]天。
落下的课程和作业，我会[向谁借笔记，哪天前补交]。
附：[医院诊断证明等；没有就删去此行]
恳请批准。
请假人：[小王]    家长签字：[ ]    联系电话：[ ]
[年月日]
```

- 未成年学生请假，通常要家长签字，或由家长同时联系老师。
- 低年级由家长代写的，第一句改成「我是[班级][孩子姓名]的家长[姓名]」，落款写家长姓名和电话。
- 只请一天的，起止可以合写成「需请假 1 天（[X月X日]，星期[ ]，全天）」。

## 2. 公司请假申请

```
请假申请
[部门负责人]：
本人[姓名]，[部门、岗位]，因[事由]，申请[假别][N]天，自[X月X日 时刻]至[X月X日 时刻]，共[N]个工作日（或自然日，按本单位口径）。
工作安排：[在办事项]已交接给[同事]；紧急事项可在[时段]通过[电话]联系我。
附件：[证明材料名称]
请审批。
申请人：[姓名]    [年月日]
```

- 按半天或小时请的，起止写到时刻，如「自[X月X日] 9:00 至 11:30，共 2.5 小时」。
- 办公系统里的「请假理由」栏只写一行：假别＋事由＋天数＋交接人，例如「病假：急性肠胃炎，医嘱休息 2 天，附诊断证明；工作已交接小李」。

## 3. 微信或电话先打招呼（来不及走流程时）

```
【微信先打招呼】
[李经理]，我[明天上午]要[去办理证件]，想请[半天事假]（[9:00–13:00]）。[手上的报表]已交接给[小李]，下午正常到岗。稍后在系统里补申请，您看可以吗？
```

一条消息说全：什么时候、请什么假、多久、手上的事交给谁、什么时候补书面。

## 4. 补假申请（口头请过，事后补书面）

```
补假申请
[称呼]：
[X月X日][时刻]，我因[事由]通过[电话/微信]向您请假[N]天，您当时同意。现补交书面申请：实际自[ ]至[ ]，共[N]天[，比原计划多N天，原因是……]。
附件：[ ]
申请人：[姓名]    [年月日]
```

补录四步：返岗返校第一天就交；写清当时哪天几点、向谁、用什么方式请的、对方怎么答复；起止按实际发生写，多了或少了写明原因；该附的材料附上，聊天记录截图自己留存备查，一般不必附。

## 5. 续假申请（原假期结束前提交）

```
续假申请
[称呼]：
本人[姓名]，原经批准请[假别][N]天，自[X月X日]至[X月X日]。因[续假原因]，需续假[M]天，自[X月X日]至[X月X日]，续假后合计[N+M]天。
[工作安排或课程补救，按原请假条的写法更新]
附件：[新的证明材料，如复诊证明]
请审批。
申请人：[姓名]    [年月日]
```

续假一定在原假期结束之前提出；原起止、续假起止、合计天数三样都写，审批人不用回头翻原申请。
