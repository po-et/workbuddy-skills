# 请假条

定位一句话：**请假条要让批假的人不用回问就能批——谁、为什么、从哪天几点到哪天几点、共几天、落下的课或手上的活怎么安排、怎么找到你。**

## 何时使用

用户这样说时用本技能：

- 「明天发烧要去医院，帮我给班主任写个请假条」
- 「请病假怎么写？要附什么材料？」
- 「下个月结婚，公司的婚假申请怎么写」
- 「上周电话里请过假，现在要补一份书面申请」
- 「系统里的请假理由栏该填什么」
- 「假期到了还回不去，续假怎么写」

适用对象：学生向班主任、辅导员请假；员工向主管或人事提交请假申请，或在办公系统里填请假理由；口头请过假、事后要补书面材料时。

不适用（遇到时这样处理）：

- 问「婚假产假该有几天、工资怎么扣、单位能不能不批、算不算旷工」：属于劳动法定性，一句话说明以本单位制度和当地规定为准，建议问人事、工会或当地劳动保障部门，需要时咨询律师；请假条照写，不下结论。
- 没请假就缺了勤，要写情况说明或检讨：转给检讨书技能 `reflection-letter`，本技能只写请假、补假和续假。
- 休学、缓考、长期病休：走学校或单位的正式程序，找班主任、辅导员、教务或人事。

## 先判断：场景、假别、时间、流程

| 要定的事 | 怎么判断 |
|---|---|
| 场景 | 学校（交班主任或辅导员）还是公司（交主管或人事），两套格式见下一节 |
| 假别 | 病假、事假、婚假、产假、年假还是其他；假别决定理由写多细、附什么材料 |
| 时间 | 起止精确到日期加上午、下午或时刻；按工作日还是自然日计，以本单位口径为准 |
| 流程 | 先口头打招呼还是直接提交、要不要逐级审批、提前几天申请、交原件还是复印件，以本单位制度为准 |

拿不准制度时，先翻学生手册或员工手册，或直接问班主任、人事；不要凭印象写天数。

批假的人最常回问五件事：哪天几点回来？落下的课或手上的活谁管？有没有证明？这几天能不能联系上？为什么非得是这几天？动笔前把这五问的答案列出来，写进正文，一次就能批。

## 两套格式：学校与公司

- **学校请假条**：称呼 → 我是[班级]的[姓名] → 事由一句话 → 起止（日期＋星期＋上午/下午）与共几天 → 落下的课和作业怎么补 → 附件 → 恳请批准 → 请假人、家长签字、联系电话、日期。未成年学生通常要家长签字；家长代写的，第一句改成「我是[班级][孩子姓名]的家长[姓名]」。
- **公司请假申请**：称呼 → 姓名、部门岗位 → 事由与假别 → 起止到时刻、共几个工作日或自然日（按本单位口径）→ 工作交接给谁、紧急时段怎么联系 → 附件 → 请审批 → 申请人、日期。按半天或小时请的，起止写到时刻。
- **系统「请假理由」栏**只写一行：假别＋事由＋天数＋交接人，例如「病假：急性肠胃炎，医嘱休息 2 天，附诊断证明；工作已交接小李」。

完整填空模板（学校版、公司版、微信先打招呼、补假申请、续假申请）见 [references/templates.md](references/templates.md)。

模板里的「共[N]天」别心算，用脚本输出自然日与其中的周一至周五天数：

```bash
python3 scripts/leave_days.py 2026-11-05 2026-11-11                     # 自然日 7 天，周一至周五 5 天
python3 scripts/leave_days.py 2026-11-05 2026-11-06 --from-half pm      # 5 日下午开始：1.5 天
python3 scripts/leave_days.py 2026-11-05 2026-11-11 --off 2026-11-09 --work 2026-11-08
```

脚本不认识法定节假日和调休上班日，要对照当年放假安排用 `--off`（休）、`--work`（班）或 `--calendar` 文件标出来再算；最终以考勤记录为准。

## 五种假别的写法差异

- 病假：病情概况＋医嘱休息天数，不必写全诊断；常附诊断证明或病假条。急病先电话告知，返岗后补材料。
- 事假：什么事、为什么必须本人去、为什么是这几天；涉及隐私的，写到「家中有事须本人处理」即可。
- 婚假：写登记日期或婚礼日期；常附结婚证复印件。天数和休假时限各地各单位不同。
- 产假：写预产期或分娩日期和产前交接安排；天数与待遇差异大，提前找人事确认。
- 年假：写起止与剩余年假天数，不必写理由。

每种假别常附的材料和「特别留意」对照表见 [references/leave-types.md](references/leave-types.md)；丧假、陪产假等照同一思路：事由写到能批，日期写全，材料按制度附。

## 口头请假后的书面补录

来不及走流程时，先用微信或电话打招呼，一条消息说全：什么时候、请什么假、多久、手上的事交给谁、什么时候补书面（模板见 [references/templates.md](references/templates.md) 第 3 节）。对方同意后，按四步补书面：

1. 时间：返岗、返校第一天就交，别等人来催。
2. 写清当时的请假过程：哪天几点、向谁、用什么方式（电话、微信、当面）、对方怎么答复的。
3. 起止按实际发生写；比口头说的多了或少了，写明原因。
4. 该附的材料附上；聊天记录截图自己留存备查，一般不必附。

没请假就缺了勤的，不属于补录，要写情况说明，可配合检讨书技能 `reflection-letter`。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（场景、假别、起止） | 先问最影响正文的 1–3 项：学校还是公司、什么假、从哪天到哪天；其余用默认值（称呼写「老师」「领导」、交接人留空），在交付物里标 [待确认] 或 [待补] | 「先确认三件事：交给学校还是公司？请什么假？从哪天上午或下午到哪天？其余我先留空，你补上就能交。」 |
| 起止只说「明天到后天」「下周」 | 按对话日期换算成具体日期并标 [待确认]；换算不了就问 | 「我按今天是 11 月 4 日算，『明天到后天』是 11 月 5 日至 6 日，对吗？」 |
| 天数和日期对不上（说 3 天，日期却跨 4 天） | 指出矛盾，给两种理解让用户选；用脚本核对 | 「11 月 9 日到 12 日是 4 天（周一至周四）。你是请 3 天、结束日应为 11 日，还是请到 12 日、共 4 天？」 |
| 超出本技能范围（问能休几天、会不会扣钱、单位能不能不批） | 不下结论；请假条照写，天数留 [待确认：以本单位制度为准] | 「能休几天、工资怎么算要看本单位制度和当地规定，建议问人事；请假条里我先把天数标成待确认。」 |
| 时间紧，只要最小可用版 | 交三行版：称呼＋「因[事由]请[假别][N]天（起止）」＋落款；公司场景再加系统一行版；附件和交接标 [待补]，返岗后补全 | 「先给你能马上发的三行版，附件和交接我标了待补，回头补上。」 |
| 用户坚持越界（编病情、代开或改证明、倒填日期） | 守住边界，给合规替代：如实写到「能批」的程度，证明缺失就写「补交中」 | 「证明我不能代开或修改，也不编病情；可以写『诊断证明补交中』，先把假请下来。」 |
| 延长假期、到期回不去 | 按续假写：原起止、续假起止、合计天数、原因、新证明，原假期结束前提交 | 「这属于续假，得在原假期结束前交。我按原起止＋续假起止帮你写。」 |

脚本 `scripts/leave_days.py` 的退出码与报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 计算成功 | 把输出里的天数填进「共[N]天」，并注明工作日还是自然日 |
| 1「不是日期」「不存在」 | 日期格式不对或日子超出范围（如 2026-02-30） | 写成 `YYYY-MM-DD`，核对日历 |
| 1「结束日期早于开始日期」 | 起止写反了 | 按提示对调两个日期 |
| 1「同一天既从下午开始又在上午结束」 | 半天参数自相矛盾 | 只请半天时只写 `--from-half pm` 或 `--to-half am` 之一 |
| 1「同时被标成了休和班」「格式不对」 | `--off` 与 `--work` 冲突，或节假日文件某行不是「日期 休/班」 | 按当年放假通知核对后改正 |
| 1「参数错误」 | 少了结束日期或用了不存在的选项 | 按提示补齐，或看 `--help` |
| 2「找不到节假日文件」「读不了」 | `--calendar` 路径不对或不是 UTF-8 文本 | 检查路径、另存为 UTF-8，或改用 `--off` / `--work` |
| 130 | 按了 Ctrl+C | 重新运行即可，脚本不写任何文件 |

## 输出契约

动笔前先问清五项，缺哪项问哪项，一次不超过三个问题：学校还是公司、假别、起止到半天、是否已口头请过、本单位有没有模板或系统字段。

交付物按这个顺序，不增不减：

1. **请假条正文**：学校版或公司版，可直接提交；口头请过的用补假申请，延长假期的用续假申请。
2. **系统一行版**：公司场景必给；学校场景写「不需要」。
3. **附件清单**：每条标注「以本单位制度为准」；不需要附件的写「一般不用」。
4. **天数核对**：脚本输出或计算过程；区间内的节假日、调休提醒用户核对。
5. **待补 / 待确认清单**：逐条列出。

占位符规则：用户没给的写 `[待补：姓名]` 这类；用了默认值或需要用户核对的写 `[待确认：……]`；天数只按用户给的日期算；不编造事由、诊断和证明。

交付前自检（逐条答「是」才交）：

- [ ] 起止写到了具体日期加上午、下午或时刻，没有「明天」「下周」？
- [ ] 「共[N]天」和脚本结果一致，并注明按工作日还是自然日？
- [ ] 批假人常问的五件事（哪天回、谁接手、有无证明、能否联系、为何是这几天）在正文里都有答案？
- [ ] 用户没给的信息全是 [待补] 或 [待确认]，没有编造的事由、诊断或证明？
- [ ] 附件清单每条都标了「以本单位制度为准」？
- [ ] 对能休几天、扣不扣钱、能不能不批，没有下任何结论？

## 示例

示例（对话发生在 2026 年 11 月 4 日，周三；人名均为虚构）：

**用户**：明天发烧要去医院，帮我给班主任写个请假条。

**助手**（先问）：三件事确认一下：你在哪个班、班主任怎么称呼？请一天还是半天，预计哪天回校？医院会开诊断证明吗，家长能签字吗？

**用户**：高二（3）班，班主任李老师。明天请一天，后天回。会开证明，家长能签。

**助手**（先核对天数：`python3 scripts/leave_days.py 2026-11-05 2026-11-05` 输出自然日 1 天，其中周一至周五 1 天），交付：

```
请假条
李老师：
我是高二（3）班的[待补：姓名]，因发烧需去医院就诊，需请假1天（11月5日，星期四，全天），11月6日（星期五）正常返校。
落下的课程和作业，我会向[待补：同学姓名]借笔记，返校当天补交作业。
附：医院诊断证明（就诊后补交）
恳请批准。
请假人：[待补：姓名]    家长签字：______    联系电话：[待补]
2026年11月4日
```

- 系统一行版：不需要（学校场景）。
- 附件清单：医院诊断证明，就诊后补交；要不要交、交原件还是复印件，以学校规定为准。
- 待补：姓名、借笔记的同学、联系电话。待确认：如果医生让多休息，在 11 月 5 日放学前向李老师续假。

## 常见问题（FAQ）

**Q：只口头请过假，还用写书面的吗？**
A：看本单位制度；即使口头同意了，也建议补书面或在系统里留痕，免得考勤对不上。急病急事可以先打电话、发微信，返岗或返校第一天补交书面材料。

**Q：医院没开证明，或者证明丢了怎么办？**
A：先问医院能否补开证明或打印就诊、缴费记录；正文里如实写「诊断证明补交中」。不代开、不修改任何证明，缺了怎么处理以本单位制度为准。

**Q：「共几天」按工作日还是自然日算？**
A：以本单位口径为准。`scripts/leave_days.py` 同时给出自然日和周一至周五天数，节假日和调休要你标注后再算。

**Q：能不能直接帮我发给老师，或者在系统里提交？**
A：不能，本技能只写文本；发送、提交和审批都由你自己操作。

**Q：假期到了还回不去怎么办？**
A：在原假期结束前申请续假，写明原起止、续假起止、合计天数和原因，附新的证明，模板见 [references/templates.md](references/templates.md) 第 5 节。

**Q：只请半天或几个小时怎么写？**
A：起止写到时刻，如「自 11 月 5 日 9:00 至 11:30，共 2.5 小时」；按天计的半天用 `--from-half pm` 或 `--to-half am` 算。

**Q：事假的理由涉及隐私，必须写清楚吗？**
A：写到能批即可，如「家中有事须本人处理」；单位要求说明材料的，按制度提供。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 只写「因个人原因请假几天」 | 起止、天数、交接全没有，大概率被退回 | 事由写到能批，起止到半天，写明共几天和交接人 |
| 起止写「明天到后天」 | 没有日期，也没说上午还是下午，事后对不上考勤 | 写「11 月 5 日（星期四）上午至 11 月 6 日（星期五）下午」 |
| 天数和日期对不上：写 3 天，日期却跨了 4 天；或把周末算进了工作日 | 审批和考勤都按日期重算，对不上就退回 | 用 `scripts/leave_days.py` 算，注明工作日还是自然日 |
| 病假写了一大段病史 | 批假只需要概况，多写只是暴露隐私 | 写病情概况和医嘱休息天数，细节交给证明材料 |
| 先走后批 | 没有任何请假记录，考勤上说不清 | 急病急事可以先打电话，但事后一定补书面 |
| 到期不归 | 超出的天数没有批准，怎么处理要看本单位制度，往往很被动 | 原假期结束前申请续假，写明原起止、续假起止和原因，附新的证明 |
| 回来不销假 | 系统一直显示请假中，考勤对不上 | 返校、返岗当天跟老师或主管说一声，系统里有销假步骤的要点掉 |
| 编理由、改证明 | 一经核实，比请假本身麻烦得多 | 如实写到能批的程度；证明缺了就写「补交中」 |

## 边界与不做什么

- 不涉及劳动法定性：假期该有几天、工资怎么算、单位能不能不批、算不算旷工、会不会影响劳动合同，去问人事、工会或当地劳动保障部门，需要时咨询律师。
- 不给医疗建议，不判断该休几天病假，以医生开具的为准。
- 不代开、不修改任何证明材料。
- 学生请长假、休学、缓考，走学校正式程序，找班主任、辅导员或教务。
- 不替用户在任何系统里提交或审批。
