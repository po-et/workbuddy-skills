# 请假条

定位一句话：**请假条要让批假的人不用回问就能批——谁、为什么、从哪天几点到哪天几点、共几天、落下的课或手上的活怎么安排、怎么找到你。**
何时用：学生向班主任、辅导员请假；员工向主管或人事提交请假申请，或在办公系统里填请假理由；口头请过假、事后要补书面材料时。

## 先判断：场景、假别、时间、流程

| 要定的事 | 怎么判断 |
|---|---|
| 场景 | 学校（交班主任或辅导员）还是公司（交主管或人事），两套格式见下一节 |
| 假别 | 病假、事假、婚假、产假、年假还是其他；假别决定理由写多细、附什么材料 |
| 时间 | 起止精确到日期加上午、下午或时刻；按工作日还是自然日计，以本单位口径为准 |
| 流程 | 先口头打招呼还是直接提交、要不要逐级审批、提前几天申请、交原件还是复印件，以本单位制度为准 |

拿不准制度时，先翻学生手册或员工手册，或直接问班主任、人事；不要凭印象写天数。

批假的人最常回问五件事：哪天几点回来？落下的课或手上的活谁管？有没有证明？这几天能不能联系上？为什么非得是这几天？动笔前把这五问的答案列出来，写进正文，一次就能批。

## 两套格式：学校与公司

```
【学校请假条】
请假条
[李老师]：
我是[班级]的[小王]，因[事由，一句话写清]，需请假[N]天，自[X月X日]（星期[ ]）[上午/全天]至[X月X日]（星期[ ]）[下午]，共[N]天。
落下的课程和作业，我会[向谁借笔记，哪天前补交]。
附：[医院诊断证明等；没有就删去此行]
恳请批准。
请假人：[小王]    家长签字：[ ]    联系电话：[ ]
[年月日]

【公司请假申请】
请假申请
[部门负责人]：
本人[姓名]，[部门、岗位]，因[事由]，申请[假别][N]天，自[X月X日 时刻]至[X月X日 时刻]，共[N]个工作日（或自然日，按本单位口径）。
工作安排：[在办事项]已交接给[同事]；紧急事项可在[时段]通过[电话]联系我。
附件：[证明材料名称]
请审批。
申请人：[姓名]    [年月日]
```

- 未成年学生请假，通常要家长签字，或由家长同时联系老师；低年级由家长代写的，第一句改成「我是[班级][孩子姓名]的家长[姓名]」，落款写家长姓名和电话。
- 按半天或小时请的，起止写到时刻，如「自[X月X日] 9:00 至 11:30，共 2.5 小时」。
- 办公系统里的「请假理由」栏只写一行：假别＋事由＋天数＋交接人，例如「病假：急性肠胃炎，医嘱休息 2 天，附诊断证明；工作已交接小李」。

模板里的「共[N]天」别心算，输入起止日期，输出自然日与其中的周一至周五天数：

```bash
python3 -c "import datetime as d,sys;a,b=(d.date.fromisoformat(x) for x in sys.argv[1:3]);n=(b-a).days+1;w=sum((a+d.timedelta(i)).weekday()<5 for i in range(n));print('自然日',n,'其中周一至周五',w)" 2026-11-05 2026-11-11
```

脚本不认识法定节假日和调休上班日，要对照当年放假安排手动加减；最终以考勤记录为准。

## 五种假别的写法差异

| 假别 | 事由写到什么程度 | 常见要附的材料（以本单位制度为准） | 特别留意 |
|---|---|---|---|
| 病假 | 病情概况＋医嘱休息天数，不必写全诊断 | 诊断证明或病假条、就诊或缴费记录 | 急病先电话告知，返岗后补材料 |
| 事假 | 什么事、为什么必须本人去、为什么是这几天；涉及隐私的，写到「家中有事须本人处理」即可 | 通常不用；个别单位要求说明材料 | 是否扣薪、全年上限，先看制度 |
| 婚假 | 登记日期或婚礼日期 | 结婚证复印件 | 天数、有没有休假时限，各地各单位不同 |
| 产假 | 预产期或分娩日期，产前的工作交接安排 | 医院出具的预产期或生育证明、出生医学证明 | 天数与待遇差异大，提前找人事确认 |
| 年假 | 起止与剩余年假天数，不必写理由 | 一般不用 | 提前多久申请、能否分段、能否跨年，看制度 |

其他假别（丧假、陪产假等）照同一思路：事由写到能批，日期写全，材料按制度附。

## 口头请假后的书面补录

来不及走流程时，先用微信或电话打招呼，一条消息说全：

```
【微信先打招呼】
[李经理]，我[明天上午]要[去办理证件]，想请[半天事假]（[9:00–13:00]）。[手上的报表]已交接给[小李]，下午正常到岗。稍后在系统里补申请，您看可以吗？
```

对方同意后，按下面四步补书面：

1. 时间：返岗、返校第一天就交，别等人来催。
2. 写清当时的请假过程：哪天几点、向谁、用什么方式（电话、微信、当面）、对方怎么答复的。
3. 起止按实际发生写；比口头说的多了或少了，写明原因。
4. 该附的材料附上；聊天记录截图自己留存备查，一般不必附。

```
补假申请
[称呼]：
[X月X日][时刻]，我因[事由]通过[电话/微信]向您请假[N]天，您当时同意。现补交书面申请：实际自[ ]至[ ]，共[N]天[，比原计划多N天，原因是……]。
附件：[ ]
申请人：[姓名]    [年月日]
```

没请假就缺了勤的，不属于补录，要写情况说明，可配合检讨书技能 `reflection-letter`。

## 最常见的错误

- 只写「因个人原因请假几天」：起止、天数、交接全没有，大概率被退回。
- 起止写「明天到后天」：没有日期，也没说上午还是下午。
- 天数和日期对不上：写 3 天，日期却跨了 4 天；或把周末算进了工作日。
- 病假写了一大段病史：批假只需要概况，细节交给证明材料。
- 先走后批：急病急事可以先打电话，但事后一定补书面。
- 到期不归：需要延长的，在原假期结束前申请续假，写明原起止、续假起止和原因，附新的证明。
- 回来不销假：返校、返岗当天跟老师或主管说一声，系统里有销假步骤的要点掉。
- 编理由、改证明：一经核实，比请假本身麻烦得多。

## 输出契约

1. 先问：学校还是公司、假别、起止到半天、是否已口头请过、本单位有没有模板或系统字段。
2. 交付：可直接提交的正文；系统「请假理由」一行版；要附材料的清单，每条标注「以本单位制度为准」。
3. 天数只按用户给的日期算，节假日和调休标出来让用户核对。
4. 不编造事由、诊断和证明，用户没给的留 [ ]。

## 边界与不做什么

- 不涉及劳动法定性：假期该有几天、工资怎么算、单位能不能不批、算不算旷工、会不会影响劳动合同，去问人事、工会或当地劳动保障部门，需要时咨询律师。
- 不给医疗建议，不判断该休几天病假，以医生开具的为准。
- 不代开、不修改任何证明材料。
- 学生请长假、休学、缓考，走学校正式程序，找班主任、辅导员或教务。
- 不替用户在任何系统里提交或审批。
