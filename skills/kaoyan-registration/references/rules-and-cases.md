# 报考点、校验与修改：常见情况与处理

本文件是 [SKILL.md](../SKILL.md) 第 2、3、4、6 节的展开。下面写的是**常见情况**，每一条都以教育部、研招网、省级教育招生考试机构和报考点的当年公告为准；公告与本文不一致时，一律以公告为准。

## 1. 报考点判断表

| 你的情况 | 常见原则 | 要额外核实的 |
|---|---|---|
| 应届本科毕业生 | 原则上选就读学校所在省（区、市）的报考点 | 本校是否设报考点、是否只收本校生 |
| 往届生，在职 | 原则上选工作所在地或户口所在地省级教育招生考试机构指定的报考点 | 报考点是否要求工作证明、社保证明等 |
| 往届生，未就业 | 原则上选户口所在地的报考点 | 报考点接收范围 |
| 单独考试、部分管理类专业学位 | 常有专门规定（如在招生单位所在地） | 招生简章和当年公告的具体要求 |
| 应届生但人在外地实习 | 实习地通常不属于应届生的原则范围 | 两地报考点公告有无例外；提前安排考试期间的行程 |

## 2. 打电话问报考点的问题清单

打之前准备好：身份证号不必报，只说身份类别和问题。

1. 我是[应届 / 往届]考生，[就读 / 户口 / 工作]在[省份]，能否在贵报考点报考？
2. 网上确认要上传哪些材料？照片有什么具体要求？
3. 学历学籍校验不通过，认证报告最晚什么时候上传？
4. 审核不通过会怎么通知？补传的截止时间？

记录：日期、时间、接听人（如对方愿意告知）、答复原文。答复与公告不一致时，以公告为准，并请对方说明依据。

## 3. 学历学籍校验不通过：分情况处理

| 情况 | 先做 | 再做 |
|---|---|---|
| 填写错误 | 在报名期内按系统说明修改或重新填报 | 再查校验结果 |
| 应届生：学籍状态异常、改名、转专业未更新 | 找本校学籍管理部门核实 | 在学信网申请《教育部学籍在线验证报告》，按报考点要求上传 |
| 往届生：学历数据查不到或不一致 | 在学信网查询本人学历信息 | 申请《中国高等教育学历认证报告》，按报考点要求上传 |
| 国（境）外学历 | 准备学位证书等材料 | 申请教育部留学服务中心的国（境）外学历学位认证书 |
| 以同等学力身份报考 | 看招生单位对同等学力的报考条件和加试要求 | 按报考点和招生单位要求提交材料 |

时间：认证需要办理周期，一般要在网上确认结束前完成（以报考点公告为准），所以发现不通过当天就办。

## 4. 照片与材料：常见要求

| 材料 | 常见要求（以报考点公告为准） |
|---|---|
| 证件照 | 近期、正面、免冠、无美颜、不 PS；背景颜色、尺寸、格式、文件大小按公告 |
| 身份证件 | 有效期内的居民身份证正反面，清晰完整 |
| 学生证 / 毕业证书 | 应届生学生证（含注册信息页），往届生毕业证书 |
| 认证报告 | 校验不通过者上传对应报告 |
| 专项计划证明 | 按招生简章要求，符合条件者提交 |
| 其他 | 报考点另行要求的材料 |

照片会印在准考证上，也用于考试和复试时的身份核验；照片和本人差别太大可能带来麻烦。

## 5. 修改规则：常见情况

| 时点 | 常见情况 | 建议 |
|---|---|---|
| 报名期内、未缴费 | 可修改 | 核对表全过一遍再缴费 |
| 报名期内、已缴费 | 多数信息仍可修改或重新填报一条，只保留一条有效信息；换报考点常需重新填报并缴费 | 改完确认只剩一条有效信息；费用处理问报考点 |
| 报名截止后 | 不再补报、一般不能再改 | 立即联系报考点说明情况，以其答复为准 |
| 网上确认后 | 报名信息在考试、复试、录取阶段一般不得修改 | 确认前第三遍核对 |

## 6. 专项计划与特殊情况

- 专项计划（如退役大学生士兵专项计划、少数民族高层次骨干人才计划等）有明确的报考条件和证明材料要求，以当年公告和招生简章为准；不符合条件不要选。
- 定向与非定向、全日制与非全日制的区别，以招生单位简章为准；定向就业一般要与用人单位签协议，报名前看清。
