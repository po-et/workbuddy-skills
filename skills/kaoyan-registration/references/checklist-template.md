# 报名信息核对表（模板）

用法：报名前把要填的内容先写进这张表，每一项都写清「对照来源」，再和系统里填的逐项对。**缴费前、报名截止前、网上确认前各核一遍**，最好请一位同学按表念、你看屏幕对。栏目以研招网报名系统的实际页面为准，下表是常见栏目。

结果列只填三种：✓（一致）、✗（不一致，写明改成什么）、[待确认]（还没找到依据）。
