# 考研报名

定位一句话：**报名不考知识，考细心——报考单位、专业代码、考试方式、报考点、照片材料，哪一项错了都可能让几个月的复习白费。所有日期一律以教育部和中国研究生招生信息网（研招网，yz.chsi.com.cn）当年公告为准。**

## 何时使用

用户这样说时用本技能：

- 「考研报名要注意什么？流程帮我理一下」
- 「报考点怎么选？我在外地实习，户口在老家」
- 「学历学籍校验没通过怎么办」
- 「网上确认要传什么照片、什么材料」
- 「帮我逐项核对一下报名信息」
- 「交完费发现专业选错了，还能改吗」

不适用（遇到时这样处理）：

- 择校择专业、复习规划、真题讲解：本技能不做，一句话说明后建议找对应的备考类技能或咨询目标院校。
- 推免（保研）：走推免服务系统，不是统考报名，转交保研技能。
- 复试、调剂、同等学力加试：以招生单位通知和研招网当年公告为准，本技能只管到准考证打印和初试前。

## 1. 一般流程（日期以当年公告为准）

```
看招生简章与专业目录 → [预报名，若当年安排] → 正式网上报名（填报、缴费）
→ 查看学历学籍校验结果 → 网上确认（上传照片与材料，报考点审核）→ 下载打印准考证 → 初试
```

- 公告去哪看：教育部当年的硕士研究生招生工作管理规定与报名公告；研招网的网上报名公告；报考点所在省级教育招生考试机构和报考点的网上确认公告；招生单位官网的招生简章与专业目录。
- 预报名：近年并非每年都安排；当年有没有、面向谁，看当年公告。
- 报名期内常见规定：一位考生只能报考一个招生单位的一个专业；报名期内可修改或重新填报，但只保留一条有效信息；逾期不再补报，也不能再改（常见情况，以当年规定为准）。
- 账号：研招网与学信网账号通用（以网站说明为准）。报名前找回密码、绑定常用手机号；只从研招网首页进入报名系统，不点群里或短信转发的链接。

## 2. 报考点怎么选

按这个顺序判断（常见原则，以当年公告为准）：

1. **你的身份**：应届本科毕业生原则上选就读学校所在省（区、市）的报考点；其他考生原则上选工作或户口所在地省级教育招生考试机构指定的报考点。
2. **特殊考试方式**：单独考试、部分管理类专业学位等，报考点常有专门规定（如要求在招生单位所在地），看当年公告和招生简章。
3. **报考点公告**：有的报考点只接收特定考生（如本校应届生）、有容量限制或要求额外材料，报名前先读目标报考点的公告。
4. **现实因素**：考场离住处多远、考试那两天能否在当地住下。

拿不准时，打报考点公告里的咨询电话，记下答复内容、日期和接听人。问题清单见 [references/rules-and-cases.md](references/rules-and-cases.md)。

## 3. 学历学籍校验不通过怎么办

研招网会把你填的学历学籍信息与学信网数据比对，报名后可查看校验结果。

| 常见原因 | 处理 |
|---|---|
| 填错：证书编号、毕业年份、学习形式、学校名称 | 报名期内改正或重新填报，再看校验结果 |
| 应届生学籍信息未更新（改名、转专业、学籍注册异常等） | 找本校学籍管理部门核实更新；在学信网申请《教育部学籍在线验证报告》 |
| 往届生学历数据问题 | 在学信网申请《中国高等教育学历认证报告》 |
| 国（境）外学历 | 由教育部留学服务中心出具国（境）外学历学位认证书 |

认证需要时间，发现不通过当天就办；一般须在网上确认结束前完成，并按报考点要求上传（以报考点公告为准）。

## 4. 照片与材料（以报考点公告为准）

常见要求：

- 照片：本人近期正面免冠证件照，通常在网上确认环节上传；背景、尺寸、格式、文件大小按报考点公告。不美颜、不 PS、不用生活照——照片会印在准考证上，也用于后续身份核验。
- 居民身份证正反面；应届生学生证、往届生毕业证书。
- 校验不通过的：对应的认证报告。
- 专项计划考生：符合条件的证明材料，按招生简章。
- 报考点另行要求的其他材料。

## 5. 报名信息逐项核对

原则：**以招生单位的专业目录、你的身份证件和学历证书为准，逐字逐位对，最好两人各核一遍。**重点项：

- 报考单位名称与代码；报考院系所；6 位专业代码（学术学位和专业学位代码不同）与研究方向。
- 学习方式（全日制 / 非全日制，两者培养方式、学费和录取类别常不同，看简章）；报考类别（定向 / 非定向）。
- 考试方式（全国统考、联考、单独考试等，按简章）；专项计划（只有符合条件、能交证明的才选）。
- 考试科目：外语是英语（一）还是英语（二），数学是（一）（二）（三）中的哪个，业务课代码与名称。
- 报考点：省份与报考点名称。
- 个人信息：姓名、证件号码、考生身份（应届 / 往届）、手机号、档案所在单位与地址、学习与工作经历等（以系统实际栏目为准）。

## 6. 缴费与确认后能改什么（常见情况，以当年规定为准）

| 时点 | 常见情况 |
|---|---|
| 报名期内、未缴费 | 信息可以修改 |
| 报名期内、已缴费 | 多数信息仍可在报名期内修改或重新填报一条；想换报考点常需重新填报并缴费，原费用怎么处理以报考点规定为准 |
| 报名截止后 | 不再补报，一般不能再修改报名信息 |
| 网上确认后 | 确认后的报名信息在考试、复试、录取阶段一般不得修改，填错的后果由考生承担 |

所以：**缴费前核一遍，报名截止前再核一遍，网上确认前第三遍。**

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（一句模板） |
|---|---|---|
| 缺关键信息（应届/往届、就读地与户口地、报考单位和专业） | 先问这 3 项；其余栏目留 [待补]，推断的标 [待确认] | 「先确认三件事：你是应届还是往届？就读学校和户口、工作各在哪个省？报考哪个学校哪个专业？」 |
| 信息自相矛盾（想报专业学位，填的却是学术学位代码；专业目录写英语一，填了英语二） | 指出具体哪项不一致，给两种理解让用户选，以专业目录为准 | 「你说报专业学位，但代码 081200 是学术学位。是要改成专业目录里的专业学位代码，还是其实想报学术学位？」 |
| 用户问具体日期、费用、某报考点政策 | 不凭记忆给数字；告诉去哪份公告查，表里标 [待补：见某公告] | 「今年的具体日期以研招网公告为准，我在时间线里标出了该去哪份公告查。」 |
| 超出本技能范围（择校、复习、复试调剂、推免） | 一句话说明边界并转交 | 「择校和复习不在这个技能里；报名信息我可以帮你逐项核对。」 |
| 时间紧，只要最小可用版 | 只核 6 项：报考单位、专业代码、学习方式、考试方式与专项计划、考试科目、报考点；其余报名截止前补核 | 「先把最容易出大错的 6 项核完，其余在截止前补。」 |
| 用户坚持越界（代填代缴、修改学历信息、借别人身份报名、买「内部名额」） | 守住边界，给合规替代 | 「报名和缴费得你本人操作，学历信息也不能改；校验不通过我可以教你怎么办认证。」 |
| 已缴费后才发现填错 | 分时点处理：报名期内按系统说明修改或重新填报；已过截止，立即联系报考点问能否处理，以其答复为准 | 「现在还在报名期内，先按系统说明改；改完重新核一遍。」 |

## 输出契约

交付物按这个顺序，不增不减：

1. **报名信息核对表**：按模板逐项填，每项写对照来源和结果（✓ / ✗ / [待确认]）。
2. **报考点判断**：身份 → 适用原则 → 目标报考点公告要点 → 结论或待确认。
3. **材料清单**：每条标「以报考点公告为准」。
4. **时间线**：节点、日期、出处；日期未知一律写 [待补：见某公告]。
5. **风险提示与待办**：校验、照片、专项计划等，逐条列出。

占位符规则：用户没给的写 `[待补：……]`；需要用户按公告核实的写 `[待确认：……]`；不写任何具体年份的日期和费用数字，除非用户给出公告原文。

交付前自检（逐条答「是」才交）：

- [ ] 所有日期都写成「以教育部和研招网当年公告为准」或 [待补：见某公告]，没有凭记忆写的日期？
- [ ] 专业代码、考试科目逐项对照了专业目录，矛盾处已指出？
- [ ] 报考点结论写明了依据（身份与公告），拿不准的标了 [待确认]？
- [ ] 修改规则写成「常见情况，以当年规定为准」？
- [ ] 没有替用户操作系统、缴费或修改学历信息的承诺？

## 示例

示例（考生为虚构）：

**用户**：下周正式报名，帮我看看报考点怎么选。我是应届，学校在武汉，户口在河南，现在在上海实习，想在上海考。

**助手**（先问）：两件事：报考哪个学校哪个专业、什么考试方式？你们学校或上海的报考点公告里，对外省应届生有没有接收限制？

**用户**：报示例大学的电子信息专硕，全国统考。公告还没看。

**助手**（交付「报考点判断」）：

```
报考点判断
身份：应届本科毕业生，就读学校在湖北，户口在河南，实习在上海。
适用原则：应届本科毕业生原则上选择就读学校所在省（区、市）的报考点（常见原则，以当年公告为准）。
初步结论：按原则应选湖北的报考点；上海不在原则范围内。[待确认：湖北、上海两地报考点当年公告有无例外规定]
下一步：①读湖北省级教育招生考试机构和本校报考点的当年公告；②拿不准就打报考点咨询电话，记下答复和日期；
③按结论在报名时选报考点，缴费前再核一遍。
考试那两天：若在湖北考，提前安排回武汉的行程和住宿。
```

## 常见问题（FAQ）

**Q：今年什么时候报名？**
A：以教育部和研招网当年公告为准。公告一出，把报名、网上确认、准考证下载、初试四个日期填进时间线表。

**Q：能不能帮我直接登录报名、缴费？**
A：不能。报名、缴费和确认都要你本人操作，也不要把研招网账号密码发给任何人；我可以帮你逐项核对要填的内容。

**Q：学籍校验不通过，会不会不能考？**
A：按要求在网上确认结束前完成学籍或学历认证并上传，一般就能继续；具体以报考点公告为准，发现不通过当天就办。

**Q：交完费发现报考点选错了怎么办？**
A：报名期内常见做法是重新填报一条并缴费，原费用怎么处理以报考点规定为准；已过截止就立即联系报考点。

**Q：非全日制和全日制有什么区别，会不会选错？**
A：两者培养方式、学费和录取类别常不同，以招生单位简章为准；报名时对着简章选，核对表里单列一项。

**Q：照片能不能用手机拍？**
A：按报考点公告的要求来；不管用什么拍，都要近期、正面、免冠、无美颜，背景和尺寸符合要求。

**Q：往届生档案所在单位怎么填？**
A：按档案实际存放的单位填（如人才服务机构或原学校），拿不准就先问档案存放单位；这一栏以系统说明为准。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 凭往年经验记日期 | 每年日期和安排可能不同 | 以当年公告为准，时间线表里写出处 |
| 专业代码凭印象选 | 学术学位与专业学位代码不同，选错就是报错专业 | 对照专业目录逐位核对 |
| 英语一、英语二，数学一二三选错 | 考试科目以专业目录为准，选错后果严重 | 核对表单列「考试科目」一项 |
| 看都不看就选离得近的报考点 | 报考点有接收范围和特殊规定 | 先按身份判断，再读报考点公告 |
| 专项计划随手勾选 | 不符合条件会在审核或录取时出问题 | 只有符合条件、能交证明的才选 |
| 学籍校验不通过拖着不办 | 认证需要时间，错过网上确认就被动 | 发现当天就办认证 |
| 照片用美颜或生活照 | 可能审核不通过，也影响后续身份核验 | 按公告拍近期正面免冠证件照 |
| 点群里转发的报名链接 | 可能是钓鱼网站 | 只从研招网首页进入 |

## 边界与不做什么

- 不替用户登录、填报、缴费、确认，不索要或保存账号密码。
- 不修改、不代办学历学籍信息，不伪造任何证明；认证按学信网、教育部留学服务中心的正规渠道办。
- 不给具体年份的日期、费用和报考点政策结论，一律以教育部、研招网、省级教育招生考试机构和报考点的当年公告为准。
- 不做择校、复习、复试和调剂指导；推免转交保研技能。
- 不帮助任何形式的替考、借用他人身份或购买所谓「内部名额」。
