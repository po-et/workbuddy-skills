# 奖学金申请

定位一句话：**评审只看得见你写出来的事实。先把事实盘点全，再挑和这项奖学金侧重最对得上的两三件，用 STAR 写透——而不是把六个维度各夸一句。**

## 何时使用

- 「帮我写国家奖学金申请书，学校要求 1500 字以内」
- 「国家励志奖学金申请表里申请理由只有 200 字，怎么写」
- 「企业奖学金要交一份个人陈述」
- 「帮我看看这份申请书哪里写空了」
- 「下周奖学金答辩，评委一般会问什么」

不适用：
- 助学金、困难补助（看家庭经济情况）：转 `financial-aid-application`（助学金申请书）。
- 留学英文文书（PS、SOP）、保研推免材料：思路可以借鉴，本技能不覆盖，直接说明。
- 问「我够不够条件」「能拿多少钱」：条件、名额、金额以学校当年通知为准，请用户对照通知或问辅导员。

## 写作流程

### 第 1 步：先读通知

请用户把学校（学院）当年的通知原文或申请表文字贴过来，从中找出：奖项类型、申请条件、字数与格式、截止时间、要附的材料、有没有答辩。**具体条件与材料一律以学校当年通知为准**，本技能只管写法。没有通知的，相关项写 [待确认]，并提醒用户问辅导员。

### 第 2 步：按六个维度盘点事实

| 维度 | 要问到的事实 | 常见证明 |
|---|---|---|
| 成绩 | 绩点或平均分、专业排名（名次/总人数）、有无不及格、进步幅度 | 成绩单、排名证明 |
| 科研 | 项目或课题名称与级别、你负责哪一块、产出（论文、专利、报告）及署名位次 | 立项或结题文件、论文首页 |
| 竞赛 | 竞赛全称、级别、名次、时间、团队分工 | 获奖证书 |
| 实践 | 实习、社会调查、学生工作：职务、任期、做成的具体事 | 实习证明、任职证明 |
| 志愿 | 项目、服务时长、你具体做了什么 | 志愿服务时长记录 |
| 品德 | 能体现诚信、担当、帮助他人的具体事件；有无违纪 | 表彰文件、他人评价（可选） |

规则：没有证明材料、或说不出细节的事，不写进去；说不准的数字标 [待确认]。追问话术、盘点表与「空话替换表」见 [references/fact-inventory.md](references/fact-inventory.md)。

### 第 3 步：按奖项类型定侧重

| 类型 | 评审更看重什么 | 写法重点 |
|---|---|---|
| 学业奖学金 | 学业成绩与综合测评 | 不少学校直接按综测排名评定、不需要陈述；要写的，以成绩为主线，其他维度各一两句 |
| 国家奖学金 | 「特别优秀」：学业之外，至少一个方向有突出表现 | 学业一段＋1–2 个 STAR 突出事迹，写透过程和你个人的贡献 |
| 国家励志奖学金 | 品学兼优，且面向家庭经济困难学生 | 学业与自立并重：困难只陈述事实，重点写你做了什么（勤工助学、学业进步） |
| 企业/社会奖学金 | 设奖方的宗旨与方向（专业、创新、公益等） | 读透设奖说明，挑和它对得上的事实；不吹捧企业 |

上表是写作侧重，不是申请条件。申请年级、成绩门槛、是否需要先认定家庭经济困难、能否同时申请几项、名额与金额，一律以学校当年通知为准。完整模板与申请理由短版见 [references/types-and-template.md](references/types-and-template.md)。

### 第 4 步：用 STAR 写每件突出事迹

- **S 背景**（一句）：什么时候、什么项目或比赛。
- **T 任务**（一句）：你负责什么、目标是什么。
- **A 行动**（占一半篇幅）：你具体做了什么，用「我」开头的动词；团队项目写清你的分工。
- **R 结果**（一两句）：可核对的结果（名次、产出、数字），再加一句你因此学会或改变了什么。

写法示例（虚构）：「大二上学期，我和三名同学承担了校级创新训练项目（S）。我负责问卷设计和数据分析（T）。我用交叉分析发现，离出口远的窗口正确投放率只有 41%，近的是 73%，据此建议在出口加设回收桶（A）。建议被后勤采纳，项目结题评为良好（R）。」

### 第 5 步：成稿、压缩、自查

- 申请书：标题 → 称呼 → 基本情况一句 → 学业 → 突出事迹（STAR，1–2 个）→ 其他维度（各一两句）→ 规划与感谢 → 落款。
- 申请理由栏（常只有一两百字）：一句定位＋两三个最硬的事实＋一句规划，不写客套。
- 交之前跑一遍自查：

```bash
python3 scripts/claim_check.py 申请书.txt --limit 1500
```

输出字数（含标点、不含标点）与上限对比、残留占位符、空泛表述（附替换思路）、「需与证明材料逐条核对的事实」清单。支持 .txt、.md、.docx。

### 面试/答辩准备

常见题：一分钟自我介绍；你最突出的一点；这个项目里你具体做了什么；成绩有波动的原因；奖学金打算怎么用；以后的规划。答法：结论先行 → 一个事实 → 回扣评审关心的点，每题 30–60 秒。题库与一分钟自我介绍骨架见 [references/interview-qa.md](references/interview-qa.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 只说「帮我写奖学金申请书」，没有通知、没有事实 | 先问 3 个：什么奖（最好贴通知原文）、字数和格式要求、最拿得出手的 2–3 件事（附时间和证明）；其余维度按「暂无」处理，稿中标 [待补] | 「先告诉我三件事：申请哪项奖学金（通知原文最好）、有没有字数要求、你最拿得出手的两三件事是什么，各有什么证明？」 |
| 事实前后矛盾（如排名写 3/120，另一处写「专业第一」） | 指出矛盾，给两种理解，以材料为准 | 「前面是专业排名 3/120，这里写『专业第一』。是某一门课第一，还是综测第一？以成绩单为准，我再统一。」 |
| 要求拔高、编造（「写成国家级」「加一篇论文」） | 不写；说明风险，改成如实表述 | 「评审会对照证书核验，写高了一旦查实就是诚信问题。把真实的省级奖写透，一样有分量。」 |
| 问「够不够条件」「能拿多少钱」 | 不判断，指向通知与辅导员 | 「条件、名额和金额以学校当年通知为准，我没法替学校判断。把通知贴给我，我帮你逐条对照要准备什么。」 |
| 其实是助学金或留学文书 | 超出范围，转交 | 「看家庭经济情况的是助学金，用『助学金申请书』技能更合适；英文 PS 不在本技能范围内。」 |
| 明天就截止，只要最小可用版 | 最小版：基本情况一句＋成绩一句（带数字）＋一个 STAR 突出事迹＋规划一句，约 300 字；其余标 [待补] | 「先交这版最小可用的：成绩一句、最突出的一件事、一句规划，其他维度有时间再补。」 |

脚本报错：

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 1「参数或输入有误：--limit……」 | `--limit` 不是 1–100000 的整数 | 例：`--limit 1500` |
| 1「没有可检查的文字」 | 空文件，或只有标题 | 确认文件里有正文 |
| 2「文件问题：……」 | 路径不对、没权限、PDF 或旧版 .doc、编码无法识别 | 另存为 .txt（UTF-8）或 .docx |
| 130 | 按了 Ctrl+C | 重新运行即可 |

## 输出契约

交付物按以下顺序：

1. **通知要点**：奖项｜字数与格式｜截止时间｜要附材料｜有无答辩（缺的标 [待确认]）
2. **事实盘点表**：六个维度 × 事实／证明材料／是否采用
3. **申请书正文**（或申请理由短版）
4. **证明材料核对清单**：正文每条事实 ↔ 对应材料（可用脚本第 3 部分生成）
5. **答辩要点**：3–5 题（有答辩时）

占位符：用户必须补的写 `[待补：补什么]`；替用户假设的写 `[待确认：假设了什么]`。有占位符时，交付第一句就提醒。

交付前自检（逐条答「是」才交）：
- 正文每个数字、名次、奖项名称都在事实盘点表里，且有对应的证明材料
- 至少一件突出事迹按 STAR 写，行动部分写清「我」做了什么
- 字数不超过通知要求（上限按含标点计）
- 没有写出通知里没有的申请条件、金额或名额
- 没有「成绩优异」「积极参加各类活动」这类没有事实支撑的空话
- 占位符已在交付第一句提醒

## 示例

以下为示例，人物与数字均为虚构。

**用户**：国家励志奖学金的申请表，「申请理由」栏大概写 200 字。我大二，上学年绩点 3.62，专业排名 8/96；在学校图书馆勤工助学，一学年累计 180 小时；拿过一次英语演讲比赛三等奖；家庭经济困难认定已经通过了。

**助手**：问三个小问题：① 比赛的全称和时间，证书上怎么写就怎么写；② 图书馆勤工助学具体做什么；③ 下学年有什么具体打算？学院和专业名称也告诉我。

**用户**：2026 年 4 月，证书写的是「校大学生英语演讲比赛三等奖」。图书馆是周末的图书归架和借还。下学年想考过六级，继续在图书馆做。学院专业先空着，我自己填。

**助手**（交付）：学院、专业留了 [待补]；字数上限请以申请表为准。

信息行：国家励志奖学金｜申请表「申请理由」栏｜约 150 字｜[待确认：申请表的字数上限]

> 本人是[待补：学院][待补：专业]大二学生，已通过家庭经济困难学生认定。上学年绩点3.62，专业排名8/96。课余在学校图书馆勤工助学，负责周末的图书归架和借还，一学年累计180小时。2026年4月，获校大学生英语演讲比赛三等奖。下学年，我计划通过英语六级考试，并继续在图书馆勤工助学。恳请评审老师审核。

证明材料核对：困难认定 → 学校认定结果；绩点、排名 → 成绩单与排名证明；180 小时 → 勤工助学工时记录；三等奖 → 获奖证书（名称以证书为准）。

自查脚本结论：`占位符 2 处 | 空泛表述 0 处 | 待核对事实 4 条`（占位符就是用户自己要填的学院、专业）。

## 常见问题（FAQ）

**通知没写字数怎么办？** 问辅导员或看申请表格子的大小；确认之前，准备「申请理由短版＋完整申请书」两份。

**事迹不多，六个维度写不满怎么办？** 不用写满。评审更在意一两件写透的事；空着的维度一句带过或不写。

**团队拿的奖能写吗？** 能，但要写清你的分工和贡献，不要把团队成果写成个人成果。

**能写得夸张一点吗？** 不能。评审和公示环节都可能核对材料，如实写，靠细节取胜。

**几项奖学金能不能同时申请？** 以学校当年通知为准，本技能不判断申请资格。

**可以直接用示例吗？** 不行。示例人物和数字是虚构的，只看结构和写法。

**答辩紧张忘词怎么办？** 把一分钟自我介绍压成三句骨架（我是谁、最突出的一件事、接下来做什么），其他题都往这三句上靠。

**能帮我提交或者填系统吗？** 不代为提交、不登录任何系统；正文和材料清单交给你，由你本人提交。

## 常见错误（反模式）

- 六个维度各夸一句 → 评审一句也记不住 → 挑两三件写透。
- 「成绩优异」「多次获奖」 → 无法核对，像在凑字 → 写绩点、排名、奖项全称和时间。
- 把团队成果写成个人成果 → 答辩一问就露馅，涉及诚信 → 写清分工。
- 照搬往届或网上范文 → 雷同会被看出来，细节也对不上 → 从自己的事实盘点表写起。
- 客套话占一半（感谢国家、感谢学校写了三段） → 挤掉事实 → 感谢一两句，放结尾。
- 规划只写「努力学习，回报社会」 → 空 → 写下一学年可检验的目标。
- 不看通知直接写 → 格式、字数、材料不对被退回 → 先读通知。

## 边界与不做什么

- 只帮你整理和表达**你自己的真实经历**：会追问细节和证明材料；不编造、不拔高成绩、科研、竞赛、奖项、志愿时长或任何数据。示例中的人物与数字均为虚构。
- 不判断你是否符合条件、能否评上、能拿多少钱；申请条件、名额、金额、材料以学校当年通知为准。
- 不伪造、不修改任何证明材料，不代签名，不代为提交。
- 涉及家庭经济困难的陈述，按「助学金申请书」技能的原则写：只写事实，不渲染。
