# 四类奖学金的写作侧重、申请书模板、申请理由短版

**先说清楚：** 下面讲的是「怎么写更对评审的胃口」，不是申请条件。申请年级、成绩门槛、是否需要先认定家庭经济困难、几项能否同时申请、名额、金额、要交哪些材料，一律以学校当年通知为准。

## 一、四类奖学金怎么写

### 学业奖学金（校级、院级）
- 不少学校直接按综合测评或学业成绩排名评定，不需要写陈述；需要写的，按通知格式写。
- 以成绩为主线：绩点或平均分、排名、进步幅度；其他维度各一两句。
- 常见坑：把学业奖学金写成国奖那样的长篇事迹，重点反而被冲淡。

### 国家奖学金
- 评审找的是「特别优秀」：学业扎实，另外至少一个方向（科研、竞赛、实践、创新创业、志愿等）有突出、可核对的表现。
- 结构：学业一段 → 突出事迹 1–2 个（STAR，写透你个人做了什么）→ 其他维度简写 → 规划。
- 常见坑：奖项罗列成清单，没有一件写出过程；团队成果写成个人成果。

### 国家励志奖学金
- 面向品学兼优的家庭经济困难学生：学业表现与自立自强并重。
- 困难情况只陈述事实（写法见助学金申请书技能），不渲染；篇幅重点放在你做了什么——勤工助学、学业进步、帮助他人。
- 常见坑：通篇写家里有多难，学业和个人努力只有一句。

### 企业奖学金、社会奖学金
- 先读设奖说明：设奖方看重什么（专业方向、创新、实践、公益、地域等），就挑和它对得上的事实。
- 可以写你和设奖方向的真实联系（专业、实习、项目），但不要吹捧企业，不要写你并不了解的企业情况。
- 常见坑：一份申请书改个抬头投所有奖项，看不出为什么申请这一项。

## 二、申请书模板

```
[奖项名称]申请书

尊敬的[评审委员会／老师]：

我是[学院][专业][年级]学生[姓名]，[现任职务，没有就删]。根据[学校／学院]本年度[奖项名称]评审通知，我申请参评，现将[上学年]情况汇报如下。

一、学业：[一句话小标题，写你学业上最突出的一点]
[绩点或平均分、专业排名（名次/总人数）、有无不及格；一门代表性的课和你怎么学的，一两句。]

二、[突出事迹 1 的小标题]
[S 背景一句。T 你的任务一句。A 你做了什么（占一半篇幅）。R 可核对的结果＋你学会或改变了什么。]

三、[突出事迹 2 的小标题，可选]
[同上。]

四、服务与实践
[学生工作、志愿服务、社会实践：各一两句，带数字（时长、次数、任期）。]

五、下一步
[下一学年一到两个可检验的目标；和你的专业或突出方向接得上。]

[感谢一句。]恳请[评审委员会／老师]审核。

此致
敬礼！

申请人：[姓名]
[年月日]
```

使用说明：
- 方括号全部换成真实内容；没有的整段删掉，不要留空标题。
- 小标题写成「一句话结论」（如「科研：从一份问卷到食堂出口的回收桶」），比「科研情况」更容易被记住。
- 通知给了固定格式或表格的，以通知为准，本模板只作内容参考。

## 三、申请理由短版（申请表里的小格子）

按格子大小选一档，句子顺序固定：**定位 → 最硬的事实 → 规划**。

- **约 100 字**：一句定位（年级、专业、身份）＋两个最硬的事实（成绩排名＋一项突出表现）＋一句规划。
- **约 200 字**：一句定位＋成绩（带排名）＋一到两项突出表现（各一句，带时间和级别）＋一句规划。
- **约 300 字**：在 200 字版基础上，把最突出的一项展开成两三句的小 STAR。

短版里不写：客套和感谢（格子太小）、没有证明的形容词、与该奖项侧重无关的经历。

## 四、规划与感谢怎么写不空

| 空的写法 | 具体的写法（示例） |
|---|---|
| 努力学习，争取更大进步 | 下学年通过英语六级，专业排名保持在前 10% |
| 回报社会、回报母校 | 继续参加河道水质采样志愿服务，下学年累计再服务 40 小时 |
| 感谢国家、感谢学校、感谢老师…… | 感谢[具体的人]在[具体的事]上给我的指导（一句即可） |
