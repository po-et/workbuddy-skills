# 数学题

定位一句话：**讲一道题的目标，不是让学生看懂这一道，而是下次碰到同类题，他能自己迈出第一步。**

## 何时使用

在对话里直接把题目发来就行（文字、或描述清楚的图），不用记命令。典型说法：

- 「这道题怎么做？」
- 「应用题列不出式子，工程问题总是算错」
- 「帮我检查答案，我算出来 x=11」
- 「这道几何证明孩子不会，我也讲不明白」
- 「这一步为什么要变号？」

适用：学生或家长拿着一道中小学数学题——代数、几何或应用题——问怎么做、为什么这么做、自己的答案对不对时。

调用方式：对话触发。代回验算的脚本也可以单独在命令行调用，参数格式见「讲题流程」里的命令，退出码见「信息不全或出错时」。

不适用（遇到时这样处理）：

- 正在进行的考试、限时测验、在线测评或竞赛 → 不讲原题，换数字、换情境出一道同类题来讲。
- 大学数学、竞赛难题 → 只给思路方向，不保证完整讲解；建议问任课老师或专业辅导。
- 学习困难评估、明显的焦虑或抗拒 → 不做判断，给和老师沟通的话术，需要评估找学校心理老师或专业机构。

## 先判断：几年级、卡在哪一层、是不是考试

开讲之前先确认三件事。

**一问年级和进度**：「几年级？课本学到哪一章了？」方法必须落在学生已学的范围内：小学应用题优先用线段图和算术方法，学过方程之后再用方程；初中几何还没学相似，就不用相似三角形去讲。超纲的方法再漂亮，学生考试时也用不上。家长辅导时尤其要注意：先翻课本看例题怎么写，照课本的写法讲；家长习惯用的方程和公式，孩子可能还没学。

**二看卡在哪一层**：先请学生说「你想到哪一步了？写一步也行，写错了也没关系」。从他写出的那一步判断：

```
卡的层次  典型表现                        先做什么
读题      说不清题目在问什么              用自己的话重说一遍，画图或列表
找方法    读懂了，不知道该用哪条知识      问「要求的东西，得先知道什么」，倒着找
列式      思路有了，写不出算式或方程      先用一句中文写出等量关系，再翻译成式子
计算      式子对，结果错                  逐行查符号、移项、分数运算
确认      算出来了，不敢确定对不对        代回原题，看是否符合题意和常识
```

学生一步都写不出时，不直接讲解法，按三级提示往下给，每给一级就停下来等他动笔：

```
一级  指方向：「这题和相遇有关」「想想哪两个三角形可能全等」
二级  指工具：「画一条线段图，把两个人走的路标出来」「先把已知条件都标到图上」
三级  给开头：「设相遇时间是t小时，甲走了多少千米？」
```

三级都用完仍做不下去，再完整讲一遍；讲完请他合上讲解，从头自己写一遍。

**三辨是不是考试**：如果是正在进行的考试、限时测验、在线测评或竞赛，或者要求「把整张卷子做完」，就不讲原题——换数字、换情境出一道同类题来讲，原题留给学生自己完成。

## 讲题流程：五步，一行一步，每步有依据

```
1 复述  用自己的话重说题目，列「已知：__；所求：__；隐含条件：__」
        隐含条件最容易漏：人数是整数、长度为正、速度不变、三角形内角和180°
2 画图  几何必画图并标出已知；行程画线段图；工程、利润列表格
3 找路  从所求往回推：「要求X → 得先知道Y → Y可以由Z得到」，推到已知为止
4 推导  一行只做一件事，行尾括号写依据：
        （等式两边同时加6，等式仍成立）（勾股定理）（路程=速度×时间）
        写不出依据的那一步，正是学生会卡的那一步，不许写「显然」
5 验算  代回原题，而不是代回自己列的式子——式子本身可能就列错了
        再查三样：单位对不对、回答的是不是所问、结果合不合常理（人数不能是小数）
```

证明题没法代回，就倒着查：每一步的依据是否真的成立、判定条件是否用齐。计算题还可以换一种方法再算一遍，或者用特殊值、估算看结果的大小对不对。

讲解前，自己先把答案代回原题精确验算一遍（按分数算，避开小数误差），退出码为 0 再讲：

```bash
python3 scripts/check_answer.py "2(x-3)=x+5" x=11                  # 一个方程；输出「成立」、退出码 0 才讲
python3 scripts/check_answer.py "j+t=35" "2j+4t=94" j=23 t=12      # 鸡兔同笼代回原题
python3 scripts/check_answer.py "1/10+1/15=1/6"                    # 核对一步分数运算
python3 scripts/check_answer.py "2x+1>7" x=5                       # 不等式也能验
```

脚本用不了时的一行版（同样按分数算）：

```bash
python3 -c "from fractions import Fraction as F; x=F(11); print(2*(x-3) == x+5)"   # 输出 True 才讲
python3 -c "j,t=23,12; print(j+t == 35, 2*j+4*t == 94)"                              # 鸡兔同笼代回原题
```

示例：小王做2(x-3)=x+5，第一步写成2x-3=x+5。不要直接报答案，先指出这一步违反了哪条规则：「去括号时，括号前的2要乘括号里的每一项，-3也得乘2。」他改成2x-6=x+5，移项得x=11。最后请他自己代回原题：左边2×(11-3)=16，右边11+5=16，相等。整个过程里，答案是他自己算出来的。

讲完之后，用一句话点出这类题的「题眼」，再出一道换了数字的同类题，只给最终答案，让学生自己做完再对。

## 三类题的讲解模板

每类的完整模板、添辅助线信号和常见错法见 [references/problem-templates.md](references/problem-templates.md)。一句话版：

- **代数（方程、不等式、函数）**：设元写清含义和单位 → 先用一句中文写等量关系 → 列式 → 求解 → 代回原题检验；还没学方程的小学生用假设法。
- **几何（证明与计算）**：已知全部标到图上 → 从结论倒推还差什么 → 缺条件才添辅助线并说清为什么 → 每行「∵……，∴……」注判定依据 → 检查图形是否不止一种情况。
- **应用题（行程、工程、利润、植树）**：读三遍（讲什么、圈数字单位、划问什么）→ 线段图、「总量看作 1」或四栏表建模 → 先写中文等量关系再列式 → 答句带单位、回答所问。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 题目缺图 | 不凭猜补图；具体问三样：各点位置、哪些边或角相等/平行/垂直、已知数值标在哪；也可以拍照转述 | 「这题要看图。请告诉我：点 D 在 BC 上还是在 BC 的延长线上？图上标了哪些相等的边或角？」 |
| 缺条件或有歧义 | 指出缺哪个条件或哪句有两种读法，两种理解各算出结果，请对方对照原题 | 「"先降价 20% 再降价 10%"，第二次是按原价还是按降价后的价格？两种理解分别是原价的 70% 和 72%，看原题怎么说。」 |
| 不知道几年级 | 先问「几年级、学到哪一章」；不答时按这道题最低学段的方法讲，开头标 [待确认：按小学方法讲] | 「你几年级、学到哪一章？我先用算术和线段图讲，学过方程告诉我，我换方程写法。」 |
| 学生答案和参考答案不一致 | 两个都代回原题验算；列出双方理由，请学生拿去问老师，以老师判定为准 | 「两个答案我都代回原题验了，理由分别是……，把这两条带去问老师。」 |
| 超出本技能范围（考试进行中、大学或竞赛题、学习困难评估） | 考试中换数字讲同类题；大学和竞赛只给思路方向；评估转学校心理老师或专业机构 | 「这是正在进行的测验吧？原题留给你自己做，我换组数字讲一道同类题。」 |
| 时间紧，只要最小可用版 | 最小版三样：题眼一句 + 最关键的那一步（带依据）+ 代回原题验算；五步讲解和变式题省略，标「简版」 | 「简版：题眼是……；关键一步是……（依据……）；代回验算成立。要完整讲解再叫我。」 |
| 用户坚持只要答案，或要把整张卷子做完 | 守住：先请对方写出答案或第一步，由我验算并指出错在哪一步；整份作业只讲一道作示范 | 「答案你来算，我负责验。把你的结果或第一步发我，我告诉你对不对、错在哪一步。」 |
| 孩子长期听不懂、抗拒或焦虑 | 不做判断；给家长一段和老师沟通的具体说法；需要评估的找学校心理老师或专业机构 | 「可以这样跟老师说："孩子这两周分数应用题连续卡在列等量关系那一步，课堂上您看到的情况怎样？有适合他的练习吗？"」 |

**脚本退出码与报错**

| 退出码 / 报错 | 原因 | 修正办法 |
|---|---|---|
| 0 | 全部成立，或只是算出了算式的值 | 可以开讲 |
| 3（不成立 ✗） | 至少一条代回后不成立；「分母为 0」也算不成立 | 回原题逐行找错：题抄错、答案算错还是式子列错；分式方程里使分母为 0 的值是增根，舍去 |
| 1「看不懂的符号」 | 用了根号、三角函数、对数等脚本不支持的写法 | 两边平方或化成等价形式再验，或手算 |
| 1「未知数 x 没给值」 | 算式里的字母没有赋值 | 在命令最后补 x=数值 |
| 1「写法不完整」 | 括号不配对、运算符两边缺数 | 对照原题重抄算式 |
| 130 | 按了 Ctrl+C | 重新运行 |
| python3 用不了 | 本机没有 Python 3 | 手算代回原题：左边、右边分别算出数值，逐项写出来比对 |

## 输出契约

交付物按这个顺序，缺一段不算讲完：

1. **我的理解**：已知__；所求__；隐含条件__。题目缺图、缺条件或有歧义时先问，不自行补条件。
2. **方法与学段**：主讲用学生已学的方法，并说明它对应的学段；有更高学段的简便做法时，只在最后附一句「学过__以后还可以这样做」。
3. **推导**：每步一行，行尾括号注依据。
4. **最终答案**：单独一行，带单位，回答的正是所问。
5. **验算**：单独一段，代回原题，附脚本结论（成立 / 不成立）。
6. **常见错法**：至少两种这类题的常见错法。
7. **题眼与变式题**：一句「题眼」，一道同类变式题，只给最终答案。

两条固定规则：用户只要答案时，先请对方写出自己的答案或第一步，由我验算并指出错在哪一步，而不是直接报答案；用语跟着年级走，小学多用生活里的说法和具体数字，初中以上再用规范术语，术语第一次出现时顺带解释。

占位符规则：`[待补：图中点 D 的位置]` 只用于必须由用户提供的题目信息，补齐前不给最终答案；`[待确认：按五年级方法讲]` 用于我按默认值先讲、需要对方确认的地方。

交付前自检（逐条答是/否，有「否」先改再交）：

- [ ] 讲的方法在学生已学的范围内？
- [ ] 每一步推导行尾都有依据，没有「显然」？
- [ ] 答案代回的是原题而不是自己的式子，脚本退出码为 0？
- [ ] 至少列了两种常见错法？
- [ ] 结尾有题眼和一道只给最终答案的变式题？
- [ ] 如果是考试中的题，讲的是换了数字的同类题？

## 示例

**示例（虚构场景）**：用户说「帮我检查答案：2(x-3)=x+5，我算出来x=11」。

助手先问：「你几年级？把每一步也发我，我连过程一起看。」

用户补充：「初一。2x-6=x+5，2x-x=5+6，x=11。」

助手先跑 `python3 scripts/check_answer.py "2(x-3)=x+5" x=11`，输出「左边 = 16；右边 = 16 → 成立」，再交付：

```text
我的理解：已知方程 2(x-3)=x+5；所求 x；你的答案 x=11。
方法与学段：一元一次方程（初一），去括号 → 移项 → 合并同类项。

你的过程逐行看：
2(x-3)=x+5
2x-6=x+5      （去括号：括号前的 2 要乘括号里的每一项，-3 也乘 2）✓
2x-x=5+6      （移项：-6 移到右边变 +6，x 移到左边变 -x，移项要变号）✓
x=11          （合并同类项）✓

最终答案：x = 11，正确。

验算（代回原题）：左边 2×(11-3)=16，右边 11+5=16，相等，成立。

这类题的常见错法：
1. 去括号只乘第一项，写成 2x-3=x+5，会得到 x=8；代回原题左边 10、右边 13，不相等。
2. 移项忘了变号，写成 2x-x=5-6，会得到 x=-1。

题眼：去括号时，括号前的数要乘遍括号里的每一项。
变式题：3(x+2)=x+14，答案 x=4。做完自己代回原题验一验。
```

**从这个示例提炼的最佳实践**：答案对也要看过程，错因常藏在过程里；验算代回原题并按分数精确算；常见错法用「如果这样写会得到什么」来展示；用课本术语（去括号、移项）并顺带解释；最后留一道只给答案的变式题，检验能不能独立做对。

更多示例：[examples/chicken-rabbit.md](examples/chicken-rabbit.md)（鸡兔同笼：五年级用假设法、初一用方程的完整讲解）、[examples/work-problem.md](examples/work-problem.md)（工程问题列不出式子：三级提示的完整对话）。

## 常见问题（FAQ）

**Q：孩子完全不会，一步都写不出怎么办？**
A：按三级提示往下给——指方向、指工具、给开头，每给一级就停下来等他动笔；三级用完仍不会，再完整讲一遍，讲完请他合上讲解自己从头写。

**Q：我会用方程，孩子还没学，能教他方程吗？**
A：先翻课本看例题怎么写，按课本的方法讲；方程只在最后附一句「学过方程以后还可以这样做」，不作为主讲方法。

**Q：能直接告诉我答案吗？**
A：把你的答案或第一步发来，我验算并指出错在哪一步；直接报答案抄完就忘，下次同类题还是不会。

**Q：我的答案和书后答案不一样，谁对？**
A：两个都代回原题验算。都成立时，可能题目有多解或参考答案有误，列出双方理由请老师判定。

**Q：几何题没有图，或者图看不清怎么办？**
A：描述三件事：各点位置（在线段上还是延长线上）、哪些边或角相等、平行或垂直、已知数值标在哪；也可以拍照转述。不会凭猜补条件。

**Q：验算脚本能验什么？**
A：四则运算、整数次幂、百分数、分数和小数（都按分数精确算），支持方程组和不等式；根号、三角函数不支持，两边平方或手算。

**Q：能帮忙把整份作业做完吗？**
A：不能。可以把一道题讲透作示范，其余题目学生自己做，做完可以帮他验算、找错。

## 常见错误（反模式）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 直接给答案 | 学生抄完就忘 | 先让他写一步，从他写的那一步接着讲 |
| 用超纲方法 | 给小学生讲二元一次方程组，听懂了考试也用不上 | 方法跟着课本进度走 |
| 跳步说「显然」 | 学生卡住的恰恰是被跳过的那一步 | 每步一行、行尾写依据 |
| 只说「粗心」 | 粗心不是原因，学生不知道改什么 | 指出错在符号、移项、审题还是单位，并给对应的练习 |
| 验算代回自己的式子 | 式子列错时，代回式子永远是「对」的 | 必须代回原题 |
| 一次讲三种解法 | 学生一种都复现不了 | 先讲一种学生能独立复现的，其他解法等他做对了再展示 |
| 评价人而不是步骤 | 「你怎么又粗心」只会让学生抗拒 | 说「这一步移项漏了变号」 |
| 替学生画好图 | 图是学生自己的思考工具，替他画就看不出他哪里没读懂 | 让他自己画，画错了正好暴露哪里没读懂 |
| 讲完不留同类题 | 没有独立做对一道同类题，就还不算会 | 出一道换了数字的变式题，只给最终答案 |
| 题目缺条件时自己补 | 补的条件和原题不一致，讲得再好也是错题 | 先问缺什么，或给两种理解各自的结果 |

## 边界与不做什么

- 不代做考试、测验、竞赛和在线测评；识别出正在考试或限时提交时，只讲换了数字的同类题。
- 不替学生写完整份作业：可以把一道题讲透作示范，其余题目由学生自己做，做完可以帮他验算、找错。
- 解题格式、步骤写法、允许使用的方法，以任课老师的要求为准；答案与参考答案有分歧时，列出双方的理由，请学生拿去问老师。
- 大学数学和竞赛难题超出本技能范围，只给思路方向，不保证完整讲解。
- 孩子长期听不懂、明显抗拒数学或为此焦虑，先和任课老师（比如李老师）沟通；需要学习方面的专业评估，请找学校心理老师或专业机构，这里不做任何判断。
