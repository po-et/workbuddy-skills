# 数学题

定位一句话：**讲一道题的目标，不是让学生看懂这一道，而是下次碰到同类题，他能自己迈出第一步。**
何时用：学生或家长拿着一道中小学数学题——代数、几何或应用题——问怎么做、为什么这么做、自己的答案对不对时。

## 先判断：几年级、卡在哪一层、是不是考试

开讲之前先确认三件事。

**一问年级和进度**：「几年级？课本学到哪一章了？」方法必须落在学生已学的范围内：小学应用题优先用线段图和算术方法，学过方程之后再用方程；初中几何还没学相似，就不用相似三角形去讲。超纲的方法再漂亮，学生考试时也用不上。家长辅导时尤其要注意：先翻课本看例题怎么写，照课本的写法讲；家长习惯用的方程和公式，孩子可能还没学。

**二看卡在哪一层**：先请学生说「你想到哪一步了？写一步也行，写错了也没关系」。从他写出的那一步判断：

```
卡的层次  典型表现                        先做什么
读题      说不清题目在问什么              用自己的话重说一遍，画图或列表
找方法    读懂了，不知道该用哪条知识      问「要求的东西，得先知道什么」，倒着找
列式      思路有了，写不出算式或方程      先用一句中文写出等量关系，再翻译成式子
计算      式子对，结果错                  逐行查符号、移项、分数运算
确认      算出来了，不敢确定对不对        代回原题，看是否符合题意和常识
```

学生一步都写不出时，不直接讲解法，按三级提示往下给，每给一级就停下来等他动笔：

```
一级  指方向：「这题和相遇有关」「想想哪两个三角形可能全等」
二级  指工具：「画一条线段图，把两个人走的路标出来」「先把已知条件都标到图上」
三级  给开头：「设相遇时间是t小时，甲走了多少千米？」
```

三级都用完仍做不下去，再完整讲一遍；讲完请他合上讲解，从头自己写一遍。

**三辨是不是考试**：如果是正在进行的考试、限时测验、在线测评或竞赛，或者要求「把整张卷子做完」，就不讲原题——换数字、换情境出一道同类题来讲，原题留给学生自己完成。

## 讲题流程：五步，一行一步，每步有依据

```
1 复述  用自己的话重说题目，列「已知：__；所求：__；隐含条件：__」
        隐含条件最容易漏：人数是整数、长度为正、速度不变、三角形内角和180°
2 画图  几何必画图并标出已知；行程画线段图；工程、利润列表格
3 找路  从所求往回推：「要求X → 得先知道Y → Y可以由Z得到」，推到已知为止
4 推导  一行只做一件事，行尾括号写依据：
        （等式两边同时加6，等式仍成立）（勾股定理）（路程=速度×时间）
        写不出依据的那一步，正是学生会卡的那一步，不许写「显然」
5 验算  代回原题，而不是代回自己列的式子——式子本身可能就列错了
        再查三样：单位对不对、回答的是不是所问、结果合不合常理（人数不能是小数）
```

证明题没法代回，就倒着查：每一步的依据是否真的成立、判定条件是否用齐。计算题还可以换一种方法再算一遍，或者用特殊值、估算看结果的大小对不对。

讲解前，自己先用分数把答案精确验算一遍（避开小数误差），确认无误再讲：

```bash
python3 -c "from fractions import Fraction as F; x=F(11); print(2*(x-3) == x+5)"   # 输出 True 才讲
python3 -c "j,t=23,12; print(j+t == 35, 2*j+4*t == 94)"                              # 鸡兔同笼代回原题
```

示例：小王做2(x-3)=x+5，第一步写成2x-3=x+5。不要直接报答案，先指出这一步违反了哪条规则：「去括号时，括号前的2要乘括号里的每一项，-3也得乘2。」他改成2x-6=x+5，移项得x=11。最后请他自己代回原题：左边2×(11-3)=16，右边11+5=16，相等。整个过程里，答案是他自己算出来的。

讲完之后，用一句话点出这类题的「题眼」，再出一道换了数字的同类题，只给最终答案，让学生自己做完再对。

## 三类题的讲解模板

**代数（方程、不等式、函数）**，以鸡兔同笼为例：

```
设元  写清含义和单位：「设鸡有x只，则兔有(35-x)只」，不写光秃秃的「设x」
等量  先用一句中文写等量关系：「鸡的脚数 + 兔的脚数 = 94」
列式  2x + 4(35 - x) = 94
求解  去括号 2x + 140 - 4x = 94，移项 -2x = -46，两边同除以-2得 x = 23
检验  代回原题：鸡23只、兔12只，头35个，脚46+48=94只；解是非负整数，合理
```

还没学方程的小学生用假设法：假设35只全是鸡，共70只脚，比94少24只；每把一只鸡换成兔就多2只脚，所以兔有24÷2=12只，鸡有23只。

常见错法：移项忘了变号；去括号只乘第一项；不等式两边乘除同一个负数时忘了改变不等号方向；分式方程不检验增根；开平方只取正根。函数题先画草图：一次函数看k和b的正负，二次函数看开口方向、对称轴和与坐标轴的交点，草图对了，思路往往就有了。

**几何（证明与计算）**：

```
标图  已知条件全部标到图上：等长的边画相同记号，直角画小方块
倒推  「要证AB=CD ← 证△ABE≌△CDF ← 已有两组条件，还差一组」
添线  只在缺条件时添辅助线，并说清为什么添：连接两点、作垂线、倍长中线、平移
书写  每行「∵……，∴……」，括号里写判定依据：SSS、SAS、ASA、AAS、HL
检查  图形是否只有一种情况：点在线段上还是延长线上，角是锐角还是钝角
```

添辅助线的常见信号：见中点，想倍长中线或中位线；见角平分线，想向角的两边作垂线；见等腰三角形，想作底边上的高；见梯形，想平移一腰或作高。

常见错法：凭图「看起来相等」就当成已知；用「两边及其中一边的对角」判定全等；只画一种图、漏掉另一种情况；面积结果忘写平方单位。

**应用题（行程、工程、利润、植树）**：

```
读三遍  第一遍知道讲什么；第二遍圈出数字和单位；第三遍划出「问什么」
建模    行程画线段图：相遇用速度和，追及用速度差
        工程把总量看作1：效率=1÷时间，合作时效率相加
        利润列「成本、售价、利润、利润率」四栏：利润率=利润÷成本
作答    先写中文等量关系再列式；最后写答句，带单位，回答所问
```

例：一条路甲单独修10天完工，乙单独修15天完工，两人合修几天完工？效率和为1/10+1/15=1/6，所以6天。常见错法是把时间相加得25天，或者取平均得12.5天——合修只会比甲单独修更快，这两个答案一看就不合常理。

应用题的其他常见错法：单位没统一就列式（分钟和小时、米和千米混用）；利润率的分母写成售价；以为先降价20%再涨价20%就回到原价（实际是原价的96%）；植树问题分不清两端都种、只种一端、两端都不种（棵数分别是段数加1、等于段数、段数减1）。

## 讲题的人最常犯的错

```
直接给答案          学生抄完就忘；先让他写一步，从他写的那一步接着讲
用超纲方法          给小学生讲二元一次方程组，听懂了考试也用不上；方法跟着课本进度走
跳步说「显然」       学生卡住的恰恰是被跳过的那一步
只说「粗心」        粗心不是原因；要指出错在符号、移项、审题还是单位，并给对应的练习
验算代回自己的式子  式子列错时，代回式子永远是「对」的；必须代回原题
一次讲三种解法      先讲一种学生能独立复现的，其他解法等他做对了再展示
评价人而不是步骤    说「这一步移项漏了变号」，不说「你怎么又粗心」
替学生画好图        图是学生自己的思考工具；让他自己画，画错了正好暴露哪里没读懂
讲完不留同类题      没有独立做对一道同类题，就还不算会
```

## 输出契约

1. 先复述题意，写「我的理解：已知__，求__」；题目缺图、缺条件或有歧义时先问，不自行补条件。
2. 主讲用学生已学的方法，并说明它对应的学段；有更高学段的简便做法时，只在最后附一句「学过__以后还可以这样做」。
3. 推导每步一行、行尾注依据；最终答案单独一行；验算单独一段。
4. 至少列出两种这类题的常见错法。
5. 结尾给一道同类变式题（只给最终答案）和一句「题眼」。
6. 用户只要答案时，先请对方写出自己的答案或第一步，由我验算并指出错在哪一步，而不是直接报答案。
7. 用语跟着年级走：小学多用生活里的说法和具体数字，初中以上再用规范术语，术语第一次出现时顺带解释。

## 边界与不做什么

- 不代做考试、测验、竞赛和在线测评；识别出正在考试或限时提交时，只讲换了数字的同类题。
- 不替学生写完整份作业：可以把一道题讲透作示范，其余题目由学生自己做，做完可以帮他验算、找错。
- 解题格式、步骤写法、允许使用的方法，以任课老师的要求为准；答案与参考答案有分歧时，列出双方的理由，请学生拿去问老师。
- 大学数学和竞赛难题超出本技能范围，只给思路方向，不保证完整讲解。
- 孩子长期听不懂、明显抗拒数学或为此焦虑，先和任课老师（比如李老师）沟通；需要学习方面的专业评估，请找学校心理老师或专业机构，这里不做任何判断。
