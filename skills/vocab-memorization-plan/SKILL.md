# 背单词

定位一句话：**记住一个词，靠的不是第一次背得多用力，而是在快忘掉之前被再想起来一次。所以计划的核心是复习排期，每天背多少新词，是从复习量倒推出来的。**
何时用：要为四六级、考研、雅思或日常英语排一个背词计划；或者已经在背，却「背了就忘」「复习越欠越多」「每天从abandon重新开始」时。

## 先判断：目标、缺口、每天几分钟

先拿到三项输入，缺哪项问哪项：

```
目标词表  考什么、哪天考、用哪本词表（词条总数以考试大纲或词表实际收词为准）
当前水平  从词表里随机抽100个词，看英文说中文；说对的比例×词条总数≈已经会的词量
每天时间  按最忙的那一天也能保证的分钟数算，不按理想状态算
```

自测抽词要按页均匀地抽，不要只抽前几页；说得出一个主要意思算对，犹豫超过三秒算错。词表只用一本：考试类选按大纲收词、标了真题出现频次的，日常类就用自己的生词本。

目标不同，「会」的标准和侧重也不同。只需要读懂的词，做到见词知义就够；作文、翻译、口语里要自己用出来的词，才需要练到会拼、会用。

```
四六级  先保高频词；有听力，每个词都要听读音，做到听得出来
考研    专门记「熟词僻义」：address 有「处理」、fine 有「罚款」、novel 有「新颖的」
雅思    写作口语要主动用词；阅读听力里同义替换多，近义词成组记；听力填空必须拼对
日常    词表从自己常看的剧、文章、工作邮件里攒：同一个生词遇到第二次才收进来
```

日常英语的量可以更小，每天五到十个就够，但每个词都来自真实材料，复习时连原句一起看。要主动用的词，从已经认得的词里挑，每周挑十几个，各造一个和自己生活有关的句子，练到张口就能用。

每天新词数这样算：

```
每个新词约1分钟（听读音、看释义、读一个例句、合上书自测一次）
每次复习约15秒（看词说义，想不起来就翻看并做标记）
每个新词复习5次，排期跑满15天后：每天总用时≈新词数×(1+5×0.25)=新词数×2.25分钟
每天新词数=每天分钟数÷2.5（多留一成余量），向下取整
```

两个用时是经验估计，第一周按实际计时修正：复习明显更慢，就把除数调大。

示例：小王考研，离考试200天，每天能保证40分钟，每天新词就是40÷2.5=16个。假设词表5500词、自测认识45%，缺口约3000词，要3000÷16≈188天。可用天数=200−最后15天（让最后一批词走完复习）−每周1天复盘（约28天）=157天，不够。二选一：每天加到50分钟（每天20个，150天够用）；或者把低频词降级为「只认不拼」，只保证见词知义。

## 排期流程：学后第1、2、4、7、15天各复习一次

学新词那天记为第0天，之后第1、2、4、7、15天各复习一次。换个方向说：**第D天要复习的，是第D−1、D−2、D−4、D−7、D−15天学的那几组。** 每周第7天是复盘日，不学新词，复习照常。这组间隔常被叫作「艾宾浩斯复习表」，但具体天数是经验值，不是定律；实在跟不上可以整体拉长，顺序不能乱。

可直接填的排期表（前8天已按规则排好，之后照同一规则往下填；复盘日另外清一遍错词本）：

```
天数  日期   新学    要复习的组  用时  错词  完成
第1天 __/__  D1组    —           __分  __    □
第2天 __/__  D2组    D1          __分  __    □
第3天 __/__  D3组    D2 D1       __分  __    □
第4天 __/__  D4组    D3 D2       __分  __    □
第5天 __/__  D5组    D4 D3 D1    __分  __    □
第6天 __/__  D6组    D5 D4 D2    __分  __    □
第7天 __/__  复盘日  D6 D5 D3    __分  __    □
第8天 __/__  D8组    D6 D4 D1    __分  __    □
```

不想手排，用这段命令按你的开始日期生成完整排期：

```bash
python3 - <<'EOF'
import datetime as dt
start, days = dt.date(2026, 10, 1), 30  # 改成你的第1天日期和要排的天数
done = set()
for d in range(1, days + 1):
    rest = d % 7 == 0  # 每第7天是复盘日，不学新词
    due = [f"D{d-k}" for k in (1, 2, 4, 7, 15) if d - k in done]
    if not rest: done.add(d)
    day = start + dt.timedelta(days=d - 1)
    print(f"第{d}天 {day:%m/%d} 新学 {'复盘日' if rest else f'D{d}组'} 复习 {' '.join(due) or '—'}")
EOF
```

每天的顺序固定：先复习、后新词，保证复习不欠账。零碎时间（通勤、排队）做「看词说义」的复习，整块时间留给新词；睡前把当天的新词过一遍，第二天一早先自测。

一组词怎样才算复习完成：整组过一遍，说不出的当场看例句、再自测一次，并打上标记；只翻不测不算完成。

漏了一天：第二天先补复习、再学新词；当天复习量超过可用时间的一半，就暂停新词一天，先还复习债。连续一周完成率不到一半，就重排：停新词三天只清复习，再用实测用时重新算每天新词数。

有考试日期的，最后15天不再学新词，只走完已排的复习和错词本，每天加一次旧词抽查；考前三天只看错词本。

## 记法：词根词缀帮理解，语境管用法

一个新词的一分钟这样花：听两遍读音并跟读；能拆就拆，看词根词缀；读例句，圈出搭配；合上书，看英文说中文，再看中文拼一遍。用纸质本也行：左边写英文，右边写中文和例句，复习时用纸条遮住一边。

```
词根词缀  pre-（在前）+ dict（说）→ predict 预言；trans-（跨过）+ port（运）→ transport 运输
          同根词串着记：export、import、portable；inspect、respect、spectator
          只拆拆得开的词，拆不开的别硬编故事
          小心陷阱：inflammable 和 flammable 都是「易燃」；invaluable 是「极其珍贵」，不是「没价值」
语境      每个词配一个例句，优先用真题或原版材料里的句子；连搭配一起记：
          make a decision（不说 do a decision）、raise a question、pay attention to
自测      先看英文说中文，再看中文说英文，最后遮住例句里的这个词做填空
          想不起来之前不翻答案：主动回想比反复看记得牢，这是最该用上的一条
读音      跟读，并按音节拆开拼写：re-mem-ber、de-ci-sion；读得准的词更容易拼对
联想      可以用，但要短：一个词配一句话的联想，三秒想不出就算了，不花时间编长故事
```

## 错词本与一周复盘

错词本只记四栏：单词、错的方式（不认识、和谁混了、拼错）、一个例句、下次复习日期。规则四条：

1. 复习时三秒内说不出意思，或者拼错，就进错词本。
2. 进了错词本的词，从当天重新算第0天，再走一遍1、2、4、7、15。
3. 连续三次复习都对，才移出错词本。
4. 形近、义近的词成对记，一次写两个：affect/effect、adapt/adopt、principle/principal。

错词本每天都看：复习完当天的组之后，顺手把错词本里今天到期的词过一遍，过完更新下次复习日期。

每周复盘放在复盘日，十五分钟：

```
看三个数  本周新学词数；复习完成率=完成的组÷应复习的组；错词率=错词数÷复习词数
调整      完成率低于80%：下周新词减两成，先还复习债
          错词率高于30%：新词减量，每个词多配一个例句，自测改成英中、中英各一遍
          完成率100%、错词率低于10%、时间还有富余：新词加一到两成
抽查      从两周前学的词里随机抽30个自测，记下正确率，和上周比
```

阈值都是经验值，跑两三周后按自己的情况调。

## 最常见的错误

```
只看不测      看着眼熟不等于会；每次复习都要先自己回想，再看答案
只做选择题    选择题只练「认得」；要会拼的词，必须默写或口头拼读
天天从头背    每天都从第一页背起，前三页滚瓜烂熟，后面没见过；按组往前推，不回头重来
新词贪多      第一周就一天一百个，第三周复习债压垮计划；第一周按算出来的一半起步
抄写十遍      手在动，脑子没在想；遮住回想一次，比抄十遍管用
只记中文释义  阅读里碰到一词多义就认不出；至少记一个例句和一个常用搭配
频繁换词表    每换一次就从头开始；一本词表跟到底，别的材料只用来「再遇见」
只背不读      词表之外再也碰不到这个词；每周读几篇目标考试或兴趣领域的文章
复盘日全休    复盘日只停新词，不停复习；停了复习，第二天就要背两天的复习量
```

## 输出契约

1. 先写出三个输入：目标与日期、当前水平、每天分钟数；缺的逐个问，用户没答的写明所用默认值。
2. 给出每天新词数的计算过程，时间估计标明是估计，并说明第一周按实际计时修正。
3. 交付前两到三周的排期表（按上面的模板，含复盘日），或者附上生成排期的命令。
4. 交付错词本四栏格式，以及每周复盘的三个数和调整规则。
5. 附上掉队时的重排规则和最后15天的安排。
6. 用户已经在背、只是来求救时，先看他现在的完成率和错词率，再决定是减新词、补复习还是改记法，不推倒重来。
7. 工具只说类型——纸质本、电子表格、任何支持间隔复习的卡片工具——不点名具体付费产品。

## 边界与不做什么

- 不推荐具体的付费App、课程或词汇书品牌；词表以考试官方大纲或学校、老师指定的为准。
- 不预测考题、不承诺分数：背下多少词和考多少分之间，没有固定换算。
- 考试的题型、分值和报名安排，以当年官方公告为准，不凭记忆回答。
- 不代打卡、不代完成学习任务；学生的背词作业以老师的要求为准。
- 如果出现持续失眠、明显焦虑，或者感觉记忆力突然明显变差，请先找医生或学校心理老师，这里不做判断。
