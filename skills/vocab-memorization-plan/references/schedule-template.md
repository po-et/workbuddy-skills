# 可直接填写的排期表

学新词那天记为第 0 天，之后第 1、2、4、7、15 天各复习一次；换个方向说，**第 D 天要复习的，是第 D−1、D−2、D−4、D−7、D−15 天学的那几组**。每周第 7 天是复盘日，不学新词，复习照常；复盘日另外清一遍错词本。

前 8 天已按规则排好，之后照同一规则往下填：

```
天数  日期   新学    要复习的组  用时  错词  完成
第1天 __/__  D1组    —           __分  __    □
第2天 __/__  D2组    D1          __分  __    □
第3天 __/__  D3组    D2 D1       __分  __    □
第4天 __/__  D4组    D3 D2       __分  __    □
第5天 __/__  D5组    D4 D3 D1    __分  __    □
第6天 __/__  D6组    D5 D4 D2    __分  __    □
第7天 __/__  复盘日  D6 D5 D3    __分  __    □
第8天 __/__  D8组    D6 D4 D1    __分  __    □
```

不想手排，用脚本按开始日期生成完整排期（与上表同一规则，输出可以逐行对照）：

```bash
python3 scripts/vocab_plan.py --start 2026-10-01 --days 30
python3 scripts/vocab_plan.py --start 2026-10-01 --days 60 --per-day 16 --csv plan.csv
```

`--csv` 另存的表格多了「词数」「备注」和空着的「用时(分)」「错词」「完成」三列，用电子表格打开后每天填写；文件是 UTF-8 带 BOM，Excel 直接打开不乱码。

## 错词本四栏

```
单词      错的方式（不认识／和谁混了／拼错）   例句                                   下次复习日期
adopt     和 adapt 混了                       The school adopted a new timetable.    10/09
```

进了错词本的词，从当天重新算第 0 天，再走一遍 1、2、4、7、15；连续三次复习都对，才移出错词本。
