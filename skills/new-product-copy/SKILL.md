# 上新文案

定位一句话：**新品文案卖的不是参数，而是「谁在什么时候用它解决了什么、用完是什么感觉」——每个卖点都从功能走到场景、再走到情绪，每一步都要有凭据。**
何时用：新品要上架电商详情页、发公众号、拍短视频口播；要排预热、首发、返场的节奏；手上只有参数表和产品图，不知道从哪写起。

## 先判断什么：动笔前收齐六样

```
产品  品类、规格参数、价格与首发优惠、开售日期、是否限量及数量
凭据  每个卖点背后的证据：检测报告、专利、原料来源、实测数据、试用反馈——没凭据的卖点先放一边
人群  谁用、谁付钱（常常不是同一个人）；他们现在用什么凑合、对它哪里不满
场景  一天里什么时刻、在哪、因为什么会用到它
对手  同价位竞品详情页首屏都在强调什么；你的差异只挑一两个
风险  是否属于食品、保健食品、化妆品、医疗器械、药品、母婴用品——这些品类的宣称有专门规定，先标红
```

六样里缺哪样就先问哪样。凭据缺得最多时，宁可少写一个卖点，也不要先写上去「回头再补」。

## 卖点提炼：功能 → 场景 → 情绪

流程：先把所有参数列成行，每行往右推两格；推不到场景的参数只放进参数表，不当卖点。

```
功能（可验证）          场景（谁、何时、在哪）                情绪（省掉的麻烦或得到的感觉）   凭据
单手按压开盖            骑车等红灯、抱着孩子时单手喝水         手不够用时也不狼狈               实拍视频
装热水 8 小时后仍温     早上 7 点装的水，下午 3 点开会还能喝   不用满楼找饮水机                 检测报告（待补编号）
杯身 350 毫升、重 260 克 塞进通勤包侧袋不鼓包                  出门少一件要惦记的东西           实测称重
筛选  三个卖点封顶；首屏只讲「场景最常见、情绪最强、凭据最硬」的那一个
```

示例产品是虚构的通勤保温杯，数字只作格式示意，实际以你的检测报告和实测为准。情绪这一格写具体的麻烦和感受，不写「幸福感」「品质生活」这类放在哪个产品上都成立的词。

场景和情绪写不出来时用笨办法：翻同类商品的差评、追评和问答，把用户原话抄下来，按「什么时候、在哪、为什么不满」归类；出现最多的三类就是你的场景素材，文案里尽量用用户自己的词，而不是行业术语。

## 标题公式与正文结构

```
公式1 人群或场景 + 痛点 + 解法   早八通勤党：单手就能喝到热水的保温杯
公式2 具体数字 + 可验证结果      早上装的热水，下午开会还是温的（需有检测或实测）
公式3 对比旧方式                不用再找饮水机：一天的热水装进包里
公式4 新品身份 + 核心差异        新品｜单手开盖保温杯，骑车等灯也能喝
公式5 提问                      为什么你的保温杯总在包里漏水？
自检  至少含一个用户会搜的词；有数字就有凭据；不用「最」「第一」「100%」「全网最低」
```

按平台挑公式：电商标题要装进搜索词（品类词 + 属性词 + 场景词）；公众号标题要让人想点开，公式 1、3、5 更合适；短视频封面字要一眼看懂，控制在十个字上下。

正文结构（五段，顺序固定）：

```
1 开头  先给场景或痛点，不从品牌介绍开始
2 卖点  最多三个，每个按「功能—场景—情绪—凭据」写
3 信任  检测、材质、工艺、授权使用的真实试用反馈；不编评价、不编销量
4 顾虑  尺寸重量、清洗方法、售后规则，以及不适合谁
5 行动  首发价、开售时间、数量限制、在哪买
```

一个卖点段写出来是这样：「早上 7 点装的热水，下午 3 点开会时倒出来还是温的。杯身是双层真空结构，不用满楼找饮水机，也不用将就一口凉水。保温数据见检测报告（待补编号）。」——场景在前，功能居中，情绪收尾，凭据跟在后面。

## 三平台改写与上新节奏

```
电商详情页  首屏：主图 + 一句主卖点（12 字以内）
            分屏：痛点场景 → 三个卖点各占一屏（图 + 一句话 + 凭据小字）→ 细节与参数 → 用法 → 包装清单 → 售后
公众号推文  标题 + 摘要 + 正文 1,200–2,000 字：从一个具体的人和场景讲起 → 问题 → 产品怎么解决
            → 真实的研发或选材故事 → 首发福利 → 购买路径；段落短，每两三段配一张图
短视频口播  30–60 秒，按秒写分镜，一句不超过 15 个字，写完念出声计时
            0–3 秒 钩子：一个冲突或问题，画面先动起来
            3–15 秒 痛点演示；15–40 秒 两个卖点现场演示（嘴上说功能，画面给证据）
            40–55 秒 价格与首发福利；55–60 秒 一句行动指令
```

同一个卖点在三个平台的写法（示意）：

```
详情页  单手一按就开｜骑车等灯、抱娃时都能喝上一口（小字：按压开盖，实拍见下屏）
公众号  上周五早上，小王一手抱着孩子、一手拎着包，在公交站想喝口水，杯盖拧了半天……所以新品把杯盖改成了一按就开。
口播    （画面：单手按开杯盖）一只手？够了。按一下，开了。
```

30 秒口播完整示意（念出声计时，超了就删句子，不加快语速）：

```
0–3 秒    （画面：公交站，一手抱孩子、一手拧杯盖）你是不是也这样？
3–10 秒   想喝口水，得先找个地方把东西放下。
10–20 秒  （单手按开杯盖）一只手，按一下，开了。
20–25 秒  （倒水冒热气，画面角落的时钟显示下午三点）早上装的，现在还是温的。
25–30 秒  X 月 X 日上午十点开售，首发价 X 元，先点预约，开售提醒你。
```

上新节奏（T 为开售日）：

```
T-14 至 T-7  悬念：只露局部或使用场景；征集问题「你的保温杯最烦人的是什么？」
T-6 至 T-3   揭晓：公布名称、主卖点、开售时间，开放预约提醒
T-2 至 T-1   倒计时：首发福利、真实的限量数字、常见问题答疑
T 日         三个平台同步发，主卖点、价格、时间三处口径一致
T+1 至 T+7   返场：授权后的真实反馈、使用教程、答疑补充
预热模板  悬念  「早上 7 点装的热水，你的杯子能撑到几点？X 月 X 日见分晓」
          揭晓  「新品通勤保温杯：单手开盖，热水温到下午。X 月 X 日 10:00 开售」
          倒计时「还有 1 天：首发前 N 只 X 元，之后恢复 Y 元」——N、X、Y 必须真实可兑现
```

三个平台分工不同：短视频负责让人看到，公众号负责讲清楚，详情页负责下单，但主卖点那一句话三处必须一致。开售一周后复盘：记下各平台用了哪个标题公式、首屏讲了哪个卖点，对照点击、停留和评论；评论区反复出现的问题补进详情页的「顾虑」段，下一轮标题从表现最好的那个公式往下延伸。

## 最常见的错误与合规风险

- 参数堆砌 → 每个参数都推到场景，推不动就进参数表。
- 卖点太多 → 首屏一个，全页不超过三个。
- 三个平台一套文案 → 详情页重信息，公众号重故事，口播重节奏。
- 「极致」「颠覆」「黑科技」 → 换成具体数字或现场演示。
- 没凭据的数字和对比 → 删掉或标「待补」；「比某某强 3 倍」要有能公开的依据，也不贬低竞品。
- 预热承诺兑现不了 → 只写确定能给的福利；「原价」要真实成交过，限时限量要真的限。
- 合规风险：绝对化用语（最、第一、国家级等）广告法有限制；普通商品不说治疗、预防疾病；食品不暗示保健或治疗功能；化妆品的美白、防脱等功效要有依据，部分类别需注册或备案；保健食品、医疗器械、药品的广告须经审查。这几类一律交法务或合规审核后再发，具体以现行法规和平台规则为准。

## 输出契约

1. **缺料先问**：六样收不齐就先列出缺什么；没凭据的卖点写「待补」，不替用户编数字。
2. **按顺序交付**：卖点阶梯表 → 五个备选标题（注明用了哪个公式）→ 正文 → 三平台改写稿 → 上新节奏表与各阶段预热文案。
3. **每个数字旁注凭据**：检测、实测还是用户反馈；拿不准的就标出来。
4. **风险单列**：风险词和敏感宣称单独列一张表，每条给一个可替换的写法，并注明「需合规审核」。
5. **注明平台与篇幅**：每一稿开头写清发在哪个平台、多少字或多少秒；口播稿附上念出声的实测时长。

## 边界与不做什么

- 不写虚假或兑现不了的承诺：不编销量、评价、专家背书、媒体报道、原价和限量。
- 医疗、功效类表述只提示风险，不判断某句话是否合法；涉及食品、保健食品、化妆品、医疗器械、药品、母婴的，发布前交法务或合规人员审核。
- 不写贬低竞品的内容，不对比较广告做法律判断。
- 不承诺转化率和销量，不代发布、不代投放。
- 不使用未授权的肖像、音乐、字体、图片和他人文案。
