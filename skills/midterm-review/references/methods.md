# 复习方法卡：往年题、课件、主动回忆、错题本与各课型打法

本文件是 SKILL.md 第 1、4、5 步的展开。方法是通用的，具体考试范围和题型以任课老师说明为准。

## 1. 把握度自评换算

不看书，冷做一道往年题或课后题（最好 3–5 道，覆盖不同章节），按正确率换算：

| 正确率 | 把握度 |
|---|---|
| 低于 20% | 1 |
| 20%–40% | 2 |
| 40%–60% | 3 |
| 60%–80% | 4 |
| 80% 及以上 | 5 |

复习一周后再测一次，更新把握度，重跑脚本——分配会自动向还没起色的课倾斜。

## 2. 往年题：第一遍是诊断

1. 计时冷做一整套，不翻书。
2. 对答案，每题标：会 / 会但错 / 不会。
3. 按题型归类，填下表，时间先投给"不会"最多的题型：

| 题型 | 题号 | 会 | 会但错 | 不会 | 对应课件章节 |
|---|---|---|---|---|---|
| （如：求极限） | 1、4、7 | | | | |

4. "会但错"进错题本写错因；"不会"回到课件和作业补方法，再找同类题练。
5. 考前 3 天再计时做一套没做过的，检验效果。

## 3. 课件：改写成问题，而不是重读

把每页标题改写成一个能自测的问题：
- "第 3 章 导数的应用" → "用导数判断单调性的步骤是什么？极值和最值怎么区分？"
- "指针与数组" → "`int *p = a;` 之后 `p[2]` 和 `*(a+2)` 为什么相等？"

问题写在一张纸或一个文档里，就是这门课的自测题库；每块时间开头抽几道回答，答不出的标记，回课件查。

## 4. 主动回忆：白纸法

1. 合上所有资料，写下章节名。
2. 10 分钟内把能想起来的定义、公式、推导、例题写出来。
3. 打开课件对照，用另一种颜色补上漏掉和写错的。
4. 补上的内容就是这一章的薄弱点，写进要点卡。
5. 隔天再做一次，看补上的内容还在不在。

进阶：讲给同学听，或者对着空椅子讲一遍；讲不顺的地方就是没懂的地方。

## 5. 错题本模板

| 日期 | 课程·章节 | 题目（或出处页码） | 错因 | 正确思路（一句话） | +1 天 | +3 天 | 考前一天 |
|---|---|---|---|---|---|---|---|
| 10-20 | 高数·极限 | 往年卷第 4 题 | 方法不会 | 0/0 型先试等价无穷小替换 | ☐ | ☐ | ☐ |

- 错因只选四类：概念不清 / 方法不会 / 计算粗心 / 审题。
- 概念不清 → 回课件；方法不会 → 找 2 道同类题；计算粗心 → 记下自己常错的步骤；审题 → 圈关键词再做。
- 连续两次重做都对，就划掉，不再占时间。

## 6. 要点卡

一章一页，只放四样：必背的定义和公式、典型题型的解题步骤、自己的易错点、一道代表例题。考前一天只看要点卡和错题本。

## 7. 各课型打法

**计算推导类**（高数、线代、概率论、大学物理）
- 往年题按题型归类，每类吃透 2–3 道。
- 公式不死背：白纸推一遍，推不出来的才背。
- 做题写完整步骤，很多老师按步骤给分（以老师说明为准）。

**编程类**（C 语言、数据结构）
- 读程序写结果、找错改错、手写代码三类分别练。
- 上机题一定要真的敲一遍、跑一遍，不能只看。
- 把自己踩过的语法坑（分号、数组越界、`=` 与 `==`）记进错题本。

**记忆理解类**（思政、史纲、管理学等）
- 先画框架：章节 → 要点 → 一个例子。
- 按老师划的重点做问答卡，用主动回忆过一遍，再对照教材补漏。
- 论述题用固定结构练：观点 → 理论依据 → 例子 → 结论。

**语言类**（大学英语等）
- 单词按课文分组自测，错的进错题本。
- 作文准备一个结构模板，按往年题目写 2–3 篇并对照范文修改。
- 听力、阅读每天少量保持手感，比考前突击有效。

## 8. 同一天两门

- 前一天：主攻先考的那门（错题本 + 要点卡），另一门只翻要点卡 30 分钟。
- 当天两场之间：只看后一门的要点卡，不做新题；吃饭、喝水、休息优先。
