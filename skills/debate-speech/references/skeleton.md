# 完整骨架（不预设立场，方括号处替换）

用法：整份复制，方括号逐个替换成你的内容；替换不了的保留并改成 [待补] 或 [待核]，交付和上场前一眼就能看出还缺什么。写完用 `python3 scripts/speech_timer.py 稿子.txt 你的语速 --limit 时长` 计时。

只计需要上场的正文：计时前删掉「辩题、持方、时长」这些准备说明，不把攻辩和结辩一起当成三分钟立论。纯英文加 `--language en`，语速单位是词/分钟。

## 一辩立论

```
辩题：[原文照抄]    我方：[正方/反方]    立论时长：[3] 分钟
【一辩立论】
谢谢主席，问候在场各位。开宗明义：[关键词1]是指[界定，注明依据]；[关键词2]是指[……]。
今天判断[辩题核心]，应当看[标准]，因为[这把尺子为什么公平]。
第一，[主张]。[论据＋出处]。所以在[标准]下，[我方结论]。
第二，[主张]。[论据＋出处]。所以……
第三（可选），[对对方最可能论点的预先回应]。
综上，[一句话把论点挂回标准]，我方坚定认为[我方持方原文]。谢谢。
【二三辩攻辩】链一、链二各四问（共识→前提→矛盾→收束），另备一条
【自由辩】战场表＋每人三个问题＋两个现成例子
【四辩结辩】锁定分歧（留空）→ 逐一裁决（留空）→ 回到标准 → 用立论里的画面收尾
```

## 攻辩链（每条四问，复制两到三份）

```
链[一]：打对方的[哪个论点]
1 共识问：[预期双方可接受的前提；也准备否认分支]？
2 前提问：[把对方论点背后没说出口的前提问出来]？
    对方答「是」→ 追问：[……]？
    对方答「不是」→ 追问：[……]？
3 矛盾问：您方[一辩/二辩]说[对方原话，场上核对]，那[这个前提]和它怎么同时成立？
4 收束句：对方明确承认时引用[实际承认的内容]，再说明[论证缺口]。
    对方否认→ 问[否认的依据或替代标准]，不能使用“对方承认”。
    对方绕开→ 赛制允许时重述一次；仍绕开，只说[哪个具体问题尚未回答]，切下一条链。
```

## 自由辩战场表（最多三个战场）

```
| 战场 | 我方守住的一句话 | 进攻问题（三个） | 备用例子或数据 | 主责 |
|---|---|---|---|---|
| 定义 | [……] | ①[……] ②[……] ③[……] | [……（出处）] | [二辩] |
| 标准 | [……] | ①[……] ②[……] ③[……] | [……] | [三辩] |
| 事实与后果 | [……] | ①[……] ②[……] ③[……] | [……] | [一辩、四辩] |
```

## 四辩结辩框架（只写框架，第 2、3 段场上填）

```
1 锁定分歧：今天双方真正的分歧是[一到两个]。
2 逐一裁决：[待补：引用对方场上原话]——在双方都认可的[标准]下，我方占优，因为[……]。
3 回到标准：[重申标准]；对方的论证在这把尺子下缺了[哪一环]。
4 收尾：回到立论里的[画面或例子]，不喊口号。能否提新论据以规则为准，一般不提。
```

## 论据出处清单

```
| # | 用在哪 | 论据 | 出处（机构／作者、标题、年份、页码或链接） | 状态 | 查不到时怎么说 |
|---|---|---|---|---|---|
| 1 | [第一论点] | [……] | [……] | 已核 / [待核] | [换成哪句推理，或删掉] |
```

出处写到别人能按图索骥找回原文的程度；只写「据调查」「有研究表明」等于没写。
