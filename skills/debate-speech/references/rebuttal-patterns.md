# 反方常用拆解句式与自查

正方拆对方时一样适用。左边两列拿去打对方，右列拿来检查自己的稿子，别给对方留下同样的口子。

| 拆法 | 句式 | 自查 |
|---|---|---|
| 拆定义 | 按对方的定义，[反例]也算[X]，这显然不是今天要讨论的[X] | 拿一个反例测自己的定义，过宽过窄都改 |
| 拆标准 | 对方只看[A]，那[B]在对方的标准里算什么？ | 标准有没有漏掉对方一定会提的维度 |
| 拆因果 | [A]和[B]同时出现，不等于[A]导致[B]；[C]排除了吗？ | 每个因果论据至少排除一个其他原因 |
| 拆样本 | 一个例子能代表多数情况吗？比例是多少？ | 案例后面补上比例或数据 |
| 拆可行 | 就算问题存在，对方的方案谁来做、钱从哪来、多久见效？ | 政策题写清执行主体、成本和时间 |
| 拆代价 | 对方只讲收益，代价由谁承担？ | 主动承认代价，说明为什么可以接受 |
| 拆滑坡 | 从[A]走到[Z]，中间每一步都必然发生吗？ | 推论链的每一步都有依据 |

## 怎么用这张表

1. **立论写完先自查**：七行的右列逐条过一遍自己的稿子，哪条答不上就改稿，而不是指望场上临时圆。
2. **备赛时拆对方**：先列出对方最可能的三个论点，每个论点挑最致命的一到两种拆法，写成攻辩链里的「矛盾问」（链的写法见 SKILL.md「攻辩、自由辩与结辩」）。
3. **自由辩里用一句话版**：只说句式的前半句，把问题抛给对方，例如「一个例子能代表多数情况吗？」，别在自由辩里长篇论证。
4. **结辩里用来裁决**：「对方的论证缺了哪一环」往往就是某一种拆法，点名说出来，评委更容易记住。

## 用法演示（示例，辩题「大学生兼职利大于弊」，正反两方各举）

以下句子只演示句式怎么落地，不含任何数据或真实案例。「拆可行」只用于「该不该」类政策题，这个辩题是「哪个更」类，不演示。

| 拆法 | 反方拆正方 | 正方拆反方 |
|---|---|---|
| 拆定义 | 按对方的定义，暑假全职打工三个月也算「兼职」吗？ | 按对方的说法，校内勤工助学不算兼职，那它算什么？ |
| 拆标准 | 对方只看「能力」，学业成绩在对方的标准里算什么？ | 对方只看成绩，走进社会需要的能力在对方的标准里算什么？ |
| 拆因果 | 做过兼职的同学更会沟通，是兼职的功劳，还是本来就外向的人更愿意去兼职？ | 成绩下滑的同学做过兼职，就等于兼职导致成绩下滑吗？课程难度、作息排除了吗？ |
| 拆样本 | 对方举的是专业对口的兼职，发传单、端盘子占多大比例？ | 对方举了一个被骗的例子，一个例子能代表多数兼职吗？ |
| 拆代价 | 兼职占掉的学习时间，由谁来补？ | 不兼职省下的时间，都用在学习上了吗？ |
| 拆滑坡 | — | 从「做兼职」到「荒废学业」，中间每一步都必然发生吗？ |
