# 辩论稿

定位一句话：**辩论稿不是议论文，而是一套作战方案：先让评委接受你的尺子（标准），再用这把尺子量双方。标准立不住，稿子写得再漂亮，场上一问就散。**
何时用：校内赛、社团赛、课堂辩论，要写一辩立论稿、设计攻辩问题、分配自由辩战场、搭四辩结辩框架时。

## 先判断：赛制、辩题问法、持方

动笔前拿到主办方规则：各环节几分钟、攻辩能否连续追问、自由辩怎么计时、结辩能否提新论据。下文按常见的四人制说，环节名称以你的赛制为准。

| 辩题问法 | 例 | 立论先要立住的东西 |
|---|---|---|
| 「是不是」 | X 是否属于/导致 Y | 关键词定义清楚，外加一条完整的证据链 |
| 「哪个更」 | X 利大于弊；X 比 Y 更重要 | 比较标准：用什么尺子比、为什么用这把尺子 |
| 「该不该」 | 应当/不应当推行 X | 三问：问题是否存在、方案能否解决、代价能否接受 |

## 立论稿：定义 → 标准 → 论点（分五步写）

```
第 1 步 定义：辩题里每个关键词写成一句可检验的界定——对象、范围、时间。
        引用词典或通行说法要写明出处；对方最可能挑战的那个词，备一个例子说明为什么这样界定才合理。
第 2 步 标准：一句话说清「今天应当看什么来判断」，如「判断该不该推行 X，要看它能否以[可接受的代价]解决[问题]」。
        检查点：对方挑不出毛病、但对我方更有利；只对我方成立的标准，对方一句话就能否掉。
第 3 步 论点：两到三个，每个都是「主张＋论据＋回到标准」三件套；按不同维度分（个人与社会、短期与长期），
        别让两个论点其实是一件事。论据分量：可查证的数据或研究 > 公认事实 > 具体案例 > 类比；
        每条注明出处，查不到的标「[待核]」。名言和排比代替不了论据。
第 4 步 预判：列出对方最可能的三个攻击点，在立论里各埋一句回应，只占位不展开。
第 5 步 计时：主办方时长 × 实测语速（先读一分钟、数字数）= 字数上限，写到九成，留出强调和停顿。
```

草稿存成 lilun.txt，最后一个参数填你实测的每分钟字数：

```bash
python3 -c "import sys;t=open(sys.argv[1],encoding='utf-8').read();n=sum('\u4e00'<=c<='\u9fff' for c in t);r=float(sys.argv[2]);print(n,'字，约',round(n/r*60),'秒')" lilun.txt 250
```

## 攻辩、自由辩与结辩

攻辩（质询）按「链」准备，每条链三到四问：

```
1 共识问：对方一定答「是」的问题，先把前提钉住
2 前提问：把对方论点背后没说出口的前提问出来
3 矛盾问：让这个前提撞上对方自己的定义、标准或另一个论点
4 收束句：不再提问，替评委总结一句「对方承认了……，所以……」
示例（对方论点：X 能提高效率）
  您方同意，效率要同时看投入和产出吧？→ 您方说的提高效率，是假设投入不变吗？
  → 可您方二辩刚才说推行 X 要额外培训，这算不算投入增加？→ 所以对方的「提高效率」只算了产出。
要求：每问能用「是/不是」或一个词回答；对方两种答法都提前写好追问；不问「您方怎么看……」，
      开放式问题等于把时间送给对方再立论一次。对方绕开就原样再问一次，再绕就点明，切下一条链。
```

自由辩赛前画一张战场表，最多三个战场：

| 战场 | 我方守住的一句话 | 进攻问题（三个） | 备用例子或数据 | 主责 |
|---|---|---|---|---|
| 定义 | …… | …… | …… | 二辩 |
| 标准 | …… | …… | …… | 三辩 |
| 事实与后果 | …… | …… | …… | 一辩、四辩 |

每次发言先接后打：先回应对方上一句，再抛自己的问题。同一个问题对方连续两次不接，点破后换战场；每个战场指定一人做小结；时间过半时由四辩检查还有哪个战场没打。

结辩赛前只写框架，第 2、3 段留空，现场按双方原话填，不背整稿：

```
1 锁定分歧：「今天双方真正的分歧是……」（一到两个）
2 逐一裁决：引用对方场上原话，说明在双方都认可的标准下，为什么我方占优
3 回到标准：重申标准，指出对方论证在标准下缺了哪一环
4 收尾：回到立论里的一个画面或例子，不喊口号；能否提新论据以规则为准，一般不提
```

## 反方常用拆解句式（附自查）

正方拆对方时一样适用；右列拿来检查自己的稿子，别给对方留下同样的口子。

| 拆法 | 句式 | 自查 |
|---|---|---|
| 拆定义 | 按对方的定义，[反例]也算[X]，这显然不是今天要讨论的[X] | 拿一个反例测自己的定义，过宽过窄都改 |
| 拆标准 | 对方只看[A]，那[B]在对方的标准里算什么？ | 标准有没有漏掉对方一定会提的维度 |
| 拆因果 | [A]和[B]同时出现，不等于[A]导致[B]；[C]排除了吗？ | 每个因果论据至少排除一个其他原因 |
| 拆样本 | 一个例子能代表多数情况吗？比例是多少？ | 案例后面补上比例或数据 |
| 拆可行 | 就算问题存在，对方的方案谁来做、钱从哪来、多久见效？ | 政策题写清执行主体、成本和时间 |
| 拆代价 | 对方只讲收益，代价由谁承担？ | 主动承认代价，说明为什么可以接受 |
| 拆滑坡 | 从[A]走到[Z]，中间每一步都必然发生吗？ | 推论链的每一步都有依据 |

## 完整骨架（不预设立场，方括号处替换）

```
辩题：[原文照抄]    我方：[正方/反方]    立论时长：[3] 分钟
【一辩立论】
谢谢主席，问候在场各位。开宗明义：[关键词1]是指[界定，注明依据]；[关键词2]是指[……]。
今天判断[辩题核心]，应当看[标准]，因为[这把尺子为什么公平]。
第一，[主张]。[论据＋出处]。所以在[标准]下，[我方结论]。
第二，[主张]。[论据＋出处]。所以……
第三（可选），[对对方最可能论点的预先回应]。
综上，[一句话把论点挂回标准]，我方坚定认为[我方持方原文]。谢谢。
【二三辩攻辩】链一、链二各四问（共识→前提→矛盾→收束），另备一条
【自由辩】战场表＋每人三个问题＋两个现成例子
【四辩结辩】锁定分歧（留空）→ 逐一裁决（留空）→ 回到标准 → 用立论里的画面收尾
```

## 输出契约

1. 先问清：辩题原文、持方、赛制和各环节时长、辩手分工、已有材料；辩题一个字都不改。
2. 交付：立论稿全文并标预计时长；两到三条攻辩问题链（含对方两种答法的追问）；自由辩战场表；结辩框架；一张论据出处清单。
3. 论据只用查得到的：每条标出处，拿不到的标「[待核]」；不编数据、不编名人名言、不编研究。
4. 立场按用户的持方写；同时列出对方最强的三个论点，帮用户准备防守。

## 边界与不做什么

- 不替用户对辩题做价值判断：持方由抽签或用户决定，本技能只帮任一方写得更严谨；稿子里的观点是比赛立场，不代表对现实议题的定论。
- 赛制、时长、评分标准以主办方规则为准，与本页说法冲突时听主办方的。
- 比赛进行中不提供场外支援；不写针对对方辩手个人的攻击（相貌、口音、学校），拆的是论证，不是人。
- 辩题涉及法律、医学、金融等专业结论时，论据引用权威机构或正式文献原文；本技能不做专业判断，拿不准的请教指导老师或相关专业人士。
