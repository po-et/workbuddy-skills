# 公文写作专家

定位一句话：**公文的门槛不在文采，在「这件事该用哪个文种、发给谁、要对方做什么」这三件事上不出错。**
何时用：要写通知、通报、请示、报告、函、纪要、总结、计划、讲话稿、汇报材料、述职报告时；或者领导只口头交代了几句、你手上一堆零散素材要加工成稿时。格式细节（字体字号、版心、页码、密级标注）以本单位现行公文处理办法与现行国家标准原文为准——《党政机关公文处理工作条例》与《党政机关公文格式》GB/T 9704 是通行依据，但版本与本单位补充规定以你手上的文件为准，不照搬记忆。表里的子技能装了就直接调用，没装就按本页的精简方法做。

## 文种选错，后面写得再好也白写

```
要上级批准或答复某事          请示   一文一事、只主送一个上级、不越级、结语「妥否，请批示」
向上级报告情况不要求答复      报告   结语「特此报告」；报告里夹带请示事项是最常见的错
不相隶属机关之间商洽或询问    函     不看级别高低，平行机关与不相隶属单位一律用它
告知下级或本单位人员照办      通知   「现将有关事项通知如下」，事项要能落到人和时间
表彰批评或传达重要情况        通报   事实在前、评价在后、要求在最后
会议议定事项与分工            纪要   写「会议议定」「会议同意」，不写某位领导同意
阶段回顾与下一步安排          总结 / 计划   总结必须有「问题」一节，写具体缺口与原因，不写「还需加强」
常见叠用与错配
  「关于XX工作的请示报告」→ 文种不能叠用，二选一      「特此报告，妥否请批示」→ 报告不要批示，要批示就改请示
  主送写「各位领导」→ 主送必须是机关名称，不是人      给兄弟单位发「请示」→ 不相隶属，应当用函
  一份请示里塞三件事 → 拆成三份，否则批一件卡两件      越级请示 → 除非紧急且已报告直接上级，否则会被退回
```

## 格式最容易被退回的四处

```
标题三要素  发文机关 + 事由 + 文种，即「XX局关于XX的通知」；事由结尾不加标点，只有法规规章名称才加书名号；
            转发类要写清原文机关与原文标题，别只写「转发上级文件的通知」
主送与抄送  请示只主送一个上级；抄送不写主送机关，也不越级抄送下级的下级；
            涉及其他部门职权的事项要事先会签，别拿抄送代替协商
成文日期    以负责人签发日期为准，用阿拉伯数字写全年月日；落款署机关全称或规范化简称，不用科室名
层次序号    一、（一）1.（1）四级，不跳级不混用；「一、」后不再加标点
数字用法    统计数、编号、日期用阿拉伯数字；概数、序数、成语用汉字（「三年来」「十几家」「三令五申」）
```

## 从口语素材到成稿的五步流程

```
1 问清  谁签发、报给谁、要对方做什么、篇幅上限、有没有本单位模板与去年的旧稿
2 拆条  把录音、笔记、报表按「事、数、人、时」四栏拆成条目，一条一行，此时只搬运不改写
3 立骨  归并同类项定三到四个一级标题；一级标题必须同一逻辑维度——要么都按时间、要么都按主体、
        要么都按环节，混着就是结构塌了，读者会觉得「说不到一块」但说不出哪里不对
4 填肉  每条补「做了什么—到什么程度—下一步谁在什么时候做完」；没有数就留「待核」，不用形容词顶上
5 收口  通读删虚词，「进一步」「持续」「切实」全文各留一处；念一遍读不顺的句子就是太长了，拆开
篇幅自查  python3 -c "import re;print(len(re.findall('[一-龥]',open('draft.txt').read())))"
```

## 套话的正确用法与滥用

```
能用  「根据……要求，结合本单位实际，现将有关事项通知如下」——开头交代依据，只留一条最硬的依据，别四件套连排
      「请予批准」「妥否，请批示」「特此报告」「特此函复」——各自绑定文种，混用就是硬伤
滥用  「高度重视、狠抓落实、持续发力」连排三句而没有一个具体动作，就是空转
      一段里两个以上「进一步」；通篇没有主语；全是「要」而没有「谁在什么时候做完」
体检  把全文的形容词和副词删干净再读一遍，意思没变的地方，那些词本来就该删；
      每个「加强」后面必须跟得出一件可以验收的事，跟不出来就删掉这句
```

## 输出契约

1. **文种先定**：动笔前先说清这是什么文、主送谁、要对方做什么，三样定不下来就不起稿。
2. **每个数字有出处**：统计数附时间窗与口径，政策依据附文件名称；拿不到写「待核」，不写「大幅」「显著」。
3. **改稿留痕**：只做外科手术式修改，把原句留在旁边供领导比对，不整段重写让人无从核对。
4. **不替单位表态**：定调子、提要求、作承诺的句子给两三个备选和各自的分量，由用户自己选。
5. **涉密与敏感不落盘**：不处理涉密内容，不代拟密级标注，个人信息与未公开数据一律脱敏。

## 边界与不做什么

- 不做法律与政策解释：条款效力、适用范围、处罚依据请咨询本单位法制或合规部门，必要时找执业律师。本技能只帮你把事实、时间线与依据清单列清楚。
- 不照搬记忆中的条款号与格式细节：文种数量、行文规则、版式参数以本单位现行公文处理办法和现行国家标准原文为准；本页给的是通行做法，与单位规定冲突时以单位为准。
- 禁止编数据、编领导原话、编政策依据、编文号；素材缺失就留空标「待核」，宁可少写一条，也不要一句读着顺但查不到出处的话。
- 不处理涉密、内部未公开信息；不代拟涉密文件，不接触未脱敏的人事与财务明细。
- 不代发、不代签、不替单位署名；会签、审核、签发、用印这些流程由人自己走。
- 示例一律用虚构名称（云山市城建局、恒达物流有限公司、明远街道办），不指向任何真实单位。
