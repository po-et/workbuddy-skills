# 检讨书

定位一句话：**检讨书好不好，不看认错的调门多高，而看读的人能不能一眼找到四样东西——发生了什么、错在我哪一步、影响了谁、以后具体怎么改。**
何时用：老师或辅导员要求写检讨；工作出了差错，领导让写检讨或情况说明；迟到、旷课、旷工被要求书面说明时。已经进入处分或调查程序的，先看文末「边界与不做什么」。

## 先判断：写检讨书还是情况说明

| 对方要什么 | 写哪种 | 写到哪一步 |
|---|---|---|
| 错误已确认，要你认错并保证不再犯 | 检讨书 | 事实、责任、影响、整改四层都要 |
| 事情还在查，要你把经过讲清楚 | 情况说明 | 只写时间线和事实，不下结论、不自我定性 |
| 你有责任，别人或流程也有问题 | 检讨书 | 只检讨自己那部分；流程问题写成改进建议，不点名指责 |
| 已进入处分、调查或申诉程序 | 不在本技能范围 | 先问清程序，见文末边界 |

动笔前问清四件事：交给谁（班主任、辅导员、直属领导、人事）；有没有字数要求；手写还是打印；要不要当众念。当众念的稿子句子要短，也不能写别人的隐私。

## 四层拆解：分五步写

```
第 1 步 事实：时间、地点、我做了什么、谁发现的。只写旁人能核对的内容，主语用「我」。
        检查点：每句都经得起对方拿记录来对；「一时糊涂」「不小心」不算事实。
第 2 步 责任：写清错在哪个具体环节——明知规定没遵守、该核对没核对、该请假没请假。
        检查点：挑出含「因为」的句子，主语不是自己的，要么删，要么补一句「但我本可以……」。
第 3 步 影响：写到具体的人和事——同学多等了二十分钟、客户收到错误报价、班级被扣分。
        检查点：不夸大（一次迟到不是「给集体抹黑」），也不缩小（有没有影响由对方判断）。
第 4 步 整改：每条都是「做什么＋从哪天起＋谁能检查」；工作失误再分两段：已做的补救、防再犯的办法。
        检查点：每条都能被别人验收，验收不了的就是口号，删掉。
第 5 步 收尾：一句表态加请求监督；落款写全姓名、班级或部门、日期。
```

字数要求比内容多时，按这个顺序补真细节：事实层补完整时间线（之前、经过、被发现后）；责任层补「哪几个节点本可以停下」；影响层按对象分写（老师、同学、班级，或同事、客户）；整改层给每条补上检查方式和复盘时间。补完仍不够，宁可短一点，也不要注水。交之前数一下（草稿存成 draft.txt）：

## 三种场景模板（方括号处替换）

```
【校园违纪】
检讨书
尊敬的[李老师]：
[X月X日]第[N]节[课程]课上，我[具体行为，如：用手机看视频]，被您当场发现。
错在我明知[哪条班规或校规]，还是[做了什么]；当时想着[真实想法]，但这不是理由。
这件事影响了[课堂秩序/同学听讲/班级量化分]，也让您中断了讲课。
我的改正办法：1. [如：上课前把手机交班长保管，放学再领]；2. [如：本周五前补齐这节课笔记，交您检查]；3. 请[同桌/班长]随时提醒我。
请老师和同学们监督。
检讨人：[姓名]  [班级]  [日期]

【工作失误】
关于[事项]失误的检讨
[称呼]：
[日期]，我在[负责的工作]中[具体错误，如：报价单单价写错]，于[时间]由[谁]发现。
问题出在[哪个环节，如：发送前没有按清单核对]，这是我的责任。
造成的影响：[延误多久/涉及几张单据/客户反馈；没核实的数字写「待核」]。
已做的补救：[时间＋动作＋当前状态，如：当天致电客户说明并重发正确版本，客户已确认]。
防再犯：1. [如：报价发出前按三项清单自查]；2. [如：金额超过[ ]元的由[岗位]复核]。
检讨人：[姓名]  [部门]  [日期]

【迟到旷工】
关于[日期]迟到（旷工）的检讨
[称呼]：
我[日期]应于[时刻]到[岗/校]，实际[时刻]到（或：全天未到，也没有请假），与考勤记录一致，本月累计[N]次。
原因是[如实写]；但我没有[提前告知/按规定请假]，这是我的问题。
这让[同事临时代班/交接推迟/班级考勤扣分]。
改正：[如：闹钟提前到[时刻]，[时刻]前出门]；遇到特殊情况，至少提前[时长]向[谁]请假。请[考勤负责人]监督。
检讨人：[姓名]  [日期]

【附：情况说明——责任未定、事情还在查时用】
关于[事项]的情况说明
[称呼]：
现将[事项]经过说明如下：
[时间1]  [发生了什么、谁在场、我做了什么]
[时间2]  [……]
[时间3]  [我何时向谁报告了此事]
以上情况属实，相关记录（[聊天记录/单据/考勤]）可供核对；如需补充，我随时配合。
说明人：[姓名]  [日期]
```

忘了请假导致旷工的，检讨之外还要补请假手续，可配合请假条技能 `leave-request-note`。

## 最常见的写砸方式

| 写砸方式 | 典型句子 | 改法 |
|---|---|---|
| 推责 | 「同事没提醒我」「路上太堵」 | 外部原因最多一句，紧跟着写自己可控的那一环 |
| 空话 | 「深刻认识到错误的严重性」连写三段 | 每句表态后面跟一个可验收的动作，跟不出来就删 |
| 过度自贬 | 「我辜负了所有人，我不配……」 | 情绪不等于诚意，读的人会担心你，或觉得在表演 |
| 夸大影响 | 一次迟到写成「给集体抹黑」 | 影响写到具体的人和事，定性留给对方 |
| 编造细节 | 编病因、编交通事故 | 一经核实，事情就从违纪变成诚信问题 |
| 抄范文 | 字数够了，事实对不上 | 老师一眼看得出；宁可短而真，不要长而假 |

改写示范（同一件事，推责加空话 → 四层齐全）：

```
改前：由于最近工作太忙，加上同事没有提醒，我不小心把报价写错了。我深刻认识到错误的严重性，今后一定严格要求自己，杜绝此类事情再次发生。
改后：5 月 12 日我发给客户的报价单里，[A 型号]单价把[1200]元写成了[120]元，当天下午客户来电询问才发现。发送前我没有按清单核对金额，这是我的责任。当天我已致电客户说明并重发正确报价，客户已确认。今后报价发出前，我按型号、数量、单价三项逐一核对，金额过万的请[主管]复核。
```

## 输出契约

1. 先问后写：交给谁、什么事、字数和形式要求；缺的事实留「[待补]」，不替用户编时间、原因和数字。
2. 交付三样：可直接誊抄的正文；四层对照（事实、责任、影响、整改各在哪几句）；一份需要用户本人核对的事实清单。
3. 字数贴着要求走，默认不超出一成；不够就补细节，不加口号。
4. 用户叙述里责任明显不清，或自称被冤枉的，先建议写情况说明，并当面和老师或主管沟通，而不是先认下来。

## 边界与不做什么

- 不代替纪律处分程序中的正式陈述、申辩或申诉材料：涉及纪律处分、违纪调查、解除劳动合同的，材料会进入正式程序、影响本人权益，先向班主任、辅导员、学校学生管理部门或单位人事问清程序和期限，需要维权时咨询律师。
- 不写与事实不符的检讨，不帮人替别人顶责；不做责任认定，也不做法律定性。
- 涉及欺凌、骚扰、打架受伤、安全事故或违法行为的，不是一份检讨能解决的：告诉老师、家长或单位负责人，必要时报警。
- 未成年学生的检讨，建议交之前给家长看一遍。
