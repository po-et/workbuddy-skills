# 检讨书

定位一句话：**检讨书好不好，不看认错的调门多高，而看读的人能不能一眼找到四样东西——发生了什么、错在我哪一步、影响了谁、以后具体怎么改。**

## 何时使用

用户这样说时用：

- 「帮我写份检讨」「检讨书怎么写才不空」
- 「上课玩手机被收了，老师让写一份 800 字的检讨书」
- 「给客户报错了价格，领导让写检讨，怎么写才不像推卸责任」
- 「这个月迟到三次，人事要我交一份情况说明」
- 「帮我看看这份检讨，老师说太空了」

也就是：老师或辅导员要求写检讨；工作出了差错，领导让写检讨或情况说明；迟到、旷课、旷工被要求书面说明时。

不适用：

- 已进入纪律处分、违纪调查、解除劳动合同或申诉程序，要写正式陈述、申辩材料：先向班主任、辅导员、学校学生管理部门或单位人事问清程序和期限，需要维权时咨询律师（见文末边界）。
- 涉及欺凌、骚扰、打架受伤、安全事故或违法行为：不是一份检讨能解决的，先告诉老师、家长或单位负责人，必要时报警。
- 只需要请假条或补请假手续：用请假条技能 `leave-request-note`。

## 先判断：写检讨书还是情况说明

| 对方要什么 | 写哪种 | 写到哪一步 |
|---|---|---|
| 错误已确认，要你认错并保证不再犯 | 检讨书 | 事实、责任、影响、整改四层都要 |
| 事情还在查，要你把经过讲清楚 | 情况说明 | 只写时间线和事实，不下结论、不自我定性 |
| 你有责任，别人或流程也有问题 | 检讨书 | 只检讨自己那部分；流程问题写成改进建议，不点名指责 |
| 已进入处分、调查或申诉程序 | 不在本技能范围 | 先问清程序，见文末边界 |

动笔前问清四件事：交给谁（班主任、辅导员、直属领导、人事）；有没有字数要求；手写还是打印；要不要当众念。当众念的稿子句子要短，也不能写别人的隐私。

## 四层拆解：分五步写

```
第 1 步 事实：时间、地点、我做了什么、谁发现的。只写旁人能核对的内容，主语用「我」。
        检查点：每句都经得起对方拿记录来对；「一时糊涂」「不小心」不算事实。
第 2 步 责任：写清错在哪个具体环节——明知规定没遵守、该核对没核对、该请假没请假。
        检查点：挑出含「因为」的句子，主语不是自己的，要么删，要么补一句「但我本可以……」。
第 3 步 影响：写到具体的人和事——同学多等了二十分钟、客户收到错误报价、班级被扣分。
        检查点：不夸大（一次迟到不是「给集体抹黑」），也不缩小（有没有影响由对方判断）。
第 4 步 整改：每条都是「做什么＋从哪天起＋谁能检查」；工作失误再分两段：已做的补救、防再犯的办法。
        检查点：每条都能被别人验收，验收不了的就是口号，删掉。
第 5 步 收尾：一句表态加请求监督；落款写全姓名、班级或部门、日期。
```

字数要求比内容多时，按这个顺序补真细节：事实层补完整时间线（之前、经过、被发现后）；责任层补「哪几个节点本可以停下」；影响层按对象分写（老师、同学、班级，或同事、客户）；整改层给每条补上检查方式和复盘时间。补完仍不够，宁可短一点，也不要注水。交之前数一下（草稿存成 draft.txt）：

python3 -c "import re,sys;t=open(sys.argv[1],encoding='utf-8').read();print('汉字',len(re.findall(r'[\u4e00-\u9fff]',t)),'不含空白的全部字符',len(re.sub(r'\s','',t)))" draft.txt

## 三种场景模板

三套可填空模板（校园违纪、工作失误、迟到旷工）和一份责任未定时用的情况说明，全文见 [references/templates.md](references/templates.md)。挑法：在学校犯错且已确认 → 校园违纪；工作中出错 → 工作失误（已做的补救和防再犯分两段）；考勤问题 → 迟到旷工（事实与考勤记录一致）；事情还在查 → 情况说明（只写时间线，不下结论）。方括号处换成用户给的事实，没给的留 [待补]。

忘了请假导致旷工的，检讨之外还要补请假手续，可配合请假条技能 `leave-request-note`。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话 |
|---|---|---|
| 缺关键信息（交给谁、发生了什么、字数和形式） | 一次只问三件：交给谁；什么时间、做了什么、谁发现的；字数与手写还是打印。其余用默认值：打印版、500 字左右、称呼按对象的常用写法，都标 [待确认] | 「先问三件事：交给谁？哪天、做了什么、谁发现的？有没有字数要求，手写还是打印？」 |
| 事实给不全（时间、数字、原因记不清） | 不替用户编，正文留 [待补]，列进待核对清单 | 「几点到的你记不清，我先写成 [待补]，你对着考勤记录填上。」 |
| 叙述前后矛盾（先说「没请假」，后说「跟主管说过」） | 指出矛盾处，给两种理解让用户选 | 「你前面说没请假，后面说跟主管说过。是①口头说了但没走请假流程，还是②确实没打招呼？两种写法不一样。」 |
| 责任不清，或用户说自己被冤枉 | 不先认下来：建议先写情况说明，只写时间线，再当面和老师或主管沟通 | 「还说不清是谁的责任，先交一份情况说明把经过讲清楚，比先认错更稳妥。」 |
| 超出范围（已进入处分、调查、申诉程序；涉及欺凌、安全事故或违法） | 不写正式陈述或申辩材料；按边界转交学校、单位或律师，必要时报警 | 「这份材料会进入正式程序，先向辅导员或人事问清程序和期限，需要维权就咨询律师。」 |
| 时间紧，只要最小可用版 | 最小版 = 事实一句 + 责任一句 + 影响一句 + 一条带日期和检查人的整改 + 落款，约 150–200 字；之后再按「补真细节」扩写 | 「先给你一版能交的短稿，四层都齐；要凑到 800 字，我们再按顺序补细节。」 |
| 字数要求远超事实能撑起的内容 | 按「补真细节」的顺序补；补完仍不够，如实说差多少，不注水 | 「真细节补完大约 600 字，离 800 还差一些。宁可短而真，也可以问问老师能不能按实际写。」 |
| 用户坚持编造理由、替别人顶责，或要写「我不配……」 | 守住边界，给能做的替代 | 「编的理由一核实，事情就从违纪变成诚信问题；我帮你把真实原因写得得体一点。」 |

## 输出契约

交付物按这个顺序，缺哪部分也保留标题并写 [待补]：

1. **文种判断**：检讨书还是情况说明，附一句理由。
2. **正文**：可直接誊抄——标题、称呼、事实、责任、影响、整改、表态、落款。
3. **四层对照**：事实、责任、影响、整改各在正文哪几句。
4. **待核对清单**：全部 [待补]、[待确认]，以及需要用户本人对着记录核对的事实。
5. **字数**：用上面的命令数出的汉字数和全部字符数，与要求对比。

规则：先问后写，不替用户编时间、原因和数字；字数贴着要求走，默认不超出一成，不够就补细节、不加口号；用户叙述里责任明显不清，或自称被冤枉的，先建议写情况说明，并当面和老师或主管沟通，而不是先认下来。

占位符：[待补] = 只有用户知道的事实（时间、地点、数字、真实原因、姓名落款）；[待确认] = 按默认值写的内容（字数、称呼、手写还是打印），或需要对照记录核实的说法。

交付前自检（逐条答是或否）：

- [ ] 每句事实都经得起对方拿记录核对，没有我编的时间、原因、数字？
- [ ] 责任层的主语是「我」，外部原因最多一句？
- [ ] 每条整改都有「做什么＋从哪天起＋谁能检查」？
- [ ] 没有后面不跟动作的空表态（如「深刻认识到错误的严重性」）？
- [ ] 字数在要求的上下一成以内，而且是用命令数的？
- [ ] 正文里每个 [待补]、[待确认] 都列进了待核对清单？

## 示例

**示例**（人物和细节为虚构）

用户：「上课玩手机被收了，班主任让写检讨，300 字，明天交。」

助手：「先问三件事：哪天、第几节、什么课？当时用手机做什么，谁发现的？手写还是打印？」

用户：「周二第三节数学课，在桌子底下看短视频，看了五分钟左右，被李老师看到收走了。那节课讲新内容，我作业有两道题没做出来。要手写。」

交付：

> **文种判断**：检讨书——错误已确认，老师要的是认错和改正。
>
> **正文**（手写版，句子已拆短）：
>
> 检讨书
> 尊敬的李老师：
> 本周二第三节数学课上，我在课桌下用手机看了大约五分钟短视频，被您当场发现并收走。
> 错在我明知班规不允许上课使用手机，还是把手机带进教室，并在上课时拿出来看。当时我想着只看一会儿不要紧，但这不是理由。
> 这件事打断了您讲课，也影响了周围同学听讲。那节课讲的是新内容，我漏听了一部分，当天作业有两道题没做出来。
> 我的改正办法：
> 1. 从下周一起，每天早读前把手机交给班长保管，放学再领回；
> 2. 本周五前补齐这节课的笔记，把两道没做出来的题弄懂，交给您检查；
> 3. 请同桌在我上课走神时提醒我；下周五放学前，我向您汇报这一周的执行情况。
> 请老师和同学们监督。
> 检讨人：[待补：姓名]  [待补：班级]  [待补：日期]
>
> **四层对照**：事实 = 第 1 句；责任 = 第 2、3 句；影响 = 第 4、5 句；整改 = 三条改正办法。
>
> **待核对清单**：姓名、班级、日期 [待补]；「班规不允许上课使用手机」请对照班规原文 [待确认]；「影响了周围同学听讲」与实际不符就删掉 [待确认]；三条改正办法是建议，确认自己做得到再抄 [待确认]。
>
> **字数**：汉字 260，不含空白的全部字符 301，要求 300 字，在上下一成以内。

## 常见问题（FAQ）

**Q：字数不够怎么凑？**
A：按「补真细节」的顺序补：完整时间线、本可以停下的节点、按对象分写影响、给整改补检查方式。补完仍不够，宁可短一点也不注水。

**Q：事情我懒得细说，能直接给我一篇 1000 字的吗？**
A：可以先给一份带 [待补] 的骨架，但时间、经过、原因必须你来填；编出来的细节一核对就露馅。

**Q：我觉得自己没错，还要写检讨吗？**
A：先写情况说明，只讲经过、不下结论，再当面和老师或主管沟通；不要先认下来。

**Q：检讨书和情况说明有什么区别？**
A：检讨书用于错误已确认，要写齐事实、责任、影响、整改；情况说明用于事情还在查，只写时间线和事实，不自我定性。

**Q：要当众念，稿子要改吗？**
A：要。句子改短、一句一个意思，删掉涉及别人的细节和隐私，念一遍计时。

**Q：迟到是因为生病或家里有事，能写进去吗？**
A：如实写一句原因，重点写为什么没有提前请假、以后怎么请；需要补假的按制度补手续，可配合 `leave-request-note`。

**Q：能直接帮我交给老师，或者发给领导吗？**
A：不代交、不代发。我给你可以直接誊抄或复制的正文，由你本人交；未成年学生建议交之前给家长看一遍。

## 常见错误（反模式）

| 错误做法（典型句子） | 为什么错 | 正确做法 |
|---|---|---|
| 推责：「同事没提醒我」「路上太堵」 | 读的人找不到「错在我哪一步」，像在推卸 | 外部原因最多一句，紧跟着写自己可控的那一环 |
| 空话：「深刻认识到错误的严重性」连写三段 | 没有任何能验收的内容 | 每句表态后面跟一个可验收的动作，跟不出来就删 |
| 过度自贬：「我辜负了所有人，我不配……」 | 情绪不等于诚意，读的人会担心你，或觉得在表演 | 只写错在哪一步、以后怎么改，语气平实 |
| 夸大影响：一次迟到写成「给集体抹黑」 | 失真，反而显得不诚恳 | 影响写到具体的人和事，定性留给对方 |
| 编造细节：编病因、编交通事故 | 一经核实，事情就从违纪变成诚信问题 | 只写真实原因，记不清的留 [待补] |
| 抄范文：字数够了，事实对不上 | 老师一眼看得出 | 宁可短而真，不要长而假 |

改写示范（同一件事，推责加空话 → 四层齐全）：

```
改前：由于最近工作太忙，加上同事没有提醒，我不小心把报价写错了。我深刻认识到错误的严重性，今后一定严格要求自己，杜绝此类事情再次发生。
改后：5 月 12 日我发给客户的报价单里，[A 型号]单价把[1200]元写成了[120]元，当天下午客户来电询问才发现。发送前我没有按清单核对金额，这是我的责任。当天我已致电客户说明并重发正确报价，客户已确认。今后报价发出前，我按型号、数量、单价三项逐一核对，金额过万的请[主管]复核。
```

## 边界与不做什么

- 不代替纪律处分程序中的正式陈述、申辩或申诉材料：涉及纪律处分、违纪调查、解除劳动合同的，材料会进入正式程序、影响本人权益，先向班主任、辅导员、学校学生管理部门或单位人事问清程序和期限，需要维权时咨询律师。
- 不写与事实不符的检讨，不帮人替别人顶责；不做责任认定，也不做法律定性。
- 涉及欺凌、骚扰、打架受伤、安全事故或违法行为的，不是一份检讨能解决的：告诉老师、家长或单位负责人，必要时报警。
- 未成年学生的检讨，建议交之前给家长看一遍。
