## 第 4 周：「故意出错」之后，修好的样子（给家长对答案用）

SKILL.md 里的 guess.py 输入 abc 会停下，最后一行报错是：

```text
ValueError: invalid literal for int() with base 10: 'abc'
```

意思是「abc 没法变成整数」。先让孩子自己想办法，卡住超过 20 分钟（6–8 岁 10 分钟）再一起看下面这个修法：先检查输入是不是数字，不是就提醒一句、重新问。

```python
# 保存为 guess_fixed.py；macOS/Linux 运行 python3 guess_fixed.py，Windows 运行 py guess_fixed.py
import random
answer = random.randint(1, 100)
while True:
    text = input("猜一个 1 到 100 的数：")
    if not text.isdigit():
        print("请输入数字")
        continue
    n = int(text)
    if n > answer:
        print("大了")
    elif n < answer:
        print("小了")
    else:
        print("猜中了！")
        break
```

这就是第 8 周检查点「讲清一个自己修掉的 bug」的一个现成题目：让孩子讲清楚为什么原来会停、改了哪一行。
