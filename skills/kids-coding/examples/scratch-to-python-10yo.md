# 示例：Scratch 学了一年，什么时候转 Python

**示例**（孩子情况为虚构；代码在标准 Python 3 里运行过）

## 对话

用户：「Scratch 学了一年，什么时候转 Python？」

助手：「先问两件事：孩子几岁？再请你帮他回答五个问题，是或否就行：
1. 能不看键盘、比较顺地打出英文单词吗？
2. 能看懂简单的英文提示（如 error、name、print）吗？
3. 在图形化工具里自己用过「重复」「如果」「变量」吗？
4. 能专注做一件事 30 分钟以上吗？
5. 想做的东西在图形化里已经很费劲（算术、文字处理、数据）吗？」

用户：「10 岁。打字还行但要看键盘；英文提示能看懂；重复、如果、变量都用过；能专注；最近想做计算器，嫌积木拖起来太麻烦。」

## 交付

**起点判断**：五个问题里「是」有四个（第 2、3、4、5 题；第 1 题打字还要看键盘，算「否」）。按「学过图形化」那条，第 1、3、5 题没有全答「是」，还不到完全转过去的时候；按 9–10 岁那条，「是」有四个，可以图形化和 Python 双线并行。结论：**双线并行**——Python 这条线用两周过渡起步（翻译他做过的旧作品），同时练打字；等第 1 题也变成「是」，再以 Python 为主。他已经在嫌积木麻烦，Python 正好接上。

**两周过渡**：

- 第 1 周：对照积木学写法，每次挑两三条，边看边在 IDLE 里敲一遍：

```text
说「你好」               →  print("你好")
询问并等待，得到回答     →  name = input("你叫什么？")
把「分数」设为 0         →  score = 0
把「分数」增加 1         →  score = score + 1
如果……那么……否则         →  if 条件:  和  else:
```

- 第 2 周：挑一个他做过的图形化计分问答，用 Python 重写成文字版，不要画面：

```python
# 保存为 quiz.py；macOS/Linux 运行 python3 quiz.py，Windows 运行 py quiz.py
score = 0
answer = input("3 + 4 等于几？")
if answer == "7":
    score = score + 1
    print("答对了！")
else:
    print("再想想，答案是 7")
answer = input("8 - 5 等于几？")
if answer == "3":
    score = score + 1
    print("答对了！")
else:
    print("再想想，答案是 3")
print("一共答对", score, "题")
```

运行时依次输入 7 和 3，最后一行显示「一共答对 2 题」。让他再加一道自己出的题，就是「加」的那一步。

**8 周计划**：过渡完进入 8 周计划的 Python 一列（全表见 [../references/8-week-plan.md](../references/8-week-plan.md)），第 5 周的「口算练习器」正好对上他想做计算器的兴趣。图形化照样可以玩，想做带画面的游戏时用图形化更快。

**节奏**：每次 40–60 分钟，每周 2–3 次（参考值）；需要带键盘的电脑，从 Python 官网装 3.x，Windows 安装时勾选添加到 PATH 的选项，用自带的 IDLE，按 F5 运行。

**最容易卡住的两处**：代码里的括号、引号、冒号、逗号都要在英文输入法下打；冒号后面的下一行统一缩进 4 个空格，不和 Tab 混用。

**家长提问卡**（打印贴在电脑旁）：

```text
卡住时问：你想让它做什么？它现在实际做了什么？你最后改的是哪一处？
看作品问：最难的是哪部分？哪里是你自己想出来的？再加一个功能，你加什么？
```

**下一步**：两周过渡结束后告诉我他重写的是哪个项目、卡在哪里，我们排 8 周计划的第 1 周；8 周后按「独立做完一个小项目、遇到 bug 先自己查、能讲给别人听」三件事决定开第二轮还是重做第 5–8 周。
