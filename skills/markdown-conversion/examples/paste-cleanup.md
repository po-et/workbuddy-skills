# 示例：网页粘贴来的 Markdown，清理前后对照

以下为示例，内容与数据均为虚构。输入文件就是 [messy-input.md](messy-input.md)（故意写乱的练习文件），下面的输出都是本机实际运行结果。

## 1. 用户原话

> 从网页粘贴过来的格式全乱了，帮我清一下，最后要转成 Word 交给别人改。

## 2. 助手先确认

- 方向：Markdown → Word；母版：清理后的 .md（以后只在它上面改）；Word 给别人改。
- 本次先做清理与预检，转换命令放在最后。

## 5. 人工处理（要判断的部分）

表格那一处先问了用户：「第 14 行多出一列『备注』，是①表头补一列，还是②删掉这一格？」用户选①。

| 问题 | 怎么改 | 依据 |
|---|---|---|
| 「**第二部分**」冒充标题 | 改成「## 第二部分」，同时消掉了 # → ### 的跳级 | 清理规则 5：层级不跳级 |
| 表格第 14 行多一列「备注」 | 问过用户，选择在表头补一列「备注」，其余行留空 | 列数必须一致；删还是补属于内容判断，要问 |
| 「1、」「（2）」「•」 | 改成「1. 」「2. 」「3. 」 | 清理规则 6 |
| 替代文字「截图」 | 改成「待补：一句话说明这张图」，由用户补写 | 替代文字会变成图注 |
| 「本季度 新增用户」多出的空格 | 删掉（U+00A0 换成普通空格后留下的） | 中文之间不加空格 |
| 第 4 行行尾原有两个空格（强制换行） | 已删；这里两行本就该是一段，不加反斜杠 | 清理规则 2 |
| 图片找不到 | 请用户把 funnel.png、funnel.svg 放进 img/ | pandoc 按运行目录找图片 |
| SVG | 这次只转 Word，先不处理；以后要转 PDF 先转成 PNG | SVG 走 LaTeX 容易失败 |

## 7. 复查

图片放进 img/ 之后再跑一次：

```
$ python3 {baseDir}/scripts/md_check.py final.md
检查 final.md（29 行）
  [需人工：SVG/WebP 图片] 第 20 行 img/funnel.svg → 转 PDF 前先转成 PNG
```

只剩 SVG 的提醒，和这次转 Word 无关。转换命令（在 final.md 所在目录运行）：

```bash
pandoc final.md -o final.docx --reference-doc=ref.docx   # ref.docx：你的样式模板，没有就先去掉这个参数
```

## 8. 清理报告

- U+00A0 换成普通空格 1 处；删除 U+200B 1 处、U+00AD 1 处、正文中间的 U+FEFF 1 处；删除行首全角空格 2 个；删除行尾空格 2 行（其中 1 行原是强制换行）。
- 人工：标题 1 处、表头补列 1 处、列表 3 行、替代文字 1 处、多余空格 1 处。
- 待补：图注说明；两张图片文件。
