# 图片描述

定位一句话：**先弄清这张图在页面里替读者做什么，再动笔；同一张图放在不同位置，描述可以完全不同。**
何时用：给网页、App、文档、公众号里的图写替代文本（alt）；给商品图写描述；给社媒上的图配文；把一张数据图表讲成文字，给看不到图或没空看图的人。

## 先判断：这张图在干什么

```
装饰（分隔花纹、氛围背景、与旁边文字重复的配图）  alt=""，读屏软件直接跳过；alt 属性本身不能省，缺了会被念出文件名
功能（图标按钮、图片链接）                        写动作或去向：放大镜图标写「搜索」，不写「放大镜」
信息（照片、示意图、截图）                        写这张图在这里要传达的那一件事
图中有字（海报、横幅、截图里的报错）              把字原样写出来，字就是信息
复杂图（图表、流程图、地图）                      alt 只说「是什么 + 结论」，完整数据放正文或图下表格
商品图、社媒配图                                  alt 之外还要一段写给人看的文字，见第三节
```
判断不出时问一句：**把这张图删掉，这一页少了什么？** 少的那部分就是要写的内容；什么都没少，就是装饰图。

同一张照片（李老师站在报告厅讲台前）放三个地方，三种写法：

```
校庆新闻稿      李老师在校庆典礼上致辞，台下坐满校友          ← 读者要知道谁、在什么场合
报告厅预约页    报告厅内景：讲台正对约 200 个阶梯座位，两侧各一块投影幕  ← 读者要判断场地够不够用
博客页眉装饰    alt=""                                        ← 删掉它，这一页什么都没少
```
一组图（商品多图、活动九宫格）：第一张写总述，其余只写和前一张不同的地方，别每张重复一遍品名。

## 写作流程：四步

```
1 定读者与位置  读屏用户、买家还是粉丝；写进 alt、详情页还是正文
2 抓主体        一句话：谁或什么 + 在做什么 / 处于什么状态，主体放句首
3 挑细节        只留和上下文有关的：新闻稿写人物与事件，服装页写颜色版型，教程截图写要点的那个按钮
4 压缩与自检    删掉「图片显示」「这是一张……的照片」——读屏软件本来就会报出这是图像；alt 不超过 125 字符
```
字数自查（中英文都按字符计）：

```bash
python3 -c "import sys; t=sys.argv[1]; print(len(t), '超长，挪进正文' if len(t) > 125 else 'OK')" "粘贴你的 alt"
```
125 是业内常用的经验上限，WCAG 本身不规定字数。超了说明你在写长描述：alt 留一句，其余挪进正文、图注或表格。

## 四种用途：模板与反例

**无障碍 alt**
```
模板  [主体] + [动作或状态] + [与上下文相关的一个细节]
正例  小王在白板前讲解项目排期，身后三位同事在记笔记
反例  图片显示几个人在一个房间里开会的照片      ← 冗余开头，主体模糊，看不出这张图为什么在这
反例  会议 团队 协作 高效 白板 办公室            ← 堆关键词，读屏念出来是一串词
```

**电商商品图**
```
alt 模板  [品类] + [看得见的区分点：颜色 / 材质外观 / 款式] + [视角或场景]
正例      藏青色 V 领针织开衫，平铺正面
详情描述  补图上看不出的：尺码对照、面料成分、色差说明——从商品资料取，不从图里猜
反例      爆款！绝美显瘦开衫 百搭 ins 风          ← 营销词不是描述，读屏用户仍不知道它长什么样
反例      100% 纯羊毛                             ← 图上看不出成分，资料没写就不能写
```
同款多色时，每张图的 alt 都写出颜色，否则读屏用户分不清这几张图的区别。

**社媒配文**
```
模板  图里看不到的背景（时间、地点、为什么拍）→ 一句感受或观点 → 需要时一个互动问题 → 2–4 个话题标签
正例  周六带学生去湿地公园做鸟类调查，一上午记到 23 种。你们那边最近能看到什么鸟？#自然观察 #周末去哪儿
反例  今天去了公园，图就是公园                    ← 重复画面，没有新信息
```
平台提供「替代文字」栏时另写一句 alt；配文代替不了 alt。表情符号会被读屏逐个念出名称，别连排一串；话题标签放句末，英文多词标签首字母大写（#BirdWatching），读屏才能分出单词。

**数据图表文字化**
```
模板  [图表类型]：[主题]，[时间范围与单位]。[一句总体趋势]。[2–3 个关键数字：最高 / 最低 / 拐点 / 同比]。完整数据见下表。
正例  折线图：2026 年 1–6 月月销售额（万元）。2 月最低 35，之后连续 4 个月增长，6 月最高 88，是 1 月（42）的 2.1 倍。完整数据见下表。
反例  如图所示，销售额呈明显变化趋势              ← 没有方向，没有数字
反例  由于 3 月促销，销售额大涨                    ← 图里没有原因，别替数据加因果
```
数字逐个对照原始数据核过；小数位与单位全文一致；只有一条结论就只写一条，别凑。

复杂图表 alt 只放上面那一段，另写长描述放在图下正文或表格里（网页可用 aria-describedby 把图和长描述关联起来），按这个顺序写：

```
1 总述      一句话：这张图讲什么、结论是什么
2 读法      横轴、纵轴、单位；有几条线 / 几组柱，各代表什么
3 走势      每个系列一两句：升降方向、拐点、异常值
4 数据表    完整数值用表格给出，比任何文字都准
```

## 最常见的错误

- 装饰图写了 alt，信息图 alt 却为空：前者浪费读屏时间，后者让人错过信息。
- 拿文件名当 alt：`IMG_2031.jpg`、`banner-final-v3` 会被原样念出来。
- 图标按钮写外观（「齿轮」）不写功能（「设置」）。
- 同一页相邻几张图用同一句 alt。
- 猜看不出来的东西：人物身份、年龄、民族、健康、情绪的原因。只写看得见的（「一位戴眼镜的男士」）；需要写身份时，从图注或用户给的资料里取。
- 图表 alt 把每个数据点念一遍——那是表格的活。

## 输出契约

1. **先给判断**：这张图属于装饰、功能、信息、图中有字、复杂图中的哪一类，附一句理由。
2. **按用途交付**：alt 给 1 条主推 + 1 条备选，标出字符数；电商、社媒、图表各按模板给完整一段。
3. **不确定就标出来**：看不清的字、无法确认的人物与属性、要对原始数据的数字，一律标「待确认」，不猜。
4. **没见到原图时**：只根据用户的文字描述写，并注明「未见原图」。

## 边界与不做什么

- 不做人脸识别，不从长相推断身份、年龄、种族、健康状况等敏感属性。
- 不替商品编造功效、成分、认证；宣传用语是否合规（广告法、平台规则）请找法务或平台客服确认。
- 医学影像、化验单、伤情照片只描述画面，不做任何诊断解读，请找医生。
- 不写误导性描述：合成或修过的图不写成「实拍」，截图不编造上下文。
- 本技能写单张或一组图片的描述；整站无障碍合规评估（逐条对照 WCAG）请找专业无障碍测评人员。
