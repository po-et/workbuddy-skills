# 示例：用统计脚本给业主群做一次活跃度体检

> 聊天记录与成员名单是为演示构造的样例（昵称均为虚构），输出是脚本的真实运行结果，未手改。

## 用户原话（示例）

> 我是小区业主群群主，把这周的聊天记录复制下来存成了 chat.txt，成员名单也整理了一份。想知道群里到底有多少人在说话、什么时候发通知最合适。

## 输入（节选）

`chat.txt`：

```

张阿姨 08:12

李先生 08:15
收到，谢谢张阿姨

赵同学妈妈 09:02
大家好，我是 5 栋新搬来的
……
2026年9月2日 星期三
孙总优选 07:58
新鲜水果团购，扫码进群领券 👉
群主老陈 08:03
@孙总优选 群里不发广告哦（群规第 5 条），麻烦撤回一下，谢谢
孙总优选 撤回了一条消息
……
```

`members.txt`：每行一个群昵称，共 16 行（`#` 开头的行是注释）。

## 命令

```bash
python3 scripts/chat_stats.py chat.txt --members members.txt --list-silent
```

「撤回了一条消息」「邀请……加入了群聊」这类系统提示没有算成发言；不在名单里的发言人是那个广告号。

## 助手的解读（交付物）

```
【结论】
1. 通知时间：本群早 8–9 点最热闹，物业和群主的通知放在 8 点前后发，当天 12 点再提醒一次。
2. 沉默比例 44%：业主群以看通知为主，这个比例本身不说明问题；下月同期再跑一次比趋势。
3. 沉默名单 7 人都用了「楼栋-姓氏」昵称，说明入群时按群规改过名，大概率是只看不说的业主，不建议清理。
4. 广告号只发了 1 条就被提醒并撤回，处理得当；如果再发，按群规第 7 条的处理梯度公开警告，第三次移出。
5. 深夜 22–23 点有 4 条消息，主要是报修和回复：可以在群公告里写明「夜间报修请直接打物业值班电话 [待补]」。
【下一步】把高峰时段写进月度通知计划；本月回顾公告放在月末早 8 点发。
```
