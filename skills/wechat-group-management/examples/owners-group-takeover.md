# 示例：接手一个乱糟糟的业主群

> 对话与交付物均为示例，群名、昵称为虚构。

## 对话

**用户**：我刚接手我们小区的业主群，快 400 人了。每天都有人发广告，前两天还因为停车位吵起来了。想把群整顿一下，从哪儿下手？

**助手**：先确认三件事，其余我按业主群的常见做法默认：
1. 你现在是群主，还是管理员？（决定能不能改群规、移出成员）
2. 物业有没有人在群里？有没有另外的二手群或团购群？
3. 停车位的争议现在还在吵吗？

**用户**：我是群主，另外有两个邻居愿意当管理员。物业有一个客服在群里，没有二手群。停车的事昨天停了，但火药味还在。

**助手**：好。按「先定规矩 → 再处理存量问题 → 再建立节奏」来，下面是可以直接用的东西。群规里停车相关那条我写成了「只作意见收集」，避免群里投票被当成决定。

## 交付物

```
【一、群的定位（写进公告第一行）】
[XX 小区]业主群：小区公共事务通知与讨论、邻里互助。报修投诉走物业正式渠道。

【二、分工】
群主（你）：群规、公告、最终处理
管理员 A：新人入群核实与欢迎（每天 20:00 统一欢迎一次）
管理员 B：广告与违规处理、处理记录
物业客服：只发正式通知，不参与争论
设置：开启群聊邀请确认、仅群主和管理员可改群名（设置入口以微信当前版本为准）

【三、群规】（采用 references/templates.md 的业主群模板，改了两处）
4. 公共事务（停车、维修资金、业委会等）就事论事、以事实为据；群内接龙和投票只作意见收集，正式决定以法定程序为准
5. 不发广告；二手转让每周六 10:00–12:00 集中发；停水停电以物业正式通知为准

【四、上线公告】（群主发，@所有人一次）
【群规更新】从 [9月X日] 起执行新群规（见群公告）。
改了什么：广告一律不发；二手转让改到每周六上午集中发；公共事务就事论事。
为什么：群里消息太多，重要通知容易被淹没。
有疑问：私聊 @管理员A 或我。

【五、存量问题】
1. 广告：按「提醒 → 警告 → 移出」执行，管理员 B 每次记一笔（日期、昵称、事由、结果）
2. 停车争议：群主发一条降温消息 ——
   「停车的事大家的意见都看到了。现在已知的事实是：[已核实的情况]。
    我会整理大家的意见交给物业和[业委会/居委会]，有进展在群里同步。
    这个话题先暂停，有新情况请私聊我。」
   之后把意见整理成一条，私下转交物业，不在群里继续辩论
3. 冒充物业收费：群公告加一句「任何收费以物业正式通知和正式渠道为准」

【六、每月节奏】
月初 8:00  本月事项汇总（检修、缴费通知来源、活动）
事前 1–2 天  通知；当天 8:00 再提醒
月末 8:00  本月回顾
（发布时间先按 8:00 [待确认]；跑一次统计脚本看本群真实高峰后再调）

【七、一个月后自查】
用 scripts/chat_stats.py 跑本月记录：发言率、集中度、高峰时段；
对照 references/operations-playbook.md 的自查表填「本月 / 上月」两列。
```

## 为什么这样安排

- 先公告新群规再执行，成员有预期，移出广告号时就不会引发「凭什么」的争论。
- 停车这类利益争议，群里只收集意见、不做决定：群主的角色是把意见转交给有权处理的物业、业委会或居委会，而不是当裁判。
- 分工到人、处理留记录，群主换人时可以直接按交接清单移交。
