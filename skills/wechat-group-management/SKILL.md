# 微信群管理

定位一句话：**先定位、再立规矩、再建节奏——群规一屏读完，违规处理有梯度有话术，每月用数据自查一次；全程手动运营，不碰任何个人微信自动化。**

## 何时使用

- 「刚接手一个业主群，天天有人发广告，从哪下手？」
- 「帮我写个班级群的群规，要简短」
- 「新人进群怎么欢迎？群公告怎么写才有人看？」
- 「客户群冷清没人说话，一个月的活动怎么排？」
- 「群里两个人吵起来了，群主该怎么说？」
- 「想清理一批不说话的人，怎么做不得罪人？」

不适用：
- 要机器人自动欢迎、自动回复、定时群发、自动踢人、批量拉人 → 不做，原因见「边界」；企业的客户群运营可以看企业微信官方提供的客户群功能，具体以企业微信管理后台和官方文档为准。
- 诈骗、诽谤、泄露隐私等纠纷的法律定性 → 保存证据，用微信的投诉功能举报，必要时报警或咨询律师。
- 公众号、视频号、朋友圈的内容运营 → 不在本技能范围，只简答方向。

## 第 1 步：先定位群的类型

| 类型 | 目标 | 规矩松紧 | 节奏 | 沉默多正常吗 |
|---|---|---|---|---|
| 社群（兴趣、学习、付费） | 交流与成长 | 中：鼓励讨论，严禁广告 | 每周固定栏目 | 不太正常，要找原因 |
| 客户群（门店、品牌） | 通知、福利、答疑 | 严：只做通知与答疑 | 固定时段，每天有上限 | 正常，看通知有没有触达 |
| 公共事务群（班级、业主） | 通知与公共事务 | 严：就事论事、保护隐私 | 按需通知 + 月度汇总 | 正常，看接龙完成率 |

## 第 2 步：建群设置与分工

1. 群名写清对象和用途，如「XX 小区业主群」「XX 班家长群」。
2. 分工到人：群主定规矩和最终处理；管理员分别管新人欢迎、违规处理与记录。
3. 人多或公共事务群开启群聊邀请确认，只让群主和管理员改群名（设置入口与可用选项以微信当前版本为准）。
4. 群规放进群公告，一屏读完。
5. 欢迎语用固定模板；一批人进群时每天固定时间统一欢迎一次，避免刷屏。

## 第 3 步：群规、欢迎语、群公告

三种群的群规模板（社群、客户群、班级群与业主群）、单人与批量欢迎语、通知 / 活动 / 规则更新三类公告模板，见 [references/templates.md](references/templates.md)。写群规的三条原则：
- 顺序固定：这个群做什么 → 欢迎做的事 → 不要做的事 → 怎么处理；
- 每条都能判断是否违反：写「不发广告、拉人、二维码」，不写「文明发言」；
- 带版本日期，改了就发「群规更新」公告。@所有人每周不超过 1–2 次，否则大家会开免打扰。

## 第 4 步：节奏

一月四周：第 1 周开场破冰，第 2 周干货或福利，第 3 周互动，第 4 周复盘与预告；运营消息固定在本群高峰时段发（用脚本看），每天有上限。公共事务群换成「月初汇总 + 事前通知 + 月末回顾」。完整节奏表见 [references/operations-playbook.md](references/operations-playbook.md)。

## 第 5 步：处理违规与冲突（提醒 → 警告 → 移出）

| 级别 | 适用 | 动作 |
|---|---|---|
| 提醒 | 初犯、轻微（偶发广告、跑题刷屏） | 私聊，请本人撤回 |
| 警告 | 再犯或较重（明显推广、人身攻击、传谣） | 群内公开，说明依据哪条群规 |
| 移出 | 第三次，或严重（诈骗、色情、泄露隐私、冒充老师或物业收钱） | 直接移出，必要时投诉，群内简短说明 |

提醒话术（私聊）：「您好，群里暂不发推广信息（群规第 X 条），麻烦撤回一下；有合作需要可以私聊我，谢谢理解。」吵架时不站队，只讲已核实的事实和下一步，然后转私聊。警告、移出说明、降温、辟谣、防冒充收费的完整话术，以及处理记录的写法，见 [references/operations-playbook.md](references/operations-playbook.md)。

## 第 6 步：自查、清理与交接

- 每月自查：发言率、集中度、新人 7 天内是否发言、高峰时段、公告是否过期——都和本群上月比，不和别的群比。
- 每季度或半年清理：定规则 → 提前 7 天公告 → 人工核对名单 → 拿不准的私聊确认 → 手动移出，只公布人数不点名。
- 换群主按交接清单：权限转让、规则与模板、节奏、处理记录、交接公告、过渡期。
自查表、清理步骤、交接清单与公告模板见 [references/operations-playbook.md](references/operations-playbook.md)。

## 活跃度统计脚本（本地、只读）

`scripts/chat_stats.py` 读取你自己复制粘贴保存的聊天记录文本，统计每人发言条数、时段和星期分布、前 10% 发言人的占比；给了成员数或名单时算沉默比例。自动识别「时间在前」「名字在前」「只有时刻 + 日期行」「没有时间」几种格式，入群、撤回等系统提示不算发言；认不出的格式用 `--pattern` 自定义。

```bash
python3 scripts/chat_stats.py chat.txt --member-count 180
python3 scripts/chat_stats.py chat.txt --members members.txt --list-silent --format md --out report.md
python3 scripts/chat_stats.py chat.txt --member-count 180 --anonymize   # 发言人显示为 成员01…，便于分享
```

真实运行输出与解读见 [examples/chat-stats-report.md](examples/chat-stats-report.md)。

## 信息不全或出错时

| 情况 | 怎么处理 | 对用户说的话（模板） |
|---|---|---|
| 缺关键信息 | 只问 3 个：什么群、多少人；你是群主还是管理员；眼下最头疼的一件事。其余按该类型默认，交付物里标 [待确认] | 「先说三件事：什么群、多少人；你是群主还是管理员；现在最头疼的是什么？」 |
| 描述自相矛盾（说是客户群，又想让群员互发广告） | 指出冲突，给两种定位让用户选：只做通知答疑的客户群 / 另建定时段互推的资源群 | 「客户群和互推群目标相反：要么这个群只做通知和答疑，要么另建一个群定时段互推，你选哪个？」 |
| 超出范围（诈骗、诽谤等违法纠纷） | 给保存证据、投诉、报警或咨询律师的方向，不做法律定性 | 「这已经涉及违法，先截图保存证据，用微信的投诉功能举报，必要时报警。」 |
| 时间紧，只要最小可用版 | 只给三样：一屏群规、一条欢迎语、一条群规上线公告 | 「先把这三样发出去，节奏和清理下周再做。」 |
| 坚持要自动化（机器人、定时群发、自动踢人、批量加好友或拉群） | 拒绝并说明风险，给手动替代或企业微信官方功能的方向 | 「这类工具可能违反微信规则导致封号，我不提供；可以每天固定时间手动欢迎，企业客户群可看企业微信官方功能。」 |
| 统计结果和感觉对不上 | 看下表的退出码与说明；常见是昵称改过、名单写法不一致 | 「报告说有发言人不在名单里，多半是改过昵称，核对名单后重跑。」 |

脚本退出码：

| 退出码 / 提示 | 原因 | 修正办法 |
|---|---|---|
| 0 | 完成 | — |
| 1 | 参数错误：`--list-silent` 没配 `--members`、`--pattern` 不合法或缺 `name` 分组、成员数不大于 0 | 按提示改，`-h` 看用法 |
| 2 | 文件读不了或写不进去 | 检查路径；文本另存为 UTF-8 |
| 3 | 没识别到任何消息 | `--show-unparsed 5` 看前几行，再用 `--pattern` 自定义 |
| 130 | 按了 Ctrl-C | 重跑 |
| 「发言人数超过群成员数」「发言人不在名单里」 | 有人改过昵称，或名单与群昵称写法不一致 | 核对名单后重跑 |

## 输出契约

交付物按固定顺序：
1. **群的定位**：类型、目标，一句话写进公告第一行。
2. **分工与设置**：谁负责什么；要开的群设置（以微信当前版本为准）。
3. **群规**：一屏以内，带版本日期。
4. **欢迎语与上线公告**。
5. **眼下问题的处理方案**：按提醒 → 警告 → 移出，附话术和记录方式。
6. **节奏**：一月四周或月度汇总。
7. **自查安排**：下次复盘时间和要看的指标。

占位符：用户要填的写 [待补]（群名、联系人、时间）；按默认给的写 [待确认]（发布时段、清理周期）。

交付前自检（逐条是/否）：
- [ ] 群规每一条都能判断「违反了没有」？
- [ ] 违规处理按提醒 → 警告 → 移出，每级都有话术？
- [ ] 没有建议任何自动化工具、外挂或批量操作？
- [ ] 沉默名单、违规记录等个人信息没有建议公开？
- [ ] 提到微信功能的地方都写了以当前版本为准？
- [ ] 公共事务群没有把群内投票当成正式决定？

## 示例

**用户（示例）**：帮我写个群规，班级群用的，要简短。

**助手**：（信息够用，直接给；学校名、老师回复时间留 [待补]）

```
【[学校][班级] 家长群 · 群规】（[日期] 版）
1. 本群用于学校与班级通知、需要家长配合的事项
2. 需要回复时请用接龙，不逐条刷「收到」
3. 孩子的个别情况请私聊老师，群里不讨论成绩和隐私
4. 不发广告、拉票、砍价、求点赞、代购
5. 有意见私聊老师或家委会，不在群里争论
6. 群昵称统一为「孩子称呼+家长」；老师 [待补] 点后不回复，紧急请打 [待补]
7. 任何收费以学校正式通知为准，有人以老师名义收钱先电话向老师核实

欢迎语：欢迎 @[新成员]！请先看群公告里的群规，并把群昵称改成「孩子称呼+家长」。
上线公告：【群规更新】从 [日期] 起执行新群规（见群公告），有疑问请私聊老师或家委会。
```

## 常见问题（FAQ）

- **能帮我装个机器人自动欢迎、自动回复吗？** 不能。自动化工具可能违反微信规则导致封号。每天固定时间手动欢迎一次就够；企业的客户群可以看企业微信官方功能。
- **可以在群里点名不说话的人吗？** 不建议。公开点名伤面子也涉及隐私；要清理就先公告规则，再私聊确认。
- **群里有人冒充老师或物业收钱怎么办？** 立即在群里提醒「先电话向本人核实」，移出冒充者，截图后用投诉功能举报，涉及损失的报警。
- **业主群里的投票算数吗？** 只作意见收集。维修资金、业委会等重大事项，正式决定以法定程序为准。
- **客户群一天发几条合适？** 看本群高峰和退群情况，固定时段、设上限，内容以福利和答疑为主；退群明显增多就减量。
- **统计聊天记录会上传吗？** 不会。脚本只在你的电脑上处理你自己保存的文本，要分享报告就加 `--anonymize`。
- **群快满了怎么办？** 按楼栋、年级或主题分群，或拆成「只发通知的群 + 自由交流的群」；分群公告写清各群用途。

## 常见错误（反模式）

- 群规写成大段口号 → 无法判断是否违反，执行时人人不服 → 每条写成可判断的具体行为。
- 一接手就批量踢人 → 引发对立和质疑 → 先公告新群规，再按提醒、警告、移出执行。
- 群主在争吵里站队 → 失去公信力 → 只讲事实和下一步，转私聊。
- @所有人天天用 → 大家开免打扰，真正的通知没人看 → 每周最多 1–2 次，平时用接龙。
- 在群里公开违规者或沉默者名单 → 伤面子、涉及隐私 → 私聊处理，只公布结果人数。
- 用外挂、机器人拉人或自动回复 → 可能被封号，还会骚扰成员 → 手动运营，企业场景用官方工具。
- 客户群里讨论具体订单 → 泄露顾客信息 → 订单和售后一律私聊。
- 群公告写「最终解释权归本店」 → 这类条款可能被认定为不公平格式条款（以市场监管部门规定为准）→ 把规则本身写清楚。

## 边界与不做什么

- 不做任何个人微信自动化：机器人、外挂、自动欢迎或回复、定时群发、自动拉人或踢人、批量加好友、抓取聊天记录的插件。自动化工具可能违反微信规则导致封号，也会骚扰群成员。
- 不刷量、不买粉、不做诱导分享或拉人头，不爬取、不导出他人数据。
- 统计脚本只处理用户自己复制粘贴保存的文本，在本机运行、不联网；报告里的个人信息不外传，分享时匿名。
- 不代发消息，不代为操作任何人的微信。
- 涉及违法的纠纷不做法律定性：保存证据，用微信投诉功能举报，必要时报警或咨询律师。
- 微信与企业微信的功能入口、名称和上限以当前版本和官方说明为准；平台规则以微信官方发布的最新规范为准（例如《微信个人账号使用规范》；企业微信以其官方文档为准）。
