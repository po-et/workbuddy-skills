# 模板：群规（3 种群）、入群欢迎语、群公告

用法：方括号 [ ] 里的内容替换成自己的；用不上的条款整条删掉，不要留空壳。群规控制在一屏内读完，超过 8 条就合并。

## 一、群规模板

### 1. 社群（兴趣、学习、付费社群）

```
【[群名] 群规】（[年月日] 版，入群即视为同意）
一、这个群做什么：[一句话，例：每周一次 Python 学习分享与答疑]
二、欢迎做的事
  1. 提问前先看群公告和精华；提问写清背景、做了什么、卡在哪
  2. 分享与主题相关的资源，注明出处
  3. 就事论事地讨论，欢迎不同意见
三、不要做的事
  1. 广告、拉人、二维码、推广链接（想合作先私聊群主）
  2. 与主题无关的刷屏、连续转发、投票拉票、砍价助力
  3. 人身攻击、地域或群体歧视、违法违规内容
  4. 未经同意公开他人的聊天截图、联系方式
四、节奏：[周三 20:30 主题分享]；[22:00 以后尽量不发消息]
五、违规处理：第一次提醒，第二次警告，第三次或情节严重直接移出
六、管理：群主 [称呼]，管理员 [称呼]；有事私聊管理员
```

### 2. 客户群（门店、品牌、商家）

```
【[店名] 客户群 · 群须知】
1. 本群用于：新品与活动通知、会员福利、使用答疑
2. 通知集中在 [时段] 发，每天不超过 [N] 条，不打扰休息
3. 订单和售后问题请私聊客服 [称呼]，群里不讨论具体订单，避免您的信息外露
4. 请勿在群内发广告、拉人、发其他商家链接
5. 我们不会以任何理由私下要求您转账或扫码付款；遇到冒充客服的，请截图私聊群主
6. 活动规则以当期群公告为准；退群自由，无需说明
```

### 3. 公共事务群：班级群与业主群

班级群（家校）：

```
【[学校][班级] 家长群 · 群规】
1. 本群用于：学校与班级通知、需要家长配合的事项
2. 通知由老师或家委会发布；需要回复时请用接龙，不要逐条刷「收到」
3. 个别孩子的情况请私聊老师，群里不讨论孩子的成绩、表现和隐私
4. 不发广告、拉票、砍价、求点赞、代购
5. 不在群里争论或指责老师、其他家长；有意见私聊老师或家委会
6. 群昵称统一为 [孩子称呼+家长，如「小明妈妈」]（学校另有规定的按学校规定）
7. 老师 [时间] 后不回复消息；紧急情况请打 [学校或老师公布的电话]
8. 任何收费以学校正式通知为准；有人在群里以老师名义收钱，先向老师本人电话核实
```

业主群（小区）：

```
【[小区名] 业主群 · 群规】
1. 本群用于：小区公共事务的通知与讨论、邻里互助
2. 入群请改昵称为 [楼栋-单元，可只写到楼栋]；非业主或租户由群主核实后入群
3. 报修、投诉请走物业正式渠道，群里可以同步进展；不对物业人员人身攻击
4. 公共事务（维修资金、停车、业委会等）就事论事、以事实为据；群内接龙和投票只作意见收集，正式决定以法定程序为准
5. 不发广告；二手转让请到 [指定群或固定时段]；停水停电等以物业正式通知为准，不转发未经核实的消息
6. 不公开他人门牌、车牌、照片、电话；邻里矛盾请私下沟通，或找物业、居委会调解
7. 违规处理：第一次提醒，第二次警告，第三次或情节严重直接移出
```

## 二、入群欢迎语

单人入群：

```
欢迎 @[新成员] 加入[群名]！
1. 先看一眼群公告，群规和常用信息都在里面
2. [公共事务群：请把群昵称改成「XX」格式]
3. 用一句话介绍自己吧：[称呼] + [来自哪里或做什么] + [想在群里得到什么]
有问题随时私聊我或 @[管理员]
```

一批人同时入群（避免刷屏，每天固定一个时间统一欢迎一次）：

```
欢迎今天新加入的 [N] 位朋友：@A @B @C
群公告里有群规和[本周安排]，[周三晚 8 点半]有主题分享，欢迎来听。
自我介绍接龙 👇（格式：称呼 + 做什么 + 想聊什么）
```

## 三、群公告

写法：一屏读完；第一行就说「什么事、什么时候、要你做什么」；需要回复的给接龙或截止时间；写上联系人。@所有人要省着用，每周不超过 [1–2] 次，否则大家会把群设成免打扰。

通知类：

```
【通知】[事项]
时间：[月日 星期 时:分–时:分]
地点或方式：[ ]
需要大家做的：[具体动作]，请在 [截止时间] 前 [接龙/私聊/填表]
联系人：[称呼]
```

活动类：

```
【活动】[主题]
时间：[ ]　形式：[线上分享 / 线下 / 打卡]
报名：[接龙，限 N 人]
规则：[怎么参与、怎么算完成、奖励是什么（如有）]
注意：[安全、费用、不强制参加]
```

规则更新类：

```
【群规更新】从 [日期] 起：
改了什么：[一句话]
为什么改：[一句话]
有疑问：私聊 [管理员]
```

群公告发布后成员会收到提醒，具体提醒方式、谁能编辑公告，以微信当前版本为准。
