# 运营手册：活动节奏、违规处理、活跃度自查、定期清理、交接

## 一、活动节奏表（一月四周）

社群与客户群用这张表；班级群、业主群见表后的说明。

| 周 | 主题 | 形式 | 负责人 | 提前准备 |
|---|---|---|---|---|
| 第 1 周 | 开场与破冰 | 月度计划公告 + 新人自我介绍接龙 | 群主 | 本月日历、接龙模板 |
| 第 2 周 | 干货或福利 | 30 分钟主题分享；客户群换成会员福利或新品介绍 | 嘉宾或店长 | 分享提纲、福利规则 |
| 第 3 周 | 互动 | 话题讨论、有奖问答、打卡挑战（三选一） | 管理员 | 话题清单、奖品 |
| 第 4 周 | 复盘与预告 | 本月精华汇总 + 下月预告 + 意见征集 | 群主 | 精华截图、问卷链接 |

日常规则：
- 运营消息固定在高峰时段发（用统计脚本看本群的高峰），每天不超过 [2–3] 条。
- 每次活动只做一件事，写清怎么参与；接龙代替逐条回复。
- 活动后 24 小时内在群里发一条小结，点名感谢参与者（只点愿意被点名的）。

公共事务群（班级、业主）不追求热闹，节奏换成「月度通知汇总 + 按需通知」：
- 月初：本月重要事项汇总公告（开学、缴费通知来源、检修计划）。
- 事前：通知至少提前 [1–2] 天发，当天再提醒一次。
- 月末：把本月通知整理成一条「本月回顾」，方便新进群的人补看。

## 二、违规处理梯度：提醒 → 警告 → 移出

| 级别 | 适用情况 | 动作 |
|---|---|---|
| 提醒 | 初犯、轻微：偶发广告、跑题刷屏、情绪化发言 | 优先私聊；请本人撤回 |
| 警告 | 再犯，或较重：明显推广、人身攻击、散布未经核实的消息 | 群内公开警告，说明依据哪条群规 |
| 移出 | 三次，或严重：诈骗、色情、恶意拉人、泄露他人隐私、冒充老师或物业收钱 | 直接移出；必要时通过微信投诉功能举报；群内简短说明 |

话术（直接可用，改称呼即可）：

- 提醒（私聊）：「您好，群里暂不发推广信息（群规第 [X] 条），麻烦您撤回一下；有合作需要可以私聊我，谢谢理解。」
- 警告（群内）：「@[昵称] 这是第二次在群里发推广了，按群规第 [X] 条先警告一次，再发会移出群聊。大家看到类似消息也可以私聊我。」
- 移出后说明（群内）：「已将发布 [诈骗链接/违规内容] 的账号移出群聊。提醒大家：群里任何让你转账、扫码领钱的消息都别信，有疑问私聊管理员。」
- 争吵降温（群内）：「两位的意见我都看到了，先暂停一下。[事情] 按事实来说是：[已核实的事实]。大家先冷静，我私下分别和两位聊。」——不站队、不评判人，只讲事实和下一步，然后转私聊。
- 谣言（群内）：「这条消息目前没有正式来源，大家先别转发。[停水停电/放假安排] 以 [物业/学校] 的正式通知为准。」
- 冒充收费（班级群、业主群）：「提醒全体：以 [老师/物业] 名义在群里收钱的，请先电话向本人核实，正式收费只走 [学校/物业] 的正式渠道。」

处理原则：
- 先对事、后对人；公开场合只说依据哪条群规，不翻旧账、不贴标签。
- 每次处理记一笔（日期、昵称、事由、处理结果），交接时要用。
- 涉及违法（诈骗、色情、侵犯隐私、人身威胁）：先截图保存证据，再移出和举报；需要时报警，不在群里做法律定性。

## 三、活跃度自查表（每月一次）

| 项 | 怎么看 | 本月 | 上月 | 判断 |
|---|---|---|---|---|
| 发言率（发过言的人 ÷ 群成员） | 统计脚本 `--member-count` | | | 和上月比趋势 |
| 集中度（前 10% 发言人的消息占比） | 统计脚本 | | | 越高越像「小圈子」 |
| 新人 7 天内是否发过言 | 抽查本月新人 | | | 破冰是否有效 |
| 高峰时段 | 统计脚本 | | | 运营消息是否发在高峰 |
| 群公告最近一次更新 | 看群公告 | | | 超过一个月没更新就过时了 |
| 运营消息与成员自发消息的比例 | 数一下群主、管理员发的条数 | | | 只剩运营在说话，说明内容没打动人 |
| 本月违规处理次数、退群或被移出人数 | 处理记录 | | | 突增要查原因 |

判断原则：所有数字都和本群上月比，不和别的群比；公共事务群沉默高是正常的，看的是通知有没有触达（接龙完成率）。

## 四、定期清理（每季度或每半年）

1. 定规则：写清什么情况会被清理，例如「连续 [3] 个月没有发言也没参加任何活动」「已毕业或转学」「已搬离小区」「广告号」。
2. 先公告：提前 [7] 天在群公告里说明规则和时间，留出申诉渠道（私聊管理员）。
3. 再核对：用统计脚本 `--members 名单 --list-silent` 得到候选名单，逐个人工核对；不在群里公开点名。
4. 私聊确认（可选）：对拿不准的人私聊一句「还需要留在群里吗？」
5. 手动移出并记录；清理完在群里发一句结果（只说人数，不列名单）。

清理必须人工逐个操作，不使用任何自动踢人工具。

## 五、交接给新群主的清单

| 类别 | 交接内容 | 完成 |
|---|---|---|
| 基本信息 | 群名、定位、建群时间、当前人数、群规版本 | [ ] |
| 权限 | 群主转让给新群主（操作入口以微信当前版本为准）；管理员名单是否调整 | [ ] |
| 规则与模板 | 群规、欢迎语、公告模板、常用话术 | [ ] |
| 节奏 | 固定栏目、活动日历、合作方或嘉宾联系人 | [ ] |
| 记录 | 违规处理记录、清理记录、正在处理的纠纷 | [ ] |
| 账号与资料 | 群相关的共享文档、表格、收款说明（资金往来单独对账，不在群里交接） | [ ] |
| 对外说明 | 交接公告：谁卸任、谁接任、新群主自我介绍、有事找谁 | [ ] |
| 过渡期 | 老群主留在群里协助 [2] 周，之后转为普通成员或退出 | [ ] |

交接公告模板：

```
【群主交接】感谢大家这段时间的支持。从 [日期] 起，[新群主称呼] 接任群主，
群规和日常安排不变。有事请找 @[新群主] 或 @[管理员]。我会继续留在群里 [两周] 协助交接。
```
