# 根代理对客户端说明的补充

`review-revised.md` 保留客户端原始文字，作为 AI 说明的样本；四份 `.txt` / `.json` 才是检查脚本的原始 stdout。根代理已逐字节复跑四份 stdout，并核对以下边界：

- 字号取第一个**设置了 `sz` 的层**；若该显式值非法，记录未确定，不再向较低优先级回退。不能把“取第一个有效值”理解成跳过非法显式值。
- 第 4 页三层页内字号均缺失，最终字号未确定；不能把说明中的“不含继承字号”理解为已排除继承。母版、版式与主题继承均在脚本范围之外。
- 这组 PPT 验证两处小字号、覆盖优先级与未知项保留。其他标题/密度等启发式在本样本中没有触发，不能据此声称覆盖了它们的正反行为；单元测试属于另一层证据。
- 说明中的“未做视觉复核”指该 WorkBuddy 任务。根代理另行查看了 ArtifactTool 的 8 张渲染图，仍未完成 PowerPoint GUI 与实际投影验收。

脚本报告、AI 说明、渲染预览和演示软件验收分别记录；以案例 README 和结构化核验中的已确认结果为准。
